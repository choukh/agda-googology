## 翻译账

**主线 “经指定孩子” 那一行取兄弟孩子 c′ + c 的账（2026-11-14，作者定；摆脱侧 YiTB 的编译事实已填入）。**

| 成分 | 来源 | 树的要求逼出？（编译依据） |
|---|---|---|
| 换基本身：在孩子 c′ + c 的层上折该层的 Ω 树 | FGH “参数进下标”（审查的脉络判断）；c′ + c 是不判定地造出的字面上界 | 逼出的是 “原行要换”（`YiRCNeg.main-neg-all`），逼出者是判据，不是合法性；取 c′ + c 这一种**可去掉**：比较表那一行不用它，同一判据对一切 n 过（`YiTBCrit.tb-crit`） |
| 回退尾巴 | 保严格单调，与累加同类 | 在兄弟孩子写法里**逼出**：去掉尾巴就不单调（`YiTBTail.notail`、`nomono`）；在比较表写法里，有条目的两支**不需要**尾巴（`YiTBRow.row-tb`）；没有条目时仍退回带尾巴的原行 |
