>
> **这一篇做什么.** 作者本轮选定 "C 线继续攻: X₂ / 往 Λ", 说明: "攻击 (构造+否定): 先把可数折叠推广到带底种类, 再写 X₂ = lΩ lz (λ c → ls (ofU c)); 不先压缩". 接 [X1Up](X1Up.lagda.md) 接手清单第 1 条.
>
> 1. **带底的可数折叠.** 叠层之间 ($X_1\oplus m\to X_1\oplus i$) 就是 `X1UpFold.ΦU` (底种类一律留, 已不要 `TySupIf.noK`); 新增**越过底**的一段 `X2Fold.ΦB`: 第 $X_1\oplus i$ 层的带路径的值经 `ΦX` 折到 $X_1$, 再经 `PathOutFold.Ψ` 折到 $X_1$ 之下的目标. 路径由 `PH-ΦU`, `PH-ΦX` 给出. 本路没有改写 `TySupIf` 本身 (判断: `ΦU` 已是它在带底时的同式推广, 缺的是越过底的那一段).
> 2. **`lΩ` 层号的折叠** `X2Fold.Ψ₂` (对一切满足接口的 `V`): 种类分两类 (`X2If.ClX`). 低种类是底 $X_1$ 的种类的视图, 照 `PathOutFold.Ψ` 折 (决定与证据都是 `PathOutIf` 的); 高种类 (叠层 $X_1\oplus i$, 带 $i\sqsubset B$ 的字面证据) 对 $X_1$ 之下的目标一律在上: 链从 `topU i` 起, 每项是 `ΦU` 把整个换到第 $X_1\oplus B$ 层的分支折到第 $X_1\oplus i$ 层, 链交给 `ΦB`. 输出由形状合法 (`Sh-Ψ₂`).
> 3. **实例** `X2Inst.I₂`: 层号 $X_2=$ `lΩ lz (λ c → ls (ofU c))`; 种类结构 `XS₂` 的分量 $c$ 用 `X1UpFold.LS (hs c)` (与 `Lv (ls (ofU c))` 逐子句同式, 有限 $c$ 上 `refl`). 换层与路径搬运 (`liftOK`, `PH-cv`) 只证世界有序, 同 X1Up 的做法.
> 4. **闭项** `TX2`: $X_2$ 的地板 `topL₂` ($\Omega_1$ 结点, 分支 $g(c+1)=g\,c\boxplus\iota_c\,\Omega_{\Omega_1+c+1}$), 合法 (`Lg-topL₂`), 带路径 (`PH₂-top`, 定理), 经 `Ψ₂` 折到第 0 层. 证书 `LgB-TX2` (标准 `LgB`), FGH `fghX2`.
>
> **读法 (判断, 没有值的定理).** 按 TySup 的约定 (ψ(a+1)=ψ(a)·ω, ψ(0)=1, 外加累加): 根是 $X_2$ 的 $\Omega_1$ 结点, 对目标 $0$ 同层, 坍缩成链 $d_{n+1}=d_n\boxplus\Psi_2(g(1\boxplus\mathrm{leg}(d_n)))$ (界 $0$ 起); 分支 $g\,y$ 是 $\sum_{c<y}\Omega_{\Omega_1+c+1}$, 每个 $\Omega_{\Omega_1+c+1}$ 结点在第 $X_1\oplus c$ 层坍缩后经 $X_1$ 折到 $0$, 读 ψ₀(Ω_{Ω_1+y}). 链是 $\alpha\mapsto$ ψ₀(Ω_{Ω_1+α}) 的不动点迭代, `TX2` 读 **ψ₀(Ω_{Ω·2})** (Ω = Ω_1). 与 X1Up 的 `TU2` 读法**相同**, 没有高于它 (作者给的目标 "高于 ψ₀(Ω_{Ω·2})" 本路**未达到**). 新的是: 同一个序数由一个 `lΩ` 层号的地板经一次折叠得到, 不由可数层号的对角得到 (同 PathOut 的 `TXL` 对 TySup 的 `TΩΩ`).
>
> **为什么没有更高 (定理与判断).** 高于 ψ₀(Ω_{Ω·2}) 的下一步要第 $X_2$ 层上的值大于地板, 如 $\Omega_{\Omega_1\cdot2}\cdot2$ (`topL₂ ⊞ topL₂`), 或在 $X_2$ 上叠层 (X1Up 那样). 两者都在高种类的分支里放进 $X_2$ 自己的 $\Omega_1$ 结点. 本路的 `Ψ₂` 把高种类的分支**整个换层**到第 $X_1\oplus B$ 层, 而 $X_2$ 的 $\Omega_1$ 结点 (共尾于一切 $X_1\oplus c$) 不在任何第 $X_1\oplus B$ 层里, 不可换: `X2Inst.no-ΩΩ` (定理) 说 `topL₂ ⊞ topL₂` 不带路径. 不换层而直接把分支折到叠层目标, 就要在叠层目标下**留** $X_2$ 的 $\Omega_1$ 结点, 留下时坐标要回灌 ($W\boxplus\mathrm{leg}\,y$, 否则分支里的比较没有公共上界, `Fab4LOm.exact→Sep`), 而回灌后的分支不满足底 $X_1$ 的路径结构 (`nxt = y+1`): 本篇 `shift-kept-not-PH` (定理) 是这个形状在世界 $1$ 里的反例. 所以这一步要改底 $X_1$ 的路径结构 (让进入 $\Omega_1$ 结点后的世界随回灌变), 那是改 PathOut 的实例, 本路没有做 (判断; 不是否定这条路线).
>
> **代价, 如实.** (1) 累加: `Ψ₂` 的 ℕ-极限取部分和 (同 TySupFold, PathOutFold); `leg` (PathOut) 在根的回灌里. (2) 路径机制大于折叠本身 (见行数: `X2Fold` 的折叠 46 行, 实例的路径 89 行). (3) 种类结构用 `LS (hs c)` 而不是 `Lv (ls (ofU c))`: 有限层号字面相同, 变量层号的 `≡` 要函数外延 (否定一路 `NegX2Lv` §4 有不用外延的搬运, 本路没有用). (4) 高种类的分支要可换层 (`CB`), 实例里排除 $X_2$ 的 $\Omega_1$ 结点 (见上).

## §1 闭项真的经过折叠 (定理, 由计算)

`TX2` 的根是链的 ℕ-极限 (根结点同层坍缩), 链的第 0 项又是 ℕ-极限 (分支 $g\,1$ 的根是第 $X_1\oplus0$ 层的新种类, 高种类, 经 `ΦB` 折下来). 由计算, `tt`. 这是形状, 不是值.

```agda
IsLim : HB S⊥ → Set
IsLim (hl _) = ⊤
IsLim hz = ⊥
IsLim (hs _) = ⊥
IsLim (hΩ () _)

Head0 : HB S⊥ → Set
Head0 (hl f) = IsLim (f 0)
Head0 hz = ⊥
Head0 (hs _) = ⊥
Head0 (hΩ () _)

head-lim : Head0 TX2
head-lim = tt
```

## §2 卡点的形状 (定理)

在底 $X_1$ 的路径结构里, 一个 $\Omega_1$ 结点若在坐标 $y$ 处放 "回灌后的坐标 $1\boxplus\mathrm{leg}\,y$" 层的种类 (直接把 $X_2$ 的 $\Omega_1$ 结点留到叠层目标时的形状), 在世界 $1$ 里不带路径: 进入坐标 $1$ 后世界是 $2$, 种类的证据要 $3\lhd2$.

```agda
kept : Cd → HB XS₁
kept y = hΩ (inj₂ (W₀ ⊞ leg y) , inj₂ tt) (λ _ → hz)

no32 : _⊲[_]_ {S⊥} (hs (hs (hs hz))) tt (hs (hs hz)) → ⊥
no32 (hsuc (hsuc ()))

shift-kept-not-PH : PH W₀ (hΩ κΩ kept) → ⊥
shift-kept-not-PH (_ , p) = no32 (proj₁ (p (hs hz) (hself , tt)))
```

前提可满足: `kept` 是一个具体的第 $X_1$ 层的高度, 世界 $1$ 合法 (`PathOut.lW₀`); 定理说的是这个具体高度不带路径, 不是说一切留法都不行.

## 翻译账

- **新结点, 新字段.** 无新结点. 接口字段: `lvW`/`lgW` (世界的界作叠层层号, 合法), `Ev₂`, `cls` (种类分低/高两类), `CvK`/`cvK`/`cvE` (逐种类换层). 新规则: 高种类对 $X_1$ 之下的目标一律在上, 分支换层后用 `ΦU`; 低种类是底种类的视图, 用底的决定.
- **由树逼出.** (1) 高种类的比较要字面公共上界: `X2If.up` 带 $i\sqsubset\mathrm{lvW}\,W$, 证据来自 $c+1\lhd B$ (PathOut 的世界; 否定一路 `NegX2Lv.no-fixed-m` 说没有固定的可数 $m$ 盖住一切分支). (2) 分支 $c$ 里底 $X_1$ 的种类要 $X_1$ 自己的证据 (`NegX2Lv.no-exact-base-X₂`): `Ev₂` 取 `PSL (hs c)` 的证据, 分类时经 `clP` 读回 $X_1$ 的证据. (3) 高种类坍缩后的值要带路径才能交给 `Ψ` (`ΦB` 的参数), 所以 `PH₂` 对高种类要求 "对带路径的坐标, 换层后的分支带路径"; 搬运只用序 (`liftOK`, 同 X1Up 的 `clP`/`upkE`/`upkA`). (4) 换层不能包含 $X_2$ 自己的 $\Omega_1$ 结点 (`no-ΩΩ`); 直接留它要回灌, 回灌与底的路径结构冲突 (`shift-kept-not-PH`).
- **受记号启发, 如实.** 读法 ψ₀(Ω_{Ω_1+y}), ψ₀(Ω_{Ω·2}) 是对照扩展 Buchholz 记号的判断; 地板的形状同 PathOut 的 `topL` (θ 形).
- **摆脱侧.** 没有读记号的基本列规则. 折叠 `Ψ₂` 是 `PathOutFold.Ψ` 加一个 "高种类" 分支; 新的东西 (分类, 换层, 路径条件) 都由上面 (1)-(3) 的树侧要求说出.
- **攀爬侧.** 读法不升 (ψ₀(Ω_{Ω·2}), 与 X1Up 的 `TU2` 相同). 这一步让 "一个 `lΩ` 层号, 分支是叠层" 有了折叠; 往上要的东西由两条定理划出 (`no-ΩΩ`, `shift-kept-not-PH`).

## 接手清单

1. **让高种类的分支里能有 $X_2$ 的 $\Omega_1$ 结点.** 这是高于 ψ₀(Ω_{Ω·2}) 的第一步 (判断). 两条出口: (a) 改底 $X_1$ 的路径结构, 让 $\Omega_1$ 结点进入后的世界随回灌变 (例如 `nxt W y = (W ⊞ leg y)+1`, 且 `Ψ` 不再在进入处回灌而在结点处记界); 这要一个新的 $X_1$ 实例与新的 `PathOutIf` 实例, `shift-kept-not-PH` 是旧实例里的反例. (b) 高种类的分支不换层, 改为对叠层目标直接折叠 (`Ψ₂` 加叠层目标), 它的输出路径同样碰到 (a) 的问题. 未编译, 判断.
2. **$X_2$ 上叠层 ($X_2\oplus m$, 再对角).** 要把 `Ψ₂` 做成 `X1UpIf` 的底 (`X1UpIf` 要 `P : PathOutIf`, `Ψ₂` 不是 `PathOutIf` 的折叠: 多一个高种类分支). 要么把 `X1UpIf` 的底推广成 "带折叠与路径的种类结构", 要么写 X2 版的 `X1UpIf`. 叠层的链 ($b\boxplus b'$, $b$ 是 $X_2$ 的地板) 正是 `no-ΩΩ` 的形状, 所以先要第 1 条. 判断.
3. **对层号递归 (往 Λ).** 没有写. 卡点 (判断): 每站的折叠是上一站的折叠加一个 "高种类" 分支, 高种类的换层落在上一站的叠层里; 写成对 `LH` 递归要把 "底的折叠 + 叠层折叠 + 越过底" 打包成一个随层号递归的结构 (`CRw` 一路在做压缩, 本路不碰). `tw n` 的一般 $n$ 要坐标层不是第 0 层 (`lΩ k`, $k\ne$ `lz`), 否定一路 `NegX2Bd` 说那里多一个 `leg` 子句 (第 1 层合法化) 是构造, 不是墙 (否定一路结果, 未复核).
4. **值的定理.** 没有. `TX2` 与 `TU2` 的序数值关系要比较两个字面不同的折叠的输出, 本路没有做.
5. **接口盲区.** `cls` 的分类与 `cvK` 的换层之间没有律 (一个高种类换层后的种类是不是 "第 $i$ 层的新种类" 不是律); `CvK` 可以处处为空 (那时 `PH₂` 对高种类结点不成立, 折叠只是不接受这些输入). 判断, 留给否定一路.

## 结论 (按档)

- **[定理]** 接口 `X2If` (`ClX`, 高种类带字面上界证据); 对一切 `V`: 换层 `cv`, 带路径 `PH₂`, 带底的可数折叠 `ΦB`, 链的路径 `PH-chU`, 折叠 `Ψ₂`, 形状合法 `Sh-Ψ₂`; 实例 `I₂` (`cls₂`, `cvK₂`), 搬运 `liftOK`, 换层保路径 `PH-cv`, 地板 `topL₂` 合法 (`Lg-topL₂`) 且带路径 (`PH₂-top`); 闭项 **`TX2`**, 证书 **`LgB-TX2`** (标准 `LgB`), FGH `fghX2`; `comp-Ω`, `comp-0`, `comp-1`, `cls-root`, `cls-new`, `cls-base`, `head-lim`; 边界 **`no-ΩΩ`**, **`shift-kept-not-PH`**.
- **[判断]** 读法: `TX2` ψ₀(Ω_{Ω·2}), 与 `TU2` 相同, 未高于; 卡点的分析与接手清单的出口.
