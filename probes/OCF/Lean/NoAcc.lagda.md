# NoAcc: 去累加, 证书读输入合法 (入口; 构造一路)

> 不含记号. 构造一路 NoAcc (配对否定一路 NegNoAcc), 2026-11-06. 全文 `--safe --without-K --lossy-unification`, 无公设, 无洞, 无停机或正性编译指示, 无 `trustMe`, 不用函数外延, 不用 UIP. 不改任何已有文件. 导入闭包只有 stdlib 与 `OCF.Lean.CRw*`, `OCF.Lean.NoAcc*`.
>
> **任务** (作者本轮选定, 原话 "去累加: 证书读输入合法"; 说明: "摆脱 (构造+否定): 按 NegCRw 的约束, 试不累加、证书读输入合法 (或用 Fab5 的值合法 Mo) 的折叠; 去掉作者说的毛刺"). 约束来源 [NegCRwAcc](NegCRwAcc.lagda.md): 部分和子句不保第一位置; 形状证书加逐点推出像是链; 不累加就得让证书读输入合法.
>
> **结果: 未找到.** 不累加 (ℕ-极限逐点) 而证书读输入合法的折叠, 在 CRw 的层号上**没有找到**; `TU2` 没有重现. 卡点有两处, 一处是编译过的定理 (本路), 一处是否定一路的编译结果加本路的判断:
>
> 1. **同底, 在上的两段折法 (定理, [NoAccStuck](NoAccStuck.lagda.md)).** 把 CRw 的折叠只改 ℕ-极限子句为逐点 ([NoAccFold](NoAccFold.lagda.md) 的 `Φᴾ`), 第 $2$ 层折到第 $0$ 层, 有一个合法输入使输出**不合法** (`not-lg`), 所以 `Φᴾ` 没有任何 "输入 `LgB` ⇒ 输出 `LgB`" 的证书 (`no-cert`). 根是 `route-mismatch`: $N=\lim(0,1,2,\dots)$ 时 $\Phi_{2\to0}N\not\lhd\Phi_{1\to0}(\Phi_{2\to1}N)$. 直接折法对无 $\Omega$ 的部分作用一次, 在上的两段折法作用两次, 两者字面不可比; 逐点的 ℕ-极限把这个不可比直接搬进输出的相邻项. 同一输入上 CRw 的累加折叠合法 (`crw-lg`). 这一处与世界、回灌无关, 有限层 (第 $2$ 层) 就发生.
> 2. **跨底, 留下的 $\Omega_1$ 结点 (判断 + 否定一路的定理).** (a) 定义: 跨底的决定 `dcx` 用 `cmpB`, 公共上界是世界的界, 所以**折叠的定义**要新世界合法. 接口 [NoAccIf](NoAccIf.lagda.md) 的回灌 `sh₀ B c = B ⊞ c` 只在 $c$ 合法时给合法的新世界 (`lg-nx` 读 `LgB e`), 而留下的结点的分支对一切坐标定义, 坍缩链的坐标是折叠自己的输出; 所以在 `NoAccIf` 上写不出跨底的那一步, `Φᴾ` 的跨底部分只好沿用 `CRwIf` (实例 `CRw.I₁` 的回灌 `leg` 是部分和). (b) 值: 否定一路报告 (`NegNoAccX.kept-world-Φᴾ`, 主审复核前不算数): 对本路的 `Φᴾ` (实例 `I₁`), 一个合法且带路径的 $\Omega_1$ 层输入折到第 $1$ 层, 两层 $\Omega_1$ 结点都留下, 输出不合法; 同一输入在 CRw 的累加折叠下也不合法, 根是回灌 $W\boxplus d$ 对世界不单调.
> 3. **对角 `TU2` 写不出 (判断, 读代码).** CRw 的对角 `yU (n+1) = yU n ⊞ TU (yU n + 1)` 要把上一步的输出当层号, 而折叠的**定义**要层号合法 (`dcl` 以层号为 `cmpB` 的公共上界). CRw 用 `LgB-TU` (形状证书) 给出; 逐点的折叠没有证书 (第 1 条), 对角就写不出来, 除非把层号先合法化 (那就是 `leg` 一类的部分和).
>
> **对纲领与目标.** 纲领 1–4 不受影响 (闭项仍是 `Cd`, 无公理, 不读记号; 本路没有新的成品候选). 目标 "让树自足" 的判据 "有树侧的合法性标准": 本路给出一条树侧的信息, **累加不只是由 "证书只看形状" 逼出, 也由 "在上走两段折法" 逼出**: 只要在上的种类先坍缩到下一层再折到目标层, 而 ℕ-极限逐点, 字面第一位置就保不住 (第 1 条, 定理, 对这一个折叠). NegCRwAcc 的判断 "不累加就得让证书读输入合法" 在同底部分被推进一步: 读输入合法也不够, 因为折叠本身在合法输入上不保合法. 去掉累加要么改 "在上" 的写法 (复合式, 见 Fab3Typed, 只到有限层), 要么换关系 (值合法 `Mo` 与值关系, 见 Fab5Val, 那时最终证书不是 `LgB`), 要么限制输入 (见接手清单). 这些都是判断, 穷尽与否是判断.

## §1 闭项 (只有闭项, 没有证书)

**交付拆成闭项与值** (作者 2026-11-05): (a) 闭项照写, (b) 关于它的合法与值, 本路没有定理. `TXᴾ`: $\Omega_1$ 层的地板经逐点的跨底折叠到第 $0$ 层 (同 CRw 的 `TX`, 只差 ℕ-极限子句). `TCᴾ n`: 第 $n$ 层的地板 ($n\ge1$ 时是新种类的 $\Omega$-结点, 地板不含部分和) 经逐点的同底折叠到第 $0$ 层.

```agda
TXᴾ : Cd
TXᴾ = Φᴾ bX hz (wf bX hz) tt b⊥ hz (cx W₀ tt (z⊲ᴮ W₀)) hz topL (PH-topL W₀ hself)

numC : ℕ → Cd
numC zero = hz
numC (suc n) = hs (numC n)

lgC : ∀ n → LgB (numC n)
lgC zero = tt
lgC (suc n) = lgC n

TCᴾ : ℕ → Cd
TCᴾ n = Φᴾ b⊥ (numC n) (wf b⊥ (numC n)) (lgC n) b⊥ hz (sm (z⊲ᴮ (numC n))) hz (top b⊥ (numC n)) tt

fghXᴾ : ℕ → ℕ
fghXᴾ = FGH TXᴾ

fghCᴾ : ℕ → ℕ → ℕ
fghCᴾ n = FGH (TCᴾ n)
```

**读法 (判断, 没有值的定理).** 同 CRw 的约定 (ψ(a+1)=ψ(a)·ω, ψ(0)=1): `TCᴾ n` 读 ψ₀(Ω_n), `TXᴾ` 读 ψ₀(Ω_Ω), 与 CRw 的 `TX` 同. 没有合法证书, 所以这两个读法连 "是不是一棵合法的树" 都没有定理支撑: `TXᴾ`, `TCᴾ n` 合法与否, **未证, 未否定** (第 1 条否定的是折叠对一切合法输入保合法, 不是这几个闭项).

## §3 两边账 (累加 vs 逐点)

**比较对象.** CRw 的 `Φ` (累加) 与本路的 `Φᴾ` (逐点) 只差 ℕ-极限子句一行; 同一个闭项形状 `TX` / `TXᴾ`. 两边都用 CRw 的后继子句 (`mul`, 部分积), 坍缩链 (`chain`, 每点加上前面的和), 地板 (`ΣT`, 部分和) 与回灌 (`leg`, 部分和): 本路**只去掉了折叠的 ℕ-极限子句的累加**, 链、地板、回灌的累加原样留着 (第 2 条说回灌的 `leg` 在 `NoAccIf` 上去不掉; 链与地板没试).

**去掉 ℕ-极限的累加, 省了什么.**

- 毛刺: 输出的 ℕ-极限的第 $n$ 项从 $\Phi f_0\boxplus\dots\boxplus\Phi f_n$ 变成 $\Phi f_n$ 本身 (`e1ᴾ` 对 `e1ᴬ`, 定理). 这是作者说的毛刺在折叠这一子句上的全部.
- 行数: 折叠定义本身不变 (`Φᴾ` 与 `Φ` 都是 27 行); 少用一个 `Σ⁺` (3 行, 但 `CRwPath.PH-Σ` 仍用它).

**加了什么 / 失去什么.**

- 证书: 累加时证书由形状给出 (`Sh-Φ`, `sh→lg`, 约 50 行, 对一切输入, 不读路径). 逐点时**没有证书**: `no-cert` 说 "输入 `LgB` ⇒ 输出 `LgB`" 不成立, 所以不是 "证明义务变重", 而是这一条义务对这个折叠是假的.
- 对角: CRw 的 `TU2` 要上一步输出合法才能当层号 (`LgB-TU`); 逐点时写不出 (§0 第 3 条).
- 证明义务对照 (判断): 若改 "在上" 的写法使单调成立, 读输入合法的证书至少要 Fab3Typed 的 `Ψ-mono` + `Ψ-lg` 那一套 (约 40 行), 再加 sup 层的决定在两个输入上一致 (留下的种类字面相同, 要搬运 `cl`/`along` 的等式) 与跨底的世界对应; CRw 的形状证书一条都不要. 这一项本路没有写成定理.

## §5 翻译账

- **新结点, 新字段.** 无. `Φᴾ` 是 CRw 的折叠改一个子句. 接口 `NoAccIf` 的字段来自树的要求: 回灌对坐标保第一位置 (`sh-⊲`, 单调证书要), 新世界合法读坐标合法 (`lg-nx`, 去掉 `leg` 之后只能这样).
- **由树逼出 (本路新增, 定理).** 逐点的 ℕ-极限加上 "在上走两段折法", 字面第一位置在合法输入上就保不住 (`route-mismatch`, `not-lg`). 所以 CRw 的 ℕ-极限部分和不只是 "证书只看形状" 的代价, 也在替 "在上" 的两段折法兜底 (判断, 对这一个折叠是定理).
- **由树逼出 (判断).** 跨底的决定要世界合法, 是**定义**的要求, 不只是证书的: 在 `NoAccIf` 上去掉 `leg` 后写不出跨底折叠 (§0 第 2 条).
- **受记号启发, 如实.** 读法是对照扩展 Buchholz 记号的判断; 其余沿用 CRw.
- **摆脱侧.** 本路是摆脱侧的一步: 结论是一条定理加两条判断, 说明 "去掉 ℕ-极限的累加" 在 CRw 的形状里走不通的具体位置 (在上的两段折法; 跨底的世界合法). 没有让树说出下一步.
- **攀爬侧.** 无 (读法不升, 没有合法证书).

## §6 接手清单

1. **"在上" 的写法.** 卡点是两段折法 $\Phi_{j\to t}\circ\Phi_{m\to j}$ 与直接折法 $\Phi_{m\to t}$ 在无 $\Omega$ 的部分上不一致. 候选 (判断): (a) 复合式: 每次只折一层 (Fab3Typed), 单调是一步定理, 但只到有限层; 到 sup 层要回答 "无穷多层怎样复合". (b) 输入限制: 只在 "规范" 输入上证保合法 (例如每个无 $\Omega$ 的 ℕ-极限 $x$ 满足 $x\lhd\Phi x$); 判断: $\lim(2,3,4,\dots)$ 也不满足, 规范输入大约就是折叠自己的像, 这有翻译成记号正规形的危险. (c) 换关系: Fab5Val 的值关系下两段折法与直接折法可比是开放的 (Fab5Val 接手清单第 1 条的路线引理), 那时最终证书不是 `LgB`.
2. **跨底.** 去掉 `leg` 要在定义里用到坐标合法: 要么坐标带合法 (Ω-分支只对合法坐标, 即纲领 1 的 "按低层合法树分支"), 那折叠要与证书同时定义; 要么用否定一路提的 "回灌的层都在旧界之上" 的拆分, 只在目标在旧界之下时可行. 否定一路的 `NegNoAccX` 说留下的 $\Omega_1$ 结点在累加与逐点两种折叠下都不 `LgB` (主审复核前不算数), 跨底的合法要先解决世界对回灌的不单调.
3. **对角 `TU2`**: 等 1 与 2.
4. **`TXᴾ` 是否合法**: 未证, 未否定. 有限测试 (`NoAccTest`) 在深度 4 内没测出它与 `TX` 的差别.

## §7 结论 (按档)

- **[定理]** 接口 `NoAccIf`, `PtFold` (定稿 01:40); 逐点折叠 `Φᴾ` (对一切 `CRwIf`), `Φᴾ-pt`; **`route-mismatch`**, **`no-step`**, **`not-lg`**, **`no-cert`**: 逐点折叠在第 2 层的合法输入上输出不合法, 没有读输入合法的证书; `crw-lg`: 累加折叠在同一输入上合法; `Φ-ok`, `NI-Φ` 等不变量; 毛刺的字面形状 `e1ᴾ`, `e1ᴬ`; 闭项 `TXᴾ`, `TCᴾ n` 与 FGH (无证书).
- **[有限测试]** `NoAccTest` 的 `t1`–`t7`.
- **[判断]** 跨底在 `NoAccIf` 上写不出; 对角写不出; 读法; 接手清单的方向. "去累加只有这几条出路" 是判断.
- **未找到**: 不累加、证书读输入合法、覆盖 CRw 层号并重现 `TU2` 的折叠.
