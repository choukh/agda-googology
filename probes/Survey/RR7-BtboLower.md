# 第七次独立审查: BTBO 是下一站闭项的下界

2026-11-11. 审查者是 Opus 5.5 的内部子智能体 (主审建议用 Fable 5.2, 作者定全部 Opus). 次序: 先读规则与对象的定义, 写下自己的看法 ([预览](Reports-2026-11-11/Review7-preview.txt)), 再读已编译的定理陈述, 最后才读回报与台账. 简报与回报原文: [Reports-2026-11-11/Review7.md](Reports-2026-11-11/Review7.md).

## 1 结论 (编译定理, 主审复核)

`D.BTBOᴵ ≼ NA.read NT.T⁺` 无前提成立; 已发表的 BTBO 经同值定理 `BTBO≈` 也成立. 审查者在临时目录里写成两个纯 `.agda` 文件, 主审移入仓库为验收文件 [YiBtboV2](../OCF/Lean/YiBtboV2.lagda.md) (73 行代码) 与 [YiBtboLower](../OCF/Lean/YiBtboLower.lagda.md) (213 行代码), 删接口后 6G 冷编退出码 0, 各只有自己的 Checking 行, 常驻峰值 1.14G 与 1.68G; 禁用构造 0, 没有函数外延, 模块不带参数.

```agda
btbo      : D.BTBOᴵ ≼ read T₃
btbo⁺     : D.BTBOᴵ ≼ NA.read NT.T⁺
src-btbo⁺ : tr₀ S.BTBO ≼ NA.read NT.T⁺
```

不用 `FUNC`, `KEYsuc`, `SpineT`, `ChainP`, `StrChain`, 值单调的任何形式. 前三层一行不改. 这是下界, 不涉及上界与同值.

## 2 证法

链上的不变量只是值序 `D.γ n ≼ read (co (pts m))` (`chainV`, 取 m = 2n). 每一步造前驱嵌入 `emb : ∀ n m → D.γ n ≼ read (co (pts m)) → PEmb (D.L n) (κ (suc m))`, 四段复合 (`PEmb-∘`):

1. 参照层号嵌进它自己的累加规范化 (`PW₃ (V1 (SV-L n))`, 已有).
2. 规范化层号之间, 值序给出嵌入 (`V2′`: `BTBOFullEb.V2` 的副本, 目标一侧只要极限逐项不降 `Mono`; 合法的第 0 层树由 `cp⊑` 满足它).
3. 链点 η 的规范化层号嵌进主线折叠值 `read (F η)` 的字面前驱 (`V3m`, 新的, 对一切合法 η). 后继情形用 `Fsuc` (后继层号上折叠值结构严格升高); 极限情形用 `Blk.Lim`: 主线在极限层号上的顶取部分和, 第 n 块是 `read (psum n)` 之上的一段, 与 `cumsum` 的分块逐块对上; 下一块的像非零, 所以块之间放得下.
4. 平移到下一个链点 (`shift-κ`, 已有).

再由 `Ψ-emb` 得值, 接 `lower-read` 与 `plus≽` 推进不变量, 最后接 `btbo-embⁿ`, `btbo-emb⁺`.

与已编译的否定不冲突 (主审核过机制): `embV→LPO`, `embVˢ→LPO` 否定的是 "值序 x ≼ y 推出 `toLevel x` 到 `toLevel y` 的嵌入, 对一切 (严格的) y"; 这里的目标是规范化层号 `ordᴰ` (有空位) 与下一个链点, 不是同高度的原层号. 不用 `⊑ᴵ` (三处 `no-L` 不涉及), 不用三歧与完备性.

## 3 四类办法的评估 (审查者的判断, 主审标注)

- 换参照: 已发表的 BTBO 多一行 (编译). 在参照框架里造累加的对角线再比: 判断, 第一个障碍与 `FUNC` 同类, 没做. 起作用的是参照框架里的层号规范化 (`BTBOFull` 的 `V1`, `V2`, `Blk`), 早已编译.
- 小改树的设计: 不需要 (编译事实). 部分和是 `V3m` 极限情形用到的结构, 不是障碍.
- `FUNC`, `KEYsuc`, `SpineT`, ψ⁰ 层的链上值单调: 对这个目标不再需要. 它们仍是开放的数学问题, 没有被否定.
