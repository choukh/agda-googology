## 回报原文

#### 1. 结论与位置

**结论: 那一行会被触发. 档位是编译定理, 无前提.** 用的是做法 (b): 写了一个与 `ψ` 同样递归的出现谓词 `Hit P …`, 给出见证 (证明出现) 或否定 (证明不出现).

`Hit` 的读法 (白话): 它逐条对应 `YiRWFold.ψ` 的子句.
- 树到 `zero` 时, 计入底值 β 的出现 `Hβ`.
- 保留判定为 `just` 时, 取某一个分支; 为 `nothing` 时, 取某一步的和项 `G (iter s x₀ n)`, 或者算下一个链元的那次折叠 `C`.
- 底只在被调用的地方计入 (`HB`). 自身行的上折 `Up` 不调用 `ψ`, 只计左项的折叠.
- 到那一行时取参数谓词 `P k h j c′ c`.

所以一个见证就是从闭项出发、到那一行为止的一条有限调用路径. 另外, 参数 `P` 取成一串等式, 由 `refl` 核对, 所以每个位置的参数也是编译过的事实.

| 闭项 | 是否触发 | 层号 ℓ (下标层 k) | c′ | c | 目标 j |
|---|---|---|---|---|---|
| `twᶜ 1` | 不触发 (`no-tw1`, 对任何 `P`) | — | — | — | — |
| `twᶜ 2` | 触发 (`hit-tw2`) | tw 1 ⊕ ↑ (tw 1) (b₁ + b₁), k = 0 | 0 | 0 | tw 1 ⊕ ↑ (tw 1) b₁ |
| `twᶜ n`, n ≥ 2 (含 n = 3) | 触发 (`hit-tw≥2`) | 与 n = 2 相同 | 0 | 0 | 与 n = 2 相同 |
| `EBOᶜ` | 触发 (`hit-Λ2`) | tw 2, k = tw 1 | 0 | 0 | 0 |
| `EBOᶜ` | 触发 (`hit-Λ1`) | tw 1, k = 0 | `proj₁ (next⁺ (next⁺ (Ωt zero)))` | 0 | 0 |

表中 b₁ = `proj₁ (Ωt (tw 1))`, 即 tw 1 的 Ω 树.

**在哪一部分计算里 (问题 2):**
- **`twᶜ 2`:** 位置在顶层 Ω 结点的回灌链里. 具体是由第 1 个链元算第 2 个链元的那次折叠 (链元从第 0 个数起, 目标 tw 1).
  - 先经孩子层往下: 保留结点的分支 0, 到 ℕ 极限层号 tw 1 ⊕ ↑ (tw 1) (`proj₁ (next⁺ (Ωt (tw 1)))`), 取它的第 1 项, 进孩子 1 (Ω 形状); 再取保留结点的分支 0, 到一个 ℕ 后继层号.
  - 这个后继层号上的链调用底. 底的闭包一路上传, 到 ℕ 极限层号的底, 把该层的左项 `cum 0` 按 "经孩子 1" 重折.
  - ℕ 极限那一行用 `emb` 把右项嵌进孩子 1, 嵌入的结果是 `up zero 0 …`, 于是在 Ω 形状的孩子 1 上, 带 `inc` 路径落到那一行.
- **`twᶜ n` (n ≥ 3):** 由 `step` 得到, `step` 本身只是 `0 , inj₁ h`. 第 n 项顶层的第一个和项 (孩子 0 就是 tw (n−1), 折到第 0 层) 的出现类型, 与 `twᶜ (n−1)` 的出现类型逐字相同. 所以会逐项往下, 最后到第 2 项的回灌链那一处.
- **与 K(n) 的关系:** K(n) 用的那次折叠就是 `twᶜ n` = ψ₀(tw n). 对 n ≥ 2, 那一行就在这次折叠之内, 但不在顶层 ℓ = tw n 上, 而在回灌链之下的孩子层与底里.
- **`EBOᶜ`:** 两处都在 Λ 的孩子 tw n (n = 2 或 1) 本身的层号上.
  - 都来自 Λ 的底: 它把 Λ 的左项 (部分和) 按 "经孩子 n" 重折, ℕ 极限一行再把右项嵌进 tw n.
  - `hit-Λ2` 的路径: tw 2 链元 0 的和项, 进 tw 1, 走 tw 1 结点的回灌链, 链的底再上传到 Λ 的底.
  - `hit-Λ1` 的路径: tw 1 链元 1 的和项, 下两层 ℕ 极限, 到 ℕ 后继层号的链, 底再上传.
  - 单独的 `twᶜ 1` 不触发, 但 tw 1 放在 Λ 之下会触发, 差别就在 Λ 的底.

**对后续的意义 (判断):**
- 那一行在 `twᶜ n` (n ≥ 2) 与 `EBOᶜ` 的计算里都在用, 改写它会改动这些闭项的计算, 所以在这一行上花力气与这些闭项有关.
- 三个见证的触发机制相同: 每条嵌入子句都会造出底闭包, 底闭包带着经指定孩子的路径 `inc c u` 去重折, 再经 ℕ 极限一行的 `emb` 碰上嵌入树. 这是对三例的观察, 不是 "只有这一种机制" 的定理.
- c′ = c 与 c′ ≠ c 两种情形都出现.
- 若给塔项顶层加证据的变体 (如 `rb-tw`) 将来用到 EBO 闭项上, 证据会在 tw 1、tw 2 这两处被用到. 这也是判断: `YiRBSib` 里没有 EBO 闭项.
