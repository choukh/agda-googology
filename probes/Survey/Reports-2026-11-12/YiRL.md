### 回报：孩子为 ℕ 极限处的一步（YiRL）

#### 1. 判决

**对纲领与目标的意义。** 用现有关系 `M 2`（不带项序封闭）陈述的判据在 η = 1 处被编译否定，两种换基都是。这不否定换基，也不否定值；按读回域那条实践，读作 "关系太严"。它直接影响本路：ψ₂(Ω_ω) 的基本列第 1 项就是 ψ₂(Ω₁)，所以 η = ω 处用 `M 2` 陈述的判据只能证到 "除第 1 项外逐项成立"。换成按项序封闭的形式（`YiDCRel.M̃` 的形状）后，有限 η 全部通过，η = ω 处逐项通过。ℕ 极限形状的层本身不是障碍。全部工作在验收一侧，没有改树、折叠、合法性。

**第 0 步（临时文件 `RL0.agda`，退出码 0）。**
- 判据可陈述：`M 2 (ψᴺ 2 (E.Ωt ωᵀ)) (proj₁ (g ωᶜ))`，g 取 `gˢ` 或 `gᵗ`；前提 `ωᶜ-M : M⁰ ωᵀ ωᶜ` 可满足。
- 参照的余尾是 ω，基本列第 k 项是 ψ₂(Ω_k)。前几项的余尾（`refl`）：第 0 项 ω，第 1 项 `cΩ []`，第 2 项 `cΩ (natT 1)`，第 3 项 ω。
- c = ω 处折的层：兄弟孩子是 `nd sL (λ n → h₁ (nat 2 + nat n))`，路径 `inc zero self`；目标层 ⊕ c 是 `nd sL (λ n → two ⊕ ↑ zero (nat n))`，路径 `inu`。
- 这一层的 Ω 树各项都是孩子层 Ω 树的嵌入，折叠逐项落到有限层。所以 η = ω 处不需要 ℕ 极限层号上的关系族；`Mω`、`LFω` 没有搬。

- **η = 1 的否定的机制。** ψ₂(Ω₁) 的余尾是 `cΩ []`，关系里只有槽位在第 0 层的 Ω 结点或松弛能给出它。谓词 `Q`（第一位置之下没有这样的结点）沿 `◃` 向下封闭，对第 2 层的自身折叠、上折、加法、`next⁺` 封闭，那一支满足 `Q`。

**第 3 步，一般的 ℕ 极限孩子。**
- 余尾 ω 的任意 η 一步归约到基本列各项，对任意层与路径（`limSL`，无前提）。
- 有限 η ≥ 3 的判据从 c = `nat n` 推广到整个 `M⁰ (natT n) c`（`finᵗ`；`finˢ` 须 `Can`）。
- 封闭后的形式在一切有限 n 上成立，含 n = 1，见证项是 ψ₂(Ω₃)（`fiñᵗ`、`fiñˢ`）。

#### 4. 第一个障碍，精确到引理

1. **η = 1（挡在 c = ω 之前）。** `M 2 (ψᴺ 2 (Ωᴺ 1)) (proj₁ (g c))` 在 c = `nat 1` 处为假。c = ω 处要它，就要证或否定 `Q (proj₁ (gᵗ ωᶜ))`。这需要把 `QF` 推广到层 `fn (2+n)` 朝第 2 层的折叠，即各层上一族谓词（Ω 结点的槽位不在第 0 层，对回灌的分支遗传）。没有做；判断是它成立，于是 η = ω 的判据在 `M 2` 下为假。
2. **兄弟孩子的一般 ℕ 极限。** 缺 `PreOk f a : (m : ℕ) → wˢ (f 0) ∙ from0 (λ k → ℓˢ (f k)) (proj₁ (oˢ (lim f a))) m ≡ wˢ (f m)` 对一般 `lim f a` 成立。相邻步进含 `◃l m`（m ≠ 0）时两条路径字面不同。出路是证 "折叠对 `inc` 链路径的选择不敏感"，或把有限层的 `LF` 对一切 `inc` 路径陈述。未走通，没有否定。
3. **η = ω+1。** 层是 ℕ 极限形状之上的后继，Ω 树的分支在 `Tr (nd sL g)` 里，回灌链要该层上的关系族与折到有限层的保持（`YiLMLow.Mω`、`LFω` 的对应物），并且要对每个满足 `M⁰ ω c` 的 c 的层都有。
