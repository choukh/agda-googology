##### 具名未证前提与接口的精确内容

`Kid₂` 的 `foldᶜ`（这是接口字段；`YiKQSuff.kid` 对语义 Kdˢ 实填它）：

```agda
record Kid₂ : Set₁ where
  field
    Kd : (c : Tr (tw 1)) → E.T → Tr (h₂ c) → Set
    foldᶜ : ∀ c v → Pc c v → (B : Base (h₂ c)) → OKB B
      → (β : Tr⁺ zero) → M⁰ (ψᴺ 0 []) (proj₁ β)
      → ∀ {s y} → Kd c s y
      → M⁰ (ψᴺ 0 s) (proj₁ (ψ (h₂ c) (proj₂ o² c) (rbᶻ (h₂ c)) B zero v β y))
```

语义关系与完整 Lift₂（类型已编译，不是完整前提已有证明）：

```agda
Kdˢ : (c : Tr (tw 1)) → E.T → Tr (h₂ c) → Set
Kdˢ c s y = ∀ v → Pc c v → (B : Base (h₂ c)) → OKB B
  → (β : Tr⁺ zero) → M⁰ (ψᴺ 0 []) (proj₁ β)
  → M⁰ (ψᴺ 0 s) (proj₁ (ψ (h₂ c) (proj₂ o² c) (rbᶻ (h₂ c)) B zero v β y))

Lift₂ : Set
Lift₂ = ∀ {η c} → A.M¹ η c → Kdˢ c (E.Ωt η) (proj₁ (Ωt (h₂ c)))
```

两条路径与关系的域：

```agda
Pc : (c : Tr (tw 1)) → zero ≤ h₂ c → Set
Pc c v = (v ≡ z≤ (h₂ c)) ⊎ (v ≡ z≤ (tw 1) ∙ proj₂ (proj₁ o²) c)
```

`M² = Mᴴ (Sig ℓ²) Low² Kd Nu²`。只有根下标层槽位 `inj₁ (inj₁ tt)` 的 `Low²` 非空，值为 `A.M¹ (E.Ωt η) c`；该槽位的 `Nu² p ν` 为 `ν ≡ []`。继承的更深槽位与孩子槽位在这个验收关系中取空。`Sp` 完全照 `YiLTKid.Top.Sp`：零成立，后继、ℕ 极限、Ω 分支、松弛与 mc 遗传；嵌入的左推导必须是 `mz`。这不要求左项的树本身是 zero，故 `gbx` 仍必须对任意 x 处理底。规范 `leaf²` 的 `Sp` 由 `leafSp` 给出。

这里的 `A.M¹` 固定使用表 `rbᶻ (tw 1)`，孩子关系是既有 `YiLTKid.Sem.Kdˢ`。上层也固定使用 `Ok-tw 2` 与主线表 `rbᶻ (tw 2)`，没有交对任意表的推广版本。
