**形状 (草图; 完整可编译版本见 `R12Scope.agda`)。**

```agda
module G (X Sc : Set) (rt : Sc) (Root : Sc → Set) (Dom : (s : Sc) → Root s → Set)
         (Kid : Sc → Set) (sub : (s : Sc) → Kid s → Sc) where
  data T : Sc → Set where
    zero : T s ;  suc : T s → T s ;  lim : (ℕ → T s) → T s
    nd   : (r : Root s) → (Dom s r → T s) → T s        -- 位置 = 当前作用域的根; 分支留在本作用域
    into : (c : Kid s) → T (sub s c) → T s             -- 进孩子 c
    up   : (c : Kid s) → sub s c ≡ s′ → T s → T s′     -- 回外层 (左加数由此进入)
    hole : T rt → X → T rt                             -- x + (根之外的东西), 只在换环境时出现
    top  : T s → T s                                   -- x + 本作用域那一层的 Ω (形式左加)
-- Path k = ⊤ ⊎ Below k;  Below (suc k) = Path k;  Below (lc k g) = Σ (Raw k) λ η → Path (g η)
-- Raw k = T ⊥ (Path k) … 在根作用域
plus x (into c t)    = into c (plus (up c refl x) t)   -- 不摊平
plus x (up c refl y) = up c refl (plus (into c x) y)
-- 折叠四个函数, 没有 Lw / cmpw / Way / Ext / D:
-- O  ρ K J q b t : 目标层 J 与当前树无关, 结点经自己那一层的链折叠
-- Rl ρ K q r b t : 折到当前作用域根结点的下标层
-- In ρ (suc k) (inj₂ p) b t : 在目标层之内, 结点原样保留; 遇 up 到根则回到 Rl
-- dn ρ K (inj₂ …) t : 把环境 K 换成孩子, 越过孩子根的 up 变成洞
O  ρ (lc k g) J (inj₂ (η , p)) b t = O  id (g η) J p b (dn ρ (lc k g) (inj₂ (η , p)) t)
Rl ρ (lc k g) (inj₂ (η , p)) r b t = Rl id (g η) p r b (dn ρ (lc k g) (inj₂ (η , p)) t)
```

**由构造成立的事 (临时试验, `R12Scope.agda`, 退出码 0, 都是 `refl`)。**
- `plus-into`: 左加不打开嵌入支。
- `O-into`, `Rl-sub`: 在孩子 η 的作用域里折叠 = 在孩子层里折叠, η 只被传递, 不被检查。
- `O-plus-into`: 先左加再折叠仍是孩子里的折叠。
- `keepL`, `keepR`, `keepR₃`: `mis` / `not-out` 的形状 (层号 `ω` 换成任意 `a`; 树是"进孩子 `a+1`, 在根上放结点")。在层 `a+2` 自身、在 `lc k (λ _ → a+2)` 的任意孩子 η、再套一层 `lc`, 折到 `a+1` 的输出都是同一个保留结点, 对变量 η 全称。
- `keep-plus`: 左加数与结点同在孩子里时结点保留, 分支是左加数的折叠。
- `esc-off`: 越出孩子的东西一律 `O` 折叠, 即这个设计不给跨孩子的保留。
