#### (B) 路回报：块内次序倒置

##### 1. 判决

**倒置证出了，是编译定理，无前提，没有用函数外延。** 我交的是严格版：孩子 one 的一棵第 1 层树 `Y₁ + 1`，它的折叠严格高于孩子 two 的 Ω₂ 树 `up β two (Ωt 2)` 的折叠（`inversion⁺`）。非严格版对 `Y₁` 本身成立（`inversion`）。高一层同样成立：孩子 three 的 Ω₃ 树，不高于孩子 two 的一棵第 2 层树（`inversion₃`）。

**Y₁ 是哪棵树。** `Y₁ = Yw zero S₁ = lim (Tw zero S₁)`，`Tw` 是一列第 1 层的树：
- 第 0 项是零。
- 第 n+1 项是第 1 层的 Ω 结点：分支 0 上是第 n 项，分支 c ≠ 0 上是 `zz n + (c+1)`，即 `up (zz n) tt (suc c)`。
- `zz` 是 Ω₂ 树折叠内部的链，与第十五次审查的试验同文。
- 合法性由第一分支给出（`◃w`）。

**Y₁ 读作什么（判断）。**
- 第 n+1 项读作 max(第 n 项, zz n + Ω₁)，所以 `Y₁` 读作 sup_n (zz n + Ω₁)。
- `seed-form`、`zz-step`（都是 `refl`）给出：`zz (n+1) = next (ψs 1 self β₁ (zz n))`，种子 `β₁ = Ω (λ c → Ωt 1 + ι (G c))` 读作 Ω₁·2；`ψs 1 self β` 读作 β·ω^x。
- 所以 zz 1 = Ω₁·ω，zz (n+1) = Ω₁·2·ω^{zz n + 1}，链趋于 ε_{Ω₁+1} = ψ₁(Ω₂)，`Y₁` 读作 ε_{Ω₁+1}。
- 类型保证 `Y₁ < Ω₂`；具体值是判断。
- 常值分支的见证 `Y₀`（分支 c ≠ 0 上是 `zz n + 1`）也读作 ε_{Ω₁+1}，它的 Ω 结点是退化的；`Y₁` 不退化。

**机制。** 两件都是 `refl`：
- `base-same`：孩子 two 在 `up zero tt …` 之后进第 1 层的底，与孩子 one 的底整个记录相同。审查只核了三条路径上的分量相等，这里整条记录相等。孩子 three 对孩子 two 同样成立（`base-same₃`）。这就是审查说的 "进孩子时造的底不认识左边的 x"：孩子 c+1 的低层底与孩子编号无关。
- `lhs-form`：Ω₂ 树的折叠，是一列第 1 层树的折叠的部分和极限。

再加上 `absorb`（对一切后继层号 `suc k`、一切底、一切列）：后继层号上这种部分和极限总被一棵同层的树吸收。证明只用每个 `Tw` 结点折叠的前两行。审查预计的第一个引理（`Tr 1` 上被折叠保持的值序，"ψs 自身目标不读底" 的外延版）因此不需要。

**对纲领与目标的意义。**
- 纲领：诊断文件，树、折叠、合法性一行不改，不进成品。陈述不引用记号；导入闭包经 `YiT2Frame`（它的 `note-cof` 用 `EboLeanDef`）含记号模块。
- 改定义的编译依据：`inversion⁺` 加 `base-same`，原因指到分支侧一行造的孩子底。
- 目标 "树自足"：`inversion⁺` 是纯树侧的陈述，给出一个树侧判据的候选：孩子 c+1 的 Ω 树的折叠，不低于孩子 c 的一切树的折叠。F2 违反它（定理）；记号满足它，因为 ψ₀ 弱单调（判断）。(A)、(C) 两路的新设计可以拿它当编译判据。
- 终点：缺陷在孩子 1→2、2→3 两处有定理，支持 "终点读法要重估"（判断）。

**一处要更正简报的前提（判断）。** 简报引的 "记号里对一切 Y < Ω₂ 有 ψ₀(Ω_Ω+Y) < ψ₀(Ω_Ω+Ω₂)" 太宽。审查 §1 自己写了 ψ₀(Ω_Ω+Ω₂) = ψ₀(Ω_Ω+ψ₁(Ω_Ω+Ω₂))，所以 Y ≥ ψ₁(Ω_Ω+Ω₂) 时取等号。结果是：
- 非严格的倒置在记号里也有对应（取 Y = ψ₁(Ω_Ω+Ω₂)），单独不算证书。`absorb` 本身在记号里也有对应（连续性），不是缺陷。

- 要归到 "左边偏低"，还要一条判断 J：块在 `up β one (Y₁+1)` 上不高于记号。由于 |Y₁| ≈ ε_{Ω₁+1} < ψ₁(Ω_Ω+Ω₂)，在 J 下非严格版也够。
