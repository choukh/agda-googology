##### 4. 第一个障碍

**引理：`A1S`**，即 η = ν+1、c = suc x、已知 `M⁰ ν x` 时的 `S (ψ₁ᵗ (Ωt η)) (suc x)`。

**挡在关系工具上，不在候选 A 的某一行。** 地板、`cut`、`kpA`、`φ` 各行在已证情形里都按预期化简：
- c = 0, 1 时结点落到地板并保留；
- c ≥ 2 时不保留，回灌链在源层；
- ℕ 极限层号的第 n 行字面地是孩子 n 上的 `φ`，底与起点换成前 n 项的折叠。

**具体缺什么：**
- ψ₁(Ω_{ν+1}) 的基本列是 ψ₁(γₙ)，γ₀ = Ω_ν，γₙ₊₁ = ψ_ν(γₙ)。树侧是 `limc (next (φ (zₖ)))`，`zₖ` 是层号 `h₁ x` 上自身折叠的链。
- 要对上，需要层号 `h₁ x` 上的关系 (ν 层的记号项对 `Tr (h₁ x)`) 及其三条保持：上折、自身折叠、`φ`。
- `YiKVRel` 只有 `M⁰`、`M¹`；ν = 0, 1 正是它们够用的两种，即 `a1s-1`、`a1s-2`。

**以下是判断 (纸面，未编译)：**
- **ν = 2 (η = 3) 及一切有限 ν**：缺第 ν 层的关系与对应的保持引理，形状与 `PF`/`QH`/`ΦF` 相同，属于另一路 (YiPH) 那种更高层号锚点的工作。有限的 c 之下字面地有规范的 ν̄ (`two⊴` 的做法可推广)，所以只需在 c = η 处对量化域内一切底证。
- **ν 是 ℕ 极限或更高 (η = ω+1 起)**：`M⁰ ν x` 的 `mL` 情形里各 `h n` 互相独立，把记号层号配到 x 的子层号时可能不保序。保留与否在记号侧按下标大小判，在树侧按路径判，配对不保序时两边判法不一致。对任意 `M⁰` 推导做归纳可能走不通，量化域要先收到配对一致的推导 (回灌链 `chain` 产生的推导是这一类)。这是没有编译否定的判断，只写 "未走通"。
- **tB 第 1 行绕不开整条 A1**：`QH` 在结点处只查链点，但链点的 η 是 ψ₀(Ω_Ω+…) 形的大项，`a1-lim` 沿基本列下降会碰到任意高的后继，所以有限几个点不够。
- **`a1₂` 不能直接改进 `tA≼W`**：`M¹` 在 Ω 结点上只能经第一分支下降，"第 c 支 ≥ ψ₁(Ω₂)" 进不了结点本身的关系。`tA≼W` 用的是空前缀 `PF` 加前缀 Ω_Ω 的 `QH`，没用 A1。
