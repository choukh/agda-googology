## 1. c₁ 的根与 h₁ 的原形

**判断。** 设

- `κ = proj₁ (baseᴱ 3 T₂ (ink self))`；
- `a(d) = T₁ ⊕ ↑ T₁ d`，所以 `T₂ = nd (sΩ T₁) a`；
- `p` 是 `T₂` 的根位置 `inj₁ (inj₁ tt)`。

`chain 2 1 = feed 2 zero`，`child 2 zero = T₂`，`g zero = up zero zero U_T₂`。由 `YiFRStep` 51–63、`YiRWBlock` 138、144–146，以及 `YiTBRow` 81、89–91，第一次 feed 落到 **T₂ 上的 self 折叠**，起点为 κ。随后 root Ω 的 Keep 是 just（`YiRWFold` 42），而 up 的 self 行是 Up（`YiTBRow` 84–86）。因此，忽略证明字段，

```
c₁ = Ω p K
K(d) = proj₁ (Up (a(d)) (down stop d) κ⁺ (U_a(d)))
```

其中 κ⁺ 是原 `baseᴱ 3 T₂ (ink self)`，不是另选的正性证书。

特别地，c₁ 是字面非 zero 的 Ω 根，而非由其“应有序数值”推断非零。`↑` 与 `⊕` 的原定义给出

```
H = h₁ = T₂ ⊕ ↑ T₂ c₁
  = nd (sΩ T₁) q
q(d) = T₂ ⊕ ↑ T₂ (K(d)).
```

所用行为 `YiRWBlock` 133–142。每个 q(d) 都字面非 zero，因为左端 T₂ 非 zero：右端为 zero 时结果就是 T₂，右端为 nd 时结果仍为 nd。

这里必须保留 K(d) 中的 κ。`Up` 在 zero 处返回原起点（`YiRWOps` 143），所以不能把 K(d) 当作一个不含 κ 的“同形小树”。

## 2. 限制底到底变成什么

**判断。** 先定义两个完全按原定义的零层闭树：

```
δ₁ = proj₁ (ψ T₁ (B₀ T₁) zero (z≤ T₁) (Ωt zero) U_T₁)
δ₂ = proj₁ (ψ T₂ (B₀ T₂) zero (z≤ T₂) (Ωt zero) U_T₂)
δ₀ = proj₁ (next⁺ (Ωt zero))
```

δ₀ 的通常序数值为 ω（`YiRWOps` 33–36、55–56、99）。这只是给 δ₁、δ₂ 一个原定义名称，**没有断言它们分别通过了哪个 ψ 记号的值验收**。令 D 为按顺序的零层和 `(δ₀ + δ₁) + δ₂`。

原 `out 2 c₁` 先通过 tw3 的 `inu` 行下降到 H（`YiTBRow` 87–88）；由于该 up 的 x 是 zero，新的限制底恰是

```
B*(i,u) = baseᴱ 3 i (inc c₁ u),     u : i ≤ H.
```

外层起点仍为 `β = betaᴱ 3`，没有随该下降改成 1。

现在展开 `baseᴱ 3`。`YiGIInst` 72–80 与 `YiRWOps` 58–60、38 给出

```
pre 3 = up (up (up zero 0 U_T₀) 1 U_T₁) 2 U_T₂.
```

在 Λ 上，目标路径为 `inc 3 (inc c₁ u)`。源孩子 m 依次为 0、1、2；`way` 的每次结果均把 T_m 嵌入 T₃（`YiRWPath` 179–186）。三个嵌入在 T₃ 的外层都是

```
up zero zero e_m
```

其中 `e_m` 是 U_T_m 沿零孩子链嵌入 T₂ 的结果（`YiRWPath` 202–206）。在 T₃ 上，此时：

- 源孩子是 zero；目标指定孩子是 c₁；
- c₁ 是 Ω 根，故不是 zero；
- `child 2 zero = T₂` 是 nd，而非 zero。

所以比较确实走

```
tbᶻ T₂ child zero c₁
= lo (child zero) (child c₁)
= lo T₂ H
= nothing.
```

逐行依据：`YiMTTab` 29–31、37–41。不是在比较序数大小后选择 nothing，也不是“高层都 nothing”；这里是对确定构造子的直接模式匹配。

`YiTBRow` 99–104 的退路因此返回

```
当前已算出的起点 ⊞ ψ T₂ (B₀ T₂) zero (z≤ T₂) (Ωt zero) e_m.
```

右端明确另用 B₀ 和 Ωt zero，既不继承当时的底，也不继承左端的起点；但左端当前起点并未被删除。`⊞` 正是向目标层加上零层树的 ι 嵌入（`YiRWOps` 105–117）。

三个新加项分别化为 δ₀、δ₁、δ₂：e₀ 为两次零孩子 up 后的 suc zero，e₁ 为一次零孩子 up 后的 U_T₁，e₂ 就是 U_T₂；向零层折时 `z≤` 走 inu，x 为 zero，B₀ 的限制仍为 B₀（`YiRWPath` 58–60；`YiTBRow` 81、87–88；`YiRWFold` 30–31）。故得到如下**路径无关的限制底计算式**：

```
proj₁ (B*(i,u))
  = ((Uᵢ + ι i δ₀) + ι i δ₁) + ι i δ₂.
```

等式在本稿是对原定义的纸面展开判断，未声称为已编译的 definitional equality。用通常序数值简写，零层的该底为 `1 + |D|`。

这说明重置发生在三个局部退路的右端；原前缀折叠作为左加项存活。把整条式子写成仅 `Ωt i` 或仅 `ι i D` 都会丢掉原定义的部分。

## 3. 两个不能略掉的原始量

**判断。** 前节限制底简化，不等于 κ 或 β 也按同样规则简化。

κ 的目标在 T₃ 处是 `ink self`，不是 `inc c₁ u`；因此三个前缀在 T₃ 处均走 `YiTBRow` 89–91，随后到 T₂ 的 self 行，不能套用上节的 nothing 计算。

可进一步把 κ 写成有限 self 操作。令 `J_e(b)` 表示在 T₂ 上、self 路径、起点 b，对 e 的原 ψ 折叠。self 下 Ω 根被保留，up 走 Up，因而这一操作的输出不依赖 Base 的选择（逐条看 `YiTBRow` 81–86、`YiRWFold` 42、61）。用前节的 e₀、e₁、e₂，有

```
κ = J_e₂ (J_e₁ (J_e₀ (U_T₂)))
c₁ = J_e₂ (κ).
```

这是一个明确的有限结构，不能仅因为后续 B* 出现 D 就从 H 中删掉。

另一方面，β 是 `YiGIInst` 82–83 的原 `betaᴱ 3`。其目标路径为 `z≤ Λ = inu ...`，在 Λ 及后继下降处不等同于上节指定孩子路径。β 并没有得到 `1+D` 的计算式。最终 out 的源外层 x=zero，故 β 原样传到 H；任何声称 out 小于目标的论证都还需控制 β。

## 4. 原 out 的剩余递推（没有换定义）

**判断。** H 的根是 `nd (sΩ T₁) q`。对每个 d，记

```
v_d : T₁ ≤ q(d)
```

为 H 原 Ok 字段给出的路径；按构造，它是 T₁ 经 T₂ 再经 `lift T₂ (↑ T₂ (K(d)))` 到 q(d) 的路径。B* 在 q(d) 上的限制仍是前节同一公式，记作 B*_d。

令

```
G(d) = proj₁ (ψ (q(d)) B*_d zero (z≤ (q(d))) β U_q(d))
b = B*(T₁, ink self)
s(d) = proj₁ (ψ (q(d)) B*_d T₁ v_d b U_q(d))
d₀ = zero
dₙ₊₁ = s(dₙ).
```

这里 b 的树部分是 `((U_T₁ + ι T₁ δ₀) + ι T₁ δ₁) + ι T₁ δ₂`，不是 U_T₁。

由于目标零层没有 Pos，根 Keep 必为 nothing（`YiRWBlock` 80–85；`YiRWFold` 34、41–58）。结合 `YiTBRow` 84–85、89–91 与 `YiRWFold` 62，原输出正是

```
proj₁ (Step.out 2 c₁) = lim (cum (λ n → G(dₙ))) ...
```

因此在通常零层序数值解释下，

```
|Step.out 2 c₁| = sup_N ( |G(d₀)| + ... + |G(d_N)| ).
```

这不是一个把所有 Ω 分支都直接取 sup 的式子；取到的是原反馈 s 的迭代。并且是有限和的 sup，不是未经检查便以 `sup |G(dₙ)|` 替换。只有另证共尾性或加法封闭，才可作后一替换。

## 5. 可得的粗上下界

**判断。** 对任意合法底 B、正的零层起点 b，记 `C(a,B,b)` 为在 a 的 U_a 上沿 `z≤ a` 折到零层的原 ψ 值。按所给定义作结构归纳，可得以下纸面下界：

```
C(a,B,b) ≥ |b|·ω                         对所有 a；
C(a,B,b) ≥ |b|·ω²                        若 a 字面非 zero。
```

归纳理由需分构造子，不能只用“Ω 比零大”：

- a=zero 时 U_a=suc zero，故结果为 next b，值为 |b|·ω（`YiRWOps` 55–56、99；`YiTBRow` 82）。
- sS 的 U_a 为 Ω 根；各被采样的分支折叠都是某个不小于 b 的结果再 next，故各项至少 |b|·ω。limc 取有限和再取 sup，至少 |b|·ω²（`YiRWOps` 100；`YiTBRow` 81–84、87–88）。
- sΩ 的 U_a 也是 Ω 根；每个孩子的折叠由归纳假设至少 |b|·ω，limc 同理给 |b|·ω²（`YiRWOps` 102）。
- sL 的 U_a 是累计 up 的自然极限；第 n 个累计项把上一个输出当作下一个孩子的起点，归纳给至少 |b|·ω^(n+1)，所以极限至少 |b|·ω^ω，足以推出所写下界（`YiRWOps` 58–63、101；`YiTBRow` 83、87–88）。各次继承的底虽改变，归纳命题量化任意正底，故此处不要求底恒定。

在本题中所有 q(d) 非 zero，所以每个 G(dₙ) 至少 |β|·ω²。代入第 4 节的有限和 sup，得到

```
|Step.out 2 c₁| ≥ |β|·ω³.
```

此外，pre 3 从 FΛ 0 连续作两次合法 up；零层原 mono 行保持这种严格前驱关系，而 FΛ 0 的 β=1 折叠值为 ω。因此 |β|>ω（`YiGIInst` 72–83；`YiRWOps` 38、58–60；`YiTBRow` 107、112–115、153）。特别有粗下界 ω⁴，但参数式 `|β|·ω³` 提供的信息更多。

粗上界只有：按通常经典序数解释，零层树只有 zero、suc、可数 lim，故其值是可数序数，即

```
|β|·ω³ ≤ |Step.out 2 c₁| < Ω₁.
```

此处 Ω₁ 是通常的第一不可数序数；这是元层面的通常序数解释，不是仓库中已构造出来的比较证据。该上界远不足以回答题给的可数目标。没有得到任何严格低于目标的 ψ 形式上界；不把缺少这种上界写成“定义已丢值”。

## 6. 与目标逐项对照后，具体还差什么

**判断。** 追加的 EBO 片段使目标的参照基本列可以直接写出，不需要猜测另一个 ψ 系统。设

```
A = ψ₀(Ω_Ω)
γ₀ = 1
γₙ₊₁ = ψ₀(Ω_γₙ)
T = ψ₀(Ω_{Ω_A}).
```

从 `EBO` 52–56、128–155、353–380 和 `EboLeanDef` 34–52，按原规则展开：Ω_Ω 共尾度为 Ω₁，A 走折叠行；γT 从 Ω₀=1 起步，得到

```
A[n] = γₙ₊₁
T[n] = ψ₀(Ω_{Ω_γₙ₊₁}).
```

所以目标 T 的值应按这条参照自然极限计算。这里没有把原树的基本列说成这条基本列。

要证明原 out 达到 T，一个明确的未解任务是：对每个 n，从第 4 节原迭代 dₘ 和有限累计和中找到一个上界于 `T[n]` 的项，即证明类似

```
∀ n, ∃ M,  |T[n]| ≤ |G(d₀)| + ... + |G(d_M)|.
```

要证明原 out 严格不到 T，则需要一个真正低于 T 的共同上界 R，并控制全部累计和；仅证明每个单项低于 T 仍不够，因为其 sup 可以等于 T。

目前缺的不是 c₁ 是否非零，也不是哪一行返回 nothing：这两点上文已经逐行展开。具体未解的是三部分的联合控制：

1. δ₁、δ₂ 两个原 B₀ 折叠的值；未获得它们与 A 或上述 T[n] 的双向比较。
2. 原 β 的值；它沿 inu 从 pre 3 传来，不属于第 2 节的 reset 计算。
3. 含 κ 的 q(d) 上，以 `U_T₁ + ι D` 为反馈起点的 s 迭代，是否足以共尾覆盖上式 T[n]。

因此我的阶段 0 判决是 **未能判定能否达到目标**。已得到的局部事实支持“指定孩子路径中的限制底确实被改写为 Ω 树加固定可数尾项”；它既不单独支持“原 out 小于目标”，也不单独支持“保留 β 就足够达到目标”。任何第二阶段结论都应对照这三个余项，而不能只对照设计意图。
