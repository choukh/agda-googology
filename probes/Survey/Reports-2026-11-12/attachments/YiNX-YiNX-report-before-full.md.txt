## 4. 第一个障碍（精确到引理）

完整 low0 的第 n 片叶子是左项 A n、见证 Wit n；`fsLow` 与 `leAB` 已验证这一对应和语法序条件。已填 n = 0。沿当前出口证明办法，接下来需要 n = 1：

```agda
FirstMissing : Set
FirstMissing = Σ (HC (Wit 1)) λ h′ → Rt hA₁ ≼ Rt h′
```

展开是：给 ψ₀(ψ₂(Ω₄)) 的 HC 推导，并证明 ψ₀(ψ₂(Ω₁)) 的参照值不高于该推导的参照值。左项有 `hA₁`、`nf-small 1 (s≤s z≤n)`，语法序前提有 `leAB 1`；缺的最先字段是较大见证项的 `HC` 构造，没有用矛盾前提把出口做成空真。`FirstMissing` 的可满足性尚未证明，因此本轮不把它作为一个已实填前提的条件定理来汇报。

更完整的待证陈述为：

```agda
LowMove : Set
LowMove = ∀ n → Σ (HC (Wit n)) λ h′ → (h : HC (A n)) → Rt h ≼ Rt h′
```

边界事实：`fsn (Wit 1) 0 = W 2 = ψ₀(ψ₂(Ω₃))`，而原样套用规范化目标 N 3 = ψ₀(Ω₄) 的平移会要求它等于 `fsn (N 3) 1 = ψ₀(ψ₃(Ω₃))`。`¬shift₄` 通过检查器否定的正是这个固定语法等式；没有折叠值、没有对所有规范化办法的量化，不能读成规范化路线已否定，亦不归到既有墙的名字下。

后续建议（判断，不是本轮另开任务）：发展跨过一层以上的记号侧吸收／规范化引理，并先在 `FirstMissing` 上检查可满足性；保留树、折叠、合法性。没有尝试修改这三者。
