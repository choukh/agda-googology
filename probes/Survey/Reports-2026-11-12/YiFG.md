##### 2. 设计说明

**签名.** `Φ ℓ o B j w β x : Tr⁺ j`。
- 参数 B 是底族, 在每条路径 `j ≤ ℓ` 上给一棵非零树;
- β 是目标底。
- 输出是算子 (B, β) ↦ Tr⁺ j。读回的约定: 闭项把它作用在默认底族 `B₀` (每层是该层的 Ω 树) 与 `Ωt zero` 上, 再对第 0 层的树用 `readRW`。

**各行**
- 零: `suc β` (FGH 的 f₀)。
- 后继: 对 (底族, 底) 这一对迭代 ω 次, 取目标分量的极限。一步是 `(B, β) ↦ (jB x B, Φ x (B, β))`, 其中 `jB x B i u = Φ x (B, B i u)`。每一层都从当前累积的值出发。
- ℕ 极限: 逐点。
- 结点 `Ω p g`, 由 `kp` 字面判定:
  - `just`: 严格低于目标, 在目标层的槽位上逐分支保留。
  - `nothing`: 等于或高于目标, 两者不分。先算 `B′ = jB (g b₀) B`, `β′ = Φ (g b₀) (B, β)`; 下标取 `B′` 在槽位自己的层 (`at ℓ p`, 路径 `posW ℓ p`) 上的值; 值是 `Φ (g 下标) (B′, β′)`。首分支起跳是为了满足第一位置序的 `◃w`。
- 坐标 `up x c y`, 行形与主线逐行相同 (自身路径用 `Up`; ℕ 极限比较孩子编号 `way`; Ω 形状经指定孩子时回退)。孩子的底族是 `λ i u → Φ x 在 (i, inc c u)`, 孩子的目标底是 `Φ x (B, β)` ("底认得左边的项")。

**链怎样由复合得出.** 结点里没有链。`Φ (a+1)` 迭代整族, 所以分支层 m 上的分量随迭代变成一条链, 目标层的值是在这条链的点上折子树。这对应 Buchholz 的 ψ_j(a[γ_n]), γ_{n+1} = ψ_m(a[γ_n]); 对应关系是纸面判断。代价 (判断): 裸的 Ω 数只有一次对角, 所以 Φ(a+1) 约等于 ψ(a)。

**极限层号与 Ω 形状层号的约定.**
- 不需要"下一层": 不严格低于目标的分支总在槽位自己的层上取对角, 而槽位的层总存在, 与源层的形状无关。
- ℕ 极限层号上比较孩子编号 (ℕ 上可判定)。
- Ω 形状层号经指定孩子时不比较孩子, 回退。

**与主审读法的偏离 (判断, 你们可以否决).** 我没有写成 "Φ_{ℓ→dn ℓ} 之后再对输出折 Φ_{dn ℓ→…}" 的逐层复合。纸面理由三条:
- (a) 极限层号没有 dn;
- (b) 对输出再折需要按层号递归;
- (c) 中间层若用固定参数, 中间层的链不会随迭代长大。

我改为"整族迭代"。所以本折叠一次可以折到任意目标, 与主线一样带路径。

**先验检查三条**
1. 目标是对一切孩子一致的 (`inu`, `ink`), 还是指定孩子的 (`inc`)? 指定孩子只在 Ω 形状上出现, 那里回退, 不比较 c 与 c′。
2. 孩子下标类型上的证据函数: 只在 ℕ 上 (`way`), `Tr k` 上没有。
3. 不按存在性保留: `kp` 是对槽位与路径的结构递归。

因此对不上 `obs→dec` 一族的前提。代价就是 M 形那一行。
