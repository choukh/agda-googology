### 回报: V82 ℕ 极限层号不同号孩子的两行 (YiLim)

#### 1 判决

- **接口**: 已定稿, `YiLimIface.Iface`, 实填 `YiLimCheck.limI` (编译通过), 已发 "YiLimIface 接口定稿"。
- **两行改成什么** (只在 `lim g` 层, 目标 `inl n w`, 结点或嵌入在孩子 m)。两个编号只在 ℕ 上比较 (`cmp`), 再由相邻路径合成 `Way`:
  - 结点: m < n 时槽位沿路径搬进孩子 n (`psh`), 在孩子 n 里按 w 判定; m ≥ n 时目标搬进孩子 m (`w ∙ v`, 同号时 v 是 `self`)。
  - 嵌入: m ≥ n 时目标搬进孩子 m, 交孩子 m 的折叠, 底是 x 对同一目标的折叠 (J2 的形状); m < n 时孩子树沿路径搬进孩子 n (`emb`, 一串 `up zero c ·`), 再交孩子 n 的折叠。
  - 没有路径 (`none`) 时两行与 `YiUpFold` 同文 (结点走默认, 嵌入走回退)。
- **证据与简报不同的一处 (主要发现)**: 相邻路径在证据里是可选的 (`Maybe`), 不是必带的。
  - 编译定理 `no-req : Req (tw 1) → ⊥`: 塔第 1 项的孩子层由任意第 0 层的树读出, 必带路径的证据不可满足。反例是不合法的树 `lim (1,0,0,…)`, 按规则读作 "量化域太宽", 不是数学障碍。
  - 编译定理 `◃→⊑`, `req-leg`, `RtP↑`: 合法树读出的层号有路径, 第一位置序每条规则给一条路径 (第十四次审查的判断现在是定理)。
  - 但折叠对分支 c 是全函数, 只拿到裸的 c, 拿不到 c 的合法性。所以 `Rt-tw` 在由树读出的 ℕ 极限处只能给 "没有路径" (`tw1-none`, `tw1-none-all`, `refl`)。
  - "不存在对一切 c 全定义、且在合法 c 上给出路径的证据函数" 是判断 (理由: 要认出两个闭包字面相等), 没有编译的否定。
- **J2, 单调, 保持合法, 合法闭项**: 都仍成立, 都无前提。J2 各律是 `refl` (同号一条先用 `way-refl`); `mono⊥`, `monos`, `pres⊥`, `press`, `twᶜ-leg`, `EBOᶜ-leg`, `kstep`, `self-up`, `kall` 都重证。
- **(a) 回归**: 路线取 `Rt₀` 时与 `YiUpFold` 在 6 个样本上相同, 带路径而同号的样本 1 个也相同。这是有限测试, 比的是深度 4 的截断: 两个折叠是不同的互递归定义, 整棵树不能用 `refl` 比。
- **(b) 决定性测试**:
  - 层号 `lim gL` 上, 孩子 1 的底在 "孩子 1 里的第 1 层" 的分量, 带路径时是结点 (`b-new`, 形状 `b-new-form`), 没有路径或原折叠时是极限 (`b-none`, `b-old`)。一般式是编译定理 `adj-up`, 对照 `lim-up`。
  - ω+1 那一层本身: 取合法性给出的路线是结点 (`bω-leg`), 取塔第 1 项给的路线是极限 (`bω-tw`)。
- **(c) `limA`, `limB`**: 带路径时两条都保留, 而且是同一个槽位 (`c-A`, `c-B`, `c-A-slot`, `c-B-slot`, 对一切 B, G); 没有路径时仍是一条保留一条不保留 (`c-B-none`)。
- **值**:
  - m = 2 的 ω+1 分量: **未走通**。那一层经塔得到的路线是 "没有路径", 新折叠在那里与 YiUp 走同样的行。
  - 整条 m = 2 与 BTBO: 未走通, 仍只有 YiUp 的条件定理, 这一路没有改进。
  - 无前提定理 (回归): 新折叠上 `bho-lower` 与 `bho-tw1 : L.ψ⁰ (L.Ω I2) ≼ read Tw1ᴸ` 仍成立, 即 ψ₀(Ω₂) 的下界, 只有下界。
  - 带路径的层号 (如独立取出的 ω+1 层配 `Rt-ω+1`) 上的值没有做, 缺按层号统一的模拟族。
- **对目标意味着什么**: 这两行在折叠里可以照 J2 的形状写出来, 四项结构检查都过, Λ = lim tw 自己这一层已经用上闭的路径 (`ink self`)。但 "快速往上爬" 卡在塔第 1 项的那个 ω+1 上, 这两行在那里用不上: 路径要从分支 c 的合法性来, 而块里的分支是裸树, 折叠是全函数。所以 `LOWER′` 在 m = 2 的障碍从 "折叠的两行" 移到了 "证据的量化域": 下一步要定的是分支的合法性怎样进折叠或进块, 不是再改行。

#### 4 设计与翻译账

- **由树的要求逼出的**:
  - `Rt` 在 `lim g` 处的可选相邻路径: 折叠要算 `psh`, `∙`, `emb`, 必须有字面路径; 可选由 `no-req` 逼出。
  - `Way` / `caseW`: 检查器逼出。用 `with` 时终止检查不过 (新行的树参数不降, 只有层号降, `with` 的辅助函数丢掉层号关系)。同理 `press` 用 `caseW-ind`, 孩子的底合法在互递归块里内联。
  - `emb` 对层号递归并带 `Ev`: Λ 的相邻路径是 `ink self`, `ink` 一步要经证据路径进第一个孩子 (与 `kp` 同一理由)。
  - `_⊑_` (没有 `ink` 的路径): `_≤_` 在左加基底之下不保持 (`ink` 的端点在基底里), 偏移的路线要先在 `⊑` 上陈述再平移。
- **读自记号的**: 没有。两行的形状来自 YiPhi 对 k 侧的办法与 J2。"m < n 时把孩子树搬进高孩子" 是我取定的: 读作 x + ↑y 不变, 只换嵌入的位置; 这个读法是判断, 没有值定理。
- **新增脚手架**: 多一个证据参数 `Rt`, 闭包定理没有为它加前提。这一站没有加深翻译, 也没有提高值。

#### 5 第一个障碍

精确到引理: 缺的是全函数

```agda
(c : Tr zero) → Req (zero ⊕ ↑ zero c)      -- 塔第 1 项各孩子层的必带路径
```

- 它被 `no-req` 否定。
- 带合法性的版本 `req-leg` 成立, 但折叠的 `(Ωₗ k h, ink / inu, up x c y)` 行与 `kp` 的 `Ωₗ` 各行取证据时只有裸的 c (`proj₂ ρ c`)。
- 没有检查器报错: 这是类型上取不到, 不是证明没过。

**后续候选 (都是判断, 未编)**:
- (F1) 折叠带合法性: `ψs … x (l : Leg ℓ x)`, 链步的回灌要 "折叠保持合法", 所以折叠与 `press` 互递归。估计是把 Fold 与 Legal 约 600 行重写成一个互递归块, 终止性有风险。
- (F2) 块里让分支或极限自带相邻证据 (合法性进 `L` / `Tr` 的定义)。这是改块。
- (F3) 塔的读回在 ℕ 极限处取部分和 (相邻路径就是 `lift`, 闭的, 对一切 c 全定义)。会改层号的值, 作者对累加有过保留。

三条都超出本路 "只改两行" 的范围, 需要作者定。
