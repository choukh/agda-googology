#### 第十八次独立审查回报（R18，Fable 5.2）

对纲领与目标的含义先说：**"一步折叠的复合" 本身不压平，但也不避开墙。** 压平出在别处：Ω 形状层号上，左加项要从指定孩子内部的层去看。FGH 的读法在这一处给出一条不读记号的约定（"换基"：以目标层为参数，把孩子 c 的那一块换成 目标 ⊕ c 上的块）。这条约定对规范家族可写（已编译），对任意一块不可写（纸面）。没有新的值定理；编译的只有形状与取样。

##### 1. 对问题 1–5 的判断

**问 1。**
- `BoundedTrich.<-dec` 在后继层上就是对 `i < suc ℓ` 的证明做模式匹配。一步折叠 `θ : Ord (suc ℓ) → Ord ℓ` 不调三歧性即可写出。
- ψ₀(Ω₂)：直接折叠与 θ₀∘θ₁ 的第 0 到 3 项取样相同（`A0`–`A3`）。
- 订正前的规则（我按文首订正的描述重建，链只经目标层）在 Ω₂ 上逐项等于 ψ₀(Ω₁) 的后一项（`B0`–`B2`），与订正后不同（`E2`）。
- 差别：订正前的掉值来自 "高于目标" 一行里链经过目标层。一步折叠没有这一行，Buchholz 的链 γ_{k+1}=ψ_j(f(γ_k)) 就是第 j 层那一步的对角（`lfp`），之后各步逐项作用在 ℕ 极限上。
- ψ₀(Ω₃)：第 0、1 项取样相同（`D1`）；第 2 项不逐项相同（`D2n`），内层结点上复合的序列比直接的晚一位（`D2`）。
- 纸面：复合是 ψ₀(ψ₁(a))，不低于 ψ₀(a)，a ≥ Ω₂ 时相等。零行在每层给出 Ω，所以小参数处复合偏高。
- ψ₀(Ω_{ω+1}) 没有编译。纸面判断：先 θ_ω，再从 ω 层逐块下降，不掉值。

**问 2。**
- "等于目标" 是 "不低于目标" 的特例，差一位（`C0`、`C1`）。三歧实际只用作 "保留 / 经分支层自身走链"，这正是主线 `node⁺` 的两种情形。
- 和的行 ψ(x+y) = F_y(ψ(x)) 需要参数。主线的 `β` 加 `Base` 已经是 "每个中间层各一个参数" 的算子。
- 缺的不在输出一侧，在输入一侧：Ω 形状层号上的一块要能在别的地板上重新取值，即是一族而不是一棵树。只把输出改成 `Tr j → Tr j` 不够，孩子内部的链仍要第 i 层的底 ψ_i(x) 作为值。

**问 3。**
- ℕ 极限层号：主线已有的写法（`way` 比较孩子编号，`emb` 或沿路径折叠）就是约定。订正前 "对 f(n) 取对角" 不需要。
- Ω 形状层号：FGH 的 f_{lim a}(n)=f_{a n}(n) 对应 "目标层 j 作参数，孩子 c 的层换成 j ⊕ ↑c"。之后每个槽位要么在 j 之内（按路径如实判定），要么逐字是 j ⊕ u′（走链），都是字面区分。
- `seen : (k : L) → Ok k → (j : L) → Ok j → k ≤ j → Tr k → Tr⁺ j` 对一切 k、j、c 通过类型检查，只用主线的 `ψ`、`Ok⊕`、`OkO↑`、`lift`。
- 对任意一块 y : Tr (a ⊕ ↑c) 不可写（纸面）：换基要把以 Tr (a ⊕ u′) 为分支的结点改成以 Tr (j ⊕ u′) 为分支，方向是反变的。
- 推论（判断）：要么嵌入的字段改成一族 `(d : Tr k) → Tr (h (d + c))`（`h (d + c)` 是字面孩子，归纳-递归上可取），要么量化域收到规范构造的读回域。

**问 4。**
- 比较重新出现在两处，都是 "输入在 Ω 形状层、目标在指定孩子内"：
  - 孩子的底 `λ i u → ψ … i (inc c u) … x`（左加项 x 折进孩子 c 的第 i 层）；
  - 槽位在孩子 c 内、分支取值在本层的结点的链（`posW` 给 `inc c …`）。
- 来源是数据（和 x+y 里 x 含别的孩子的块），不是折叠的步数。从上面折进本层的后继行就产生这样的和，例如 Ω_Ω+Ω_c。
- 逐块如实的行会判定孩子下标的序，已被 `obs→dec` 一族覆盖，不必另写否定。
- 换基不满足 `Hand`（z 与 c′ 逐字相同时那一块也被抬高），回退也不可观察，所以不在 `hand→wdec`、`branch→wdec` 的前提内。不引入新的下标类型，不触壁垒。

**问 5。**
- 主线第 94 至 95 行：`M-shape` 对一切 c′、z 是 `refl`，这一行逐字是 "底 ⊞ 折到第 0 层再嵌回"。头部在 z = 1、2、4 都是 ℕ 极限（`M1`、`M2`、`M4`）。
- 候选 A，目标第 3 层：
  - z = 1 保留（`A1`）；
  - z = 2 走链（`A2`，即 D2）；
  - z = 3 与 c′ 逐字相同也走链（`A3`），而孩子自己的折叠保留（`O3`）；
  - z = 4、5 走链（`A4`、`A5`，正确）。

##### 2. 设计要点与第一条引理

方向在行的层面可行；在 Ω 形状层号上是否可行取决于下面的引理。

规则：
1. 零给底；后继迭代；ℕ 极限逐点。
2. 结点：槽位经字面路径落在目标之内就保留；否则经槽位自身层走链，再继续折。不分 "等于" 与 "高于"。
3. 和 x + y（y 在孩子 c）：折 y，底是 "x 从孩子 c 的各层看" 的一族。
4. ℕ 极限层号上 "从孩子 n 看" 用孩子编号比较。
5. Ω 形状层号上 "从层 j 看"：不投影到含 j 的孩子；每块换到 j ⊕ ↑c，沿 `lift` 折到 j。
