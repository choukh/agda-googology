#### 1. 判决

**对纲领与目标**：独立样本写出了一个只导入标准库的块、折叠、塔与 Λ 的闭项，类型即合法，折叠不比较孩子。但龙骨判据没有达到，而且我的纸面判断是这个设计达不到。

- **K(1)（塔第 1 项 ≥ ψ₀(Ω_Ω)）：未证。** 只到 ε₀ 锚点：`anchor : (h : HC (EBOψ 1)) → Rt h ≼ read (twᶜ 1)`，编译定理，无前提。
- **K(2)：未证，未动。**
- **步骤引理 K(n)→K(n+1)：未证，没有写出陈述。**
- **条件出口**：`keel→ebo : (∀ n → K (suc n)) → toL EBO-tree′ ≼ read EBOᶜ`，编译定理，前提未证，所以只是蕴涵。
- **判断（纸面，非定理）**：K(1) 对本设计很可能为假。上确界结点（ℕ 极限层与 Ω 结点层）的树没有"孩子位置上的全值分支"，所以极限层上方一层的坍缩只比极限层高出一个可数量，x ↦ ψ₀(Ω_x) 在第一个极限层 ω 之后几乎不再增长。按"否定路线要有依据"，这里只写"未走通"；编译过的只有诊断 `restart`，它不是 ¬K(1)。
- **块、折叠、闭项**：都已编译。`twᶜ n`、`EBOᶜ` 是 `T z` 的闭项，没有合法性谓词，合法由类型给出。
- **约束 3**：没有三歧，没有下标比较。`T z` 的位置类型是 `⊥`，不可数类型不作第 0 层的构造子。Ω 只以分支域出现，坍缩时取对角 ℕ 极限并回灌。
- **约束 4**：
  - `gstep` 只按位置的字面形状 `top` / `low p` 分两类；
  - 上确界结点的叶 `pk x t` 沿结点里存的路径 `w x : g x ↘ b` 下行；
  - 路径构造子 `ch x` 只指定一个孩子；
  - 没有任何子句按 c ≡ c′ 或按存在性命题分情况；
  - `E` 在上确界叶上不看孩子，一律 `suc acc`。
- **约束 5**：折叠里没有读自记号的字段。规则 4、规则 5(ω) 与 γ 链只出现在验收证明 `YiKBAccept` 里。需要说明：`E` 的后继子句（`acc + ω^t` 迭代 n 次）与规则 4 同形，来源是 ω 的幂的后继步。

#### 2. 设计说明

- **层号 `L`**：`z`，`s ℓ`，`sp b i g w`。
  - `sp` 是带基底的上确界结点：基底 `b`；下标 `i` 是 ℕ（ℕ 极限）、基底自己的树 `T b`（Ω 结点）或基底某个低位置的树；孩子层号 `g x`；字面下行路径 `w x : g x ↘ b` 存在构造子里。
- **树 `T ℓ = Tr (Pos ℓ) (Dom ℓ) (Lf ℓ)`**：泛型布劳威尔树，零、后继、ℕ 极限、全值分支 `br`、叶 `lf`。
  - 位置是沿基底的脊：`Pos (s ℓ) = ⊤ ⊎ Pos ℓ`，`Pos (sp b …) = ⊤ ⊎ Pos b`。
  - 后继层的叶是前驱层的树（嵌入）；上确界结点的叶是 `pk x t`，`t : T (g x)`，整个待在一个孩子里。
- **树当层号 `lv`/`lev`**：逐构造子对应，零→基底，后继→`s`，极限→ℕ 上确界，分支→以该位置为下标的上确界。上确界叶 `pk x t` 取孩子 `x` 上方的层号，路径经 `ch x` 回来。
- **塔**：`tw (n+1) = sp (tw n) iΩ lev (lv↘ rf′)`，`Λ = sp z iℕ tw tw↘`。
- **龙骨的位置**：
  - `Ωtop (tw (n+1)) = br top (λ c → lf (pk c (Ωtop (lev c))))`；
  - `twᶜ 1` 是对角列 x ↦ 2 ⊔ ψ₀(Ω_x) 的极限；
  - `EBOᶜ = lim (λ n → join 2 (twᶜ n))`；
  - `lev (Ωtop (tw 1))` 展开成按可数树 y 分支的"Ω_y 当层号"。
  - 以上都是 `refl` 测试，只说明形状，不说明值。
- **折叠**：`step ℓ acc t` 读作 `acc + ω^(…)`，用累加器，不需要树上的加法。顶分支取对角，低分支保留，叶各自处理。`down ℓ e` 沿路径逐步坍缩，对 `(ℓ, e)` 字典序递归。
- **证据**：只有 `w x`（孩子到基底的字面路径）与 `≤ˢ`（后继链嵌入）。

#### 5. 第一个障碍

**缺的引理**：对上确界结点 `ℓ = sp b i g w`，`E rf′ acc (lf (pk x t))` 应当是 `acc + ω^(pk x t)`。

- 它的 View 是孩子 `g x` 某位置 q 上、值落在整个 `T ℓ` 里的分支。`T ℓ` 没有这种结点（`Pos ℓ = ⊤ ⊎ Pos b`），所以现在只能写 `suc acc`（`YiKBFold` 里 `E` 的最后一个子句；`YiKBTest` 末条与 `restart` 是它的编译表现）。
- 补上这种结点后，`step`/`down` 要对它取对角，回灌的元素属于 `Dom (g x) q`，得把 `T ℓ` 的值坍缩到"指定孩子 x 的位置 q"这个目标，途中要判定别的结点 (x′, q′) 在目标之上还是之下。
  - ℕ 下标：我的判断是可以靠累加链（后一孩子字面建在前一孩子上）加 ℕ 的比较做到，但没有写。
  - Ω 下标：这正是比较两个指定孩子，约束 4 禁止。我没有找到不比较的写法。
- **对 K 的后果（判断）**：K(1) 只需要可数层号（后继与 ℕ 极限）加顶上一个 Ω 结点，所以 K(1) 的障碍在 ℕ 极限层；K(2) 才碰到 Ω 下标的那一半。
- **证明一侧**：ε₀ 之后的下一级是把 `ev` 扩到有限下标的项（ψ₀(Ω_n) 各行），没有做。
