##### 5. 翻译账

**来自记号的：**
- 目标 "底认得左项"：来自第十五次审查用记号做的诊断。
- 判据本身。
- `kpA` "低于目标的槽位保留" 与规则 5Ω 同向，但实现的机制与已有的 `kp` 相同：字面路径判定。

**由树的要求逼出的：**
- **地板：** 读回层号 a ⊕ Ωₗ k h 的孩子共有 a，而不只是共有 k。这是 ⊕ 的结构；没有地板时，YiCert 只能先折到 k 再嵌入。
- **`cut`：** 目标落在地板以下时，各孩子在那里字面相同，可以不比较 c、c′ 就走孩子自己的折叠。
- **不比较 c、c′、地板之上不保留：** 由 `branch→wdec`、`hand→wdec` 一族逼出，这就是 D2 的来源。

**新增脚手架：**
- 地板字段与 `kpA` 是值需要的：没有它们，第 1 层底各支是 Ω₁ + 可数（`old-any`）。
- `cut` 是让同一行在地板以下与一致行同式。
- 验收层的 `Mᴰ` 是记号引导的：构造子读记号的 cof/pred/fsn/fsT。

**判断：** 没有照记号的基本列写树的字段，闭包定理没有新增专属前提。是否让缺陷变浅，只有 A1 的三个点和 `old-any` 作依据。

##### 6. 第一个障碍

就是两条前提本身，定义在 `YiKVValue`：
- `A1 = (η : E.T) (c : Tr zero) → M⁰ η c → M¹ (ψ₁ᵗ (E.Ωt η)) (proj₁ (g₁ c))`
- `A0 = (η : E.T) (c : Tr zero) (w : zero ≤ h₁ c) → M⁰ η c → M⁰ (ψ₀ᵗ (E.Ωt η)) (proj₁ (A0f c w))`

对 `M⁰ η c` 归纳时，四种情形的状态：
- **极限情形：** 已编译（`a1-lim`、`a0-lim`）。
- **零情形（η = 0）：** 未写。判断：要一条对 c 结构归纳的引理；ℕ 极限层号经 `emb` 嵌进后面的孩子，所以不是字面子树。
- **后继情形（η = η′+1，η′ ≥ 1）：** 要孩子层号 h₁ c′ 上的关系（c′ 是任意可数树），以及 ψ_{η′} 自身折叠在那里的保持，即一般层号的模拟（YiME 的 "A"）。还有一个问题：层号对记号下标是松弛的（`M⁰ η′ c′`），块在 h₁ c′ 上保留、记号在 η′ 处折叠的槽位，`Mᴰ` 里没有构造子可用（YiME 已指出）。判断。
- **松弛情形（`mw`，c ◃ c″）：** 要 `g₁` 对 c 沿 ◃ 的跨层单调。`g₁ c` 在 `g₁ (suc c)` 里的拷贝换了源底，不是字面子树（读行的判断）。

A0 是同一问题在目标第 0 层的版本。它在任何块上都没有关系式的证明，所以不是本候选特有的缺口；A1 才是掉值所在。

判断（把握中）：目标第 1 层、地板 0 时，没有严格介于地板与目标之间的层，所以 `φ` 的保留与折叠与 Buchholz ψ₁ 一致，只是叶子多一。因此 A1 很可能为真；但没有定理。
