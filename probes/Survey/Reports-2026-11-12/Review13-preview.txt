1. 作用域块 (YiScope) 卡在哪
 - 编译事实: YiScopeLglNeg.R-illegal. 反例 T 的层号是 L1,L2,L3 (零的逐次后继), 孩子下标全是 tt. 里面没有 Ω 结点层号 (raw k), 没有任何需要比较的孩子下标.
 - 机制 (读定义): (a) YiScopeLegal.Dn 的 into 行与 up 行把 "越出再进来" 认作同一棵 (Dn z (up c refl w) = Cp (into c z) w ⊎ …); 这是 plus 的左加数总在根作用域 (wrap) 逼出来的, sucS 在作用域里要靠它才合法. (b) 折叠不认: 作用域里的 z0 由 In 保留 (In 的 nd 行), 经 wrap 包回 L3 根再 lift 回来的那一份, 在 dn 的 up{s=root} 行变成洞, 洞里只有 col 折叠 (Res = ∀ J → Raw J → Raw J, 只带 F … col), 所以被 In 的 up{s=root} 行经 ρ 全折. 失败的字段是 Legal (lim) 的第一分量 (相邻项 Cp), 在 A 0, A 1 之间.
 - 所以反例显示的是 "序把越出再进来认作恒等, 洞只会 col", 不是 "Ω 结点层号的孩子要判下标相等". 在后继层号 (孩子唯一) 上这已经失败, 修它不需要比较任何东西 (孩子只有 tt). "对 raw k 要判下标相等" 是执行方对假想修法的判断, 不是这条编译否定的内容.
 - 另: 作用域块的折叠只有两种方式: col (全折到任意 J, J 与 K 没有位置关系) 与 kp (只对 sup one, 折到唯一的孩子). Ω 结点层号的根结点链步是 RlD (raw) = F … k col, 全折. 所以 YiScopeSame 的 "嵌入一致对一切层号" (F-into) 只是 col 方式的; 有定位目标的保留只在 one 上.

2. 空白页样本 (YiFresh) 卡在哪
 - 编译事实: YiFreshCheck.J2-Ωₗ-gap. 有折叠, 没有值, 没有合法性失败. 失败的是 YiFreshFold.ψs 的最后一行 (Ωₗ, inb c′ w, up x c y): 目标路径 w : j ≤ h c′, 嵌入在 h c; 要交给孩子层折叠, 类型上就要 c ≡ c′ 的证据 (或 h c 与 h c′ 的公共结构), 没有就走默认 (偏移折叠 + ι j (ψ⊥ 孩子)). 同样的默认还在 kp 的两行 (Ωₗ, inb) 与 (Ωₗ, inj₂, ink).
 - 合法性的归纳能过, 因为默认式对同一字面形状一律使用, 而它的序 (◃) 没有 "越出再进来" 的等同.
 - 附件 folded: 结点槽位 p₃ = inj₂ (c₃, …) 直接出现在外层树上 (不是经 up). 我的判断: 规范树 (Ωt) 的结点槽位都是 "顶" (suc 的 inj₁ tt, Ωₗ 的 inj₁ (inj₁ tt)), 折叠 kp 在顶槽位上只在 self 保留, 所以外层树上的 inj₂ 槽位可能不在读回域内 —— 待核.
 - 附件 step₂: 这是另一处, 不是分支侧: 目标在 k 侧 (ink self), 嵌入在分支 c. 这里不涉及 c 与别的下标比较; 缺的是 "k 在 h c = k ⊕ ↑c 里的位置" (⊕ 是递归函数, k 被抄进每一支, 没有统一的路径).

3. 是不是同一处
 - 不完全是. 我看到三件不同的事:
   (i) 分支侧目标对另一分支的嵌入 (要 c ≡ c′): 只有空白页有这个陈述 (J2-Ωₗ-gap); 作用域块根本没有分支侧的定位目标 (没有 kp 于 raw).
   (ii) Ω 结点层号的根结点链步 (目标是下标层 k): 两路都退成全折 (作用域 RlD raw = col; 空白页 step₂ 的回退). 这是两路真正共同的退让, 且它不需要比较孩子下标, 需要的是 "每个孩子层都字面含 k".
   (iii) 作用域块的合法性失败: 越出再进来的等同 + 洞只带 col; 在后继层号上就有.
 - V68 把 (i) 与 (iii) 合成 "同一个孩子吗". 逐条看, (iii) 的编译反例里孩子是 tt.

4. 三者能否兼得 (嵌入一致于 Ω 结点层号分支, 合法性归纳, 不比较孩子下标)
 - 分支侧, 按 "c ≡ c′ 时交孩子, 且交接类型正确" 来读: 交接要 Maybe (c ≡ c′) 且对角上是 just; 对 Tr zero (含 lim) 这推出 WLPO (可能要函数外延作前提). 预期与 cmp-full→lpo 同型 —— 待对陈述.
 - k 侧 (基底目标), 按 "孩子是 k ⊕ b" 来读: 我认为能兼得. 设想: φ : Tr (a ⊕ b) → (j ≤ a) → Tr j, 对树递归并按 b 的构造子展开类型; up x c y 一律交给孩子 (a ⊕ b′), 不看 c. 计划在空白页的块上直接写 φ, 证 J2 (refl), 单调, 保持合法.
 - 分支侧目标在规范折叠里是否出现: 会经 Base 出现 (ψ⊥ (Ωₗ) (up x c y) 给孩子的底是 ψs … (inb c w) x), x 是偏移. 规范 Ωt 里 Ωₗ 层的偏移 x 是 zero; lim 层 (Λ) 的偏移是前几项的累加 (cumΩ), 对应 eqℕ 的 nothing 行. 所以 "跨孩子" 在规范域里先出现在 ℕ 极限层 (可判), Ωₗ 层上是否出现待查.

5. 初步倾向
 - 两路的差别比主审说的小: 作用域块的 "对一切层号一致" 与空白页的 J2⊥ 是同一档 (全折); 有定位目标的一致两路都只到 one (空白页还多 nat).
 - 空白页的组织 (偏移在外 up x c y, 序没有再进入等同, 合法性结构归纳已通) 加上 "基底目标" 的折叠 φ, 可能是最便宜的合一.
