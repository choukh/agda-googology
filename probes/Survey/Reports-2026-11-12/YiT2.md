#### 4. 设计与翻译账

**参照的选择。** 混用：
- 朝第 0 层的 `up` 一帧用 (b) 的 Level 参照，因为 `lower` 现成且对一切 OKB 的底成立。
- 自身行用 (c) 的记号直连 `Lev.Mᴸ`，因为它对层号递归，能对一切 k 陈述。
- `Ix` 没有给出实例。它在 Ω 结点与 ℕ 极限层号上的定义仍是空缺。

**由树逼出、不读记号的：** `_⊑¹_` 与 `desc`/`descB`（第一孩子的底化简回标准底或限制）、`tw-step`、`ok-dW`、`eqk`、`fallback`、`inner-base`、`at-mv`、`low-mv`。

**来自记号规则的：** `PF`/`PU` 的六个情形（规则 4、5、5Ω、和），`Le`/`cofΩk`/`fsTk`，`note-cof`。

**脚手架归类：** 全是值验收用的，没有进定义。`Kept` 是翻译带来的前提：它要求记号一侧结点保留，块在自身目标上一律保留。

**对主审两条补充的落实：**
- 一般 k：`desc`、`descB`、`ok-dW`、`eqk`、`PF`、`PU` 都对任意下标层号写。只到 "下标可数" 的是 `up-lower`（孩子层号要 `NL`），以及 `Frame` 里 `tw 1` 的实例。推广时第一个挡住的是 `YiLSFold.lower` 对含 `Ωₗ` 的层号没有陈述，因为 `Corr` 与参照都没有这一种。
- 一般底：`descB`、`ok-dW`、`up-lower`、`eqk`、`PF` 都对一般底陈述。`sucΩ≼tw2` 只对 `B₀ (tw 2)`，原因见 §1 的表；没有接 (B) 的 `transferP`。

#### 5. 第一个障碍

`step⁺-suc` 的前提是 `∀ n → Σ k → M⁰ (ψ₀ᵗ (γ₊ n)) (next (ψ₀ (tw 1) … (d⁺ k)))`。按层往下：

1. **链（自身行）**：`chain-sim` 给 `Mᴸ (tw 1) (γ₊ n) (d⁺ (n+1))`，缺两条前提。
   - `Mᴸ (tw 1) (E.Ωt Ω₁ᵗ) (Ωt (tw 1))`：要对一切 `M⁰ η c` 有 `Mᴸ (h₁ c) (E.Ωt η) (Ωt (h₁ c))`。纸面上对 c 归纳可行（后继处用 `mΩ`，ℕ 极限处经 `mU` 与 `◃l n`），但它要 `Ix (h₁ c′) (pred η)`。
   - `Kept (tw 1)`：要由 `M⁰ ν c` 推出 ν+1 < Ω₁，即记号一侧的可数性；`Mᴰ` 不带这条。这是这一层第一个挡住的引理（判断，未编译）。
2. **行（朝第 0 层的折叠），真正的障碍**：要 `Mᴸ (tw 1) a x → M⁰ (ψ₀ᵗ a) (ψ₀ (tw 1) … x)`，即 `VW` 在 `tw 1` 上。
   - 它的结点情形要 `QH` 的对应物：朝孩子层目标 `inb c w` 的折叠保持关系。
   - 这条在两处与记号不一致：`up` 一行是回退（`fallback`），孩子一侧槽位的结点一律折叠（`flat-lim` 对 `note-cof`）。
   - 所以第一个挡住的引理是：`Mᴸ (tw 1) a x → Mᴸ j (ψ_j a) (ψs (tw 1) … j (inb c w) β nβ x)`。它在 x 是 `up` 或孩子一侧结点时按现在的 `Mᴰ` 填不上（判断；没有写 `¬` 的定理，按规则只写 "未走通"）。
3. **`RowMono`**（简报第 2 条里 `mw` 情形的陈述）：只证了起点为零的一段（`row≽`）。
   - 其余要 "孩子的底从 `dL`/`dW` 换成标准底值不升"，是规范域上的基底单调，这里没有。
   - 走 `suc (tw 1)` 这条路时它不在关键路径上。

我没有把第 2 条归到 `flat→wdec`/`branch→wdec` 那堵墙：那两条说的是 "能观察地保同支就弱判等"，这里的事实只是块与记号余尾不同，没有折叠的新写法，也没有判等。
