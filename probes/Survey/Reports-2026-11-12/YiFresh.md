#### 目标与约束

最终目标 (背景): 在布劳威尔树上定义读法为 ψ₀(Λ) 的合法闭项 (EBO = ψ₀(Λ), Λ 是 x ↦ Ω_x 的第一个不动点), 树的分层写法要让折叠 (一种 ψ, 把高层的树压到低层) 能由检查器保证停机. 你这一路只做块、折叠与合法性, 不做值.

五个约束:
1. 用布劳威尔树定义序数, 每一层的树最终都能读成普通的布劳威尔树 (零, 后继, ℕ 极限); 高层可以有以低层合法树为下标的分支 (Ω 一类的极限).
2. 无公理: `--safe --without-K`, 不许 `postulate`, 洞, `TERMINATING`, `NO_POSITIVITY_CHECK`, K, `--irrelevant-projections`, `--cubical`; 停机与正性由检查器保证.
3. 壁垒: 不得引入这样的下标类型: 以可数序数的树为精确初始段、含 Ω 一类的共尾元、且有有界三歧 (可判定的比较); 这会推出 LPO. 也不能要求对两个独立的低层下标做处处完全的比较 (仓库里已有编译定理: 这推出 LPO).
4. 最终定义与记号无关: 块、折叠、合法性不引用任何序数记号的项、序或基本列.
5. **被比较的两个位置要有字面的公共上界, 加法不得把嵌入的分支打开** (例如 x + (嵌入到某个孩子里的树) 不能化成高层里一个摊平了的位置); 折叠里不要有按层号字面相等去判断的派发函数.

另一个已知事实 (作为要避开的失败, 不是设计提示): 有一种旧设计在 "结点的源层号是 ℕ 极限层号、目标层有这个层号的槽位" 时一律把结点折叠掉, 丢掉了本该保留的结点; 你的设计在这种情形下应当保留.

#### 4. 设计: 来源

**块:**
- `zero`, `suc`, `lim`: 约束 1。
- `Ω p g`, 其中 p : Pos ℓ, g : Br ℓ p → Tr ℓ: 约束 1 的高层分支。槽位取路径, 是为约束 3 与 5 (不引入可比较的下标类型)。`Br` 与 `Pos` 同步递归, 是检查器停机的需要 (`Tr (at ℓ p)` 不是结构递归)。
- `up x c y`: 约束 5 (嵌入不打开) 与 J2。
- 层号 `Ωₗ k h`: J1。
- 塔分支写成 `tw n ⊕ ↑c` 而不是 `↑c`: 树自身的合法性需要, 使 tw n 成为 tw (n+1) 的第一位置。上确界不变。
- `Pos (Ωₗ k h)` 分 k 侧与分支侧: 底结点的链需要以 k 为目标。

**折叠:**
- 加法递归到 `up` 时停下: 约束 5。
- `ψs ℓ B j w (Ω p g)` 经 `kp` 判定保留: 约束 5, 两条路径在同一个 ℓ 里比较。
- ℓ = lim g 时比较 ℕ 编号 (`eqℕ`), 不比较层号: 约束 5。
- 对角链 γₙ₊₁ = ψ_p(g γₙ), 取部分和 `cum` 的极限: 部分和是合法性保持的需要。它让相邻项按第一位置序步进, 不要求分支单调。这是代价: 结构上与 "直接取极限" 不同, 判断上值相同 (分支值是加法主数时部分和坍缩到末项, 未证)。
- 后继式 `next b = lim (b, b+b, …)`: 从 b 起步, 是 "x ◃ suc x ⇒ ψx ◃ ψ(suc x)" 的需要。
- `up` 的目标是 ℓ 自身时原样保留嵌入: 约束 5。
- `up` 的回退 `ψs x + ι (ψ⊥ y)`: 单调性的需要 (常值回退会让 `◃c` 失去严格性)。
- `Base` 是记录: J2 默认底情形能定义上成立。
- `ψ⊥` 与 `ψs` 分开 (第 0 层目标单列): 合法性的需要。第 0 层目标对一切孩子一致, 偏移的折叠恰是孩子层的底。
- `Ωt (suc a)` 取 sup(↑(c+1)), `Ωt (lim g)` 取部分和: 合法性 (嵌入的孩子非零, 相邻项步进) 的需要。

**合法性:**
- 第一位置序中, Ω 结点只以 g 0 为前驱: 对角式的单调需要它。
- `◃u` 带 "孩子非零" 前提: 这让单调不需要合法性前提。
