0. 我对块的读法 (判断, 待编译核对)
- LF 是层号; Raw k 是第 k 层的树, top 读作 Ω_k; Pre k = "低于 k 的层号" 的路径 (有重数), lev 取出层号.
  Pre (suc k) = {k} ∪ Pre k; Pre (lim f) = ∪ Pre (f n); Pre (lc k g) = ∪_{合法 η} Pre (g η).
  Ω 结点层号 lc k g 自己的根层 k 不是 Pre (lc k g) 的指定位置: 只有某一支 g η 里恰好含层 k 时才有 (tw 2 的 p₀ 取在 top 支, 因为 ⌜top⌝ = 1).
  常值 g (如 lc k (λ _ → zero)) 合法, 而 Pre 为空: 退化结点.
- 折叠 Ψ m V x ξ: Buchholz 式 ψ_m; 派发 x : Ext m k 对每个位置给 keep (目标层里字面的槽位, lev 用命题相等) 或 fold.
  Lv k 是 "同一层内两个位置的比较器": vs/vl 字面可比; vΩ 跨分支不可比 (壁垒), 现在一律 fold.
- 合法性与派发无关: Ψ-lgl 对任意 x 成立. 所以 "合法闭项" 与 "值" 两件事里, 派发只影响值.

1. 塔的形状 (判断, 想用 refl 核对)
- tw n (n ≥ 2) 定义性地等于 lc zero (upT^{n-2} ∘ ⌜_⌝): 每一项塔的根都是第 0 层的 Ω 结点, 分支在 Raw 0 上.
  所以 T_n 的根总是 "目标 0, 结点层 0, 全折叠", 这一步与 tw 2 一样是对的.
  需要推广的地方在分支内部: g_n η = upT^{n-2} ⌜η⌝ 对后继 ⌜η⌝ = suc c 是第 c 层 (c > 0) 的 Ω 结点 lc c (upT^{n-3} ∘ up c).
- Λ 的闭项: Ψ 0 (vl V st) (λ _ → fold) top 定义性地是 lim (psum 0 (λ n → Ψ 0 (V n) fold top)); st 在 top 行不被用到.
  所以 ψ₀(Λ) 的合法闭项只要 V n : Lv (tw n) 对一切 n, 加 Ψ-lgl; 不需要 Shift (tw n) (tw (n+1)) 的构造 (但 vl 的字段要求它, 可以给一个平凡的? 不行, Shift 要保持 lev, 需要真的构造或换一个不带 Shift 的极限构造子).

2. 推广 vΩ 的三个部件 (判断)
 (a) Lv 对 Ω 结点层号 lc j g 一般化: vΩ : (V : ∀ η → Lgl j η → Lv (g η)) → ... → Lv (lc j g),
     以及 Lv 对 upT 与读回 up 封闭 (仿 YiNextTower 的 Legal-Ω̂ / lgl→Legal 的互递归). 这是机械的.
 (b) top 在 Raw (lc j g) 上的折叠:
     - 根层 j 的派发: 保留要目标层里层号为 j 的字面槽位; 自身折叠 (self) 时槽位必须在 Pre (lc j g) 里, 现块里没有指定位置 (p₀ 的推广). 第一个障碍候选.
     - 保留时的分支族 Kf 要在 Raw j 上对一切合法下标有定义且单调; j > 0 时 Raw j 有 lc 与 em, 现有 Kf/nrm 只覆盖 Raw 0.
     - 折叠时的链在 Raw j, F η = Ψ j (V η) (D η) top, 派发 D η : Ext j (g η) 要 "低于 j 的保留"; 现在写死为全折叠, 只在 j = 0 对.
     - 观察单调: 现在靠 Up 字段与 up-lv; 若观察改取部分和 psum (像 vl 的 top 行与 Kf), Up 字段可以整个去掉, 合法性由 psum-lgl 给出.
       代价: 基本列变成部分和 (毛刺), 值上 (加法主数的部分和) 应当同值, 但这是判断.
 (c) cmp 跨分支: 壁垒 (两个分支下标之间没有字面公共上界). 同一分支也无法判定 (Raw 0 树相等不可判定), 所以 "同支则比较" 也只能靠结构传递, 不能靠判定.

3. 我预期的 "最省" 设计 (判断)
 - 只求合法: (a) + (b) 中根层一律折叠、D 一律折叠、链观察取 psum. 规模 ~150 行 (Lv 封闭 ~60, vΩ 推广与 top 行 ~40, 合法性 ~50).
   这样得到的闭项合法无前提, 但正层 j 上的 ψ_j 全折叠, 值估计会掉 (不期望到 EBO); 只是合法性的基线.
 - 要值: 关键是 D (目标 j 的派发) 与根槽位. 我倾向 "读回派发": 对 g = upT^p ∘ up j 这种规范分支, 位置的层号来自 η 的结构, 按结构递归定义 keep/fold, 只在读回域 (链点, 从 top 起) 上值正确, 其余域合法但值低.
   第一个障碍: 根层 j 的槽位 (Ω 结点层号没有指定的根位置); 可能需要在新块里给 Pre (lc k g) 加根位置 ⊤ (改第 1 层, 要作者定), 或让 vΩ 带见证位置 (只在规范实例上可造).
 - 跨分支 cmp 一律折叠的值损失, 我预期在 T_n 的根 (层 0) 不出现, 在正层的保留结点的分支内部出现; 量级不知道.
