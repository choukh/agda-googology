###### 1 判决

结论先说: 在本路范围内, 关键路径上没有暴露出挡路的问题。必带路径的证据可以满足, ω+1 那一层有路径, 决定性测试是结点, 塔第 1 项的 ψ₀(Ω₂) 下界换一条证法重证成功。代价落在值上: 层号的值改了, 基本列有毛刺。

**证据可以满足 (编译定理, 无前提)**
- 塔各项: `Req-twᶜ : (n : ℕ) → Req (twᶜ n)`。Λᶜ: `Req-Λᶜ : Req Λᶜ`, 相邻路径是 `ink self`。
- 换成 `YiLimCheck.Req` 的类型: `req-twᶜ1 : LC.Req (twᶜ 1)`, `req-all : (c : Tr zero) → LC.Req (zero ⊕ ↑ᶜ zero c)`。对照的是旧塔的 `no-req : LC.Req (tw 1) → ⊥`。
- 原因: ℕ 极限处的相邻路径就是 `⊑lift (cumₗ s n) (s (suc n))`。它是闭项, 对一切树全定义, 不看树是否合法。
- `no-req` 的反例 `bad = lim (1,0,0,…)` 现在读成常值的 lim (1,1,1,…), 第 0 步的路径是 `self` (`bad-path`, `bad-terms`)。

**ω+1 有路径 (编译定理, `refl`)**
- 对一切 f, 由树读出的极限都是 `just` (`tw1ᶜ-just-all`)。对照的是 `tw1-none-all`, 那里是 `nothing`。
- ω+1 那一层本身: `ω+1-just`。

**决定性测试 (有限测试)**
- 照 `bω-tw`, 用塔自己给的路线与层号证据, ω+1 那一层孩子 2 的底是结点 (`bωᶜ-tw`)。旧塔在同一处是极限 (`LC.bω-tw`)。
- 同一层号换成没有路径的 `Rt₀` 是极限 (`bωᶜ-none`), 所以差别来自路径。
- 注意: 孩子 2 现在是层号 3, 不是 2。目标路径是 `ins (ins self)`。

**结构**
- `YiLimFold` 与 `YiLimLegal` 一行不改。
- 闭项合法: `ctwᶜ-leg`, `cEBOᶜ-leg`, 是 `twᶜ-leg`, `EBOᶜ-leg` 的对应物。
- 孩子结点的槽位保留: `kallᶜ`, 是 `YiLimIface` 字段 `kall` 的对应物。

**值的账, 两边**

- (a) 层号的值: 累加不低于原读回, 在 ω+ω 处更高。
  - 不低于 (编译定理): `up≼upᶜ`, 对一切第 0 层的树。
  - ω+ω 处 (编译定理): `ωω-strict : L.suc (v↑ ωω) ≼ v↑ᶜ ωω`, 由此 `ωω-not≼`。
  - 反方向 (编译定理): 每个 `↑ᶜ c` 都与某个 `↑ c′` 互相 `≼` (`cof`)。
- (b) 塔与 Λ 的读法 (判断, 依据如下):
  - 塔第 1 项: 两族分支层号在值上互相共尾 (`tw1-cof`, 编译定理)。由此判断上确界不变, 塔第 1 项仍读作 ψ₀(Ω_Ω)。这一步没有编译, 因为没有 Ω 层号的值函数。
  - 第 n ≥ 2 项 (判断): 经典读法下 ↑ c ≤ ↑ᶜ c; 部分和是可数多个都在下一个 Ω 之下的层号的和, 仍在它之下 (正则性)。所以层号的上确界不变, ψ₀(Λ) 的读法仍是读法。
  - 链点处 (判断): 我估计 σ(β) ≤ ω^{β+1}, 所以在 ε 数处读回的值不变; 塔的链点在经典读法下是 ε 数。
  - 折叠不是层号值的函数 (`mono-fragment-not-cong`), 所以闭项的读法仍要靠值定理。现有的是下界 `bho-tw1ᶜ`, 与旧塔同档 (见 d)。
- (c) 毛刺 (有限测试):
  - 层号 ω 的基本列从 0, 1, 2, 3 变成 0, 1, 3, 6 (`tri`, `tri-old`)。
  - ω+ω 的第 1 项从 ω+1 变成 (ω⊕ω)+1 (`ωω-term1`), 层号的值也升了。
  - 塔第 1 项闭项的链点 1 仍是 `lim (1, 1+1, …)` (`pt1-same`), 但它读成的层号的孩子从 1, 2, 3 变成 1, 3, 6 (`pt1-child`)。
  - 判断: 闭项 `Gᶜ (ptᶜ 1)` 的基本列跳层, 是 ψ₀(Ω₁), ψ₀(Ω₃), ψ₀(Ω₆), …; FGH 的值会不同 (FGH 不作验收目标)。
- (d) 对值证明的影响:
  - `bho-lower` 不受影响: 它只说层号 2, 不提塔。
  - `bho-tw1` 原证明搬不过来, 有两个原因: 孩子 1 是层号 3, 而 `At.lower2` 只对层号 2; 那里的底由路径搬入, 不再是回退行的 `Ωt 1 + ι 1 c₁`。
  - 已换证法重证: `bho-tw1ᶜ`, 无前提, 只有下界。证法是层号 3 经 `ins` 行下到层号 2 (`form3`)。新形状的底第 1 层分量是结点 (`β₁-form`), 它的第一分支是 `next (Ωt 1)`, 所以 `hβ = S-w Sβ₀ (◃t (◃l 0) ◃w)`。
  - 没动: 依赖旧 `h₁` 的 `YiFreshValTw1`, `YiUpValTw1` 属于旧折叠, 若保留要另搬。
