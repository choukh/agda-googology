#### 2. 写法说明

**证书**（`YiCertPath`）：
```
data Ab (k : L) : L → Set where
  here : Ab k k
  via  : ∀ {a} → k ≤ a → Ab k a
  ab   : ∀ {s h} → ((c : Ch s) → Ab k (h c)) → Ab k (nd s h)
```
- `OkS (sΩ k) h = Ok k × ((c : Tr k) → Ab k (h c))`，原来第二个分量是路径 `k ≤ h c`，现在由 `ab→≤` 读出。
- 塔的孩子层：`ab⊕ here (↑ (tw n) c)`，叶子全是 `here`。读回层号：`ab⊕ (via v) (h c)`。

**底的规则**（`YiCertFold`）：底的式子没变，`λ i u → ψ ℓ o B i (inc c u) (B i (inc c u)) x`。变的是它经过的那一行：
```
ψ (nd (sΩ k) h) o B j (inc c′ v) β (up x c y e) =
  φ (h c′) (proj₂ o c′) (孩子 c′ 的底) (kh o c′) j v
    (h c) (proj₂ o c) (proj₂ (proj₁ o) c) (孩子 c 的底) (ψ … β x) y
```
`φ` 按证书分情形：
- `here`（层号逐字是 k）：树嵌进锚层 `h c′`，按锚层正常折叠。
- `via w`：先折到 k，再嵌入锚层折叠。
- `ab f`：逐构造子递归。嵌入逐孩子下行，底是源层自己的 "x 朝该层的折叠"。结点按 `kpA` 判定：槽位落到叶子 `here` 时推进锚层按路径判定，否则不保留，链在源层回灌。

**先验检查三条**：
1. 目标：是指定孩子的。但这一行对一切 c、c′ 是同一个式子，不主张同支交接（`Hand`），也没有可观察的回退。
2. 证据函数：孩子下标类型上没有。证书是层号上的全函数，给结构，不是 `Maybe (c ≡ c′)`；`φ` 只按证书的构造子派发。
3. 按存在性保留：没有。`kpA` 沿证书与字面路径算槽位，`via` 叶子、源层自己的槽位、内层下标层侧一律不保留。

#### 5. 翻译账

- **来自记号的**：目标 "底该认得左边的项" 来自第十五次审查用记号做的诊断。`φ` 的写法本身没有照记号的规则写。
- **由树的要求逼出的**：
  - 不比较 c 与 c′，所以只能把孩子 c 的树整棵重读在孩子 c′ 的层之上；这是壁垒一族（`hand→wdec`、`branch→wdec`）逼出的。
  - 证书 `Ab`：`φ` 要对孩子层的字面结构递归，并知道叶子处层号逐字是 k，才能把树嵌进锚层。
  - 高于 k 的槽位不保留：保留要把分支类型换成锚层的，方向反了；不保留只要源层回灌，不需要换型。
- **新增脚手架**：`via` 叶子是为读回层号仍有证书，不是值需要的。`s+` 的加一是嵌入要非零带来的。
- **验收**：只用形状与一条吸收定理，没有用 `Lab`。
- **性质（判断）**：没有给闭包定理加专属前提，没有照记号的基本列写字段。但语义偏离记号（偏高与偏低两个方向都有），是否让缺陷变浅没有定理。
