## 1. 我对定义的读法（纸面）

- 层号 `L` 自己是树：后继形 `sS`、ℕ 极限形 `sL`、Ω 形 `sΩ k`（在第 k 层的树上分支）。`tw 1` 读作层号 Ω，`tw (n+1)` 读作 Ω_{tw n + 1}，`Λ` 是它们的 ℕ 极限。`Tr ℓ` 读作 Ω_{ℓ+1} 以下的树，`Ωt ℓ` 读作 Ω_ℓ（Ω₀ = 1）。
- 折叠 `ψ ℓ o B j w β x` 读作 "ψ_j(c + x)"，其中 β = ψ_j(c)，底族 B 给出各层的 ψ_i(c)。各行：零给 β；后继乘 ω；ℕ 极限逐项；Ω 结点按槽位层与目标层的关系保留，或走链（以底族在槽位层的值起步，把折到槽位层的结果回灌作下标，取累加极限）；`up x c y` 先折 x 再进孩子 c 折 y；目标就是本层时不折，挂成 `ex β β x`（读作 β·ω^x）。这就是 Buchholz 式的树塌缩。
- `ex a b x`（读作 a + b·ω^x）朝低层折时，由 `E`/`It n` 把 "右边接上 b" 迭代 ω^x 次；各阶 `It n` 只是为了让指数 x 里再嵌 `ex`。语义上它等于把 b·ω^x 展开成纯树（`W4Val.val` 的 `Ev`）再用四行折叠去折。
- 终点是 `EBOᶜ = lim_n v_n`，`v_n` 是在 `tw n` 上折 `Ωt (tw n)` 到第 0 层（底取 `v_{n-1}`，底族由前缀给出）。每座塔的顶层是一次走链：`z_{k+1}` = 把 `Ωt (tw (n-1) ⊕ ↑z_k)` 折到 `tw (n-1)`，`G(z_k)` = 把同一棵树折到第 0 层。

## 2. 为什么现在是逐站（判断）

塔第 1 项里第 3 层的折叠，链点是 z₁ = Ω₂·ω，z₂ = Ω₂·ω^{Ω₂·ω+1}，……。折 z₂ 要把 "接上 Ω₂" 迭代 ω^{Ω₂·ω} 次，其中每个 Ω₂ 又要在第 1 层上对角。现有证明对每一种指数形状单独建立 `E`/`It` 的值关系（一份 Ω₂，两份，ω 份，再到 Ω₂²·Ω₁ 附近），所以每前进一点就是新的一站。缺的是一条对一切指数树成立的定理，见 §5。

## 3. 两行丢信息的行在 W4 里原样存在（编译）

- `blind`：把 "右边接上 Ω_Ω" 作用在这个条目上，对任意状态 S 与当前值 v，结果逐字是保留的 Ω₁ 结点，分支 z ↦ v ⊞ ψ₀(Ω_z)。右边不含 S：这个条目的演化看不见状态里的任何别的东西。

这与外部审计 LEMAudit 的 `W4Local.bare`、`off` 是同一事实；与 MathCap 对旧候选编译的 `base-inc`、`base-fb` 是同一行。交接文 §4 说"旧候选上的反例有明确作用域"，就这两行而言作用域包含 W4。

## 4. 两个方向的论证，各自缺什么

**封顶一侧（纸面加判断）。** 理想的 ψ₀(Ω_Ω·Ω₂) 的基本列是 γ_{n+1} = ψ₁(Ω_Ω·γ_n)：要把 Ω 层上的和塌缩到第 1 层再喂回去。W4 在第 1 层这个条目上只做两件事：加上固定的尾巴（分支 z ↦ ψ₀(Ω_z) 的 Ω₁ 结点），以及把指数里的结点按孤立的方式折下来。于是第 1 层的回灌读作 ψ₁(Ω_Ω + …) 一类，不含"已经堆了多少个 Ω_Ω"。第 2 层以上连尾巴的效果也没有（MathCap 的"第 1 层因尾巴而精确，第 2 层起亏损"，我独立得到同一句）。按这个读法，塔第 2 项的各次返回停在 ψ₀(Ω_Ω·Ω₂) 以下，远低于 ψ₀(Ω_{Ω+1})。

**补偿一侧（纸面）。** 有两个真实存在的补偿机制，旧审计只算了第一个的一部分。

- 尾巴带来层号反射。记 x₀ = ψ₀(Ω_Ω)，f(c) = 在可数层号 c 上从头折 Ω_c 的值。我算得 f 的闭包点依次是 x_{n+1} = ψ₀(Ω_Ω + ψ_{x_n}(Ω_Ω))，上确界是 ψ₀(Ω_Ω·2)。按这个算法，一次"接上 Ω_Ω"虽然每个私有层都只拿到尾巴，在第 0 层上经 ω 次闭包仍然补齐一整块。块内不丢，丢的只可能是"数了多少块"。
- 层号路线。塔 n+1 的顶层链只折 `Ωt (tw n ⊕ ↑z)`，目标不高于 `tw n`。`lift` 给出的路径在 `tw n` 之上每一层都是一致路径 `inu`，那两行在这段上不触发；后继层只需记作"至少乘 ω"（用现成的 `mono` 与 `◃e`，不必算 `E`/`It`）；强度全部来自 z 的形状被读回成层号的形状。若"折 `Ωt (a ⊕ ↑z)` 不低于理想地折 z 本身"成立，就得到塔 n+1 不低于参照的第 n 行，即**差一座塔的滞后**，足以推出 EBO ≤ Y。
- 这条路线恰好卡在 §3 的第三条：z 里下标层在私有层的结点，朝另一个私有层目标时被摊平成 ℕ 极限，取样只用当时的标准底。之后上下文变大，理想折叠会重新对角，W4 用的是冻结的样本。

**我关不上的地方。** 两边都要把 W4 的树读成"有效序数"，而回退行产生的是值很小、折起来却很强的非正规树，按值读可以偏低也可以偏高（MathCap 的弱点 W1，我在同一处反复改过估计）。没有折叠的第一个上界定理，封顶只能是判断；没有私有层回灌的下界，滞后也只能是判断。

**把握（主观）。** Y < EBO 约六到七成；Y < ψ₀(Ω_{Ω+1}) 约五到六成；塔第 1 项等于 ψ₀(Ω_Ω) 约九成。这些数字只表示我对命题真假的倾向，不表示工期。

对象：没有 Ω 形子层号的层号（后继与 ℕ 极限生成，含一切有限层）。

- **(F) 经 `val` 的分解。** 对这类层号 ℓ，W4 折叠与"先用 `val` 展开成纯树，再用只有四行的纯树折叠去折"在第 0 层互相 `≼`。证明是对折叠定义的一次归纳，`E`/`It n` 部分用一族按阶的逻辑关系（"K 把迭代 d 次的东西变成迭代 d·ω^e 次的东西"），对一切阶同一条引理；行与 `Ev (x ⊹ y) F = Ev y (Ev x F)` 逐条对上。B6A 的 `Real`/`W1`/`W2` 是它在"第 1 层折到第 0 层"的实例。

### 8.2 对旧审核的修正（判断）

### 8.3 Ω_Ω·Ω₂ 这一格的纸面进展

前提 (I)：可数层号上的折叠，相对它拿到的底族，是理想的 Buchholz 塌缩。(I) 未证，就是 §5 的 (F)(H)。在 (I) 之下：

- 尾巴使私有的第 1 层条目在折回第 0 层时触发一次闭包跳 J（跳到 f 的下一个闭包点，ω 次 J 是一整块 Ω_Ω）。算得：m 份 Ω_Ω 折到第 0 层约为 ψ₀(Ω_Ω·ψ₁(Ω_Ω)·m)，不低于理想的 ψ₀(Ω_Ω·m)。小倍数上 W4 偏高，不偏低。
- Ω 之上第一个后继层的值约为 ψ₀(Ω_Ω·ψ₁(Ω_Ω+Ω₂))。门槛 ψ₀(Ω_Ω·Ω₂) 的基本列是 γ₁ = ψ₁(Ω_Ω)，γ_{n+1} = ψ₁(Ω_Ω·γ_n)；这个值在第 1 项与第 2 项之间。
- 再往上有两条各自自洽的推导。
  - **封顶。** 第 0 层数 "块" 用的计数树都形如 ψ₁(Ω_Ω+δ)，δ 是孤立算出的第 2 层序数或它的弱替身，恒低于 ψ₁(Ω_Ω+Ω₃)，于是整个塔第 2 项低于 ψ₀(Ω_Ω·γ₂)，Q 不成立。
  - **滞后。** 层号路线在每个私有层 i 上都有下标对角，回灌是内容在该层的像（值上只比理想少一块）；逐层级联后，层号下标里每多一个 Ω_Ω，ψ₁ 的自变量里就多一个 Ω_Ω，即 "折 Ω_K 约等于理想地折 K"。按它 Q 在层号下标 Ω_Ω·Ω₂ 处成立（低于 z₁ 的层号），全体只差一层 Ω 的滞后，Y 等于 EBO。
- 分歧可以缩到一点：层号下标过了 Ω·2 之后，第 2 层的回灌树有没有进入第 1 层的计数。我两种估法各得一个答案，没有能力靠估算判定。

### 8.4 依赖

Q 的任一方向的证明都以 (I) 为前提：下界要它来算孩子里的折叠，上界同样。没有 (I)，连塔第 1 项等于 ψ₀(Ω_Ω) 也没有。所以按依赖排，实际的下一步是 §5 的 (F)(H)，它本身交付 ψ₀(Ω_n)、ψ₀(Ω_ω)、ψ₀(Ω_Ω) 不高于 Y，并且是 Q 的两个方向共同要用的。§6 第 2 步在 (I) 之后才谈得上编译。

### 9.1 形状事实（编译）

[核对件](Reports-2026-11-24/attachments/AuditFable52-Mirror.agda.txt)，全是 `refl` 或空模式，与 W4 附件同目录编译，6G，退出码 0。记 K = `tw 1`。

- `keep-K-real`：取塔第 2 项的真实孩子 c = `Ωt (tw 1)`，层号 K ⊕ ↑c（读作 Ω + Ω_Ω，Ω 形，下标层是第 0 层）与它在 `Ok-tw 2` 里的证书。朝 K 折它的 Ω 树，结点保留，输出结点落在 K 自己的顶位置。
- `keep-1`：K 自己的顶位置上的结点，朝孩子 1 里的第 1 层折，保留。
- `keep-K-inu`、`flat-after`、`keep-K-ink`：同一个层号 M₂（下标层第 0 层，孩子 c 是 K ⊕ ↑c），两份都合法的证书。下标路径取一致路径时，朝 K 保留的结点落在 K 的孩子 zero 的位置上，再朝孩子里的层折就被摊平（走链）；下标路径经 K 自己的下标时，结点落在 K 自己的顶位置。

最后一条的含义：**W4 的折叠输出依赖层号证书里的下标路径**，两份合法证书给出的树不同，往下一步一个保留、一个摊平。真实运行的证书由读回（`OkO↑`）给出，是 "经自己下标" 的那一种。这一点此前没有记录。

### 9.2 哪一行对哪些目标丢信息（由定义读出，实例已编译）

K 上的树朝孩子 c′ 里的第 i 层折（路径 `inc c′ u`）时：

| 树的形状 | W4 的做法 | 是否丢信息 |
|---|---|---|
| K 自己顶位置的结点（下标层 0） | 保留 | 不丢 |
| 孩子 c 位置上的结点，下标层 i′ ≥ i | 走链 | 不丢，走链本来就是对的 |
| 孩子 c 位置上的结点，下标层 i′ < i | 走链 | 丢：应当保留。i = 1 时就是孩子位置上下标层为 0 的结点（`flat-after` 是一例） |
| `up x c y`（左项加孩子里的树） | `ψ x ⊞ ψ₀ y`，y 从头折到第 0 层作尾巴 | 丢：对一切 i ≥ 1 |

所以朝**第 1 层**折时，K 自己顶位置上的结点不丢；丢的是回退行，以及落在孩子位置上的下标层 0 的结点。一个下标层为 0 的结点落在哪种位置，取决于它的下标路径：经 K 自己的下标（`ink`）落在顶位置，经某个孩子（`inc c`）或一致路径落在孩子位置（9.1）。

### 9.3 对第二轮两种读法的更正（判断）

- **封顶读法的论据不成立。** §8.3 的封顶推导说 "第 1 层的计数树都形如 ψ₁(Ω_Ω+δ)，δ 是孤立算出的"。`keep-K-real` 与 `keep-1` 合起来说明：K 以上的 Ω 形层号折到 K 得到的结点，再折到第 1 层时仍是结点，分支是 "把更高层号在 K 上的折叠值再折到第 1 层"。即 K 以上的结构确实作为结构进入第 1 层的树，不是孤立的。封顶在 Q 这一格的论据撤回；这不等于 Q 成立。
- **滞后读法多了一步有编译骨架的机制，但值没有证。** 进入第 1 层的结构，分支是 W4 自己朝 K 的折叠值的像；它在序数上有多大，取决于 K 以上各层朝 K 的折叠（sS、sL 形的层号上是忠实的行；Ω 形层号上又有它自己的私有层与尾巴，同一种损失上移一层）。
- **损失的位置比第二轮说的更具体。** 按 9.2，来自 K 以上的结构能否进入私有层的计数，取决于它在 K 上落在哪种位置：层号下标树里 K 自己的结点（如 Ω_Ω 的顶）读回成经 `ink` 的下标路径，结构保留；孩子里的树的结点（如嵌在孩子 c 里的 Ω₁、Ω₂）读回成经 `inc c` 的路径，朝别的私有层折时被摊平。若有封顶，它出现在后一种结构不可缺的地方。我没有能力靠估算给出位置，这一轮估算里又翻转了两次（先因 "计数只有尾巴" 倾向封顶，编译出 `keep-K-real` 后撤回）。
- **证书依赖是一个独立的设计问题。** 9.1 最后一条表明，换一份合法证书，K 以上的结构到第 1 层就被摊平。值定理必须对着真实证书陈述；"换证书输出不变" 在 Ω 形层号上不成立。

把握（主观）：Q 成立略高于一半；Y 达到 EBO 仍给不出倾向。

### 9.4 不靠记号的门槛写法

记 F(z) 为在可数层号 `h₁ z` 上从头折 `Ωt` 的值。可数层号定理给出 F(z) 不低于参照的 `ψ⁰ (Ω (code (h₁ z)))`；`btbo-lower` 说的是 F 的第一个闭包点不低于 BTBO。回退行的尾巴就是 F 的值，所以私有层上的一个 "右边接上 Ω_Ω" 是一个分支为 v ⊞ F(z) 的结点，折回第 0 层时走到 F 的下一个闭包点，记作一次跳 J。

于是可以在参照一侧不用记号地定义：对第 1 层的 Level 树 A，I(A) 是 "按 A 的形状迭代 J"（零不动，后继跳一次，ℕ 极限逐项，下标层 0 的结点取对角）。门槛 Q 的树侧写法是：**塔第 2 项是否不低于 I(A)(BTBO)，其中 A 的形状是 ψ₁(Ω_Ω·ψ₁(Ω_Ω))**。它与原记号的 ψ₀(Ω_Ω·Ω₂) 的对应是估计（ω 次 J 是一整块 Ω_Ω，见 §4）。

### 9.5 两个方向各自要证什么（纸面设计，未编译）

## 12. 链点是否字面嵌套（2026-11-25）

作者说两件事都开始，这是第二件：剩下的损失在无穷的私有层，那里若有路径作证据就能就地折；路径可以由两个孩子之间字面的步进证据算出。所以查真实运行里的链点是否字面嵌套。

### 12.1 塔第 1 项：嵌套，对一切 n（Agda，无前提）

[核对件](Reports-2026-11-24/attachments/AuditFable52-Nest.agda.txt)，与 W4 附件同目录编译，退出码 0。记 `zt n` 为塔第 1 项顶层链的第 n 个链点，`st` 为链的一步。

- `first-st`：对任意极限树 `lim f`，`st (lim f)` 的第 0 项逐字是 `st (f 0)`。原因是层号的第 0 个孩子上状态与底都没有变。`refl`。
- `nest : (n : ℕ) → zero ⊢ zt (suc n) ◃ zt (suc (suc n))`：每个链点字面地是下一个链点的第一位置后代（取两次第 0 项）。`n01` 是第 0 步。
- 于是由 `◃→⊑`，前一个链点读回的层号字面地出现在后一个链点读回的层号里，位置是 "第 0 个孩子的第 0 个孩子"。

### 12.2 塔第 2 项：沿第一位置找不到（有限检查，不是定理）

[检查件](Reports-2026-11-24/attachments/AuditFable52-Nest2.agda.txt)。顶层链的第 1 个链点 z₁ 是 `tw 1` 上挂起的乘幂，第 2 个链点 z₂ 是 `tw 1` 上的结点。沿第一位置从 z₂ 往下走 1 到 5 步，都不等于 z₁（检查器报不相等；形状依次是极限、结点、极限、极限、结点，与层号路径一致）；第 6 步在两分钟内没有算完。判断：不在第一位置的后代链上，因为走到后继层时第一位置给出的是 "底乘 ω"，不再递归进更低一层的 Ω 树。经别的位置是否嵌套没有查。

### 12.3 读法（判断）

- 塔第 1 项的顶层链是可数层号上的事，那里的折叠本来就忠实，嵌套在那里用不上；它说明的是 "链点字面嵌套" 这类事实可以成立并且有很短的证明。
- 要用嵌套，折叠在回退处必须拿到两个孩子之间的步进证据。现在的折叠拿不到：孩子的下标是裸的树。把证据带到那里是新设计（例如让嵌入结点或目标路径带着来源），没有做。
- 另一个更近的改进方向：试验四只处理了绝对的有限层，对 `tw 1` 生效。更高的 Ω 形层号上，私有层都是 "基底加上一段"；"相对基底有限" 的那些同样可以定位，但折叠要知道孩子的层号是 "基底加一段" 这个分解，而层号的数据类型现在不记它。这与 "把下标层的位置写进层号" 是同一次重构。

## 14. "候选不低于 W4" 派发前的自查：这条陈述逐行不成立（2026-11-25，判断）

作者说开始证 "候选不低于 W4"。派发前先写接口并自查，结果是**不派**：这条陈述在被改的第一行上就不成立，而且方向与我此前的说法相反。没有编译的否定（缺折叠的上界工具），所以标为判断，路线写 "暂停"。

**哪一行。** Ω 形层号 K 上，朝孩子 c′ 里的层 j 折 `up x c y`。记 b 为左项 x 朝 j 的折叠。

- W4：结果是 b 加一条尾巴，尾巴是 y 在自己的孩子里**从头折到第 0 层**的值（`Gen.fallback`）。
- 候选：结果是 y 在自己的孩子里以 b 为底**朝 j** 的折叠（`branch-2`、`branch-3`）。

**为什么不可比。** 两个结果以后都要再折到第 0 层。W4 的那条尾巴是第 0 层的树，再折时原样带下去，所以第 0 层的值不低于 "y 的完整塌缩"。候选的结果是第 j 层的树，再折到第 0 层得到的是 "y 朝 j 的塌缩" 的塌缩。y 所在的层高于 j 时，后者更小。

**一个实例。** K = `tw 1`，j 是第 1 层，y 是孩子 3 里的 Ω₃。W4 的条目带一条尾巴，它的值不低于参照的 ψ₀(Ω₃)（已编译：`KLow.inst` 在 η = 3 处）。候选的条目是 Ω₃ 朝第 1 层的折叠，是一棵第 1 层的树；按理想塌缩，第 1 层的树折到第 0 层不超过 ψ₀(Ω₂)。后一句没有定理（要上界），是判断。

**后果。**

- 候选与 W4 逐行不可比：有的地方候选更大（低塔的内容以结构进入私有层），有的地方 W4 更大（尾巴带着完整的第 0 层塌缩）。两个闭项谁大不知道。
- 我此前把候选说成 "损失更少"、并据此把 "命题为真" 调高，依据不成立，撤回。能说的只是：候选的这几行与规则的形状一致（朝哪一层折就得到那一层的塌缩），W4 的回退行不一致，但 W4 的不一致有时使值偏高。§4 里记过的 "尾巴在小倍数上使 W4 偏高" 是同一件事。
- 用一棵 W4 树支配另一棵的遗传关系来比较两个折叠，在保留判定那一格也过不去：W4 走链时用的是当时的状态，候选保留结点、以后在别的语境里再对角，那时的状态可以更小。
- 候选真正的用处因此不是 "比 W4 大"，而是 "能对着参照证"：它在有限私有层上的输出逐字是可数层号上的折叠，已编译的折叠保持定理可以直接用上；W4 的尾巴没有参照可对。

**顺带发现的一处简化（没有做）。** 候选给证书加的那条可选路径可以不加：下标路径在孩子 zero 处是 `self` 时（塔的证书正是这样），孩子 zero 的层号就是下标层，路径由已有的下标路径算出。这样候选与 W4 用同一份证书，路径模块不必另抄。
