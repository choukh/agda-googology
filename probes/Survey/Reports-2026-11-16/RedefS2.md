#### 2. 设计

##### 2.1 块：`ex`，指数与本层同型（改 MathK 的 K1）

```
ex : (a b : T S) → Lt S zero b → (x : T S) → T S          -- a + b·ω^x
◃e : Lt S a (ex a b nb x)
◃x : Lt S x x′ → Lt S (ex a b nb x) (ex a b nb x′)
```

- 加法：`x′ + ex a b x = ex (x′ + a) b x`。
- View（纲领第 1 条）：按 x 的构造子看。
  - 零：a + b。
  - 后继：ℕ 极限，逐项 `ex (前一项) b x′`。
  - ℕ 极限：逐项。
  - 结点 `Ω p g`：同一槽位 p 上的 Ω 极限（x 是本层的树，槽位不用搬）。
  - `up x′ c y`：按 y 再看；y 的结点对应旧上折搬出的孩子侧位置。这个位置只在 View 里出现，折叠不经过它。
- `up` 不动。`Up`、`mv`、`Upm` 退出折叠，留作 `ex` 的摊平视图。
- 第 0 层没有 Ω 结点与孩子，最终输出的布劳威尔树不变形。

为什么不用 MathK 的 `pw a x c y`（指数在孩子层）：`pw` 的自身折叠要对 y 递归并在 `self` 路径上保留，输出又是裸的孩子侧结点（MathV 2.3 的 (ii)）。`ex` 让 "朝自身层折" 整体挂起：

```
ψ ℓ … ℓ self β x = ex zero β x          -- 自身行: 一个构造子
```

旧自身行各子句（后继 `next⁺`、结点保留、`up` 上折）正好是 `ex` 的 View 各情形【纸】。

##### 2.2 折叠进指数：迭代子 `E`

把折叠看成状态变换：状态 = (各目标上的底 B, 当前值 β)。"右边接上 t" 是变换 D t，现折叠的左上下文写法 `λ i u → ψ … (B i u) x` 就是它【纸：对 t 归纳，现各行逐条成立】。

```
D (ex a b x) = E x (D b) ∘ D a
E : (x : Tr ℓ) → {X} → Alg X → (X → X) → (X → X)          -- op 迭代 ω^x 次
E zero       A op = op
E (suc x)    A op = λ m → limA (n ↦ iter (E x A op) m (suc n))
E (lim f)    A op = λ m → limA (n ↦ E (f n) A op m)
E (Ω p g)    A op = λ m → nodeA p (z ↦ E (g z) A op m)
E (up x c y) A op = leave (Eᶜ y (enter (E x A op)))        -- 进孩子 c 的框架
E (ex a b x) A op = E x (pt A) (E b A) (E a A op)          -- 高一阶类型上的同一个 E
```

- `Alg X`：结果类型上的 ℕ 极限与结点运算；`pt A` 逐点抬到函数空间。
- 同一个 `E` 取 X = 层号，就是读回 `↑` 的 `ex` 一行（MathK 的 `Rd`）。读回与折叠共用一个组合子。
- **停机：** 对树结构递归，`ex` 一行是多态递归。【编，玩具】`S2Toy` 的 `E`、`D`、`selfFold` 通过；玩具没有层号、合法性与保留判定。

##### 2.3 A 类：框架内的目标（补 MathV 的缺口）

折叠的结果类型按当前框架 φ : `Maybe L` 分度（共享靠类型下标，不靠各结点自存，同 MathK §4.2）。目标有两种写法：
- 环境写法：(j, w : j ≤ ℓ)，同现在。
- 框架写法：(j, τ : j ≤ m)，只在 φ = `just m` 时有。

规则：
- `enter`（进 `up x c y` 的 y，m = h c）：外面来的目标只有环境写法。
- 框架里 y 的结点 `Ω p′ g′`：
  - 目标是框架写法 τ：判定 = `kp (h c) _ p′ τ`（R-A）。
  - 目标是环境写法 w：照现行各行；Ω 形状配 `inc c′ v` 仍是 `nothing`（D 类或裸目标）。
  - 走链时回灌的目标 = (`at (h c) p′`, 框架写法 `posW (h c) p′`)。这是造 τ 的地方。
- 框架里遇到外层的东西（底 b、左加数 a、状态里的 B）：把框架写法忘成环境写法 `inc c τ` 再折（跨框架，裸）。
- `leave`：只接受环境写法的状态。
- 嵌套框架（y 里再有 `up`/`ex`）：进内层时外层的 τ 置空。第一版不带框架栈。

#### 3. 一致性的陈述与证明骨架

##### 3.1 为什么不能照简报的字面写【纸】

- 保留结点是 `Ω⁺ q (z ↦ G (cv z))`。两个折叠的输出要互相 ≼：`Ω≼` 一侧对一切 z 量化，`≼Ω` 一侧可换分支。换分支要 "折叠对分支自变量按值单调"，这已有反例（`YiPSNeg.no-mon`，只读了文首）。所以实际要逐分支一致，即对一切 z。
- 只在 "塔生成的 z" 上要求一致，回灌的链点两边就只是相关而不字面相等。链点又作孩子下标进层号（h a 与 h a★ 是不同的层号，`Tr (h a)` 与 `Tr (h a★)` 是不同的类型），证明变成跨层模拟；`YiCompatDlLPO` 说对孩子封闭的这类关系推出 LPO。
- 所以可证的形式只有：比较函数处处相同 ⇒（函数外延）折叠字面相同。

##### 3.2 陈述

在新块上按比较函数参数化 `Star′ cmpK ctx`。各行同新折叠，只有 "环境写法目标 + Ω 形状 + 孩子侧槽位 + `inc c′ v`" 这一行查 `cmpK h c c′`。构造性折叠 ψᶠ := `Star′ cmp₀ true`。

#### 1. 这条通道在设计里是哪一步

`base-inc` 的底族是 `λ i u → ψ ℓ … i (inc c u) (B i (inc c u)) x`：左项 x 朝孩子 c 里的第 i 层折，路径是裸的 `inc c u`。
