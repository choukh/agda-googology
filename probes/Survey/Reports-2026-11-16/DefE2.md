**1.1 第 0 层：选 "禁掉 `ex`"【编】**
- 做法：`Sg` 加字段 `Ex`，并令 `EX zero = ⊥`、`EX (nd _ _) = ⊤`，`ex` 带一个 `Ex S` 参数。第 0 层不需要补子句，覆盖检查自己判出 `ex` 不可居，`ι` 和 `ι-mono` 就此去掉了 `ex` 行。
- 自身行 `ex β β x tt` 只在非零层用。第 0 层的自身行落回原来的 FGH 行：零给 β，后继给 `next⁺`，ℕ 极限逐点。
- 理由（判断）：
  - 第 0 层的树没有 Ω 和 up，没有东西需要挂起。View 那三条（零、后继、ℕ 极限）在第 0 层直接算出来，就是原来的行。
  - 这样不用为第 0 层另写 `≼` 的 View 证明，输出 `Tr zero` 按类型只有 zero、suc、lim 可居。
  - 代价约 10 行：`EX`、`sfLt` 和 `mono` 限到 `nd`，再加两行第 0 层的 `mono`。

**1.2 带序的结果代数（`E2Block`）【编】**
- `record RA` 的字段：
  - 语境 `Ctx : L → Set`，下行 `dn`；
  - 载体 `Car`，序 `Rel`，传递 `trn`；
  - ℕ 极限 `limA`（要带相邻步进的证据）和上界 `limUB`；
  - 结点 `nodeA κ p G` 和上界 `nodeUB`。
- `OpA A` 是膨胀的 op。`pt A` 是高一阶代数：载体是 `OpA A`，序取逐点的 `Rel`。
- 迭代子 `Eh A κ x F`，与 `opE`、`Emh` 互递归：
  - `ex` 行是 `proj₁ (Eh (pt A) κ x (opE A κ b nb)) (Eh A κ a F)`，即多态递归，停机检查通过。
  - 膨胀律是 b 非零时的 `Emh`，因为 `Eh zero G = G`。
- 不变式 `record PS`（谓词 `Pr`，语境守卫 `Gd`，`limP`，`nodeP`），高一阶的不变式 `ptP`（保持 `Pr` 的 op）。
- 定理 `EP : Gd κ → Opp S F → Opp S (Eh A κ x F)`：对一切树，`ex` 行在高一阶的不变式上用归纳假设。

**1.3 读回取 X = 层号【编】**
- 层号代数 `AL`：语境是 `⊤`，序是 `⊑`，ℕ 极限是 `nd sL`，结点是 `nd (sΩ (at m p))`。
- 读回的 `ex` 行：`↑ k (ex a b _ x _) = proj₁ (Eh AL tt x (opR (↑ k b))) (↑ k a)`，其中 `opR w = (_⊕ w , lift)`。粗写法去掉了。
- `E2Path` 的 `PSL a`（谓词 `OkO a`，守卫 `(m ≤ a) × Ok m`）：
  - ℕ 极限形状的相邻路径，由 `limA` 的证据给出；
  - Ω 形状下标层的路径是 `posW m p ∙ v`，配 `Ok-at`。
- 由此：
  - `OkO↑` 的 `ex` 行就是 `EP AL (PSL a) …`；
  - `◃→⊑` 的 `◃e` 用 `Eh` 的膨胀，`◃x` 用 `Emh`；
  - `Ok-tw n`、`Ok-Λ` 照旧编译。

**1.4 折叠的多态递归 `ex` 行（`E2Fold`）【编】**
- 高一阶代数 `A₂ o d`：载体是框架 d 的 op，序是逐点的 ◃。语境是从框架层下行的链 `κ : Dn m₀ m`。
- `A₂` 的结点按 `kpT (d ++ κ) o p (embT d κ t)` 判定；走链时回灌的目标是 `chT d κ p = dropT d κ (hereT (d ++ κ) (posW m p))`。
- 第一阶 E 的 `ex` 行：`run (proj₁ (Eh (A₂ o d) stop x (opb o d b nb)) (op (E o d a F) (Einf o d a F))) S i t v`。它取代了 E1 的回退写法。
- `Einf`、`Emono` 的 `◃e`、`◃x` 两行由 `Eh` 的膨胀和 `Emh` 给出。
- 设计上的选择：第一阶保留框架栈（E1 的判据 (a) 要用）；高一阶的 up 行不开新框架，沿 κ 把槽位推上去判定。理由【纸】：用 `enterOp ∘ K ∘ leaveOp` 把 op 搬进框架时，膨胀律在非像点上不成立，因为 `leaveOp` 丢掉了框架目标上的值。

**1.5 判据（`E2Check`，全是 `refl`，有限测试另行标出）**
- **(a)、(b)、(c) 重跑**：`top-chain`、`child-keep`、`step-node`、`first-feed`、`second-feed`、`old-k6`、`k-both lem`、`k-bare`、`k-bare-flat`、`c-base`、`c-chain`、`c-sharp` 全部通过。
- **(d) 读回**：
  - `rd-zero`：`↑ (ex a b nb zero tt) ≡ ↑a ⊕ ↑b`；
  - `rd-suc`：指数为后继时是 `nd sL (iter …)`；
  - `ok-child`：`Ok (tw 1 ⊕ ↑ (tw 1) (ex 0 b 1))`，由一般的 `Ok-tw 2` 给出。
- **(e) 高阶调用**：
  - `e-row`：第一阶 `ex` 行转到 `A₂`；
  - `e-nest`：指数本身是 `ex` 时转到 `pt (A₂ o d)`，即第三阶；
  - `e-up`：高一阶的 up 行沿 `down stop c` 下行。
- **(e′) 有限测试 `e-fold-head`**：tw 1 上 `ex 0 b (ex 0 b 1)` 朝第 0 层折，输出头部是 ℕ 极限。
- **(f) `f-zero`**：第 0 层自身行的后继就是 `next⁺`。
- **(g) tw 2 的闭项**：`tw2-ok : Ok (tw 2)`，`tw2ᶜ = twᶜ 2` 是定义；有限测试 `tw2-head : IsLim tw2ᶜ`。
- **(h) 高一阶不开框架的代价**：
  - `ho-chain`：二阶里孩子顶结点回灌的目标被忘成裸写法 `inc 2 τ`；
  - `ho-bare`：再下一层孩子的 q 结点对它的判定是 `nothing`。一阶框架里同一格是 `just`（`k-both`）。
