#### W3 回报：不单射的孩子编码

##### 0 结论

- **第 1 步**：最小实例 `Tr (sc zero) ↠ Tr w₁` 的满射造出来了。

##### 1 新文件、关键定理、档位
四个文件都在 `probes/OCF/Lean/`，共 825 行。除注明的以外，档位都是条件定理（排中律 `LEM`、函数外延 `Funext`，均作模块参数）。

**`YiQNEncBase.lagda.md`**（160 行，编译定理，无前提）
- `lem→uip : LEM → (A : Set) → UIP A`（Hedberg）。
- `inj→surj : LEM → A → Inj A B → Surj B A`。
- `limEq : UIP (T S) → Funext → f ≡ f′ → (∀ n → (f n , f (suc n) , a n) ≡ (f′ n , f′ (suc n) , a′ n)) → lim f a ≡ lim f′ a′`。
- 记录 `Emb a b`（以下称"嵌入"）：
  - 字段：`σ`、`σm`（保持第一位置序）、`σz : σ zero ≡ zero`、`inj`（树上单射）、`injL`。
  - `injL`：在相邻证明的全空间 `TL S = Σ x Σ y (Lt S x y)` 上单射，两端相等由调用者给出。
- 另有 `inj⁺`（非零树上的单射）、`idE`、`natT-inj`。

**`YiQNEncStep.lagda.md`**（313 行）
- `Step.step : StepData s h s′ h′ → Emb (nd s h) (nd s′ h′)`。
- 一步数据包括：
  - 孩子映射 χ，以及每个孩子的嵌入；
  - 槽位映射 π，以及分支类型的满射 ρ，带 `ρb`：第一分支对应第一分支；
  - 槽位的单射标签 `tagP : Pos a → Tr b`，孩子的单射标签 `tagC : Ch s → Tr b`。
- 编码方式：用目标层的 Ω 对 `⟪X , Y⟫ = Ω p₀ (0 ↦ X, 其余 ↦ Y)` 把原像和标签拼在一起。
  - Ω 结点 ↦ `⟪Ω (π p) (σ∘g∘ρ) , tagP p⟫`；
  - 嵌入结点 ↦ `up ⟪σ x , tagC c⟫ (χ c) (σ_c y)`。

**`YiQNEncPair.lagda.md`**（78 行，第 1 步）
- `E₁ : Emb w₁ (sc zero)`：一步嵌入的实例，孩子编号和槽位编号 n 都记成标签 `natT n`。
- `surj₁ : Surj (Tr (sc zero)) (Tr w₁)`。
- `ps₂′ : PS (sc w₁) (sc (sc zero))`。
- `tp₂′`：`sc w₁` 的每棵树被 `sc (sc zero)` 的某棵树按值支配。反方向是已有的 `YiQNCollapse.tp₂`。

**`YiQNEncGen.lagda.md`**（274 行，第 2 步）
- `G.Gen : (a : L) → Acc _≺ᴸ_ a → Ok a → a ≼ᴸ b → Emb a b × PZ a b`。
  - 对左侧层号按值良基递归。
  - 孩子和槽位用递归得到的嵌入；槽位的嵌入再经排中律取逆，成为满射。
  - 槽位路径编码进目标层（`PathEnc`）：孩子路径 ↦ `up (lab c) (χ c) …`，下标层路径 ↦ `Ω p₀ (常值)`。
  - 第 0 层用 `ι`（`ZeroE.ιE`）。
- `G.IS : Ok a → a ≼ᴸ b → Emb a b`。
- `G.psAll : Ok a → Ok a′ → a ≼ᴸ a′ → PS a a′`。
- `G.tpAll : YiRVOmega.Tp`（经 `tpPS`）。
- `G.ΩtMono`（= `Mono.M`）：Ok ℓ、Ok ℓ′、Nm ℓ′、ℓ ≼ᴸ ℓ′ ⟹ `val (Ωt ℓ) ≼ val (Ωt ℓ′)`。
- `G.ΩtSame`（= `M≈`）。
- 例 `ex₂`：合法同值对 `sc (sc zero)`、`sc w₁` 的 `Ωt` 同值（这对层号没有同层号槽位）。

**前提可满足**
- `LEM`（对一切 `Set`）加 `Funext`：经典集合模型同时满足。注意 LEM 经 Hedberg 推出 UIP，所以与单价性不相容，但与 `--without-K` 相容。
- 这里的 `Funext` 是普通的函数外延，比 `YiQNCollapse` 用的 `FunextE` 弱，不需要计算律。
- `Ok a`、`a ≼ᴸ b` 的实例：`ex₂`。

**两种写法**
- 第一种写法：标签放在唯一孩子里，形如 `up (up (σ x) tt (A n)) …`。它对第 1 步那一对也编译通过（退出码 0），但已经退役。备份在 `<实验目录>/cl/W3/Step-v1.lagda.md.bak`。
- 退役原因：一般情形下 χ 不单射，孩子 c 的标签所在的类型依赖于 χ c，单射性证明会遇到依赖类型的转运。
- 第二种写法把标签改放到目标层自己的 Ω 对里，这个问题就不出现了。现行文件都是第二种。
