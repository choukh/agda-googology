### B10B · 独立核查真实分支并把逐项界接回 Ψ₃

请在协调者给定的私有 B10B 目录工作，以 `B10Exit` 为模块前缀。模型 Opus 5.5。先读公共源码 `YiLAB10Rows`、`YiLAB10Branches`、`YiLAB9Paths`、`B9InnerOuter` 的定义与签名，自己展开两个编号，再对照[主审的纸面推导](../Lead/指令-03.md)。可以独立于 A 路完成。

**交付。** `assemble : ((n : ℕ) → YiLAB10Rows.Row n) → YiLAB10Rows.Result`。Result 是 Level 的 ψ⁰(Ω₂+Ω₂) 不高于 W4 的具体 `read Ψ₃`。同时交一个可实例化的单项出口及分别对零号项、首个非零项的无前提调用。整个族作前提时，注明其统一实例依赖 A 路的回报。

1. 以同一个 k 对照 `YiLAB9Paths.S k`、`v k`、`cz k` 与 `YiLAB10Branches.states k`。在 `WKGen.Main ok₂ (S k) w2 (v k) ...` 中取 `fold 2`，核实 `zs 2` 与 `B.z k 2` 的定义性等式。该模块的 `hc` 由 Ω₁ 到第一次更新的步进与 `B.rise` 传递，两个零层正性前提由现成的 `v-bound`、`cz-bound` 和 `1≼ψ⁰` 推出。实际 `Ψg` 是 `v (suc k)` 的树。
2. 将单项出口量化为任意已经配对的具体 `D`，或再弱到只用它在原始分支上的被加项证据。取 `Match.add-l`、`L2-sem`，用 `Match.add-w` 对齐两边的底和链底，再经 `Ψg-ge 2`、`approx k` 推至 `read Ψ₃`。零号项可在 k = 0 用 `seed`，沿 `chain-step 0` 到 `c 0`，沿 `◃e` 到 `z 0 2`。首个非零项用 `row0`。最后以 `finish` 合并零号与各个后继号。核对这条证明对更高前缀和 `Gap′` 的依赖。
3. **独立反查。** 在同一接口刻意把首个非零项的原始状态替换成冻结初态，用 `frozen₀` 验证这个改写确实失效。另查若把零层底或 `inc tt (inc tt self)` 链底错用成初态，哪一个前提首先丢失。若能给出该具体错配的编译否定就交付；只发生类型失配就按其范围说明。若主审写错轨道或分支，优先报告有类型的反例或给出正确编号。该反查允许发现比 `Row` 更弱的充分条件。

每路约 1200 行，可换一次写法。只在私有目录写纯 Agda，不改 W4。用仓库工程选项，每次 Agda 带 6G 堆。需要经典原理时只作验收参数并标明。交回入口、源码、日志、首个错误或退出码、前提的实例及纸面首个偏差。尚未与 A 路合成时把结论写成条件定理。请分开记录 Level、src、塔和 Λ 四种端点。

## 回报原文

### B10B 回报 · 外层出口与反查

#### 结论

- **出口（单项）**：已编译，无前提。对第 k 个状态的原始内链项 `B.z k j`，只要有被加项证据 `Ld D d` 与 `SumR (B.z k j) d`，就得到 `ψ⁰ (body D) ≼ read Ψ₃`。指数那一半不用。证明里没有用到更高前缀的语义、`Gap′` 和 `First`。依赖图核过：`B10ExitCore` 的导入闭包里没有 `B9UpperMain`、`B9UpperRel`、`B9UpperTop`。
- **零号项与首个非零项**：都无前提。`term0` 给出 ψ⁰(body (Y 0))，`term1` 给出 ψ⁰(body (Y 1))，两者都 ≼ read Ψ₃。`term1` 与 B9A 的 `outer` 是同一个陈述，这里只是改用通用出口证明。所以无前提部分的值没有超过第九批。
- **assemble**：`((n : ℕ) → Row n) → Result` 已编译，是条件定理。整族 Row 的统一实例要等 A 路的 `rows`。
- **更弱的充分条件**：已编译，`assemble-add` 只要求每个 n 存在某个状态 k、链位 j 与 d，使 `Ld (Y (suc n)) d` 且 `SumR (B.z k j) d`。`exit-below` 进一步允许证据落在 `B.z k j` 之下的任一树上，再经 `SumR-up` 上传。
- **主审纸面**：轨道与分支编号没有写错。第 1 步的对照全部是定义性等式，第 3 步原样编出。唯一的偏差在简报反查一节对 `frozen₀` 的读法，见下文「纸面首个偏差」。

#### 1. 编号对照（全部已编译）

- `S≡states k : P.S k ≡ B.states k` 是 refl。原因是 `st1 = itS F 1 B₀` 定义上归约为 `stepS F B₀`。
- `cz≡ k : P.cz k ≡ B.states k zero (inc tt (inc tt self))` 是 refl。
- `v≡slot k : P.v k ≡ B.states k zero w2` 对 k 归纳，是命题相等。零层底与零层链底取自同一状态的两条不同路径：w2 是 inu 路径，链底是 `inc tt (inc tt self)`。
- `module M k = WKGen.Main ok₂ (B.states k) w2 (P.v k) (inj₂ (Ω₁◃c k)) (one-v k) (one-cz k)`：
  - `Ω₁◃c 0 = chain-step 0`，`Ω₁◃c (suc k) = ◃t (Ω₁◃c k) (B.rise k)`。
  - `one-v` 与 `one-cz` 由 `1≼ψ⁰`，加上 `v-bound` 或 `cz-bound` 得到。
- 下面三条对任意 j 都是 refl：
  - `zs≡z k j : M.zs k j ≡ B.z k j`
  - `Ψg≡v k : M.Ψg k ≡ proj₁ (P.v (suc k))`
  - `c≡ k : M.c k ≡ B.c k`

#### 2. 出口

`exit-add` 的证明链如下（a、c 分别是 `v k` 与 `cz k` 的读回）：

> `L2-sem al a c (v-bound k) (cz-bound k)` → `aw (M.B′ k) (wd w2) (v k) a c refl refl (one-cz k)` → `M.Ψg-ge k j` → `P.approx k`

其余各项都由它推出：

- `exit-match` 与 `exit-row k = exit-match k 2` 由它直接得到。
- `term0 = exit-below 0 2 (◃t (chain-step 0) ◃e) (add-l seed) (add-w seed)`
- `term1 = exit-row 0 R.row0`
- `assemble rows = P.finish`，零号用 `term0`，后继号用 `exit-row n (rows n)`。

#### 3. 反查

**(a) 所取项换成冻结初态的分量 `chainW 0`。**
- `frozen-row = R.frozen₀`，无前提。
- 比它更强的 `frozen-add : (d : Sh 0) → Ld (Y 1) d → SumR (chainW 0) d → ⊥`，取自 `B8FreezeMain.no-add`，无前提。出口只用被加项证据，所以这一改写在出口的接口上确实失效，与参数无关。
- 对照 `frozen-below : chainW 0 ◃ B.z 0 2`：冻结项在实际链项之下。

**(b) 把首个非零项的「状态」换成初态 B₀。**
- 这样同一个 Main 的第 2 个链点是 `zW 2`，不是 `chainW 0`（`zs-frozen : Outer.M0.zs 2 ≡ zW 2`，refl）。`frozen₀` 不覆盖这一情形。
- 只交出条件否定：`no-frozen-state-if : (H : T₀) → H₂ ≼ H → suc H ≼ ψ⁰ (Y 1) → (d : Sh 0) → Ld (Y 1) d → SumR (zW 2) d → ⊥`。
  - 其中 `H₂ = sE (sC (eU 1)) fΩ (fΩ 𝟏 𝟏) (fΩ 𝟏 𝟏)`，上界由 B9N 的 `topB` 给出：`zW2-up`。
  - 前提 `suc H₂ ≼ ψ⁰ (Y 1)` 是 Level 与影子之间的闭不等式，与 `Gap′` 同类，未证明，可满足性只是判断。
  - 能不能从 `Gap′` 推出它，要看 `sE` 是否在底参数上单调。现有库里没有这条引理，没有做。

**(c) 零层底或零层链底错用成初态 `Ωt zero`（读回为 1）。**
- 两种错配都能实例化：`Mβ k` 把零层底换成初态，`Mc k` 用混合底族 `Bh k`，只换第 0 层的槽，链不变（`chain-same` 是 refl）。WKGen.Main 的三个前提都还成立，SumR 的三个前提在 a = c = 1 时也成立。
- 首先丢失的是 L2-sem 的 ψ⁰(Ω₂) 正性，有编译否定：`lost-β`、`lost-c`，均基于 `no-Ω₂≼1 : ψ⁰ Ω₂ᴸ ≼ 𝟏 → ⊥`。
- 零层底错配时还有第二处丢失：`Ψg` 不再是 `v (suc k)`，`approx` 接不上。这只是类型失配，不是否定定理。
- 剩下能用的只有 `Ld-sem`，它只给 ψ⁰ D，丢掉了 Ω₂ 前缀。
- 这两条否定只否定 L2-sem 的前提，不否定错配后的结论本身。否定结论需要 Ω₂ 折叠的上界，没有做。

#### 纸面首个偏差

- **反查一节的读法。** B10B 简报第 3 步写「把首个非零项的原始状态替换成冻结初态，用 `frozen₀` 验证」。实际上 `frozen₀` 否定的是「所取项换成冻结状态的分量 `chainW 0`」，这与 `YiLAB10Rows` 的注释一致。真正把「状态」换成 B₀ 得到的是 `zW 2`，那里只有 (b) 的条件否定。
- **Row 比出口需要的强。** 纸面第 2 步预期的 Row 带指数一半，出口完全不用，`AddAt` 已经足够。这对 A 路意味着：如果 `Real` 那一半卡住，可以只交被加项族，组合用 `assemble-add`。
- **原样编出的纸面步骤。** 第 3 步全部：`approx`、两条零层界、`Ψg-ge 2`、零号经 `seed`、`chain-step 0` 与 `◃e`，以及 `finish`。没有需要改写的中间陈述。

| src | 无新结果，最好的仍是 B9 主审补证的 `strict-src`。本路没有把 Level 的 ψ⁰(Ω₂+Ω₂) 翻译到 src。 |
