#### 1. 不变式与证明骨架

##### 1.1 为什么候选 (i)(ii) 的直接写法不行【纸】

- **逐项相同的精确参照**（树的基本列与记号逐项相等）就是 `Lab`，太严。树与记号至少在四处基本列不同：链起点（树是 0，记号是 Ω_κ）、部分和极限、`next⁺` 的项数、龙骨的孩子（`tw n ⊕ ↑c` 对 c）。
- **与记号的序型相等**不成立。记号里 Ω_1 以下的标准形是可数个，序型是可数的；`tw 1` 的值是对一切 `Tr zero` 取上确界。两边不是同一个序数。
- **集合论的 Buchholz 函数**（在树的值上定义 C 集）可以给出与表示无关的精确值定理，但要在 Agda 里重做 C 集、标准形、基本列的全部理论，还要给结点的分支函数加 "对 C 集一致" 的遗传条件。我判断比下面的写法贵，没有展开【判】。
- **按值单调**不能作不变式：ψ♯ 对非退化的树也不按值单调（§1.5）。

##### 1.2 命名不变式的陈述【纸】

记号：|ℓ| 是层号的值（S1Sharp 的 `≼ᴸ`）；‖x‖ = |↑ k x| 是树的严格值；NF 是记号标准形（`EboLean` 的 `NF`）；s < t 是 `_<ᵀ_`。

**项模型** ⟦t⟧：把记号项在树的代数里求值。和对应嵌入，ψ_u(b) 对应 "ψ♯ 朝 ⟦u⟧ 读成的层号折 ⟦b⟧"，Ω_u = ψ_u(0) 对应底值 `Ωt`。它用 ψ♯ 自己定义，所以折叠对项模型的精确性是定义加同余。

**命名关系**（逻辑关系，对层号的值良基递归）：
- 层号：ℓ ≐ ν 指 ℓ 与 ⟦ν⟧ 读成的层号同值，且 ℓ 正规（ℕ 极限形状的孩子按值严格增，Ω 形状的孩子没有最大元）。
- 树：x ≐ a 指
  - (V) ↑x 与 ⟦a⟧ 同值；
  - (H) 按构造子遗传。零、后继、ℕ 极限逐成分。结点 `Ω p g`：槽位层 ≐ κ（a 的余尾是 Ω_{κ+1}），且有函数 F 使 "z ≐ η 推出 g z ≐ F(η)"，并且 a[η] ≤ F(η) < a。嵌入：两个成分各有名字，a 是它们的标准形的和。

结点的名字带一个函数 F，不要求 F 就是记号的 Ω 基本列 a[·]。这是为了龙骨：`Ωt (tw 2)` 的分支是 η ↦ Ω_{Ω+η}，记号的是 η ↦ Ω_η，两者在小的 η 上逐点不同，上确界相同。

**不变式**：
- **(A)** 对标准形 s < t，⟦s⟧ 读成的层号严格低于 ⟦t⟧ 的。
- **(B)** x ≐ a，目标层 j ≐ u，底族与底值 ≐ 上下文 K，则 ψ♯ 朝 j 折 x 的输出 ≐ ψ_u(K ∔ a)（∔ 是标准形的和）。

**A 推出两边判定处处一致**：槽位层 ≐ κ，目标层 ≐ u。记号比较 κ+1 与 u；树比较两个层号的值。A 加记号的三歧，加 `≺ᴸ` 反自反，两边同支。再由 `keep-forced`、`chain-forced`【编】，ψ♯ 实际走的就是这一支。

**读回域**：有名字的层号上有名字的树。它对折叠的三种递归调用封闭，全由 B 给出：
- 孩子层调用：嵌入行，B 用在左项与孩子树上。
- 底族调用：只在有名字的目标层上被问到。被问到的目标层要么是当前目标，要么是有名字的树的结点槽位层，后者由结点一条带名字。
- 链的回灌：对 n 归纳。z₀ = 0 ≐ 0；z_{n+1} 是朝槽位层折 g(z_n)，g(z_n) ≐ F(γ_n)，由 B 得 z_{n+1} ≐ ψ_κ(K ∔ F(γ_n))。"链点都在读回域里" 就是这条归纳。

##### 1.5 对照 `no-mon`

- `no-mon` 的反例用 `G₃`（按链点的构造子取值）和 `D₆`（常值分支）。它们不在读回域里：常值分支的结点没有满足 a[η] ≤ F(η) < a 的名字。命名不变式不对这类树说话，所以 `no-mon` 不挡它【纸】。
- 但挡住的东西比 "退化" 多：ψ♯ 对非退化的树也不按值单调【纸，未编译】。在层号 `one` 上，值为 ε₀+1 的树（经嵌入）低于 `Ωt one`（值 Ω），但朝第 0 层折前者得 ω^{ε₀+1}，折后者得 ε₀。原因是 ψ♯ 是按树的结构递归的折叠，对应记号里不加标准形条件的 ψ。
- 所以两边性不能写成 "ψ♯ 在合法树或正规树上按值单调"。能写的是 A：在标准形的名字上按记号的序单调。ε₀+1 作 ψ₀ 的参数不是标准形，不在 A 的范围内。

##### 1.6 "只依赖层号的值" 的范围

- 保留判定：只依赖值。`keep-forced`（槽位层严格低于目标层就是保留）与 `chain-forced`（目标层不高于槽位层就是走链）对一切 `lem` 成立【编】。这使对齐可以只谈值。
- 底族：不只依赖值。`Dg = nd (sΩ zero) (常值 zero)` 与 `one` 同值（`D≼one`、`one≼D`），`Ωt Dg` 的值不超过 1，`Ωt one` 的值至少是 2（`shape-matters`）【编】。所以命名关系里层号要带 "正规"。
