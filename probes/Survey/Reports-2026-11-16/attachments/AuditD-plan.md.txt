# D 路第 1 步封存判断（只读定义，未读任何结论文件）

记号：k = h₁ one（能在 Tr zero 上分支，输出 < Ω₂，对应 ψ₁）；a₁(suc one) = nd (sΩ k) (hh one)，
hh one z = nd sS (λ _ → tw 1 ⊕ ↑(h₁ one) z)，按层号的值读是 Ω_{Ω₂}；链步
fd z* = ψ (a₁(suc one)) … k (ink self) (B k) (up zero z* (Ωt (hh one z*)))，z* = Ωt (h₁ one) 读 Ω₁。

## (a) 现行折叠在这一步上做什么；承不承载 ψ₁(Ω_{Ω₁})
判断（纸面，未编译）：**不承载**，把握约八成。依据是 `YiRWFold.kp` 与 `YiTBRow.ψ` 的三行：
1. `kp (nd (sΩ k) h) _ (inj₂ _) (inc _ _) = nothing`：位置在孩子 c 里、目标在另一个孩子 c′ 下面时一律不保留，
   哪怕该位置的层号是 zero、目标 k 自己就有在 Tr zero 上分支的槽位（`YiKTSlot.kp*`、`YiRQDom.drop` 是这一行的实例）。
   于是本该是 Ω₁-共尾的分支被换成 ℕ-对角（`node⁺ nothing` → `limc⁺`），反馈在层号 zero 上做（ψ₀ 的可数值）。
2. `ψ (nd (sΩ k) h) … (inc c′ v) β (up x c y e) = dW (proj₁ r c c′) … (ψ x ⊞ ψ₀(h c) y)`，而 `rbᶻ` 的表
   只在 c 或 c′ 字面是 zero 且 h zero = zero 时给出比较（`ent-ss`、`ent-ll` 是 nothing）。所以在 tw 1 = nd (sΩ zero) h₁ 里，
   目标 k 在孩子 `one` 下面时，孩子 suc c 上的项 `up x (suc c) y` 被折到层号 zero 再加上去（`YiRQDom.fall`，refl）。
   ψ₁(Ω_{Ω₁}) = sup_{c<Ω₁} ψ₁(Ω_c) 需要的正是这些项对目标 k 的折叠；现行行给出的是 β + ψ₀(Ω_c)（可数加项），
   整个 Ω₁-分支的值约为 β + Ω₁。
3. 链步的实际走法：`Ωt (hh one z*)` 的顶分支（在 Tr X′ 上，X′ = tw 1 ⊕ …）不保留 → 在 X′ 上对角；X′ 的顶槽位 p*（层号 zero）
   按第 1 行又被丢掉 → 反馈是可数的 c_n；往下各后继层（nd sS）是如实的折叠，但到前缀 tw 1 时落入第 2 行。
   结果估计：fd z* 的值不超过某个 ψ₁(Ω_{c*})（c* 可数）量级的若干次复合，严格低于 ψ₁(Ω_{Ω₁})（后者对可数参数的 c ↦ ψ₁(Ω_c) 封闭）。
   另一个旁证：ψ₁(Ω_{Ω₁}) 的共尾是 Ω₁，而 fd z* 顶上是 `lim`；这不矛盾下界，但说明下界只能靠某个 G(x_n) 越过它，而上面每一项都不越过。
未核：基底 Bᴱ 在中间层号上的具体内容（只看到 `start-form`：层号 h₁ d 上是 Ωt ⊞ Y₁ ⊞ Y₂）；若基底在别的层号上自带大值，估计要改。
注意档位：`no-spec*` 否定的是接口 `KeepSpec′`，不是值；值的否定需要一条上界读法（`Refute` 的前提），我没看到它被证明。

## (b) 候选折叠改了哪几行；能不能修；有没有更简单的改法
- (A) `kpᴬ = alt kp (flr …)`：kp 说不保留、位置层号字面是 zero、目标非 zero 时，用目标里的地板槽位保留。只改第 1 行在层号 zero 的情形。
- (B) `lifted = true`：把第 2 行的回落 `ψ x ⊞ ψ₀ y` 换成 `ψˡ`：把孩子上的 y 当作 ℓ 的树，对同一个目标 j 就地折叠，不比较 c 与 c′。
- (C) `Org`/`Pv`/`kpʳ`/`kpᶜ`：来源表，记录 ↑ 出来的 sΩ 结点的位置来自 k 的哪个位置，`ink` 行与目标表 `ot` 用它保留。
判断：(A)+(B) 对 d = one 这一步是对路的（目标 k 以下的层号只有 zero，地板够用；(B) 让 Ω_c 的项对 k 折叠而不是对 zero）。
d ≥ 2 或目标是别的反馈层号时，需要保留 "层号在目标之下但不是 zero" 的位置，(A) 不够，才要 (C)。
对 (C) 的担心：表在反馈与换目标处重置为 `org-no`（`YiKFFold.ψ` 的 Ω 行与各 up 行的基底参数），这些正是对角的反馈折叠，
可能在下一层重现同样的掉值；`kpʳ` 的 `(inj₂ _) (inc _ _) = nothing` 一行原样保留，兄弟孩子之间仍只有地板。
更简单的改法（判断）：只用 (B)，再把 "保留" 改成只靠字面证据的一条规则——位置的层号 b 与目标 j 之间有字面路径 b ≤ j 的证据时保留——
证据不从比较 c、c′ 得到，而由层号构造时携带（⊕ 的前缀 `lift`、↑ 的来源）。(A) 是它在 b = zero 时的特例（`z≤`），(C) 是它在 ↑ 来源上的特例。
若这条统一规则写不出来（证据要按孩子下标派发），按 AGENTS 先验检查应对照 `obs→dec` 一族。
改动理由是否来自树侧：是。"低于目标保留" 是 FGH 规则形状里写明的效果，第 1、2 行没有实现它；这不是为了验收方便。

## (c) 攻法对不对；最难的一步在哪里
- 站 → 里程碑 → 同步对象链步，这个归约本身是合理的定位手段；但如果 (a) 的判断对，链步在现行折叠下是假的，
  继续在现行折叠上证 `Cand`/`TightDom` 是白费；先要判定 (a)（一个上界或一个更小对象上的否定），再决定改折叠。
- 我预计同一个缺陷不限于 d = one：任何 sΩ 结点下 "目标在孩子 c′ 下、材料在孩子 c 上" 的情形都落到这两行；
  第 3 站以后每一站都会再遇到，所以它应当写成一条对折叠的整体引理（"层号低于目标的位置被保留、高于目标的项对目标折叠"），不按站逐个证。
- 最难的一步是数学的：在不判定兄弟孩子层号大小的前提下实现 "低于目标保留"（壁垒禁止全分支比较）。工程上的堆墙是次要的。
- 备选攻法：终点只要下界，若存在不经过中间目标（只对目标 zero 与自身层号折叠，路径只有 `inu`/`self`）的累计构造能给出 ≥ EBO 的值，
  就可以绕开这两行；我怀疑绕不开，因为对角的反馈必然以中间层号为目标。
