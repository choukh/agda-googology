结论是 (b): 保持律 (`YiSOLow.Keepᵗ` 的多目标形式, 参照逐项取 ψ_κ(K ++ t)) 从塔第 2 项起在值上不成立.

## 1 所选的域

- 状态: 由 `rootˢ n` 经 `stepˢ` 生成的可达状态 (同 `YiQVDom.Reach`).
- 树: Ω 树 `Ωt (层号)`, 状态所在层号是可达状态的层号.
- 读法: 精确读法, 即层号 a 的读法 μ 与真值相等 (|μ| = |a|), 推导每个结点的槽位读法 ν 等于槽位层真值.
- 目标: 两种口径都考察. (甲) `Keepᵗ` 原样, 对一切目标量化; (乙) 只取终点递归实际问到的目标.

理由. 树的域收不窄已有编译定理 (`YiQVDom.full-succ`, `dom-full₂`), 所以不在树上再收.
读法不精确时保持律的失败读作谓词太宽 (YiSO, 审查 F 路, YiQV 都是这一类); 取精确读法后剩下的失败才是折叠与参照之间的事.
域非空: 塔各项的规范读法是精确的 (`YiNLCanonical.canon-read`, `canon-top`; |κ n| = |tw n| 是【纸】: tw (n+1) 的孩子是 tw n ⊕ ↑c, 上确界是 Ω_{|tw n|+1}).

## 2 主结果

**定理 A (形状,【编】`MathAShape.crossN`, `foldN`, `rowΩ`, `up-slot`).**
设 d : `Tr zero`, t′ : `Pos⁼ (h₁ d)`, g 任意, W = `Ω (inj₂ (d , t′)) g` : `Tr (tw 1)` (根结点的槽位在 tw 1 的孩子 d 一侧), N = h₂ W.
对任意 d′, 任意 j 与 v : j ≤ h₁ d′, 取路径 w = `inc d′ v ∙ lift (tw 1) (↑ (tw 1) W)` : j ≤ N.
则 `kp N oN (inj₁ (inj₁ tt)) w ≡ nothing`, 于是 `BS.ψ N oN r B j w β (Ωt N)` 对一切 r, B, β 是部分和极限 (链).
另: 上折把孩子层 h₁ d 的结点 `Ω p g` 搬成 tw 1 上槽位为 `inj₂ (d , inj₂ p)` 的结点 (`up-slot`), 所以这样的 W 就是自身行的输出.

证明的三步: (1) tw 1 上孩子侧槽位配路径 `inc` 是 `kp` 的子句 `kp (nd (sΩ k) h) _ (inj₂ _) (inc _ _) = nothing` (`cross₁`, `refl`);

(3) Ω 形状顶上的下标侧槽位配 `inu` 是推进到孩子 `zero` 再判 (`top`).

## 3 定理 B 的计算

**层号与读法.** h₁ 2 = `nd sS (nd sS zero)`, 真值 2. `Ωt (h₁ 2)` 是前驱层 (第 1 层) 槽位上的结点, 第 c 支是 `suc c` 的嵌入, 真值 Ω₂.
W = `Ω⁺ (inj₂ (2 , inj₂ (inj₂ (tt , inj₁ tt)))) (c ↦ next⁺ (Up … b c))` (`Up` 的结点行与嵌入行, `up-slot` 给出槽位), c 取遍第 1 层的树.
上折在零上给 b, 后继上 `next⁺`, 极限与结点逐项, 所以 |Up … b c| = |b|·ω^{|c|}, |W| = |b|·ω^{Ω₂} = Ω_{Ω₁}·ω^{Ω₂} = ω^{Ω_{Ω₁}+Ω₂} = ψ_{Ω₁}(Ω₂) = μ.
μ 的余尾是 Ω₂ (规则 5Ω, 1+1 ≤ Ω₁), μ[η] = ψ_{Ω₁}(η). |N| = Ω₁ + μ = μ. N 的孩子 N_c = tw 1 ⊕ ↑(next⁺(Up … b c)), |N_c| = |b|·ω^{|c|+1} = ψ_{Ω₁}(|c|+1).
`Ωt N` = `Ω (inj₁ (inj₁ tt)) (c ↦ up zero c (Ωt N_c))`, 读法 Ω_μ, 余尾 Ω₂, 槽位读法 ν = 1 (第 1 层).

**参照.** K = [], t = Ω_μ, κ = 2. cmpᵀ(ν+1, κ) = cmpᵀ(2, 2) = eq, 规则 5Ω: ψ₂(Ω_μ)[η] = ψ₂(Ω_{μ[η]}) = ψ₂(Ω_{ψ_{Ω₁}(η)}), η < Ω₂. 值是这些的上确界, 余尾 Ω₂.

**树.** 定理 A 给 `kp ≡ nothing` (取 d = d′ = 2, t′ = `inj₂ (inj₂ (tt , inj₁ tt))`, v = `self`). 折叠值是 `limc⁺ (k ↦ G (pt k))`:
pt 0 = 零, pt (k+1) = 朝第 1 层 (路径 `posW N (inj₁ (inj₁ tt))` = `ink self`) 折 `up zero (pt k) (Ωt N_{pt k})` 的输出, G z = 朝第 2 层折 `up zero z (Ωt N_z)`.
每个 pt k 是第 1 层的一棵树, ζ_k = |pt k| < Ω₂; ℕ 个这样的值的上确界 ζ < Ω₂ (Ω₂ 正规).
G z 的值: `up zero z y` 配路径 `inu` 进孩子 z, 朝第 2 层折 `Ωt N_z`. 【判 1】这个值不超过理想的坍缩值 ψ₂(K′ + Ω_{|N_z|+1}), 其中 K′ 是一个与 z 无关的可数或 < Ω₃ 的常量上下文 (起点与底的贡献).
依据: 这次折叠里路径在地板以上都是一致的 (`inu`), 不经过 `seen` 那一路的替身; 没有编译的上界定理.
于是树的值 ≤ sup_k ψ₂(K′ + Ω_{ψ_{Ω₁}(ζ_k+1)+1}) ≤ ψ₂(K′ + Ω_{ψ_{Ω₁}(ζ+2)}).
参照取 η = ζ+3 的一项 ψ₂(Ω_{ψ_{Ω₁}(ζ+3)}) 已不低于它 (K′ 小于 Ω_{ψ_{Ω₁}(ζ+3)}, 被吸收), 而参照是余尾 Ω₂ 的上确界, 所以严格更大.

**为什么这是折叠的事而不是读法的事.** 槽位层 (第 1 层) 的真值严格小于目标层 (第 2 层); 读法是真值的下界, 槽位读法取不到 ≥ 2. 把目标读法取低 (κ ≤ 1) 时参照坍缩, 那是另一条陈述, 值更低.
所以 "同一棵树另有读法更高的推导" (YiQV 对 `NodeDrop` 的判断) 在这一格不适用: 这里槽位真的低于目标, 该保留而折叠走链.

**【判 2】** 推论 C 用到 "`GR.R (h₁ 2) s x` 推出 |s| ≤ |x|". 第 2 层没有 Ω 形状, 关系的规则逐条对值可靠 (`mz`, `m1`, `mL`, `mΩ`, `mU`, `mw` 显然; `mc` 在两边都是标准形时可靠). 对非标准形的 `mc` 不可靠, 所以推论 C 的严格形式是: 前提组不能由只含标准形 `mc` 的推导同时满足.

## 4 命题 D: 终点递归实际问到的格

塔第 2 项的顶结点朝第 0 层走链. 链点 z₁ = Z = 朝 tw 1 自身折 `Ωt (tw 1)` 的输出 = `Ω idx (d ↦ U_d)`, U_d = `Up (h₁ d) (down stop d) b₀ (Ωt (h₁ d))`.
A₁ = h₂ Z 是 Ω 形状 (下标层是第 0 层), 孩子 A₁_d = tw 1 ⊕ ↑U_d. `Ωt A₁` 朝第 0 层又走链, 链点 d₁, d₂, … 是第 0 层的树.

【判 3】链点 d_m (m ≥ 1) 的第一孩子脊上有一棵形如 `lim (i ↦ x + (i+1))` 的树 (相邻项都是后继). 依据: 朝第 0 层的折叠输出由起点经 `next⁺`, 极限, 部分和生成, 第一项一路回到起点; 根状态的起点里有 `next⁺ (Ωt zero)` = ω (即 `betaᴮ 1`, 定义展开). 没有对具体的 d₁ 逐项展开核对.

在【判 3】下: h₁ d_m 的脊底是 ℕ 极限形状, 孩子是后继层 e_i + 1 (e_i = e₀ + i). 上折逐项给 W_i = `Ω⁺ (第 e_i 层的槽位, 在 tw 1 的孩子 d_m 一侧) (c ↦ next⁺ (Up … W_{i-1} c))`.
A₁_{d_m} 的脊底是 M = `nd sL (i ↦ M_i)`, M_i = tw 1 ⊕ ↑W_i, Ω 形状, 下标层是第 e_i 层; M_i 的孩子 zero 是 `nd sL (k ↦ tw 1 ⊕ ↑(W_{i-1}·(k+1)))`, 它的孩子 0 是 M_{i-1} (由 `Upm`, `◃→⊑` 算出相邻路径是 `inc zero (inc 0 self)`).

朝第 0 层折 `Ωt M` 时, 第 i 个部分和项是 `Ωt M_i` 朝第 0 层的折叠, 顶结点 (槽位第 e_i 层) 走链 (目标第 0 层, 正确).
第一个非零链点 = 朝第 e_i 层 (路径 `ink self`) 折 `up zero zero (Ωt M_{i,0})`: 嵌入行 `ink` 进孩子 zero, 路径成为 `posW (tw 1) p_i ∙ lift …`, 其中 p_i 是 W_i 根槽位, 在孩子 d_m 一侧, 所以 `posW (tw 1) p_i` = `inc d_m …`;
孩子 zero 是 ℕ 极限形状, `Ωt` 是部分和极限, 第 0 项 (`inu` 行进孩子 0) 就是: 在 M_{i-1} 上朝第 e_i 层折 `Ωt M_{i-1}`, 路径 `inc d_m … ∙ lift (tw 1) (↑W_{i-1})`.
这正是定理 A 的形状 (W = W_{i-1}, d = d′ = d_m): `kp ≡ nothing`, 走链. 槽位是第 e_{i-1} 层, 目标是第 e_i = e_{i-1}+1 层: 该保留.

递归对应: 这一格是 `lowAll` 在顶结点 `dropGt` 的 `chain` → `slotQ` → `hQ` → 嵌入行 `fb` → ℕ 极限行 → `fb` → 结点, 在规范推导 (`raiseR` 的 `mL` 行把参照第 n+1 项对到树的第 n 个孩子) 下落到 `NodeMis` 的 `drop-eq`.
值: 参照 ψ_{e+1}(K ++ Ω_{μ'}) (μ' 是 M_{i-1} 的读法, 余尾 Ω_{e+1}, 穿透); 树是 ψ_{e+1}(K + Ω_{μ'[ζ]}), ζ < Ω_{e+1} 是链的上确界. 树一侧严格小 (同 §3 的论证).

## 5 命题 E: 亏损被补回

**在 ℕ 极限里 (命题 D 的格).** 那一格是孩子 zero 的部分和极限的第 0 项, 层号 tw 1 ⊕ ↑(W·1), 读法 μ' (W = W_{i-1}). 第 k 项的层号是 tw 1 ⊕ ↑(W·(k+1)), 读法 μ'·(k+1), 根槽位仍是第 e 层, 同样走链.
第 k 项的值 ≥ ψ_{e+1}(K + Ω_{μ'·k + μ'[γ₀]}) ≥ ψ_{e+1}(K + Ω_{μ'·k}), 因为 Ω_{μ'(k+1)}[γ] = Ω_{μ'k + μ'[γ]}.
所以 sup_k (第 k 项) ≥ sup_k ψ_{e+1}(K + Ω_{μ'·k}) = ψ_{e+1}(K + Ω_{μ'·ω}), 即理想值. 逐项看, 树的第 k 项低于参照的第 k+1 项, 但不低于参照的第 k 项.

**在关系里怎么写 (【纸】).** 走链且参照穿透的结点上, 对每个链点读法 γ_k 仍有 `GR.R j (ψ_κ(K ++ fsT t γ_k)) (折叠值)`:
由归纳假设 `hQ γ_k (pt (suc k)) (chain k)` (`chain` 的构造只用 `slotQ`, 与 cmpᵀ 的结果无关), 再 `cumᴿ`. 即这一格上成立的是把 t 换成 t[γ_k] 的较弱陈述.
参照第 k 项 Ω_{μ'·k} ≤ᵀ Ω_{μ'·k ++ μ'[γ₀]} (列表前缀, 项序), 用一次 `mc` 接上. 所以 ℕ 极限层号的推导若把参照第 n 项对到树的第 n 个孩子 (比 `m-next` 的对法晚一项), 这一格不触发不一致.
代价: `mc` 多一个; 改的是 `raiseR` 生成的推导, 不是树.

**在 Ω 结点里.** 设外层是保留的结点, 分支 c″ 内有孩子侧槽位 (第 d′ 层) 的结点, 目标是第 d 层. d′ < d 的分支该保留而走链, 值偏低; d′ ≥ d 的分支走链是对的, 而且这些分支的值随 c″ 增大而超过小分支的理想值. 上确界不变.
但 `mΩ` 规则要求逐分支 (读法 η 对同一个 c), 所以关系里补不回来, 除非外层不用 `mΩ` 而只用第一分支 (`mw` 配 `◃w`).

**结论.** 没有找到终点值掉下去的格. 找到的是: 保持律按 "参照项与树逐项, 逐分支对应" 陈述时为假. 这与 `YiQV` 的 `drop-shape`, 审查 F 路的 `FCross`, 对照表 "C-X 低 (判)" 是同一处, 这里多出的是规范树与精确读法上的值的计算, 以及它被问到.

## 6 命题 F: `seen` 的底

`seen S j oj u β c` = `R.ψ (j ⊕ offsets c) … (rb-no) (B₀) j (lift) β (Ωt (j ⊕ offsets c))`: 起点是当前的 β, 底是默认底 `B₀`.
`Ωt (j ⊕ offsets c)` 里槽位层不低于 j 的结点朝 j 走链, 链点从 `B₀` 的 Ω 树出发, 不带上下文 K′.
取偏移 o+1 (后继形状, λ = |j ⊕ o|): 链是 y_{k+1} = `next⁺` (自身折 y_k, 起点 Ωt λ), 上确界 ε_{Ω_λ+1} = ψ_λ(Ω_{λ+1}); `seen` 的值是 ψ_κ(K′ + ψ_λ(Ω_{λ+1})).
`RebRow` 的参照是 ψ_κ(K′ ++ Ω_{λ'+1}) (λ' 是孩子层号 `floor ⊕ o` 的值), 按规则 6 是 ψ_κ(K′ + γ_∞), γ_{k+1} = ψ_{λ'}(K′ + γ_k).
当 j 的偏移被 o 吸收 (λ' = λ) 且 K′ 含大于 Ω_{λ+1} 的项时, γ₁ = ψ_λ(K′ + Ω_λ) > ψ_λ(Ω_{λ+1}), 树一侧严格小.
当 λ > λ' (j 明显高于地板) 时 ψ_λ(Ω_{λ+1}) ≥ Ω_λ ≥ Ω_{λ'+1}, 树一侧不低 (替身高估).
塔第 1 项与各项的根底上 K′ 被材料吸收或替身是自身折叠 (不走链), 不触发 (§7).
这种格在终点递归里是否被问到: 【判】从塔第 2 项起, 左部非零的嵌入 (如 `Ωt A + Ωt A` 的分支) 在 Ω 形状层号上给孩子算底时会问到; 没有逐项展开.

## 7 核算: 塔第 1、2 项与目标孩子 ω

**塔第 1 项, 根底, 目标孩子 ω (换基行 X-a).** `baseᴮ 1 (h₁ ω) (inc ω self)`: Λ 上 `pre 1` = `up zero 0 1`, ℕ 极限行把材料经 `emb` 放进 tw 1 的孩子 0, 得 `up zero 0 (suc zero)`; tw 1 上路径 `inc ω self`, `route` = `split zero (↑ω) _ self` = `inj₂`.
值 = `seen` ⊞ ψ₀(1), `seen` = 在第 ω 层朝自身折 `Ωt (h₁ ω)`, 起点 `Ωt (h₁ ω)`, 即 Ω_ω·ω^{Ω_ω} = ψ_ω(Ω_ω); 尾项是 ω. 树: ψ_ω(Ω_ω) + ω.

**塔第 1 项, 顶链.** β = `betaᴮ 1` = `next⁺ (Ωt zero)` = ω. z₀ = 0, G(z₀) = `next⁺ β` = ω².

## 8 出口条件

本文没有给出满足 `Exᴴ` 的推导, 因为主定理是否定的. 两点说明.
(1) §5 的补法每用一次要一个 `mc`, 两边是 ψ_κ(K ++ Ω_{μk}) 与 ψ_κ(K ++ Ω_{μk ++ μ[γ₀]}). 它在第 0 层目标上出现时要两边标准形; K ++ Ω_{…} 这种把上下文与材料拼接的列表一般不是降序和 (§7 里 K′ 被吸收的情形), 所以不是标准形. 这与 `YiXCEnd.¬closeNF-all` 是同一件事.
(2) 所以出口条件与保持律不是两个独立的问题: 参照取 ψ_κ(K ++ t) 这种拼接形式, 既造成逐项对应的失败, 也造成 `mc` 两边非标准形.

## 9 若要继续, 陈述该怎么改 (【判】)

- 参照不能固定为 ψ_κ(K ++ t). 走链而参照穿透的结点上, 成立的是 ψ_κ(K ++ t[γ_k]) 对一切 k; 要么让参照项随树的派发定义 (在这种结点上取 ψ_κ(K ++ t[ψ_ν(K ++ t)])), 要么让推导只在会被正确派发的结点上用 `mΩ`.
- 这样参照就是树的派发的函数, 终点要另证一条纯记号侧的命题: 改后的参照序列在 EBO 下共尾. §5 的计算是它的两个实例.
- 上下文要规范化 (吸收被材料盖过的项), 否则出口条件过不去.
- 更直接的做法是改折叠: R77 那一格在两个槽位同在一个没有 Ω 形状的孩子里时可判 (`way`), `YiCMCross.keepS` 已有地板以上的保留. 这要改定义, 属于作者裁决.
