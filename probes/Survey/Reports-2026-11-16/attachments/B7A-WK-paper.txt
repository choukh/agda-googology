0. 结论
-------
* 一切有限 k 的 "W4 的 ψ₀(Ω_k) ≥ src 的 ψ₀(Ω_k)" 没有做到, k = 3 也没有做到. 停在 k = 3 的第 0 阶两分量关系
  (带两个链点的 𝓡⁽³⁾ 0) 之前; 缺口的精确陈述见 §5 与 §6.
* 编译了四块:
  (a) [编译] WKGen.Main.main: B6A 的 ψ₀(Ω₂) 定理对一切 Ok 证明、一切路径、一切底族成立, 前提只有
      "第 1 层链底 ⊒ Ω₁ (W4 的序)" 与 "第 0 层链底、底 ≥ 1". 这是一切 k 的归纳里都要的鲁棒性 (§4.4).
  (b) [编译] WKTower.srcΩ₂-tw: 塔第 1 项 twᶜ 1 ≥ src 的 ψ₀(Ω₂) (B5D 只编译到 ψ₀(Ω₁)). 是第三站
      (twᶜ 1 ≥ ψ₀(Ω_ω)) 的 k = 2 一格; 塔的接线 (层号 ω, 第 1 个近似项, 底族) 已逐字核对 (refl).
  (c) [编译] WKShape: k = 3 时 B6A 的关系不够的机制, 全是 refl (§1).
  (d) [编译] 第 3 层理论的两块零件: WKAmb (目标 0 部分与环境层号、树框架无关), WKSum + WKStep
      (第 1 层的值作被加项, 对目标 1 的输出构造封闭, "前缀无关" 解决累加行; 第 1 层状态的一步更新保持它).

1. k ≥ 3 的新现象 (机制) [编译, WKShape]
-------------------------------------
1.1 保留规则. 第 k 层的位置按分支层号 m (0 ≤ m < k) 分类; 折到目标层 i 时
      kp 给 just (保留)  ⟺  m < i;      kp 给 nothing (走链, 链在第 m 层)  ⟺  m ≥ i.
    [编译] WKShape.kp-table 对 k = 3 的九种 (m, i) 逐一核对; keep₀: 目标 0 上 Keep 只能是 nothing.
    [纸面] 一般 k: 对 kp 的 sS 行归纳 (路径每下一层, 位置的 inj₁ 先到就是 m ≥ i, self 先到就是 m < i).
    这正是 AGENTS 的 FGH 规则形状: 低于目标保留, 同层或高于目标经该层走链.
1.2 Ψ_k 的链. Ψ_k 的链点 z_{n+1} = ex Ω_{k-1} Ω_{k-1} (suc z_n) 在第 k-1 层 ([编译] k = 2 WVTwo, k = 3 WKShape.s₃-shape;
    [纸面] 一般 k: ψ 的 sS inc 行加第 k-1 层的自身行). 折到 0 的值 = 以 "右边接上 Ω_{k-1}" 为 op 的 E 迭代.
1.3 多个链底. 这个 op 在目标 0 上是第 k-1 层 Ω 树的折叠, 它的走链目标是第 k-2 层, 链底是状态在第 k-2 层的分量:
    [编译] WKShape.chain₀ (k = 3): 链点是 ex c₁ c₁ (suc z), c₁ = S lvl1 (inc tt self). 一般地, 第 k 层的计算里
    状态 S 在每个第 m 层 (m < k) 都有一个被读的分量 (分支层 m 的结点在目标 ≤ m 时走链, 链底读 S lvl_m).
1.4 状态在高层增长. 同一个 op 在目标 1 把 c₁ 换成 "Ω₂ 以 c₁ 为底折到第 1 层" = lim cum (ex c₁ c₁ (suc z_n)):
    [编译] WKShape.step₁. 所以 E 的每次迭代都让第 1 层的链底变大; 第 0 层的结果经 1.3 依赖它.
1.5 保留行. 第 1 层子树 (第 2 层结点的孩子框架) 的 Ω₁ 结点在目标 1 保留, 输出仍是 Ω₁ 结点:
    [编译] WKShape.keep₁, E-keep. 在目标 0 同一结点走链 (B6A).
结论 [纸面]: B6A 的 𝓡 只约束 S zero ch. k = 3 时它仍是合法的下界关系, 但它的前提不约束 c₁, 用它能证的界与把
c₁ 换成任一 ⊒ Ω₁ 的常值时相同 (WKGen 恰好是这种鲁棒性). Level 的 ψ⁰(Ω₂·2) 的链 x_{n+1} = ψ₁(Ω₂ + x_n) 在第 1 层增长,
常值链底的影子在上方控制不住它. [判断] 只带第 0 层链底的关系证不到 ψ₀(Ω₂·2), 更到不了 ψ₀(Ω₃).

2. 值域与关系的形状 (一般 k, 目标 i < k) [纸面]
----------------------------------------------
2.1 值域. V_0 = T₀. V_m (1 ≤ m) 是 "第 m 层的值" 的影子. 对 k = 3 只需 V₁:
      V₁ = Sh 0 × ES⁺,   (d, e): d 是作被加项在目标 0 被消费的影子 (B6A 的 Ld 的 d 形状),
                               e 是作指数的影子; ES⁺ 是 ES 推广到两分量运算影子 (§3.6, C4).
    W4 一侧的实现  y ⊩₁ (d, e) := SumR y d × Real⁺ y e   (y : Tr lvl1);  y ⊩₀ a := a ≼ read y.
    Level 一侧的控制 Y ⊑₁ (d, e) := Ld Y d × Lx Y e       (Y : Level 第 1 层树; B6A 的 Ld, Lx).
    一般 m: V_m 是第 m 层树作 "被加项 + 指数" 的影子, 指数影子作用在含目标 0..K-1 的运算影子上 (任意 K > m).
2.2 运算影子. 第 k 层环境里的 op F 的影子 f = (f_i)_{i<k},
      f_i : V_i (目标 i 的底) → V_i × V_{i+1} × … × V_{k-1} (目标 ≥ i 的链底) → V_i.
    依赖范围由 1.1 决定: 目标 i 的结果只读分支层 m ≥ i 的结点的链, 链底在 S lvl_m.
    (B6A: k = 1+1, 只有 f_0 : T₀ → T₀ → T₀.)
2.3 关系 (第 0 阶). 链点一层一个: ch_m : ⟦ X ⟧ lvl_m, ch_m = mk (hereT fr π_m), π_m 是第 m 层在树层号里的路径
    (第 k 层里分支层 m 的位置的 posW 都给同一条路径 inc tt (… self)).
      𝓡 0 ch⃗ F f := ∀ S i t v a c⃗.  v ⊩_i a → (∀ m ≥ i. S lvl_m ch_m ⊩_m c_m) → (∀ m ≥ i. S lvl_m ch_m ⊩_m Ω̂_m)
                                  → run F S lvl_i t v ⊩_i f_i (a; c_i, …, c_{k-1}).
    第三个前提推广 B6A 的 "1 ≼ rd S ch" (Ω̂_0 = 1): Level 的链从 Ω_m 起, W4 的链从 0 起, 第一步要状态的第 m 层分量
    不低于 Ω_m 的值. W4 里它由 "状态 ⊒ B₀ = Ωt" 加膨胀保持 (C7).
2.4 关系 (高阶). 𝓡 (n+1) 同 B6A, Good m := ∀ m′. π m (σ m ch_{m′}) ≡ ch_{m′} (对每个链点). W4 定义里出现的延伸
    (idM, chM / chMT, liftM, ⊙) 对每个链点都 Good, 论证逐个链点同 B6A.

3. 每一行的不等式 [纸面, 除标注外]
-------------------------------
左边 W4, 右边影子, 都在 𝓡 的意义下; 目标 i, 结点的分支层 m.
3.1 limC, enter, upC (只取 R 部分): 同 B6A, 逐分量. upC 第 0 阶用 A 的膨胀, 高阶用 Good (对每个链点).
3.2 保留行 (m < i):
      前提  ∀ y z. z ⊩_m y → 𝓡 n ch⃗ (G z) (h y)
      结论  𝓡 n ch⃗ (nodeC n p jd ch_m G) (node⃗ h),  (node⃗ h)_i (a; c⃗) := node_{i,m} (λ y → h_i y (a; c⃗)).
    node_{i,m} : (V_m → V_i) → V_i 是 V_i 的结点运算; W4 一侧要的封闭:
      (∀ y z. z ⊩_m y → G z ⊩_i w y)  ⟹  Ω⁺ q (G ∘ cv) ⊩_i node_{i,m} w.
    [编译, i = 1, m = 0, 被加项一半] WKSum.SumR-Ω: 保留下来的 Ω₁ 结点在目标 0 被消费时就是 nodeS 0.
    sS 层号上 cv 是恒等 ([编译] WKShape.keep₁); 塔层号 (sΩ, sL) 上 cv 经 mapK / pshBr (C2).
3.3 走链行 (m ≥ i):
      同一前提 ⟹  分量 i:  lim_n h_i (x_n) (a; c⃗),   x_0 = Ω̂_m,  x_{n+1} = h_m (x_n) (c_m; c_m, …)
    (链用分支影子的第 m 分量, 底取链底 c_m). W4 一侧: z_{n+1} = fromBr (run (G z_n) S lvl_m ch_m (S lvl_m ch_m)),
    由前提的第 m 分量得 z_{n+1} ⊩_m x_{n+1}; 输出 limc⁺ (G z_n) 在分量 i 不低于逐项.
    - i = 0: 输出读回成 T₀, 累加不低于末项 (cumL). 这就是 B6A.
    - i ≥ 1: W4 输出是累加的极限 lim (cum …), Level 的链输出是逐项的极限. 下界要 "a + b 实现 b 的影子".
      [编译, i = 1, 被加项一半] WKSum.prefix: 结构关系 Sm b d ⟹ SumR (a + b) d (a 任意); WKSum.cumR:
      lim (cum F) 不低于 lim_n d n. 只用 W4 的膨胀 (baseInfl) 与具体的 Mv 单调, 不要影子单调.
      指数一半 (Re b e ⟹ Real (a + b) e) [纸面]: 逐构造子同 Gen.real, 只有 zero 行改用 Emono / Itmono 的 zero ◃ a.
3.4 第 0 层孩子 (E/It 的 up 行进第 0 层): 同 B6A 的 L0E / L0I, 逐分量 (第 0 层树没有结点).
3.5 第 1 层孩子在目标 0: [编译] WKAmb.Amb.Lem.real 对任意环境层号与树框架成立 (链点 mk (hereT fr (inc tt self))).
    实例: 第 2 层结点的孩子框架, 链点的外层分量是第 0 层在第 2 层里的写法 ([编译] WKAmb.child-chp).
3.6 第 1 层孩子在目标 1 (k = 3 的新行): E 的 Ω₁ 行保留 (1.5), 所以第 1 层指数的影子在目标 1 分量上必须是
    "保留结点" node_{1,0}, 在目标 0 分量上是 B6A 的 nodeS. 即 ES 要推广成对运算影子的每个分量分别解释的形式
    (结构同 W4 的 Eh 作用在带序的结果代数上: 结点运算由代数给出). 未做.
3.7 Ω_{k-1} 作指数 (B6A 的 W1) 与 ex Ω_{k-1} Ω_{k-1} (suc x) (W2): 影子 Ω̂_{k-1} = 在分量 i ≤ k-2 走链 (第 k-2 层的链),
    在分量 k-1 … 不出现 (目标 < k). sh_{k-1} e 同 B6A 的 sh, Kb / Kₑ 换成 Ω̂_{k-1}. W2 的证明只用 Itmono / Emono 与 W1,
    逐分量照搬 [纸面]; WKGen.W2c 是 k = 2 时 "链底 ⊒ Ω₁ 而不等于 Ω₁" 的版本 [编译].

4. 对 k 的归纳结构 [纸面]
------------------------
4.1 归纳的对象. 一个 "值塔" Tow(k): V_0 … V_{k-1}, 各自的 ⊩_m (W4) 与 ⊑_m (Level), 结点运算 node_{i,m} (m < i < k),
    链步 (3.3), 极限, 关系层面的和 (B6A 的 Ld-sum 形状, 不在 ψ 上证结合律), 以及第 m 层指数影子 ES_m 对含任意多分量
    的运算影子的解释. 第 k 步: 由 Tow(k) 造 V_k、⊩_k、⊑_k、ES_k, 证 Tow(k+1) 的律.
4.2 第 k 步用到的律 (只用这些, 不按阶也不按 k 定制):
    W4 一侧: inf / Einf / Itinf, Emono / Itmono, mono (折叠沿 ◃ 单调), Rn 的传递, 1.1 的保留规则, Good.
    影子一侧: 无条件的逐点膨胀 (B6A InflE); 极限与结点的上界.
    Level 一侧: Ld / Lx 的构造子与它们的语义引理推广到 "ψ_i (A + D) ⊑_i f_i (…)" (i < k), Level 的 <ᴵ-dec 在有限层号上
    与 1.1 同形 (injᵃ ⟺ m < i 保留; injᵇ / injᶜ ⟺ m ≥ i 走链, 链在第 m 层, 从 Ω_m 起, 每步 ψ_m).
4.3 移位引理 (一切 k 的关键, 推广 B6A 的 shiftH): Lx_{k-1} T e ⟹ Lx_{k-1} (ψ_{k-1} T) (sh_{k-1} e), 以及第 0 阶移位
    ψ_i (A + ψ_{k-1} T) 由 e.E 作用在 Ω̂_{k-1} 的被加项影子上控制 (i < k-1). Level 的 ψ_{k-1} 对下标 < k-1 的 limᵢ 穿透
    (injᵃ, 带 tr⁻), 对下标 = k-1 不出现 (第 k-1 层的树没有第 k-1 层下标).
4.4 底族的鲁棒性. 第 k 层的定理要对 "状态 ⊒ B₀ (逐层, W4 序)" 的一切底族成立, 因为:
    (i) E 的迭代改变状态 (1.4); (ii) 更高层号 (塔) 里, 第 k 层的 Ω 树出现在累加的第 k 项, 底族来自前面各项的折叠.
    [编译] k = 2: WKGen.Main (前提 Ω₁ ⊴ B lvl1 (inc tt self)); 塔里的实际底族: WKTower.cω-shape (= ex Ω₁ Ω₁ Ω₁).

5. 挑战: 哪一步可能不成立, 最小反例候选
--------------------------------------
C1 (只用第 0 层链底). 见 §1 结论. 反例候选 [判断]: Level 的 ψ⁰(Ω₂·2) 的第 1 层链 x_1 = ψ₁(Ω₂ + Ω₁) 已高于任何
   常值链底的影子在第 1 层能给的值; 用 B6A 的 𝓡 不可能控制它. 没有编译 (要先有 Level 第 2 层的一条上界才能写成定理).
C2 (保留行的搬运). sS 层号上 cv 是恒等 ([编译] keep₁). 塔层号上 kp 经 mapK (pshBr), 分支要搬回; 需要一条引理
   "pshBr 保持 ⊩". [判断] 例行, 未做. 第三站必经.
C3 (走链行在目标 ≥ 1 输出累加). 若只用结构的和 (Ld-sum 形状, 影子是复合 d_B ∘ d_A), 要从和的影子降到末项的影子
   就要影子单调: d_B (d_A (a, c), d_A (c, c)) ≥ d_B (a, c). 反例候选: d_B 对底不单调时这条在影子上不成立
   (我们的具体影子 Mv, Nx 单调, 但 B6A 刻意没有建立一般组合子的单调性理论).
   修法: 在 W4 一侧用膨胀吸收前缀 ([编译] WKSum.prefix, cumR, 被加项一半). 指数一半纸面同理, 未编译.
C4 (指数影子在目标 1 要保留) [判断, 机制未编译]. B6A 的 ES 只有目标 0 分量, Ω₁ 结点的影子 nC 是走链. 若在目标 1 也用走链影子:
   W4 一侧仍是下界, 但 Level 一侧 ψ₁ 对第 0 层下标穿透 (injᵃ, 输出 limᵢ), Ld / Lx 的 Li / Ei 行要求影子在该处是结点
   形状; 走链影子在当时的链底处就折叠, 之后链底变大 (1.4) 时它不再变, 控制不住 Level 的保留结点在之后被折叠的值.
   反例候选 [判断]: x = Ω₁ 作第 1 层指数, 在目标 1 迭代后再作第 2 层结点的分支下标. 修法: ES 推广 (3.6).
C5 (Level 侧多层). ψ_i (A + D) (i ≥ 1) 的链 (injᶜ) 在第 i 层产生 Level 第 i 层的树, 它们要由 ⊑_i 控制; 每次穿透有 tr⁻
   (B6A C5), 每层都要 "分支条件写成关系式 (∀ y ≼ y′)". 加法只在关系层面做 (B6A C3), 每层一次.
C6 (一切阶 × 多链点). upC 高阶行的子语境链点经 Good 相等, 现在要对每个链点; Good 的定义改成对一切链点的合取.
   [判断] 无新机制.
C7 (链起点). Level 的链从 Ω_m 起; W4 从 0 起, 第一步 z_1 = G(0) 在目标 m, 底 S lvl_m ch_m. 要 S lvl_m ch_m ⊩_m Ω̂_m,
   即 "状态的第 m 层分量 ⊒ Ωt lvl_m". W4 的 B₀ = Ωt 满足, E 的迭代经膨胀保持. 若某处底族给第 m 层 0 (WKGen 的前提
   排除了它), 第一步断. k = 2 的形式是 WKGen 的 hc 与 h0.
C8 (塔项的接线, 第三站). [编译] k = 2: Ftw 1 的第 1 个近似项里第 2 层 Ω 树的路径、底族、Ok 证明都由定义算出
   (zt1-shape, Lω-shape, gL1, cω-shape, 全是 refl). 一般 k: emb 的路径来自 Ok 证明的 sL 分量
   (from0 g r k = r 0 ∙ … ∙ r (k-1)), [判断] 定义上仍化成 inc tt (… self), 未核.

6. 下一个必经缺口与剩余距离
--------------------------
6.1 下一个必经缺口 (位置精确): k = 3 的第 0 阶关系 𝓡⁽³⁾ 0, 即带两个链点 (ch_0, ch_1) 与两分量影子 (f_0, f_1) 的
    关系, 以及它的走链行在目标 1 的指数一半 (3.3 末尾) 与 ES 的两分量推广 (3.6). 不先有它, Ψ₃ 计算里第一次 E 迭代
    (WKShape.step₁ 把 c₁ 换成新树) 之后的第 0 层值就没有下界. WKStep.step-sum 只给了这一步的被加项一半
    (c₁ 的结构关系 ⟹ 新 c₁ 的结构关系所控制的被加项值), 指数一半与 Level 一侧都没有.
6.2 嵌套位置. 第一站 (ψ₀(Ω_k), 一切 k) 里: k = 3 → 第 1 小格 (第 0 阶, 两分量) 未做; 之后是一切阶 n 的两分量关系,
    W1 / W2 的第 2 层版本, Level 第 2 层 (Ld / Lx 带第 1 层分量, ψ₁ 的链, ψ₂ 的移位), 组装.
    第二站 (twᶜ 1 ≥ ψ₀(Ω_ω)) 要第一站对一切 k 一致, 再加 4.4 的鲁棒性与 C2、C8.
6.3 剩余距离 [判断, 行数是估计]: k = 3 约 1500 行 (多分量 𝓡 与逐行 500, ES 推广 150, 目标 1 的值域指数一半与保留行
    150, Level 第 2 层 600, 组装 150). 对 k 一致: 写成 4.1 的接口加一步, 约 2500 行以上. 之后第二站约 150 行接线.
    强度: 现在编译到的是 ψ₀(Ω₂) (Ψ₂ 与 twᶜ 1); 目标链 ψ₀(Ω₃) → ψ₀(Ω_ω) (BO) → ψ₀(Ω_Ω) (BTBO) → EBO.
