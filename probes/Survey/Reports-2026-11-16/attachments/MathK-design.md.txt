# 数学先行第二次 (b): 带证据的保留行的纸面设计 (K 路, 2026-11-17)

三档标记: 【编】仓库里已编译 (写名字), 或本目录 `MathKShape.agda` 已编译 (6G, 退出 0); 【纸】本文纸面推算或论证; 【判】判断或假设.
本文是候选设计, 只在纸上. 不改仓库, 不替作者选路线.

## 0 结论

1. **设计完成, 不落进先验检查的禁区** (【纸】; 其中 "为什么非改块不可" 一段是【判】). 设计叫 "框架保留": 槽位层与目标层各带一条到**同一个字面层号 m (框架)** 的路径, 保留判定在 m 里用现有的 `kp⁼` 做, 参数里没有任何孩子下标, 不判定树的相等, 不判定层号的大小.
2. **代价不小.** 框架证据要由 "没有摊平的嵌入" 产生. 现在的自身行用 `Up` 把孩子层的树摊平进本层, 出处在这一步丢掉. 所以设计含三件: (K1) 块里加一个构造子 `pw` (挂起的上折, 读作 a + x·ω^y), (K2) 层号的框架证据 `Fr`, (K3) 折叠多带一个可缺的框架目标 τ, 保留判定加一行. 前三层估计新增或改动 400 到 600 行 (【判】), 换基折叠之上的验收全部要重做.
3. **A 路定理 B 字面的那一格 (目标由外面给一条裸路径) 任何设计都保留不了** (【纸】, §3.1): 裸数据里槽位层与目标层之间唯一的联系是两个孩子下标. 能保留的是 "目标带着框架进来" 的同一格 (【编】`MathKShape.cellA`), 以及 A 路命题 D 那种由链步回灌产生目标的格 (【纸】§6.2 逐步推算; 框架里的判定一步【编】`cellD`). 验收陈述的量化域要相应收成带框架的目标.
4. **没有回答的**: 这一格保留以后值是否与参照相等 (没有值的定理); 终点值掉不掉 (那是 (a) 路的事). 若 (a) 证出终点不掉值, 本设计只对 "逐项对应的验收陈述" 有用, 是否值这个代价由作者定.

## 1 那一格的精确定位 (由定义推出)

记号: `YiRWBlock` 的 `L`, `Tr`, `Pos`, `at`, `↑`, `⊕`, `tw`; `YiRWPath` 的 `Pth`, `posW`, `psh`, `Ok`, `OkO↑`; `YiRWFold` 的 `kp`, `Keep`; `YiRWOps` 的 `Up`, `mv`. h₁ d = `zero ⊕ ↑ zero d` 是 tw 1 的孩子 d 的层号.

**事实 1 (【编】`MathAShape.cross₁`, `spine`, `top`; `YiCMExit.kp-exit`).** 那一格的 `nothing` 出在地板 tw 1 = `nd (sΩ zero) h₁` 这片叶子上: 槽位被推成 `inj₂ (d , s)`, 目标路径是 `inc d′ v`, 落在子句 `kp (nd (sΩ k) h) _ (inj₂ _) (inc _ _) = nothing` (R77).

**事实 2 (【纸】, 逐行读 `OkO↑`, `OkS⊕`, `kp` 的 R79/R80).** 在命题 D 的格里, 槽位与目标都不是树直接给的 tw 1 的位置, 而是两个 **Ω 形状偏移结点的下标层**:
- 层号 M_i = tw 1 ⊕ ↑(tw 1) W_i 是 `nd (sΩ e_i) …`, 下标层 e_i = `at (tw 1) p_i`, p_i = `inj₂ (d , t_i)` 是 W_i 根结点的槽位. M_{i-1} 在 M_i 的孩子 zero 的孩子 0 里.
- 目标 e_i 由 `Ωt M_i` 顶结点的链步回灌产生 (路径 `ink self`), 进孩子时路径变成 `kh_i c` = `posW (tw 1) p_i ∙ lift` = `inc d (posW⁼ (h₁ d) t_i) ∙ lift`.
- 槽位是 `Ωt M_{i-1}` 的下标侧顶槽位, 被 R79/R80 沿 `kh_{i-1}` = `inc d (posW⁼ (h₁ d) t_{i-1}) ∙ lift` 推进孩子.
- 两条路径都由 `OkO↑ … (Ω p g) = (posW k p ∙ v , …)` 从位置 p_i, p_{i-1} 各自算出. 两个位置里的 d 是同一棵树的两份拷贝.

**事实 3 (【纸】).** p_i, p_{i-1} 都是同一次上折 `Up (h₁ d) (down stop d) b y` 的输出里的位置: y : `Tr (h₁ d)` 的结点槽位 p′_i, p′_{i-1} 本来是 `Pos (h₁ d)` 的元素, 不含 d; `mv (down stop d)` 逐个把 d 写进去. 在 h₁ d 内部, 两个槽位层的字面关系由 `kp` 现有的行就能判 (后继形状进唯一孩子, ℕ 极限形状用 `way`).

所以要的证据是: "e_{i-1} 与 e_i 都在同一个字面的 h₁ d 里". 它在 y 里是现成的, 在 `Up` 摊平时丢掉.

## 3 为什么证据必须由块携带

### 3.1 裸数据上的保留行必然是对角见证 (【纸】)

R77 那一行的输入是 (k, h, 证据, c, t, c′, j, v : j ≤ h c′). 要交出 `Keep j (Br⁼ (h c) t) …`, 需要 q : `Pos j` 与换型 `Br j q → Br⁼ (h c) t`, 即 j 与 (h c, t) 之间的字面关系. 输入里 j 只经 v 与 h c′ 有关系, 与 h c 的关系只能来自 c 与 c′ 的关系, 或来自对两个裸层号的搜索.
- 来自 c 与 c′: 那是对角上的证据函数. D 型的格里 d 含 ℕ 极限 (A 路【判 3】), 在这样的 c⋆ 处有条目就弱判等 (`ColW.wdecα` 的同形论证; 对 `Maybe (c ≡ c′)` 是 `diag→dec`).
- 来自搜索裸层号: `Pth` 只有 "j 字面是 ℓ 的子层号" 一种 (没有同余构造子), 末端要 `self`, 即两个层号字面相等. 含 ℕ 极限形状的层号上这不可判 (`YiDGDiag.pathA`, `pathB`).

所以定理 B 字面的那一格 (目标由外面给裸路径) 没有不落进禁区的保留行. 只能改数据.

### 3.2 三种较便宜的写法都不行 (【纸】前两条, 【判】第三条)

| 写法 | 为什么不行 |
|---|---|
| 每个结点各存一份 "到框架的路径" (`Σ m. k ≤ m`) | 两个结点各自的 m 是否相同又要判层号相等. 共享只能靠类型参数或同一个绑定子 |
| 读回时从摊平的树算框架 (像 `OkO↑`, 或 `YiKFKeep.Pv↑` 的来源表) | 读到的是位置 `inj₂ (d , t)`, `inj₂ (d″ , t″)`, 要知道 d ≡ d″. `YiKFKeep.rel-Ω-no` 已是这个结论 (Ω 形状孩子里的槽位之间恒缺) |
| 只在折叠的状态里带证据, 块不动 | 链步的值两次穿过裸类型 `Tr k`: 一次作树的分支函数 g 的自变量, 一次作层号孩子函数 h 的自变量 (`up zero c (Ωt (h c))`). 嵌入行看到的 c 是裸的, 要认出 "c 就是刚才那个链点" 又是判等. 所以出处要在 `Tr k` 的元素自身的结构里 |

另一种局部补丁 (记下, 不够): 两个层号都不含函数 (有限后继塔) 时直接结构比较. 它不撞 `ColW.wdecα` (极限孩子处无条目), 但只覆盖 e₀ 是数字层的最早几格; 链点一旦含 ℕ 极限就失效 (【判】). 不满足 "阶段无关".

### 3.3 出处在哪里是现成的

加法嵌入 `up x c y` 没有摊平: y : `Tr (h c)` 保留自己的相对位置, `↑ (nd s h) (up x c y) = ↑ x ⊕ ↑ (h c) y`, y 的结点读成的偏移结点, 下标层全是 h c 的子层号 (`posW (h c) p′`). 丢出处的只有自身行的 `Up` (乘幂嵌入 b·ω^y 被摊平). 所以: 让乘幂嵌入也不摊平.

## 4 设计

### 4.1 (K1) 块: 挂起的上折 `pw`

`T S` 加一个构造子, 序加两个:

```
pw : (a x : T S) → Lt S zero x → (c : C S) (y : D S c) → R S c (z₀ S c) y → T S     -- 读作 a + x·ω^y
◃p : Lt S a (pw a x nx c y e)
◃q : R S c y′ y → Lt S (pw a x nx c y′ e′) (pw a x nx c y e)
```

- 与 `up` 平行: `up x c y` 是 x + y, `pw a x c y` 是 a + x·ω^y; 两者的 y 都是孩子层自己的树, 不动.
- 加法: `x′ + pw a x c y = pw (x′ + a) x c y`, 单调照 `◃u`, `◃c` 的写法.
- 自身行改成不摊平: `ψ (nd s h) … self β (up x c y e) = pw zero (ψ … self β x) c y e` (带非零证明). `Up`, `mv`, `Upm` 从折叠里退出 (可留作 `pw` 的摊平视图).
- View (纲领第 1 条): `pw a x c y` 按 y 的构造子看. y 是后继 y′+1 时是 ℕ 极限, 第 n 项 s_n = `pw s_{n-1} x c y′` (s_{-1} = a); y 是 ℕ 极限或结点时逐项或逐分支; y 是嵌入时是嵌套的 `pw`. 每一项仍是同一类型的对象. 值上一致要证 (§8 风险 2).
- 第 0 层没有孩子 (`CH zero = ⊥`), 所以 `Tr zero` 里没有 `pw`, 最终输出的布劳威尔树不变形.

读回 (层号一侧不改 `L`):

```
↑ k (pw a x c y) = ↑ k a ⊕ Rd (↑ k x) (h c) y
Rd xl m zero       = xl
Rd xl m (suc y)    = nd sL λ n → rep (n+1) (λ b → Rd b m y) xl      -- (xl·ω^y)·(n+1), 用高阶迭代, 对 y 结构递归
Rd xl m (lim f _)  = nd sL λ n → Rd xl m (f n)
Rd xl m (Ω p′ g′)  = nd (sΩ (at m p′)) λ z → Rd xl m (g′ (fromBr m p′ z))
Rd xl (nd s h) (up y c′ y′) = Rd (Rd xl (nd s h) y) (h c′) y′
Rd xl m (pw …)     = 同法, 对指数里的 y 结构递归 (§8 风险 3)
```

在 D 的格上 `Rd` 读出的层号与现在 `↑ (Up …)` 读出的同形 (下标层逐字是 e_i; 【纸】§6.2).

### 4.2 (K2) 层号的框架证据 `Fr`

与 `Ok`, `Rb` 并列的第三份证据, 对层号结构递归, 以当前框架 φ : `Maybe L` 为**类型参数** (共享靠这个参数, 不靠各结点自存):

```
Ix : Maybe L → L → Set
Ix nothing  k = ⊤
Ix (just m) k = Maybe (k ≤ m)                 -- 本结点的下标层在框架里的位置, 可缺

Fr  : Maybe L → L → Set
Fr⁺ : Maybe L → L → Set
Fr φ zero          = ⊤
Fr φ (nd sS h)     = (c : ⊤) → Fr⁺ φ (h c)
Fr φ (nd sL h)     = (n : ℕ) → Fr⁺ φ (h n)
Fr φ (nd (sΩ k) h) = Ix φ k × ((c : Tr k) → Fr⁺ φ (h c))
Fr⁺ φ a = Fr φ a ⊎ (Σ L λ m → Ok m × Fr (just m) a)      -- 沿用当前框架, 或在这条边上换一个框架
```

- 缺省 `fr-no` (处处无框架) 对一切层号是闭项; 塔与 Λ 的规范证据由读回给出.
- 产生: 读回函数 `Fr↑` 对树结构递归, 与 `OkO↑` 同形. 遇到 `up x c y` 或 `pw a x c y`, 对 y 读出的那段偏移换框架 m₀ = h c, 段内每个由 y 的结点 `Ω p′ g′` 读成的偏移结点得到 `just (posW m′ p′ ∙ ⟦D⟧)`, 其中 m′ 是 y 当前所在的子层号, D : `Dn m₀ m′` 是框架内的下行链 (`up` 嵌套时加深), ⟦D⟧ : m′ ≤ m₀ 由 `inc` 接成. 底 x, a 读出的部分不属于这个框架 (`nothing`, 或它们自己的 `pw`/`up` 另起框架).
- 没有 `Maybe` 是算出来的比较: 每个 `just` 都是位置自己的路径, 无条件存在.
- 与换基证据的关系: `Schema` 的地板 a 是 "目标在地板之上" 用的公共界 (`keepS`); 框架 m 是 "目标在地板之下, 两边同在地板的一个孩子里" 用的公共界. 可以并成一份证据 (§6.4).

### 4.3 (K3) 折叠: 框架目标 τ 与保留判定的一行

折叠签名多三个参数 (φ 是隐式的类型下标):

```
Tg : Maybe L → L → Set
Tg nothing  j = ⊤
Tg (just m) j = Maybe (j ≤ m)                 -- 目标在当前框架里的位置, 可缺

ψ : (ℓ : L) → Ok ℓ → Rb ℓ → {φ} → Fr φ ℓ → Base ℓ → (j : L) → j ≤ ℓ → Tg φ j → Tr⁺ j → Tr ℓ → Tr⁺ j
```

三条规则:

1. **造 τ (链步回灌).** 结点行回灌时目标是 `at ℓ p`, 路径 `posW ℓ p`. 同时由当前层号的框架证据算 `tg ℓ fr p : Tg φ (at ℓ p)`: p 是 Ω 形状结点的下标侧顶槽位且 `Ix` 给 `just u` 时取 `just u`; 下标侧更深的槽位 t 取 `just (posW⁼ k t ∙ u)`; 孩子侧的槽位进孩子递归 (孩子换了框架或末端是层号自身则 `nothing`). 对 p 结构递归.
2. **传 τ.** 折叠进孩子 (嵌入行 R91–R95, `kp` 的各递归行) 时, 孩子的证据是 `Fr⁺ φ (h c)`: 沿用框架则 τ 原样传下去; 换框架则 τ 置 `nothing`. τ 自身不随路径改写 (它是到 m 的路径, 与当前层号无关).
3. **用 τ (新的一行).** 保留判定 `kp′` 与 `kp` 逐行相同, 多带 (fr, τ). 在 "Ω 形状结点, 下标侧槽位 `inj₁ t`" 的三行 (R78, R79, R80) 上:

```
kp′ (nd (sΩ k) h) o (ix , _) (inj₁ t) w τ = alt (原来那一行的结果) (frame ix τ t)
frame {φ = just m} (just u′) (just u) t = kpF m om u′ t u      -- om : Ok m 存在框架里
frame _ _ _ = nothing
kpF m om u′ t u = mapK (pshBr u′ t) (pshFirst u′ t) (kp⁼ m om (psh u′ t) u)
```

`alt` 先取原判定, 原判定走链才看框架, 所以原来保留的格结果逐字不变. `kpF` 调的是已定义好的旧 `kp⁼`, 不是 `kp′` 自己.

可选的合并 (不是这一格必需): `Tg (just m) j = Maybe ((j ≤ m) ⊎ (m ≤ j))`, 第二支 (目标在框架之上) 用 `keepOf` 沿 u′ ∙ v 保留. m 取换基地板时就是 `YiCMCross.keepS`.

### 4.4 `pw` 作输入时的折叠行

`pw a x c y` 可以出现在被折叠的树里 (后继形状层号的 Ω 树把分支 c 嵌成 `suc c`), 所以要有行. 与摊平后的折叠同义, 对 y 结构递归, 不 "进孩子":

```
ψ ℓ … j w τ β (pw a x nx c y e) = Φ ℓ … (左上下文的底 Bₐ) (ψ ℓ … j w τ β a) x c y
Φ B′ β′ x c zero       = ψ ℓ … B′ j w τ β′ x
Φ B′ β′ x c (suc y)    = lim⁺ (n ↦ 第 n+1 次迭代 (B, b) ↦ (各目标上的 Φ B (B i u) x c y , Φ B b x c y))
Φ B′ β′ x c (lim f _)  = lim⁺ (n ↦ Φ B′ β′ x c (f n))
Φ B′ β′ x c (Ω p′ g′)  = node⁺ (kp′ ℓ … (inj₂ (c , inj₂ p′)) w τ) (z ↦ Φ B′ β′ x c (g′ z)) (回灌: 朝槽位层的 Φ)
Φ B′ β′ x c (up y c′ y′) = 加深一层链的 Φ
```

其中 Bₐ i u = `ψ ℓ … i u (B i u) a` (左加数朝各目标的折叠, 与现有嵌入行给孩子的底同一写法).

## 6 核对

### 6.1 定理 B 的那一格

- 裸目标 (路径 `inc 2 self ∙ lift`, 无框架): 新判定与旧判定相同, `nothing`. 由 §3.1, 这不可避免.
- 带框架的同一格: 新块里 W = `pw zero b 2 (Ωt (h₁ 2))`, N = tw 1 ⊕ `Rd (↑b) (h₁ 2) (Ωt (h₁ 2))` 仍是 `nd (sΩ lvl1) …`, 框架 m₀ = h₁ 2, 结点证据 `just (inc tt self)` (lvl1 ≤ lvl2). 目标第 2 层就是框架自身, τ = `just self`. 新行给 `kpF (h₁ 2) _ (inc tt self) (inj₁ tt) self`, 是 `just` (【编】`MathKShape.cellA`): 保留在第 2 层的槽位 `inj₂ (tt , inj₁ tt)` 上, 分支类型是第 1 层的树. 这正是 A 路说 "该保留" 时的那个槽位.

### 6.2 命题 D 的格 (【纸】, 新块上逐步推算; 沿用 A 路【判 3】关于 d_m 的脊的假设)

1. 链点 Z = 朝 tw 1 自身折 `Ωt (tw 1)` = `Ω idx (d ↦ pw zero β d (Ωt (h₁ d)))`. (自身行不摊平.)
2. A₁ = tw 1 ⊕ ↑Z 的孩子 d 是 tw 1 ⊕ `Rd (↑β) (h₁ d) (Ωt (h₁ d))`. 设 h₁ d 的脊底是 `nd sL g`, g i 是后继层 e_i + 1. `Ωt (nd sL g)` 是 `up y_{i-1} i (Ωt (g i))` 的部分和极限, `Rd` 逐项给 L_i = `nd (sΩ e_i) (c ↦ nd sL (n ↦ (L_{i-1}·ω^c)·(n+1)))`. L_i 的孩子 zero 的孩子 0 是 L_{i-1}. 与 A 路 §4 的 M_i 同形.
3. 框架: 整个孩子 d 的偏移在同一个 `pw` 结点之下, 框架 m₀ = h₁ d. L_i 的证据是 `just (inc i (inc tt self))` : e_i ≤ m₀; L_{i-1} 的是 `just (inc (i-1) (inc tt self))`. 两者的 m₀ 是同一个类型参数.
4. 朝第 0 层折 `Ωt M_i`: 顶结点走链 (槽位层 e_i 高于目标 0, 正确). 回灌目标 e_i, 规则 1 给 τ = `just (inc i (inc tt self))`.
5. 进孩子 zero (嵌入行 `ink`), 再进孩子 0 (ℕ 极限形状, `inu`): 都沿用框架, τ 原样.
6. 在 M_{i-1} 上遇到 `Ωt M_{i-1}` 的顶结点, 下标侧槽位, 证据 `just (inc (i-1) (inc tt self))`. 原判定照旧走到 tw 1 的 R77, `nothing`. 新行: `kpF m₀ _ (inc (i-1) (inc tt self)) (inj₁ tt) (inc i (inc tt self))`. 在 `nd sL g` 上是 `kp` 的 ℕ 极限行: `way g r (i-1) i` 给 g (i-1) ≤ g i, 槽位推进孩子 i, 再经后继行到 `self`: **保留**, 槽位是 e_i 里层号为 e_{i-1} 的那个.
7. 这一步的形状在 g n = 第 2n 层, 槽位第 1 层在孩子 1, 目标第 3 层在孩子 2 的实例上已编译: 【编】`MathKShape.cellD` (`just`); 槽位高于目标 `cellD-high` (`nothing`); 同层 `cellD-diag` (`nothing`, 对角走链); 同样两条路径接上 `inc ωᵉ` 经 tw 1 进来, 现行 `kp` 给 `nothing` (`cellD-cur`).

第 1 到 5 步是纸面 (新块没有写成 Agda). 第 6 步里 "g (i-1) ≤ g i 的路径形如 `inc tt self`" 取决于 `Ok` 给的相邻路径, 实例上成立, 一般情形是【判】.

### 6.3 是否阶段无关

- 定义不按塔的项数, 不按站: `pw`, `Rd`, `Fr`, `tg`, 新行对一切层号与一切树定义.
- 机制对任何 Ω 形状的地板一样: 塔第 n+1 项的地板 tw n 上, 自身行输出 `pw … c y`, 框架是 tw n 的孩子 c 的层号.
- **不覆盖的同类格** (如实列出):
  - 两个结点出自不同的嵌入结点 (不同框架), 例如槽位来自底 β 或左加数 a, 目标来自 y. 第一版一律不保留. 其中槽位层字面是 `zero` 的可由字面地板 (`z≤`, 候选 A) 另行处理, 不在本设计内.
  - 嵌套框架 (指数 y 里又有 `pw`/`up`): 内层结点到外层框架的路径可由 "换框架处存一条 m₁ ≤ m₀" 复合得到. 第一版不做, 记为扩展.
  - 框架 m 内部再在 Ω 形状结点上分叉: `kp⁼ m` 仍给 `nothing`. 新块里自身行不再产生 Ω 形状层号的孩子侧位置, 这种格是否还被问到是【判】.
  - 无框架的目标 (外面给的裸路径), §3.1.
- "终点递归问到的分叉格全是同框架的" 是【判】, 依据只有 A 路命题 D 的形状分析, 那里的【判 3】没有逐项展开.
