## 3 缺陷在 ψ₀(Ω_{Ω₂}) 以下是否起作用：是

### 3.1 第一格在哪里 【纸】

设 a′ 是 Ω 形状层号 `nd (sΩ k) h`，孩子 d 的层 h d 是后继形状 `nd sS ρ`（ρ = h d 的前一层）。四步，每步是折叠的一个子句：

1. 层号 `nd sS a′` 上的 `Ωt` 是槽位 a′ 上的结点，朝任何低层走链；链点 z_{m+1} = `next⁺`（z_m 在 a′ 上折到自身）。折到自身的嵌入行是 `Up`。
2. a′ 上的 `Ωt a′` 的分支是 `up 0 d (Ωt (h d))`；折到自身后是 N_d = `Up (h d) (down stop d) β (Ωt (h d))`。`Up` 用 `mv` 把孩子层的结点搬成 a′ 的孩子侧槽位（`up-node`）。N_d 的分支是 w ↦ `next⁺ (Up ρ (down (down stop d) tt) β w)`，w 取遍 ρ 层的树；w 自己的结点被搬到更深的孩子侧槽位。
3. 朝更低的 j 折 N_d：槽位层 ρ 不低于 j 时走链（正确）。链点 w_{m+1} 是 "朝 ρ 层、沿 `posW` 折分支 (w_m)" 的值；`posW` 是 `inc d (…)`（`feed-path`）。
4. 这条折叠里，w_m 的每个结点都是 a′ 的孩子侧槽位，目标路径是 `inc d …`，落进 K6（`k6`），走链。这些结点的槽位层都严格低于 ρ，按 "低于目标保留" 该保留。

所以只要有 "Ω 形状层号上面的后继层"（下标 λ+1，cf λ = Ω 型），第 2 个链点 z₂ 起就含 N_d，第 3 步的回灌在 ρ ≥ 1 时就亏损。最小实例：a′ = tw 1，d = 2，ρ = 第 1 层，被折的是 b·ω^{Ω₂}，即 E 路 §4 的 `lossy-cell`。它在塔第 2 项里从第 1 个主链点 z₁ = "b 折到自身" 的分支就出现（E 路命题 R）。

值的位置：b·ω^{Ω₂} 的折叠是 ψ₀(Ω_Ω·ω^{Ω₂})，它小于 ψ₀(Ω_Ω²) = ψ₀(Ω_Ω·ω^{Ω_Ω})，后者小于 ψ₀(ε_{Ω_Ω+1}) = ψ₀(Ω_{Ω+1})。参照第 1 项 ψ₀(Ω_{ψ₁(Ω_Ω)}) 在这三个值之上。所以缺陷在目标以下很远处已经被问到。

ρ = 第 0 层（d = 1，b·ω^{Ω₁}）时不亏损：w 没有结点，底朝第 0 层走链本来就对。

### 3.2 与塔无关 【纸 + 编】

把 tw 1 换成任何 Ω 形状层号，3.1 的四步逐字成立。`MathO2Check` 第 (3) 段是 `W one` 的世界里的实例：a′ = 1+Ω₁，孩子 d 的层是 1+d+1，N_d 的槽位层是 1+d ≥ 第 1 层，d = 0 就亏损。任何下标不低于 Ω·2 的层号都以 Ω+1 型的层为子层（`↑ (β + β)` 的第 0 个孩子是 `↑ β` 上的后继层），所以我试过的三族闭项（塔 `tw n`、`W a`、`ℓ ⊕ ↑ ℓ (Ωt ℓ)`）都走到这一格。"现在的块上没有任何理想值不低于 ψ₀(Ω_{Ω+1}) 的闭项能避开这一格" 是判断。

### 3.3 主线多出的一处：E6 的回退 【纸 + 编】

第 3 步里链点的底是 E_ρ = "朝 ρ 层、沿 `inc d …` 折 `Up` 的底 β"。β 是 tw 1 上的树（b 或更大）。逐子句：

- β 的下标侧结点（分支取第 0 层的树）：`kp … (inj₁ t) (inc d v)` 把槽位推进孩子 d 再比较，ρ ≥ 1 时保留。
- β 里的嵌入 `up x e y`（y 是孩子 e 的层上的树）：主线查表 `tbᶻ zero h₁ e d`。只有 e 或 d 字面是 `zero` 才有表项；d = `nat 2`、e 非零时没有（`tb-none-s`、`tb-none-l`），回退成 "x 的折叠 ⊞ ψ₀(y)"（`fallback`）。y 被整棵折到第 0 层。
- β 里的孩子侧结点：K6，走链。

所以 E_ρ 是 ρ 层上这样一棵树：零处是 `Ωt ρ`，β 的下标侧结点各变成一个分支取第 0 层树的结点，其余都是可数的项。对 β = b：E_ρ = `Ω q (e ↦ Ωt ρ + ψ₀(Ω_e))`，值 Ω_ρ + Ω₁。该有的是 ψ_ρ(Ω_Ω)。

E 路 §5 的模型假设 (H2)：以 u 为底的 f(u) ≥ ε_{u+1}。主线上 f(u) = u + Ω₁（β = b 时），(H2) 不成立。E 路分析的是换基候选 `YiBSFold`（那一行走 `route`/`seen`），不是主线；它的 "极限处补回" 的模型结论不能搬到主线。

### 3.4 这一格的两边的值 【纸，末句判】

朝第 0 层折 N（β = b，ρ+1 层的 Ω 树在指数上）：

- 该有的：链 w_{m+1} = E·ω^{w_m+1}（w_m 的结点保留），上确界 ε_{E+1}，E = ψ_ρ(b)；外层值 ψ₀(b·ω^{Ω_{ρ+1}})。
- 实际的：w_{m+1} 的零处是 E_ρ，后继与极限照 w_m 的形状，w_m 的结点都换成可数条链上的部分和。所以 w_{m+1} = E_ρ·ω^{α_m}，α_m 是可数序数；上确界 X_ρ = E_ρ·ω^γ，γ 可数，值小于 (Ω_ρ+Ω₁)·Ω₁。外层折的是 b·ω^{X_ρ}。
- X_ρ 里的 `Ωt ρ` 是 ρ 层上的真结点；但 X_ρ 被 `Up` 搬回 a′ 的孩子侧，外层再折它时，ρ = ρ′+1 的话又是同一格。递推：指数位置上 Ω_{ρ+1} 的作用降到 Ω_ρ 的可数倍，再降到 Ω_{ρ′} 的可数倍，直到 Ω₁（第 0 层槽位不亏损）。极限层的 `Ωt` 是后继层的 `Ωt` 的部分和，不补回。
- 【判】于是 tw 1 的树里，指数上只有 Ω₁ 的结点是按理想值工作的；ψ₀(Ω_Ω·ω^α) 在 α 只含 Ω₁ 结点时与理想值一致，α 含更高层的结点时掉到这个范围里。这个范围的上确界大约是 ψ₀(Ω_Ω·ε_{Ω₁+1}) = ψ₀(Ω_Ω·ψ₁(Ω₂))。这与仓库现状相容（已证的终点下界 ψ₀(Ω_Ω+ψ₁(Ω_ω)+ω)；`tower→V130` 把越过 ψ₀(Ω_Ω+ψ₁(Ω₂)) 归约到未证前提），但不是定理：折叠没有独立的上界，折叠值依赖树的结构（E 路 §4 的提醒同样适用于本段）。

## 4 三条到 ψ₀(Ω_{Ω₂}) 的路

### 4.1 塔第 2 项里字面的 Ω₂ 形状孩子：未走通，有两边的值

被问到的闭项：K = `tw 1 ⊕ ↑ (tw 1) (upz 2 (Ωt (h₁ 2)))`（下标 Ω+Ω₂，`K-shape`），`Ωt K` 朝第 0 层的折叠；理想值 ψ₀(Ω_{Ω+Ω₂}) = ψ₀(Ω_{Ω₂})。K 型的层在塔第 2 项里以带非默认底的子层出现，这里按默认底算。

顶结点朝第 0 层走链，链点 c_{m+1} 是朝第 1 层折 `Ωt (K 的孩子 c_m)` 的值，孩子 c 的层是 Ω+c+1。第 1 层到这些层的路径是 `inc 2 (inc tt self) ∙ lift …`（`K-path`）：在一切偏移层上是 `inu`，到 tw 1 时是 `inc 2 …`。

亏损在三处【纸】：

- (i) c 的 Ω₁ 型结点读成层号后是下标层为第 0 层的 Ω 形状偏移层，它的下标层证据是 "第 0 层 → 第 1 层 → tw 1 的孩子 2"。朝第 1 层折这一层的 `Ωt` 时，槽位沿证据推到 tw 1 上是孩子侧（孩子 2 里的第 0 层），目标路径是 `inc 2 …`，K6，走链。该保留（0 < 1）。所以 c_{m+1} 不继承 c_m 的任何 Ω₁ 型结构，只在可数个点上取值。
- (ii) 降到偏移为零的叶子时在 tw 1 上折 b 的各次幂；非零孩子的嵌入走回退（`fallback`），3.3 的 E_ρ。
- (iii) 这些层上面的后继层里是 3.1 的格。

两边的值：

- 该有的：c_{m+1} = ψ₁(Ω_{Ω+c_m+1})，与 γ_m 共尾；c₁ 已高于一切 γ_m 的理想值。
- 实际的【纸 + 判】：把 "朝第 1 层、沿 `inc 2 …` 在 tw 1 上折" 记作 π。π 逐构造子是：零给 `Ωt one`，后继给 `next⁺`，极限逐项，下标侧结点保留成 Ω₁ 型结点，非零孩子的嵌入变成加一个可数项，孩子侧结点走链。c₁ = Σ_m `next⁺` π(z_m)，z_m 是 b 的 m 重幂塔，π(z_m) 的值约为 Ω₁ 的 m 重幂塔，所以 c₁ 的值约为 ε_{Ω₁+1}。c_{m+1} 约为 ε_{Ω₁+δ_m}，δ_m 是 c_m 的可数骨架的序型。一切 c_m 的值都小于 ε_{Ω₁·2}，而 γ₁ = ψ₁(Ω_Ω) 已远在其上。

外层补不回的理由【判】：链点不继承上一个链点的不可数结构（(i)），所以链的增长只来自可数骨架；这是 "朝孩子侧层号的折叠只留下标侧结点" 的直接后果，不是某一项晚到的问题。是否有别的子项补回属于 4.2。按规则这只算 "未走通"：实际值的上界没有定理。

### 4.2 主链换名（tw 1 充当第 1 层）：卡在同一格

塔第 2 项的主链 z_{n+1} = "朝 tw 1 折 `Ωt (tw 1 ⊕ ↑ z_n)`"，路径是 `ink self` 再 `lift`，派发精确；z_n 的下标侧结点读成层号后，下标层证据是 `ink self`，朝 tw 1 保留，朝第 0 层走链，都对（与 4.1(i) 不同）。结构上 `Tr one` 嵌进 `Tr (tw 1)`（第 1 层的结点对 tw 1 的下标侧结点，`up x tt y` 对 `up x zero y`），层号 `one ⊕ ↑ c` 对 `tw 1 ⊕ ↑ (像 c)`。所以塔第 2 项的主链是 `W one` 的主链换名之后的像再加上多出的结构。

但 `W one` 自己在下标 Ω+1 处就是 3.1 的格（3.2），换名之后还是。要用这条路，需要 4.3 的结论再加一条 "多出的结构只增不减" 的支配引理；后者要一个对非正规树有定义的值的序（E 路的 (S1)）。

### 4.3 换基的新闭项 `cand`（研究候选，不是主线）：卡在同一格

`cand` 的层号 `W one` 不经 tw 1：一切目标（第 0 层、第 1 层）到偏移层的路径都是 `inu`；偏移层的下标层证据是 `inc tt self`（后继形状上的 `inc`，精确）。所以 4.1 的 (i)(ii) 两处在它的主链上不出现【纸】：c_{m+1} = "朝第 1 层折 `Ωt (one ⊕ ↑ c_m)`" 保留 c_m 的 Ω₁ 型层号结点。它的理想值恰是 ψ₀(Ω_{Ω₂})。

剩下的是 3.1 的格（`up-node`、`feed-path`、`k6` 在 a′ = 1+Ω₁ 上）：c_m ≥ Ω₁+1 时 G(c_m) 的计算经过下标 Ω+1 型的层，那里指数上的 Ω_{1+d+1} 亏损；回灌的底在这个世界里同样走回退（`tbᶻ zero hd e d` 只在 e = d = `zero` 有表项，因为 hd zero 字面不是 `zero`）。参照第 1 项 ψ₀(Ω_{γ₁}) 的 γ₁ = ψ₁(Ω_Ω) 已经超过 Ω+1，所以第 1 项就要越过这一格。

`cand` 相对塔的用处【判】：它把问题缩成一个不含 tw 1 的世界，卡点只剩 3.1 一种格。它不解决问题。

## 5 卡住的那一步

要证 "某闭项不低于参照第 1 项 ψ₀(Ω_{ψ₁(Ω_Ω)})"，按依赖排序缺三条。

- **(C1) 值的语义。** 需要一个对含亏损格输出的树（非正规树）也有定义、对折叠各行单调的量，才能陈述 "实际折叠不低于某某"。记号关系 `Mᴰ` 在第 1 层以上太刚（`Mᴰ` 对不上 "η ≤ z 推出 η ≤ Ω_z"：后继项对不上 Ω 结点，台账 V128 的记载与我的核对一致）；第一位置序 `⊴` 只给粗界。这与 E 路 (S1)、V 路第 2 条是同一个缺口，本轮没有新办法。
- **(C2) 补回引理，真假未知。** 最小的一条：是否存在主线折叠的一个合法闭项 t，使 ψ₀(Ω_Ω·ω^{Ω₂}) 的参照树不高于 t，且证明不经过 N₂（b·ω^{Ω₂} 的 `Up` 像）自己的折叠值。按 3.4，N₂ 自己的折叠值【判】低于参照；能补的只有更高处的项（例如下标 Ω+2 的层里槽位是后继形状孩子的结点，那里的回灌是 `inc tt self`，精确）。这要求把 "tw 1 的树的指数上的 Ω₂" 换成 "上面某个健康槽位上的树" 来模拟，即一条跨层的模拟引理；它的陈述依赖 (C1)。
