## 0 结论

**(c): 一轮内写不出.** 既没有 "终点不低于 EBO" 的完整纸面证明, 也没有 "终点掉值" 的反例.

本轮确实得到的:

1. 【纸】终点问题归到一族具体的格 (★ₙ), 见 §3. 归约的每一步是折叠的一行加 "和不小于每一项".
2. 【纸 + 编】折叠的派发在哪里精确, 在哪里不精确, 有逐子句的分类 (§2). 不精确只有一种情形: 目标经 Ω 形状层号的**指定孩子**到达. 朝第 0 层, 朝地板, 朝下标层的折叠在派发上都精确.
3. 【纸】最小亏损格的两边的值 (§4): 该保留而走链的结点, 使槽位层上的链点从 "底值之上的下一个 ε 数" 降到 "底值乘 ω 的可数次幂". 形状已编译 (`lossy-cell`).
4. 【判】这处亏损在外层是否补回, 只在一个简化模型里算过 (§5): 模型里亏损在极限下标处补回, 但不是 A 路命题 E 说的 "晚一项", 而是嵌套 j 层时要晚到约 2j 项. 模型的三条假设没有证明.

## 1 问题与参照的核对

- 层号的值 (只在纸面用): |zero| = 0, 后继形状加一, ℕ 极限与 Ω 形状取上确界. `Tr ℓ` 的树的值小于 Ω_{|ℓ|+1}; `Ωt ℓ` 的值是 Ω_{|ℓ|} (Ω₀ = 1). 记 νₙ = |tw n|: ν₀ = 0, ν₁ = Ω₁, ν_{n+1} = Ω_{νₙ+1}.
- 终点的参照: `EBOψ n = ψ₀(ΩTower n)`, `ΩTower 0 = 1`, `ΩTower (n+1) = Ω_{ΩTower n}` (`EBO.lagda.md` 第 479 到 487 行; `YiGIEnd.omega-kt` 给 Ω_{kt n} = ΩTower n). 即第 1, 2, 3 项的参照是 ψ₀(Ω₁), ψ₀(Ω_{Ω₁}), ψ₀(Ω_{Ω_{Ω₁}}).
- 第 n 项的理想值是 ψ₀(Ω_{νₙ}). 所以 A 路那句 "第 n 项的参照 ψ₀(Ω_{kt n}) 恰是第 n−1 项的理想值" 只对 n ≤ 2 逐字成立; n ≥ 3 时第 n−1 项的理想值严格更大 (ν₂ = Ω_{Ω₁+1} > Ω_{Ω₁} = ΩTower 2). 对终点而言这只让要求更松: 只要对每个 N 有某一项的值不低于 ψ₀(ΩTower N).

## 2 已编译与派发的分类

**【编】`MathECheck.agda`.**

- `beta-is-prev : ∀ n → proj₁ (betaᴮ (suc n)) ≡ twcᴮ n` (`refl`): 第 n+1 项的底值逐字是第 n 项的闭项.
- `step-up`: 第 n+1 项的底值 `⊴` 第 n+1 项 (用 `YiWREnd.ψ-⊵ᴮ`). 两条合起来: 塔的各项按第一位置序不降. 这是目前唯一无前提的值的下界: twcᴮ (n+1) 不低于 twcᴮ n.
- `top-chain`: 塔顶结点朝第 0 层走链.
- `lossy-cell`: tw 1 上, 槽位是孩子 2 里的第 0 层, 目标是孩子 2 里的第 1 层, `kp ≡ nothing`. 这是 A 路定理 A 的最小实例 (槽位低于目标, 两者在同一个孩子里, 折叠走链).
- `idx-kept-eq`: 同一目标, 槽位换成 tw 1 的下标层 (字面的第 0 层), `kp` 给 `just`, 保留.

**【纸】派发的分类 (逐子句读 `YiRWFold.kp`, `YiBSFold.ψ`).** 把路径 w : j ≤ ℓ 分三类.

- (P1) 自身 `self`: 结点保留, 嵌入走 `Up`. 精确.
- (P2) 一致路径: 在每个 Ω 形状层号上是 `inu` 或 `ink`. 朝第 0 层 (`z≤`), 朝地板 (`lift a b`), 朝下标层 (`ink self ∙ lift`) 都是这一类. 这时 `kp` 的孩子侧槽位进孩子比较 (`inu`, `ink` 两行), 下标侧槽位推进孩子 `zero` 再比较; 嵌入一行进孩子, 不经 `seen`. 派发与 "槽位层低于目标则保留, 否则走链" 一致.
- (P3) 在某个 Ω 形状层号上是 `inc c′`. 这时有两行不精确: `kp (nd (sΩ k) h) _ (inj₂ _) (inc _ _) = nothing` (孩子侧槽位一律走链); 嵌入一行在 `route` 给 `inj₂` (目标在地板之上) 时用 `seen ⊞ ψ₀(y)`. `route` 给 `inj₁` (目标不高于地板) 时用 `back` 进孩子, 精确. 下标侧槽位配 `inc` 仍进孩子比较, 精确 (`idx-kept-eq`).

推论 【纸】: 塔第 n+1 项的主链 (塔顶结点的链点 z_k, 目标是 tw n, 路径 `ink self` 再 `lift`) 在派发上全程精确. (P3) 只在一种地方出现: 朝某个**孩子侧槽位**的链. 孩子侧槽位由 Ω 形状层号上的自身折叠 (`Up` 的 `mv`) 产生.

塔第 1 项没有 (P3): tw 1 上被折叠的只有 `Ωt (tw 1)`, 链的路径是 `ink self`, 之后都在可数层号 (只有后继与 ℕ 极限形状) 里. 这与 A 路 §7 一致.

【判】在可达的折叠里, Ω 形状层号上的嵌入 `up x c y` 的 y 都逐字是 `Ωt (h c)` (来源只有 `Ωt` 的分支与底里的 `Ωt`). 若成立, `seen` 丢掉 y 这件事不造成亏损, `seen` 的问题只剩内部用默认底 (A 路命题 F) 与内部是不带换基证据的旧行 (`R.rb-no`). 没有证明, 只逐类看过树的来源.

## 3 归约: 终点归到 (★ₙ)

记 T¹ₙ = tw n ⊕ ↑ (tw n) (Ωt (tw n)), 值是 νₙ + Ω_{νₙ} = Ω_{νₙ}.

**命题 R 【纸】.** 对 n ≥ 1, 存在由 `rootᴮ (n+1)` 经 `stepᶻ` 可达的状态 s*, 使 twcᴮ (n+1) 的值不低于 `Φᶻ s* (Ωt T¹ₙ)` 的值.

证明 (n = 1, 一般 n 逐字相同). (i) 塔顶结点走链 (`top-chain`), 和不小于第 1 个链点的项 G(z₁). z₁ 是 `Ωt (tw 1)` 的自身折叠, 底是 β₁ = `baseᴮ 2 (tw 1) (ink self)`, 所以 z₁ = `Ω idx (d ↦ U_d)`, U_d = `Up (h₁ d) (down stop d) β₁ (Ωt (h₁ d))`.
(ii) G(z₁) 是朝第 0 层折 `Ωt (tw 1 ⊕ ↑z₁)`; 这个层号是 Ω 形状, 顶结点走链, 第 0 项是孩子 d = 0 的项; U₀ = `next⁺ β₁`, 层号是 ℕ 极限形状, `Ωt` 是部分和, 第 0 项是 `Ωt (tw 1 ⊕ ↑β₁)`.
(iii) β₁ 按 `pre 2 = up (up zero 0 1) 1 (Ωt (tw 1))` 展开 (ℕ 极限行两次, `emb`, `ink` 行进孩子 0, 自身行): β₁ = `Ω idx (d ↦ Up … β₀′ (Ωt (h₁ d)))`, β₀′ = `next⁺ (Ωt (tw 1))`. 再取两次第 0 项, 到 `Ωt (tw 1 ⊕ ↑(Ωt (tw 1)))`.
每一步是 "部分和极限或链的和不小于其中一项", 沿途底与底值只增 (`ψ-⊵ᴮ`). ∎

于是: **若对无穷多个 n 有 (★ₙ): `Φᶻ s* (Ωt T¹ₙ)` 的值不低于 ψ₀(ΩTower (n+2)), 则终点不低于 EBO.** 理想值是 ψ₀(Ω_{Ω_{νₙ}}), 不低于 ψ₀(Ω_{ΩTower (n+1)}) = ψ₀(ΩTower (n+2)).

(★₁) 的内容: T¹₁ 是 Ω 形状, 下标层是字面的第 0 层, 孩子 d 是 Λ_d = tw 1 ⊕ ↑ (h₁ d) (Ωt (h₁ d)) (值 Ω₁ + Ω_d). 顶结点朝第 0 层走链, 链点 d_{m+1} 是朝第 0 层折 `Ωt Λ_{d_m}` 的值. 理想的链是 d_{m+1} = ψ₀(Ω_{Ω₁+Ω_{d_m}}), 上确界 ψ₀(Ω_{Ω_{Ω₁}}). 所以 (★₁) 等价于: 实际的 D(Λ_d) 随 d 的增长与 ψ₀(Ω_{Ω_d}) 共尾.

## 4 最小亏损格的两边的值

【纸】设 b : `Tr⁺ (tw 1)`, 孩子 2 (h₁ 2 是两次后继). W = `Up (h₁ 2) (down stop 2) b (Ωt (h₁ 2))` = `Ω⁺ p (c ↦ next⁺ (Up₁ b c))`, c 取遍第 1 层的树, 槽位 p 是孩子 2 里的第 1 层; 值是 |b|·ω^{Ω₂}. 朝第 0 层折 W: 结点走链 (正确), 链点 c_{m+1} 是朝第 1 层 (路径 `inc 2 (inc tt self)`, 属 (P3)) 折 `next⁺ (Up₁ b c_m)` 的值.

`Up₁ b c` 逐构造子照 c 的形状 (零给 b, 后继给 `next⁺`, 极限逐项, c 的结点搬成 tw 1 上孩子侧的结点, 槽位是孩子 2 里的第 0 层). 朝第 1 层折它: 零处给 E = 朝第 1 层折 b 的值; 后继与极限照搬; c 的结点处是 `lossy-cell` 的格, 走链.

- 该有的: c 的结点保留, 折叠值是 E·ω^{c}, 链 c_{m+1} = E·ω^{c_m+1}, 上确界是 |E| 之上的下一个 ε 数 ε_{|E|+1}.
- 实际的: c 的每个结点换成它在可数个链点上的分支的部分和, 折叠值是 E·ω^{γ}, γ 是这副可数骨架的序型, γ < Ω₁. 所以一切链点 c̃_m 的值小于 |E|·ω^{Ω₁}, 上确界不超过 |E|·Ω₁, 严格小于 ε_{|E|+1}.

这是 A 路定理 B 低一层的同一格; 多出的是把亏损写成了链点的界. 层号一般化: 目标是孩子侧的第 s 层时, 被折叠的树里槽位低于 s 的孩子侧结点全部走链, 第 s 层上的链点都小于 E_s·Ω₁, E_s 是底在第 s 层上的折叠值. 被保留的只有下标侧的结点 (`idx-kept-eq`) 与可数层号内部的结点.

注意 【纸】: 这里 "值小于 E·Ω₁" 是序数值的界, 不直接给出外层折叠值的界. 折叠值依赖树的结构, 不只依赖序数值: 把一棵可数的大树放进指数, 折叠值可以超过布赫霍尔茨函数在同一序数值上的值 (布赫霍尔茨函数在不动点之后是常值, 树的折叠不是). 我在推演中两次因为把这两者混同而得到矛盾, 所以下面 §5 的比较只在模型里做.

## 5 外层是否补回: 只有模型计算 【判】

模型: 把朝第 0 层的折叠读成 "正规形上的 ψ₀", 上下文记 K. 则 §4 的格在外层是

- 该有的 ψ₀(K·ω^{Ω₂}) = ψ₀(K·ω^{ε_{E+1}}), E = ψ₁(K);
- 实际的 ψ₀(K·ω^{E·Ω₁}).

两个指数都是正规形, 实际的严格小. 即在这一格上, 指数里的 Ω₂ 被换成 Ω̃₂ = ψ₁(K)·Ω₁. 一般地指数里余尾 Ω_{s+1} 的结点被换成 Ω̃_{s+1} = ψ̃_s(K)·Ω₁, 其中 ψ̃_s(K) 是 ψ_s(K) 这棵树里的 Ω_s 再递归地换成 Ω̃_s.

记 f(u) 为 "以 u 为底的 ψ_s(K)". 模型的三条假设: (H1) f 单调; (H2) f(u) ≥ ε_{u+1} (K 不低于 Ω_{s+1} 时成立); (H3) 各层的 f 可比. 则实际的 X_{j+1} = f(X_j), 该有的 H_{j+1} = f(ε_{H_j+1}), 归纳得 X_{2j} ≥ H_j: X_{2j+2} = f(f(X_{2j})) ≥ f(f(H_j)) ≥ f(ε_{H_j+1}) = H_{j+1}.

模型的结论: 嵌套 j 层的该有的值, 被实际的嵌套 2j 层的值盖过. 层号是极限时两边的上确界相同. (★₁) 里 Λ_d 的 d 是折叠输出, 都是极限形状, 所以模型给出 (★₁) 成立. 塔的各项同理, 因为 T¹ₙ 的孩子的下标取遍一个极限.

与 A 路的差别: A 路命题 E 说树的第 k 项不低于参照的第 k 项 (只晚一项). 模型里晚一项只对一层成立; 嵌套时要晚到约两倍. 所以按 "参照晚一项" 改 `raiseR` 的办法 (A 路 §5) 在嵌套的格上不够, 这一点是模型推出的, 没有具体格的核算.

我的判断: 终点不掉值的可能性大于掉值 (约六成五对三成五). 依据是模型, 以及主链在派发上精确 (§2). 反面的依据: 若把同样的不精确施加在一个只有有限个后继层的系统的每一层上, 模型给出整体停在很低的位置 (每升一层只多出约半层); 塔之所以不落进这种情形, 靠的是孩子的下标取遍极限这一点, 而这一点我只在模型里用过. 另外 `seen` 的两处 (默认底, 内部是旧行) 完全没有进模型.

中间各站的精确值 (不取极限的位置) 在模型里是掉的, 这与 A 路一致, 不影响终点.

## 6 卡在哪一步

要把 §5 变成证明, 缺下面四条, 按依赖排序.

- **(S1) 没有 "该有的值" 的树侧定义.** (P3) 的折叠输出不是正规形的像. 要陈述 "实际值不低于某某", 右边必须是一个对非正规的树也有定义, 且对折叠各行单调的量. 仓库里现有的只有 `GR.R` (逐项对应, 已被 A 路反例否定) 与第一位置序 `⊴` (只给 `step-up` 这种粗界). 这是本轮写不出的直接原因.
- **(S2) 半速支配引理, 未证.** 陈述: 对可达状态, Ω 形状层号 ℓ, 孩子侧的槽位层 e 与其下的 e′, 设 V 是层号下标里余尾为 Ω_{e+1} 的结点, V⁻ 是把它的分支限制到 `Ωt e` 以下得到的树 (余尾降一档), 则朝第 0 层折 `Ωt (a ⊕ ↑V″)` 的值不低于朝第 0 层折 `Ωt (a ⊕ ↑V⁻)` 的该有的值, 其中 V″ 是 V 上面再套一层同样的结点. 即 §5 的 X_{2j} ≥ H_j 在树上的形式. 它依赖 (S1), 并且要对朝各孩子侧目标的折叠同时归纳 (一个目标一条), 不能只对第 0 层.
- **(S3) `seen` 的下界, 未证.** 需要: `seen S j … β c` 的值不低于朝 j 折 `Ωt (floor ⊕ offsets c)` 的该有的值减去 (S2) 那种一档的亏损. 内部是 `R.ψ` 配 `rb-no`, 即不带换基证据的旧行, 它在 Ω 形状的偏移上还有一层回退 `ψ x ⊞ ψ₀(y)`. 这一层的亏损我没有算.
- **(S4) y 逐字是 `Ωt (h c)` 的不变式 (§2 的判断).** 不成立的话 `seen` 丢掉 y 会是新的亏损来源.

(S1) 与 (S2) 是数学上的缺口; (S3), (S4) 是工作量.
