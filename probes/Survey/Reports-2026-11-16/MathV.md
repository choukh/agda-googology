## 问 1 (ii)："该有的值" 能不能在树侧定义

要的东西：对每个层 ℓ、目标 j、树 x 的 "理想折叠值" V(ℓ,j,x)，对一切树有定义，且折叠各行单调，使 "实际折叠 ≥ V" 能逐行归纳。

困难（三条，前两条是纸面论证，第三条引 A/R）：
1. **作为全函数的精确理想折叠不存在。** 精确的 K6 要按 "槽位层低于目标层" 派发；折叠输出的头部（Ω 结点还是 ℕ 极限）可观察，所以精确派发判定这个层号命题（`obs→dec` 的形状）。层号是带 ℕ 极限与 Ω 分支的树，孩子下标取遍 `Tr k`，这个命题一般不可判。所以能写出的全函数一定在某些格上低于理想，也就不是 "该有的值"。
2. **作为关系（带证据的理想折叠）能定义，但逐行保持在 K6 上是假的。** 可以写归纳关系 I(ℓ,j,x,v)，K6 上允许凭字面路径 `at ≤ j` 的证据保留。但 "∀ v, I x v → v ≼ 实际折叠 x" 在 K6 那一格逐结点不成立（A 路定理 B，R 路复算；值的部分是纸面加折叠上界的判断）。亏损只在外层补回，所以命题必须写成滞后的形式：I(x, v) → v ≼ 折叠(shift x)，shift 是树上的某个放大（A 路的观察：层号读法 μ 换成 μ·2 时 μ·2[ζ] = μ + μ[ζ] ≥ μ）。shift 要对一切树（含非正规的，因为 `full-succ` 说域收不窄）有定义并与各行交换。我一轮内写不出这样的 shift，也没有它存在的证明。
3. 以记号项为参照（`GR.R`）时，非正规树对应非标准形，`mc` 两边不是标准形（`¬closeNF-all`，转述）。这是同一个困难在记号侧的样子。

我的预判：(a) 一轮写不出是可信的；必经的卡点是第 2 条（滞后的 shift 对非正规树的定义与交换）。它是不是 "必经" 取决于是否接受 (c3)。

## 问 2：能在 A 路那一类格上保留的判定必须避开什么

那一类格：层号 `nd (sΩ k) h`，槽位 `inj₂ (c , t)`，目标路径 `inc c′ v`，槽位层低于 j。保留要交出 `q : Pos j`、换型 `cv : Br j q → Br ℓ p`、第一分支到第一分支。现成的做法是给一条字面路径 `u : at ≤ j`（非 `self`），用 `psh`、`pshBr`、`pshFirst`。

逐条读否定定理的前提：
- `branch→wdec`（YiAbsFrame）：固定一棵树 o、同一个目标 j、一族路径 `w : ∀ c′ → j ⊑ chL ℓ c′`；若头部在 c₀ 为 true，在一切 c′ ≠ c₀ 为 false，则 ∀c′ WDec (c₀ ≡ c′)。**避开：在同一目标对一切孩子都有路径的地方，只在一支上保留、别处可观察地不保留。** 注意前提要 j 在每个孩子里都有路径；在塔层号上这逼出 j ≤ 地板（例如 tw 1 上 j ≤ h₁ zero = zero）。目标在地板以上时这族路径不存在，这条定理的前提不满足。
- `hand→wdec`：某层上 `Hand`（对一切 c、一切 `w : j ⊑ chL ℓ c`，`inc c w` 上的嵌入逐字交给孩子 c）加探针处回退可观察（`Offᴾ`：一切 c′ ≠ c₀ 头部 false）。同样要探针里的 `w : ∀ c′`。**避开：裸 `inc` 路径上的精确交接配可观察回退。**
- `viaE→dec`：行经证据函数 `E : (c c′) → Maybe (c ≡ c′)` 派发且在探针处同支成立，则判定探针与一切 c′ 的字面相等。**避开：孩子下标上自反的证据函数。**（对固定的有限深度探针，如数字 2，与它的字面相等本来可判，定理的结论在那里不是禁忌；对含 ℕ 极限的探针如 ωᵉ 才是。）
- `full→dec`、`sig→lpo`：**避开 "凡能保留处都保留"（对存在命题完全）。**
- `ColW.wdecα`（YiDGDiag）：tw 1 上任何一列 c ↦ Maybe (h₁ c⋆ 与 h₁ c 之间某方向的字面路径)，在 c⋆ = sᵐ ωᵉ 有条目，就对康托族弱判等。**避开：以孩子下标为键、给出两个孩子层之间字面路径的表，且在极限孩子的对角上有条目。** 同文件 `diag-nat`：数字孩子上对角可满足。文首明说不否定 "保留判定的变体（保留不要求字面路径，类型逼不出别处为空）"。
- `kp-diag`、`row-diag`：现行判定在同一变量给两边时就是空的；所以 "同一孩子" 的见证不能从两个裸下标算出，只能来自构造。
- `barrier`：不得要求以 `Ordᴰ` 为精确初始段、含 Ω-共尾元、有界三歧的下标类型。**避开：对层号或孩子下标的序做判定。**

所以保留判定必须避开：(1) 两个裸孩子下标 (c, c′) 的任何在极限孩子对角上成立且可观察的函数；(2) 对 "存在字面路径/存在槽位" 完全；(3) 层号序的判定。

**能避开的设计至少要带的数据（纸面）：槽位层到目标层的字面路径，且这条路径不是由比较 c 与 c′ 得到，而是由构造带来。** 我看到三种来源：
- (s1) **只用目标这一个孩子**：槽位在下标侧（层 ≤ k）时，`kh c′ : k ≤ h c′` 与 `v : j ≤ h c′` 是进同一个 h c′ 的两条路径，c′ 是同一个变量。有 `Schema` 时 `split` 给 j ≤ 地板 或 地板 ≤ j；后一种情况 k ≤ 地板 ≤ j 是字面路径（`index-floor ∙ u`），可保留；前一种把问题降到地板里。不比较孩子。孩子侧槽位 `inj₂ (c , t)` 同理：对 `posW` 再 `split` 一次，"槽位 ≤ 地板 ≤ 目标" 可保留，"都在地板以下" 降到地板里，"目标 ≤ 地板 ≤ 槽位" 走链正确。**剩下的硬格是槽位层与目标层都在地板以上、分处孩子 c 与 c′ 的偏移里**，以及降到地板后在更低的 Ω 形状上重复出现的同一格。A 路那一格降到 tw 1 后正是硬格（槽位 lvl1、目标 lvl2 都在 tw 1 的地板 zero 以上，经孩子 2）。
- (s2) **目标带框架**：目标不以裸路径给，而连同 "它是哪个层的哪个位置、经哪条下行链到当前层" 一起给，使槽位与目标落在同一个变量的孩子里时这件事是字面的。链步回灌产生的目标天然有这个数据（目标就是 `at ℓ p′`）。但槽位 p 与 p′ 都是 `Pos ℓ` 的元素，各自带一个孩子下标，直接比较又回到 (c, c′)。所以框架要管用，槽位也得以相对框架的形式出现；现在的块里 `Up` 把孩子树压平成 ℓ 的树，槽位是 `mv d p`，d 丢了。要么 (s2a) 改块，让上折挂起（树里保留 "这一段住在孩子 c 里" 的构造子，折叠进到里面时层号换成 h c，c 从两边的地址里一起消失）；要么 (s2b) 不改块，只覆盖槽位在下标侧的格（下标侧槽位不带孩子下标，见 s1）。
- (s3) 孩子下标的部分判等（只对有限深度的下标给 `just`）：能盖住 A 路那个具体的格（c = c′ = 2），但盖不住极限孩子，且对高层 `Tr k` 的下标基本无用。不算设计。

**"目标给裸路径的那一格是否任何设计都保留不了"：不是定理。** 编译过的否定只禁了三种形式（对角精确且别处可观察为空；经字面路径的列在极限孩子对角有条目；对存在命题完全）。它们的前提在这一格上并不自动成立：`branch→wdec`、`hand→wdec` 要同一目标在一切孩子里都有路径，地板以上的目标没有；`ColW` 要的是两个孩子层之间的字面路径，保留判定的类型只要求 `Br j q → Br ℓ p` 的换型，文件自己声明不否定。数字孩子上还明确可满足。我的判断是：对极限孩子与高层下标，裸路径上的保留在实践中做不出（任何我能想到的做法都要先定出 c 与 c′ 的偏移里两个子层的序，而那在 `Tr k` 上会按 `full→dec` 的方式判定存在命题），但这句话应标成判断，不应写成 "任何设计都不行"。

## 预判与我要挑战的点

1. (a) 若把 "写不出" 归到 "没有对非正规树有定义且对折叠单调的该有的值"，我同意那是逐行归纳这条证法的必经点，但不是终点下界的必经点（见 c3）。
2. (a) 的派发分类若只列 K6 而没列 E6 地板以上与底丢上下文（`seen` 的 `B₀`），算漏。
