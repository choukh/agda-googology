## 回报原文

#### 0 一句话结论
`Ωt` 对正规层号的值单调这次只证到条件档。我编译证明了：在排中律之下，它与一条只讲树类型的命题 `Tp`（值低的合法层号上的每棵树，都被值高的合法层号上的某棵树按值支配）互相等价。下一个必经缺口就是 `Tp`。`Tp` 唯一难的情形在 Ω 结点：两层的槽位值相同而形状不同，要把一族树换到另一种分支类型下标上去。正规层号第一种定义（遗传式）在 `tw 2` 上被编译否定；换成第二种（共尾式），`tw n`、`Λ` 都有闭项证据。止损放宽后第 4 条用了约 290 行，没有越限；停在 `Tp`，因为我判断它在 600 行内证不出来（理由见第 3 节）。

#### 1 新文件、关键定理、档位
都在 `probes/OCF/Lean/`，都是 literate Agda，只导入树侧模块（`YiRWBlock/Ops/Path`、`YiVWVal`），不引用任何记号。

**`<仓库>/probes/OCF/Lean/YiRVLevel.lagda.md`（247 行）** 第 1 到 3 条。除另注外都是无前提的编译定理；排中律只在 `Cl` 里作参数。
- **层号值序**：`_≼ᴸ_`、`_≺ᴸ_` 重新定义，与 S1 的值序逐字相同。另有 `≺-irrefl`，以及 `Cl.Dk`（a ≼ b 或 b ≺ a，以排中律为参数）。
- **⊕ 的代数**，对应 |a ⊕ b| = |a| + |b| 的各个方向：
  - `≼⊕ˡ`：a ≼ a ⊕ b；`≼⊕ʳ`：b ≼ a ⊕ b；
  - `⊕-monoˡ`、`⊕-monoʳ`：两侧单调；`⊕-strictʳ`：右侧严格；
  - `⊕-pos`：0 ≺ b 推出 a ≺ a ⊕ b；`z⊕`：0 ⊕ b ≈ b；`⊕-assoc`：结合律，到 ≈。
- **读回 ↑ 的代数**：
  - `↑-strict : k ⊢ x ◃ y → ↑ k x ≺ᴸ ↑ k y`，即树的第一位置序送到层号的严格值序；
  - `↑-+ : ↑ k (x + y) ≈ᴸ ↑ k x ⊕ ↑ k y`。
- **正规 `Nm`（第二种定义）**：
  - 极限形状（ℕ 或 Ω）：每个孩子之下都有严格更高、而且正规的孩子；
  - 后继形状：对孩子不作要求。
  - 为何够用：值单调的证明只在右侧用 `Nm`，每遇到极限形状就换到更高的正规孩子，遇到后继形状就停。
  - 闭项证据：`Nm-tw n`、`Nm-Λ`、`Nm-⊕`；读回层号的构造子引理 `Nm-↑lim`、`Nm-↑up`；`Nm-↑Ωt-sc`（后继层 Ω 树的读回是正规的）。
- **第一种定义的否定**：`NmH` 是 N1 原文的遗传式正规（ℕ 极限孩子严格增，Ω 孩子无最大元，对一切孩子遗传）。`¬NmH-tw2 : NmH (tw 2) → ⊥`，原因是孩子 `tw 1 ⊕ ↑ dg₁` 的孩子全是 `tw 1`。
- **读回层号一般不正规**：`¬Nm-↑dg`。合法树 `dg` 的读回就是 N1 的退化层号 `Dg`。
- **类型界**：`tb↑ : ↑ ℓ x ≺ᴸ ↑ (sc ℓ) (proj₁ (Ωt (sc ℓ)))`，其中 `sc ℓ = nd sS (λ _ → ℓ)` 是 ℓ 的后继层号。

**`<仓库>/probes/OCF/Lean/YiRVOmega.lagda.md`（201 行）** 第 4 条。
- **类型界的值版**（无前提）：`tbV : W.suc (val ℓ x) ≼ val (sc ℓ) (Ωt (sc ℓ))`。
- **条件 `Tp`**，即值支配：
  `Tp = ∀ {a a′} → Ok a → Ok a′ → a ≼ᴸ a′ → (x : Tr a) → Σ (Tr a′) λ x′ → val a x ≼ val a′ x′`。
- **一般类型界 `K`**（条件 `Tp`）：右侧 ℓ′ 合法且正规，左侧 j 合法且 j ≺ᴸ ℓ′，则对 j 层上的每棵树 x，`W.suc (val j x) ≼ val ℓ′ (Ωt ℓ′)`。
- **值单调 `Mono.M`**（条件：排中律 + `Tp`）：ℓ、ℓ′ 都合法，ℓ′ 正规，ℓ ≼ᴸ ℓ′，则 `val ℓ (Ωt ℓ) ≼ val ℓ′ (Ωt ℓ′)`。左侧不需要正规。
- **同值同值 `Mono.M≈`**（同一条件）：两侧都正规、层号同值时，`Ωt` 同值。
- **反方向 `nec : OmMono → Tp`**（无前提）：只用后继层号上的单调就推出 `Tp`。连同 `suf : LEM → Tp → OmMono`，在排中律之下两者等价。
- **难点只在 Ω 结点**：`Reg` 是说 Ω 结点上以分支类型为下标、取值在高层的一族树，在高层里有一棵按值支配全族的树。`tpR : Reg → Tp` 是编译定理；零、后继、ℕ 极限、嵌入四种情形都不需要 `Reg`。对角情形 `regSelf`（a′ 就是 a）无前提成立。

**`<仓库>/probes/OCF/Lean/YiRVTpEdge.lagda.md`（92 行）** `Tp` 的两条边界，都是无前提的编译定理。
- `TpPath`：有语法路径 `k ≤ ℓ` 时，`Tr k` 被 `Tr ℓ` 按值支配。
- `¬TpNoOk`：去掉 `Ok`，值支配可以被否定。反例层号是 `Bg = nd (sΩ (sc zero)) (λ _ → zero)`，它与 `sc zero` 同值，但它的 Ω 结点能对 `Tr (sc zero)` 全体取上确界。所以 `Tp` 讲的是树类型的大小，不只是值；前提里的 `Ok` 去不掉。

#### 3 对下一步的意义
- **A 的 `lv<` 情形**：它要的 "类型界 + `Ωt` 按值单调" 现在都写成了以 `Tp` 为条件的定理（`K`、`M`、`M≈`）。N1 要求底族 B♯ 只依赖值，这一点由 `M≈` 在 `Nm` 层号上给出。N1 的 `shape-matters` 与这里一致：`Dg` 不正规，而 `M` 只要求右侧正规。
- **下一个必经缺口**：带 `Ok` 的 `Tp`，等价地说就是 `Ωt` 的值单调本身。按 `tpR`，它的位置在 `Reg` 的 Ω 结点情形：值低层的一个槽位 b 与值高层的槽位 b′ 值可比、形状不同，要把以 `Tr b` 为下标的树族改成以 `Tr b′` 为下标。
- **我判断 600 行内做不出 `Reg` 的理由**（判断，没有编译）：只要求值的上界还不够，需要 `Tr b′` 到 `Tr b` 的真正满射。而按结构定义的映射 r 与截面 s 之间的 `r (s z) ≡ z` 要用函数外延；ℕ 极限还带相邻证明 `Lt`，也要相等。即便是 `sc zero` 对 `nd sL (λ _ → zero)` 这样最简单的同值异形一对，也会碰到这两点。可选的出路有三条：
  1. Funext 作验收前提（标 "条件"），再构造单射的搬运；
  2. 只在路径相关的层号对上用 `Tp`（`TpPath` 已闭），但 `lv<` 里的 ⟦u⟧ 与 ⟦v⟧ 一般没有路径，我判断不够；
  3. 先对一个具体的同值异形对试构造或否定 `Reg`。
- **剩余距离**：`Tp` 是不是真的成立都还未判，`¬TpNoOk` 只说明 `Ok` 必不可少。我判断它在 ZFC（有选择公理）里成立，只有排中律时不明。
- **翻译账**：本路不引用记号，`Nm` 与 `Tp` 都由树侧的需要逼出，只在验收层，不改定义。
