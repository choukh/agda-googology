##### `YiNMName.lagda.md`（223 行）：命名关系写得出，第一种写法即通过
- `Nmd ℓ o ac x a = NF a × Vl × Hd`，对层号的 `Acc _≺ᴸ_` 与树递归，是函数不是数据类型，所以没有正性问题。
  - (V) `Vl`：`↑ ℓ x ≈ᴸ sv ⟦a⟧`。
  - (H) `Hd` 五行：零；后继（`cof a ≡ c1`，前驱有名字）；ℕ 极限（各项名 `G n`，低于 a，在 `fsn a` 里共尾）；结点（槽位层 `LvN` 名为 κ，函数 F，`fsT a η ≤ F η`，`F η < a`）；嵌入（`a ≡ a₁ ∔ a₂`）。
- `LvN ℓ ν = (ℓ ≈ᴸ lev ν) × Nm ℓ`。
- 陈述：`AStmt`；`BRow D ℓ o x`，其中 D 是底族被问到的层号的域。
  - 加 D 的理由【纸】：`LvN` 只按值与正规，不保证 ℕ 极限层号的孩子有名字；"对一切 `LvN` 层号底族都有名字"很可能不可满足，会让 B 空真。N1 原文的层号命名有同一问题。
- 【编】`zeroRow : BRow D ℓ o zero`，无额外前提。
- 【编，条件】`sucRow : AddRep → BRow D ℓ o x → BRow D ℓ o (suc x)`。
  - `AddRep`：名为主项 P 的树自加 n 次，名为 P 重复 n+1 次。未证；只有 n = 0 是恒等（`addRep₀`）。
  - (V) 是真证出来的（`⟦sucT⟧` 加 `↑-iter`）；(H) 取 G n = ψ_u(c)·(n+1)。
  - 标准形前提的传递用了记号侧的 `Gtri`、`T-pred`（`nfψ-pred`）。
- 只陈述、未证：`NodeRow`、`KeepRow`、`ChainRow`、`LimRow`、`UpRow`。【编】`node-split : KeepRow → ChainRow → NodeRow`。

##### `YiNMAbsorb.lagda.md`（187 行）：反例
记 `E⁺` 为朝第 0 层折 `Ωt one` 的输出（ψ₀(Ω₁)，值 ε₀），`E′` 是它嵌进 `one` 层，`T* = E′ + Ωt one`（结点 c ↦ ε₀ + (c+1)）。
- 【编】`absorbed : ↑ one T* ≈ᴸ ↑ one (Ωt one)`：上下文 ε₀ 被吸收，两棵树严格值相同。
- 【编】`absorb-fails : ↑ zero E⁺ ≺ᴸ ↑ zero out`：朝第 0 层折 `T*` 的输出严格高于折 `Ωt one` 的输出。链的第 0 项已是（朝 0 折 ε₀）·ω。
- 【编】`model-E`（`refl`）：项模型里 ψ₀(Ω₁) 的严格值就是 `E⁺` 的。
- 【编】`ctx₀ : CtxN D₀ B♯ [] []`：域只有第 0 层时底族的前提是定理（用 `lev-nz`：非空项的层号非零）。
- 【编，条件】`B-false : Nmd one o₁ (wfL one) T* Ω₁ᵗ → BRow D₀ one o₁ T* → ⊥`。
  - 唯一前提"`T*` 名为 Ω₁"只有纸面依据：结点一行取 κ = 0，F(η) = ε₀ ∔ (η+1)，夹逼 η ≤ F(η) < Ω₁ 成立；分支由嵌入一行命名。
  - 这个纸面依据本身要用"`E` 名为 ψ₀(Ω₁)"，即 B 在根上成立，以及项模型在可数和上的值是序数和。所以准确的说法是：N1 的 B 在 `Ωt one` 与 `T*` 上不能同时成立。
- 【编】`¬◁ : Trian [] ψ₀Ω₁ Ω₁ᵗ → ⊥`：ε₀ 对 Ω₁ 不满足记号侧的 ◁。

##### 纸面部分

**反例的机制【纸】。** 链的第一步名字应是 ψ₀(ε₀+1)，它不是标准形（G₀ 里有 Ω₁ > ε₀+1），B 的归纳假设用不上，树的值随之偏高。直接的嵌入 `up`（左 ε₀，孩子 `Ωt one`）同样是反例，所以嵌入一行也要加条件。

**修正版走链行【纸，不完整】。** 把结点一行的 `F η < a` 换成 `Trian η (F η) a`，并要求 ψ_u(K) 是标准形。记 K∔a = K′++a，γ′₀ = 0，γ′_{n+1} = ψ_κ(c_n)，c_n = K∔F(γ′_n)。
- 已在纸面证到：
  - 一切 c_n 使 ψ_u(c_n)、ψ_κ(c_n) 是标准形。对 n 归纳 G_u(γ′_n) < K′++F(γ′_n)，用 `T-cons`、`Gtri`、`hZ0`/`EboLeanBach.bach`、`EboBach.below`。
  - 共尾：γ_n ≤ γ′_{n+1}，所以 ψ_u(K∔a)[n] ≤ ψ_u(c_{n+1})。上界由 `ar<`。
  - 这两条对"K 被 a 吸收而不被 F(η) 吸收"同样成立，所以吸收不需要单独的引理，它由夹逼吸收掉。
- 没有核：部分和的命名（树加法封闭，与 `AddRep` 同族）；输出各项对 ψ_u(K∔a) 的 `Trian`（链带上下文时 `T-case4` 的类比）。

**Λ 行【纸】。** K = Ω_{ν_{n-1}}，a = Ω_{ν_n}，F(η) = Ω_{ν_{n-1}∔η}。ν_m 的 G 集只有 0，所以标准形条件与 `Trian` 都平凡成立。链名是 0，ψ_κ(Ω_κ·2)，ψ_κ(Ω_{γ′_m})，上确界与无上下文时相同。以 B 在更小实例上成立为前提。
