#### 1. 证明骨架与引理清单

##### 1.1 本轮编译的对象【编，`S1Sharp`】

- **层号的值序** `_≼ᴸ_`、`_≺ᴸ_`：|zero| = 0，|nd s h| = sup(|h c| + 1)。自反、传递、良基（`wfL`）无前提；二分 `Dk`（a ≼ b 或 b ≺ a）条件于排中律。
- **`path→≼`、`posLt`**：有路径则值不高；槽位层严格低于本层（用 `Ok`）。
- **`slot♯`**：严格低于 ℓ 的每个层号值，ℓ 里都有同值的槽位（条件）。
- **换型 `τ`**：值不高的层号的树搬进值不低的层号，槽位按值选，分支反向换型；带第一位置单调 `τm`。对源层号的 `Acc` 递归。
- **`kp♯`**：只看值。槽位层严格低于目标层就保留，否则走链。
- **折叠 `ψ♯` 与 `mono♯`**：五行（零、后继、ℕ 极限、结点、嵌入）。目标层 j 任意，不带路径；底族对一切层号给值。嵌入行逐字是 "进孩子层"（`up-row`，`refl`），不比较孩子，没有回退行，没有上折行，没有 `seen`。
- 闭项 `tw♯ n`、`EBO♯`。

ψ♯ 的值本轮没有算，也没有任何关于它的值定理。

##### 1.2 到 EBO 的骨架（沿已有出口 `YiAbsGEbo.ebo-end`）

出口只要 `Leaf`、`Lift`、`LowKeep`、`Base`、`Keel`。关系 R 是接口的字段，可以经典地选。对 ψ♯，`LowKeep` 按 R 的生成规则分情形【纸】：

| 情形 | 要用的 | 状态 |
|---|---|---|
| Zero | 底不高于输出（`mono♯` 加 `z◃`），`Bd` | 纸面成立 |
| Succ | "R 对树加法封闭"；参照恒等式 ψ_j(K⊕a)[n] = ψ_j(K⊕pred a)·(n+1) | 纸面成立，恒等式要对 `E.fsn` 核 |

| Node，两边判定不一致 | 没有规则可用 | **缺口** |

**缺口的精确陈述。** 树侧按实际的值判 |槽位层| < |目标层|，参照侧按下标判 κ < ν。R 只是下界关系时，被读成层号的树（`lift k x`）的值可以高于参照下标，两边的判定就可能不同。两种不一致都救不回来【纸】：
- 参照保留、树走链：就是已编译的 `unkept→¬low` 那一类。
- 参照走链、树保留：要 "任意分支不高于结点" 的规则，它对折叠不保持（折叠对分支不按值单调，`no-mon`）。

我试过加一条 "Ω 余尾的上确界规则"（一切代入都不高于同一棵树则本项不高于它）。它被 `LowKeep` 保持【纸】，但推不出链点对任意小参照项的关系，补不上这个缺口。

所以要的是两边的不变式：喂作层号下标的树，值恰好等于参照项。这等于要 ψ♯ 的上界方向。

#### 2. 比较函数的问题与改法

##### 2.1 `kp★` 在哪里会错【纸】

对层号的值 |·| 逐子句核：`kp★` 的每一行在子调用正确时都正确，唯一例外是 K6 行里比较缺项的分支。嵌入行同理：唯一的损失是缺项时的回退。所以 ψ★ 的正确性恰好归结为 "该问的格上 `cmpᴵ` 不缺项"。

##### 2.2 五个问题

1. **问得比需要的多**【纸，读定义】。`cmpᴵ h c c′` 比较两个孩子的层号，语义上只需要 "目标 j 到嵌入孩子有没有路径"。目标是第 0 层或在地板以下时，这条路径总存在（`z≤`、`lift`），`cmpᴵ` 却仍可能缺项。
2. **任意孩子对都被问到**【纸】。下标侧结点被保留时，输出对一切分支 c 逐个折叠，每个 c 都与目标孩子 c′ 比较。只看这一个结点的上确界时无妨（c′ + d 一族可比且共尾），但输出树的坏分支是回退值。
3. **链上被问到的孩子对在值上该可比，字面上没有路径**【纸，路径不存在是判】。上一条的保留结点以后被搬进更外层，在朝第 0 层折叠时走链，链点 e 被喂进它的分支，分支里就是 `cmpᴵ h e c′`。c′ 是外层的回灌值，e 是内层的回灌值。产生 "同值不同树" 的三个来源：
   - 部分和：链的极限里是 G(z₀)+…+G(z_m)，回灌值是 G(z_m) 本身，后者不是前者的字面子树。
   - 同一棵树经不同路径折出的树不同：经 `ink`/`inu` 直接进孩子，经 `inc` 走比较、嵌入或回退。
   - `⊞` 回退行。

   候选格（塔第 2 项里）：tw 1 上，目标是孩子 γ 里一个值大于 0 的子层 λ，嵌入孩子是内层链点 e，|e| ≥ |λ|，但 e 里只有 γ 的同值异形拷贝。此时回退给 Ω_λ 加一个可数量，该有的是 ψ_λ(Ω_e)。我没有把 "没有路径" 编成否定定理，所以写 "未走通"，不写 ψ★ 到不了。
4. **排中律选的路径是任意的**【纸】。`lem (h c ≤ h c)` 可以给任何路径，不必是 `self`（例如 `inc tt self` 与 `inu (λ _ → self)` 都是 one ≤ two）。不开 K 时 "a ≤ a 的路径只有 `self`" 证不出命题相等，所以 P4 的 T0′ 要换成 "结果与路径无关（在关系意义下）"。
5. **`self` 要层号命题相等**【纸】。两个逐点相等而非定义相等的层号之间，没有 Funext 就证不出 `self`，排中律可以答 "没有路径"。要么加 Funext 作参数，要么不依赖路径。

##### 2.3 第四条通道（主审中途转告的 `base-inc`、`base-ink`）

嵌入行交给孩子层的底族是 "左项 x 经 `inc c u` 朝 i 层的折叠"。按上面的核法【纸】：
- i 的值大于下标层时，左项里的下标侧结点被保留，落进问题 2（任意孩子对）。
- i 在下标层或以下时走链，链点与 c 比较，落进问题 1：路径 i ≤ h c₁ 总存在，`cmpᴵ` 仍可能缺项而回退。回退把上下文丢掉，底是默认值时值不变，底非平凡时是损失。

所以 "`cmpᴵ` 在可达格上处处正确" 在这条通道上同样不成立。ψ♯ 的底族调用不带路径，不受影响。

##### 2.4 改法

简报设想的 "经典地按值比较，再取路径" 不够：没有路径时无路径可取。要的是沿值相等搬运，即 `τ`。改后的 ψ♯ 仍是合法的验收侧定义【编】。它比 ψ★ 少四行（上折行、`sL` 的 `way` 行、`sΩ` 的比较行、回退行）。

对简报第 2 问的直接回答：(b5) 那类孩子对在可达格上会出现（问题 2 是纸面确定的；问题 3 是纸面加判断）。

#### 3. `seen` 的两种底谁对
