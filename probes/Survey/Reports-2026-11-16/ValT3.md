##### 1. 新文件、关键定理、档位
新文件只有一个：`<仓库>/probes/OCF/Align/EboBach.lagda.md`。共 386 行，其中非空代码 298 行，文首 2 行。只导入 `EboLeanDef`、`EBO`（`pred-suc`、`<-sucT`、`[]<sucT`）和 `EboLeanBase`。以下各条都是【编译定理】，无前提。

- `bach : NF s → s <ᵀ t → (cof t ≡ c1 → s ≤ᵀ pred t) × (cof t ≡ cω → Σ n. s ≤ᵀ fsn t n) × (∀ {κ} → cof t ≡ cΩ κ → Σ η. NF η × η <ᵀ Ωs κ × s ≤ᵀ fsT t η)`。这就是简报的陈述，t 不必是标准形。
- 严格形式（各支分开写）：
  - `bach-suc`：t 是后继时 s ≤ pred t，连 NF 也不要。
  - `bach-ω`：余尾 ω 时有 n 使 s <ᵀ fsn t n。
  - `bach-Ω`：余尾 Ω_{κ+1} 时有标准形 η < Ω_{κ+1} 使 s <ᵀ fsT t η。在正则叶上 η 取 s+1。
  - `bach-0`：t 为零时 s < t 不成立。
- T3a 的情形：和（尾项递归）、规则 4（`rep<`：s 降序且首项 ≤ x 时 s < x·(|s|+1)）、规则 5ω、规则 5Ω、Ω 正则叶、奇异叶（ω 与 Ω 两种）。
- T3b，规则 6 由两条引理组成：
  - `below : cof β ≡ cΩ ν → NF α → α <ᵀ β → Small ν p α → α <ᵀ fsT β (p ∷ [])`。`Small ν p α` 的意思是：α 中下标 > ν 的主项继续拆进下标与参数，拆到下标 ≤ ν 的主项（ν-成分）为止，这些成分都 <ᴾ p。它是 Buchholz 的 "K_ν α < ξ" 的句法版，ξ 取单个主项。这条引理对 β 不要标准形。
  - `Chain.R`（模块 `Chain b be`，其中 `be : cof b ≡ cΩ ν`）：若 c 是标准形且 G_ν(c) 的元素都 < b，则有 N 使 `Small ν (pγ N) c`，pγ N 是 γ_N 的唯一主项。下标恰为 ν 的成分 ψ_ν(d) 满足 d ∈ G_ν(c)，所以 d < b；对 d 递归，再用 `below` 得 d < b[γ_M]，于是 ψ_ν(d) < γ_{M+1}。各成分的 N 取最大值，这一步要用 `pγ-mono`。
  - `Chain.rule6`：u ≤ ν，ψ_u(c) 是标准形，c < b，则有 N 使 c <ᵀ fsT b (γT b ν N)。证明由标准形条件 G_u(c) < c 和 `G-mono` 得到 G_ν(c) < b，再接 `R` 与 `below`。
  - 这与 N1 的纸面论证形状一致，只差一处：N1 写 "对 d 归纳"，这里是对 c 的结构递归，前提是 "G_ν(c) < b"，不再带 G_u(c) < c。
- 副产品：
  - `fsT-mono`：余尾 Ω 时 fsT β 按下标严格单调，不要标准形。
  - `Chain.γ-step`、`pγ-mono`：γ-链严格递增。
  - `nf-sucT`：s+1 保持标准形。
  - `cof-nz`：非空项的余尾不是零。

核对现行定义（对照代码）：`fsn` 用的是 `EboLeanDef` 的裸值版，`EboLeanCmp.fsn≡ : fsn t n ≡ EBO.fsn t n` 是已编译定理，所以结论对 EBO 的 `fsn` 同样成立。`fsT`、`γT` 直接取自 EBO：γ_0 = Ω_ν = ψ_ν(0)，γ_{k+1} = ψ_ν(b[γ_k])。规则 6 的触发条件是 `cmpᵀ (ν+1) u ≡ gt`，即 u ≤ ν。各哑值分支都由余尾等式排除：`fsn0 c1`、`fsnc lt/eq`、`fsT₊ c0/c1/cω`、`fsTc gt`。其中 `fsn₊ c0` 要用 `cof-nz` 排除。
