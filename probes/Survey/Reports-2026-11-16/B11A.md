#### 做法（简报第 1 到 3 步，全部按纸面通过，没有额外前提）

**第 1 步：描述侧。** `B11PrefixGen.Desc (P) (e) (ie : InflE e) (bd : Ld (ψ P) (sE e Nx)) (bx : Lx (ψ P) (sh e))` 是一个模块，参数依次是前缀 P、它的指数影子 e、e 的膨胀性和两个基例。其中 `ψ P` 指 `ψ zero id P`，即 `q m L.zero`。模块里的 `LdQ`、`LxQ` 按输入的 `Lx X h` 归纳，目标与简报一致：
- `Ld (QB X) (sE (e ⨾ h) Nx)`
- `Lx (QB X) (sh (e ⨾ h))`

这里 `QB X = ψ zero id (P + up zero X)`，在定义上就等于 `q m X`。六个构造子的证明与 `B8PairLevel` 逐条对应。只有两处改动：
- 用到 `inflΩ₂` 的地方换成 `ie`。
- 零层尾部 `LdP`、`LxP` 的零号行（`z≼`）换成 `bd`、`bx`。

原因是 `add` 对第三个参数递归，`ψ` 的穿透分支（`<ᴵ-dec (suc zero) zero`）也不看 P 的形状。所以这些证明除了基例以外完全不碰 P。

**第 2 步：沿 m 升站。** 内部不变量是 `Inv m`，记录三项：`infl : InflE (prefix m)`，`bd : Ld (q m 0) (sE (prefix m) Nx)`，`bx : Lx (q m 0) (sh (prefix m))`。
- 固定 m 后，`chain m I n : Lx (y m n) (track (prefix m) n)` 从 `Lx-Ω₁` 起逐次用 `LxQ` 得到。
- `lowerI` 是对 `chain` 用 `LdQ` 得到的。
- `inv 0` 取自 `inflΩ₂ / Ld-base / Lx-base`。
- `inv (suc m)` 的三项：
  - `Infl-lC _ (Infl-⨾ (prefix m) Ω̂ (infl (inv m)) Infl-Ω̂)`，即取零号分支；
  - `base-d m (stage-of m (inv m))`；
  - `base-x m (λ n → chain m (inv m) (suc n))`。

不需要用 `LeE` 按投影搬运。

**第 3 步：语义侧。** `B11PrefixGen.Sem (P)` 是共用的参数化定理：

```agda
sem : Ld D d → (a c : T₀) → ψ⁰ P ≼ a → ψ⁰ P ≼ c → ψ⁰ (P + up zero D) ≼ d a c
```

它与 `L2-sem / ch2 / L2u` 同形，并复用 `B9InnerLevel2.ψ≼ψ⁰`。它对 P **没有任何前提**。在同一个 P 上，两处 `ψ⁰ P` 的下界由 `ha` 和 `hc` 提供：`Lz` 和零层尾部 `Pu` 用 `ha`，`Li` 的链 `ch` 用 `hc`。

**交付项：**
- `stages m = stage-of m (inv m)`。
- 闭实例 `stage1 = stages 1` 和 `stage2 = stages 2`，它们只是一般定理的实例，不是单独的测试。
- `new-x₁ = bx (inv 1)`，与公共模块的 `first-new-x` 同型。`check-first` 只核对了类型一致，没有比较两个证明项。

#### 三档区分

- **编译定理：** `stages`（对一切 m）、`Desc.LdQ/LxQ`（对任意 P 及满足前提的 e）、`Sem.sem`（对任意 P）。`Desc` 的前提有实例：每个 m 都由 `inv m` 实际给出。
- **有限测试：** 无。
- **判断：** 第 4 步的未闭合情形没有出现，所以没有反例要交。至于合成后 Goal 能否闭合，要看 B11B 能否在 Ψ₃ 的实际输出上消费 `Stage.lower` 和 `Stage.sem`，本路没有验证。
