## 回报原文

#### V1 回报：值支配 `Tp` 的 Ω 结点情形

##### 0 结论
一般的 `Reg` 没有证出来，所以第 3 步（去掉 `Tp` 前提的值单调）没有做。已编译的结果有两项。
- **无前提**：`Reg` 归结为一个更具体的条件：对每个合法、值有序的层号对，低层的每个槽位在高层都有一个槽位，后者的分支树类型满射到前者的（`PS`）。
- **条件（函数外延）**：在一对合法、同值，但没有同层号槽位的层号上，造出了这个满射。

下一个必经缺口：子层号映射不单射时，要把几个孩子的树编码进同一个孩子。最小的未做实例是 `Tr (sc zero) ↠ Tr (nd sL (λ _ → zero))`。

##### 1 新文件、关键定理、档位

**`probes/OCF/Lean/YiQNReg.lagda.md`**（198 行，编译定理，无前提，不用排中律）
- `PS a a′ = (p : Pos a) → Σ (Pos a′) λ p′ → Surj (Tr (at a′ p′)) (Tr (at a p))`，其中 `Surj B A = Σ (B → A) λ ρ → ∀ z → Σ B λ u → ρ u ≡ z`。
- `TpS : PS a a′ → (x : Tr a) → Σ (Tr a′) λ x′ → val a x ≼ val a′ x′`。
  - 不需要 `Ok`，也不需要 `a ≼ᴸ a′`。
  - 在嵌入（`up`）结点上，不像 `tpR` 那样换到对面的孩子层，而是把孩子树直接搬到 a′ 里相加：`X + Y`，配 `val-+`。这样递归只需要 `PS-ch`：子层号的槽位就是 a 的槽位。
- `regS : PS a a′ → RegAt a a′`。做法：取 `Ω p′ (φ ∘ fromBr ∘ ρ ∘ toBr)`，见证由满射给出。另有 `toBr` 与 `ft`、`tf`，说明分支类型与槽位层号的树类型互逆。
- **接口**：
  - `regPS : (∀ {a a′} → Ok a → Ok a′ → a ≼ᴸ a′ → PS a a′) → YiRVOmega.Reg`
  - `tpPS : 同一前提 → YiRVOmega.Tp`
- **路径情形**：
  - `PP a a′`：a 的每个槽位层号有一条语法路径 `≤` 通到 a′ 的某个槽位层号。
  - 在这个条件下，沿路径往下走（`reach`、`deep`）能在 a′ 里找到层号恰好相等的槽位。于是 `PP→PE→PS`，满射取 `subst Tr`。全程无前提，不需要单射。
- **第 1 步的具体同值异形对**：`sc zero` 与 `w₁ = nd sL (λ _ → zero)`。两个方向都有同层号槽位（`pe₁`、`pe₁′`），所以 `tp₁`、`tp₁′` 无前提成立。
- **上一层的对**：`sc (sc zero)` 与 `sc w₁`。
  - 两者都合法（`ok₂`、`ok₂′`），且同值（`le₂`、`le₂′`）。
  - 但 `¬PE₂ : PE (sc (sc zero)) (sc w₁) → ⊥`，也就是没有同层号的槽位。

**`probes/OCF/Lean/YiQNCollapse.lagda.md`**（168 行，条件定理，条件为 `FunextE`）
- 前提：`FunextE = ∀ {A B f g} (h : ∀ x → f x ≡ g x) → Σ (f ≡ g) λ E → ∀ x → cong (λ k → k x) E ≡ h x`，即带计算律的函数外延，作模块参数。
  - 可满足的理由（纸面）：立方类型论里 `funExt` 满足 `happly (funExt h) ≡ h`。
  - 本路没用排中律。
- 截面 `σ : Tr (sc zero) → Tr w₁`：槽位与孩子都送到 0 号。
- 收拢 `ρ : Tr w₁ → Tr (sc zero)`：孩子 n 都收到 tt。ρ 按构造子定义，保持第一位置序。
- `RId : ρ (σ z) ≡ z`，与 `coh` 互递归。`coh` 说明相邻证明经 `ρm ∘ σm` 搬运后不变。
  - ℕ 极限和 Ω 结点的相等，连同 `◃l`、`◃w` 的搬运，用 `FunextE`（`limEq`、`Ωeq`）。
  - 其余情形是无前提的 J 引理（`Ls`、`Lu`、`Lc`、`Lt3`）。
- 结果：
  - `surj₁ : Surj (Tr w₁) (Tr (sc zero))`
  - `ps₂ : PS (sc (sc zero)) (sc w₁)`
  - `tp₂`：`sc (sc zero)` 的每棵树被 `sc w₁` 的某棵树按值支配（条件：`FunextE`）。

##### 3 对下一步的意义
- **缺口的位置**：`Reg`（也就是 `Tp`，也就是值单调）现在等价于一个只关于树类型的命题：对合法的值有序层号对，给出分支树类型之间的满射 `PS`。整个缺口已不涉及值。
  - 剩余距离：一般层号对之间的满射构造。
- **两种写法各覆盖了什么**：
  - 同层号/路径：无前提。
  - 按构造子收拢加函数外延：覆盖子层号映射单射、孩子可收拢的情形。
  - 上面两类都做不出来的最小实例是反方向那一对：`sc w₁` 与 `sc (sc zero)`，要 `Tr (sc zero) ↠ Tr w₁`。
  - 我的纸面判断（未编译）：
    - 按构造子定义、保持第一位置序的收拢在这一对上不存在。原因是 `Tr zero` 的非零树在第一位置序下连通，所以收拢后的孩子编号只能取常值。
    - 只能换成 "带标签的单射截面 + 排中律取逆"。孩子编号 n 和槽位编号都要编码进唯一的孩子 `zero` 的树里，例如 `up (σ x) tt (A_n + y)`，A_n 两两不同；Ω 结点用有限的标签树区分。
    - 单射性要用函数外延，还要相邻证明 `σm` 的单射性。排中律经 Hedberg 推出 UIP，可以缓解无 K 下的合一问题。
  - 我估计光这一对就要 500 到 800 行。一般情形还要对任意形状给位置映射与孩子映射（下标层号不是结构子项，递归要按值良基）。所以按止损停在这里。
- **没有反例**：`Ok` 之下没有编出 `Tp` 的反例，`lv<` 情形不受动摇。
- **另一条纸面判断**：满射不能取自值严格更低的槽位，因为 Ω 结点给出 Cantor 式的基数增长。所以 `PS` 只能用同值或更高值的槽位。
- **翻译账**：本路不引用记号。`PS` 和满射由 Ω 结点的值比较逼出，只在验收层，不改定义。
