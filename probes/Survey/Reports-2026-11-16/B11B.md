#### 2. 单步的结构（与简报逐项对照）

**不变量.** `InvR m R v` 含三个字段：
- `sv : ψ⁰(ll m) ≼ read v`；
- `sz : ψ⁰(ll m) ≼ read (R zero zpath)`；
- `ss : Str (prefix m) R`，其中 `Str` = `Real C P`、`Real C Ω̂`、`SumR C Nx`、`Ω₁t ◃ C`。

`Inv m = InvR m (state m) (value m)`。首站各项分别来自 `Ω₂-v₁`、`Ω₂-cz`、`Real-cΩ₂`、`Real-cΩ₁`、`SumR-cNx` 与 `chain-step 0`。

**`Inner P R`：一轮 G 内沿 F 的第 n 个状态.**
- 携带 `Real (cn n) (track P n)` 与 `Str P`。
- `Real-z1`：原始第 1 项实现 `P ⨾ track P n`。左槽取前缀 P，底槽取 track。
- `SumR-z2`：原始第 2 项供被加项消费，描述是 `sE (P ⨾ track P n) Nx`。
- 分支 1 是 `U n 1 ◃ cn (suc n)`（`◃l 1`），把 `track P (suc n)` 传给下一次 F。
- 分支 0 是 `first-exp`（`◃l 0`），把第 1 项的指数传入这次 F 更新的结果。

**`Up`：新前缀.**
- `kid≡`：kid 的槽等于 F 第 n+1 次的槽。由 `O.project-value (suc n)` 与新引理 `itV-self` 合成，后者对 n 归纳，不是对所有 n 的 refl。
- `Real-lim` 作用在 `O.child` 的实际分支上，得到 `prefix (suc m)`。
- 再沿 `child-in-G` 用 `Real-up`，落到 `c₁ (state (suc m))`。
- Ω₁ 指数、Nx 与 Ω₁ 的结构步进沿 G 的 `inf` 保持。

**`Exit m Sg R H w β`：零层值界，对任意路径 w 和底 β.**
- 每个 n 实例化 `WKGen.Main ok₂ (Rs n) w (vv n)`，用 `Stage.sem`、SumR 与 `Ψg-ge _ 2`。
- 已核为 refl：链点 `zs ≡ zz`，`Ψg ≡ vv (suc n)`，链底 `B′ zero (inc tt self) ≡ Rs n zero zpath`。
- 零号参照项用 Ω₁ 种子 `Match.add-w seed`，经 `Ω₁ ◃ C ◃e z 0 2` 上传。后继项用 `Stage.lower n` 与 `SumR-z2`。
- 逐项经 `in-child`、`child-in-G` 提升，`l≼` 合并，与 `next-shape` 的展开一致。
- 两条路径分别取 `(w2, value m)` 与 `(zpath, state m zero zpath)`。`wd` 随路径取。零层上不需要 itV 与 itS 的相等，底链 vv 与链底 Rs 分别估界。

#### 4. 换站实例与反查（编译定理，无前提）

**换站实例.** 即第 1 节的 `inv1` 一组。

**低分支比较.**
- `low m : ψ⁰(ll m) ≼ ψ⁰(ll (suc m))`。
- `strict m : suc ψ⁰(ll m) ≼ ψ⁰(ll (suc m))`。

两者都取参照的具体低分支：先取 Ω₁ 的第 0 支，得 ψ⁰(suc (ll m)) 的迭代，再取第 1 项和第 2 项。由此对一切 m 有 `Ω₂-low m : ψ⁰ Ω₂ᴸ ≼ ψ⁰(ll m)`。

- `no-init m : ψ⁰(ll m) ≼ read (Ωt zero) → ⊥`，经既有的 `no-Ω₂≼1` 得到，对一切 m 成立。

**只更换槽位的值（`Slot R`）.** 底族 `Bh` 只把第 0 层槽换成 `Ωt zero`，第 1 层分量照旧。
- `slot-same`、`chain-same`（第 0 个状态的内链逐字相同）都是 refl。
- `keep`：Str 照样成立。
- `Mh`：`WKGen.Main` 的三个前提照样成立。
- 首先丢失的字段是 `sz`：`lost-sz`。
- 在第 1 站的真实状态上：`str1-kept` 与 `sv1-kept` 仍成立，`no-inv1-slot : InvR 1 S1.Bh (value 1) → ⊥`。

**在旧底族上重跑计算：未做.** 这里没有定理。纸面判断（未编译）：在 B₀ 上重跑 G，单步的第一个前提是 `Str.rP`，即 `Real (c₁ B₀) eΩ₂ = Real Ω₁t eΩ₂`。正反两向都没有编译过的结论，因此不写成否定。
