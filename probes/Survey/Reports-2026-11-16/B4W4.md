**1.1 统一的带框架代数（`W4Fold`）【编】**

*语境*
- `data Cx ℓ`：`nil` 是环境写法 `i ≤ ℓ`；`cons u X` 在语境 X 上加一个树框架 u 的写法分量，即 `⟦ cons u X ⟧ i = Tg u i × ⟦ X ⟧ i`。
- 延伸 `Mor X Y` 是一对映射：σ 把外层目标送进深语境，π 把深语境的目标忘回。配套有 `idM`、`_⊙_`、`chM`（加孩子分量）、`liftM`（把孩子分量推到延伸上）。

*各阶的载体*
- `Ca 0 = Op`。`Ca (suc n) X` 是在 X 的一切延伸上都有定义的严格膨胀变换（自然 op）。`Rn n` 是逐点序。
- `Ca`、`Rn` 对 n 互递归，用 Σ 写，不用 record，所以不触发正性检查。

*对 n 递归的通用件*
- `limC`/`limCUB`、`nodeC`/`nodeCUB`：结点的判定 `jd` 经 π 搬运，走链目标 `ch` 经 σ 搬运，到第 0 阶才形成 `node⁺`。
- `enter`：第 0 阶是 Op 的搬运，高阶就是限制。
- `upC`/`upC-inf`/`upC-mono`。

*树数据*
- `TD X mu` 有三个字段：树框架 `fr`，语境目标的树框架写法 `tv`，树框架目标在语境里的写法 `mk`。
- 配套 `trTD`（沿延伸搬运）、`chTD`/`chMT`（up 行加孩子分量，孩子树的写法取 `proj₁`）、`tdNil`。

*迭代子（互递归块）*
- `E`：第一阶，同 D1，只是换成语境。
- `It n`：对一切 n 同一条定义。
  - Ω 行：判定是 `kpT (fr T) o p (tv T t)`，走链目标是 `mk T (hereT …)`。
  - up 行：`upC n (down (fr T) c) (inj₂ ∘ tv T) (It x K G) (It (chTD T c) y (enter (Itᴺ x K)) (enter (It x K G)))`，即进孩子框架、从 E x K G 起迭代。
  - ex 行：转到 `It (suc n)`。
- 另有 `Itᴺ`、`Kₑ`、`Kb`；律 `Einf`、`Emono`、`Itinf`、`Itmono`。

*与简报写法的一处偏离*
- up 行的结果不是 D1 的 "出框架 R"，而是 `upC`：在底层先跑 A = `It x K G`，再在孩子语境里跑 R。
- 原因：从三阶起，对自然 op "出框架" 时，要比较 G 在 m 上和在推出延伸上的值（一种 "松弛自然性"），这在定义上不成立。
- 改成在底层复合后，膨胀律（`upC-inf`）与 ◃u 单调在定义上直接成立。
- 代价：二阶的值比 D1 的 E₂en 多先作用一次 A。按吸收 1+ω^y = ω^y 看是同值，这只是纸面判断，没有定理。

*fg-bare 的修法*
- 简报给的候选是 "树框架 ⊎ 元素框架" 的和。实际写成积：语境逐层加树框架分量，树判定只看 `tv`，元素只看忘回的写法。
- 效果与简报候选相同（判断）。膨胀律无害，已编译。
