#### B5A 回报：W4 跨孩子格上的 D-tail

##### 对纲领与目标意味着什么

- `D-tail` 已构造性证出，不用排中律，也不用函数外延，是编译定理。所以这一格不需要第 4 层的经典数学，第 3、4 项（排中律版、否定）都不必做。
- 这个结果的信息量很小。证明只用了一条自界：塔第 1 项层号下，孩子 c 层的 Ω 树折向第 0 层，记其输出为 Ψ c，则 Ψ c 按值不低于 c，即 ψ₀(Ω_c) ≥ c。
  - 右边是对一切零层树取上确界的 Ω 结点。左支 c 取右边的下标 Ψ c 就被支配，链条是 Ψ c ≼ shift 2 (Ψ c) ≼ Ψ (shift 2 (Ψ c))。
  - 这对任何按值膨胀的换号 ρ 都成立（`d-any`），与折叠强到什么程度无关。
- 所以 "跨孩子格只比上确界" 在 D 格是自动满足的。它没有给 W4 的折后值带来超过 "Ψ c ≥ c" 的下界，W4 仍没有 BTBO 或更高的下界。
- 纲领方面：没有引用记号，没有新增派发，没有改 W4、S1 和仓库的任何文件。

##### 对主审纸面判断的挑战

主审判断 D-tail 归结为 "ψ₀ 在规范输入 `Ωt (h₁ c)` 上随 c 按值单调"。这一判断不成立：D-tail 不需要单调，只需要上面的自界。

关于 "规范域上的跨层单调"，现状是：
- 后继一步 Ψ c ≼ Ψ (suc c) 对一切 c 成立，已编译。
- 极限的首支 Ψ (f 0) ≼ Ψ (lim f a) 已编译。
- 极限的其余支（n ≥ 1）和一般形未证，只写成了陈述。
- 卡住的机制（判断，未编译）：极限层的第 n 支在折叠里带着非标准的底族 `B'_{cum (n-1)}` 和非标准的底值 β。比较时需要 ψ 对底族和底值按值单调。Ω 结点不保留时，ψ 走对角，迭代项 `s` 依赖底族，这又要求 ψ 对树参数按值单调，而 `mono` 只给 ◃ 方向的单调。

##### 关键定理与档位

**编译定理（无条件）：**
- `d-tail : D-tail`：类型就是 `W4Local.D-tail`。
- `d-equiv : val lvl2 (Ω q₂ G₂) ≈ val lvl2 (Ω q₂ (λ c → G₂ (shift n2 c)))`：由 `d-tail` 和已有的 `d-back` 合成，两个结点按值互相支配。
- `d-any : (ρ : Tr zero → Tr zero) → (∀ x → val zero x ≼ val zero (ρ x)) → val lvl2 (Ω q₂ G₂) ≼ val lvl2 (Ω q₂ (λ c → G₂ (ρ c)))`
- `cof`：上面三条用的抽象引理。对任意前缀 A、任意自界的族 F、任意按值膨胀的 ρ，`Ω q₂ (λ c → A + ι lvl2 (F c)) ≼ Ω q₂ (λ c → A + ι lvl2 (F (ρ c)))`。
- `self-bound : (c : Tr zero) → val zero c ≼ val zero (Ψ c)`，其中 `Ψ c = proj₁ (ψ₀ (h₁ c) (proj₂ o₁ c) (proj₁ (Ωt (h₁ c))))`。
- `lb : (ℓ : L) (o : Ok ℓ) (B : Base ℓ) → PB ℓ B → (β : Tr⁺ zero) → lv ℓ ≼ val zero (proj₁ (ψ ℓ o B zero (z≤ ℓ) β (proj₁ (Ωt ℓ))))`
  - 这是自界的一般形，对一切层号、一切合法证明、一切非零底值成立。
  - `PB` 要求每个底值在 ◃ 的自反闭包里不低于该层的 Ω 树。`B₀` 以相等满足它。
  - `lv` 把层号读成零层值：后继加一，ℕ 极限取极限，Ω 形不计。
  - 后继层用链的第 1 项，经 `mono`、`ψsuc`、`add-dom`。ℕ 极限层逐项用归纳假设，底族条件沿 `mono` 传下去。
- `stepSS`：后继层的严格一步。
- `Ψ-step : (c : Tr zero) → val zero (Ψ c) ≼ val zero (Ψ (suc c))`
- `Ψ-lim0`：极限的首支。
- `d-one`：首个被跳过的非零分支 `G₂ (suc zero)`，用 "自然" 下标 1（换号后是 3），经 Ψ 1 ≼ Ψ 2 ≼ Ψ 3。
- 小工具：`pos`（零层正树 ≥ 1），`+≈₀`，`ι≈`，`+ι≈`，`+ι-mono`，`nextsuc`，`ψsuc`。

**只是定义的未证陈述：**
- `Ψ-lim-all`：极限的一切支。
- `Ψ-mono`：c ≼ d 推出 Ψ c ≼ Ψ d。
- 另有编译过的 `mono→lim : Ψ-mono → Ψ-lim-all`。

**判断：** 上面 "卡住的机制" 一段，以及 "D 格对折叠强度不敏感" 的读法。

##### 下一个必经缺口

- **位置。** D 格只比较两个 Ω 结点的上确界，现在已经按值相等。审计 §3 所说的 "尚须比较理想族与构造族" 没有被本结果触及，W1 的结点型跨孩子格（极限后继目标、外来目标）也没有。这两处的比较不是对不可数下标取上确界：它们落在只访问 ℕ 个对角分支的地方，或者要做跨块比较。所以自界这一招不能直接搬过去（判断）。
- **剩余距离。** 照审计 §3 的清单，这一格之后剩下：理想族与构造族的比较，结点型跨孩子格，回灌，跨块比较，各塔项统一的封闭，到 Λ 的下界。W4 的 BTBO 保底界（审计方案 D）也仍然没有。强度方面，本路只得到 ψ₀(Ω_c) ≥ c 这一条下界，没有 ψ₀(Ω_x) 形式的新强度结论。
