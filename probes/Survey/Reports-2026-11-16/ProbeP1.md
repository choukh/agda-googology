#### 0. 一句话结论

依据：

- 换基候选用 `seen` 把这个分量重建回来，剩下的损失只来自 K6。若下面 A4 的 "截断参照" 引理成立，每多一项塔就多出一层，终点不低于 EBO。这是纸面链条，不是证明。

#### 1. 要证的精确陈述（分台阶）

终点陈述与 `YiWREnd.ebo-end` 同形：`toL ET.EBO-tree′ ≼ K.readRW E`，E 取 `EBOᴮ`。前提是模块参数 `lem : (A : Set) → A ⊎ ¬ A`，结论标 "条件"。

- **A0 值的全序（本轮已做）。** 在排中律下，`YiVWVal` 的值 V 上任意两棵树可比，跨层也可比：`a ≼ b ⊎ b ≼ a`。【编】
- **A1 解除 LPO 型前提。** 由排中律证出 `YiVmConExact.Tri`（第 0 层上 a ≼ b 推出 b ≼ a 或 suc a ≼ b），再经 `tri→vm` 得到 `VMᴸ`（条件）。`YiLowNeg` 的 `EmbV`、`YiCompatDlLPO` 的 `Compat` 同样处理。【纸】
- **A2 精确域。** D_ex 是这样的调用集合：目标路径在 Ω 形状层号上不经过 `inc`，只用 `self`、`ink` 或 `inu`。陈述：在 D_ex 上，实际折叠与 Ψ* 的值互相 ≼；并且 D_ex 对递归调用封闭，回灌调用除外。
- **A3 理想折叠不低于参照。** Ψ*₀(`Ωt (tw n)`) 不低于参照 ψ₀(Ω_{tower n})。参照可取 `EboLean3Tree` 抽出的树；若在 Lean 里做，取集合论的 Buchholz ψ。
- **A4 截断参照（下一个必经缺口，只对换基候选）。**
  - 先定义 trunc(x)：x 里凡是 K6 该保留却走了链的结点（槽位层 e 低于目标层，分支取 `Tr e`，值与 Ω_{e+1} 共尾），都截成只取前 Ω_e 个分支。
  - 陈述：在某个读回域 D 上，Ψ^{BS}_j(x) ≽ Ψ*_j(trunc x)。
  - 证明需要折叠对分支参数的值单调，至少在 D 上成立。排中律不给这一条。
- **A5 截断在 Ω 形状层号上被吸收。** Ψ*₀(trunc(`Ωt (tw (n+1))`)) 不低于参照。理由：tw (n+1) 的 Ω 顶是对各孩子取上确界，孩子 c+1 截断之后不低于孩子 c。
- **A6 组装。** 对 n 归纳，再取 Λ 处的极限（`upperᴮ` 已有）。

#### 2. 经典侧的纸面计算（塔的第 1、2、3 项）

##### 2.1 损失只在哪里发生【纸】

我逐行读了 `YiRWFold`、`YiTBRow`、`YiBSFold`。只有 K6 与 E6 两处违反 "低于目标保留，同层或高于目标走链"：
- K6 连 c = c′ 的情形也不比较。
- E6 在主线上查 `tbᶻ`，只有字面为零的孩子有表项，其余回退成 "左项的折叠 ⊞ 孩子树折到第 0 层"。换基候选在这里走 `route`/`seen`。

其余各行在经典值上都与 Ψ* 一致：`way`、`kp` 的下标侧推进、`Up`、`inu`、`ink`。

两处缺陷都要求目标路径在 Ω 形状层号上是 `inc`。目标路径只有三种来源：
- 折到第 0 层用 `z≤`，它处处是 `inu`；
- 回灌用 `posW`，它在孩子侧槽位上是 `inc`；
- 下标侧槽位用 `ink`。

由此得到三条推论【纸】：
1. **外层主链精确，主线与换基候选都是。** T_{n+1} 的主链 z_{m+1} = Ψ_{tw n}(`Ωt (tw n ⊕ ↑ z_m)`)，在 tw n 处的路径是 `self`。
   - 一切低于 tw n 的槽位都保留（`kp ℓ o p self = just`）。
   - 只有后继形状的槽位走链，那里槽位层 ≥ tw n，回灌路径是 `inc tt self`，最后落回 `self`。
   - 所以 z_m 与理想链逐项相同。
2. **T_1 = ψ₀(Ω_Ω)，精确。** 回灌路径是 `ink self`，分支 Ω_c 走 `inu`。仓库已有编译的下界（第 2 站）。
3. **损失只来自朝孩子侧槽位层 e ≥ 1 的回灌。** e = 0 时 K6 没有可保留的东西。

##### 2.2 T_2：亏损格两边的值

亏损格是 N_{ρ+1} = b·ω^{Ω_{ρ+1}}，即 `Up` 的像，槽位在孩子 ρ+1 里。它朝第 0 层折叠时在 ρ 层走链，回灌经过 `inc (ρ+1) …`。

- **理想：** 链 γ_{k+1} = ψ_ρ(Ω_Ω·ω^{γ_k+1})，值为 ψ₀(Ω_Ω·ω^{Ω_{ρ+1}})。
- **主线【纸】：** b 的各分支全走 E6 回退，所以回灌的底 E_ρ = Ω_ρ + Ω₁（形状已由 MathO2 的 `fallback` 编译）。
  - 链点内部低于 ρ 的结点全走 K6。
  - 下一层又遇到同一格，所以指数位置上的 Ω_{ρ+1} 逐层降到 Ω₁ 的可数倍。
- **换基候选【纸】：** b 的分支走 `seen`，在层号 ρ ⊕ ↑c 上把 Ω_{ρ+c} 折回 ρ。
  - 这些层号只有后继与 ℕ 极限两种形状，碰不到 K6/E6，所以这一段精确。
  - 于是 E_ρ ≈ sup_c ψ_ρ(Ω_{ρ+c}) ≥ ψ_ρ(Ω_Ω)，Ω_Ω 分量保住了。
  - 剩下的只是 K6：链点内部低于 ρ 的结点走链，没有保留。

T_2 的下界：
- 【纸】**两条线都有 T_2 ≥ Ψ₀(Ω_{Ω+1}) ≥ ψ₀(Ω_Ω·ω^{Ω₁})。**
  - 依据：第一位置单调（`mono`、`nodeLe`），加上 Ω₁ 那一格不亏损（e = 0）。
  - 这个界高于已编译的 ψ₀(Ω_Ω+ψ₁(Ω_ω)+ω)，但远低于 ψ₀(Ω_{Ω+1})。没有编译。
- 【判】**主线：T_2 < ψ₀(Ω_{Ω₂})，与 MathO2 同向。** tw 1 上的一切树经第 0 层读出时，孩子侧的 Ω_{e+1}（e ≥ 1）都只起到 Ω₁ 那一级的作用。
- 【判】**换基候选：T_2 可能达到读法。** 每个亏损格只滞后一层。b 的下标侧链对孩子取上确界时补了回来：ρ 取遍可数序数，sup_ρ Ω_ρ = Ω_Ω。所以 Ψ₀(b·ω^b) 可能达到 ψ₀(Ω_Ω²)。这正是 A4 加 A5 要证的。

##### 2.3 每多一项塔，精确的外层是否至少多出一层 Ω 下标

- 外层主链对一切 n 都精确【纸】，所以多出的结构确实生成在树里：T_{n+1} = sup_m Ψ₀(Ω_{tw n + z_m})，z_m 与理想链相同。
- 卡在读出：下标侧的结点精确；孩子侧的结点（Ω 形状层号 tw k 的非零孩子里的层，k ≤ n）走 K6，主线还在回灌的底上叠加 E6。
- **主线：否【判】。** E6 在每个 Ω 形状层号 tw k 上重复出现。目标经过孩子 c′ 时，回灌的底只剩 "目标层的 Ω 树 + ψ₀(孩子树)"，丢掉了 Ω_{tw k} 分量。
  - 后果：读出时，tw (k+1) 的孩子侧被逐层压到最低的孩子。
  - T_3 外层多出的那一层下标位于 tw 2 的孩子 Ω+c 里，读出时同样被压掉。
  - 没有上界定理，这一条只是判断。
- **换基候选：若 A4 成立，是【判】。** `seen` 在 tw k 上以 floor = tw (k−1) 重建 Ω_{j+offset}；K6 带来的滞后是 "Ω_{e+1} 截成 Ω_e"，在孩子的上确界里被吸收（A5）。
