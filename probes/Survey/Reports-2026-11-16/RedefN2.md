###### 1.1 新折叠 `N2Fold` 的组成
- **框架**：
  - 目标类型对栈 `d : Dn ℓ m` 递归：`Tg stop i = i ≤ ℓ`（环境写法），`Tg (down d c) i = (i ≤ h c) ⊎ Tg d i`。
  - 保留判定 `kpT`：对本框架的目标调 `kp m`；对外层目标，把槽位看成外层的孩子侧槽位 `(c , p)`，交给外层的 `kpT`。
  - `upT` 出框架时把 τ 忘成 `inc c τ`。
- **状态与 op**：状态是 `St d = (i : L) → Tg d i → Tr⁺ i`。`record Op` 有两个字段：`run`，和膨胀律 `inf : proj₁ v ◃ proj₁ (run S i t v)`。
- **迭代子** `E o d x F`，与 `Einf`、`Emono` 互递归：
  - suc 行的相邻步进只有一行，就是 `Einf`。
  - Ω 行对 `kpT` 判定；走链时回灌目标是 `hereT d (posW m p)`，即框架写法。
  - up 行进框架 `down d c`。
  - 指数里再有 `ex` 的一行先回退成 `E x (F^{ω^b})` 接在 `F^{ω^a}` 之后。
- **ψ 的改动**：
  - 自身行 `ψ ℓ o B _ self β x = ex β β x`，只对非零 x；零行排在前面，给 β。
  - 新增 ex 行：`E o stop x (opB ℓ o b nb) (λ i u → ψ … (B i u) a) j w (ψ … β a)`。
  - `opB` 的膨胀律就是 `mono … nb`。
  - `mono` 加自身行的 7 个子句（经 `sfLt`），加 `◃e`/`◃x` 行（经 `Einf`/`Emono`）。
  - 嵌入行与 `YiRWFold` 逐字相同。

###### 1.2 判据（`N2Check.agda`，全部 `refl`）
项是 `tm = ex zero b (up zero 2 (Ωt lvl2))`，b = `Ωt (tw 1)`，朝第 0 层折。

- **判据 (a)**：
  - **(a1) `top-chain`**：`ψ (tw 1) o₁ (B₀ _) zero (z≤ _) (Ωt zero) tm ≡ node⁺ nothing Gtop sTop`。顶结点走链，回灌一步 `sTop z` 是框架 d₁（孩子 2）里对框架写法目标 `τ = inc tt self : lvl1 ≤ lvl2` 的 E。
  - **(a2) `child-keep`**：对任意 F、S、v、G，`proj₁ (E o₁ d₂ (Ω q G) F S lvl1 (inj₂ (inj₁ τ)) v) ≡ Ω q G′`。q 是 lvl1 里第 0 层的槽位，d₂ 是嵌套框架（孩子 2 再进孩子 tt）。
  - **(a3) `step-node`**：`sTop (Ω q G) ≡ lim H a`，且 `H zero ≡ Ω q G′`。
  - **(a4) `first-feed`**：第一次回灌 `sTop zero ≡ lim H a`，`H zero ≡ Ω q G′`。这里的 q 结点来自 b 的下标侧结点被保留。
  - **(a5) `second-feed`**：`sTop (sTop zero) ≡ lim H a`，`H zero ≡ lim H′ a′`，`H′ zero ≡ Ω q G′`。即第一次回灌的输出作孩子树时，它的结点在输出里是第 1 层槽位上的 Ω 结点。这是判据 (a) 的字面实例。
  - **(a0) `old-k6`**（对照）：仓库 `YiRWFold.ψ` 上的同一格，即上折摊平后的槽位 `(2,(tt,(tt,q)))`，对目标 `inc 2 (inc tt self)` 输出 `≡ lim H a`。
- **判据 (b)**：
  - `k-both (lem : LEM)`：`IsJust (Sharp.kp♯ lem (tw 1) (Ok-tw 1) slotᴿ lvl1ᴿ _) × IsJust (kpT d₂ o₁ q (inj₂ (inj₁ τ)))`，两边都是 `tt`。ψ♯ 一侧落在仓库块的类型上，新折叠落在 N2 块的类型上，"同一格" 指字面坐标相同。
  - 补充 `k-bare`：同一结点对同一层，若用置空后的裸写法 `inj₂ (inj₂ (inc 2 τ))`，`kpT … ≡ nothing`。
  - 补充 `k-bare-flat`：`kp (tw 1) o₁ slotN (inc 2 τ) ≡ nothing`。
- **判据 (c)**：
  - `c-base`：`b + up 2 (Ωt lvl2)` 朝第 0 层折，等于 `ψ lvl2 … (B′ B) zero (z≤ lvl2) (ψ … β b) y`，其中 `B′ B i u = ψ (tw 1) o₁ B i (inc 2 u) (B i (inc 2 u)) b`，即 "左项 b 经 inc 2 朝 i 层的折叠"。
  - `c-chain`：孩子树顶结点走链时，链的起点是 `ψ (tw 1) o₁ B lvl1 (inc 2 τ) _ b`，即 b 朝第 1 层的折叠。
  - `c-sharp`：ψ♯ 同一调用的 `up-row` 实例，它的底族不带路径。

###### 1.3 偏离与发现
- **D1，自身行**（纸面论证，编译失败的位置是事实）：
  - 按 `ex zero β x` 写，`mono` 有两处要 `β ◃ ex zero β y`：一是嵌入行目标进孩子后正好是孩子层自身（如 `(nd sS h)`，`inc c′ self`）的 ◃u 行，二是自身行里 x = 0 的情形。
  - 序只有 `◃e`、`◃x` 两条，按构造子逐条看推不出这一条；我没有为此写否定定理。
  - 所以改成 `ex β β x`：`◃e` 直接给出 `β ◃ ex β β y`。值上 x ≥ 1 时 β + β·ω^x = β·ω^x（纸面）。
  - 另一个改法是加一条序 `b ◃ ex a b nb x`（x 非零时），但粗读回下它的 `◃→⊑` 写不出：要 `↑b ⊑ (↑a ⊕ ↑b) ⊕ ↑x`，`lift` 只给左项的路径。
- **D2，框架栈**（编译件为证）：
  - S2 §2.3 写 "进内层时外层的 τ 置空，第一版不带框架栈"。按那样写，判据 (a) 过不了。
  - 原因：`Ωt lvl2` 的 K6 结点只经嵌套的 `upz tt (suc z)` 出现，置空后目标退成裸写法，`k-bare` 给 `nothing`。
  - 所以保留栈：外层目标原样留着，判定交给外层的 `kp`。外层是 sS 或 sL 形状时，`kp` 的现行各行自动完成平移；外层是 sΩ 形状、目标是 `inc c′` 时仍是 `nothing`（D 类）。
  - 代价：`Tg`、`kpT`、`upT`、`okD`、`hereT` 共约 25 行。
- **D3，Tr zero 里有了 ex**：`T` 各层共用，所以第 0 层也有 `ex`，`ι` 要加行，最终输出 `twᶜ` 不再是纯布劳威尔树。S2 说 "最终输出的布劳威尔树不变形"，这一句不成立。要么给第 0 层的 `ex` 一个 View（零给 a + b，后继给 ℕ 极限，ℕ 极限逐点），要么在第 0 层禁掉 `ex`。没有做。
- **D4，mono 要拆开写**：自身行排在 suc/lim/Ω 行之前，`ψ … w β (suc x)` 在 w 未知时卡住，所以 `mono` 的非自身各行要按 `inc`/`inu`/`ink` 拆开，约 +12 行，只是写法问题。
- **止损三条都没触发**：
  - E 后继行的相邻步进：`Op.inf` 一个字段，加 suc 行 2 行，远在 150 行以内。
  - `Emono` 对框架分度的情形：◃u、◃c 各一个子句。
  - 堆远在 6G 以下。
