#### 2. 编译定理

主定理，陈述逐字抄出：
```
neg : NegStmt
```
其中 `NegStmt = Σ (Tr zero) λ t → (loc : Locator) → CompleteAt t loc → LPO`（KLoc 原文）。见证是 `t = lim sn (λ n → ◃s)`，`sn n` 是 sucⁿ zero。
白话：只要一个定位器能在一切 z 上找到层号 h₁ t（h₁ t 是 ω 读回的层号，一个 ℕ 极限结点），就能判定每个布尔序列里有没有 true，即推出 LPO。

辅助编译定理，逐字抄出：
- `noInf : (F : ℕ → L) (m : ℕ) → nd sL F ≤ h₁ (sn m) → ⊥`
  白话：ℕ 极限结点不会字面地出现在有限的后继链里。
- `found : (α : ℕ → Bool) {a : L} → h₁ t ≤ a → a ≡ h₁ (z α) → Found α`
  白话：从探针层号里的任何一条路径都能读出 α 的一个 true。
- `hit : (α : ℕ → Bool) → Found α → h₁ t ≤ h₁ (z α)`
  白话：α 有 true 时，路径确实存在。
- `step′ : (b c : Bool) (n : ℕ) → zero ⊢ sel b n ◃ sel (b ∨ c) (suc n)`
  白话：探针相邻两项的步进证据，所以 z α 是合法的树。

#### 3. 构造与证明
- **探针。** `z α = lim (bα α) …`，其中 `bα α n = sel (any α n) n`，`any α n` 是 α 0 ∨ … ∨ α n。
  - 若 `any α n` 为 false，第 n 项取 `sn (suc n)`（sucⁿ⁺¹ zero）。
  - 若为 true，第 n 项取 `pl n`（即 t + n）。
  - 与主审设计的差别：设计里 true 之后的项是 t, t+1, …；这里第 n 项一律是 t + n，按位置统一写，不必记住第一个 true 在哪。两者对证明没有区别。
  - 步进：false 段与 true 段内部都用 `◃s`；从 false 到 true 的那一步用 `◃t (◃l (suc n)) (lt-pl n)`。
- **怎样推出 LPO。** 直接调用 `sig→lpo`，观察量取 `isJ (loc (h₁ t) (h₁ (z α)))`。
  - 有 true 时：`hit` 给出路径，完全性给出 `just`。
  - 返回 `just p` 时：由 `found` 从路径 p 读回 `Found`。
- **`found` 的四种情况。**
  - `self`：用相等证明加 `cong first0` 排除。`first0` 读第 0 个孩子是不是 zero：t 的第 0 个孩子是 zero，探针的不是，对 α 0 分两种情况都可以 refl 算出，不需要函数外延。
  - `inc c v`：交给 `back`。第 c 项若还在 false 段，`noInf` 给出矛盾；否则由有限检查 `anyF` 给出 Found。
  - `inu vs`：取 `vs zero`，同上处理。
  - `ink`：sΩ 与 sL 构造子冲突，直接排除。

#### 5. 对 "有限的 t" 是否成立（判断，没有编译）
预期不成立。这里的证明本质上用到 h₁ t 是 ℕ 极限结点：
- 一是 `noInf`，它在有限链里不出现；
- 二是排除 `self` 时，靠的是它与探针在第 0 个孩子上字面不同。

t 是有限树时，h₁ t 是有限的 sS 链，在第 0 层树的读回里定位它应当可以靠结构递归判定。这正是另一路要证的 `PosStmt`（有限层上完全）。所以这条否定划出的界线是：定位无穷的被找层号推出 LPO，有限的应当不会。
