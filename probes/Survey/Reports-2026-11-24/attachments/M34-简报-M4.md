## 背景

要证的大定理: W4 的折叠在只有后继与 ℕ 极限形状的层号上不低于参照系统 Level 的折叠. 纸面在 <仓库>/probes/Survey/W4-可数层号定理-纸面.md (先读全文, 重点 §2 §3 §4 的 (Op) 与 (It)).
W4 把挂起的乘幂 `ex a b x` (读作 a + b·ω^x) 朝低层折时, 用迭代子 `E` (一阶) 与 `It n` (一切高阶) 把 "右边接上 b" 迭代 ω^x 次, 定义在 <实验目录>/w4/W4Fold.agda. Level 一侧没有迭代子: 同一个量是纯树 `pwb V id X` (V·ω^X, 定义在 KPow) 被普通折叠折出来的.
本任务证接口 `KIface.OpStmt`: 若 "接上 v" 实现增量 V (`RealOp`), 指数满足 `Dom m X x`, 则 `E o tdNil x (opB m o v nb)` 实现增量 `pwb V id X`.
已有的同类工作: B6A 在 "第 1 层折到第 0 层" 上对一切阶做成了 (影子是第 0 层上的函数). 纸面与源码在 <仓库>/probes/Survey/Reports-2026-11-16/attachments/ 的 B6A-WS-paper.txt, B6A-WSShadow.agda.txt, B6A-WSW4.agda.txt, B6A-WSReal.agda.txt: 先读纸面 §2 (逻辑关系 R n, 延伸的合规条件 Good, 闭包 cl-W, 各行 limC nodeC upC enter Kb Kₑ Itᴺ 的不等式), 那里的证明形状可以照搬. 区别: 这里的影子是 Level 的树 (增量) 与树上的函数, 目标层任意, Ω 行可能保留 (保留时逐点), 判定一致用 KMir 的 `KT`/`KT-dec` (框架版引理 K).
已编译并定稿的部件 (只读; 需要改动时在回报里提出): KRel, KIface, KMir, KPow (`pwb-add`: V·ω^(A+Z) ≅ (V·ω^A)·ω^Z; `pwb-pwb`: W·ω^(B·ω^X) ≅ 把 "乘 ω^B" 从 W 起迭代 ω^X 次, `it0`).

## 要交的 (分阶段; 每阶段都要整体编译; 做到哪里报到哪里)

对 `Dom m X x` 的推导归纳. 内部要把陈述推广到任意语境 `Cx` 上的算子 (`Op X`) 与任意树数据 `TD`, 高阶载体 `Ca n` 对应 Level 侧的函数 (第 0 阶是增量树, 第 n+1 阶是第 n 阶到第 n 阶的函数).

- 阶段一 (nil 语境, 指数的推导只用 rz rs rl r≅ r◃): 证 `OpStmt` 的这一部分. 要点是 suc 行: 带状态更新的 ω 次迭代 (`itV`/`itS`), 两边的状态逐步保持 `RealS` 与 `CovS`; Level 一侧 `pwb V id (suc X)` 是 `lim (iter (pwb V id X +_) zero)`, 用 `add-assoc` 把 n 份逐份并进前缀.
- 阶段二: 加 rΩ (指数里的结点): 保留时逐点; 走链时两条链对齐差一步 (Level 从 `Ω j` 起, W4 从零起).
- 阶段三: 加 ru (指数里的孩子树): `E` 进孩子框架 (`chTD`, `chMT`, `enterO`); 这一步要把陈述推广到语境与框架, Level 一侧用 `pwb-add`.
- 阶段四: 加 re (指数里又有挂起的乘幂): 转到 `It 0`, 再往上是一切阶 `It n` 的同一条证明; Level 一侧用 `pwb-pwb`, 高阶的同形恒等式自己证 (放在自己的文件里).
