# M5: 把可数层号定理接到 BTBO 下界 (前缀 KAs, 工作目录 <实验目录>/m5)

先读公共约束: <实验目录>/briefs/COMMON.md . 注意: 共享基目录现在是 <实验目录>/w5 (编译命令里的 `-i .../w4` 换成 `-i <实验目录>/w5`, 两个不要同时在路径上). w5 里都已编译, 只读: W4Block, W4Ops, W4Path, W4Fold, W4Val, W4View, WVOne (`read`, `𝟏`, `h₁`, `read-+`), WVTwo (`◃→≼`), KMir (`IsS`, `IsS→IsN`, `code`, `IsS-⊕↑`), KLowIface (`Cov`, `LOWERᵂ`).

## 背景

对象: W4 的闭项 `EBOᶜ = proj₁ (ψ₀ Λ Ok-Λ (proj₁ (Ωt Λ)))` (W4Fold 末尾), 层号 `Λ = nd sL tw`, `tw 1 = nd (sΩ zero) h₁`, `h₁ c = zero ⊕ ↑ zero c` (第 0 层的树 c 读成一个可数层号). `Ωt (tw 1)` 是一个结点, 分支 c ↦ `upz c (Ωt (h₁ c))`; 朝零折叠时结点行是 `node⁺ nothing`: 输出是 `limc⁺ (λ n → G (iter s x₀ n))`, 即链点 c₀, c₁ = s c₀, … 上各项的累加极限; 每一项经孩子行变成 "在层号 h₁ cₙ 上折 Ωt (h₁ cₙ)".
在跑的另一路正在证 "可数层号定理", 它的出口陈述是 `KLowIface.LOWERᵂ`: 对只含后继与严格 ℕ 极限形状的层号 m (`IsS m`; 一切 `h₁ c` 都满足, 见 `IsS-⊕↑`), 覆盖的状态, 不低于 1 的底, 任何到零的路径, 参照系统 Level 在镜像码上的折叠 `ψ⁰ (Ω (code m …))` 不高于 W4 的折叠值. 本任务把 `LOWERᵂ` 当模块参数.
目标: `tr₀ Ord-Ord.BTBO ≼ read EBOᶜ`, 模块参数只有 `LOWERᵂ`. BTBO 是作者已发表的闭项 (`OCF.BTBO`), 参照链是 `OCF.Align.NoCumsum` 的 `γ`, `L`, `BTBOᴵ` (γ (n+1) = ψ⁰ (Ω (L n)), L n 是 γ n 的层号码), 同值定理 `OCF.Align.BTBOFull.BTBO≈`.

## 难点与要照搬的先例

`LOWERᵂ` 给的是镜像码上的界. 链上只有值序 "γ n ≼ read (第 m 个链点)", 而参照的折叠对层号码不按值单调地可证 (从值序造层号嵌入会推出 LPO, 仓库里的 `embV→LPO` 一族). 旧主线上解决过同一个问题, 请先完整读:

- <仓库>/probes/Survey/RR7-BtboLower.md (证法的四段)
- <仓库>/probes/OCF/Lean/YiBtboLower.lagda.md 与 YiBtboV2.lagda.md (已编译, 可以直接导入其中与块无关的部分)

那里的做法: 链上的不变量只是值序; 每一步造前驱嵌入 `PEmb (L n) (下一个链点的层号码)`, 再由 `Ψ-emb` 取值, 接镜像下界推进不变量. 嵌入分段: (1) 参照层号嵌进自己的累加规范化 (`PW₃ (V1 (SV-L n))`); (2) 规范化层号之间由值序给嵌入 (`V2′`, 目标一侧只要 `Mono`); (3) 链点 η 的规范化层号 `ordᴰ (cp η)` 嵌进折叠值 `read (F η)` 的字面前驱 (`V3m`, 用 `BTBOFullEb.Blocks` 的 `Eb`, `Eb-suc`, `Blk.Lim`). 第 (1)(2) 段与块无关, 第 (3) 段要 W4 版, 是本任务的主体.

## W4 版第 (3) 段的建议写法 (主审的纸面判断, 没有编译; 不成立就照实报)

W4 的折叠在极限层号上不是字面的部分和: 第 n 个部分结果是 "以前一个部分结果为底, 在孩子层上折 Ωt". 所以把陈述推广到一切运行:

    对一切 η : Tr zero, 一切在层号 h₁ η 上的运行 (Ok, 覆盖的状态 S, 底 β, 到零的路径 w):
    ordᴰ (cp η) 嵌进 read (ψ (h₁ η) o S zero w β (Ωt (h₁ η))) 的字面前驱, 且每个像字面地高于 read β.

对 η 归纳:
- 极限 lim f: `Ωt (nd sL g) = limc⁺ (λ n → upz n (Ωt (g n)))`, 折叠逐项, 第 n+1 个部分结果是孩子层 g n 上的一个运行 (状态是进孩子后的状态, 底是第 n 个部分结果). 对 f n 用归纳假设, 像都高于底, 所以各块首尾相接, 用 `Blk.Lim` 粘起来. 参考 (只读, 不必导入): <仓库>/probes/Survey/Reports-2026-11-18/attachments/B12Terminal.agda.txt 的 `Run`, `enterRun`, `limRun`, `lim-child`, 与 B12ActualSlots.agda.txt 的 `Covered`, `enter` (进孩子后的运行仍然覆盖). 这些文件的依赖很重, 需要的几十行请在自己的文件里重写.
- 后继 suc a: 层号 nd sS h, `Ωt` 是结点, 分支 c ↦ `upz tt (suc c)`, 朝零是走链: 链点 cₖ₊₁ 是朝孩子层折出来的, 以状态里孩子层的条目为底, 而折叠不低于底 (W4 的 `mono` 与 `zl`), 覆盖的状态给出 Ωt (h tt) ⊴ cₖ₊₁. 于是输出的第 1 项 (孩子层上折 suc c₁) 字面地高于 "孩子层上以同样状态与底折 Ωt (h tt)" (`mono`), 后者是层号 h₁ a 上的一个覆盖的运行, 对它用归纳假设, 再用 `Eb-suc`. 输出是各项的累加和, 所以要把嵌入整体左移一个加数 (像 x 换成 A + x; `add-≺`, `add-left` 一类引理在 `OCF.Align.BTBOValNeg`, `BTBOFullV3`).
- 需要的小引理: W4 第 0 层的步进序 ◃ 给出 read 的字面前驱 (`L.≺`); `read (a + b)` 与 `read a L.+ read b` 的字面关系; `cp : Tr zero → Ord₀` 与 `Mono`; 层号码与读回一致: `code (h₁ η) … ≅ᴵ L.toLevel (read η) …` (连同 `L.HS (read η)`).
