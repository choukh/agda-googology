# M1: Level 侧的乘幂与它的恒等式 (前缀 KPow, 工作目录 <实验目录>/m1)

先读公共约束: <实验目录>/briefs/COMMON.md

## 背景 (只需要这些)

参照系统 `OCF.Align.Level` (文件 <仓库>/probes/OCF/Align/Level.lagda.md; 先读 §4 的树族, lift, Ω, add, ψ, ψ⁰, 再读 §5 的 ≅ 与 add-≅, ψ-≅ 的证法). 它是纯树上的折叠: 树 `Ordᶜ ℓ` 的构造子是 zero, suc, lim, limᵢ, up; 没有 "挂起的乘幂".
本任务在 Level 一侧定义乘幂 (读作 V·ω^X), 并证几条只到 `≅` 的恒等式. 它们是一条更大的定理 (W4 的折叠不低于 Level 的折叠) 的 Level 侧部件. 纸面见 <仓库>/probes/Survey/W4-可数层号定理-纸面.md 的 §2.

## 要交的 (按顺序)

1. 定义 `pwb : ∀ {k ℓ} → Ordᶜ ℓ → Simᴵ k ℓ → Ordᶜ k → Ordᶜ ℓ`, 层号的记账照 `add`:
   - pwb V σ zero = V
   - pwb V σ (suc X) = lim (iter (pwb V σ X +_) zero)
   - pwb V σ (lim f) = lim (λ n → pwb V σ (f n))
   - pwb V σ (limᵢ q f) = limᵢ (σ q) (λ y → pwb V σ (f (coe (<→◃ (σ q)) (<→◃ q) y)))
   - pwb V σ (up zero x) = pwb V (λ q → σ (suc q)) x
   - pwb V σ (up (self n) x) = pwb V (λ q → σ (lim n q)) x
2. `pwb-≅`: pwb 对两个树参数都尊重 ≅ (陈述与证法照 add-≅).
3. 自身层折叠的形状 (最要紧的一条). 对 a : Ordᶜ ℓ, x : Ordᶜ k, σ : Simᴵ k ℓ, 在需要的自反性前提 (a ≅ a, x ≅ x) 下:
   `ψ {i = ℓ} {k = ℓ} {ℓ = suc ℓ} zero (λ q → suc q) (add a σ x)  ≅  pwb (ψ zero (λ q → suc q) a) σ x`
   白话: 把第 ℓ 层的树 a + x 放进第 ℓ+1 层再折回第 ℓ 层, 等于 "折 a 的结果乘 ω^x". 证明对 x 归纳; limᵢ 行里 ψ 走穿透分支 (结点层 ≺ᴵ ℓ), 输出挂在代表元上并带 tr⁻, 用 lᵢ≅ 对上.
   若这个形式的陈述有类型上的出入 (例如 σ 的合成写法), 按能编译的最近形式写, 在回报里说明差在哪里.
4. 加法: `add a σ (add b τ c) ≅ add (add a σ b) (λ q → σ (τ q)) c` (结合), 以及 `add zero σ x ≅ x` (零是左单位). 先查仓库里是否已有.
5. `pwb V σ (add A τ Z) ≅ pwb (pwb V σ A) (λ q → σ (τ q)) Z` (先 ω^A 再 ω^Z).
6. (做完 1 到 5 再做) 一阶迭代: 定义 `it0 : ∀ {k ℓ} → Simᴵ k ℓ → Ordᶜ k → (Ordᶜ ℓ → Ordᶜ ℓ) → Ordᶜ ℓ → Ordᶜ ℓ` (把 κ 从 W 起迭代 ω^X 次: zero ↦ κ W; suc X ↦ lim (λ j → iter (it0 σ X κ) W j); lim 逐项; limᵢ 保留成结点; up 下降), 并证 `pwb W σ (pwb B τ X) ≅ it0 (…) X (λ W′ → pwb W′ σ B) W` (迭代 "乘 ω^B" 共 ω^X 次). κ 需要 "尊重 ≅" 的前提就加上.

## 要点

- Level 的 ≅ 不是自动自反的 (limᵢ 结点要分支函数尊重 ≅), 仓库里的引理都带 x ≅ x 这类前提; 照做, 不要试图证一般的自反.
- 先查重: `grep` 仓库 probes/OCF/Align/ 里有没有 add 的结合律, 零单位, 或类似 pwb 的定义; 有就复用.
- 不改仓库任何文件. 只读 Level 及它已有的引理 (add-≅, ψ-≅, Ω-≅, tr-≅, tr⁻-≅, ≅-sym, ≅-trans, R→≅, ≅→R 等).
- 若第 3 条不成立 (例如某一行两边形状对不上), 报出是哪一行, 两边各是什么.
