# M0: W4 的 ℕ-层号与 Level 层号码的镜像, 以及保留判定的一致 (前缀 KMir, 工作目录 <实验目录>/m0)

先读公共约束: <实验目录>/briefs/COMMON.md

## 背景 (只需要这些)

W4 的层号类型 `W4Block.L` 有三种形状: sS (后继), sL (ℕ 极限), sΩ k (在第 k 层的树上分支). 本任务只管由 zero, sS, sL 生成的层号, 称 ℕ-层号.
W4 的折叠在 Ω 结点处用 `W4Fold.kp : (ℓ : L) → Ok ℓ → (p : Pos ℓ) → ∀ {j} → j ≤ ℓ → Keep j (Br ℓ p) (fromBr ℓ p zero)` 判定 "保留" (just) 还是 "走链" (nothing).
参照系统 `OCF.Align.Level` (文件 <仓库>/probes/OCF/Align/Level.lagda.md, 先读 §2 到 §4) 用层号码 `Ordᴵ`, 序 `<ᴵ` `≅ᴵ` `⊑ᴵ` `≺ᴵ`, 它的折叠在结点处用 `<ᴵ-dec`: 结点层 ≺ᴵ 目标层时保留, 否则走链.
要证: 把 ℕ-层号翻成层号码之后, 两边的判定一致. 纸面论证见 <仓库>/probes/Survey/W4-可数层号定理-纸面.md 的 §1 (引理 K).

## 要交的 (按顺序; 前面的是后面的前提)

1. 谓词 `IsN : W4Block.L → Set`: zero 是; nd sS h 是当且仅当 h tt 是; nd sL g 是当且仅当一切 g n 是.
2. `code : (m : L) → IsN m → Ok m → Level.Ordᴵ`: zero ↦ zero; nd sS h ↦ suc (code (h tt)); nd sL g ↦ lim (n ↦ code (g n)) (相邻项的 ⊑ᴵ 证据). 极限行的相邻证据要从 `Ok` 给的路径 `g n ≤ g (suc n)` 得到, 所以大概要与 "路径给出 ⊑ᴵ" 互递归 (Level 的 toLevel 与 toLevel-⊑ 是同样的互递归, 可参照). 子层号的 IsN 与 Ok 从父层号得到. 不同的 IsN/Ok 证明给出的码只要求 ≅ᴵ.
3. 槽位对证明: 对 p : Pos m, 有 `code (at m p) <ᴵ code m` (字面的 <ᴵ; 若只能到 ≺ᴵ 也交, 说明原因).
4. 路径对序: 对 w : j ≤ m, 有 `(code j ≅ᴵ code m) ⊎ (code j ≺ᴵ code m)`.
5. 引理 K (主要目标), 对一切 ℕ-层号 m, 槽位 p, 路径 w : j ≤ m:
   - `kp m o p w ≡ just x → code (at m p) ≺ᴵ code j`
   - `kp m o p w ≡ nothing → (code j ≅ᴵ code (at m p)) ⊎ (code j ≺ᴵ code (at m p))`
   陈述里的 IsN/Ok 参数按需要加. 注意 kp 的 sL 行用 `way` 与 `psh`/`pshBr` 在两个孩子之间搬槽位.
6. (做完 5 再做) 框架版: `W4Fold.kpT` 对 `Dn`/`Tg` 的同样两条, 只管框架链上全是 ℕ-层号的情形.

## 要点

- 这是 "构造与证伪" 合在一路: 若第 5 条不成立, 最小反例 (具体的 m, p, w, 两边判定不同, refl 级别) 比证明更重要, 立刻报.

- 不要改 W4 的任何定义. 不要碰 sΩ 形状 (IsN 排除了它; kp 里 sΩ 的子句对 IsN 的层号不可达, 用 IsN 的证据排除).
