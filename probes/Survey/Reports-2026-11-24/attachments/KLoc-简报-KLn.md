# KLn: 完全的层号定位推出 LPO (否定一路; 前缀 KLn, 工作目录 <实验目录>/m6n)

先读公共约束: <实验目录>/briefs/COMMON.md . 注意: 共享基目录是 <实验目录>/w8 (编译命令里的 `-i .../w4` 换成 `-i <实验目录>/w8`). w8 里都已编译, 只读: W4Block, W4Ops, W4Path, W4Fold, WVOne, WVTwo, KLoc.

## 背景

W4 的层号 `L` 自己是树 (W4Block: `zero`, `nd sS`, `nd sL`, `nd (sΩ k)`). 路径 `j ≤ a` (`Pth true j a`, 构造子 `self`, `inc`, `inu`, `ink`) 说的是层号 j 字面地出现在层号 a 里的某个位置. 第 0 层的树 t 读回成层号 `h₁ t = zero ⊕ ↑ zero t` (WVOne).
折叠朝 "某个孩子里的层 j" 折一棵 "在另一个孩子 c 里的树" 时, 现在一律回退 (丢信息). 若能在孩子 c 的层号里找到 j, 就可以在孩子 c 里就地折. 所以问题是: 定位能做到多完全.
接口在 <实验目录>/w8/KLoc.agda (已编译, 不要改): `Locator`, `CompleteAt`, `NegStmt`. 另有一路在做构造 (有限层上完全的定位器), 与你共用这个接口.

## 要交的

证 `KLoc.NegStmt`: 给出一棵固定的第 0 层树 t, 使得 "对一切 z, 只要 `h₁ t ≤ h₁ z` 就找到" 的定位器推出 LPO (`OCF.Lean.YiAbsObs.LPO`; 那里的 `sig→lpo`, `obs→dec` 可以直接用).

主审的纸面设计 (判断, 没有编译; 不成立就照实报, 可以换探针):
- t 取 `lim (n ↦ sucⁿ zero)` (读回层号是 `nd sL (n ↦ lvl n)`).
- 对 α : ℕ → Bool 取 z_α = `lim b`: 在 α 的前 n 项都是 false 时 b n = suc^(n+1) zero (比 t 的第 n 项多一个后继, 所以与 t 的第 0 项就不同); 一旦出现 true, 之后的项取 t, t+1, t+2, …. 要给出相邻项的步进证据使 z_α 是合法的树.
- Found α 时 t 字面地出现在 z_α 的某一项里, 所以有路径, 完全性给出 just.
- 反过来, 从 just p 的路径 p 分情况: `self` 不可能 (两个层号在第 0 个孩子上就不同, 不需要函数外延); `inu` 不可能 (要到每个孩子, 第 0 个孩子太小); `inc n v` 时 v 是 t 的层号到 b n 的层号的路径, b n 若还是有限的后继链就不可能 (无穷层号进不了有限层号), 所以前 n+1 项里有 true, 有限检查即得 Found α.

## 要点

- 定理要无前提: 不用函数外延, 不加公设.
- 卡住时把没证的部分写成带确切陈述的模块参数, 使文件整体编译, 回报里列出.
- 回报里另写一句: 这条否定对 "有限的 t" 是否也成立 (预期不成立: 有限层的定位是可判定的, 另一路在证); 不必证.
