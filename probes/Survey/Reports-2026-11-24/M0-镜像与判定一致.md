#### 2. 编译定理 (陈述逐字)

##### KMir.agda

**第 1 条.** ℕ-层号, 定义与简报一致:
```
IsN : L → Set
IsN zero          = ⊤
IsN (nd sS h)     = IsN (h tt)
IsN (nd sL g)     = (n : ℕ) → IsN (g n)
IsN (nd (sΩ _) _) = ⊥
```
辅助函数 (各一行, 均编译): `IsN-ch : (m : L) → IsN m → (c : CH m) → IsN (kid m c)`, `IsN-path : ∀ {j m} → j ≤ m → IsN m → IsN j`, `Ok-path : ∀ {j m} → j ≤ m → Ok m → Ok j`, `IsN-at : (m : L) → IsN m → (p : Pos m) → IsN (at m p)`。

**第 2 条.** 层号码 (三者互递归, 通过停机检查):
```
code : (m : L) → IsN m → Ok m → Ordᴵ
code-irr : (m : L) (i i′ : IsN m) (o o′ : Ok m) → code m i o ≅ᴵ code m i′ o′
pth⊑ : (j m : L) → j ≤ m → (ij : IsN j) (oj : Ok j) (im : IsN m) (om : Ok m) → code j ij oj ⊑ᴵ code m im om
```
- `code` 按简报的三行写: `zero ↦ I.zero`, `sS ↦ I.suc`, `sL ↦ I.lim`。极限行第 n 个相邻证据是 `pth⊑ (g n) (g (suc n)) (proj₁ o n) …`, 也就是把 `Ok` 给的路径译成 `⊑ᴵ`。
- `pth⊑` 说明路径总给出 `⊑ᴵ`, 不需要严格性, 所以 `code` 在退化层上也有定义。
- `code-irr` 说明不同的 IsN/Ok 证明给出 `≅ᴵ` 的码。

**严格层号 (新增前提):**
```
_<ₙ_ : L → L → Set
j <ₙ zero   = ⊥
j <ₙ nd s h = Σ (Ch s) λ c → j ≤ h c

IsS : L → Set
IsS zero          = ⊤
IsS (nd sS h)     = IsS (h tt)
IsS (nd sL g)     = ((n : ℕ) → IsS (g n)) × ((n : ℕ) → Σ ℕ λ k → g n <ₙ g k)
IsS (nd (sΩ _) _) = ⊥
```
附带 `IsS→IsN : (m : L) → IsS m → IsN m` 和 `IsS-path : ∀ {j m} → j ≤ m → IsS m → IsS j`。

**孩子低于父亲, 严格路径:**
```
chlt : (m : L) → IsS m → (c : CH m) (ic : IsN (kid m c)) (oc : Ok (kid m c)) (im : IsN m) (om : Ok m)
     → code (kid m c) ic oc ≺ᴵ code m im om
below : (j a : L) → j <ₙ a → IsS a → (ij : IsN j) (oj : Ok j) (ia : IsN a) (oa : Ok a) → code j ij oj ≺ᴵ code a ia oa
```

**第 4 条.** 路径对序:
```
pathle : (j m : L) → j ≤ m → IsS m → (ij : IsN j) (oj : Ok j) (im : IsN m) (om : Ok m)
       → (code j ij oj ≅ᴵ code m im om) ⊎ (code j ij oj ≺ᴵ code m im om)
```

**第 3 条.** 槽位对证明, 到 `≺ᴵ`:
```
slot : (m : L) → IsS m → (p : Pos m) (ia : IsN (at m p)) (oa : Ok (at m p)) (im : IsN m) (om : Ok m)
     → code (at m p) ia oa ≺ᴵ code m im om
```

**第 5 条.** 引理 K。先定义判定的含义 `Ag`, 再对 kp 的每一行证明:
```
Ag : (a j : L) {Z : Set} → Maybe Z → Set
Ag a j (just _) = (ia : IsN a) (oa : Ok a) (ij : IsN j) (oj : Ok j) → code a ia oa ≺ᴵ code j ij oj
Ag a j nothing  = (ia : IsN a) (oa : Ok a) (ij : IsN j) (oj : Ok j) → (code j ij oj ≅ᴵ code a ia oa) ⊎ (code j ij oj ≺ᴵ code a ia oa)

K : (m : L) → IsS m → (o : Ok m) (p : Pos m) {j : L} (w : j ≤ m) → Ag (at m p) j (kp m o p w)
K⁼ : (a : L) → IsS a → (o : Ok a) (t : Pos⁼ a) {j : L} (w : j ≤ a) → Ag (proj₁ (sl⁼ a t)) j (kp⁼ a o t w)
```
- 证明按 kp 的子句走。
- sL 行用 `cW-ind` 分 `way` 的两支。搬槽位的一支用 `Ag-map` (mapK 不改 just/nothing) 和 `at-psh : ∀ {k a} (u : k ≤ a) (t : Pos⁼ k) → proj₁ (sl⁼ a (psh u t)) ≡ proj₁ (sl⁼ k t)` (psh 不改槽位层)。
- sΩ 子句由 `IsS = ⊥` 排除。

简报形式的两半:
```
K-just : (m : L) → IsS m → (o : Ok m) (p : Pos m) {j : L} (w : j ≤ m) {x : _} → kp m o p w ≡ just x
       → (ia : IsN (at m p)) (oa : Ok (at m p)) (ij : IsN j) (oj : Ok j) → code (at m p) ia oa ≺ᴵ code j ij oj
K-nothing : (m : L) → IsS m → (o : Ok m) (p : Pos m) {j : L} (w : j ≤ m) → kp m o p w ≡ nothing
          → (ia : IsN (at m p)) (oa : Ok (at m p)) (ij : IsN j) (oj : Ok j)
          → (code j ij oj ≅ᴵ code (at m p) ia oa) ⊎ (code j ij oj ≺ᴵ code (at m p) ia oa)
```

与 Level 判定一致的直接陈述 (`Keeps d` 当且仅当 `<ᴵ-dec` 给出 `injᵃ`, 即保留):
```
agree : ∀ {a j : L} {Z : Set} (r : Maybe Z) → Ag a j r → (ia : IsN a) (oa : Ok a) (ij : IsN j) (oj : Ok j)
      → {c : Ordᴵ} (pa : code a ia oa <ᴵ c) (pj : code j ij oj <ᴵ c) → Same r (Keeps (I.<ᴵ-dec pa pj))
K-dec : (m : L) → IsS m → (o : Ok m) (p : Pos m) {j : L} (w : j ≤ m)
      → (ia : IsN (at m p)) (oa : Ok (at m p)) (ij : IsN j) (oj : Ok j)
      → {c : Ordᴵ} (pa : code (at m p) ia oa <ᴵ c) (pj : code j ij oj <ᴵ c) → Same (kp m o p w) (Keeps (I.<ᴵ-dec pa pj))
```
白话: 在任何公共上界之下, W4 给 just 时 Level 的 `<ᴵ-dec` 必给第一种 (保留); W4 给 nothing 时 Level 必不给第一种 (走链)。

**第 6 条.** 框架版。只要环境层号 ℓ 严格, 框架链上的层号就都严格:
```
IsS-dn : ∀ {ℓ m} → Dn ℓ m → IsS ℓ → IsS m
KT : ∀ {ℓ m} (d : Dn ℓ m) → IsS ℓ → (o : Ok ℓ) (p : Pos m) {i : L} (t : Tg d i) → Ag (at m p) i (kpT d o p t)
KT-dec : ∀ {ℓ m} (d : Dn ℓ m) → IsS ℓ → (o : Ok ℓ) (p : Pos m) {i : L} (t : Tg d i)
       → (ia : IsN (at m p)) (oa : Ok (at m p)) (ii : IsN i) (oi : Ok i)
       → {c : Ordᴵ} (pa : code (at m p) ia oa <ᴵ c) (pi : code i ii oi <ᴵ c) → Same (kpT d o p t) (Keeps (I.<ᴵ-dec pa pi))
```
外层目标一支归到外层槽位 `(c , inj₂ p)`。它的槽位层 `at (h c) p` 与 `at m p` 在定义上相同, 所以直接递归, 不需要额外引理。

**IsS 可满足:**
```
IsS-⊕↑ : (a : L) → IsS a → (x : Tr zero) → IsS (a ⊕ ↑ zero x)
IsS-tw1 : (c : Tr zero) → IsS (zero ⊕ ↑ (tw 0) c)
```
白话: 严格层号接上任一第 0 层树的读回仍严格, 塔第 1 项的每个孩子都严格。

##### KMirNeg.agda (否定)

**(a) 原样 IsN 下的反例.** `m₀ = nd sL (λ _ → zero)`, `o₀ = (λ _ → self) , (λ _ → tt)`, `p₀ = inj₂ (zero , inj₁ tt)`, `at m₀ p₀ ≡ zero` 是 refl。
```
kp₀ : kp m₀ o₀ p₀ self ≡ just (p₀ , (λ z → z) , refl)
no-≺₀ : (ia : IsN (at m₀ p₀)) (oa : Ok (at m₀ p₀)) (im : IsN m₀) (om : Ok m₀) → ¬ (code (at m₀ p₀) ia oa ≺ᴵ code m₀ im om)
no-path₀ : (im : IsN m₀) (om : Ok m₀) → ¬ ((code zero tt tt ≅ᴵ code m₀ im om) ⊎ (code zero tt tt ≺ᴵ code m₀ im om))
no-bound₀ : (im : IsN m₀) (om : Ok m₀) {c : Ordᴵ} → I.zero <ᴵ c → code m₀ im om <ᴵ c → ⊥
kp₁ : kp m₁ o₁ p₁ w₁ ≡ nothing
```
- `kp₀`: W4 保留, 但码 `zero` 不 `≺ᴵ` 码 `lim (λ _ → zero)` (`no-≺₀`)。
- `no-bound₀`: 两个码根本没有公共上界, Level 的 `<ᴵ-dec` 无从比较, 镜像在这里断了。
- `kp₁` 是 nothing 一侧的反例: `m₁ = nd sS (λ _ → m₀)`, 槽位取 m₀ 本身, 目标 zero, 路径 `inc tt (inc zero self)`。

由此得到简报原样的四条陈述都被否定, 陈述逐字见文件:
- `slotN-false`: 第 3 条;
- `pathN-false`: 第 4 条;
- `KN-just-false`: K 的 just 一半;
- `KN-nothing-false`: K 的 nothing 一半。

**(b) 严格层号上第 3 条的字面 `<ᴵ` 也不成立.**
- 构造: 层号 `W′ = nd sL g′`, 其中 `g′ = 1, W, W+1, …`。它有两份 Ok, `OkA` 与 `OkB`, 只在第 0 步的路径上不同。外层 `M` 的第 0 项是 W′ (取 `OkA`), 其后是 W′+1, W′+2, … (内部取 `OkB`)。`isM : IsS M`。
```
tagA : (i : IsN W′) → tagL (code W′ i OkA) ≡ 1
tagB : (i : IsN W′) → tagL (code W′ i OkB) ≡ 2
neAB : (i i′ : IsN W′) → ¬ (code W′ i OkA ≡ code W′ i′ OkB)
slot-literal-false : ¬ (code (at M pM) (IsN-at M iM pM) (Ok-at M oM pM) <ᴵ code M iM oM)
slot-M : code (at M pM) (IsN-at M iM pM) (Ok-at M oM pM) ≺ᴵ code M iM oM
```
- `tagA`/`tagB`: 两份证明给出的码, 第 0 步的 `⊑ᴵ` 证据不同。
- `slot-literal-false`: 即使子层号的证明取自父层号 (`IsN-at`/`Ok-at`), 字面 `<ᴵ` 也不成立。`slot-M` 是对照, 同一处 `≺ᴵ` 成立。
- 原因: 同一个子层号经两条路线到达 (直接作为第 0 项, 或作为后面各项的子项), 带着不同的 Ok 路径, 码只 `≅ᴵ` 不 `≡`。

#### 4. 不成立的命题与最小反例

- **简报原样的第 3、4、5 条 (只假设 IsN + Ok) 都不成立.** 最小反例是 `m₀ = nd sL (λ _ → zero)`, 槽位 `inj₂ (0 , inj₁ tt)`, 路径 `self`: W4 给 just (`kp₀ = refl`), 码却不满足 `≺ᴵ` (`no-≺₀`), 两个码也没有公共上界 (`no-bound₀`)。nothing 一侧的反例是 `kp₁`。四条否定都是编译定理。
- **加上 IsS 后全部成立 (编译定理).** IsS 是可满足的, 有 `IsS-tw1`。

**判断 (未编译):** IsS 是使镜像成立的自然最弱条件之一。缺了它只可能是极限层最终常值, 而 `Ordᴵ` 的 `lim` 在结构上不 `≅` 于它的常值项, 所以镜像必然断开。后续 M3 以后的段落应把前提写成 IsS, 或写成 "环境层号 IsS", 再由 `IsS-path` 和 `IsS-dn` 传到子层号与框架层号。
