- `addC : ∀ {j k₂} {D₂ : Ordᶜ k₂} {t₂ : Tr j} → IsN j → Ok j → Dom j D₂ t₂ → AddFor D₂ t₂`，八行全证，无参数。其中
  `AddFor D₂ t₂ = ∀ {k₁} {D₁ : Ordᶜ k₁} {t₁ : Tr j} → Dom j D₁ t₁ → ∀ {k″} (E : Ordᶜ k″) → E ≅ D₂ → Mirror k″ j → (τ : Simᴵ k″ k₁) → Dom j (add D₁ τ E) (t₁ + t₂)`
- 关键几行：
  - ru 行用 `simTr` 和 `Kid-≅`。
  - re 行把 V、X 沿 ≅ᴵ 用 r≅ 搬到左项的层。
- `addC′`：取 E 为 D₂ 自己的形式，rs 行用它。

**ru 行（KBRu）**
- `ruRow : … → Dom (nd s h) A₀ t₀ → BFor (nd s h) A₀ t₀ → Dom (h c) Y y → BFor (h c) Y y → (σr : Simᴵ k′ k) → A ≅ add A₀ σr Y → BForNS (nd s h) A (up t₀ c y e)`，不需要额外前提。分解见 `RuRep`：
  - A₀ 经 `embW` 搬到代表元的层。
  - 孩子树 Y 的镜像由 `Dom→Mir dY` 给出；经 `simTr` 得到层 k‴ ≅ᴵ k′，且 k‴ 字面嵌入代表元的层；Y 搬到 k‴ 后，孩子的归纳假设镜像与嵌入两样都有。
- sL 的 emb 一支（`EmbF.embFold`，对层号归纳）：链上自身行里构造的 Level 树放在各层的码上，用到下面几条新引理：
  - `liftC : (L₁ : L) {L₀ : L} (p : L₀ ≤ L₁) (i₁ : IsN L₁) (o₁ : Ok L₁) → Ordᶜ (code L₀ (IsN-path p i₁) (Ok-path p o₁)) → Ordᶜ (code L₁ i₁ o₁)`
  - `liftC-≅`
  - `embDomC : … → Dom L₀ X y₀ → Dom L₁ (liftC L₁ p i₁ o₁ X) (proj₁ (emb L₁ o₁ p (y₀ , e₀)))`：每层的规则 rz 用 `code-irr` 给的镜像，ru 的字面嵌入取 suc 或 lim n。
  - 此外 `emb-irr`、`emb-∙`、`bdPath`、`preI`。

**自身行（KBBase）**
- `selfRowG : … (i : IsN (nd s h)) (o : Ok (nd s h)) (S : Base (nd s h)) (β : Tr⁺ (nd s h)) … (P : Ordᶜ kP) (σ : Simᴵ kA kP) (r : jc <ᴵ I.suc kP) → (∀ {c} → c <ᴵ kA → c ≺ᴵ jc) → Pre S β P r → A ≅ A′ → Dom (nd s h) A′ t → Dom (nd s h) (ψ̂ r (add P σ A)) (ex (proj₁ β) (proj₁ β) (proj₂ β) t tt)`
  - re 规则取在目标层 jc 上；指数 `embW (≅W eJ) A′` 沿 ≅ᴵ 用 r≅ 搬过去；零项用 `rz (mj pre)`。
- 结点界用 `bdMir`：好代表元层的镜像加目标层的镜像。

##### 3. 没做成的
没有。上一轮的三行都证出来了，没有一行留成模块参数，也没有给任何引理暗中加前提。与 BStmt 的出入只有一处：内部归纳陈述 BFor 比 BStmt 强（对一切好代表元），BStmt 由它取 A″ = A 得到。

##### 4. 第二版里事后看多余的前提
前三条已在 KBAll 末尾编译：
- `mir-from-dom : ∀ {m k} {A : I.Ordᶜ k} {t : Tr m} → Dom m A t → Mirror k m`：BStmt 里的 `Mirror k m` 多余。按同样理由，OpStmt 里的 `Mirror k m` 可由 `Dom m X x` 得到，也多余（这一条是判断，没有单独编译）。
- `mj-from-base : … → Pre S β P r → Mirror jc j`：`Pre` 的 `mj` 多余，可由 `base` 经 `Dom→Mir` 得到。
- `rΩ-mir : … → Mirror j (at m p) → ((Y : I.Ordᶜ j) (z : Br m p) → SubD m p Y z → Dom m (F (I.into (I.<→◃ q) Y)) (g z)) → Mirror k m`：规则 rΩ 新加的第一个前提 `Mirror k m` 多余。它可由结点镜像加零下标处的分支得到：取 Y = 0、z = `fromBr m p zero`，Sub 由 `toSub (rz mp)` 给出。
- 不多余的（判断）：
  - rz 的镜像前提：不变式靠它起头。
  - r≅ 的层号限制 `k′ ≅ᴵ k`：加法相容与 (B) 的 r≅ 行都靠它。
  - `Pre.reP`、`CovS`、rΩ 的自反前提：都无法从其他前提得到。
