#### 2. 编译定理

以下都是编译定理.

**第 1 条: 定义 `pwb`** (V·ω^X), 六行与简报一致:
```
pwb : ∀ {k ℓ} → Ordᶜ ℓ → Simᴵ k ℓ → Ordᶜ k → Ordᶜ ℓ
```

**第 2 条: `pwb` 尊重 ≅.**
```
pwb-≅ : ∀ {k₁ ℓ₁ k₂ ℓ₂} {σ : Simᴵ k₁ ℓ₁} {σ′ : Simᴵ k₂ ℓ₂} {V : Ordᶜ ℓ₁} {V′ : Ordᶜ ℓ₂} {X : Ordᶜ k₁} {X′ : Ordᶜ k₂} →
        V ≅ V′ → X ≅ X′ → pwb V σ X ≅ pwb V′ σ′ X′
```
白话: 底和指数换成互模拟的树, 乘幂也互模拟. 两边的 Sim 可以任取.

**第 3 条: 自身层折叠的形状.** 异质版本:
```
ψadd≅ : ∀ {ℓ k k′ ℓ′} {a : Ordᶜ ℓ} {σ : Simᴵ k ℓ} {V : Ordᶜ ℓ′} {σ′ : Simᴵ k′ ℓ′} {x : Ordᶜ k} {x′ : Ordᶜ k′} →
  ψ {i = ℓ} {k = ℓ} {ℓ = suc ℓ} zero (λ q → suc q) a ≅ V → x ≅ x′ →
  ψ {i = ℓ} {k = ℓ} {ℓ = suc ℓ} zero (λ q → suc q) (add a σ x) ≅ pwb V σ′ x′
```
简报要的陈述:
```
ψ-add : ∀ {k ℓ} (a : Ordᶜ ℓ) (σ : Simᴵ k ℓ) (x : Ordᶜ k) → a ≅ a → x ≅ x →
  ψ {i = ℓ} {k = ℓ} {ℓ = suc ℓ} zero (λ q → suc q) (add a σ x) ≅ pwb (ψ zero (λ q → suc q) a) σ x
```
白话: 把第 ℓ 层的 a + x 放进第 ℓ+1 层再折回第 ℓ 层, 互模拟于 "ψ a 乘 ω^x".

limᵢ 那一行的机制和简报预期的一样:
- `<ᴵ-dec (suc (σ q)) zero` 定义性地归约为 `injᵃ (via (≅ᴵ-refl j) (σ q))`. 所以 ψ 一定走穿透分支, 输出结点就挂在 `σ q` 上, 和 pwb 的结点同层.
- 分支里的 `tr⁻ (≅ᴵ-refl j)` 用 `tr⁻-≅` 消去, 再用 `lᵢ≅` 对上.
- 另需两次 `out-into` 改写, 用的是 ≡ 改写 ≅ 一侧的小工具 `≡ˡ`/`≡ʳ`.

**第 4 条: 加法的结合与零单位.** 结合的异质版本:
```
add-assoc≅ : ∀ {m k ℓ m′ ℓ′} {a : Ordᶜ ℓ} {σ : Simᴵ k ℓ} {b : Ordᶜ k} {τ : Simᴵ m k} {A : Ordᶜ ℓ′} {ρ : Simᴵ m′ ℓ′}
  {c : Ordᶜ m} {c′ : Ordᶜ m′} → add a σ b ≅ A → c ≅ c′ → add a σ (add b τ c) ≅ add A ρ c′
```
结合:
```
add-assoc : ∀ {m k ℓ} (a : Ordᶜ ℓ) (σ : Simᴵ k ℓ) (b : Ordᶜ k) (τ : Simᴵ m k) (c : Ordᶜ m) →
  a ≅ a → b ≅ b → c ≅ c → add a σ (add b τ c) ≅ add (add a σ b) (λ q → σ (τ q)) c
```
零单位的异质版本:
```
add-zeroˡ≅ : ∀ {k ℓ k′} {σ : Simᴵ k ℓ} {x : Ordᶜ k} {x′ : Ordᶜ k′} → x ≅ x′ → add zero σ x ≅ x′
```
零单位:
```
add-zeroˡ : ∀ {k ℓ} (σ : Simᴵ k ℓ) (x : Ordᶜ k) → x ≅ x → add zero σ x ≅ x
```
白话: a + (b + c) ≅ (a + b) + c, 以及 0 + x ≅ x. 零单位不要求 σ 有什么性质.

**第 5 条: 先 ω^A 再 ω^Z.** 异质版本:
```
pwb-add≅ : ∀ {m k ℓ m′ ℓ′} {V : Ordᶜ ℓ} {σ : Simᴵ k ℓ} {A : Ordᶜ k} {τ : Simᴵ m k} {W : Ordᶜ ℓ′} {ρ : Simᴵ m′ ℓ′}
  {Z : Ordᶜ m} {Z′ : Ordᶜ m′} → pwb V σ A ≅ W → Z ≅ Z′ → pwb V σ (add A τ Z) ≅ pwb W ρ Z′
```
简报要的陈述:
```
pwb-add : ∀ {m k ℓ} (V : Ordᶜ ℓ) (σ : Simᴵ k ℓ) (A : Ordᶜ k) (τ : Simᴵ m k) (Z : Ordᶜ m) →
  V ≅ V → A ≅ A → Z ≅ Z → pwb V σ (add A τ Z) ≅ pwb (pwb V σ A) (λ q → σ (τ q)) Z
```
白话: V·ω^(A+Z) ≅ (V·ω^A)·ω^Z.

**第 6 条: 一阶迭代.** `it0` 的六行照简报:
```
it0 : ∀ {k ℓ} → Simᴵ k ℓ → Ordᶜ k → (Ordᶜ ℓ → Ordᶜ ℓ) → Ordᶜ ℓ → Ordᶜ ℓ
```
- suc 行是 `lim (λ j → iter (it0 σ X κ) W j)`.
- limᵢ 行保留成结点 `limᵢ (σ q) …`.
- up 行像 add 那样下降.

异质版本:
```
pwb-pwb≅ : ∀ {m k ℓ m′} {σ : Simᴵ k ℓ} {B : Ordᶜ k} {τ : Simᴵ m k} {ρ : Simᴵ m′ ℓ} {κ : Ordᶜ ℓ → Ordᶜ ℓ} →
  B ≅ B → (∀ {W W′ : Ordᶜ ℓ} → W ≅ W′ → pwb W σ B ≅ κ W′) →
  ∀ {X : Ordᶜ m} {X′ : Ordᶜ m′} → X ≅ X′ → ∀ {W W′ : Ordᶜ ℓ} → W ≅ W′ → pwb W σ (pwb B τ X) ≅ it0 ρ X′ κ W′
```
简报要的陈述:
```
pwb-pwb : ∀ {m k ℓ} (W : Ordᶜ ℓ) (σ : Simᴵ k ℓ) (B : Ordᶜ k) (τ : Simᴵ m k) (X : Ordᶜ m) →
  W ≅ W → B ≅ B → X ≅ X →
  pwb W σ (pwb B τ X) ≅ it0 (λ q → σ (τ q)) X (λ W′ → pwb W′ σ B) W
```
白话: W·ω^(B·ω^X) 互模拟于从 W 起把 "乘 ω^B" 迭代 ω^X 次.
- κ 要的 "尊重 ≅" 前提就是异质版本里的 `K`, 即 `W ≅ W′ → pwb W σ B ≅ κ W′`. 具体的 κ 由 `pwb-≅` 给出.
- suc 行对迭代次数 n 归纳. 每一步依次用 `pwb-add≅` (τ 取恒等), 上一层的归纳假设, 和 `iter-shift : iter G (G a) n ≡ G (iter G a n)`.
