# 第十五批 W4 一级回灌回报

ψ₀(Ω₃) 参照在从零起算的地址 `[1,1,0,1,0,0]` 上，其**整棵子树**的序数值已在标准 Ψ₃ 和实际 Λ 的 W4 值下得到无前提下界。第十四批核实的 `[1,1,0,1,0,0,2,0,2,0]` 位于这棵子树内。本批把六位地址的全部自然数孩子汇到同一实际运行。证明没有给出它与第十四批整支的严格值不等式。此次未覆盖完整 `[1,1]`、整棵 ψ₀(Ω₃)、BTBO 或 EBO。

## 编译定理

- `B15OrbitExit.bound` 对每个满足覆盖条件的三级 W4 运行成立。在标准三级运行及 Λ 实际访问的三级运行代入既有覆盖证书，得到 `standard` 和 `terminal`。两者都是单向值比较。在这些实例里，树、折叠、合法性和证书沿用原定义。
- `B15OrbitAction.raise` 把一个已有描述的前缀作用升为含一级分支的前缀作用。`B15OrbitRaise.Rule.exact` 证明若操作 K 已实现该作用，真实的 E(Ω₁,K) 就实现其升阶。对任意已描述、与自己结构对应的输入前缀成立，任一零层系数 y 只需满足 y≼read(z)，便可使用真实孩子 z。
- 更新同时传递汉语所说的四项，即输出值的下界、外框架零槽的下界、一级槽的描述、Ω₁ 对角自己读取的内框架零槽的下界。初始两条零路径可以取得同一底值；中间实际状态会在不同路径计算。每次更新都在该次的实际状态重新计算两份零槽见证。
- `B15OrbitEx.At.picked` 在该三级运行的一级指数中找到原有 ex b b (suc 0)。它的高阶后继将 E(b,_) 当成变换迭代。`At.all` 将同一个真实 Q 对所有有限 n 实现 raiseⁿ 的结论保留为可继续消费的状态。`At.branch` 单次运行的值出口逐一接到 `B15RefChildren.collect`；W4 和参照两种自然数迭代由 `B15OrbitExit.same` 归纳对齐。
- 参照方用 `B15RefRaise.arithmetic` 将第 n 个作用在任意前缀上的结果，校准为右加 co₁(Ω₁·n)。`B15RefChildren.whole` 把六位地址整树与这些项的极限逐项结构对应。W4 这边保持的是序数值下界。

## 冻结与检查

最终源为 `B15OrbitAction.agda`、`B15OrbitModel.agda`、`B15OrbitRaise.agda`、`B15OrbitEx.agda`、`B15OrbitExit.agda`。联合出口额外导入本批参照方的 `B15RefRaise.agda`、`B15RefChildren.agda`。五份源带 --safe、--without-K、--cubical-compatible、--guardedness、--hidden-argument-puns 和 --lossy-unification。最后运行 Agda 采用 6G 堆，联合入口退出 0；记录见 `B15OrbitExit.log`。未改仓库，未提交，未使用排中律、公设、洞或终止性绕过。

三个早期特例 `B15OrbitCount`、`B15OrbitBlock`、`B15OrbitPower` 在本路私有目录曾编译通过，其中 Power 将 [1,1,0,1,0,0,2,0] 接到两端。最终交付已将其中采用的证明归并到通用作用。试写的 `B15OrbitTransform` 未列入冻结清单。私有目录内 verifyref 保存联合编译实际读取的两份参照源。

## 尚待证明的命题与翻译账

已有通用定理允许**任意有限次** raise。在参照的 [1,1] 内，再向上一层会遇到一级 Ω 节点自己读取的变化零层系数。完整 [1,1] 要覆盖的逐项函数是 gain₁(x) = ψ⁰(co₁(ψ₁(co₀ x)))，其中 x 是前一折叠输出；参照方已经将内一级输入写成 H x Ω₁。此前计算表明一级操作 Γ(U) 的各项由 U 的一级指数作用反复计算。把高阶 It 按非有限、真实回灌的指数作用在变换上是下一步的候选。它尚未给出本次封存范围之外的 W4 下界，也没有被否定。

保留内外两零槽和使用同一 Q 的所有有限高阶迭代，分别来自 W4 的走链路径和其既有 ex/It 计算规则。Act 的参照部分和“右加 co₁(Ω₁·n)”的认定来自既有 Level 参照。本批只在第四层增加比较与验收关系。

# 第十五批参照回报

完整的 Ω₃ 基本列子树 [1][1] 已有一个只用 src 序数运算写出的闭项，与实际子树双向 ≼。W4 侧本批校准到的参照是 [1][1][0][1][0][0] 这一整棵六位父节点。前者给精确读法，后者有树侧有限次升阶的逐项入口。本路的定理均为无条件第 4 层结果。

## 已检查的陈述

- B15RefSource.closed 从 src 自己的 1 起步。每一轮先按上次零层输出构造 Ω₂ 的系数树，右乘 ω 的序列从一份开始，再折至一级、嵌入第三层、折至二级，最后取 src 的零层折叠。所有正号迭代的 ℕ 极限就是闭项。whole 证明 tr₀ closed 与 ψ₀(Ω₃) 的 [1][1] 双向 ≼。up 和 down 允许两侧输入仅有相应方向的 ≼，因此每一轮都能使用上一次真实输出，不须逐字相同。该闭项是验收参照。
- B15RefAlgebra.true-coeff 对每个零层树 x 展开 gain₁(x) 的真实一级输入。以 Ω₁ 为起点，在 x 上解释 Γ。Γ(u) 的第 j 项是以 Ω₁ 起步、把 E(u) 应用 j+1 次的结果。E(u) 的零行给 u，后继行取前项的 ω 倍，可数极限逐支，零层槽保留。B15RefMonotone 证明对这些树可按值弱化槽的输入。
- B15RefGain.described 对任意 x≼y 与任意已描述的二层前缀 p 给出 stage(x,p) 的两项描述和膨胀性。meaning 在正规前缀上给出 stage(x,p) 与 p 加 kernel(1,x) 的结构对应。values 在零前缀上给出与 gain₁(x) 的双向值桥。first 覆盖整个首项 x=1。reduce 和 necessary 把整支 W4 支配精确归结为真实回灌链各项的支配。
- B15RefRaise.arithmetic 证明任意 n 次升阶与在一级系数右端加 n 份 Ω₁ 相符，也允许从任意结构对应的前缀起步。B15RefChildren.whole 把 [1][1][0][1][0][0] 的所有孩子同时接到这同一族。collect 对任何共同终点成立，由树侧对每个 n 的值界即可组装。较深的 [1][1][0][1][0][0][2][0] 是 ψ₀(C·ω)，由 B15RefPower.full 的 refl 确认，ψ₀(C) 是此前的完整 [1][0]。

## 尚待实填

对 x=1，gain₁(1) 的完整目标还包含所有 Γ 的有限迭代。将整支 [1][1] 送入 W4，还需在每个实际反馈输入 x 上将 stage(x,0) 的折叠值送到同一物理终点。参照侧的 Described 和 src 双向值桥均已具备，这两个结论本身不提供该物理运行。以真实 It 在可数参数上迭代升阶算子是下次可审的候选，本批在有限次升阶的完整六位父节点收束。

冻结源码共七份，分别为 B15RefAlgebra、B15RefMonotone、B15RefGain、B15RefSource、B15RefPower、B15RefRaise、B15RefChildren。后两份使用同批树侧冻结的 B15OrbitAction。所有证明使用 Agda 安全模式与 6G 堆，未使用排中律、选择、函数外延、公设、洞或终止性指示。未改动仓库定义。

# 第十五批理想侧回报

**结论。** 假设排中律，标准理想 Ω₂ 的第二次回灌及包含它的全部前三项部分和，低于真实 W4 的 Λ 闭项。目标左边逐字使用第十四批标准理想 Ω₂ 分解 `B14SharpStation.Station.part lem 2`，右边是 `read W4Fold.EBOᶜ`。完整 Ω₂ 和记号 EBO 的值下界仍待证明。本批不新增以 ψ₀(Ω_x) 命名的闭下界。

## 已编译的定理

- `B15SharpSecond.Second.Run.second-prefix` 对任何具备上批真实运行接口的二层状态 r，证明双方同取实际第 0、1、2 项后的部分和不等式。单个最新项见 `Run.branch`。实例 `finiteRun 1` 接原有端点定理得到 `Second.terminal`。覆盖槽可以严格大于标准 Ω₁，实际起点和指定槽可以各自变化。
- `B15SharpAction.Action.Model` 给理想一级树以操作含义。它在任意有限个左侧加法前缀、理想底族、W4 状态、指定零层槽及独立输出起点上给出含前缀的零层值界。`power` 同步更新输出底与槽。`count` 把零层指数的值比较送进 W4 的 E，适用任意零层树及子框架；未要求 W4 对变动底族全局单调。
- `B15SharpLift.Lift.lift-block` 把一级保留 Ω₁ 的一次实际自折送入 `E Ω₁ G`，前提是起始树与操作 G 满足上述接口。标准起始实例由 `canon` 给出。保留分支中零层换型 τ 由 `cv≤` 逐树证明保持所需的值方向。`Second.Stage.self-blocks` 对任意有限和完成这个提升；取极限所得 `internal-model` 覆盖真实第二步里外层正迭代的整个底操作。这包含上批反例中取两次零号孩子抵达的 `B14SharpNext.Next.sub`。
- `B15SharpTail.Tail.Run.Compare n` 比较在第 n 个真实反馈指数上的 W4 E 与相应一级理想自折。`first-row` 和 `second-row` 分别填了 n=0、1。`next-item` 把任意已填行送到原两条轨道的下一项。`Tail.Terminal.whole` 给出充分条件，逐字为在 `finiteRun 1` 上对任意 n 从 `Compare (suc n)` 推出 `Compare (suc (suc n))`。此递推的首次未填实例是 `Compare 2`；本批没有它的证明，故没有完整理想 Ω₂ 的端点定理。
- `B15SharpRank.Rank.first-index` 已在再高一阶的操作上实填标准第一个变化指数，即在任意一级理想前缀、自折底和匹配 W4 操作 G 上，一级 Ω₁ 正次重复的自折低于 `G ↦ limₙ (E Ω₁)^(n+1) G`。`Rank.omega`、`powers`、`limit` 与 `next` 分别处理单个 Ω₁、正次数幂、极限及其组合。这里固定一级 W4 环境；`Compare 2` 还需要匹配该阶上再次保留 Ω 时进入子框架的操作。
