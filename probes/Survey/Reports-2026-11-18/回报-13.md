## 终点与有限层

已证明可沿所有后续有限层重复使用的升阶定理。子层若能在每个实际底族上把零基下界 a 提升到 f(a)，后继层就能达到 supₙ fⁿ(a)。若子层还有统一常数下界 Q，后继层可从 Q 开始迭代。[通用定理](attachments/B13FiniteLift.agda.txt)

取 P 为本批已校准的第三层 src 参数，得到两个无条件下界。[闭定理](attachments/B13FiniteClosed.agda.txt)

| W4 闭项 | src 下界的算术读法 |
|---|---|
| 标准塔 `twᶜ 1` | ψ₀(P＋ω^ω) |
| 显式终点 `EBOᶜ` | ψ₀(P＋ω^ω＋ω·2) |

只迭代常数更新 f(a)=Q，即使汇集所有有限层也不能覆盖 Q+1。上表用到了零基右乘 ω 的统一律。距离 ψ₀(Ω₃) 的缺口已写成显式终点上的充要条件，尚缺对参照实际问到的各行回灌参数的支配证明。[常数更新反例](attachments/B13FiniteNeg.agda.txt) · [终点充要条件](attachments/B13FiniteGap.agda.txt)

### 追加的有限层通用性检验

`B13FiniteLift`、`B13FiniteTower`、`B13FiniteSrc`、`B13FiniteClosed`、`B13FiniteNeg`、`B13FiniteGap` 均在 6G 堆上限编译通过。Gap 的依赖报告已有的 UnsupportedIndexedMatch 提示，退出 0。

**普遍律**。`Uniform j f` 的量化域为标准 Ω 槽有结构覆盖的一切 j 层运行，含任意允许的底族、零基 β 和任意 a≼read β。结论是 f(a) 不高于 Ω(j) 折到零层的值。`lift-uniform` 对每个非零子层 j 给出后继层的统一律，更新为 a↦supₙfⁿ(a)。其中后继是树层号的 sS 构造。子层 j 的类型并不要求是固定的有限层。真实后继对角的第 1 项是 ex c c (suc 0)，其中 c 为 j 槽；它的零层折叠包含右操作 K 的所有正次迭代。每次 K 操作用当时的底族重新计算，结构覆盖随之传递；每步使用的 Ω(j) 与 c 只在同一状态、同一路径和同一零基下比较。若子层还有对所有覆盖状态都成立的常数界 Q，第一次 K 更新已取得 Q，`lift-bound` 在后继层给出常数界 supₙfⁿ(Q)。这两条定理能一起递推。

**实际有限层**。`B13FiniteTower.Actual.allAt/lower` 在每个后续有限层的真实运行上给出常数；`at-omega` 对任意覆盖的层号 ω 运行收集全部。`B13FiniteSrc.Calibrated` 接受任一已校准有限层 j 的统一 src 界 P，取通用的零基右乘 ω 更新，推出后续每个有限层以及层号 ω 的 src 界。`opS 0 a = suc a`，`opS (suc k) a = lim (iter (opS k) a)`；`stages P 0=P`，`stages P (suc k)=opS(suc k)(stages P k)`。因此依次右加 ω、ω²、……，`omegaω P = lim (stages P)` 读作 P+ω^ω。src 证明的直接对象是这些显式递归式。

**不带形参的终点**。`B13FiniteClosed.Strong` 以第 3 层普遍定理 `B13Terminal.Calibrate.src` 及 P=`B12Arithmetic.source` 起步。`tower` 给标准 twᶜ 1≥src ψ₀(omegaω P)；`terminal` 给 EBOᶜ≥src ψ₀(plusω(plusω(omegaω P)))。后者的算术读法是 ψ₀(P+ω^ω+ω·2)。用到了所有后续有限层的量化定理。最后两次加 ω 沿真实的可数累加尾。上述下界均不含排中律、函数外延或额外前提。

**配对否定及 Ω₃ 缺口**。`B13FiniteNeg.no-higher` 证明每个 Q 的常数更新 f(a)=Q 从 Q 出发，经上述任意有限升阶再取极限仍不能覆盖 suc Q。这精确限制所选择的常数更新，不能作为 W4 终点或真实后继操作的上界。`B13FiniteGap.terminal-gap` 给真的 EBOᶜ 上的充要条件：所有 m,n 的 `ψ⁰(height₂(argument m n) 0)` 均不高于 read EBOᶜ，当且仅当 ψ⁰(Ω₃) 不高于它。第零行已由 Ω₂ 界承担，`argument` 的剩余行含真实的高层回灌参数。有限次升高定理生成的是 ℕ 次后继／极限闭包，没有为这些带高层参数的行提供模拟；亦无定理排除这种模拟。
