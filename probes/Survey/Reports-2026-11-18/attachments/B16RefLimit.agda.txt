-- 第十五批的固定 src 塔下界及其整族 floor，严格小于 Ω₃ 参照的六位真实兄弟 [1,1,0,1,0,1]。

source = out J.Boost.source
sibling = R.at Five.five 1

strict : L.suc source ≼ sibling
strict = ≼-trans Guard.into-two Five.under-second

-- 量化任意不超过此种子的初值，结论约束指定值运算本身。
floor : ∀ q → q ≼ L.ψ⁰ Guard.P → L.suc (L.lim (Guard.Bound.floors q)) ≼ sibling
floor q h = ≼-trans (s≼s (Guard.Bound.upper q h)) (≼-trans Guard.block
  (≼-trans (≼l 0 (≼-refl (L.ψ⁰ (B14RefSuffix.extend Guard.P))))
   (≼-trans (G.path-bound Guard.path (Five.Π (L.suc WVOne.𝟏))) Five.under-second)))
  where import B14RefSuffix; import WVOne

omega3 : L.suc source ≼ L.ψ⁰ R.Ω₃
omega3 = ≼-trans strict (G.path-bound (1 ∷ 1 ∷ 0 ∷ 1 ∷ 0 ∷ 1 ∷ []) (L.ψ⁰ R.Ω₃))

diagonal : L.suc source ≼ Cut.branch 0
diagonal = ≼-trans omega3 (≼-trans (≼l 3 (≼-refl (L.ψ⁰ R.Ω₃))) (≅→≼ Cut.cut≈first-branch))

bt : L.suc source ≼ N.BTBOᴵ
bt = ≼-trans diagonal (≼-trans (≼l 0 (≼-refl (Cut.branch 0))) (≼l 1 (≼-refl (N.γ 2))))

src-BTBO : L.suc source ≼ tr₀ S.BTBO
src-BTBO = ≼-trans bt (proj₂ BTBO≈)

original-two : L.suc source ≼ E.row 2
original-two = ≼-trans bt (≅→≼ (L.≅-sym (Lab-uniq (labR (E.H 2)) BTBO-label)))

original : L.suc source ≼ toL EBO-tree′
original = ≼-trans original-two (Goal.row-in 2)

no-upper : ∀ {x : T₀} → L.suc source ≼ x → x ≼ source → ⊥
no-upper h k = irr source (≼-trans h k)

no-sibling : sibling ≼ source → ⊥
no-sibling = no-upper strict
no-omega3 : L.ψ⁰ R.Ω₃ ≼ source → ⊥
no-omega3 = no-upper omega3
no-BTBO : tr₀ S.BTBO ≼ source → ⊥
no-BTBO = no-upper src-BTBO
no-EBO : toL EBO-tree′ ≼ source → ⊥
no-EBO = no-upper original
