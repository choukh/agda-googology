# 第十八批 direct 原样回报

实际 W4 在同一座标准 Ψ₃ 内覆盖 ψ₀(Ω₃) 的地址 [1]，包括它的全部 [1,n]。主线 Λ 的读值也有这个无条件下界。上批闭到 [1,1]，本批把一级运行的输出再次作各有限阶的指数，任意多次。树、折叠、合法性、证书沿用原定义。结论是单向序数值定理。

B18OrbitRows.standard : at (ψ⁰ Ω₃) 1 ≼ read Ψ₃ 与 terminal : at (ψ⁰ Ω₃) 1 ≼ read EBOᶜ。At.row r cv : ∀ n → B14RefRow.node n ≼ read (B12Terminal.value r) 与 At.whole r cv 对每个满足 Covered 的三级真实运行成立。标准运行和第 2 座有限运行给出两个闭实例。地址从零计数。

纸面检验选择了真实 Γ 更新的两个输入。默认一级槽内的 c 用来形成后续反馈指数，显式输入 b 用来形成 ex 的两个基数。B18OrbitExplicit.advance 证明只要两者实现同一个系数、默认槽包含 Ω₁，标准 F 或其支配运算的输出就实现该系数的 Γ 更新。b、c 可分别取不同树。进入环境、离开环境及迭代同时搬运这两个输入。

B18OrbitLift.next : World → World 将一个能保留零槽、收可数极限并实现 Γ 的系数空间升成全部有限阶作用的空间，逐项证出相同的物理实现律。旧问题里只对默认输入的推进在离开环境时不够，故实填基例首先需要上述对显式输入的推广。B18OrbitLevels.world : ℕ → World 由此支持任意有限深度。B18OrbitRows.At.indexed 同时量化解释深度 d 和回灌次数 k。每次 k 增加，把上一次实际一级树作 E 的指数，用 d+1 层的第零个作用在 d 层的实际基础运算上，再在原槽初值上运行。At.stored k 证明这一整棵保留节点确实位于同一真实 Ω₂ 回灌序列的第 k+2 项。用它支配原第 k+1 行的所有零层反馈点，全 n 用一次极限收合。无需单支抽取、排中律、选择或函数外延。

指数空间及深度递推属于验收用解释。一级参数、Ω 节点的保留、E 和 It 的运行以及原反馈序列的槽来自 W4。有限阶作用的分层与参照的系数递推相对照，故本次不把该解释算作主线定义自足。参照侧对接 B18RefDepth.value 和 B18RefRows.gain。

更外的地址 m≥2 仍待实填。既有 B13Target.all-arithmetic 把下一外行精确归到其真实回灌参数上的二层 height₂。这里所有升阶最终读取的是同一个一级槽，不能据此把该二层参照的作用宣布已实现。可检验的下一候选是将此次保留一级节点、逐次用真实输出作指数的通用律提到二级实际槽，并匹配 B13Target.argument 的两层回灌。本批没有判定这条候选成败，亦无 ψ₀(Ω₃) 整体或 BTBO、EBO 的闭下界。

冻结源码共八份。B18OrbitSpace、B18OrbitExplicit、B18OrbitWorld、B18OrbitBase、B18OrbitNatural、B18OrbitLift、B18OrbitLevels、B18OrbitRows。末文件以本项目库表、src、probes、上批归档、本轮 direct 和 reference 为 include，单 Agda 进程带 +RTS -M6G -RTS，退出码 0。八个新模块均有检查器接口，静态复查无公设、洞、绕过终止或正性检查的指令。仅写本路实验目录，未提交。

# 第十八批参照路原样回报

第 4 层无条件序数值结果。W4 在 Ω₃ 的原生参照上前进到完整第一正外行 [1]，其中每个自然数行号、每个零层回灌号均被同一实际终点覆盖。该桥沿用原树、折叠和证书，并没有用排中律。独立的原 EBO 有限乘积封顶适用于每个塔行。

## 原 Ω₃ 第一正外行

B18RefDelta.increment 在任意正规二级前缀 p 上，若 collapse(p) 与一级系数 u 结构同值，则 collapse(p+co₁(x)) 与 δ(y,u) 结构同值，其中允许 x≅y。δ 的零行是 Γ(u)，后继行对原作用做自然数次迭代再取极限，普通极限逐项，高一级的 Ω 槽保留零层输入。family 把第 n 个核统一成 co₁(coeff n x)，所有 n 和零层树 x 都包含在陈述中。

B18RefModel 与 B18RefTower 对任一对普通极限、Ω 槽和结构同值封闭的系数空间，证明下一层空间仍具有这些性质，且各阶共同表示同一个系数。新的基础作用接受可变原前缀，精确实行 δ。B18RefDepth 定义实际分级模型所共用的空间、种子、更新和降层程序；B18RefRows.compute/gain/accept 对任意深度 d 和行号 k 成立，每次降一层就从 coeff(k+1,x) 变为 coeff(k+2,x)。orbit 的 B18OrbitRows 以实际高阶 It 实现同一套运算，standard 和 terminal 的左端都是 ψ₀(Ω₃) 的 [1]，分别落到 read Ψ₃ 和 read Λ。

B17RefAllSource 的纯 src 双向桥仍适用，第一正外行对应 outer 1。后续外行的 pass 次数 m 仍变化；对固定 [1] 的全部 n 的封闭不提供 m 的归纳步骤。完整 Ω₃、BTBO 与 EBO 物理验收须另证。

## 原 EBO 有限乘积

B18RefProduct.cap 给出，对所有 k，suc(limₙ (row k)ⁿ) ≼ row(k+3)，使用主审 B18Product 的普通序数乘法，零次为 1。每一项已不超过 row(k+2)。B18RefExponent.multiply 对所有零层树直接证明 ψ⁰(a)·x ≼ ψ⁰(a+x)。在正规记号侧，对每个有限和在左端放入 ΩTower(k+1)；Prefix.bound 对任意带 HC 证书的右尾 s，在这个含前缀的记号下吸收 ψ⁰(Rt s)。G 条件与跟更高塔行的比较都对所有 k,n 实填。该结果只约束所述有限乘积列，使用者需另证 W4 残余落在乘积界内。

## 理想 Ω₂ 的零层升阶

B18RefHeight 对任一严格增长的理想零层底作用 f 给出 read z ≼ see(hierarchy z f a) 和 suc(see a) ≼ see(hierarchy z f a)。任一零层值 t 都可经 inflate 得到一个带有合法递增列的 W4 树，其读回至少为 t。由此验证两种不可成立的全称上界：固定 a 后不能用同一可数树封住全部 z，固定 z 后不能用同一可数树封住所有正底。这两条一般结论无经典参数，对 B17SharpSelected 的专门化使用其原有的排中律参数。本批没有得到对指定 idx 和指定继承底，将 α(κ idx) 或原 BTBO 的 γ₂ 送入 H 的闭比较；上述反证允许另择高度或另择底。


B18RefIdeal 将两种可实现的量词写成闭构造。按既有 ψ♯ 的参数给定 LEM 后，chosen-height 取 read z ≥ γ₂ 的一个另择 W4 高度，由标准正底取得原 γ₂ 下界；chosen-base 对任意 z 给出一个含 α(κz) 的正底，从而其 H 值至少是 α(κz) 的后继。两条的见证数据均显式构造。floor 对每个 z 的标准理想底继承 src 的 ψ₀(Ω₂) 下界。它们可用于核对何种强度来自输入。

# 第十八批 ψ♯，把第一次变出的指数送回同一真实 Ω₃ 反馈

**条件定理（第 4 层排中律）。** 已证明一个严格超过上批标准理想 Ω₃ 两项累加前缀的闭式，并把它的后继送入 W4 实际单元 `cell 1 0`。更一般地，同一座塔的每个 `cell 1 j` 都收到该后继。下标 1 是 `B17CellPrefix.At 1` 的塔参数。闭式使用标准理想 Ω₃ 的第一个变化指数 `u = step 0`，在变化的理想底上再次折它。全部自然数层的迭代在同一个真实操作 G 上实现，G 位于第三层 Ω 节点的反馈项 2。这个闭式与完整标准理想 Ω₃ 有一个已校准的共同下界，两者之间的直接比较尚待证明。

**构造与操作。** 第一变化指数逐字等于 `next⁺ (Ωt r₂)` 的树部分。`B18SharpMacro.Coeff.Use` 处理零初值和一级指定槽。一级结论保留 `Linked`，即全部有限高阶操作的解释和变化底上的零层输出，所以新的一级系数可以再作指数。`B18SharpEffect.Effects.Models` 要求操作同时传递这两个槽和任意被实际初值支配的零输入。一次正迭代依次更新所有理想坐标与实际状态，外面取含所有正次数的可数极限。`Raise.raised` 把每一个已实现动作的这项迭代交给真实运算 `E(c,Q)`；它实际用到 c 覆盖标准 Ω₂ 的证据及真实首孩子到数次 Q 迭代的等式。

**同一实际反馈点。** `B18SharpHead.Head.seed` 为把 u 折到任意底和任意初值的理想动作。`stage 0` 取此动作，`stage (n+1)` 取上一动作的全部正次数迭代极限。`diagonal` 在同一起点取全部 n 的极限。`At.levels` 把这族动作逐项配给物理运算 `E(c,_)` 的升阶。真实 G 的下标 n 分支就是第 n+1 个运算。`At.whole` 由 G 单一实现整个 `diagonal`，包括一级槽的全部高阶解释。

**闭项与源校准。** `B18SharpClosed.Closed.form` 再取该对角动作的全部正次数迭代极限。标准底和一作零起点时的零层读值为 `read-closed`。对一切覆盖全部标准槽的真实第三层运行，`Run.member` 与 `Run.all` 把对应任意合格零初值的每次迭代、整个极限送入同一运行。具体到真实 `finiteRun 2`，`Λ-bound` 与 `fixed j` 分别给出终点界与固定塔各孩子的严格界。`src-first` 与 `higher` 给原 src 的 ψ₀(Ω₂)、真变指数再次折到零层的值、本批闭式之间逐次各有后继余量。`B18SharpGain.Gain.At.strict-prefix` 比较整条旧两项累加前缀，任意零初值 a 均有 `suc(readRW(cum(item a) 1)) ≼ readRW(form B♯ a)`。此严格比较针对上批 ψ♯ 路的标准前缀；与其他线路已证明的源界之间没有在这里建立比较。

**标准第二次指数的检验。** `B18SharpShape.Cut.first-word` 与 `no-repeat` 给同一文法的正反对照。文法从零出发，可追加标准 Ω₂ 块，也可取任何继承合法分支的可数极限。第一次指数在此文法中；第二次不在。第二次对自身层的保留节点，其指定首孩子外形为可数极限，而文法中 Ω₂ 块的指定首孩子外形为 up。把可数极限再封闭任意多次仍改变不了这个子项。`first-in-second` 另证第一次指数确为第二次的严格树内前项；`common` 把再次折第一次指数所得零输出的后继送到标准理想 Ω₃ 的全值，真实侧已能容纳这个共同下界。

**未填陈述。** 标准理想第二次及以后各项涉及 `ψ♯ r₂ … r₂ …` 所保留的 Ω 节点。要得标准理想整棵，需要证明这些节点随实际一级输入变化的子函数还能充当二级指数，随后在整条真实轨道保持。上述语法否定只涉及该确定文法。这里没有得到完整标准理想 Ω₃ ≼ W4，也没有得到 src ψ₀(Ω₃)、原 γ₂ 或原 EBO 的新校准。与参照路沟通后，没有可直接合用的 H 上界。

六份私有源码为 B18SharpMacro、B18SharpEffect、B18SharpHead、B18SharpClosed、B18SharpShape、B18SharpGain，均用 `--safe --without-K`、单进程 6G 编译，无洞、无公设、无终止性豁免。排中律仅作值验收参数。未改仓库，未提交。

# 显式零层起点的参数比较

对任意层号 ℓ、合法性 o、环境 B、路径 w : zero ≤ ℓ、树 x 和两个合法正零层起点 a、b，若 R 对自反、同时加法、逐分支可数极限成立，则 R(a,b) 蕴涵同树同环境下的两个 ψ 输出仍满足 R。允许 R 非对称。实例可取零层树值的反身比较或恒真关系。

`B18BaseRel.Test.eval`、`index` 在每个自然阶沿 W4 原有 E、It 递归证明底关系保持。up 的子语境明确写出转入的操作和有序性证书。`B18BaseFold.Check.fold` 逐个处理 ψ 构造子，up 的 sL 路径使用 cW-ind₂，sΩ 的 inc 路径在两边追加同一项，ex 将 E 的底操作还原为同一真子树上的 ψ。

两个新源码独立复制到空接口目录，以 6G 和工程选项从同一个导入入口检查，两份源码均实际重编并退出 0，公共依赖复用已审核的接口。禁用构造扫描无命中。该关系定理比较固定 B 与 x 的两个外部零层起点。实例的序数乘法界和与首个原参照塔行的比较由主审另接。

# 正塔的重置值与真实反馈孩子

固定 Λ 的正塔编号 `suc n`，在其真实反馈链的第 `j` 步记 `x n j = B18CellState.At.fresh n j`。层号由真实索引 `ix n j` 决定，槽族来自标准塔的逐塔右加，显式零层起点取 1。

- `B18ResetCell.At.exact` 证明该塔从 1 开始的值与 `lim m (x n 0 + … + x n m)` 双向比较。这里有限和从左向右累计，`At.branch` 将每个实际索引上的读回与同一处的标准槽族 fresh 值逐个等同。没有使用函数外延。
- `At.into` 将每个重置孩子放回重置正塔。`At.bound` 证明若该塔所有孩子的值均 ≤ Q，则重置正塔值 ≤ Q 的 ω 倍。`At.cap` 证明取 Q 为原塔行 k 时，重置正塔值的后继 ≤ 原塔行 k+1。
- `B18ResetCell.first` 证明第零座塔从 1 开始的值与 `x 0 0` 字面相等。`B18ResetCellGoal.First.omega` 给出该值与 ω 的双向比较。上述各条无经典前提。
- `B18ResetCell.enough` 证明每一原行都被某一 `x n j` 支配，即推出 EBO 序数值下界。`B18ResetCellGoal.Classical.necessary` 在排中律下由终点下界给每个 k 找出 n,j，使 `suc(row k) ≤ x n j`。`Classical.iff` 给出完整的两向判据，取塔见证的闭接口由 `B18ResetGoal.Classical.necessary` 实填。构造方向、精确形状与乘 ω 上界均独立于排中律。

检查使用同批最终的 B18ResetGoal、B18Scale、B18Reset、B18TowerSlots、B18CellState 及其依赖。两份模块以 6G 编译通过。该判据将原终点的待证工作精确落到保留真实反馈索引的孩子上。它本身没有给每个原塔行选出满足下界的孩子。
