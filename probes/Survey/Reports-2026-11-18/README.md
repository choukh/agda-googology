## 在同一标准 Ψ₃ 里取极限

在真实状态上维持三个见证：输出零槽的值、链所用的零槽的值、一层状态能实现的前缀指数。算子 J 的一次更新可在前缀右侧加 Ω₂。折叠 Ω₂ 于任意算子 K 时，输出含有 K 全部正次数迭代的分支。两个零层界可以逐支取极限，一层指数也可在同一棵子树上取极限。这使第一次 G 更新可以容纳 Ω₂·ω 的三个见证，第二次即可取得 Ω₂·ω＋Ω₂ 的三个见证。[真实分支](attachments/B12Orbit.agda.txt) · [后继更新](attachments/B12Update.agda.txt) · [通用合并](attachments/B12Gather.agda.txt) · [两次更新的闭实例](attachments/B12Omega.agda.txt)

G 的第 k 个孩子实际包含 k+1 层上述操作。为核准算术读法，在 src 参照中单独定义下面的序列。每个 sup 由源码中的自然数极限实现，迭代第 0 项为输入 x。

- h₀(x) = x＋Ω₂。
- hₖ₊₁(x) = supₙ hₖⁿ(x)。
- d(x) = supₖ hₖ₊₁(x)。
- P = supₙ dⁿ(Ω₂)。

主审证明，对每个 k，实际算子实现 hₖ；一轮 G 实现 d。因此 src 的 ψ₀(P) 已落入 Ψ₃ 的第 2 个原始项，又落入第 2 个累加项。W4 零层的每条合法步进都给出后继下界，故 ψ₀(P) 的后继仍 ≤ Ψ₃，反向上界推出矛盾。折叠后的比较是编译定理。把 P 写成 Ω₂·ω^(ω+1) 是上述递推的算术读法。[层级归纳](attachments/B12Hierarchy.agda.txt) · [src 与 Level 的对应](attachments/B12LimitSrc.agda.txt) · [零层严格步进](attachments/B12Strict.agda.txt)

**在 Ω₃ 参照的实际位置。** 从 ψ₀(Ω₃) 依次取孩子，编号从 0 起。地址 `[1,0,0]` 的树与 ψ₀(Ω₂·ω) 互相 ≼。地址 `[1,0,1,1,0,0]` 的所有孩子都已有 Ψ₃ 下界，取极限得整个子树 ≤ Ψ₃。地址 `[1,0,1,1,0,1,2,2,1]` 的子树与用反复左加及极限写成的 ψ₀(Ω₂·ω^(ω+1)) 参照结构等价，已证它 ≤ ψ₀(P 的 Level 对应物) ≤ Ψ₃。这里各处都给出明确的分支、括号和起点。[分支展开](attachments/B12Omega3Ref.agda.txt) · [全孩子与极限](attachments/B12Omega3Cuts.agda.txt) · [深处子树与主界相接](attachments/B12Omega3Tail.agda.txt)
