## 可复算的值

六位地址的第 n 个孩子对应一次在前缀右端加入 `co₁(Ω₁·n)` 的操作，再折回零层。这里 `co₁` 取一级树，嵌入第三层后折至第二层。W4 用现有的指数构造在同一次真实运行中实现所有有限 n。上批的十位子树是新地址再走 `[2,0,2,0]` 的子树，已有值包含定理。新旧两棵子树之间的严格性仍未校准。[逐个孩子的对应](attachments/B15RefChildren.agda.txt) · [W4 两个闭出口](attachments/B15OrbitExit.agda.txt) · [包含定理](attachments/B15Join.agda.txt)

令 D 为如下纯 src 二层树。其第 0 项是 Ω₂，第 n＋1 项把 Ω₁ 的 n＋1 份和嵌入第三层再折至第二层，D 对这些项取可数极限。**src ψ₀(D) 与六位子树双向 ≼**。对任意已在某一正有限层的所有覆盖运行上成立的常数界，新定理从这个界起步，传过整座 W4 塔。对 D 实例化，Λ 的新 src 下界按 Ω 算术读作 **ψ₀(D＋ω^(ω²))**。代码中的精确左端是 `out Boost.source`。算术读法来自对后继、可数迭代与塔极限的解释，未另证一个算术记号等式。[src 双向值桥与闭下界](attachments/B15Join.agda.txt) · [src 塔递推](attachments/B15SourceTower.agda.txt)

这次升层的关键在于每个正塔项自己的第一次回灌。若前一塔项在持有其规范合法性证书的所有覆盖运行上实现值操作 f、具有常数界 Q，则下一塔项的同一个真实孩子同时覆盖 f 的所有有限阶可数迭代，并给出相应的常数界。证明记录了进入子节点后实际持有的证书。它只沿后继、可数极限的指定孩子、不可数节点的零号孩子传递值。任意 W4 结构步进经层号读回都生成这样的路径。这里的层号 n 可以任意变化，但还没有把每层的值作用认定为原参照的第 n 个折叠。[安全路径](attachments/B15ReadPaths.agda.txt) · [证书与回灌](attachments/B15TowerIteration.agda.txt) · [有限层起步](attachments/B15TowerSeed.agda.txt)

## 从 EBO 的原定义倒推

原参照第 k＋1 行的第 0 个孩子就是第 k 行，沿基本列的全部孩子则由该行的真实 γ 回灌给出。应用到原参照树 `EBO-tree′` 与现有 Λ 闭项，得到对**任意有限起点 K**的充要条件：原 EBO ≤ Λ 当且仅当第 K 行起的每一行都 ≤ Λ。因而可以直接攻高行。如果成功，较低行（包括 BTBO）也随之得到；当下仍欠这整族比较。完整 `[1][1]` 也已找到一个纯 src 闭项并证明双向值桥，其 W4 下界对应一个独立的全称命题。[原 EBO 充要条件](attachments/B15OriginalTail.agda.txt) · [整支的 src 值](attachments/B15RefSource.agda.txt) · [整支的 W4 缺口](attachments/B15RefGain.agda.txt)

## 路线取舍

本轮判断保持直接法为 W4 的主证明，保留理想折叠作同题对照，同时把下一轮的一路放在原 EBO 塔上。下一次先在纸面检验原始 γ 回灌需要的作用，能否由树侧统一升层给出，或能否给出一条从已覆盖行到下一实际行的保持律。若一次派发只会把一个固定地址再展开几层，优先验证上述缺口。每批记录缺口与实际端点，每三批完整复评。连续五批同一必经缺口未动，按约定交作者选择方向。三批评估与判据见[第四十五份评估](../GoalOdds.md)。
