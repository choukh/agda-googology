## 相邻正塔的所有孩子与终点取样

B17CellNext.previous n j 证明第 n 个 Λ 孩子的值低于下一座正塔的每个第 j 个反馈孩子。其原因是下一座正塔的继承底值已容纳前塔整值，而进入反馈孩子时 parent 输入取 zero，正好保留这个底。strict n j 再由真实子 Run 中的合法步进 zero ◃ Ω 给出前塔值的后继也低于该孩子。

- fixed 从任意 suc x ≼ read EBOᶜ 的比较证明中提取 n，使每个 j 都满足 suc x ≼ cell n j。eventual 给出更强的统一见证，所有编号 m ≥ n 的塔、其中每个 j 都能承接 suc x。
- eventual-goal 把整体 EBO 验收等价地表述为每个原行的后继最终被所有塔、所有反馈孩子承接。prescribed j 允许按原行与塔号预先指定孩子编号。
- every j 证明任选 j : ℕ → ℕ，read EBOᶜ 与 lim (λ n → cell n (j n)) 互相 ≼；zero-chain 可恒取编号 0。sample 进一步允许任选带共尾见证的塔号 ρ，无须 ρ 单调。零号孩子已经载有前一整塔的底值。
- 本批二位整行进入具体的 cell 0 1；封口后的纯 src 新界 tr₀ B17Join.source 进入 cell 1 j 对所有 j 成立。定理名分别为 row-in-first、source-in-every。
- 上述取样、见证及实例均未使用排中律。若指定必须从先前同一座塔、同一有限前缀里选单项，则是另一个局部命题。本补件的无条件单项落在继承前塔底值的新塔中。

# 第十七批追加，原 EBO 后续行给有限重复求和封顶

**编译定理，无前提。** 记第 k 行原参照值为 `row k`，`first k` 为第 k+1 行基本列下标 1 的读回。任意用非空有限多个 `row k` 相加所得的有限表达式，其后继不高于 `first k`。任意自然数编号的这些表达式的极限也不高于 `first k`，并且这个极限的后继不高于 `row (suc k)`。包括 `Mv (row k) 𝟏` 和每次末尾追加 `row k` 的版本。该封顶是原参照一侧的定理，向 W4 真实反馈孩子搬运时还需相应的实际值定理。

- `B17CapAppend.append` 在任意给定的三个 HC 证书上，把零层两棵参照树的和放到记号列表拼接的读回之下。对右证书递归，使用已有的拼接前驱与基本列等式。
- `B17CapRows` 定义二叉加法表达式，允许任意左右括号，并给正有限重复列表的标准形与可数性证书。`eval` 把每个树值和置于其重复列表读回之下。`mul-limit`、`right-limit` 给极限到下一行的界，`mul-strict`、`right-strict` 给其后继到下两行的界。
- `B17CapFirst` 把上界缩到固定的下标 1。`first-index` 证明下一行原 γ 链的下标 1 恰是 `EBOψ k`。`first-rise` 从 `1 < EBOψ k` 沿 k 次 Ω 嵌入提升，得到 `ΩTower k < powers k (chain k 1)`。两边再取零级 ψ，左边可附加任意多个同一主项，列表仍严格低于右边的单主项。`finite-first` 与 `limit-first` 给出全部有限加法式及整条极限的固定孩子上界，`strict-first` 用原基本列的严格递减证书得到固定孩子的后继不高于下一行。直接调用 `mul-strict k`、`right-strict k` 或一般的 `strict-limit k f` 即得后继落在第 k+1 行。全部标识符均在对应模块中有实际证明。
