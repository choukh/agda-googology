# 第十七批，整支 [1,1] 与原 EBO 的验收条件

同一棵 W4 的 Λ 已无前提地支配 ψ₀(Ω₃) 的整支 `[1,1]`。从根起、孩子从 0 编号，连续两次取第 1 个孩子，所得整棵树及其所有回灌项都在定理范围内。上批只覆盖它下面的五位子树。另已证明，若一族原记号标准形的指定下标深度有界，即使取整族的可数极限，其值仍低于 EBO。这给周期复评提供了一个尺度。完整 ψ₀(Ω₃)、BTBO 和原 EBO 在 W4 上的下界仍开放。[整支的两个实际出口](attachments/B17OrbitRow.agda.txt) · [深度与 EBO](attachments/B17Depth.agda.txt)

## 本批改变了哪项判断

第十六批提出，用同一个实际高阶作用不断更新，看它能否生成下一个原孩子要求的系数。本批先验算两个参数的位置。沿用上批作用所得整族正次迭代的极限，其后继仍不超过下一个原孩子。互换指数作用的两个参数也会给出严格偏低的界。于是停止用这两个算式猜测下一支。在实际 W4 的第二个反馈点，可以找到一个保留下来的 Ω₁ 节点。该节点的每个孩子按自己的零层输入产生所需的高阶作用，上一步的输出又充当下一次输入，由此一次覆盖整支 `[1,1]` 的全部回灌项。结论同时对标准 Ψ₃ 和所有带覆盖证据的实际第 3 层运行成立。[重复的严格界](attachments/B17RefAgain.agda.txt) · [交换两参数的反例](attachments/B17RefSwap.agda.txt) · [实际反馈](attachments/B17OrbitRow.agda.txt)

取 `[1,1]` 的纯 src 等值闭项作种子，沿用上批已经证明的动态升阶和同一座实际塔，得新 src 闭项 S。已证 **上批完整动态下界的后继 ≼ S 的读回 ≼ read EBOᶜ**。参照侧也已用纯 src 运算重建 ψ₀(Ω₃) 的所有正外行及其回灌孩子，并证明整体双向 ≼。W4 侧要从 `[1,1]` 前进一步，仍需解释一级输出如何再次充当全阶指数。完整 Ω₃ 的已知充分条件还要处理外行号变化时的二层迭代。[严格改善的闭界](attachments/B17Join.agda.txt) · [完整 src 对照](attachments/B17RefAllSource.agda.txt)

## 终点允许哪些替代路线

记 R(k) 为原 EBO 基本列的第 k 行。对每个可数标准形 t，沿其首项 ψ₀(a) 的参数 a 反复读取首项的下标，把这条链的长度记为 d(t)，空项另取 0。原 EBO 下界成立，当且仅当对任意 k，都能给出一个 d(t) ≥ k+2 的可数标准形，以及一个实际 Λ 孩子支配 t 的值。不必预先指定 t 等于哪一个塔行。若整族 t 的 d(t) 均不超过 k，整族的极限至多为 R(k)。例如 BTBO 的每个正对角项深度恰为 2，整族与 BTBO 结构对应。另有 suc(ψ₀(Ω_ω)) ≼ R(2)，即使把所有有限 Ω 层收集起来，离 EBO 仍有严格间隔。[深度怎么算](attachments/B17Cofinal.agda.txt) · [充要条件与有界反例](attachments/B17Depth.agda.txt) · [BTBO 实例](attachments/B17Calibration.agda.txt)

还可以直接检查 W4 的真实反馈。每座正塔的零层输出就是其反馈孩子有限累加前缀的极限。原 EBO 下界等价于对每个 R(k) 找到一座正塔和其中一个有限前缀，能容下 R(k) 的后继。两向均不用排中律。参照侧的另一条定理说，将 R(k) 有限次相加，任意取括号，再取可数极限，其值都不高于 **R(k+1) 的第 1 个孩子**，极限的后继也不高于 R(k+1)。由此可从已假定的 EBO 下界定位一个有限前缀，其中所有孩子同时不超过 R(k) 会导致矛盾。[真实有限前缀](attachments/B17CellPrefix.agda.txt) · [下一行的固定孩子](attachments/B17CapFirst.agda.txt) · [有限前缀的矛盾](attachments/B17Single.agda.txt)

若要求在这个已经选定的有限前缀内挑出一支，第四层的排中律提供所需的局部值二分，可以选出支配 R(k) 后继的实际孩子。能否在同一前缀中省去二分仍开放。[经典二分](attachments/B17ValueDich.agda.txt) · [固定前缀的结论](attachments/B17Single.agda.txt)

复核时回到原目标，发现塔号可以换。下一座正塔的每个反馈孩子都从一个已容纳上一整塔输出的底开始。沿该孩子内部的合法步进，还能保留一个后继的余量。由此**每座正塔都预先选第 0 个反馈孩子，这些孩子的极限就与实际 Λ 双向 ≼**。任选其他孩子编号也成立，甚至可以只用带共尾见证的塔号子列。整个等值定理没有前提，不需要排中律。这里孩子的起点包含上一整塔的计算。对 EBO 的等价验收遂可固定孩子编号，只需给每个原行找一座足够高的塔。已有闭实例：整支 `[1,1]` 进入第一座正塔的第 1 个反馈孩子，新动态 src 下界进入第二座正塔的每个反馈孩子。[共尾取样、全零取样与两个实例](attachments/B17CellNext.agda.txt)

## 同一 BTBO 缺口上的三种尝试

原 BTBO 对角的第一个未闭值项是 γ₂。上一批已将全行归约到一族真实下标的下一步输入。对 γ₂ 所问的第一个实际下标 i₃，本批证明其全部源前驱都能放进实际槽，任意一对源前驱的相对位置都触发 W4 应有的保留或走链，保留时对每个输入成立。另在任意两个有共同上层的有限塔层上，已确定相应的整条 Ω 折叠规则，包括走链时由哪次实际折叠给出下一下标。这些定理管具体规则；折叠后输出的全称值比较仍待完成。[BTBO 的实际槽](attachments/B17ActualSlots.agda.txt) · [塔层的完整计算行](attachments/B17TowerRules.agda.txt)

旧折叠提供另一个左端。任意真实零层树 z 都能逐枝复制为旧折叠的合法输入，而且原 ψ₀(Ω_{κ(z)}) 已被对应的旧输出支配。若能把旧输出运回实际 W4，就能接上原 BTBO；也可把旧标准轨道各点分别送往某个实际塔点，容许两边编号不同。这两种搬运仍是充分条件。[旧折叠与原下标](attachments/B17Legacy.agda.txt)

理想折叠 ψ♯ 的进展有两个实际端点。首先，在第一塔的每一个正反馈下标 z，可以从该次运行自己的底出发，沿 z 的完整树结构迭代以理想 Ω₂ 折叠为基础的操作，所得值已被下一实际输入支配。把原 ψ₀(Ω_{κ(z)}) 放到这个候选值之下仍待证明。其次，标准理想 Ω₂ 折到一级的输出现在可以在任意有限次真实更新中复用。这给出标准理想 Ω₃ 折到零层后的初始项与第一个变化项组成的部分和 ≼ read EBOᶜ。两处使用排中律作验收参数。下一变化项需要以已经产生的二层输出作指数。[变化下标](attachments/B17SharpSelected.agda.txt) · [一级输出的全部操作阶](attachments/B17SharpUpdate.agda.txt) · [理想 Ω₃ 的首个变化前缀](attachments/B17SharpThree.agda.txt)

## 周期复评

直接路线已解决上批指定的参数位置问题，并给出严格超过上批动态下界的闭定理。理想路线已在真实变化层号上运送一族值，尚缺将原 BTBO 所问的折叠放进这一族的定理。两路所比较的左端不同，现有结果不足以给到 EBO 的总工期排序。树侧的实际反馈、保留下来的槽和有限累加都取自已有定义。定位 `[1,1]`、计算原行的深度和封顶用到了记号；上述值定理没有改变前 3 层或给出树自足的验收。

本批也暴露了派工的一个问题。我们花了力气证明怎样从固定前缀里挑孩子，后来检查终点的量词，发现换到下一塔就能构造性地指定第 0 个孩子。把固定前缀抽取和有限和封顶保留为局部工具。终点优先检验固定第 0 个孩子后的值校准。先写出所需比较的左右端、哪些编号可换、哪些必须相同，再为确实需要的模拟写码。

第十八批的纸面检验分别问三件事：随塔号变化的第 0 个实际孩子，能否容纳原下标深度随之增长的标准形；直接路线新生成的一级输出能否再次充当一级指数；理想路线的二层输出能否承担下一轮指数。固定 Ω₃ 下再增加一个地址只能算该中间站的进展。第十八批末按约做三批完整复评，以 γ₂、完整 Ω₃、原 EBO 的实际值端点判断是否调整投入。[内部回报原文](回报-17.md) · [复评约定](../GoalOdds.md)
