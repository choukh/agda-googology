# 第十六批 · orbit 原样回报

实际 W4 的同一次 Ω₂ 运行已经覆盖 ψ₀(Ω₃) 参照树的完整五位子树 [1,1,0,1,0]。这次可让该节点生成的完整前缀更新继续运行任意有限次，并在一个实际极限内取其共同上界。整行 [1,1] 与 BTBO、EBO 的整体下界仍待证明。

## 已编译的实树与值

- B16OrbitIt.Frame.eval 对任意 y ≼ read z 解释真实 It₀(z) 的后继和极限。所迭代的变换 F、输入操作 G 及其语义 a 都是参数。B16OrbitNode.Frame.Rule.aggregate 在可收回原路径的环境中，用实际 Ω₁ 读取的零层值确定下一孩子，并在一级保留整族孩子。
- B16OrbitEnv.Frame.Rule.covers 给出任意这种环境中的 E(Ω₁) 对任意已实现底作用的升阶。B16OrbitLive.At.Start.value 将该升阶交给真实 It₀(Ω₁)，取 Φ(a)(p) = limᵢ₀(λ y → f(height y raise a)p)。每个外层反馈指数的下界都依赖上一次运行所得零层输出。式中的 y 可为任意可数布劳威尔树。
- B16OrbitExit.At.picked 在外层运行的第二个累加孩子里找到所需的实际指数。B16OrbitExit.standard 与 terminal 分别证明 ψ⁰(Φ(base)(0)) ≼ read Ψ₃ 和 ψ⁰(Φ(base)(0)) ≼ read EBOᶜ。后者来自同一实际 Λ 的 finiteRun 2。这里的 EBOᶜ 是待验收主线闭树的名字。
- 参照侧 B16RefRaise.five 给出 [1,1,0,1,0] 与上述 ψ⁰(Φ(base)(0)) 的 ≅。由 B16RefRaise.to-orbit 和两个出口可得两个端点的真五位下界。基于基本列地址的对合在 reference 路，orbit 路实现的运算只使用旧 W4 折叠。
- B16OrbitExplicit.Step.result 独立跟踪一级状态 itS(K,n,R) 和显式输入 itV(K,n,R,1,slot,v)。当 v 实现 e 和 Ω̂，默认状态满足 Str e，F ≲ K 且 J 包含 K 的正迭代时，run J R 1 slot v 实现 next e。B16OrbitWide.base 在覆盖 Ω₂ 的实际 Jc 上实例化。
- B16OrbitReuse.Rule.whole 与 wide-whole 令上述 Ω₁ 的 It 同时更新四项常规种子与任意一级显式输入。B16OrbitAction.higher 把 Φ 做成带 Described 和 ≅ 保持证明的前缀作用。B16OrbitAgain.At.rule 和 wide 将两套接口同时落实在第十五批生成的同一个真实 Q 上。
- 写 p₀ = 0，pₙ₊₁ = Φ(base)(pₙ)。B16OrbitAgain.At.point 对每个 n 提供实际状态 itS(Q,n,S₁) 与显式零层值 itV(Q,n,S₁,0,t,v₁) 上的一整包种子。B16OrbitAgain.standard、terminal 证明 ψ⁰(limₙ pₙ₊₁) 共同低于 read Ψ₃ 与 read EBOᶜ。参照的五位子树对应 p₁ 的折叠值。重复运行所得极限的精确参照地址和严格性仍待证明。

# 第十六批参照回报

第十五批从固定种子出发所得的整座塔有可检验的严格上界。其纯 src 下界的后继，已经低于 ψ₀(Ω₃) 真实地址 [1,1,0,1,0,1]。这个地址与上一批已覆盖的六位种子 [1,1,0,1,0,0] 有同一父节点。

## 定理

- B16RefTails.Prefix.upper 对任意二层前缀 P 和任意 q≼ψ⁰(P) 成立。从 q 用第十五批相同的 mulω、jump、jumpQ 递推 floor，整族极限不高于 ψ⁰(P 加一段零层尾)。B16RefDegree.cap-is 证明这里的尾与 ω^(ω²) 结构对应。一次 ω 次迭代将增量指数 d 提至 d+1，一次 jump 将其提至 d+ω。B16RefCap.epsilon 还证这段尾不超过 ψ₀(Ω₁)。
- B16RefGuard 以 B15Join.source 实例化。固定前缀 P 的第 0 孩子给出 Ω₂，其第 0 分支已容下 ψ₀(Ω₁)。P+Ω₁ 的第 1 个实际回灌参数因而容下整个尾的后继。在下一个同父子树中，回灌系数字面包含 2，系数 2 上的指定路径精确给出 ψ⁰(P+Ω₂)。B16RefLimit.strict 据此证明 B15Join.Boost.source 的零层值的后继不超过六位地址 [1,1,0,1,0,1]；floor 还给任意 q≼ψ⁰(P) 的相同 floor 运算此严格界。
- B16RefLimit.diagonal、src-BTBO、original-two 与 original 依次将这个严格界送到 BTBO 第一个未闭对角项的第 0 支、纯 src BTBO、原 EBO 的第 2 行、原 EBO-tree′。检查器也可直接排除这些目标反过来低于同一个 Boost.source 的值。范围限定在该种子及上述值运算，其他 W4 分支与其他种子可给出更高下界。
- 本批与树侧合流。B16RefFive.whole 证明五位父节点 [1,1,0,1,0] 与从 1 开始的真实一级系数回灌链逐支对应。B16RefRaise.arith 对任意可数树 y、任意满足 Fit 的基础作用与起始前缀成立，计算 height(y,raise) 附加的一级系数。B16RefRaise.five 据此证明整个五位父节点与 B16OrbitLive 的可执行目标 tree(base,0) 折到零层后结构对应。树侧提供该目标的实际 W4 运行；参照桥本身不涉及排中律、选择或函数外延。

- B16RefFiveSrc.source 是纯 src 的二层前缀。其一级系数从 Ω₁ 起步，后继取前值的正有限倍数之极限。每步将系数嵌入第三层、折至二层、取零层折叠，再用同一个零层输出驱动下一轮。whole 证明 tr₀(S.ψ₀ source) 与五位父节点双向 ≼；up、down 分别允许输入按值相关。这个二层闭项可直接供塔上的 src 增强定理使用。

## 复核与缺口

八份源码为 B16RefTails、B16RefCap、B16RefDegree、B16RefGuard、B16RefFive、B16RefLimit、B16RefRaise、B16RefFiveSrc。所有源码在只恢复源码的独立目录中编译，采用 6G 堆和工程的安全选项；最终各入口退出 0，副本与冻结源码逐字相同。禁用构造和洞扫描无命中。严格界只需第十五批及以前的模块；B16RefRaise 另用第十六批 B16OrbitTransform 的定义。

本批结论足以区分两种推进。换用保留 Ω 槽的真实高阶运行，可以覆盖前次整个固定种子塔仍达不到的兄弟节点。单用前一批从该种子得到的 floor 下界则有上述严格上界。整支 [1][1]、完整 ψ₀(Ω₃)、BTBO、EBO 的 W4 下界仍须各自的值证明。下一层纸面候选是对所有有限 k 同时解释 g₀(x)=E₀(Ω₁,x)、gₖ₊₁(x)=E(Ω₁,gₖ(x))；本批已把 k=0 接到真实运行。

# 第十六批理想侧回报

**判决。** 以排中律为参数，标准理想折叠 ψ♯ 把 Ω₂ 折到零层所得的整棵树，其值不高于真实 W4 的 Λ 闭项。上批为数列尾部留下的递推已实填。本批没有证明理想树与某棵记号参照互相 ≼，也没有产生高于既有命名下界的新 ψ₀(Ω_x) 界。前 3 层定义和证书沿用原件。

## 编译过的定理

- `B16SharpTerminal.Terminal.Λ-lower lem : B14SharpStation.Station.whole lem ≼ read W4Fold.EBOᶜ`。左端逐字取第十四批对标准理想 Ω₂ 的真实零层读回，包括全部回灌项及其部分和。右端是 W4 的 Λ 闭项。
- `Terminal.Run.whole lem r` 对每个 `B12Terminal.Run lvl2` 得到相同理想值不高于该次真实运行的输出。运行接口保有合法性、零层指定槽及输出起点覆盖 1、一级指定槽覆盖 Ω₁。实际举例是 Λ 的后代 `finiteRun 1`；输出由既有 `finite-ge 1` 搬回 Λ。允许一级槽严格大于标准 Ω₁。
- `Terminal.Run.every lem r n` 对每个自然数 n 构造 `B15SharpTail.Tail.Run.Compare lem r n`。它在同一运行的理想与实际指数上给出操作比较，所以 `Prefix` 能处理全部回灌点。这里没有预设任何未来行的值不等式。

## 证明如何越过第一次未填的行

`B16SharpModel.Graded.Rel` 对任意有限阶定义理想一级树与真实 W4 操作的关系。零阶沿用 B15 的任意前缀、独立底和指定槽的比较。正阶先给出一个 W4 框架延伸和一个已经匹配的低阶起点，再在该框架比较一次理想自折与真实操作。态射只要求在当前指定槽有 `π m (σ m ch) ≡ ch`；恒等延伸和真实下降孩子框架分别由反身性实现，复合使用相应两步等式。高阶保留 Ω 的规则 `nd` 沿所有阶复用同一条零层分支值界。保留引入的零层 τ 通过 B15 的 `cv≤` 处理。

`B16SharpCount.Count.countI` 处理任意有限阶与任意零层指数的值比较，包括子框架中的正次迭代和极限。`B16SharpOmega.Omega.GoodIndex y u` 说，理想指数 u 和真实指数 y 在任意有限操作阶、上下文、前缀和已经匹配的起点上均可共同更新。零阶真实更新是 E，正阶是 Itᴺ。`Omega.omega` 用标准 Ω₁ 同时实填所有阶。证明在进入子框架时分别搬运指定槽、外部目标与迭代底。

`B16SharpOrbit.Orbit.Vary.Advance.result` 是按指数陈述的后继规律。输入任意已配对的 u、y 以及覆盖 Ω₁ 的实际槽 c，输出配对的两个新指数是理想的 `next⁺ (selfFold B♯ Ω₁ u)` 与实际的 `ex c c nc (suc y) tt`。在任意有限阶 n，`Advance.mid` 用高一阶的旧配对来消费新指数中的正次重复；W4 的膨胀律吸收迭代起点多做的那一次更新。零指数实例如 `base-index`；于是 `Vary.all` 对真实双轨的每一步成立。这次归纳统一处理所有回灌次数。

## 范围与复核

- 排中律只以验收模块参数出现，供既有理想 ψ♯ 使用。新证明没有选择或函数外延条件。它未判定排中律对此结论是否必要。
- 这是两个实际折叠结果之间的单向序数值比较。没有证明 FGH 值比较、整个理想塔或记号 EBO 的下界。该高阶后继定理的两个指数均在一级，定理的槽覆盖 Ω₁；推广其他层仍需相应定理。
- 全部五个新源码使用 `--safe --without-K`。入口 `B16SharpTerminal` 在仓库根以单进程 Agda、6G 堆上限完成，退出 0。导入模块会产生项目既有的 cubical-compatible 索引匹配提示。此为本路自验，主审另行冷编。
