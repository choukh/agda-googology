# 第二十一批跨层、跨塔路线原样回报

实际 W4 每座独立标准正塔的同一个第 1 号正反馈孩子，同时容纳前一座正塔的所有有限后继层运行。上批已在独立层 scⁿ(tw 1) 证明的全部有限升阶，因而进入同一个闭塔值，并可送到原 Λ。其序数值现有上下界。新对角的后继支配关系足以超过上批固定两个整块；这条新对角本身仍低于 ψ₀(Ω_ω) 和 BTBO 的 γ₂，因而不能拿该数值替代任一目标。W4 真塔的上界仍待证明。

## 真实层号与收集

- B21CrossAll.Tower.located m j 以独立标准 tw(m+2) 的第 1 个实际反馈孩子 c 为共同父运行。它交出一个实际子运行，层号恰为 tw(m+1) ⊕ ↑₀(num j)，即在前一正塔外再取 j 个后继。证书沿原折叠取下，带 Covered，且该子运行的零层读回 ≼ c 的零层读回。不同 j 的子运行允许不同；父运行 c 固定。m 固定后不再换塔，也没有按值判定层号相等。
- Tower.Using 对任意零层树列 Q_j 成立。若 Q_j 在第 j 个受测层的每个覆盖、保留原合法证书的运行上是下界，则 lim_j Q_j ≤ 独立标准 tw(m+2) 的值，且 lim_j Q_j 的后继 ≤ 原 Λ 中每个 fresh(m+2,t)。前提已由本路下一项实填。全塔几何定位本身不要求 Q、p 或额外大起点。
- 对 m=0 的新界，B21CrossTower.Actual.each 进一步把所有 j 的下界放在同一更深正反馈孩子 X.child。B21CrossTower.Actual.first-positive / standard / actual / terminal 依次给第 1 号孩子、独立第二正塔、第三及以后每座原正塔的全部单位起点系数、原 Λ 的闭下界。

塔侧机制由实际折叠决定。先从第 1 个正反馈孩子只沿零号支，恢复一棵前缀后带一级 Ω 的树。其第 1 个真正零层反馈下标是可数极限，连续两次进入第 0 个数支，逐字到 1。沿这两支取出的下一个 Ω 节点，再以其真正的第 1 个下标继续；该下标支配每个有限自然数。从这个下标的纯可数读回按值证据选择分支，可找到前缀加上恰给定 j 个后继的层号。末次选择自然数分支可能改变底族，证明在这里仅保留覆盖、证书、值界。此前的零号支保留单位底槽。B21CrossLocate.At.locate 量化任意正前缀、其合法证书、额外的 0⊕ 包装层数；B21CrossAll 才代入所有标准塔。直接要求检查器化简整座闭塔的试写曾到 6G 堆墙，改成上述局部构造后全部通过。

## 值界与原参照

令 P=X(1)，ψ₀(P) 是原 ψ₀(Ω₃) 的完整第 [1] 项。定义 F₀(p)=p+↑Ω₁，Fₙ₊₁(p)=limⱼ Fₙʲ(p)，t₀=P，tₙ₊₁=Fₙ₊₁(tₙ)。本批实填的对角记作 Q=limₙ ψ₀(tₙ)。

- B21CrossSource.larger 给 suc(ψ₀(F₁(F₁(P)))) ≤ Q。B21CrossSource.exact 用原 src 的后继、加法、极限与既有 pass(Ω₂) 写出 Q 的闭项，并给双向值比较。closed 给该 src 项的后继 ≤ read EBOᶜ。
- B21CrossCoefficient.exact 给 Q 与 ψ₀(P+↑c) 的结构对应。系数 c 是可数极限。其第 0 项为 0，第 n+1 项是在上一项的右端加上 Ω₁·ωⁿ⁺¹；后一记法在代码中为 B16RefFive.g(natᶜ(n+1))，每个后继对上一棵一级树右乘 ω。这里的 n 改变右尾幂阶。B12BtboCut.finite n=ψ₀(Ω_n) 的 n 改变 Ω 的层号。
- B21CrossScalar.At.both 对任意共同的正规或非正规二层前缀 p，证明一级的保持槽关系 B15RefMonotone.Below 经过 ψ⁰(p+↑-) 后保序，且同一内部零层反馈下标也保序。借此可在原树一条已确认的支上给出 Q 的上界。有限系数的累加和在上述槽关系下 ≤ Ω₁·ωⁿ⁺¹；取极限后，原一级保留槽第一次正反馈的下标 ≥ω，能承接全部这些阶。
- B21CrossCut.entry 给 Q ≤ 上批原外行 [2] 内的具名子树 B20OldAddress.positive-entry，即 ψ₀(P+↑collapse(P))。它的原地址是 [2] 之后 [0,0,2,0,0,2,0,0,1,1,0,1]。below-three 给 Q ≤ ψ₀(Ω₃)；strict 给 suc Q ≤ ψ₀(Ω_ω)，strict-gamma 给 suc Q ≤ γ₂。所用原层号严格步进是既有 OCF.Align.BTBOFullV3.Fstep，从 Ω₃ 到 Ω₄，再选 Ω_ω 的第 4 支。这里上界的对象仅是 Q；标准塔可能支配更高值。

本路没有填入原旧对角 idx3→idx4 的模拟，也没有填入每个 n 的 ψ₀(Ω_n) 下界。全塔汇总若要用于后者，仍需在受测运行上证明相应的旧折叠下界，或用别的树侧作用取得它。就这次实填的 Q 而言，strict 是它与旧预备目标的已编译比较。整套几何定位也可以代入其它与 Ω₁ 尾无关的新实算定理。

# 第 21 批理想折叠原样回报

标准理想 Ω₃ 的第二次反馈中，已将一个严格大过上次完整反馈的保留结点，连同其全部自生成下标及累加极限，送入同一个真实 W4 操作输出。记旧二层上折树 `v = Up₁(Ω₂, Ω₁)`，`q` 为旧二层折叠在标准底上对 `v` 的零层读值。本批的上下界是 `suc (raw 1) ≼ q ≼ raw 2`，以及 `q ≼ read (run J st1 zero w2 v₁) ≼ read (value r)`。后一链在任一覆盖的真实三级运行 `r` 上成立，使用第四层的排中律。取 `finiteRun 2` 后，已有 `follow-ge`、`tower-ge` 和 `finite-ge 2` 将它分别放入 Λ 的第 1 个实际孩子和 Λ。此次没有得到 `raw 2 ≼ child k` 或原 EBO 的下界。

## 原树到真实输出

- `B21IdealInside.strict`、`under` 为无经典前提的两个旧树不等式。上折把一级 Ω₁ 移到二层的零槽。在该槽里，旧折叠沿 `indices 0 = 0`、`indices (n+1) = clock (next (Up₀ Ω₂ (indices n)))` 采样，按原规则取这些输出的部分和极限。首项正好是 `raw 1`。部分和的第二项有正值，因此首项的后继也在 `q` 之下。`appears`、`under` 把整个结点接回第二次正反馈。`Inside.ret` 是此处的二层输入树，与上批 `B20IdealRetained.ret` 命名的更外层零层子树有别。
- `B21IdealNode.Proof.exact` 在排中律参数下，给出整个 `q` 与理想零层反馈列部分和极限的树形对应。`Physical.Run.timesW` 对每个实际自生成下标逐步比较，`Closed.at-J` 将整个极限提交给 `J = block c (K c)` 的一个输出，`Closed.bound` 再连回该运行。这里没有把有限项分别散落到不同塔里。
- `B21IdealSeries.Proof.Real.Point.value` 与 `next-series` 以排中律为参数，将任意正有限次 `next` 作用于二层 Ω₂ 后的旧折叠值放进同一实际 G 输出。无条件的 `B21IdealInside.member` 把这整族定位在 `q` 的第一个正回灌项内。

# 主审合流

对任意标准槽的正塔，将 Ω 主树朝某个指定孩子任取一条零目标路径，其输出与同一座独立标准塔的完整零输出同值。在任意覆盖且持标准证书的第 m+2 座塔中，沿第 1 个正反馈孩子与真实的零号 Ω 分支找到一个有覆盖证书的 m 层子运行。它所有零槽同时支配 sₘ，即独立标准塔 m 的值；它自身的零层输出进入起始的同一个孩子。将上批要求整套零槽高的两个提升在这里实例化，在每升两座独立塔时可任选一次追加变化的一级系数，或追加整个 Ω₁ 尾块。B21TowerWords 对任意有限次混用给出完整 src 闭式的证明和可数族的实际 Λ 下界。

对任意带证书的旧层号 a，后继站的值能否进入真实 Λ 等价于该层每项裸反馈值能否进入某座真实塔。第一个正反馈的下标逐字等于对本层标准 Ω 树取一次 next。取所有旧有限站的极限时，改取每站的这个第一正反馈得到同值；各站见证对原 ψ₀(Ω_ω) 下界构造性充分。这里分别用到了旧层号与 W4 的真实有限塔号，两者的编号没有被当成同一件事。
