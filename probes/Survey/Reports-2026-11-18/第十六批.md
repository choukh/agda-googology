# 第十六批，固定种子塔的上界与两种实际回灌

第十五批的固定种子塔有了严格上界。它的后继已经低于 ψ₀(Ω₃) 中的一个真实孩子。同一个 W4 的 Λ 闭项则覆盖该孩子的整个父节点，还能用这个父节点的值驱动下一轮。理想折叠也有了不同于逐个孩子验算的证明，以排中律为参数，一次覆盖标准理想 Ω₂ 折到零层的全部回灌。原 EBO 的第 2 行 BTBO 仍待证明。[直接闭定理](attachments/B16Closed.agda.txt) · [理想闭定理](attachments/B16SharpTerminal.agda.txt)

## 固定种子到底能到哪里

令 B 为上批实得的纯 src 下界，Ω 算术读作 ψ₀(D＋ω^(ω²))。令 F 为 ψ₀(Ω₃) 参照树从根依次取孩子 `[1,1,0,1,0]` 所得的整棵树，孩子从 0 起算。上批的六位种子是 F 的第 0 个孩子。现已证 **suc B ≼ F 的第 1 个孩子 ≼ F ≼ read EBOᶜ**。最后一步也对标准 Ψ₃ 和每个有覆盖证据的实际第 3 层运行成立。[旧界到新孩子](attachments/B16RefLimit.agda.txt) · [整棵父节点到 W4](attachments/B16Join.agda.txt)

对固定二层前缀 P 和任意 q ≼ ψ⁰(P)，上批那一组乘 ω、升阶和取塔极限的运算有统一上界。上界的零层增量与 ω^(ω²) 结构对应。对 D 实例化后，把整个 ψ₀(Ω₃)、BTBO 或原 EBO 压到 B 以下均可推出矛盾。这给出了停用“在同一种子上反复加同一类尾项就能完成验收”这一做法的数学理由。换种子或在 W4 的别的分支运行，都超出了这个上界的量化域。[任意起点的上界](attachments/B16RefTails.agda.txt) · [增量校准](attachments/B16RefDegree.agda.txt)

F 本身与一个纯 src 闭项双向 ≼。其一级系数从 Ω₁ 开始，按上一轮得到的零层树遍历后继与极限，嵌入第三层再折到第二层。W4 第 3 层的实际指数恰能在给定零层下标时提供所需的作用。这个作用还能在同一个真实运行中反复使用，已有全体正有限次更新的共同下界；该共同下界在 ψ₀(Ω₃) 中的精确地址仍待校准。[纯 src 的 F](attachments/B16RefFiveSrc.agda.txt) · [参照到实际作用](attachments/B16RefRaise.agda.txt) · [实际重复运行](attachments/B16OrbitAgain.agda.txt)

另一个纯 src 闭下界可以精确复算。定义 H(0,a) 为 a 的正有限倍数的极限，H(x+1,a) 为从 a 出发迭代 H(x,−) 的可数极限，H 在极限指数上逐支取极限。从 F 的 src 值 x₀ 起，令 xₙ₊₁ = H(xₙ+1,1)。已证 **suc x₀ ≼ supₙ suc xₙ ≼ read EBOᶜ**，且 suc(suc B) ≼ supₙ suc xₙ。这里的 sup 是给定分支的可数树构造。每次回灌都由 W4 同一座实际塔的下一个选层下标支付，`B16Closed.exact` 给出整个 src 左端与实际比较所用树之间的双向值桥。[动态起点与严格步进](attachments/B16Feedback.agda.txt) · [闭项与定理](attachments/B16Closed.agda.txt)

## 理想折叠在同一终点做到了什么

第十五批的首次未填项是操作比较 `Compare 2`。本批证明 `every r n`，对任一带所需槽与底的实际二层运行 r、每个自然数 n 成立。归纳时同时保持任意有限阶的操作。下一次回灌要消费高一阶的比较时，归纳假设已经提供了它。在实际 Λ 的二层后代上实例化，得 **src ψ₀(Ω₂) ≼ 整个标准理想 ψ♯(Ω₂) 的零层值 ≼ read EBOᶜ**。两侧是在第 4 层使用排中律参数的定理，没有选择或函数外延前提。直接法的上述严格改善均无经典前提。[全阶后继](attachments/B16SharpOrbit.agda.txt) · [完整 Ω₂ 的运送](attachments/B16SharpTerminal.agda.txt) · [src 下界与反向条件](attachments/B16SharpSource.agda.txt)

另证该理想值与旧的 YiUpFold 标准 Ω₂ 输出结构对应。理想值能否反过来被 src ψ₀(Ω₂) 支配，等价于旧输出的一个尚未完成的上界。下一次同题对照应检验二层证明能否用于变化层号，或能否覆盖完整 Ω₃ 的回灌。已有证据说明任意阶保持可以一次解决整站；尚无证据比较两条路线到 EBO 的总工期。[理想与旧折叠的精确对应](attachments/B16SharpSource.agda.txt)

## 从原 BTBO 行倒推

对任一 W4 零层树 z，把它复制到 src 并作累加正规化后，所得层号的全部前驱都可保序嵌入在 h₁(z) 上真实折得的输出。定理对每层进入全体孩子的零层输出路径成立，包括实际选层和外部输出所用的两条路径。另已证第一座非平凡塔每个选层下标的零层值都被该次塔运行的输出支配。[前驱嵌入](attachments/B16IndexEmbed.agda.txt) · [在外部输出取回下标](attachments/B16ReadIndex.agda.txt)

沿实际下标序列 iₘ，若原 BTBO 的 γₙ ≼ read iₘ，则 γₙ₊₁ ≼ ψ₀(Ω_{κ(iₘ₊₁)})，κ 把该零层树读为层号。由此取得一个足以推出 BTBO ≼ read EBOᶜ 的条件。对每个 n，只需在这条真轨道上证明 ψ₀(Ω_{κ(i₃₊₂ₙ)}) ≼ read i₄₊₂ₙ。外部输出所需的不等式已由下标取回定理给出。全体 n 的输入比较仍开放，较弱的 γ₁ ≼ read i₂ 已有实例；当前并未给出整个全称条件的实例。[精确下标及条件定理](attachments/B16GammaRows.agda.txt)

## 本批的取舍

固定种子塔已由严格界排除为独立通往 EBO 的办法，保留它作为从已知种子传值的引理。直接路线接下来应先核对高阶作用的两个参数位置能否产生参照要求的 E(Ω₁,γₙ)。理想路线应取一个实际会变化的下标检验全阶关系的适用域。两项都可以在写新一批模块前明确写出目标比较，再决定是否值得实现。完整 [1,1]、ψ₀(Ω₃)、W4 上的 BTBO 下界、原 EBO 下界均开放。每批记录同一端点以及解决或留下的比较，第十八批末按约定进行三批完整复评。[上一次评估与改判条件](../GoalOdds.md)

翻译账。W4 的折叠、证书、塔路径及 Λ 闭项沿用已有定义。真实回灌使用原有指数节点和指定槽，前驱嵌入对任意规范零层路径成立。选取参照地址和一级系数依赖记号的指引。以上结果推进了值验收，尚未提供树自足的新验收定理。[内部回报原文](回报-16.md)
