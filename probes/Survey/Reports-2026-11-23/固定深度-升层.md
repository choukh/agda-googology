## 第一次回报，据已验证文件复原

每个有限层在固定底和输入下，零层路径可以互换。三级运行若所有零槽均达到 x，每条零路径的输出都严格超过 B(x)，其中 B(x) 是从 x 反复取上方首个 H 不动点的上确界。四级子运行能沿自己的反馈重复利用这条律。第四层证明了 B(D) < L₄ ≤ read(T.value Fourth.sub)，而实际坐标 (4,1) 的反馈严格超过 L₄。以 h 枚举 H 的正不动点，D = h(0)，B(D) = h(ω)，L₄ = h(ω²)，等号均为树的序数值双向比较。路径定理、坐标定理、值标定三个文件已分别通过 Agda 安全检查。完整 ψ₀(Ω₃) 及 sample 2 在此坐标的下界仍待证明。[零路径比较](../W4FourthLiftPaths.lagda.md) · [第四级真实坐标](../W4FourthLift.lagda.md) · [值计算](../W4FourthLiftValue.lagda.md)

## 第二次最终回报原文

δ 有了一个独立的闭式参照上界。Agda 无条件验证 δ ≤ ψ₀ψ₂(C)，其中 C 是原 src 二层树上的闭项。其 Ω₁ 极限的第 x 个分支从 Ω₂+Ω₁ 起，按 x 的每个后继右加 Ω₁，到可数极限取上确界。因此 C 的通常序数算术读法是 Ω₂+Ω₁²。对同一参照的 Level 表示与 src 表示，已验证折叠后的序数值双向相等。

证明同时给出每个可数 x 的比较 h(x) ≤ ψ₀ψ₂(C[x])。后继分支超过前一个读值，并对 H 封闭，故可用上方首个 H 不动点的极小性。最后比较 h 与参照函数的全部有限次迭代，合成 δ 的上界。这个上界只约束 δ。目前还缺它与两份 Ω₂ 的完整参照 a₁、三份 Ω₂ 的 a₂ 的比较，尚未由 δ 兑现 ψ₀(Ω₃) 的下界。
