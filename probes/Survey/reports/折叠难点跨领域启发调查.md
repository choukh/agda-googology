# 把滞后写成数据, 把派发交给来源: 折叠三个难点的跨领域可移植想法

四份调查笔记 (X1 不判定而计算, X2 非规范表示的单调语义, X3 滞后的支配与对层一致的定理, X4 层号自生的系统; 存于 `probes/Survey/research_notes/折叠难点跨领域启发调查/`) 共收约六十条想法, 合并后是七个家族; 排在最前的两族只动值验收层 (第 4 层), 不改树、折叠与合法性的定义, 所以服务于值验收, 不直接推进 "让树自足" 的目标, 推进目标的候选在第三、四族. **第一族把滞后写成显式的良基数据**: 模型检测的 well-founded bisimulation 秩, CompCert 前向模拟的良基索引, 程序下界分析的 metering function, 摊还分析的势, 程序逻辑的超限步进索引, 终止性分析的 nested ranking, 六个领域给出同一个结构, 即 "一侧可以暂时跟不上, 只要每次跟不上时某个良基量下降, 证明义务就只需逐步检查"; X2 与 X3 从不同入口引到了同两处文献 (Namjoshi 1997 与超限步进索引). **第二族用对一切判定都成立的界代替判定**: proof mining 的单调函数解释不实现 LLPO 的二选一, 只实现它的界 (选择子取 1, 见证取 max); 抽象解释在守卫未知处取两支的并; Moschovakis 的超算术归约对记号对一致地写出, 只在假设成立时有效. 本报告由这两族合出的推断是: 把折叠写成以部分见证神谕为参数的一族, 按 X1 的读法 (待对照代码核实) 现行折叠是空神谕的实例, 在带 LEM 参数的验收文件里 (作者 2026-11-17 的新许可) 满神谕给出正确保留的修正参照折叠, 【滞后模拟】一路要比较的就是同一定义的两个实例, 而以 LPO、WLPO 或可判定性为结论的那一类已编译否定在这一步不构成限制. 定义侧排第一的是按来源派发 (BMS 的祖先链, LogRelKit 的层号证据, PHOAS 的类型实例化), 它对着下标 Ω+1 处的保留缺陷, 与台账 U22、U27、R3 重合, 要改定义, 由作者定. 难点三 (阶段无关的下界) 的组织形状是 "以更低层为参数的一步 + 层树上的良基打结" 加 "有限规则形状上的全局条件". 所有移植都是判断, 没有一条编译过; 信息量与成本之比最高的前三个实验是一张滞后表 (有限测试), 一份纸面分类清单, 一份同时检验八条滞后想法的玩具文件.

## 读法: 档位, 路名, 难点编号, 否定定理的白话

**事实与判断的分隔.** 每条想法分五项. 第一项 "原领域" 是文献事实, 每处标出笔记给的核实档位: 【原文】笔记作者读过正文、幻灯片或代码的相关段落; 【摘要】只见摘要或检索片段; 【记忆】笔记作者依已有知识写, 未核; 【未标】笔记给了链接但没有标档位. 其余四项 (对着的难点与路, 我方草图, 最便宜的实验, 与已编译否定的张力) 一律是判断或纸面分析, 包括笔记作者的判断与本报告的推断; 本报告新加的推断标 "本报告推断". 引到的仓库定理名都在仓库里检索到 (`probes/` 下的 `.agda` 与 `.lagda.md`), 白话取自 `probes/RESULTS.md`、`probes/README.md` 与台账 `probes/Survey/IdeaLedger.md`; 张力项只标出, 不据此排除, 用某条否定前要逐条读陈述.

**本报告的两次最小检查 (编译事实, 不是项目定理).** 在 Agda 2.8.0.2 上, `{-# OPTIONS --safe --without-K --sized-types #-}` 报 `SafeFlagPragma` 错误, 所以三份笔记里 "内建 sized types 不能与 `--safe` 同用 (未核)" 现已核实; 一个最小的归纳-递归宇宙 (`data U`, `T : U → Set`) 在 `--safe --without-K --cubical-compatible --guardedness` 下通过, X3 与 X4 里 "归纳-递归在 `--safe` 下可用 (未核)" 在最小例子上成立.

**难点编号.** 难点一: Ω 形状层号上目标经指定孩子时, 保留要知道两个孩子相同或槽位层更低, 对裸树作这种比较推出 WLPO 或 LPO, 现行折叠在那里走链并掉值, 缺陷在下标 Ω+1 就出现. 难点二: 没有对一切树 (含非规范树) 定义、沿每条折叠规则单调的树侧 "意图值"; 与参照的逐步对应已被否定, 折叠局部落后, 只在外层极限追上 (指 ≼ 在外层极限处成立), 滞后随嵌套增长. 难点三: 只要下界, 希望写成与阶段无关的定理.

**五条在跑的值路 (简称).** 【经典值】经典集合论的值; 【逐层封闭】树侧按层封闭的自举; 【滞后律】带滞后的律加一次性的充分性定理; 【滞后模拟】对修正参照折叠的带滞后模拟; 【证明论】理论阶梯加形式化的证明论强度.

## 第一族: 六个领域把 "暂时跟不上" 写成良基量的下降

**汇合.** X2 的想法 1、2、3、12 与 X3 的想法 A、B、C、E、G、I、J、N、Q 用了九个名字 (滞后秩, metering function, 欠账与势, 调度无关性, 见证映射, 带度量的最终恢复, 欠账向量, 序数预算, 滞后代数), 讲的是同一个对象. 两份笔记各自指出了等同关系: X2-3 说还账引理里的 m − n 若为常数, 就是 X2-1 的滞后秩; X2-12 说调度映射 σ 的 σ(n) − n 就是滞后; X3-A 的见证映射把参照的保留结点送到 "∀n∃m 里的 m+1". 不同领域引到同一处的有: Namjoshi 1997 (X2-1 与 X3-B), 超限步进索引 (X2-1 与 X3-G), 摊还的势 (X2-3 与 X3-N), Danielsson 与 Pous 的 up-to (X2-11 与 X3-E、O). X3 有一条对我方要紧的判断: ≼ 是归纳关系, 右侧取孩子本身良基, 所以显式度量只在 "把当前不等式推迟到外层" 那一步才必需.

**仓库里已有的两件事 (仓库事实).** 台账 U25 记 `probes/OCF/Lean/YiSyncRel.lagda.md` 的关系 `_⊴⁺_` 带 `dg` 规则, 是 "落后一步" 的跨层值关系, 只对前缀 G₂ 与一个 Ω₁ 结点陈述, 往上要重陈述 (`YiSyncDiag.Diag` 用它把参照的 ψ₁(Ω_{ℓ₀}) 放到保留结点之下). `YiASNeg.¬pair₀` 无前提地说最小的不同步对没有关系, `async→weak` 说这类对的关系只能经放宽得到. 本报告推断: 本族任何关系在不同步对上都不能断言该对的 ≼, 只能用推迟规则把义务交给外层; 这与 X3 "度量只为推迟存在" 的判断一致, 也给推迟规则的健全性定下陈述形状 (推迟得到的是对外层结点的 ≼, 不是对该对的 ≼).

### 1.1 显式见证映射: 映射吸收滞后, 只证三条局部引理

**原领域 (文献).** 精化映射把实现的状态送到规格的状态; Abadi 与 Lamport 证明, 给低层规格加 history 与 prophecy 辅助变量后精化映射一定存在 【摘要】([Abadi–Lamport, TCS 1991](https://www.microsoft.com/en-us/research/?p=145187)). wqo 理论求极大序型的下界时, 把序数记号经 order-reflecting 满射放进偏序的某个线性化 【未标】([Freund, arXiv:2105.09915](https://arxiv.org/pdf/2105.09915)); 同一传统里, 对序列的情形, 原文称为 natural 的那个线性化达不到极大序型 【未标】([Rathjen–Van der Meeren–Weiermann, AML 2017 预印本](https://eprints.whiterose.ac.uk/117847/1/ArticleGapsequencessubmittedtoAMLRevisedVersion2.pdf)).

**对着的难点与路 (判断).** 难点二、三; 供给【滞后模拟】. 逐项配对把映射固定为 r[n] ↦ t[n], 本想法让映射自由选我方位置, 滞后进入映射的定义, 剩下的义务只有沿参照一步的严格上升.

**我方草图 (判断, X3).** 在验收文件里对参照树 R 的子树定义 e, 只证 `e-suc : e x ≺ e (suc x)`, `e-lim : ∀ n → e (f n) ≺ e (lim f)`, `e-Ω : ∀ c → e (g c) ≺ e (limΩ g)` (同一个 c). 通用引理 `dom : ∀ x → x ≼ e x` 对 R 结构归纳, 与层无关, X3 估计十几行; 最后证 `e R ≼ t`. 树一侧走链而参照保留结点 X 时, 令 `e X` 取外层下一个下标处的我方子树. 与 Fairtlough 路径的差别: 不要求 e 保持基本列或路径结构.

**最便宜的实验 (判断).** 一份纯 `.agda`: 对任意满足三条局部引理的 e 证 `dom`; 在简化模型上手写 e (深度 d 的下标 n 送到外层约 2^d·n 处), 看哪条局部引理不成立, 不成立的那条就是必须推迟到外层的位置. 放进实验 E3.

**与已编译否定的张力 (标出, 不据此排除).** `e-Ω` 要求 `e (limΩ g)` 在与参照同一个下标类型上分支; 我方孩子下标若带证据或坐标, 需要下标之间的证据函数 (开新行前先验检查的第二条). 若按孩子的层号决定 e 的值, 对上 `branch→wdec`、`hand→wdec`; 在带 LEM 参数的验收文件里这一选择不受这一族约束, 结论标 "条件". `e-lim` 只要求孩子严格低于父结点, 不要求我方 ℕ-极限的项按值递增, 不触 `strict→LPO`.

### 1.2 带滞后的模拟关系: 原地踏步降秩, 推迟到外层, 欠账位

**原领域 (文献).** CompCert 的 `fsim_properties` 以索引类型、良基序 `order` 与 `match_states` 为参数, 单步条件是 "`Plus L2 s2 t s2' \/ (Star L2 s2 t s2' /\ order i' i)`"; `forward_simulation_eventually` 允许源程序多走若干步再恢复匹配, 索引取 `index * nat` 的字典序; 两个模拟合成时索引取乘积, 序为 `lex_ord (clos_trans _ order') order` 【原文, Coq 文档】([CompCert Smallstep.v](https://compcert.org/doc/html/compcert.common.Smallstep.html)). Namjoshi 的 well-founded bisimulation 用取值于良基集的秩函数, 源走一步而对方不动 (或反之) 时秩下降, 所以每段口吃有限, 只需检查单步 (X3 引 §2 定义与 p. 287; X2 报告该 PDF 是扫描件, 未能抓取) ([Namjoshi, FSTTCS 1997](https://kedar-namjoshi.github.io/papers/Namjoshi-FSTTCS-1997.pdf)). Etessami、Wilke 与 Schuller 在 Büchi 自动机上引入 delayed simulation, 商化后保持语言而 fair simulation 不保持 【摘要】([ICALP 2001](https://link.springer.com/doi/10.1007/3-540-48224-5_57)). Lynch 与 Vaandrager 统一陈述前向、后向、前后混合模拟与 history、prophecy 关系, 并给健全与完备结果 【摘要】([Information and Computation 1995](https://dspace.mit.edu/handle/1721.1/149207)). Interaction Trees 支持弱互模拟意义下的等式理论 eutt 【摘要; "每个余归纳步内用归纳构造子吸收有限多个 tau" 是记忆】([Xia et al., arXiv:1906.00046](https://arxiv.org/abs/1906.00046v2)).

**对着的难点与路 (判断).** 难点二 (逐步对应已被否定, 改为允许有限步不同步) 与难点三; 供给【滞后模拟】.

**我方草图 (判断, X2-1 与 X3-B、E、J、Q 合并).** 示意, 未编译:

```agda
-- i : 字典序索引 (还需外推几层, 本层还差几步); ob : 欠下而未兑现的参照子树
data Sim : I → Ref → Our → Maybe RefSub → Set where
  sync-lim : (h : ℕ → ℕ) → (∀ n → Sim i' (f n) (g (h n)) ob) → Sim i (lim f) (lim g) ob
  lagR     : Sim i x (g m) ob → Sim i x (lim g) ob             -- 我方多展开一步
  sync-Ω   : (∀ c → Sim i' (f c) (g c) ob) → Sim i (limΩ f) (limΩ g) ob   -- 同一个 c
  defer    : i' <ₗₑₓ i → Sim i' x' t' (just X) → Sim i x t nothing   -- 把 X 交给外层, 第一分量降
  settle   : X ≼ t → Sim i x t (just X) → Sim i x t nothing         -- 外层同步处先兑现
```

`lagR` 与 `sync-*` 靠 ≼ 右侧取孩子的良基性就够, 不用度量; 度量只为 `defer`. X2-1 的同一形状写在 ℕ-极限上: `stall : Behind f d' n (suc m) → d' < d → Behind f d n m`, 主引理得 `∀ n → Σ m (Ref (f n) ≼ fold c (f m))`. X3-Q 的约化对: 严格的 ≺ 只在参照走严格一步、我方必须兑现的同步点要求, 内层只证弱关系. 健全性对 (参照结构, 索引) 的字典序良基归纳, 停机由检查器保证.

**最便宜的实验 (判断).** 三十行左右的构造子与健全性证明; 然后把 `YiASNeg` 的最小不同步对 (第 3 层 Ω 树折到第 2 层, 参照 Ω₁) 写成用 `defer` 的 `Sim` 项, 看缺哪个构造子. 放进实验 E3.

**与已编译否定的张力.** `¬pair₀`: 健全性对 `defer` 不能给出该对的 ≼, 否则矛盾. 决定是否推迟若要把分支对目标分成低、同、高三类, 而分类不是字面的, 对上 `hand→wdec`、`viaE→dec` (X3 认为这是本族最大的风险); 在带 LEM 参数的验收文件里可以分类, 结论标 "条件". `settle` 比较的两个对象要有字面公共上界 (律带公共上界); X3 判断两者同在外层上下文之下, 一般可给. 加 "up to ≼" 规则的风险见 7.2. 内建 sized types 不可用 (已核实), Danielsson 的写法只借形状.

### 1.3 滞后的计量口径: 下估计, 欠账, 欠账向量, 序数预算, 滞后代数

**原领域 (文献).** 程序下界分析: 对带更新 μ 的循环, b 是 metering function 当且仅当守卫不成立时 b ≤ 0、守卫成立时 bμ ≥ b − 1; 定理: bσ ≥ 0 时循环至少执行 ⌈bσ⌉ 次; ½x 是 metering function 而不是 ranking function, x² 反之; 守卫在一次迭代后恒成立的部分可以乘进特征函数 (conditional metering) 【原文: Def. 3.1–3.2, Thm 3.3–3.4】([Frohn–Naaf–Brockschmidt–Giesl, arXiv:1911.01077](https://ar5iv.labs.arxiv.org/html/1911.01077)). 终止性: Leike 与 Heizmann 的 nested ranking template 要求 f₁(x′) < f₁(x) − δ, 且 i ≥ 2 时 f_i(x′) < f_i(x) + f_{i−1}(x), 原文说一个分量 "cannot increase by more than the value of the previous phase's" 函数 【原文: Def. 4.7, Lemma 4.9】([LMCS 2015, arXiv:1503.00193](https://ar5iv.labs.arxiv.org/html/1503.00193)); Jurdziński 的 progress measure 是单调算子的前不动点, 有最小者且可直接计算 【摘要】([STACS 2000](https://www.dcs.warwick.ac.uk/people/academic/Marcin.Jurdzinski/Papers/Jur00-STACS.abstract)). 程序逻辑: Svendsen、Sieczkowski 与 Birkedal 用词典序的超限下标 (具体步, 下一个具体步之前允许的逻辑步) 解开两者一一捆绑 【摘要, 正文被拦】([ESOP 2016](https://hal.archives-ouvertes.fr/hal-01408649v1)); Spies、Krishnaswami 与 Dreyer 用超限步进索引组合地计算终止界, 不再要用户给出步数上界 【原文 §1】([POPL 2021](https://www.cl.cam.ac.uk/~nk480/transfinite-step-indexing.pdf)); Transfinite Iris 指出有限步进索引不满足 existential property, 只能证安全性, 换成序数下标可证终止与保终止的精化 【原文, 项目页】([Transfinite Iris](https://iris-project.org/transfinite-iris/)); 可数非确定性的 must 等价要用 ω₁ 索引, 作者注明最小非递归序数也够 【未标】([Birkedal–Bizjak–Schwinghammer, LMCS 2013](https://lmcs.episciences.org/940)). 摊还分析: Hoffmann 与 Hofmann 把势方法推广到多项式界, 推导产生线性约束 【摘要】([ESOP 2010 扩展版](https://www.cs.yale.edu/homes/hoffmann/papers/aapoly_extended.pdf)). 不动点求解: Cousot 的讲义说, 从前不动点出发, 单调方程组不论按哪种 chaotic 或异步策略迭代, 都收敛到同一个极限 【摘要】([NACSA'98 讲义](https://cs.nyu.edu/~pmc309/publications.www/slides/Cousot-NACSA-98-slides-4-1.pdf)).

**对着的难点与路 (判断).** 难点二、三; 供给【滞后律】(口径就是律里的滞后参数) 与【滞后模拟】(口径就是 1.2 的索引类型 I).

**我方草图 (判断).** 五种口径, 选哪种由实验 E1 的滞后表决定:

| 口径 | 我方形式 | 要的字面数据 | 主要风险 |
|---|---|---|---|
| 下估计 m (X2-2) | 定理 A: `m t ≼ fold c t`, 对一切树逐规则 (M0, Msuc, Mlim, 按低、同、高三条 MΩ); 定理 B: `Ref t ≼ m t`, 只对读回域, 只涉及参照一侧 (去掉序列的有限前段不改上确界). m 定义在 `Σ t (证据 t)` 上对应 conditional metering | m 本身按结构递归 | 同层对角规则要 fold 对下标单调, 非规范下标上落在 `no-carry-Ω₂` 一类否定的范围里 |

| 滞后代数 (X3-I, X2-12) | `Dom h r t := ∀ n → r[n] ≼ t[h n]`; 合成 `Dom h r s → Dom k s t → Dom (k ∘ h) r t`; 折叠律 `Dom h r t → Dom (Φ_ℓ h) (ψ r) (ψ t)`; 深度 d 的滞后是 Φ^d(h), 关于 Φ 的一条定理对层一致 | h 是 ℕ → ℕ 的具体函数 | 放宽 h 要 t[·] 弱单调, 须先在读回域上查 |

**最便宜的实验 (判断).** 先做 E1 (滞后表) 定口径, 再在 E3 里只实现选中的一种. X3-C 的检验可以纸面或脚本做: 在简化模型里列深度 d、下标 n 时所需的最小下标平移 L(d, n), 看是否满足 L(d+1, ·) ≤ L(d, ·) + L(d−1, ·) 一类不等式 (有限测试).

**与已编译否定的张力.** 跨层单调的配对否定 (`no-tw`、`lpo-tw`) 的根源记为 "位置摊平"; 欠账向量若把不同层的位置压到同一坐标, 要先对照它. `strict→LPO` 只否定严格递增, 滞后代数要的弱单调不在其中, 但要在读回域上另证. `no-uniform₂` 否定的是上界方向、形如 ψ₂(a) 的统一阈值工具接口, 不是下界的滞后度量; 若某个口径写成统一阈值, 先对照它. 下估计 m 的定理 B 若要求 Ref 的序列严格递增, 落入 `strict→LPO`, 只能用 "去掉有限前段" 这类字面操作.

## 第二族: 用对一切判定都成立的界代替判定, 经典许可下修正参照折叠由一个 LEM 神谕给出

**汇合.** 证明挖掘 (Ferreira 讲义里的单调函数解释), 抽象解释 (守卫未知处取并), Herbrand 定理与无反例解释 (有限候选表), 超算术层级 (对记号对一致的归约, 只在假设成立时有效), 可计算分析 (Brattka 与 Gherardi: 多值性只在输出不由输入的值唯一决定时才有用), 计算机代数 (动态求值: 分裂语境而不分裂值), 六个领域给出同一条做法: 写一个不读 P 的输出, 证它对 P 的每种可能真值都满足要求. X1 的结语把它写成一个陈述形状: 目标定理写 "∀ 神谕 → 参照[神谕] ≼ 输出", 而不是 "参照 ≼ 输出". X2-10 与 X3-M 从另一入口 (Howard 与 Bezem 的可优超性) 引到同一组文献, 用途是值关系而不是派发.

### 2.1 神谕参数化的折叠与单调函数解释

**原领域 (文献).** LLPO 没有 dialectica 解释 (否则一个闭项会分开两个递归不可分的 r.e. 集), 但有单调函数解释: 选择子的界取 λw.1, 见证的界取 λw,k,r. max(k, r), 验证时用到一点选择 【原文: §4.2】([Ferreira, Proof interpretations and majorizability](https://webpages.ciencias.ulisboa.pt/~fjferreira/proof_interpretations.pdf)). 不连续的泛函 E (α 恒为 0 时取 1, 否则 0) 可由常数 1 优超, 而 "最小的 n 使 α(n) ≠ 0" 的泛函 Σ 不可优超 【原文: §2】(同上). Bezem 的强可优超泛函 (强优超者也优超自己, 即单调) 是单调函数解释的基础 【原文, 经 Ferreira 转述; Bezem 1985 原文未开】(同上). 前束式公式经典有效当且仅当其 Herbrand 化有效, 定理 4.14 给出相应的项 【原文: §4.5】(同上). Rathjen 与 Swan 把 Lifschitz 可实现性推广为形式拓扑族 L_n, 证明 LLPO_{n+1} 严格弱于 LLPO_n 【摘要】([arXiv:1806.10047](https://arxiv.org/abs/1806.10047)). 抽象解释在控制流汇合处取并, widening 保证有限步稳定 【记忆】([Cousot–Cousot, POPL 1977](https://doi.org/10.1145/512950.512973)).

**对着的难点与路 (判断).** 难点一的值侧; 供给【滞后模拟】(给出修正参照折叠) 与【经典值】.

**我方草图 (判断; 前半是 X1-A 与 X1-G, 后半是本报告推断).** 示意, 未编译:

```agda
module _ (P : Node → Set) (w : (x : Node) → Maybe (P x)) where
  fold[w] : ...                          -- w 给见证处走保留, 否则走链
-- X1 的读法 (未对照代码核实): 现行折叠 = fold[ λ _ → nothing ]
-- 验收文件, 模块参数 lem : ∀ A → A ⊎ ¬ A:
--   wLEM x = [ just , (λ _ → nothing) ] (lem (P x))
--   修正参照折叠 = fold[ wLEM ]                 -- 正确保留, 结论标 "条件"
-- 定义侧候选: fold* 不读 P, 分情况行写成 keep* ⊕ chain*; 目标 ∀ w → fold[w] x ≼ fold* x
```

用法有两种. 验收侧 (本报告推断): 现行折叠与修正参照折叠是同一参数化定义的两个实例, 【滞后模拟】要证的是 `fold[nothing] ≽ fold[wLEM]` 加上第一族的滞后, 模拟关系可以对两者共用的结构递归写出, 唯一的差别在神谕给见证的结点上. X1-G 的三值测试 (一定低于, 一定不低于, 未知) 用 "字面公共上界存在且 `bdec`" 实现, 给出一个可构造的中间神谕 `w_bdec`, 介于空神谕与 `wLEM` 之间; 它说明 "未知" 出现在哪里. 定义侧 (X1-A): `fold*` 不读 P, 以和代替 max (和不低于两项). X1 的警告: 若选择的内容 (哪个孩子, 见证本身) 被回灌作下标, 情形从 "有界二选一" (像 E) 变成 "无界搜索" (像 Σ), 优超者可能不存在, 除非折叠对回灌的下标单调. X1-I 的 Herbrand 抽取是从经典证明机械地得到 `fold*` 的一条路径; 新许可之后它只在定义侧还有用.

**最便宜的实验 (判断).** 只含 ℕ-极限的玩具树: 保留 = 恒等, 链 = 迭代基本列, P 取任意 `d : ℕ → Bool`; 定义 `fold* = keep ⊕ chain`, 证 `∀ d → fold[d] ≼ fold*`; 再加一层 Ω-分支, 记下单调性在哪一步被要求. 同一文件的验收半: 以 LEM 为模块参数, 在下标 Ω+1 处写 `fold[wLEM]`, 检查它在现行折叠走链处保留. 放进实验 E4.

**与已编译否定的张力.** 强优超要求对回灌下标单调: 要对照 `no-tw`、`lpo-tw` (对任意派发推出 LPO) 与 `G-mono` (沿字面第一位置序无前提成立), 查所需单调性的量化域落在哪一边. `fold*` 不读 P, 头部观察与 P 无关, 不触 `obs→dec`; 但要核 `full→dec` 的 "能保留处都保留" 是否被 `keep* ⊕ chain*` 满足. P 不成立处的 `keep*` 若要全定义, 碰 `Toy.loop`. 带 LEM 参数时 `fold[wLEM]` 判定 P 不受 `obs→dec`、`dec→WLPO` 约束 (它们的结论由 LEM 推出). 台账 V79 有一条同向的判断: "经典地判定分支相等的折叠可满足" 那个接口.

### 2.2 偏保留的包络: dominance, 沿嵌入延拓, 单调包络

**原领域 (文献).** Escardó 与 Knapp 以 dominance 在单值类型论里定义偏元素 (定义域命题加该命题下的值), 不假设可数选择或 Markov 原则 【摘要】([CSL 2017](https://drops.dagstuhl.de/opus/volltexte/2017/7682/)). 宇宙的内射性: 给 A 上的类型族 X 与嵌入 e : A → B, 可延拓成 B 上的族 Y, 使 Y(e a) ≅ X(a), 像之外的点 Y(b) ≅ 1, 构造不判定一个点是否在像里; 若各 X(a) 可搜索, 各 Y(b) 也可搜索 【原文】([Escardó, CCC 2015 幻灯片](https://martinescardo.github.io/.talks/ccc-2015.pdf)). HoTT 书的 Cauchy 实数用 Lipschitz 延拓定义 min 与 max, 不按 x < y 分情况 【摘要, 二手】([PlanetMath 转述](https://planetmath.org/1133thealgebraicstructureofcauchyreals)).

**对着的难点与路 (判断).** 难点一 (保留只在 P 有证据时有定义); 给 2.1 的 `keep*` 提供候选; 定义侧.

**我方草图 (判断, X1-F).** (i) 以 `Σ c. P c` 为下标的上确界: `chain ⊕ sup_{(c,p)} keep(c, p)`, 与仓库已有的守卫域同形, 新的只是把它读作偏元素的并. (ii) 沿嵌入延拓: 保留的分支 g 定义在层号 μ 的树上; 构造一个定义在 "目标以下合法的下标" 上的分支, μ 真低于目标时与 g 一致, 否则取 0; 要求从目标以下的下标到 μ 层下标的纤维是命题. (iii) 单调包络 `keep* x = sup { keep y : y ≤ x, P y }`, 用守卫的 Ω-分支实现; X1 判断它是 `keep*` 的最小候选. **两份笔记在这里不一致**: X2-10 判断 `sup_{c′ ≼ c} g c′` 不是布劳威尔树能表示的上确界; X1-F 自己也指出, 以 `Σ c. P c` 为下标的上确界要读成 "按低层合法树分支的 Ω-极限", 对不满足 P 的 c 取 0 又要判定. 两者合起来的读法 (本报告推断): 包络只在守卫域本身能读成 Ω-极限时可用, 即仓库的守卫域机制 (台账 U2 "受支配的域": 尾部分支域上保留律有不要神谕的模型) 已经给出的那一类.

**最便宜的实验 (判断).** 纸面: 在现有守卫域上写出 (ii) 的纤维, 检查它是否是命题、是否只用字面公共上界. 编译: Bool 守卫的玩具, 证 `P → keep ≼ chain ⊕ envelope`. 放进实验 E4.

**与已编译否定的张力.** P 不成立时包络产生空守卫, 正是 `no-start-all`、`no-carry-Ω₂`、`no-K2′` 的退化结点; 按最佳实践先在带证据的读回域上陈述. 下标是低层树, 只能出现在允许 Ω-分支的层 (`Toy.loop`). 与台账 U2 重合.

### 2.3 一致的定义只在假设下正确, 不同表示的一致性事后证

**原领域 (文献).** Spector: |a|_O = |b|_O 推出 H(a) 与 H(b) Turing 等价 【摘要】([Wikipedia, Kleene's O](https://en.wikipedia.org/wiki/Kleene%27s_O); [Spector, JSL 1955](https://www.cambridge.org/core/journals/journal-of-symbolic-logic/article/recursive-wellorderings/00E43739CDCB310B2C134F03599EE246)). Moschovakis: |a| ≤ |b| 时 H_a 递归于 H_b, 归约的指标由 a, b 递归地算出 【摘要】([PJM 1966](https://msp.org/pjm/1966/18-2/pjm-v18-n2-p11-p.pdf)). Brattka 与 Gherardi: 弱可计算的类对复合封闭, 单值的弱可计算运算已经可计算 【摘要】([JSL 2011, arXiv:0905.4679](https://arxiv.org/abs/0905.4679)). Della Dora、Dicrescenzo 与 Duval 的动态求值: 零测试不可判时把计算分裂成 "当作零" 与 "当作可逆" 两支 【摘要】([van der Hoeven 转述](https://www.texmacs.org/joris/direval/direval.html)).

**对着的难点与路 (判断).** 难点一 (定义不比较层号), 难点二 ("该有的值" 定义为等价类); 供给【经典值】与【逐层封闭】.

**我方草图 (判断, X4-#3, X1-D, X1-H).** 写一个对一切 ℓ, t 都有定义的全函数 `emb ℓ t : Tree_ℓ → Tree_t` (按 t 的构造把 ℓ 层的树抬进去), 只证 "ℓ ≤ t 成立时 emb 保 ≼"; 保留行无条件地用 emb. "该有的值" 不在定义里要求, 事后证一条 Spector 式定理: 值相同的两个层号, 折叠输出互相 ≼. 不在同一路径上的层号对规定一个统一的安全输出 (例如一律走链), 只在读回域上证它不掉值. X1-D 的那句 "单值的弱可计算运算已可计算" 提醒: 多值性只在输出不必由输入的值唯一决定时有用, 我方只要 ≥ 参照, 中间层可以依赖码而不是值. X1-H 的动态求值变体: 结点形如 `(P → 树) × (¬P → 树)`, 值定理在每支里各证, 闭项上 P 由计算给出时坍缩; X1 判断这与已有的 `Carry` 证书路线重合.

**最便宜的实验 (判断).** 层号是到 Ω 为止的布劳威尔树的玩具里写 emb, 证 "ℓ ≼ t → emb 单调" 这条条件定理; 再把塔第 3 项闭项的保留行改成无条件用 emb, 判据是闭项合法无前提、值下界不变. 实验 E10.

**与已编译否定的张力.** `bare-way→lpo` 否定的是 "只读两个裸层号且处处正确" 的派发, 这里只在假设下正确, 不在其中; 若输出的合法性要求处处成立, `bare-incomplete` 适用. emb 不能要求保初始段 (`embVᴰ→LPO`、`seg↔LPO`). 唯一性只能是值上的 ≼, 不能是结构的 (`no-L`). 带 LEM 参数的验收文件里, 假设 ℓ ≤ t 可以判定, Spector 式定理的证明可以用三歧, 结论标 "条件".

## 第三族: 按来源派发, 保留缺陷的定义侧候选

**汇合.** 大数记号 (BMS 的升级判据是 "被折叠的根是否在我的祖先链上"), 类型论形式化 (LogRelKit 的宇宙结点自带 `l′ < l` 的证据), 参数性 (PHOAS 与 Mendler 迭代: 定义不能检查抽象类型的元素), 构造类型论 (很依赖的函数类型, cofree comonad 的历史表), 经典可实现性 (X1-J: 观察者给出的下标充当见证), 五处给出同一做法: 派发读的是层号从哪里来 (祖先, 证据, 类型实例), 不比较层号的值. X4 判断它与仓库已编译的 `compare-link` 和 `locate→irr-search` 同向. **与台账的重合 (仓库事实)**: U22 "派发作为数据随树一起构造 (位置带来历)" 未试, 有一个比较表版临时原型 `YiRC`; U27 部分走通, 同支证据闸门合法, 作为标注随折叠走的消费端合法 (`Ψᴹ-lgl`), 产出端没有试, 证据由裸树上的函数给出要判定 (`kept→dec`); R3 "派发的来历作为树的一部分" 未试, 改块要作者定. 本族的新内容是文献给出的具体形状, 不是方向本身.

### 3.1 层号写成位置: 祖先指针, 抽象类, 历史表, 很依赖的链

**原领域 (文献).** BMS 中第 m 行的 m-parent 是 "之前第 m 个元素更小的最后一列", m > 0 时还要求它是 (m−1)-ancestor, 所以第 m 行的父子关系只在上一行的祖先链里找; 展开时, B₀ 中的列 D 的第 m 个元素升级当且仅当 B₀ 的首列是 D 本身或 D 的 m-ancestor; 序与字典序一致 (Cor. 2.4), 良序证明的最后一步用 L_α 的 Σₙ-初等子结构 【原文摘读】([arXiv:2307.04606](https://arxiv.org/html/2307.04606v3)). Chlipala 用对抽象变量类型参数化的高阶抽象语法在 Coq 里形式化语义变换 【摘要】([PHOAS, ICFP 2008](https://adam.chlipala.net/papers/PhoasICFP08/)). Ahn 与 Sheard: Mendler 式 catamorphism 对含负出现的数据类型也停机, course-of-values 对负类型有问题 【摘要】([ICFP 2011](https://bibtex.github.io/ICFP-2011-AhnS.html)). Hickey 的很依赖函数类型 `{f | x:A → B_{f,x}}` 的值域可以引用 f 本身, 但须尊重定义域上的良基序, 语义在 `{a′ : A | a′ < a}` 上逐步定义 【原文】([FOOL 3, 1996](https://www.cs.cornell.edu/jyh/papers/fool3/paper.pdf)). Uustalu、Vene 与 Pardo 给出以函子与 comonad 参数化的递归格式, histomorphism 是取 cofree comonad 的特例 【摘要】([Nordic J. Computing 2001](https://www.academia.edu/7453886/Recursion_Schemes_from_Comonads)).

**对着的难点与路 (判断).** 难点一的定义侧, 直接对着下标 Ω+1 处的保留缺陷; 不在五条值路之内, 与 3.2 合用时供给【逐层封闭】.

**我方草图 (判断, X4-#1、#6、#13、#9).** 祖先指针: 树里每个层号不存成裸树, 存成 "指向祖先结点的指针" 加 "在该结点参数上的读法". 折叠到目标 t 时, 孩子的层号若经由被折叠结点的参数而来 (被折叠结点是它的祖先) 就走链或对角, 否则保留; "是不是祖先" 沿指针结构递归即可判定, 不碰层号的值. 当前的缺陷在这一写法下变成: 槽位的指针不经过被折叠结点, 就保留. 抽象类: `Tree (V : Sort → Set)`, Sort 是上下文里的位置 (不是层号的值), 第 s 类的 Ω-结点是 `(V s → Tree V) → Tree V`; 折叠到 s₀ 是一次实例化, 其他类保持抽象, 分支仍是抽象类型上的函数, 所以保留不经派发出现; "高于目标就走链" 要知道上下文里哪些位置在 s₀ 之上, 位置是上下文下标, 比较可判定. 历史表: 对层号树写 histomorphism, 在层号历史里产生的孩子层号按位置查表. 很依赖的链: `data Ch` 与 `top : Ch → Tree` 互相定义, `step : (c : Ch) → Tree (lvl (top c)) → Ch`, 任意两个链点沿这条路径有字面公共上界.

**最便宜的实验 (判断).** 两层 (Ω₁, Ω₂) 的纯 `.agda` 玩具, 层号写成祖先指针, 派发只看指针是否经过被折叠结点; 判据: 不用 `Dec` 与 `Funext` 通过检查, 两三棵小闭项与 YiLean 读回的值至少单向 ≼; 然后在下标 Ω+1 处看保留是否不经 `Dec` 出现. 同一文件加两类的 PHOAS 版本, 记下 "高于目标" 那一行需要位置的什么信息. 实验 E6.

**与已编译否定的张力.** 第一个要查的是 `top-branch→lpo`: 指针在 Ω-分支各支之间是否一致. 各支要取规范位置 (`moved-undirected`, `self-not-cohX`); 值相同而来源不同的两个层号会进不同的行, 值上是否互相 ≼ 要用验收定理说 (`chain→weak-eq` 的区域). 指针若由裸树上的函数算出, 对上 `kept→dec`; 指针本身是数据, 与 `locate→irr-search` 一致. PHOAS 树不是布劳威尔树, 要给 View (实例化 V 为对应层的树), 纲领第 1 条允许中间层比布劳威尔树多. 记号归属: 祖先链的灵感来自 BMS, 按 "借助记号探路" 如实标出, 不算树自足; X4 判断指针与类两个新字段不读自任何记号的基本列规则, 翻译账上属于 "由树的要求逼出" 一侧的候选.

### 3.2 由证据取出的下层工具包: 派发写成沿路径传下的字典

**原领域 (文献).** logrel-mltt 写 `module LogRel (l : TypeLevel) (rec : ∀ {l′} → l′ < l → LogRelKit)`; 宇宙情形的记录存 `l′` 与 `l< : l′ < l`, 再 `open LogRelKit (rec l<)` 取下层的判断; 最后 `kit l = LogRel.kit l (logRelRec l)`; 那里层号只有两档 【原文, 代码】([logrel-mltt LogicalRelation.agda](https://github.com/mr-ohman/logrel-mltt/blob/master/Definition/LogicalRelation.agda)). 对应论文在 Agda 里形式化转换判定, 正确性靠以项的等价为参数的 Kripke 逻辑关系, 参数化的基本引理实例化两次, 依赖归纳-递归但不依赖 UIP, 约一万行 【原文】([Abel–Öhman–Vezzosi, POPL 2018](https://www.cse.chalmers.se/~abela/popl18.pdf)). Kovács 的累积宇宙层级, 层号可来自任何带传递良基序的集合, 用归纳-递归建模超限层级 【摘要】([CSL 2022, arXiv:2103.00223](https://arxiv.org/abs/2103.00223)); 仓库 `probes/Survey/CodeGuide.md` 记它只上行 `Lift`, 没有往下的折叠. Griffin 把 call/cc 类型化为 Peirce 律 【记忆】([POPL 1990](https://doi.org/10.1145/96709.96714)).

**对着的难点与路 (判断).** 难点一; 供给【逐层封闭】(定义按层号开放递归).

**我方草图 (判断, X4-#2, X1-J).** `module Fold (t : Lv) (rec : ∀ {t′} → Below t′ t → FoldKit t′)`, 字段是保留行、对角行、链行; 结点不问 "我的层号与 t 什么关系", 只调用传到手里的工具包; 根处的工具包由调用者给出, 孩子的工具包由 "孩子的层号产生在本结点的分支域里" 这条证据算出; 对目标 t 的构造良基递归打结, 不对树. X4 指出已有的派发证书 `Carry` 接近工具包的形状, 这个写法把它从证书改成折叠模块的参数. X1-J 的形式: Ω-分支处分支函数取 `λ c → chain c ⊕ (若 c 自带 P 的证据则 keep 否则 0)`, 证据由观察者随下标给出.

**最便宜的实验 (判断).** 在临时目录复制 YiLean 折叠, 改成开放递归; 只看同层对角一行能否写成凭 Ω-结点分支类型携带的证据调用 `rec`; 判据: 定义里不出现 `Dec`, 行数与原折叠对比. 放进实验 E6.

**与已编译否定的张力.** 壁垒定理要有界三歧, 工具包只要 `<` 的证据, 不在其中. 若要求对每个孩子都给出工具包 (派发完全), 落到 `branch-complete→lpo`、`bare-incomplete`. 工具包里的证据必须是相关数据, 不能标成无关参数 (`compare-irr→irr-search`, `keep→irr-search`; LogRelKit 的 `l<` 也是相关的). X1 判断 X1-J 的形式大概已在 `branch→wdec` 的范围内, 排最后.

### 3.3 以系统自己的句法作层号: 算子码, 层号代数, 外层码, 度 (需作者裁决)

**原领域 (文献).** Dybjer 与 Setzer 写: Palmgren 发现给 Mahlo 宇宙加自然的消去规则导致矛盾; 他们区分外部 Mahlo 宇宙 (类型 Set 本身, 对其每个族算子 f 有归纳-递归定义的子宇宙 `U f₀ f₁` 与解码 `T`) 与内部的 `M : Set`, 只要求 f 在 `U f` 自身的族上全, 类型检查只检查 `T f₀ f₁` 像里的参数 【原文 pp. 1–6】([Predicativity of the Mahlo Universe, 2025](https://csetzer.github.io/articles/dybjerSetzerWeylVolume2025/dybjerSetzerWeylVolume2025Final.pdf)). Bezem 与 Coquand: 带膨胀自同态的并半格, 一致字问题与 loop-checking 在 PTIME, 无 loop 时约束在 (ℕ, max, succ) 里有模型, 动机是宇宙层号约束 【摘要】([TCS 913, 2022](https://research.chalmers.se/en/publication/530474)). 二层类型论: 对每个外部固定的 k 能构造 S_k, 但没有内部函数一次覆盖所有层 【摘要】([Annenkov–Capriotti–Kraus–Sattler, arXiv:1705.03307](https://arxiv.org/abs/1705.03307)). Taranovsky: C(a, b) 是 b 之上度 ≥ a 的最小元; 对角度 a_diag 中 a_i 只在 i < c 时使用 【原文 §2.1】([arXiv:1610.04633](https://arxiv.org/abs/1610.04633)). Takeuti 序数图的 i-截面与序族 <_i 【摘要】([arXiv:1902.02012](https://arxiv.org/abs/1902.02012)); Arai 用 Mahlo 类 Mh_k(ξ) 处理反射 【摘要】([JSL 2020, arXiv:1907.07611](https://arxiv.org/abs/1907.07611)); Duparc 用 Borel 运算对应序数运算读出 Wadge 度 【摘要】([JSL 2001](https://www.cambridge.org/core/journals/journal-of-symbolic-logic/article/wadge-hierarchy-and-veblen-hierarchy-part-i-borel-sets-of-finite-rank/1CEA2E6C2A8B52CD64BFCB52D4F68BC8)).

**对着的难点与路 (判断).** 难点一 (任意两个层号表达式有字面的并, 公共上界不用另找), 难点二 (层号是系统运算的输出).

**我方草图 (判断, X4).** (a) 算子码: 层号是 "由哪个已造出的折叠生成的" 码 `U f`, 新层上的折叠对 f 的构造递归; 合法性仿 "f 在 `U f` 自身上全", 只在自己的像上要求, 与 "律先对读回域陈述" 对应; 不写对全体层号消去的函数. (b) 层号代数: 原子是已产生的折叠输出, 用 ⊔ 与 Ω-后继生成; 约束是构造时记下的证据; 派发只问 "从已记录的约束能否推出", 推不出时一律走同一条规则. (c) 外层码或余归纳层塔: `record Tower` 用 `--guardedness`, 下一层的分支签名由这一层经同一运算得出. (d) Taranovsky 的 `next a b` 对度树 a 递归, Ω-分支在当前输出的近似处取值, 小于输出的子项成为参数. (e) X4-#12、#14、#15 依赖先把层号位置化, 单独做意义不大.

**最便宜的实验 (判断).** (a) 30 行左右的归纳-递归玩具 `data U (f : Op)` 与 `T` (本报告的最小检查说明这一类定义在仓库选项下过检查); (b) `data LExp` 加一个可靠而不完全的推导检查器, 接到塔第 3 项闭项的派发上, 判据仿 `chain-honest`; (c) 余归纳塔到 Ω_ω, 看到 Ω_Ω 时哪里失败; (d) 只用 Ω₁-分支的度树写 `next`, 在小闭项上与 BTBO 的 ψ₀ 比一个方向. 实验 E12.

**与已编译否定的张力与归属.** **X4 标出 (a)、(b)、(c) 引入系统自己的句法 (算子码, 层号表达式, 外层码), 是否算纲领第 4 条的 "引用记号" 由作者裁决; (e) 中 Duparc 式规范形最接近记号, 风险最高.** (d) 与 Takeuti、Arai 的灵感来自记号, 按 "借助记号探路" 标出; Taranovsky 的标准形要拿子项与输出比较, 属 `obs→dec` 一族, 去掉标准形他本人指出单调性失效. 外层码若是含 Ω-共尾元、有三歧的精确初始段, 壁垒定理直接适用, 所以外层必须不精确或不全比较; 原子的解释若要精确, `seg↔LPO`、`embVᴰ→LPO` 出现. X4 估计 (b) 是新增脚手架, (d) 若照抄标准形会加深翻译.

## 第四族: 一步引理加层树上的打结, 难点三的证明组织

**汇合.** 类型论形式化 (Abel–Öhman–Vezzosi 的参数化基本引理加层号上的开放递归, Kovács 的超限层级), 逻辑关系 (lax 与 pre-logical relation 保留基本引理且可合成), 终止性 (size-change, 循环证明的全局迹条件, almost-full 关系), 可证性逻辑 (Schmerl 公式的层间换算), 证明挖掘 (遗传可优超), 五处给出同一结构: 把 "对一切层" 拆成一条以更低层或规则形状为参数的一步引理, 加一次良基打结. Abel–Öhman–Vezzosi 一处文献在 X3-D 用于证明组织, 在 X4-#2 用于定义组织. 第七族 7.4 的否定结论从反面支持这一形状: 能对全体层一致消去的结构推出矛盾或 LPO, 所以一致定理只能写成对给定层号构造的递归.

### 4.1 开放递归加层树上的良基打结, 参数化基本引理

**原领域 (文献).** Abel–Öhman–Vezzosi 与 logrel-mltt 如 3.2 所述 【原文】. Plotkin、Power、Sannella 与 Tennent: lax logical relation 保持积类型, 不必保持指数; 普通二元逻辑关系不能合成; Honsell 与 Sannella 的 pre-logical relation 保留基本引理且可合成 【未标】([ICALP 2000](https://era.ed.ac.uk/items/7935f804-4808-44a9-aac4-eaf53cf2ef37); [Sannella 在 TYPES 列表的说明](https://lists.seas.upenn.edu/pipermail/types-list/2006/001053.html)).

**对着的难点与路 (判断).** 难点三; 供给【逐层封闭】, 也供给【滞后律】(一次性的充分性定理就是抽象接口上的基本引理).

**我方草图 (判断, X3-D 与 X3-K).** `Step : (ℓ : Lv) → (IH : ∀ ℓ′ → ℓ′ ⊏ ℓ → Thm ℓ′) → Thm ℓ`, ⊏ 取层树的结构子项关系, `thm = wfRec Step`. 第 ℓ 层的关系 (1.2 的 `Sim` 或 1.3 的 `Dom`) 以更低层的关系包为参数, Ω-分支情形用参数里的低层关系处理分支下标; 滞后函数作为 `Thm` 的输出, 1.3 的 Φ 写在 Step 里. 抽象接口 (零, 后继, ℕ-极限, 第 ℓ 层的 Ω-极限, 第 ℓ 层的折叠) 上的 lax 关系: ℕ-极限 lax 保持 (`R (f n) (g (h n))`), Ω-极限只在同一个 c 上保持 (指数处 lax); 基本引理对一切闭的折叠项一次成立. 同一个 Step 仿 "实例化两次" 用于 "参照对我方" 与 "我方对我方 (不同下标)".

**最便宜的实验 (判断).** 取两站已有的逐站证明, 把共同部分抽成带 IH 参数的 Step, 看两站能否都由同一个 Step 实例化 (只做类型检查, 不做新数学); 写出接口记录, 检查现有的逐站引理是否恰为基本引理在某个构造子处的情形. 实验 E5.

**与已编译否定的张力.** ⊏ 必须是结构的, 不是值的 ≺; Step 内不能按 "ℓ′ 与 ℓ 是否同层" 的值分情况 (`dec→WLPO`, `¬tri`); 带 LEM 参数时可以, 但结论成为条件定理, 不算 "闭包定理与阶段无关" 这一树侧判据. 折叠对高层参数不按值单调, 所以 R 不能是 ≼ 本身, 只能是更细的结构关系; Ω-下标上只能取对角关系 (`noBT`). 层号含 Ω-共尾元时, 对照壁垒定理的前提逐条核.

### 4.2 有限规则形状上的全局条件: size-change, 循环证明, almost-full

**原领域 (文献).** Size-change 原理: 每条无穷调用序列都迫使某些数据无穷下降则程序终止, 可由 Büchi 自动机判定, PSPACE-难 【摘要】([Lee–Jones–Ben-Amram, POPL 2001](https://bibtex.github.io/POPL-2001-LeeJB.html)). Ben-Amram 把它推广到单调性约束, 能在单指数时间里构造显式的全局 ranking function 【摘要】([LMCS 6(3:2) 2010](https://lmcs.episciences.org/1001)). Brotherston 与 Simpson 的 LKIDω 用全局迹条件保证非良基无穷证明的健全 【未标】([LICS 2007 版](https://core.ac.uk/download/28964889.pdf)); Sprenger 与 Dam 给出一阶 μ-演算中循环证明与树形证明的有效互译 【摘要】([FoSSaCS 2003](https://bibtex.github.io/FoSSaCS-2003-SprengerD.html)). Vytiniotis、Coquand 与 Wahlstedt 指出析取良基、size-change 与 wqo 共享 Ramsey 式论证, 在构造性类型论里用 almost-full 关系处理 【摘要】([ITP 2012](https://researchr.org/publication/VytiniotisCW12)).

**对着的难点与路 (判断).** 难点三; 供给【滞后律】(给出一次性定理所需的度量) 与【逐层封闭】.

**我方草图 (判断, X3-H, X2-13, X1-K).** 折叠的规则形状有限 (零, 后继, ℕ-极限, Ω-极限 × 低、同、高, 共十二种). 每种画一张欠账转移图: 1.3 的欠账向量各分量经这条规则是严格降、不增, 还是 "增量不超过外层分量"; 求合成下的闭包 (有限), 检查每个幂等环上是否有分量严格降; 成立则 size-change 理论保证存在字典序或析取的度量, 把它写进 Agda, 一次良基归纳. X2-13 的变体: 折叠能编译说明 Agda 的调用矩阵检查已接受它, 用调用矩阵手算闭包, 读出意图值的词典序形状.

**最便宜的实验 (判断).** 纸面: 十二张图, 手算闭包与幂等环; 在 E1、E3 定下欠账向量之后做. 实验 E9.

**与已编译否定的张力.** 图按低、同、高分情形画; 证明若在运行时要知道是哪一情形, 对上 `obs→dec` 一族; 最佳实践 "树的语言" 说规则形状只说效果, 不是可执行的分情况, 所以图要按效果画, 是否可行未知. size-change 的健全性证明是经典的 Ramsey 论证, 构造性版本要走 almost-full; 新许可下验收文件可以用经典版本, 结论标 "条件". 原技术是上界 (终止) 方向, 只借形状, 不借界.

### 4.3 层间换算律与遗传上界

**原领域 (文献).** Beklemishev 的章节给出 Schmerl 精细结构关系的一般版本 【摘要】([Springer 2015](https://doi.org/10.1007/978-3-319-22156-4_9)); Beklemishev 与 Pakhomov 得到不同复杂度的迭代反射之间的保守关系, 称为 Schmerl 公式的类比 【摘要】([arXiv:1908.10302](https://arxiv.org/abs/1908.10302v1)); Schmerl 公式的确切陈述笔记未核. Howard 的可优超性、Bezem 的强可优超性与 Kohlenbach 的逐点变体 【摘要】([arXiv:1512.07113](https://arxiv.org/pdf/1512.07113); Ferreira 讲义同上).

**对着的难点与路 (判断).** 难点三; 供给【滞后律】与【证明论】.

**我方草图 (判断, X3-L, M).** 找一条 "第 ℓ 层上长度 n 的链, 被第 ℓ⁺ 层上以 F(n) 为参数的一步支配" 的换算律, 一次证明, 作 4.1 的 Step 里的主要引理; reflexive induction 读作以更低层的换算律为函数参数的良基递归. 遗传上界按层递归定义 `Maj_ℓ`: ℕ-层上要求上界者单调 (Bezem), Ω-层上滞后是从低层下标到滞后的泛函.

**最便宜的实验 (判断).** 在简化模型里核对 "内层长度 n 的链 ≼ 外层的一步" 时外层参数要多大 (纸面或有限测试), 可用 E1 的数据.

**与已编译否定的张力.** X3 判断 4.3 只是形状类比. 遗传上界需要折叠对 c 单调, 而折叠对高层参数不按值单调 (`no-tw`、`lpo-tw`), 只能对结构关系做上界; "c* 上界 c" 若靠比较得到, 落入 `Trich₂→WLPO`.

## 第五族: 非规范树的语义靠上下文与闭包条件, 不靠分类

**汇合.** 改写终止性 (上下文依赖的解释), 逻辑关系与 NbE (Kripke 世界, glueing, 对卡住的项 reflect), 可约性候选与双正交 (CR3, ⊤⊤ 闭包), 无穷改写 (无意义项的公理化), 抽象解释 (只用 γ, 局部完备, 下近似逻辑), 域论 (理想完备化), 六处的共同做法: 语义对象或者依赖上下文, 或者是关系与闭包条件, 而不是按 "规范或退化" 分情况定义的函数; 退化的对象通过闭包规则取平凡值, 不经分类. X2 判断 4 与 7 都落到按世界索引的语义, 9 与 14 都不靠语法分类处理退化树, 2 与 8 是下近似方向的同一思路.

### 5.1 带上下文的意图值与 Kripke 单调

**原领域 (文献).** Hofbauer 的 context-dependent interpretations 是在自然数解释之上扩展的语义终止方法 【摘要; 定义形状是记忆】([RTA 2001](https://link.springer.com/doi/10.1007/3-540-45127-7_10)); Moser 与 Schnabl 给两个子类紧的 derivational complexity 上界 【摘要】([RTA 2008](https://rd.springer.com/chapter/10.1007/978-3-540-70590-1_19)). Pitts 与 Stark 的逻辑关系按状态关系索引并同时关联求值上下文与表达式 【摘要】([1998](https://homepages.inf.ed.ac.uk/stark/operfl.html)); Dreyer、Neis 与 Birkedal 构造 step-indexed Kripke 逻辑关系 【摘要】([ICFP](https://people.mpi-sws.org/%7Edreyer/papers/stslr/icfp.pdf)).

**对着的难点与路 (判断).** 难点二 (带挂起上下文的结点, 其值依赖外层目标); 供给【滞后律】与【逐层封闭】.

**我方草图 (判断, X2-4).** `V : (c : 目标) → Tree → Tree`; 逐规则 `V c (结点) ≼ 用 V c′ (各部分) 拼出的值`, c′ 由规则给出 (低于目标: c′ = c; 同层对角: c′ 取输出; 高于目标: c′ 为链的下一站); Kripke 单调 `e : c ⊑ₗ c′ → V c t ≼ V c′ t`, e 是字面的世界扩张证据 (如 `wk` 或公共上界); 主定理 `∀ c → V c t ≼ fold c t`.

**最便宜的实验 (判断).** 只给值依赖外层目标的那类结点 (台账里 framed keep 一类) 写 V_c, 其余构造子沿用现有意图值, 看逐规则不等式与 Kripke 单调能否同时成立. 实验 E11 (条件实验).

**与已编译否定的张力.** Kripke 单调是一种跨世界单调. `no-tw`、`lpo-tw` 量化的是任意派发且前提含塔的两项; `G-mono` 沿字面第一位置序无前提成立. 世界扩张若只取字面第一位置路径, 落在 `G-mono` 一侧的可能存在, 但这要逐条读两边的陈述, 不凭形状判定.

### 5.2 粘合的语义影子: 树带一个标成无关参数的参照下界

**原领域 (文献).** Coquand 与 Dybjer 直接研究正规化函数: 正规化 = quote ∘ 解释, 用 glueing 给组合子形式的 Gödel T 一个正规化算法, 方法推广到布劳威尔序数等超限归纳类型 【摘要】([MSCS 1997](https://www.cambridge.org/core/journals/mathematical-structures-in-computer-science/article/intuitionistic-model-constructions-and-normalization-proofs/15AE4B790FF9E4B1998CE92054DBD3CF)). Sterling 与 Harper 把逻辑关系当作原语类型, 在 Artin glueing 的 topos 内语言里构造 【摘要】([arXiv:2010.08599](https://arxiv.org/pdf/2010.08599)). Urban 与 Miné 把分段 ranking function 推广到以自然数值函数为系数的 ω-多项式, 自称第一个能推理序数的抽象域 【摘要】([ESOP 2014](https://www-apr.lip6.fr/%7Emine/publi/article-urban-mine-esop14.pdf)). Bruni、Giacobazzi、Gori 与 Ranzato: 抽象解释的完备性只需对给定输入成立, LCL_A 混合上近似与下近似 【摘要】([LICS 2021](https://research.unipd.it/bitstream/11577/3400197/1/cameraready.pdf)). O'Hearn 的 Incorrectness Logic: [P] c [Q] 成立当且仅当 Q 中每个状态都能从 P 中某状态经 c 达到 【摘要】([POPL 2020](https://discovery.ucl.ac.uk/10095439/1/IL.pdf)). Cousot 与 Cousot 的终止性抽象解释框架 【原文, 摘要页】([POPL 2012](https://cs.nyu.edu/~pmc309/COUSOTpapers/POPL12.shtml)).

**对着的难点与路 (判断).** 难点二 (读回域有一个原则化的定义: quote 的像; 退化树用 reflect 取平凡影子, 不判定); 供给【经典值】与【滞后律】.

**我方草图 (判断, X2-7、8、15).** 示意, 未编译:

```agda
record Glued : Set where
  field tree : Tree
        ref  : Tree                   -- 语义影子: 参照值的下界
        .lb  : ref ≼ fold c tree      -- 无关参数 (AGENTS 允许)
reflect : Tree → Glued                -- 退化或未知的树: ref := zero 或字面下界
quote   : 读回域 → Glued              -- 规范构造: ref := Ref t
```

树一侧的计算不能依赖 `ref` 与 `lb` (无关参数在类型层面保证), 对应 Sterling–Harper 的模态分离. 只用 γ 的写法: `γ r := λ t → r ≼ fold c t`, 逐构造子证可靠性方块, 读回域的封闭条件照 LCL 的规则写; ℕ-极限处的下界 "存在某一站达到" 与 IL 的 backwards variant 规则同形. 下集写法: `D t := λ b → b 落在 fold c t 之下`, 下界定理写成下集包含.

**最便宜的实验 (判断).** 给现有 BTBO 档折叠配 `Glued`, `lb` 用现有逐规则引理填; 填不进去、要额外前提的规则就是读回域必须收窄的地方, 同时得到一份 "哪些规则依赖读回域" 的清单; 与 1.3 的下估计 m 同一文件. 实验 E7.

**与已编译否定的张力.** 计算若查看 `ref` 才决定分支, 落入 `obs→dec` 一族; 无关参数防止这一点. Kripke 函数空间若要求对任意扩张稳定, 对照跨层单调的配对否定. 最佳抽象 α 需要判定, 构造性下不可用; 带 LEM 参数时可用, 结论标 "条件". 下集写法与旧调查里的 Fairtlough 路径、Ketonen–Solovay step-down 重叠.

### 5.3 退化树按闭包条件进入 "好集合"

**原领域 (文献).** Melliès 与 Vouillon 把类型解释为在双正交下封闭的项集 【摘要】([LICS 2005](https://www.irif.fr/~vouillon/publi/recursivetypes.pdf)). Kennaway、van Oostrom 与 de Vries 用公理刻画无意义项的集合, 公理推出 genericity、模无意义项的合流与等同一切无意义项的一致性, 正交 TRS 中最小的这种集合是 root-active 项 【摘要; 五条公理原文未读】([JFLP 1999 作者 PDF](https://www.cs.le.ac.uk/people/ferjan/fdv1/Distribution/meaningless.pdf)).

**对着的难点与路 (判断).** 难点二 (非规范树到处都是, 不能靠收窄定义域排除; 反复出现的 "谓词太宽" 否定); 供给【经典值】.

**我方草图 (判断, X2-9、14).** 观察者 E 是 (目标 c, 参照下界 r, 外层折叠上下文); `t ⊥ E := r_E ≼ E[fold c t]`; `Good := (Canon^⊥)^⊥`, Canon 是读回域的生成元; CR3 式规则: 常值序列 `lim (λ _ → s) ∈ Good ⇐ s ∈ Good`; 基本引理: 每条折叠规则保持 Good. 或者: `Degen` 取满足闭包公理 (对子调用封闭, 对 ≼-等价封闭, 与规则左边的重叠封闭) 的任一集合, 意图值写成关系 `Vrel t r`, 在 Degen 的子树处允许 r 取平凡下界.

**最便宜的实验 (判断).** 纸面: 把 `no-start-all`、`no-carry-Ω₂`、`no-K2′`、V64 的反例对象收成一个集合, 逐条查它是否满足闭包公理, 以及在单层玩具上是否进入 Good; 进入就说明这些否定可以统一处理. 放进实验 E2.

**与已编译否定的张力.** Degen 不可判定, V 只能是关系; 规则的计算若要知道子树是否退化, 落入 `obs→dec`; 带 LEM 参数的验收文件里可以按 Degen 分情况定义, 结论标 "条件". 观察者若比较两个分支, 落入 `full→dec`、`dec→WLPO`; 观察者太弱时会把值偏低的树也收进 Good.

## 第六族: ℕ-极限的阶段承担判定

**汇合.** 可计算性 (Putnam 与 Gold 的极限可计算, Ershov 层级, Montalbán 的 true stages), 证明论 (ε-替换法, Avigad 的更新过程, Aschieri 与 Berardi 的学习式可实现性), 可计算分析 (软比较), 构造拓扑 (ℕ∞ 的全知性), 四处用同一做法代替不可判定的关系: 一族逐阶段可判定的猜测, 在无穷多个阶段 (true stages) 或从某阶段起正确. 本报告推断 (由 X1 与 X4 合出): 布劳威尔 ℕ-极限的值是上确界, 对下界而言只要猜测在共尾的阶段上正确、猜错不使那一项的值越过合法性约束, 不需要知道何时猜对, 也不需要停机.

### 6.1 ℕ-极限作为并行搜索与试错

**原领域 (文献).** Avigad 证明算术的 1-一致性等价于一类更新过程的不动点存在, 这类过程隐含在 ε-替换法里 【摘要】([MLQ 2002](https://www.andrew.cmu.edu/user/avigad/Papers/update.pdf)). Aschieri 与 Berardi 对 HA + EM1 给出学习式可实现性 【摘要】([LMCS 2010](https://lmcs.episciences.org/1061)); Aschieri 的博士论文把超限更新过程与一致性强度对应, U(ω) 对应 PA 的 1-一致性, U(ω·2) 对应初等分析 【摘要】([arXiv:1012.4992](https://arxiv.org/abs/1012.4992)). Montalbán 对每个计算序数 ξ 给阶段上的关系 ≤_ξ: 一致可计算的预序, 沿层号嵌套, 极限处取交, 近似沿 ≤_ξ 增长, true stages 共尾; Lemma 7.4: 给定阶段只有有限多层有非空近似; Lemma 7.8: 极限处的不连续归咎到前面某层修正; 难点被移进近似的定义 【原文摘读】([arXiv:1306.2623](https://arxiv.org/abs/1306.2623)); 后续文章指出元定理按原写法只覆盖后继情形 【摘要】([Day–Greenberg–Harrison-Trainor–Turetsky, arXiv:2211.07958](https://arxiv.org/abs/2211.07958)). Konečný、Park 与 Thies 把实数比较公理化为半可判定的 Kleenean 值, 相等时 Kleenean 无定义 【原文】([arXiv:2202.00891](https://arxiv.org/abs/2202.00891)).

**对着的难点与路 (判断).** 难点一 (逐阶段可判定的猜测代替不可判定的比较); 供给【滞后律】(改判次数就是滞后的一种来源) 与【证明论】(Aschieri 的 U(α) 与一致性强度的对应).

**我方草图 (判断, X1-B、C, X4-#10).** Σ⁰₁ 型 P (P ⇔ ∃n. Q n, Q 可判定, 见证可构造): `out x = lim (λ n → if found x n then chain n ⊕ keep (见证) else chain n)`, 切换时加上保留而不换掉链, 使相邻项按合法性步进; P 不成立时值等于链, 成立时不低于保留. Δ⁰₂ 型 P: 可判定的 `guess x n`, `out x = lim (λ n → row (guess x n) 的第 n 个近似)`, 改判时累加; 改判计数器取被折叠的树本身, 递归是结构递归. true stages 式: 第 n 项用 `guess_n ℓ t`, 只读两棵层号树沿主干的深度 n 截断; 极限层号仿取交, 不连续处归咎到第 n 支. 层号比较若先找字面公共上界 (塔 `tw n` 的某一站) 再用 `bdec`, 就是 Q x n, 前提是 "层号 ≤ tw n" 本身可判定 (层号带站号证据).

**最便宜的实验 (判断).** 玩具: `α : ℕ → Bool`, P := ∃k. α k ≡ true, 保留的类型要 k 与证明; 写 `out`, 证 `chain ≼ out` 与 `P → keep ≼ out` (放进 E4). 纸面: 查仓库里各派发谓词是 Σ⁰₁、Π⁰₁ 还是 Δ⁰₂ (放进 E2). true stages 的玩具只在 Ω_ω 以内的层号上做, 先证合法 (相邻项按第一位置步进), 再对 ψ₀(Ω_ω) 的参照证一个方向的 ≼ (实验 E12).

**与已编译否定的张力.** `sig→lpo`、`full→dec` 说的是头部观察, 这里头部恒为极限, 第 n 项的头部只反映 "到 n 为止找到没有"; 要逐条核 `full→dec` 的 "能保留处都保留" 是否被 "只在极限意义上保留" 满足. 字面相等型的 P 一般是 Π⁰₁, Σ⁰₁ 的做法不适用, 要用 Δ⁰₂ 的 "精度 n 的交接", 成败在于保留在只是近似相等时能否执行; 精度 n 的回退可能落入 `sep→wdec` 的 "可观察回退" 前提. 猜测可能使相邻项不单调, 合法性要求第一位置步进, 必须证安全性 (`strict→LPO` 只否定严格递增). Ω-分支上没有阶段: 只能用于交替路线里把 Ω 表示成对角 ℕ-极限的那一层; X4 判断对 Ω-分支做有限截断是本条最大的风险 (`Toy.loop`). 累加会给基本列带来毛刺, FGH 的值可能与参照不同, 序数值验收不受影响. Ershov 层级依赖记号的选择 (Ambainis 1995, 未读), 改判计数器取树本身时与纲领第 4 条的关系另看. X4 把 #10 记为新增脚手架.

### 6.2 在表示精度上做软比较; 可搜索的离散影子

**原领域 (文献).** `select : Π(x,y : K). (⌈x⌉ ∨ ⌈y⌉) → M(⌈x⌉ + ⌈y⌉)`, 由它得到多值的软比较 `mSplit : Π(x,y,ε). 0<ε → M((x<y+ε)+(y<x+ε))`; `select` 在 Coq 中是公理 【原文】([arXiv:2202.00891](https://arxiv.org/abs/2202.00891)); 同组后续工作说, 外延地识别实数时非确定性不可避免 【摘要】([arXiv:2410.13508](https://arxiv.org/abs/2410.13508)). ℕ∞ 上 LPO 成立 (对一切 p : ℕ∞ → 2, 存在性可判定), 不用连续性; 推论: 任意两个函数 ℕ∞ → ℕ 相等或不等; 可搜索类型对 Σ 封闭, 对以子单元类型为下标的 Π 封闭, 可数族加无穷远点的和仍可搜索, 迭代给出可搜索序数 【原文】([Escardó, CCC 2015](https://martinescardo.github.io/.talks/ccc-2015.pdf)); 这些集合对可判定子集良基, 简单类型可达 ε₀ 以下任意序数 【摘要】([JSL 2013](https://projecteuclid.org/euclid.jsl/1389032274)).

**对着的难点与路 (判断).** 难点一中 "两个孩子字面相等" 那一型.

**我方草图 (判断, X1-D、E).** 找可判定的 A_n, B_n, 满足 A_n ∨ B_n 可构造地成立, A_n 下保留可执行且 ≥ 参照, B_n 下链 ≥ 参照, A_n 与 P 不等价 (否则 `obs→dec`), 再 `lim_n` 合并; 候选是 "两个孩子下标在深度 n 以内字面一致" 与 "在深度 n 以内分开". 中间层的 ℕ-极限改为 ℕ∞-极限 `f : ℕ∞ → Tree`, View 只读 ℕ 部分, 要求 `f ∞ ≼` 上确界; 若两个子对象的离散影子是 ℕ∞ → ℕ 的函数, 它们相等可判定. X1 的纸面论证 (判断, 未编译): 设 s : ℕ → Bool, β = lim_n (s 在 n 以内出现 true 则 ω+4 否则 n), α = ω+2, 则 "α ≤ β+1 或 β ≤ α+1" 的任一判定都判定 LPO; 结论是软比较的松弛只能放在表示的精度 (深度, 阶段) 上, 不能放在值上.

**最便宜的实验 (判断).** 把上面的纸面论证编译成配对否定 `softslack→LPO` (几十行, 只用 ℕ-极限的玩具树; 放进 E4); 正面: 对只含 ℕ-分支的码编译 "深度 n 的三值比较", 检查只是到深度 n 一致时保留能否执行. ℕ∞ 与它的全知性在 `--safe --without-K` 下写出 (一两百行, TypeTopology 有现成证明可对照), 只在 E2 查出某个字面相等型的 P 只依赖离散影子之后做 (实验 E11).

**与已编译否定的张力.** 壁垒定理与上面的纸面论证都说软比较不能落在值上. `sep→wdec` 要逐条核 "精度 n 的回退" 是否就是它的 "可观察回退". 树本身不离散, 只有影子可判定; Ω-分支的下标是全体低层树, 不紧; 若有人用紧序数导出层号的三歧, 立即对照 `¬tri`.

## 第七族: 三张诊断表与三个领域共同的否定结论

### 7.1 半连续性检查表: 先判断一条陈述能否传到极限

**原领域 (文献).** Abel: 对从序数到格的 f 与极限 λ, lim inf 与 lim sup 有显式定义; 上半连续指 lim sup f ⊑ f(λ); 按序数尺寸索引的类型在极限处上半连续时递归可靠; Prop. 6: A 下半连续且 B 上半连续推出 A→B 上半连续, 单调函数上半连续, 反单调函数下半连续; ∀ 保持上半连续 (Lemma 7); 反例 A(ı) = (Nat^ω → Nat^ı) → Nat^ω 通过 α = 0 检查但不上半连续, 可写出不终止的循环 【原文, 前半】([LMCS 2008](https://lmcs.episciences.org/1236)).

**对着的难点与路 (判断).** 难点二、三 (哪些陈述能从各项传到极限); 供给【逐层封闭】(极限层号处的行).

**我方草图 (判断, X2-5, X4-#4).** 命题格上的特化 (推导, 不是引文): lim inf_n P(n) 读作 "从某项起恒成立", lim sup_n P(n) 读作 "无穷多项成立". 结论要写成本身上半连续的 `∀ n → Σ m (Ref (f n) ≼ fold c (f m))`; 前提 (下标合法, 有公共上界) 要下半连续. X2 判断 Abel 的反例对应一类引理: 前提对低层的一切树量化, 结论只说当前站, 当前站变量出现在前提的反变位置. X4 的用法: 把 "合法性 (或读回域) 对层号上半连续" 写成接口的一条律, 若读回域满足它, 极限层号上逐项极限不需要部分和就合法.

**最便宜的实验 (判断).** 纸面: 把近期失败引理的前提与结论逐个标成单调、反单调、上半连续、下半连续, 看反例是否都出在 "前提不下半连续" 的位置 (放进 E2). 编译: 对当前合法性谓词在塔的读回域上陈述那条律, 先证层号 ω 一处; 证不出就抽反例, X4 预计反例是常值层号一类 (与 `const-inflates` 同位置) (实验 E8).

**与已编译否定的张力.** 与已有否定无直接冲突. 内建 sized types 不能与 `--safe` 同用 (已核实), 只借检查表, 尺寸用树自身的下标表示; 尺寸若作为有三歧的下标类型就触壁垒; 按最佳实践, 这条律在全合法域上多半不成立 (`side-lim-illegal`), 只在读回域上可能成立.

### 7.2 up-to 技术的健全性

**原领域 (文献).** Pous 给任意单调函数配一个 companion, 统一 up-to 增强与参数化余归纳 【摘要】([LICS 2016](https://lics.siglog.org/2016/Pous-CoinductionAlltheWa.html)); Danielsson 把许多 up-to 技术写成 sized types 下的保尺寸函数, 代码是 Agda 【摘要】([POPL 2018](https://www.cse.chalmers.se/~nad/publications/danielsson-up-to-using-sized-types.html)); Sangiorgi 与 Milner: bisimulation up to 在强情形可用, 在弱情形要改用 up to expansion 【未标】([CONCUR 1992](https://www.research.ed.ac.uk/en/publications/the-problem-of-weak-bisimulation-up-to/)).

**对着的难点与路 (判断).** 难点二、三; 给第一族的度量式证明定一条禁令.

**我方草图 (判断, X2-11, X3-O).** 正面 (X2): 被否定的逐步引理可能在 "up to ≼ 传递 + 序列重排 + 折叠上下文" 下成立, 改证 `Ref x ≼ cl (fold c x)`, 用显式尺寸 `_≼[ i ]_`. 禁令 (X3): 采用 1.2 或 1.3 的度量或预算后, 不随意加 "up to ≼" 规则, 前后复合 ≼ 可能重置度量, 与 "弱互模拟 up to 弱互模拟" 不健全同形; 只 up to 一个从不滞后的结构关系 (字面路径, 或 Buchholz 的 ≪_k 一类), 或只在度量之外复合 ≼. 纯归纳的 ≼ 证明里传递性始终健全.

**最便宜的实验 (判断).** 加任何 up-to 规则之前, 先在简化模型里找一个使度量无限重置的反例; 找不到再写健全性证明.

**与已编译否定的张力.** 无直接冲突; X2 未核 "归纳关系的 up-to" 与余归纳版本是否对称.

### 7.3 弱单调代数, 参数过滤与自然和

**原领域 (文献).** 弱单调代数要求解释只对非严格序单调, 允许多项式解释取 0 系数 【摘要】([Endrullis–Waldmann–Zantema, JAR 2008](https://portal.mardi4nfdi.de/wiki/Publication:928655)); μ-monotone algebra 只在可用参数位置上要求严格单调 【原文】([Hirokawa–Moser, arXiv:1102.3129](https://ar5iv.arxiv.org/html/1102.3129)); 新的序数解释实现自动证明了 Goodstein 序列改写系统的终止, 据摘要文中用自然加法 【摘要】([Winkler–Zankl–Middeldorp, RTA 2013](https://drops.dagstuhl.de/entities/document/10.4230/LIPIcs.RTA.2013.335)); Cichon 1991 问 Hydra 系统的终止序是否必须以 Howard 序数为序型, Moser 2009 给了否定回答 【摘要】([RTALooP Problem 23](https://www.cs.tau.ac.il/~nachum/rtaloop/problems/23.html)).

**对着的难点与路 (判断).** 难点二 (意图值沿每条规则单调; 局部落后可能只是左加法不严格).

**我方草图 (判断, X2-6).** 只要下界, 只需弱定向 `V (左) ≼ V (右)`. 参数过滤: V 不看的字段就不是值所需要的, 这把翻译账里 "新增脚手架是序数值需要的, 还是翻译带来的" 变成可检查的问题. 自然和: 若落后来自 α + β 中 α 变动, 在意图值一侧改用 α ⊕ β, 另证 α + β ≼ α ⊕ β; 候选写法 `lim f ⊕ lim g = lim (交错 (λ n → f n ⊕ lim g) (λ n → lim f ⊕ g n))` (`lim (λ n → f n ⊕ g n)` 是错的, 它把 ω ⊕ ω 算成 ω). **两份笔记在这里不一致**: X2-6 判断这个两参数同时递归的定义过得了调用矩阵检查; X3-N 判断布劳威尔树上的 Hessenberg 和一般需要 Cantor 范式与比较, 构造性下不可用. 两者都是判断, 一个几十行的检验即可分开.

**最便宜的实验 (判断).** 纸面 "规则 × 参数位置" 单调表, 标出现有意图值在哪个位置不单调 (放进 E2); 若不单调全出在左加法, 再做几十行的 ⊕ 检验: 停机检查是否通过, ω ⊕ ω ≽ ω·2 是否可证, 交换律在 ≼ 意义下是否成立 (实验 E11).

**与已编译否定的张力.** 交错出的 ℕ-序列不单调, 若 ⊕ 进树就可能违反 ℕ-极限的合法性; 只用在意图值 (证明一侧) 时这条约束可能不适用, 须核. Ω 层要把 Ω-族与 ℕ-族并起来. 与旧调查里 Aczel–Danner 的 hereditarily inflationary 泛函相邻.

### 7.4 三个领域共同的否定结论: 对全体自生层的一致消去

Dybjer 与 Setzer 记载 Palmgren 发现给 Mahlo 宇宙加自然的消去规则导致矛盾, 外部 Mahlo 宇宙的做法是不对 "全体层" 给消去 【原文】([2025](https://csetzer.github.io/articles/dybjerSetzerWeylVolume2025/dybjerSetzerWeylVolume2025Final.pdf)); 二层类型论对每个外部固定的 k 构造 S_k, 没有内部函数一次覆盖所有层 【摘要】([arXiv:1705.03307](https://arxiv.org/abs/1705.03307)); 仓库的壁垒定理与跨层单调的配对否定是第三处 (编译定理). X4 把三者列为同一类事实. 本报告推断它对设计的含义: 对层一致的定理只能写成对给定层号构造的递归 (4.1 的 Step 加 ⊏ 上的打结, 3.3 的 "只在自己的像上要求"), 不能写成在 "全体层号" 这个类型上消去的函数; 这为第四族的形状提供了反面的依据.

## 结论

六个领域在替代 "比较" 时用的都是随构造带着走的一项数据: 秩, 索引, 预算的字面孩子, 祖先指针, 证据 `l<`, 记录下来的约束; 四份笔记各自独立地要求这项数据是字面的, 不能由值的比较推出. 仓库已有的 "律带公共上界" 与 `locate→irr-search` 是这条要求在本项目里已编译的实例; 本调查新给出的是这项数据的两种具体用途, 一是作模拟关系的索引, 记下滞后, 二是作层号的来源, 承担派发. 前者不改定义, 后者要改定义.

经典许可把问题分成了两部分. 判定那一部分在验收侧的成本降到一个 LEM 神谕: 按 X1 的读法, 修正参照折叠与现行折叠是同一定义的两个实例, 以 LPO 或可判定性为结论的否定不再约束这一步. 剩下的构造性内容集中在一个问题上: 滞后能否从树的字面结构读出. E1 回答它. 若能读出, "Step 加度量" 形式的阶段无关构造下界就有了具体的陈述; 若不能, 【滞后模拟】只能走带 LEM 的条件路线, 它支持值验收, 不说明树自足. 会改变本报告排序的三件事: E1 显示滞后不能从字面结构读出; E3 显示推迟规则必须按低、同、高分类 (定义侧因此落入 `obs→dec`, 验收侧在 LEM 下不受影响); E6 显示祖先指针在 Ω-分支各支之间不一致 (落入 `top-branch→lpo`).
