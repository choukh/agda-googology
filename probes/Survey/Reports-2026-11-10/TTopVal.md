## 回报原文

#### 1. 对纲领与目标意味着什么

值的前沿没有动，仍是 ψ₀(Ω_{Ω·ω²})（`EmbVVInstO2.vv-ω²`）。这次把"`T⊤` 读作 ψ₀(Ω_{Ω²})"这件事，变成了一个**编译过的充要条件**，并且已经检查过它的第 0 项。另有一条编译事实：现有的标签工具（`vv-row` 一族）够不到第 n≥1 项。所以下一步要写新的脚手架，不能靠实例化现有工具。止损已触发，交的是第 3 种。

ψ₀(Ω_{Ω²}) 的带标签参照树以前不存在（`TLOneAccept` 写的是"在这一站没有参照物"），现在有了，是编译过的定理。这件事只关于记号侧和验收，不涉及树侧，也不算"树自足"。

#### 2. 交付：第 3 种，编译过的约化

**参照树**（定理，无条件，读记号）
- `TTopValRef.Y⊤-lab : Lab Y⊤ tψΩ`。`Y⊤ = lim Z⊤` 带 ψ₀(Ω_{ψ₁(Ω)}) = ψ₀(Ω_{Ω²}) 的标签，用的是 `VV` 本身的那个 `Lab`（`OrdLabZCorrespond`）。
- 做法：取 `EboLeanLab.lab-NF′`（一切可数标准形都有标签），逐个构造子搬到 `OCF.Free.Level`。标准形的证明 `nf⊤` 是手写的。`fsn≡` 逐字取自 `EboLeanCmp`（那个模块导入归档，不能直接导入）。树放在 `opaque` 里。
- 另附 `Lab-uniq`：同一标签的两棵树互相 ≅。

**约化**（定理，无条件）
- `TTopVal.vv-T⊤-if : Up → Low → VV T⊤ tψΩ`，以及反向的 `vv-T⊤-only-if : VV T⊤ tψΩ → Up × Low`。
  - `Up`：对一切 n，`T⊤` 的第 n 个分支（码 `C 𝒯 ωᶜ n` 的顶行）≼ `Y⊤`。
  - `Low`：对一切 n，参照树第 n 项 `Z⊤ n` ≼ `T⊤`。
- 这个条件 P = `Up × Low` 与结论**等价**，所以已经不能再小。反向用了 `Lab-uniq`：参照树换成任何同标签的树，结论不变。
- 只看下界也一样：`low-if` 与 `low-only-if` 给出 `Low ⇔ Y⊤ ≼ T⊤`。

**P 的非平凡实例**（定理）
- `e₀`：`T⊤` 的第 0 个分支与 `Z⊤ 0` 互相 ≅。两者同标签 ψ₀(Ω_{ψ₁(1)}) = ψ₀(Ω_{Ω·ω})，分支一侧的标签来自 `OrdLabAccept.ord-∞`。
- 于是 `up₀` 与 `low₀` 成立，即 P 在 n=0 处两个方向都满足。

**够不到第 n≥1 项**（定理，无条件，读记号，不否定路线）
- `TTopValReach.reachᴱ` 与 `reachᴸ`：两版 `NF₁` 里，ψ₀(Ω_{ψ₁(a)+…}) 只允许 a ∈ {0, 1}。`EmbVVLZStandardOmega` 那一版是 `vv-row` 的前提；`LadderLabZStandardOmega` 那一版是 `label-tree` 与 `ord-*` 的前提。
- `no-NF-brᴱ` 与 `no-NF-brᴸ`：参照树第 n+1 项 ψ₀(Ω_{ψ₁(γ_{n+1})}) 在两版里都不是 `NF₁`。
- 这只说明 `vv-row` 一族的前提给不出这些项。它不否定这些项能通过序数值验收，也不否定其它办法。

#### 4. 未完成项与止损

**止损已触发。** 要证 n≥1 处的 `Up`/`Low`，需要两条新引理，都不是现有工具的实例：
- **(i) 新的 `Sb`/`NF₁` 族。** 要容纳 ψ₁(a)（a ≥ 2，且 a 含 Ω-可见参数时真正用到 `Bnd₁`），并配上对应的标签世界克隆。按 `reach` 的结论，现有两版都没有。
- **(ii) 链码 `C 𝒯 ωᶜ n` 上一般的"码的读法"。** 即对一切链码给出 `PxB`，包括 ⌈·⌉ 带来的放大。现在的 `PxB` 是逐码手写的（`ω²ᶜ` 一个码就有 364 行）。

**规模（估计）：** 5 千到 1.5 万行。参照：`EmbVV` 从 ψ₁(1)·k 推到 ψ₁(2) 用了手写 1505 行，加上机械克隆 5989 行，而且仍然不能处理一般的 ψ₁(a)；这类估计历史上偏低 3 到 5 倍。

**为什么没用到 `V-≃`（判断）：** `V-≃` 处理同一个码内、层号不同（只同值）的两行。`T⊤` 卡住的地方是每个链码各自的读数，这时 `V-≃` 不是瓶颈。

**另一个可选办法（判断，未试）：** 只要粗界（单向的 `Le`/`PEmb` 式比较），也同样需要 (ii) 的单调版。

**未走通、不是否定：** `T⊤` 读作 ψ₀(Ω_{Ω²}) 仍是判断，现在等价于 n≥1 处的 `Up × Low`。
