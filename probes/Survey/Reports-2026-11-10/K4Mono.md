#### 3 关系, 定理, 档位

**关系 (白话).** 零, 后继, ℕ-极限 (按上确界), 提升 (透明) 的规则同 `Value._≼_`, 另加 "右边多一个后继" (`≤s`). Ω-结点只有两条:

- `i≤` (逐点): 两个结点的分支层 `≅ᴵ` 相关, 且输入相关则分支相关.
- `≤i`: 左边在右结点的**全部**分支之下.

值序的 `≼i` (在某一支之下) 与 `i≼` 不在定义里. 关系带参数 `M : Set`; `i≤` 另有一个字段, 在 `M` 之下左结点的分支对关系单调.

- `Legal` / `L` (`M = ⊤`): $a\sqsubseteq b$ 蕴含 $a\sqsubseteq a$, 关系传递.
- `Wide` / `W` (`M = ⊥`): 没有合法性要求.

两个版本共用一套证明. "合法" 指 $a\sqsubseteq a$.

**正面定理 (都已编译).**

- 折叠保持, 陈述与 `ψ-≅` 同形, `M` 任意, 无合法性前提: `Fold.ψ-⊑ : i ≅ᴵ i′ → a ⊑ᵖ b → ψ p σ a ⊑ᵖ ψ p′ σ′ b`. 同时有 `ψ⁰-⊑`, `Ω-⊑`, `add-⊑`, 左加与右加不减 (`⊑-addˡ`, `⊑-addʳ`).
- 规则 6 的两条链逐项相关: 起点 `Ω-⊑ e`, 每步是对分支的一次递归调用. 派发不一致仍由 `clash₁`, `clash₂` 排除. 没有哪一行要把 `⊑ᵖ` 换回 `≅`.
- 结构性质: `Rel.⊑ᵖ-reflˡ : M → a ⊑ᵖ b → a ⊑ᵖ a`; `Rel.⊑ᵖ-trans : M → a ⊑ᵖ b → b ⊑ᵖ c → a ⊑ᵖ c`, 一切层; `zero⊑` (零最小); `⊑ᵖ-refl⁰` (第 0 层都合法).
- 合法的树对 Ω, 后继, ℕ-极限, 提升, 加法, `ψ`, `ψ⁰` 封闭 (`Ω-legal`, `ψ-legal` 等).
- 第 0 层: `Val.⊑ᵖ→≼` 与 `≼→⊑ᵖ`, 关系就是值序.
- 推论: `ψ⁰-monoᵖ`; `ψ⁰-congᵖ : a ⊑ᵖ b → b ⊑ᵖ a → ψ⁰ a ≈ᵛ ψ⁰ b`.

**否定定理 (都已编译, 前提有实例).**
