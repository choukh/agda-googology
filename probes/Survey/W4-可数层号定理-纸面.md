# 可数层号上的一次性定理：纸面证明（2026-11-24，Fable 5.2）

第四层。**定理 LOWER 与 §6 的装配都已于 2026-11-25 编译：`tr₀ Ord-Ord.BTBO ≼ read EBOᶜ` 无前提（见 §7 末尾的进度）。** 以下 §1 到 §5 是编译前的纸面设计，留作记录，与编译结果的出入记在 §7 末尾。对象是现行 W4；不改前三层。目标是把 "W4 在只有后继与 ℕ 极限形状的层号上不低于参照" 证成一条对一切这类层号成立的定理，取代逐站。每条引理标了核对程度：**定义性**（由定义的子句直接读出）、**已核**（对着源码逐行核过陈述）、**未核**（只有论证的形状）。入口见[审计报告](W4-EBO-独立审计-Fable52.md) §5、§8.4。

## 0. 陈述

参照取仓库的 Level 系统（[Level](../OCF/Align/Level.lagda.md)：层号码 `Ordᴵ`，树 `Ordᶜ`，折叠 `ψ`、`ψ⁰`）。它是纯树上的四行折叠，前缀写在树里，没有底参数，没有挂起的乘幂。

称 W4 的层号 m 为 ℕ-层号，如果它由 `zero`、`sS`、`sL` 生成并带 `Ok`。塔第 1 项里出现的层号都是这种。

**定理 LOWER（镜像下界）。** 设 m 是 ℕ-层号，k 是 Level 的层号码，k 与 m 镜像（§1）。设运行的底族逐条目不低于标准的 `Ωt`（即 `B12ActualSlots.Covered`），底 β 不低于 1，w 是任一条 `zero ≤ m` 的路径。则

    L.ψ⁰ (L.Ω k)  ≼  read (ψ m o B zero w β (Ωt m))

**推论（判断，§6）。** 加上 Level 侧已编译的 `Ψ-emb`（层号码之间的前驱嵌入给出 ψ⁰∘Ω 的 `≼`），以及 W4 版的 "链点的规范化层号嵌进折叠值的字面前驱"（RR7 的第 3 段），得到 `tr₀ Ord-Ord.BTBO ≼ read EBOᶜ`，连同 ψ₀(Ω_n)、ψ₀(Ω_ω) 的相应陈述。

不声称：任何 Ω 形层号上的结论；上界；同值。

## 1. 镜像（层号的对应）

- `code : ℕ-层号 → Ordᴵ`：`zero ↦ zero`，`nd sS h ↦ suc (code (h tt))`，`nd sL g ↦ lim (code ∘ g) (…)`，极限的相邻证据由 `Ok` 的路径给出。k 与 m 镜像指 k ≅ᴵ code m。
- 槽位对证明：m 的槽位 p 给出 `code (at m p) <ᴵ code m`；路径 `j ≤ m` 给出 `code j ≺ᴵ code m` 或 `code j ≅ᴵ code m`。
- **引理 K（判定一致，已核）。** 在 ℕ-层号上，`kp m o p w` 给 `just` 当且仅当 `code (at m p) ≺ᴵ code j`。理由：`kp` 沿目标路径与槽位同时下降，给 `nothing` 的唯一子句是 `kp⁼ a o (inj₁ _) w`，此时槽位层就是 a 而目标在 a 之内，于是 `code j` 不高于 `code a`；Ω 形层号上那条无条件的 `nothing` 在 ℕ-层号上不出现；`sL` 行用 `way` 在两个孩子之间搬槽位，`pshBr` 是恒等，不改槽位层。Level 的 `<ᴵ-dec` 在 `≺ᴵ` 时保留，其余两种走链。所以两边同时保留或同时走链。框架里的 `kpT` 归到外层的 `kp`，同理（未核）。

## 2. Level 侧的乘幂（纯树上的恒等式）

- `𝔼 V X`（读作 V·ω^X，作为增量）：对 X 递归。`zero ↦ V`；`suc X ↦ lim (iter (𝔼 V X +_) zero)`；`lim f ↦ lim (𝔼 V ∘ f)`；`limᵢ q F ↦ limᵢ q (𝔼 V ∘ F)`；`up` 像 `add` 那样下降一层。它正是 Level 的折叠朝 "自身层" 给出的形状：`ψ zero σ (up zero X)` 逐构造子就是 `𝔼 (Ω _) X`，结点全部保留（定义性，差 `tr⁻` 的搬运）。
- 高阶：`Sh 0` = 增量（Level 的树），`Sh (n+1) = Sh n → Sh n`。`ℙⁿ X : Sh (n+1) → Sh n → Sh n`（把 k 从 g 起迭代 ω^X 次）：`zero ↦ k g`；`suc X ↦ limSⁿ (j ↦ (ℙⁿ X k)^j g)`；极限逐项；`limᵢ` 逐点，第 0 阶就是增量树里的一个 `limᵢ` 结点。
- 要用的恒等式，都只到 `≅`（未核，都是对指数树的直接归纳）：
  - 加法结合、零是左单位（`add` 上）。
  - `𝔼 V (A + Z) ≅ 𝔼⁺ (𝔼 V A) Z`（先 ω^A 再 ω^Z）。
  - `𝔼⁺ W (𝔼 B X) ≅ ℙ⁰ X (W′ ↦ 𝔼⁺ W′ B) W`（迭代 "乘 ω^B" 共 ω^X 次）。
  - 第 n 阶的同形两条（`ℙⁿ (A + Z)` 与 `ℙⁿ (𝔼 B X)`）。
- 依赖已编译的 `ψ-≅`（折叠尊重 `≅`，任意折叠证据）。

## 3. 关系

按 W4 层号 m 递归定义（结点分支的前提只用到严格更低的层，所以分层良定义）。

**树。** `D ⊴ t`，D 是 Level 的树，层号码与 t 所在的 W4 层号镜像。规则：

| 规则 | 形状 |
|---|---|
| z | `zero ⊴ t` |
| s | `D ⊴ t` 推出 `suc D ⊴ suc t` |
| l | 对一切 n 有 `f n ⊴ t`，推出 `lim f ⊴ t` |
| Ω | 结点层镜像，且对一切 `Y ⊴ c` 有 `F Y ⊴ g c`，推出 `limᵢ q F ⊴ Ω p g` |
| u | `D ⊴ t₀`，`Y ⊴ y`（孩子层），推出 `add D σ (up r Y) ⊴ up t₀ c y` |
| e | `D ⊴ u`，`V ⊴ v`，`X ⊴ x`，推出 `add D id (𝔼 V X) ⊴ ex u v x` |
| ≅ | `D ≅ D′`，`D′ ⊴ t`，推出 `D ⊴ t` |
| ◃ | `D ⊴ t`，`t ◃ t′`（W4 自己的步进序），推出 `D ⊴ t′` |

Level 一侧没有 "向下封闭" 的规则：Level 的折叠对一般的前驱包含不单调，这里也不需要（§4 的各处只用到 `≅` 与 W4 一侧的膨胀）。

- 第 0 层：`D ⊴ t` 推出 `D ≼ read t`（对规则归纳；`≅→≼` 与 `◃→≼` 已有）。
- 加法相容：`D₁ ⊴ t₁`，`D₂ ⊴ t₂` 推出 `D₁ + D₂ ⊴ t₁ + t₂`；左加膨胀：`D ⊴ b` 推出 `D ⊴ a + b`（未核）。

**状态。** 语境 X 上的状态 T 实现前缀 P，记 `P ⊴̂ T`：对一切 i 与 `t ∈ ⟦X⟧ i`，`ψ̂ᵢ P ⊴ T i t`。其中 `ψ̂ᵢ P` 是把 P 放进高一层再折到 `code i`（`ψ p (suc∘) P`），这样 i 等于 P 所在层时就是 `𝔼` 形的自身输出。

**算子。** `𝓡₀ (G, W)`：对一切 `P ⊴̂ T` 与 `ψ̂ᵢ P ⊴ β`，有 `ψ̂ᵢ (P + W) ⊴ run G T i t β`。`𝓡ₙ₊₁ (K, κ)`：对一切合规的延伸 m 与 `𝓡ₙ (G, g)`，有 `𝓡ₙ (K m G, κ g)`。形状照 B6A 的 `R n`，把那里取值在第 0 层函数里的影子换成 Level 的树与树上的函数。

## 4. 主引理

对 W4 的树 t 作结构归纳，三条互递归。前提一律是：`P ⊴̂ S`，`ψ̂ⱼ P ⊴ β`，状态各条目不低于标准 `Ωt`（走链的起点要用）。

**(B) 折叠保持。** `D ⊴ t` 推出 `ψ̂ⱼ (P + D) ⊴ ψ m o S j w β t`。逐规则：

- z：`ψ̂ⱼ P ⊴ β`，再用折叠的膨胀（`mono`，已有）。
- s：Level 是 `lim [0, Q, Q+Q, …]`，W4 是 `lim [Q′, Q′+Q′, …]`，逐项用加法相容。
- l：逐项。
- Ω：由引理 K 两边同判。保留时逐点。走链时 Level 的链从 `Ω j` 起，W4 的链从零起，对齐差一步：`γ₀ = Ω j ⊴ Ωt ⊴ S(at) ◃ z₁`，此后 `γₙ ⊴ zₙ₊₁` 由 (B) 在槽位层上给出；输出逐项进 W4 的累加和（左加膨胀）。
- u：先对 t₀ 用 (B) 得到孩子的状态实现 `P + D`，再对 y 在孩子层用 (B)。`sL` 行经 `way` 分两支；嵌入一支要一条 W4 内部的引理 "先 `emb` 再折，等于带着合成路径直接折"（未核，对路径归纳，左项为零时底族只是限制）。
- e：对 u 用 (B) 得状态，再对 x 用 (Op)。
- 目标就是本层（自身行）：W4 输出 `ex β β t`，Level 输出 `𝔼 U D` 形，直接是规则 e（左项取零）。
- ≅ 用 `ψ-≅`；◃ 用 `mono`。

**(Op) 一阶迭代。** `𝓡₀ (G, W)`，`X ⊴ x` 推出 `𝓡₀ (E o T x G, 𝔼⁺ W X)`，对一切语境与框架。逐规则照 (B)；`suc` 行是带状态更新的 ω 次迭代，两边的状态逐步保持 `⊴̂`；指数里的 `up` 进孩子框架（`chTD`、`enterO`），指数里的 `ex` 转到 (It) 的第 0 阶，用 §2 的第三条恒等式。

**(It) 高阶迭代。** `𝓡ₙ₊₁ (K, κ)`，`𝓡ₙ (G, g)`，`X ⊴ x` 推出 `𝓡ₙ (It n o T x K G, ℙⁿ X κ g)`，对一切 n 同一条证明。`limC`、`nodeC`、`upC`、`enter`、`Kb`、`Kₑ`、`Itᴺ` 各一条小引理，形状与 B6A 纸面 §2 的同名各行相同。

## 5. 顶层

- `L.Ω k ⊴ Ωt m`（k 与 m 镜像）：后继层两边都是结点，分支 `up zero Y` 对 `up zero tt (suc c)`，用规则 u 与 ◃；极限层 Level 逐项、W4 累加，用规则 u（左项取零）与 ◃。
- LOWER：取 P 为零，`Covered` 给出 `zero ⊴̂ B`，(B) 给出 `ψ̂₀ (zero + Ω k) ⊴ ψ m … (Ωt m)`，零是左单位，第 0 层的 `⊴` 推出 `≼`。Level 的 `ψ⁰` 与目标取零的 `ψ` 之间差一条 Level 内部的 `≅`（未核）。

## 6. 接到 BTBO（判断）

LOWER 给的是镜像层号上的界。B14 现有的归约 `Successors` 要的是 "前驱码 i 的值不高于 z" 时的界，码与层号不镜像，从值序造不出嵌入（`embV→LPO` 一族）。所以装配走 RR7 的四段：参照层号嵌进它的累加规范化，规范化层号之间由值序给嵌入，链点的规范化层号嵌进 W4 折叠值的字面前驱，平移；每段后用 `Ψ-emb` 取值，最后一步用 LOWER。第 3 段要 W4 版：极限层号上 W4 的顶是部分和（`limc⁺`），后继层号上折叠值结构严格升高，两条都是 W4 的形状事实（未核）。

## 8. 没有核的与可能失败的地方

- 规则 u、e 把 Level 一侧的形状固定成 `add … (up …)` 与 `add … (𝔼 …)`。Level 的折叠输出是否总能经 `≅` 写成这些形状，只核了自身行与 Ω 树两处。
- (Op) 的 `suc` 行里 Level 的迭代从零份起，W4 从一份起，靠膨胀对齐；高阶的同一处没有核。
- 引理 K 在框架里的形式（`kpT` 的外层目标一支）只读了定义，没有逐情形核。
- 真实运行的底族带回退行产生的可数尾巴（审计报告 §8.1 的 `βQ-shape` 是 Ω 形层号上的例子）。在 ℕ-层号上底族由 `sL` 行的前缀产生，是否仍满足 "不低于标准 `Ωt`"，现有的 `Covered` 已经给出；是否还要更多，没有核。
- §6 的装配整段是判断。
