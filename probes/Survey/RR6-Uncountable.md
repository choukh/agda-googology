#### 2 五个问题

##### 问题 1: 那条 LPO 定理到底否定了什么

**陈述** [定理, `YiOmNegBranch.TopBranch`, `top-branch→lpo`]. 记录有两个字段:
- `branch : (q : Pre K₂ω) (η : R) → .(Gd zero raw1 η) → Raw (lev K₂ω q)`;
- `branch-keep`: 坐标 `suc s` 的那一支与 q 路径相连 (`Link`), 且 `At (lev K₂ω q) (read0 s)` 时, 输出是 `Kept`.

**机制.**
- 陈述里有折叠的一行, 没有值.
- 被变动的是目标 q (`qα α`), 固定的是坐标 2 的那一支.
- 相连与 `At` 两个前提都只在 `Found α` 时成立. 函数的输入里没有这份证据, 输出的头与槽位却把它读了出来.
- 所以 "律只对相连的对要求" 挡不住: 相连与否本身就是那一位信息.

**与壁垒定理** [定理, `Barrier.barrier`, `Stages.lpo`]. 不是实例, 前提差四处:
1. 壁垒要一个带严格序的下标类型, 可数树精确嵌入, 有顶元, 有界三歧. `TopBranch` 里没有序类型; 关系是字面的位置 `At` (路径加层号树的字面相等).
2. 壁垒用三歧的三支与两处精确性. 这里只用保留律一条.
3. 壁垒固定 ω, 变动 ω⁺_α. 这里固定结点, 变动目标.
4. 原定理的探针 `dense α` 是 0/1 旗标的极限, 最终常值. 这一点不是本质: 我把探针换成严格递增的 (目标层 lim (n+1 或 ω+n+2), 结点层 ω), 同一个记录仍推出 LPO [临时试验 `R6Strict`, 退出码 0]. 所以它不能按 "谓词太宽 (常值极限)" 读掉.

同机制的旧定理: `Stage2.dec→WLPO`, `TreeLevelsO7.total-ψ→WLPO` (固定目标 ω+1, 严格探针, Level 框架), `YiRawNegOmega.dec-at→lpo`, `YiLvNegKeep.bare-way→lpo`. RR4 对 `total-ψ→WLPO` 的定性原样适用: 不覆盖带证据的部分折叠与只在生成域上满足方程的折叠.

**否定的范围.**
- 否定的: (甲) 里 "目标是 `Pre (tw 2)` 的任意位置, 分支域是下界 1 之上的一切 η, 守卫不带路径数据" 这一个函数类型上的完全保留.
- 没有否定的, 三条:
  1. 目标限于 `At` 可判定的层 [定理 `at-one-dec`: 目标层 1]. 单个闭目标上只有条件定理 `fixed→wlpo` (前提 `FunextR`); 它的目标层 `suc (lim (λ _ → suc zero))` 是常值极限, 不在规范域内.
  2. 分支域取目标所在一支的坐标之上的尾部, 守卫相关. 这时保留律与折叠律都有不要神谕的模型 [临时试验 `R6Tail.tail-model`, 退出码 0; 它是 `oracle-branch` 的对照物, 只是模型, 不是折叠].
  3. 相对坐标的行 [定理 `YiOmFoldRel.rel-compare`, `rowᴿ-kept`].
- LPO 的位置: `R6Strict` 的探针在 `Found α` 时, 固定的那一支 (坐标 ω+1) 在目标坐标之下. 尾部域里没有这样的支.
- 对 (乙): 无话. `Plain` 层号上没有以 `Pre (tw 2)` 为目标的函数.
- 对 (丙): 只说任何实际的折叠在那个函数类型上必不完全. 对值无话.

##### 问题 2: 三种写法各自的第一个障碍

**(甲) 派发处处完全.**

**(乙) 对角的 ℕ 极限.** 在这个块里有两种读法.

  - 第一个障碍是值, 不是写法. 它按构造对应 Stage2 §4 的朴素树 `NO` [判断]; 那里的定理 `naiveO-unlabel` 说基本列与记号不一致, 不是值定理. 它的值高于还是低于 ψ₀(Ω_{Ω+1}) 的参照, 我的纸面分析两个方向都定不下来, 标未定.

##### 问题 4: 被漏掉的写法, 被过早放下的路

1. **受支配的域 / 嵌套支配** (Symbolic 的 `ŝ c t₀ g` 与 `Mlev c η e`). 它是交替路线对 D1 的原解, 被三分法拆散到三种写法里. 仓库里与它直接相关的还有 `InaccTree.dir-L₁`, `¬WF-L₁` [定理]: 任意两棵可数树的字面公共上界存在但不步进. 所以支配只能在构造时沿链给出 (坐标写成 c +ʳ δ), 不能事后取并.
2. **固定对角的零成本基线** (`R6Diag`). GoalOdds 的步骤表里没有这条路.
3. **目标域的限制.** 折叠实际问到的目标是它自己造的保留结点的槽位, 坐标是归一的 (`YiOmFoldNorm.nrm`, `γ`, `nrm-legal`: 守卫与合法性由树算出). "归一目标上 `At` 是否可判定" 没有人陈述过; `at-one-dec` 是唯一的实例.
4. **变体乙** (ℕ 极限自带路径) 是作者没有选, 不是被否定. 它的代价 "同一序列两份路径给出两棵树", BTBO 的 `Ordᴰ` 本来就有, 而且在用. `R6Strict` 说明它消不掉这条 LPO. 相对坐标在现在的块里已给出同样的数据. 所以它目前不是必需的 [判断].
5. **变体甲** "不解决" 的理由是位置上拿不到 `Legal`. 但坐标取归一的相对坐标时, 合法性可算 (`nrm-legal`, `lᵟ`), 那条理由不适用 [判断, 没有在变体甲上编译].

##### 问题 5: 建议 (都是判断)

**先试哪一种.** 先试 "受支配的域", 即 (甲) 的修正版, 等于交替路线的原解, 等于尾部行; 不改块. 理由:
- 唯一的编译障碍住在目标坐标之下 (`R6Strict`, `R6Tail`);
- 行已在现块里编译 (`rowᴿ`);
- 有历史先例 (Symbolic);
- 下界引理的形状不受下界影响.

验收目标从 "派发处处完全" 改成 "在每个保留结点自己的 (受支配的) 分支域上完全", 外加对参照的下界. 同时把 `T⁺ᵈ` 记作基线并给它量值. 主干行式的 (丙) 放最后.

**最便宜的决定性实验.** "链上位置对是否都相连" 已由 `YiGen*` 在跑, 不重复. 我建议补一条值上的对比: 在唯一一个完全行写得出的非平凡目标 (目标层 1, `at-one-dec`) 上, 比较 top 的完全行与尾部行折到第 0 层后的值.

```agda
rowᶠ rowᵗ : Raw (suc zero)      -- top (= tw 3) 在目标 1 的两条行: 完全的; 下界抬到 3 的
obs : Raw (suc zero) → R        -- Φᵐ (suc zero) tt tt base
tail-no-loss : read (obs rowᶠ) ≼ read (obs rowᵗ)
tail-no-gain : read (obs rowᵗ) ≼ read (obs rowᶠ)   -- 或一条编译的严格反例
```

- 成立: 尾部与完全同值, "派发处处完全" 不是值所需.
- 给出反例: 尾部在第一个实例上就改值, 相对坐标与 (丙) 都要重估.
- 更便宜的确认项 (预计只换 `base` 一个前提): `∀ c′ … → L.ψ⁰ (L.Ω ⟨ 3 ⟩) ≼ read (T₃ 的根链从 c′ 起的版本)`.
