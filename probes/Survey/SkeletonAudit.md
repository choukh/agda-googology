## 0 结论先行

### 0.1 一句话

骨架 (FamFold → LvRd → LvTop → LvKt → KcFold → DnFold → GenFold) 的八个无条件闭项**全部**是 `T⁺ h lh` 且 `h : Ht` (**[实验]** `fac-TG`, `fac-TD`, `fac-Tkc`, `fac-Tkt`, `fac-Ttr`, `fac-T∞ω1`, `fac-T∞`, `fac-TΩ`, 都是 `refl`). `Ht = HB (step S₀)` 是一个固定类型, 它的两个种类的坐标只有 `A` 与 `H₀` (**[定理]** `KcFoldTower.ht-coords`). 所以无论层号塔在 `Kc s` 里爬多高, 闭项的读法都被 `sup_{h : Ht} T⁺ h` 封住. 这一处封顶 `GenFold` 入口已经指出 (它写 "ψ₀(Ω_{Ω_{ω+1}}) 量级, 粗界"); 本审的新内容是:

1. **封顶比入口写的更低 [判断].** `Ht` 的树只有 ℕ-极限, `A`-极限 (共尾 Ω), `H₀`-极限 (共尾 Ω₂) 三种分支, 作为下标读 < Ω₃; `T⁺ h` 读 ψ₀(Ω_{|h|}); 所以八个闭项的公共上界是 **ψ₀(Ω_{Ω₃})** 量级, 不是入口写的 ψ₀(Ω_{Ω_ω}) (`T∞F`, `Tkt∞`) 或 ψ₀(Ω_{Ω_{ω+1}}) (`Ttr`, `Tkt`, `Tkc`, `TD`, `TG`). 那些读法依赖 `LvKt` 入口写明的规则 (R2) "`|h|` 是 `h` 作为下标的读法, 不是 `Ht` 里的树形序数"; 但 `T⁺` 只消费 `h` 的树形 (`fac-*` 说闭项字面就是 `T⁺ h`), (R2) 在 `T⁺` 的定义里没有机制. 见 §1.3.
2. **封顶不止一处, 共七类** (§1.2 表): 层号的类型 (`LvTop`), 世界的槽类型由码的形状写死 (`LvRd`), 下降的值域 (`DnK`, `EvSys.evH` 都是 `→ Ht`), 求值的世界是基世界 (`W₀X`, `w0`, `w₀K`; `only-botLev`, `code-botK`), 读回的有损行 (`nc-old-drop`, `encH-bot`, `toD₁`, `cast`, `decH`), 极限层号处级顶只走底支 (`top-bot`), 极限站与 ℕ-极限层号处的下降是常数 (`dnG-hl-const`, `TG-lim-const`). 前三类是**类型**封顶 (定理级事实), 后四类是**内容**封顶 (定义相等, 读法是判断).
3. **类型条件今天就能同时满足 [实验].** 一般折叠 `GenFoldRun.Run` 求到第 0 层, 用 `GenFoldTree.Tree.sum` 直接读成 `A`, 不经 `rd₂` 与 `T⁺`: `SkelDxGen.Gen0.ev₀`, 每站闭项 `TXs s = TX (XG s)` (最终坍缩在 `step (Lev X_s)` 上, 随站换类型), 极限站 `TXΛ = TX ΛB` (坍缩在 `step (Lev ΛB)` 上, `Lev ΛB = sup ℕ (Lev ∘ Bᴧ)`), 都合法, 都有 FGH, 不要新接口. 这解决的是 §2 的 C1, C2, C3, C8; **值的条件 C6 (每站折叠的世界不是基世界, 回灌升得动坐标为下标的种类的界) 没有解决**, 它就是 `StallDiagnosis` 的 W 墙与拷贝墙, 不是类型问题.
4. **方法 [判断]:** 七个模块一天叠成, 每个入口都如实写了 "不是 ψ₀Λ" 与下一个障碍, 但下一路把上一路**接口里的类型决定** (`Dn T = … → Ht`, `EvSys.evH : → Ht`, 最终坍缩 `T⁺`, 站的世界 `w0`, 读回 `top`) 当作定稿只增不改, 所以每一处封顶都是上游接口里早已写下的类型. 这与 `StallDiagnosis §4` "换律的形状不换律的定义域" 是同一种模式, 这回换的是 "每站多做一步", 不换 "最后一步的类型". 应当从最终坍缩的类型倒着设计 (§4).

### 0.2 对纲领与目标意味着什么

- 纲领 1–3 在骨架里都守住了: 闭项是 `A` 的元素, 无公理, 判定只有码 (数据) 与公共上界之下的 `cmpB`/`bdec`. 本审没有发现触壁垒的地方.
- 目标 "让树自足" 的判据之一 "闭包定理与阶段无关" 在类型层已做到 (`Kc`, `nxt`, `Lev`, `GenFold` 对一切种类结构一条); 但**最终坍缩**还停在两种种类的 `T⁺` 上, 等于塔的每一站都要先翻译回第 1 站的语言 (`Ht`) 再折叠. 自足的标志应当是: 坍缩对一切种类结构一条, 不经任何固定类型. **[实验]** 说明这一步在类型上已经有了 (`Gen0`), 缺的是世界与回灌.
- 翻译账: 本审不读记号; 实验 `SkelDxGen` 新用到的字段只有 `GenFoldRun.τ₀` (第 0 层目标) 与 `Tree.sum` (第 0 层读成 `A`), 都是树侧已有的; 没有新增脚手架 (反而绕开了 `Sk`/`Cvt`/`rd₂`).

### 1.3 为什么 `Ht` 的封顶是 ψ₀(Ω_{Ω₃}) 量级 [判断]

- `A` 只有 `azero`, `asuc`, `alim` (ℕ-极限): 读 < Ω. `H₀ = HB S₀`: Ω-分支的坐标是 `A`, 共尾 Ω, 读 < Ω₂. `Ht = HB S₁`: 新加的 Ω-分支坐标是 `H₀`, 共尾 Ω₂, 读 < Ω₃ (`ht-coords` [定理]: 没有别的坐标类型). 这是树形的遗传共尾界.
- `T⁺ h` 把 `h` 当层: κA 结点折成 `nκ` (对 `A` 坐标的闭包), κH 结点折成 `nμ` (对更大世界的 `H₀` 界的闭包), ℕ-极限折成 `nl`. 值的读法 ψ₀(Ω_{|h|}) 是 `HtTowerF` 入口自己的 (它由此读 `T-Ω₂²` 为 ψ₀(Ω_{Ω₂²})). 上确界 ψ₀(Ω_{Ω₃}).
- (R2) 要 `Hn n`, `Hs s` 这些 `Ht` 元素读成 Ω_{n+2}, Ω_{|B_s|}: 这只有在 `T⁺` 的值依赖 `h` 的来历 (它是哪一级的级顶降下来的) 时才成立, 而 `fac-*` 说闭项字面是 `T⁺ h`, `T⁺` 对 `h` 结构递归, 只看树形. 回灌链 `hl (n ↦ a_n)` 的每项 `a_n : Ht` 读 < Ω₃, ℕ 个的上确界 < Ω₃. ψ₀(Ω_Ω) 那一站 "ℕ-极限的回灌读出下一个 Ω" 的机制在这里不适用: 那里的下标 `hl a` 读的是可数的 ψ₀(Ω_Ω) 本身 (不动点), 不是 Ω; 要到 ψ₀(Ω_{Ω₄}) 必须有共尾 Ω₃ 的下标, 即对 `Ht` 大小的坐标分支, `Ht` 自己没有.
- 编译过的旁证: `NegDnFoldRet.no-faithful`, `no-faithfulB` [定理]: 级里有坐标为 `Ht` 的种类时, 到 `Ht` 的下降没有左逆. 它不量化损失, 但说明 "下降保值" 没有定理依据.
- 这一条若错, 错在 `T⁺` 的语义; 要定夺只能靠第 4 层 (序数值) 的定理, 现在一个也没有 (`FstMono T⁺` 仍是条件). **建议第 4 层先做这一件**: 给 `sup_{h:Ht} T⁺ h` 一个粗上界 (哪怕只对不含 κH 的 `h`), 因为骨架里一切闭项的读法都压在它上面.

## 4 方法诊断

**是在重复 "每次只修一处、下一处再撞" [判断].** 对照 `StallDiagnosis §4`:

1. **同一假设上换写法.** 七个模块 (FamFold 11:20 → LvRd 14:28 → LvTop → LvKt 15:21 → KcFold 15:44 → DnFold 16:13 → GenFold 16:59, 按接口定稿时刻) 每个换的是 "每站多做一步" (级数 → ω+1 级 → 整座塔 → 换类型 → 读回 → 下降 → 一般折叠), 不换的是 "最后一步": `T⁺ : Ht → A`. `Dn T = … → Ht` 在 `LvRdIf` 里为第 ω 级写下 (那时 `Ht` 够用), 被 `KcFoldIf.DnK`, `DnFoldIf.EvSys.evH`, `GenFoldIf.EvGenTy` 原样继承; "接口定稿后只增不改" 把它锁死. 每个入口都正确地写了 "不是 ψ₀Λ" 与下一个障碍, 但下一个障碍总是**这个类型决定的下游**.
2. **读法规则掩盖了封顶.** (R2) 让 `Ht` 里的元素按来历读 (`Hn n` 读 Ω_{n+2}), 于是 `T∞F` 读 ψ₀(Ω_{Ω_ω}), `Ttr` 读 ψ₀(Ω_{Ω_{ω+1}}), `Ht` 看起来不是上限; 直到 `GenFold` 把每站输出都压进 `Ht`, 封顶才显形. 若一开始就问 "`sup_{h:Ht} T⁺ h` 读多少", `LvRd` 那一站就会停下来换最终坍缩.
3. **否定一路对准了接口, 没有对准类型链.** 五路配对否定 (`NegLvRd` … `NegGenFold`) 都如实报 "接口未被否定", 并交出了有用的东西 (`bdecTower`, `upd₁-sep`, 盲定理); 但没有一路问 "接口里 `→ Ht` 这个值域封在哪里". 盲定理 (手册 §3.7) 拦住了 "读回进了闭项" 的律, 没拦住 "闭项的类型本身封顶".
4. **做得对的.** 每个入口的 "第一个障碍" 与 "读法 (判断)" 分档清楚; `Hs-trunc`, `HsSS`, `not-dnC` 这类 `refl` 定理让本审能只看陈述就定位; 翻译账记了 `Cvt`, `Sk` 是脚手架. 这些纪律是本审能在半天内列全封顶点的原因.

**应当怎样一次设计到位 [判断].**

- **从最终坍缩倒着写类型链**: 先定 `A ← collapse_T (L : HB (step T)) (W : Wd (step T)) ← T = Lev X_s ← X_s : HB (Kc s)`, 每一环的类型随 `s` 变; 任何 `→ Ht`, `→ HB S₀`, `→ Sk n` 的值域都要在接口头写明 "它把读法封在 ψ₀(Ω_?)", 没有写明的不得定稿.
- **接口定稿前过一张封顶清单** (本文 §1.2 的七类): 层号类型, 槽类型, 下降/求值值域, 坍缩与对角所在类型, 站的世界, 读回的有损行, 极限处的底支/常数. 每条要么 "不适用", 要么写出上界.
- **否定一路加一项义务**: 对接口里每个固定类型的值域写一条 "封顶" 定理 (像 `ht-coords` 那样的类型事实), 与盲定理并列.
- **先交字面的闭项再爬**: `SkelDxGen.TXΛ` 这种 "类型上对了, 值上没内容" 的闭项应当在 `KcFold` 那一站就交出来, 然后集中力量只攻 C6.

## 5 对新塔 (`NewTwr`) 接口的建议

只增修改的建议, 按优先级:

1. **最终坍缩的字段**: `collapse : ∀ (T : KS) → GenK T → LgDn T → FbLg G → (L : HB (step T)) → LgB L → (∀ {w} → hs hz ⊲[ w ] L) → (W : Wd (step T)) → LgW (step T) W → DK T L W → A` 与 `Lg-collapse` (合法由 `Lg-sum` 的形状给出). 实例就是 `SkelDxGen.Gen0.ev₀`. **接口里不得出现 `Ht`, `H₀`, `S₁`, `Sk`, `T⁺`, `rd₂`.**
2. **站的世界是字段, 不是 `w0`**: `Wst : ∀ s → Wd (step (Lev X_s))` 与 `lWst`, 加一条**非底**的律, 写成构造不写成判定 (避开 `seeExact-sep`): 例如 "`Wst s` 由回灌算子 `raiseAll : A → Wd (Lev X_s) → Wd (Lev X_s)` 从基世界升到第 s 站输出的 `A`-读数" (`NegGenFoldUpd.rB` 的形状), 律只说 `≤w`, 合法, 与 `tp-rs` (升后读数在上面); **不写** "别处不动" (`upd₁-sep`). 盲定理义务: 常数世界也满足 `≤w` 与合法, 所以 `tp-rs` 是唯一有内容的律, 要在接口头写明.
3. **对角**: 极限站的一次坍缩 `collapse (Lev ΛB) … (LX ΛB) … (Wst-lim) (ΩX ΛB)` (同 `TXΛ`), 层的 ℕ-极限用 `sumι` 部分和 (`top (hl f)` 已是); 不在 `Ht` 里取对角, 不用 `alim` 跨站 (除非先有跨站 `⊲` 的定理, 那是第 4 层的事).
4. **层号与读回**: 沿用 `LvKtTower.Tower` 的 `B`, `rts = hs (top (B s))`, `Bᴧ`, `ΛB`; 这一段没有封顶, 不要重写.
5. **去掉的字段**: `DnTower`, `DnLim`, `EvSys.evH : → Ht`, `FoldAtK.H : → Ht`, `σ-of : Ht → HB S₀`; 任何 `Cvt`/`toS`/`Sk` 搬运.
6. **新增的否定义务** (给 `NegNewTwr`): (i) 对接口每个固定类型值域写封顶定理; (ii) 对 `raiseAll` 写 "一起升" 与 "点更新" 的分界 (已有 `upd₁-sep`, `upAll₁-moves`), 再问新种类 (坐标是高度) 的界由谁升: 若只能由折叠自己的读回 (`rd₁ : → HB T`) 升, 先写 `rd₁` 对闭包有损的 `refl` 陈述 (同 `nc-old-drop`), 它就是下一个内容封顶.
7. **读法纪律**: 新塔的读法表不得用 (R2); 每个闭项的上界只能从它所在类型的树形共尾界算 (§1.3 的方法), 下界只能来自形状定理或值定理.

## 6 把握 (全部是判断)

- **合法闭项, 最终坍缩在随站增长的类型上, 有 FGH**: 已有 (**[实验]** `TXs`, `TXΛ`). 读法: 低于 ψ₀Λ, 大约在 ψ₀(Ω_{Ω₂}) 到 ψ₀(Ω_{Ω₃}) 之间 (基世界 + `fb-new-none` + `rd₁` 有损; 没有定理, 连粗界也没有).
