-- 在任意正底层的任意旧枝尾部追加一个升层零树时，当前层标准树的每个真实有覆盖读回都至少达到所追加的零树值。
module B28BClock where

open import Data.Nat.Base using (ℕ; zero; suc)
open import Data.Product using (proj₁; proj₂)
import W4Block as W
import W4Ops as O
import W4Path as P
import W4Fold as F
import WVOne as V
import OCF.Align.Level as L
open import OCF.Align.Value using (_≼_; ≼-refl; ≼-trans; s≼s; z≼; ≼l; l≼)
import B12Terminal as T
import B12ActualSlots as C
import B12Strict as Strict
import B13FiniteLift as U

data Positive : W.L → Set where
  node : ∀ s h → Positive (W.nd s h)

positive : ∀ a t → Positive a → Positive (a W.⊕ t)
positive a W.zero x = x
positive a (W.nd s h) x = node s _

strict : ∀ k → U.Uniform k L.suc
strict k r c v d = ≼-trans {b = L.suc (V.read (proj₁ (T.Run.β r)))} (s≼s d)
  (Strict.strict (F.mono k (T.Run.ok r) (T.Run.bs r) W.zero (P.z≤ k) (T.Run.β r) (proj₂ (O.Ωt k))))

raise : ∀ {k} → Positive k → ∀ q → U.Bound k q → U.Bound (U.sc k) (L.suc q)
raise (node s h) q b r c = ≼-trans {b = U.repeatω L.suc q} (≼l 1 (≼-refl _))
  (U.lift-bound s h L.suc q (strict (W.nd s h)) b r c)

module At (base k : W.L) (pos : Positive base) (old : W.Tr k) where
  level : W.Tr W.zero → W.L
  level z = base W.⊕ W.↑ k (old O.+ O.ι k z)
  valid : ∀ z → Positive (level z)
  valid z = positive base _ pos

  bound : ∀ z → U.Bound (level z) (V.read z)
  bound W.zero r c = z≼
  bound (W.suc z) = raise (valid z) (V.read z) (bound z)
  bound (W.lim f d) r c = l≼ (λ n → ≼-trans {b = V.read (T.value (T.limRun (λ i → level (f i)) r n))}
    (bound (f n) (T.limRun _ r n) (C.enter W.sL _ r n (T.prefix _ n) c))
    (T.lim-child _ r n))
  bound (W.Ω () _)
  bound (W.up _ () _ _)
  bound (W.ex _ _ _ _ ())
