## 新界在原参照和实际运行中的位置

在 G(1) 的第二份 Ω₂ 和中，固定九次选支后得到一个自然数极限节点。它的第 n 个孩子恰为 ψ⁰(pass(Ω₂+n))。实际侧从实现 Ω₂ 的操作 Q₁ 出发。把任意已实现高度 x 的 Q 外包一次，产生的真实折叠包含 Q 的全部有限迭代，既能读到各次的零值，也能从相应状态继续。这就实现了高度 x+1。对同一物理序列应用这条引理，第 n+1 个操作实现 Ω₂+n，整列的零值进入同一次三级运行。[原节点及任意 n 的地址等式](attachments/B23LOriginal.agda.txt) · [统一后继提升](attachments/B23NWindow.agda.txt)

严格的闭式取原 src 的 ψ₀ 作用在第 n 项为 pass(Ω₂+n) 的可数极限上。算术缩写 X₁·ω^ω 来自如下递推。第零项是 X₁，每取一次后继，就取前一项所有有限倍数的上确界。纯 src 与上述原树整个节点互相 ≼，其后继仍在 G(1) 内。另一个独立定位给同一份内部的 ψ₀(X₁·ω+1) 与 ψ₀(X₁·ω+ω)，其中前者可指定 Λ 的第 2 个孩子。[闭式及递推](attachments/B23RExit.agda.txt) · [独立的整极限](attachments/B23RFamily.agda.txt)

## 一个可复用的封闭定理

原参照的每个正外行 m、内孩子 n 都给一个零层更新函数 Gₘ,ₙ。从 1 起反复应用它，所有正次迭代的上确界与这个孩子等值。所有这些函数都对零层值序单调，逐支保持可数上确界。因此该孩子是大于等于 1 的最小不动点。要把它放入标准塔读数的上确界 K，一个充分条件是对每座标准塔 sⱼ 证明 Gₘ,ₙ(sⱼ) ≤ K。证明直接使用零层树间的值比较，各层树的基本列可以不同。[零层单调与可数极限](attachments/B23RKernel.agda.txt) · [最小不动点](attachments/B23RFixed.agda.txt) · [送回原参照及真实 Λ](attachments/B23RCut.agda.txt)

在**第一正外行**（代码 m=0），这个思路在 W4 上得到了更强的实际结果。任给 x 严格低于 K，可以先选定一个真实 Λ 孩子，使任意 n 的 G₀,ₙ 从 x 出发的全部正次迭代及其上确界都进入这个孩子。也可以先选定一座标准塔，连各个上确界的后继一起放进去。证明在一个三级运行里跟随它实际选出的反馈点，所得塔号与孩子号都独立于 n 和迭代次数。[任意有限层的真实定位](attachments/B23LRoom.agda.txt) · [第一正外行的统一实现](attachments/B23RControl.agda.txt)

## 第二正外行问的是什么

C 对应的更新为 G(x)=ψ⁰(pass(co₀(x)))。这里 co₀ 把零层参数变为二层系数，pass 再作一次指定的参照折叠。第一笔查询是 G(1)，其自身的孩子遍历 ψ⁰(pass(Ω₂·n))。零份和一份已在预期的实际操作上实现。第二份问两份 Ω₂ 之和，涉及随一级参数变化的保留分支。若能把每个 n≥2 的整份零值放进同次三级运行对应的有限操作，就足以交出 G(1)。随后还有 G(G(1)) 等规范查询。[原第一笔查询](attachments/B23NFirst.agda.txt) · [有限和的精确出口](attachments/B23AFinite.agda.txt)

量化域也能精确刻画。C ≤ 实际 Λ 当且仅当对每个严格低于 C 的 x，都有一个实际 Λ 孩子支配 G(x) 的后继。每个这样的 x 都能由规范反馈轨道的一个有限阶段覆盖。把量词放宽到一切正合法 W4 零层输入，即使每个输入可以另选 Λ 孩子，也会被实际闭项的后继反驳。这条否定给出了改接口的理由。以 K 的封闭性证明 C ≤ Λ 仍是可行候选。[受限域的充要条件](attachments/B23NCut.agda.txt) · [过宽量词的反例](attachments/B23NDomain.agda.txt)

有限个严格在 K 内的参数可先放进一个共同门槛，再在同一标准塔或实际 Λ 孩子中选定指定有限层的运行。把层号取为三，对门槛以下的每个 y，实际选中的同一个零层反馈点能产生 co₀(y) 的零读数和一级指数。零读数进入该次运行，一级指数在下一次真实折叠被消费。改变 y 后，两次输出状态分别定义性相等。要交出 G(y)，还需再实现外层 pass。[有限组共同定位](attachments/B23LSupport.agda.txt) · [同一时钟、两次消费](attachments/B23ASelected.agda.txt)

还有一条整体归纳可供后续使用。在同一次实际运行从指定起点 J 生成的操作上，如果每次外包一个实际折叠都能把所实现的参照参数 u 更新为 u+Ω₂，则对任意可数时钟的迭代可一次作结构归纳。起始 u=0 的实例已成立，整个生成域上的保持律待证。相较之下，第一笔 G(1) 的标量出口只要求固定物理序列的零值支配，允许下一轮先用较弱的条件检验两份 Ω₂。[起始实例](attachments/B23ABlocks.agda.txt) · [可数迭代](attachments/B23AHeight.agda.txt) · [生成域](attachments/B23AReach.agda.txt)
