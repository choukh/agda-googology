#### 追加：任意高首与有界续接

原闭项的全局下降策略仍未构造。固定一棵低于原 EBO 的 W4 后缀树，把它加在已经够大的高首右边，无法正确应对所有高首；前缀余量随当前高首变化已有机检下界。反例不要求排中律。下面的 Ω_i 指语法单项 ψ_i(0)，其余 ψ₀ 的值一律指原参照。

- **高首为何改变后缀。** 对任一合格非零层标 i，设 H=Ω_i。原语法中 H+ψ₀(H) 严格小于 H+Ω₁。ψ₀(H) 隔离时含有 H，但在 H+ψ₀(H) 中，H 严格小于整个词，故获准。更一般地，对任意可数标准形 t≤ψ₀(H)，H+t 都是获准的参数。B26OUContext.At.entry 建立该事实，Rank.walk 沿此区间内的全部原前驱与基本列归纳。对任意严格秩 r，若 x 是只含首项 H 的各种证据表示的共同下界，则 r(H+Ω₁)≥(x+|ψ₀(H)|)+1。这直接说明保留最高层标后，其右侧可以再藏下整次该首的原塌缩。
- **原参照与实际孩子。** 取 r(a)=|ψ₀(a)|，B=|ψ₀(H)|。B26OUValue.At.charge 给出 |ψ₀(H+Ω₁)|≥B+B+1。若某实际 W4 结点可接这个高参数，At.descend 从证据中选出一个直接孩子，其值已经 ≥B+B。At.fail 证明，对任意实际前缀 x、尾 z，若 read x 与 read z 均 ≤B，|ψ₀(H+Ω₁)| 便不能由 read(x+z) 支配。这里的 '+' 是 W4 实际树上的加法。
- **任何固定的次 EBO 续接均有算得出的反例。** B26OUActual.counterexample 从任意真实 z 和 suc(read z)≼原 EBO 提取 n 及高首 H=ΩTower(n+2)。同一个 H+Ω₁ 击穿所有满足 read x≤|ψ₀(H)| 的 x+z。这个结论的量词允许 x 随 H 改变。它约束的是这种按加法续接且首项没有预存超额值的实现。让续接随 H 变化、让首项承担超额值或改变组合运算，仍须另行检验。

### 第 26 批实际端回报

本批目标是直接论证原 EBO 不高于 W4，主线的树、折叠与合法性均沿用已有定义。原 EBO 的下界仍未证得。独立标准塔的上确界记作 K，真实 W4 终点的零层读值记作 Y，旧定理给 K ≤ Y。以下严格不等式 x < y 表示 suc x ≼ y，等值表示两个方向的 ≼。下述十个模块均通过 --safe --without-K 的单工 6G 检查。

#### 已编译的实际端定理

1. `B26PActual.cell` 对任意被第 i 个真实塔孩子控制的 x、被第 m 个标准塔控制的 q，给出同一座后续真实塔的每一个反馈孩子中 x·q 的下界。这里塔号可统一取 1+max(i,m)，不依赖反馈次数 j。证明先用旧包含引理把 std(m) 压入该塔每个单位系数，再用真实反馈孩子的乘积分解。
2. `B26PActual.interior` 给 x < Y、q < K ⇒ x·q < Y。`bound` 给 x < Y ⇒ x·K ≤ Y，`times-omega` 给 x < Y ⇒ x·ω < Y。全部为无前提的运算保持定理。取 x=1、q=ω 即有实例。
3. `B26PSums.plus` 给 x,y < Y ⇒ x+y < Y。证明将两项送到同一孩子 a，使用 x+y ≤ a+a ≤ a·ω。`B26PDivisor.exclude` 对全部 x 及 2≤q<K 给 x·q 与 Y 不同值。它能处理未知 x 是否为零的构造性情形。二者均不使用排中律。

#### 对原 EBO 普通标准形的限制

4. `B26PAppend.both` 给任意两段及连接后记号的 HC 证书，证明参照树连接等值于序数和。`B26PSums.not-sum` 由此一次排除全体长度至少二的正规可数和对 Y 的命名。任意标准形 ψ₀(a)+ψ₀(b)+… 的首项与其余的和都严格小于整项，若整项等值 Y 则与加法封闭矛盾。
5. `B26PSuffix.Low.val` 对任意前缀 t 及可数后缀 s，证明 |ψ₀(t++s)| ≈ |ψ₀(t)|·ω^|s|，两端和后缀可以取任意 HC 证书，不要求前缀本身可数。沿 HC(s) 归纳，零支为乘一，后继支用基本列的有限重复与序数乘法结合律，可数极限支两边逐支对齐。t=s=[] 提供闭实例。
6. `B26PLowTail.prefix` 只从后缀和整项的 HC 证书构造前缀外 ψ₀ 的 HC 证书。`exclude` 对任意前缀、1≤|s|<K 排除 ψ₀(t++s) 对 Y 的命名。`normal` 对非空正规可数尾自动给出下界 1。两条均不要求预先知道 |ψ₀(t)|<Y，也不需要 LEM。
7. `B26PInterval.Canonical.At.below` 若整个名字正规，可数非空尾 s 的首项为 ψ₀(b)，则由标准形的 G₀(t++s)<t++s 与 b∈G₀(t++s) 得 s<ψ₀(t++s)，从而 |s|<整项。`terminal-cut` 给 ψ₀(t++s) ≈ Y ⇒ Y ≤ K 不成立；`interval` 在排中律下进一步给 K ≤ |s| < Y。

#### 真实环境与独立标准塔

8. `B26PPart.closed` 给 x,y<K ⇒ x·y<K。取支配两者的同一 std(m)，把它的平方压到该点以上的最小 ε 不动点之下，并使用原有的 K 内部不动点定理。`B26PBounds` 在保留实际槽族的同时把每个单位起点反馈轨道的有限部分和压入 std(m)·ω。
9. `B26PFactor.exact` 无排中律地证明 Y≈K 当且仅当对每个固定 n 可找到一个 m，使所有 j 满足 fresh(n,j) ≤ std(m)。这里 fresh(n,j) 是第 n 条实际反馈轨道的第 j 个孩子在外部零层起点重置为 1 后的系数，槽族仍含历史。必要性使用整座单位塔严格落入 Y；充分性将单轨道的和和全塔的有限乘积都吸收进 K。没有证明每条真实轨道都满足这一界。
10. `B26PFactor.Classical.alternative` 在排中律下给出二择。第一种是 Y≈K，另一种是在一个固定 n 上 ∀m ∃j，std(m)<fresh(n,j)。后一种无前提推出 K<Y 与 K·K≤Y；由 K<Y 反推存在这一个轨道使用排中律。结论允许随标准塔改变反馈孩子 j，不能将这些 j 换成一个同时支配 K 的反馈孩子。
