# 第二十四批　W4 的新闭下界与整个首查询的不动点判据

W4 的同一合法 Λ 闭项有了严格高过上批的无条件下界。精确的纯 src 表达式为 **D = ψ₀(pass(Ω₂ + ↑Ω₁))**，其中 ↑ 把一级树嵌入二层，pass 是原参照从三级折回二级的一次运算。D 同时进入标准三级闭项和 Λ 编号为 1 的实际孩子。按原 Ω 标尺有 **ψ₀(Ω₂) < D < ψ₀(Ω₃)**。序数值用零层树之间的 ≼ 验收，这里的每个严格号都证明了左端的后继不超过右端。[实际闭定理](attachments/B24AClosed.agda.txt) · [纯 src 对照](attachments/B24RExit.agda.txt) · [原标尺的粗界](attachments/B24RFixed.agda.txt)

## 哪个整值进入了 W4

在原 ψ₀(Ω₃) 的第二正外行取第零个孩子 C。C 从 1 起迭代一个零层函数 G，第一次询问为 G(1)。G(1) 的第 k 个孩子取 k 份 Ω₂ 之和，经过 pass 再折到零层。取 k = 2，得到 S = ψ⁰(pass(Ω₂ + Ω₂))。S 的第零个孩子正是 D。于是 **上批的 ψ₀(X₁·ω^ω) < D < G(1)**。这里 X₁ 是 pass(Ω₂)。D 已进入实际 W4。向上收集 S、G(1) 和 C 各自的其余孩子或反馈仍待完成。[精确地址与同值](attachments/B24ROrbit.agda.txt) · [两端严格比较](attachments/B24AClosed.agda.txt)

纸面展开 D 时，每个分支都问同一个函数 H(x) = ψ⁰(pass(Ω₂ + ιx))，ι 将零层树嵌入二层。D 是从 1 起反复应用 H 的全部正次迭代的上确界。实际侧从已经实现 Ω₂ 的操作 Q₁ 起步。对于任何已实现的底操作与任意可数树 z，实际折叠一次可以接受一切值不超过 z 读数的参照参数，并在后续状态保留零值及一级指数。实际 Ω₁ 反馈每产生一个新时钟，就能执行下一次 H 查询。一次归纳把整条轨道送入第二个实际操作 Q₂ 的同一个零层输出，再接到 Λ。[可数参数规则](attachments/B24AFrame.agda.txt) · [真实反馈归纳](attachments/B24AFeedback.agda.txt) · [Q₂ 的零值](attachments/B24AFirst.agda.txt)

## 避免逐项爬升的两个等价条件

给任意正则二层前缀 p，在它右边追加一份 Ω₂。对第 n 个零层孩子，参照树递归生成一个更新函数 Hₚ,ₙ。该孩子与从 1 开始的全部正次迭代逐枝对应。前缀取 m 份 Ω₂ 时写为 Hₘ,ₙ。这些核全都对零层值序单调，并保持可数上确界。因此每个完整孩子都是其核在 1 以上的最小不动点。m 与 n 同时是变量。[任意正则前缀的分解](attachments/B24RRows.agda.txt) · [全部有限份数的单调与极限](attachments/B24RCompare.agda.txt)

- **用封闭界。** 对目标 t，G(1) ≤ t 当且仅当零份的值 ≤ t，并且对每个 m,n 都能给出一个 b，满足 1 ≤ b ≤ t 和 Hₘ,ₙ(b) ≤ b。每一组可以选自己的 b。求得一个这样的界就覆盖整条无限轨道。必要方向用原孩子自身作见证。[最小性与双向定理](attachments/B24RFixed.agda.txt)
- **用实际孩子。** G(1) ≤ Λ 当且仅当对每个总份数 k ≥ 2、每个核及每次正迭代，都能找一个 Λ 孩子，支配该次查询值的后继。见证可以随三个编号变化。证明先得出每个正份数的后继进入下一份数，因而每次有限询问的后继严格留在 G(1) 内，再从真实 Λ 的上确界中提取孩子。零份和一份已有实证。[严格余量及实际见证的充要条件](attachments/B24AQueries.agda.txt)

两种判据都在第一个此前未覆盖的核得到实例。总份数为 2、核号为 0 时，取 b = D 便有 H₁,₀(b) ≤ b ≤ Λ 的第 1 个孩子。同一实际孩子还支配这个核的每次正迭代的后继，孩子编号与迭代次数无关。[两个实填见证](attachments/B24RInstance.agda.txt)

## 下一次反馈能读到什么

在 S 的下一个孩子，给定零层输入 x，原树先产生一级参数 u(x) = κ(pass(Ω₂ + ιx))。κ 把二层树折到一级。下一笔所需的零值是 ψ⁰(pass(Ω₂ + ↑u(x)))。一级参数会随 x 变化。[原核的递归方程](attachments/B24RRows.agda.txt)

真实的 Q₁ 对任意显式一级输入都能实现对应的指数更新，只须它与环境槽各自实现同一个输入指数，且环境槽覆盖 Ω₁。把所有有限深度的指数解释合在一起，可以同时追踪整个函数 x ↦ u(x)。Q₂ 的第二个一级反馈时钟包含表示这族输入的保留节点，后续的零层询问能再次访问它。一个配对反例说明正层律的限度。将真实 Q₁ 在所有正层的行为保留，在零层只返回输入的后继，所得操作仍满足同一条正层律，但在输入 1 处只能返回 2，连 H(1) 都达不到。真实 Q₁ 的已知零层规则正是补充信息的来源。[显式一级输入](attachments/B24NTheta.agda.txt) · [参数的读回](attachments/B24NKid.agda.txt) · [原时钟中的保留节点](attachments/B24NStore.agda.txt) · [配对反例](attachments/B24APositive.agda.txt)

在这个实际位置沿用旧零层规则，可对同一个 u(x) 读出 W(x) = ψ⁰(co₁(u(x)))。co₁ 是此前使用的一级参数生成二层项的运算。W 从 1 起的全部正次迭代的上确界也进入实际标准三级与 Λ。它同 D 的值序尚待比较。在新规则下需要的值为 ψ⁰(pass(Ω₂ + ↑u(x)))，与 W(x) 的比较也待证。[同址读取和第二条闭下界](attachments/B24NScalar.agda.txt)

对 S 的全部正核深度 k + 1，可以在同一个 Q₂ 中统一找到第 k + 2 次一级反馈保存的节点。要把整份 S 送入 Q₂，一个充分条件是每次规范查询的原零值都被同次求值的两个输出支配。其中一个输出决定下一步反馈时钟，另一个交还外层。已证明 W 在首个正深度的每次迭代都通过这两项比较，常值 1 在每个深度都有实例。若能对原核和迭代次数同时证明这两项比较，节点位置、时钟同步与实际出口已由同一归纳处理。[任意深度的实际位置、两个实例与整份出口](attachments/B24AWhole.agda.txt)
