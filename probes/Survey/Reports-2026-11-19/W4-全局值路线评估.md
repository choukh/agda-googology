# W4 的 EBO 值能否一次验收

**判断。可以跳过逐站求值。最值得检验的是，真实 W4 能否在同一次运行中实现一个有守卫的塌缩运算，并在搬到较高塔时保留它还会用到的分支。** 若对有限表达式给出这条通用律，对表达式结构归纳一次即可。经典集合论可以同时解决原参照怎样读、最后怎样把序数不等式换回树的比较。实际 W4 是否满足那条律仍开放。本评审没有得到 W4 的 EBO 下界或严格上界。

## 1. 精确的目标和一个无需另译基本列的经典标尺

记 `Y = WVOne.read W4Fold.EBOᶜ`，`R = toL EBO-tree′`。这两项都是只有零、后继、自然数分支的树。W4 先在层号 `Λ = nd sL tw` 上造 `Ωt Λ`，用带路径、底族和起点的 `ψ` 折回零层。原参照则取所有塔项 `EBOψ k` 的遗传基本列树的极限。原题是 `R ≼ Y`。已有 `B14Goal.need/enough` 把它等价地拆为原 BTBO 加上所有从第 3 行起的尾行。`B17Cofinal.necessary/enough` 还证明它等价于对每个可数标准形，在 Λ 的某个实际孩子里给出该参照树后继的下界。后面这条很适合作出口，若直接把它当作假设，则数学工作尚未减少。

对这样的树取集合序数读数 ρ，零读 0，后继读后继，极限读各孩子读数的上确界。极限处没有额外的后继。经典集合数学中有
```
a ≼ b   ⇔   ρ(a) ≤ ρ(b).
```
前向沿比较推导归纳。反向对两棵树作嵌套结构归纳。左边为极限时对每个孩子归纳；左边为后继、右边为极限时，若 α+1≤sup βₙ，某个 n 满足 α+1≤βₙ，再在右孩子上归纳。两边都是后继时同时去掉一层。结构归纳也覆盖孩子与极限读数相等的情形。这里只陈述零层。集合论里的结论作为外部第四层结论须交代与实际数据的解释；要交 Agda 项，仍要在可用的经典参数下给出这个比较引理或产出树比较的证据。某个外部模型满足命题，不能自动变成 Agda 的证明项。

**本轮纸面推导。原参照的 ρ 恰好等于本仓库可数标准形全序的序型。** 取集合 C 为同时满足 `EboLeanBase.NF` 与 `Ctbl` 的原始有限项，按底层项相等，序取原 `_<ᵀ_`。良基由 `EboLeanTau.wfNF′`，全序可按原字典比较核查。设 o(t) 是 C 中严格小于 t 的初段序型。对每个 t∈C 和它的遗传基本列证书 h 有

```
ρ(Rt h) = o(t).
```

- ≤ 向对 h 归纳。前驱严格小于父项且仍在 C。每个 ω 基本列项也严格小于父项且仍在 C。对应事实正是 `EboLeanTree.hcA` 里使用的 `T-pred`、`trian-fsn`、`cl-fsn-NF` 和可数性保持。后继取加一，极限取上确界。
- ≥ 向对 C 的序作良基归纳。对每个 s<t，`YiCFMono.mono<ⁿ` 给 `suc (Rt hₛ) ≼ Rt h`，其中 hₛ 可由 `hc` 取得。应用上一段的 ρ 可靠性和归纳假设，再对 s<t 取 sup(o(s)+1)。
- `B17Cofinal.below` 由首项下标的有限深度给每个 t∈C 一个 k，使 t<`EBOψ k`。各塔项也都在 C。因此 ρ(R)=supₖ o(EBOψ k)=otp(C)。不需要假定塔第 k 项与 W4 第 k 项对应。

于是只要在同一语义中证明 **otp(C)≤ρ(Y)**，就能回到原题。上式本身仅是精确改写，价值在于此后可以用良序嵌入、闭包或有限推导证明这个不等式。若改用另一套集合论 ψ 作上界标尺，对下界方向还可以再省。给 C 一个严格保序函数 φ，已足以推出 ρ(Rt h)≤φ(t)。甚至只需对原前驱有 φ(pred t)+1≤φ(t)，对原基本列有 φ(fsn t n)≤φ(t)。足够的最后条件是 supₖ φ(EBOψ k)≤ρ(Y)。这个方向免去逐项基本列相同的跨语言定理。使用外部 Lean 的 φ 时，仍要证明原输入是其标准项、序比较确实保持、以及外部右端确实对应真实 Y。

## 2. 真正困难的地方在什么运算

`W4Fold.ψ` 在正层的自身路径直接保存 `ex β β x`。输入 `up` 在特定 Ω 层指定孩子路径上会改为给外层结果追加一次从标准底重新算的零层值。同一 `up` 在整族路径上会沿孩子继续，并更新底族。`E` 和 `It n` 处理保存的指数，后者遇 `ex` 转到 `It (suc n)`，遇 `up` 则通过 `chTD`、`upC` 改语境。由此一个可用的归纳命题须对有限阶数和实际语境延伸有意义。一个给定对象在不同路径上的读数可能有不同的后续用途。

Ω 节点在目标保留分支时会携带一个实际的槽转换函数。选择 `nothing` 时，`node⁺` 产生 `limc⁺`，即实际轨道各项的有限累加和的极限。低层输出与下一次轨道下标来自不同目标上的折叠。证明每次累加够大，还须证明被送回去的那个树下标有待测的分支行为。`W4Val.val` 和 `W4View.view` 给了构造子上的值和内部视图，其陈述没有把这两个目标的运行行为降成同一裸序数的函数。

可以在 ZFC 中先对外层树取 ρ。若整台机器也要解释，较省的对象是从闭项生成、带原路径和语境的实际运行，加上对它的可测试行为。若主张整个 Agda 归纳递归宇宙在某集合论模型中被忠实解释，要列出宇宙或大小假设；只解释到达的运行有望少用假设，也要证明这种限制足以覆盖所需分支。可选择 ZFC 作第四层背景，排中律、选择、序数递归实际用在何处分别记录。

直接擦掉高层表示有一个集合论上的警示。对每个二进列 b，零层合法树 `limₙ nat(2n+bₙ)` 的相邻步进可用有限后继链给出，所有树的 ρ 都为 ω，而 b 不同则原树不同。只在这个值的纤维里就有连续统多个表示。即便准许选择，从每个值选代表也没有产生“任意分支函数在不同代表上表现一样”的定理。在不假设 CH 的模型中，连将全部原表示直接当作 ω₁ 的元素并作一一对应都可能失败。这是纸面例子。实际折叠方面，`B22CrossTest.FirstTower.no-lower/no-upper` 使用同一标准槽族和起点的合法探针，展开指数后可严格减值，也可严格增值。定理排除全合法输入上的两个统一比较方向。它没对标准 Ω 分支本身给出封顶。

## 3. 优先候选：把有限个带守卫的塌缩操作送进真实运行

取 sₘ 为独立标准塔的零层值，K=supₘρ(sₘ)。`B22TowerCut.terminal` 已给 K≤ρ(Y)，`B20StandardGoal.bound` 实际还有逐塔的后继余量。用 K 可以让每次构造换塔，且手里已有跨塔引理。若独立塔的界太小，也可改用 Λ 实际孩子；项目没有证明 K=ρ(Y)。

可以把候选拆成三条数学义务。

1. **标尺。** 在第四层给有限标准项 u、a、有限降序和及带 `GB u a a` 守卫的主项 ψᵤ(a) 赋予经典语义。或者以本地可数序型 o 作零层读数，在高层保留未折的项与下一次询问。高层项允许指代不可数层和作用于参数的分支。只有最后塌回零层的量须小于 K。若直接采用 `ExBuchholz` 的闭包定义，须核对 Ω₀=1、种子、准许的下标及参数守卫；该系统的集合闭包与无条件在所有小于 K 的序数上施行一个 ψ 的说法有不同定义域。
2. **真实见证。** 候选关系 `Real(q,a)` 中，q 由某一标准塔的执行生成，须能指回实际塔、语境、底族、目标路径、当前参数和所用的投影。可数结论的消去律给 o(a)≤真实零层输出的 ρ，且此输出严格小于 K，或可在更高塔取得严格余量。正层结论的消去律对原操作下一次实际会问的参数给一份带目标和继续方式的见证。它可以只保单向比较。定义的起始对象取实际初始状态与零/基底，选项和路径由现行 W4 的规则决定。`B22RowLive.Present` 同时带零值下界、结构与后续一级指数，是 X₁ 这一实例可检查的样本。
3. **局部封闭。** 对同一有限上下文中的若干 `Real` 见证，给一个可达的共同运行来读取它们；搬运须保留本步和下一步会问的投影。证明它对 `n[]`、`n∷` 与 `nψ` 相应的基底、和、带守卫塌缩封闭。塌缩律的输入是已实现的原下标、参数及其有限可见依赖；输出是在此真实运行的扩展里由实际折叠/反馈产生的 ψ 结果。量化任意允许参数、正层目标及迭代阶数，不能按塔号给不同前提。其证明必须使用 `ψ/E/It/kpT` 的具体方程及可达性。独立塔号的数值取最大只能合并零值上界；把不同运行的多个正槽放回同一运行，是单独的待证引理。

如果这三条成立，可对有限项的形成证明同时归纳它及其正层子表达式的见证。取所有已实现的零层值，基底与两种形成规则封闭，得到每个可数标准形的标尺值在 K 内。第 1 节给原 EBO 下界。有限次嵌套的 Ω 塔只是该归纳的一族输入，无须每一站写一条值定理。逻辑上，给所有可数标准形配一份支配它的运行，与目标已经十分接近；**使路线成为捷径的是同一份可对变量 u,a 实填的封闭证明**。用 `Real(q,a)` 定义为“某塔足以覆盖 a”，再把 ψ 情形留成“某塔覆盖 ψᵤ(a)”，没有给出这个证明。

**不可数分支处可再砍掉一项过强的要求。** `YiCFCofin.Ωcof` 已对任意标准形 b、其 Ω 共尾视图 w 和标准形 c<b，抽出门槛 θ<Ω_{ν+1}，每个 η>θ 都有 c<fΩ(w,η)。`six` 的第二种情形把需求归到 c 的一个 ν-可见真子项 ζ，`Cof6` 用 size ζ<size c 在原参照的 γ 链上结束。没有一条 ω 链需要、或可能共尾于一个真正正则的不可数基数；所需的是可达到由这个小数据指定的询问。针对 W4，可试以下局部版本。

- 起点情形在实际初次反馈给出所需下界；递进情形假设对 ζ 的实际见证已在某状态达到，要从一次或有限次真实更新产生一个指数，能回答 η>θ 对应的这个询问，并把本次零层下界与再下一次所需分支同时保留。量化当前标准运行、门槛的可见性证据、原分支的继续方式，允许实际步数增加、换塔或多个不同输入共用一阶段。
- 在保留情形用实际 `kpT` 的槽和 `cv`；在走链情形用实际 `iter` 产生的下标和累加输出；在带框架、`ex` 情形需对下一阶 `It` 仍能消去同一关系。所需下标可由关系解释为一个原询问的下界，不必假定每个实际树下标都有外部标准名字。
- 用检验所需的**有限依赖**，不等于仅做有限深度的测试。为一个整 Ω 节点取上确界时，仍须对其每个相关分支证明。尤其是后继的下界须在某个真实状态完整取得；只见到所有自然数的样本不能区分 ω 和 ω+1。分别在不兼容的现场得到零值和指数也不能供下一次反馈使用。

在纯集合语言中，这相当于对可实现的带类型表达式所构成的集合证明包含所需种子，并在有守卫的生成运算下封闭，然后用最小闭包的归纳原理。若走“反馈轨道的极限是最小不动点”这一写法，还须证明该轨道递增，在所需域上更新函数外延且保相应上确界；或者只证前述有限询问终能得到回应。给一族任意函数取上确界不能自动交换反馈中的函数复合与换基。Skolem 包或可数初等子结构可以把询问放进小集合，额外义务仍是用已到达的 W4 运算同时实现其中所需的询问。单取可数 M≺H(θ) 并令 δ=sup(M∩ω₁)，不会产生 δ≤ρ(Y)。

## 5. 其它整体方法

**直接构造严格序嵌入。** 若能对 C 的有限项构造进入 K 的保序函数，把这个函数用真实运行中的参数替换、加法、保留、反馈给出，第 1 节立即完成原验收。它侧重比较任意两项，可能利用原字典序与有限可见支撑。构造名称然后假设保序，或在 ZFC 先以 otp(C)≤K 作选择来给出映射，则绕回待证式。优点是在原尺一侧完全不需要外部 ψ，也不需要反向值比较。

**把理想折叠与真实折叠作单向模拟。** 若已有理想端支配原 R，并能用一条对所有规范参数可复用的模拟把它送回真实 Y，也能一次过站。可试在原运算所生成的、带语境的有限询问上作延迟模拟。现有证据只到某些整值和部分实际反馈；理想端本身的 EBO 下界亦未见。无约束的 `ex` 展开、所有高层树按秩替换有上述反例。早先 `ProbeP1/P2/P4` 的全域比较、滞后及保留缺口针对较早折叠，不能当作针对 W4 的否定。

**膨胀函子与迭代塌缩。** Freund–Rathjen 关于 ν-不动点的工作提供有有限支撑、限制/延伸与塌缩比较律的候选接口。若特定 D 的最小不动点有原 C 的序嵌入，再把 W4 可达运行组织成容纳该不动点的一个实例，便有原下界。两侧的实例化都需给出。W4 的正层分支可取任意函数；限制到规范操作后，有限支撑、对嵌入的自然性以及在真实 `upC` 之后仍成立的比较律尚待证。ν-不动点的存在或任何理论能证明其良基性，都不指定本闭项是哪一个不动点。可以借其局部支撑律，直接整套实例化的投入较大。[Freund–Rathjen，2023，特别是 §1 的定义与例子](https://link.springer.com/article/10.1007/s00029-023-00879-2)

**用证明论给下界。** 所需方向为找到理论 T 并分别证明 otp(C)≤|T| 及 |T|≤ρ(Y)。后半可用 W4 给 T 的每个可证良序作真实秩界，或给一套已校准的推导做有界切消与塌缩；前半可由原项良序逐段在 T 内可证而给出。Rathjen 2010 的 Lemma 12.9 与 Theorem 12.11(i) 对其自身系统给出塔共尾和 ψ₀(Φ₁0)≤|Π¹₁-TR₀|。他的闭包语言有 φ、Φ，须另比本项目的 C，只需所需的不等式即可。旧 `ProbeP5b.keep-law-fails` 打中当时旧折叠的一条保留律，不能据此关闭 W4 上的证明论路线。T 中证不出某个编码良基、沿某秩可推出 Con(T)、FGH 不可证全等，各自还依赖编码/校准定理，单独均不推出这里的值不等式。与直接实现塌缩律相比，这条路线还增加了一整套推导嵌入与有界性工作。[Rathjen，2010，第 12 节](https://eprints.whiterose.ac.uk/76751/1/Diss.pdf)

**作为选择依据。** 经典集合论取秩和本地可数标准形序型提供的是可立即固定的验收接口。实际可试的跨站工作是第 3 节的局部塌缩律，第一道门槛是一个可变量化的原分支以及同一状态的下一次使用。若真实标准域上这一步失败，应同步检查全局上界或改用 Λ 的其它真实孩子来给下界；无须先补齐所有较低站，更不能从单格失败宣布 W4 整体低于 EBO。等值还需相反方向 ρ(Y)≤otp(C)，可以用一个独立的上估模型争取。
