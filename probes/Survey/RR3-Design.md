## 0 结论先行

1. **数学骨架只有一种 (判断, 依据 §1):** 以层号为下标的树族 `T ℓ`, 每层有 ℕ-极限与 "对低层 `T j` 分支的 Ω-极限", Ω_ℓ 由层号的结构算出, Buchholz 式折叠 ψ_i 对树结构递归并在 Ω-结点处按 "目标 i 对结点层 j" 三路派发, Λ 取为 Ω-塔的 ℕ-对角. BTBO 就是这个骨架在可数层号上的实例. 终点 ψ₀Λ 要的只是把层号推到 Λ 之下的一切序数.
2. **层号类型一旦含 Ω-共尾元, 骨架在类型论上只剩两条写法 (两条事实, 一条判断):**
   - [定理] `Barrier.barrier`: 含 `Ordᴰ` 精确初始段、Ω-共尾元与有界三歧的层号类型推出 LPO. 所以 BTBO 的派发机制 (对层号的有界三歧) 过不了 Ω.
   - [实验 1, 退出码 42] 想把派发换成 "码上的可判定比较" 而不改树族的写法, 即单一树族 `T : Code → Set`、Ω-结点 `limΩ : (j : Code) → cmpC j ℓ ≡ lt → (T j → T ℓ) → T ℓ`, 被正性检查拒绝 (`T` 出现在箭头左侧). 分支的类型必须是**先于本层定义好的类型**, 所以层族只能 (A) 沿层号的**结构**递归 (层号是树, `j < ℓ` 是结构路径, BTBO 与仓库的 `LevelFix`/`Ordᴵ` 都是), 或 (B) 沿码序的**可及性** `Acc` 递归 (层号是有限项, 需要码序良基).
   - [判断] (A) 之下, 派发要比较两个结构路径, 在 Ω-分支分叉处就是比较两个无公共上界的低层树, 由壁垒定理这不可判定; 于是 ψ 只能是**部分函数**, 定义域要带 "每个结点与目标的关系" 的证据, 证据要随回灌更新并对 ψ 封闭. 仓库的世界、可入性、坐标、差树、事件表全部是这一步逼出来的, 不是自加约束 (§3.2). 而 "对 ψ 封闭且能判定派发的证据类型" 就是 Λ 之下层号上的一个可判定全序, 按定义是一个记号系统 (§2.4).
   - [实验 2, 退出码 0] (B) 的类型骨架可以写: 树族沿 `Acc` 递归 (`T c (acc h) = T₊ c (λ j p → T j (h p))`), 折叠 ψ 对树递归、派发只看 `cmpC`、不用任何树上的比较, 跨 `Acc` 证明的搬运 `coe` 对 `Acc` 结构递归. 代价在 §2.3: 作层号用的码要 `Acc`, 链点的码要在标准形内, 这就是记号侧的良基与封闭 (`EboLean3` 的 487 与 579 行), 省不掉 (判断).
3. **推荐 (判断):** 把 "层号的序必须是有限项上的可判定序" 从禁忌改为设计前提, 写进最佳实践 (不触四条纲领: 树仍在先, 无公理, 停机由树的结构递归保证, 码与序是自己写的, 不导入记号文件). 在此前提下最短的完整构造是 (B): 树是主对象, 基本列由树上的 ψ **生成**而不是由规则写出, 码只做派发. 第一步是把实验 2 的骨架换成真码 (EBO 形的项与比较), 接上 `EboLean3` 已有的 NF 与良基, 写出 ψ₀Λ 的闭项并对 `WfFsn.EBO-tree` 验收序数值. 预计前三层 1000 到 1500 行 (与 1513 同量级, 不会显著更短), 成功率中高; 它的收获不是行数, 是 "基本列由树给出" 这一半自足, 以及一条干净的终点定理.
4. **应放弃或放宽的 (只限纲领之外):** "1513 行标杆" 作为路线优劣的判据 (§5); "读法" 命名的中间站; 继续在裸下标或可入下标上攻世界更新 (A 路) 作为主线; "树自足 = 不要任何有限项序" 的目标表述. 理由各在 §5.
5. **本设计最可能失败在哪里 (判断):** (i) 作者不接受 "层号的序是记号" 这一放宽, 那么 §2.4 的判断就要先写成否定定理, 否则 A 路只能继续; (ii) (B) 的链点码需要标准形封闭, 若在 `--safe` 下重写 `ExBuchholz` 的 `Closure` 超预算, 则 (B) 退化为 `DirectClosed` 的现状; (iii) 层号的 Ω 需要层号自带的树, 若码与树的配对在 `Acc` 搬运处要 UIP, 就撞 `LevelFix` 的 `Un`.

## 1 第一原理: 通向 ψ₀Λ 的树构造必须含什么

只用三样已知: 纲领; BTBO 的四个部件 (层族 `Ord ℓ`, `Ω`, `↑`, `ψ<`); 壁垒定理.

### 1.1 目标的分解

ψ₀(Λ) = sup_n ψ₀(t_n), t_0 = 1, t_{n+1} = Ω_{t_n}. 要算 ψ₀(t_n), 需要: (a) 一个能表示 Ω_u (u < t_n) 的树类型; (b) 从那里折到可数树的 ψ₀. Buchholz 的 ψ₀ 在 Ω_{j+1}-共尾结点处走 γ-链 γ_{k+1} = ψ_j(f γ_k), 所以 (b) 需要一切中间层的 ψ_j, 而 ψ_j 在结点 lim_{j′} 处要判定 j′ 对 j 的三歧 (j′ < j 保留结点; j′ = j 取最小不动点; j′ > j 走链). **层号比较是 ψ 的内生需求, 不是实现选择** (判断; 纸面检查了 ψ₀(Ω_{Ω+1}) 的展开: 目标 δ′ 与 Ω_Ω = lim_0 (c ↦ Ω_c) 的分支 c 之间的比较对**一切** c 出现, 因为结果结点的分支函数必须全定义).

### 1.2 骨架 (与 BTBO 逐项对应)

| 部件 | 是什么 | 为什么这样 | 与壁垒的关系 |
|---|---|---|---|
| 层号 `Lv` 与树族 `T : Lv → Set` | `T ℓ` 有 `zero`, `suc`, `lim : (ℕ → T ℓ)`, `limΩ_j : (T j → T ℓ)` 对 `j < ℓ` | 纲领 1 的 View 要求 Ω-极限按低层合法树分支; `T j` 必须先于 `T ℓ` 定义 (实验 1) | 壁垒落在 `j < ℓ` 的表示与比较上 (§2) |
| `Ω : (ℓ : Lv) → T ℓ` | 0 层 ω; 后继层 `limΩ_{ℓ⁻} ↑`; 极限层沿层号自己的基本列取 ℕ-极限或 Ω-极限 | 极限层的基本列要么从层号的**树**读 (层号是带树的对象), 要么从层号的**码**按规则算 (记号的基本列规则) | 无 |
| `↑ : ℓ₁ < ℓ₂ → T ℓ₁ → T ℓ₂` | 逐结点提升, Ω-结点的证据经传递性 | 链与 Ω 都要它 | 需要 `<` 传递 |
| `ψ_i : T ℓ → T i` | BTBO 的四行; Ω-结点处三路派发 | Buchholz 规则 | **派发 = 层号的三歧** |
| 回灌 | ψ 的输出作层号 (BTBO 的 `ordᴰ`) | 不动点 Λ 要 x ↦ Ω_x 迭代 | 输出要能作 `Lv` 的元素, 即要带 `Lv` 需要的证据 |
| Λ | `lim (n ↦ ψ₀ (Ω (t n)))` 在 `T 0` 里的 ℕ-对角 | ψ₀Λ 本身可数, 对角合法 | 无 |
| FGH | BTBO 的 `FGH` | — | 无 |

这张表上只有一格有壁垒: 派发. 纲领 1–3 对其余各格都没有新要求.

## 2 类型论上的二分

### 2.1 层号类型不能同时含 Ω-共尾元与有界三歧 [定理]

`Barrier.Ω-Extension → LPO` (`probes/OCF/Barrier.lagda.md`, `barrier`). 前提: `ι : Ordᴰ → I` 严格保序且精确, `top` 在一切 `ι a` 之上, 有界三歧 `<ᴵ-dec`. BTBO 的派发正是 `Ordᴰ.<-dec`. 所以 ψ 的派发不能靠层号类型的有界三歧越过 Ω. 这一条仓库已有, 本审只核对了陈述与证明结构 (`Stages.lpo` 用到三歧的三个分支与两处精确性).

### 2.2 换成码上的比较, 树族的写法就必须改 [实验 1]

`rr3design/RR3NegPos.agda`: `data T : Code → Set` 的构造子 `limΩ : (j : Code) → cmpC j ℓ ≡ lt → (T j → T ℓ) → T ℓ`. 退出码 42, 报错 `T is not strictly positive, because it occurs to the left of an arrow in the type of the constructor limΩ`. 这与 `LevelFixCore` 文件头记的 P1 (`LF is not strictly positive`) 是同一件事, 本审把它写成最小样本.

后果: Ω-结点的分支类型必须是本层定义之前就存在的类型. BTBO 的办法是把低层族作模块参数 `Ord< : (i : Ordᴰ) → i < ℓ → Set`, 并沿**证明** `i < ℓ` 的结构递归 (`Ord< i zero = Ord₊ i Ord<`, 隐参数 ℓ 减小). 要推到 Λ, 只有两种递归:

- **(A) 结构递归:** 层号是树 (含 Ω-分支), `j < ℓ` 是结构路径 (`Ordᴵ` 的 `<ᴵ`, `LevelFix` 的 `Gd`/位置, 高度树的 `⊲`). 树族定义不需要良基证明, 但派发要比较两条路径.
- **(B) 可及递归:** 层号是有限项 (码), `j < ℓ` 是 `cmpC j ℓ ≡ lt`, 树族沿 `Acc` 递归. 派发免费, 树族定义要码序在所用码上的 `Acc`.

"只有这两种" 是判断. 本审试过的第三种 (单一类型、分支取同类型) 就是实验 1, 被正性拒绝; "分支取码而不取树" 把 Ω_{c+1} 的分支函数变成 "把码求值成树", 求值要对码递归, 回到 (B).

### 2.3 (B) 的骨架能写 [实验 2], 它的账

`rr3design/RR3AccIdx.agda`, 退出码 0 (6G 堆, 玩具码 `z`/`s`, 玩具 `cmpC`, 层号的 Ω 用 ω 占位). 内容:

- `module Layer (ℓ : Code) (Low : ∀ j → j <ᶜ ℓ → Set)`: `T₊` 四个构造子, `limΩ : (p : j <ᶜ ℓ) → (Low j p → T₊) → T₊`; 通用 `ω`, `lfp`, `_+_` 只看 `T₊`.
- `T c (acc h) = T₊ c (Low c (acc h))`, `Low c (acc h) j p = T j (h p)`: 树族沿 `Acc` 递归.
- `coe : (a a′ : Acc c) → T c a → T c a′`: 跨 `Acc` 证明的搬运, 由对 `T₊` 结构递归的逆变 `mapT` 和对 `Acc` 的递归组成; 不需要 `Acc` 的证明无关性, 不需要 UIP.
- `ψ : (aℓ : Acc ℓ) (ai : Acc i) → T ℓ aℓ → T i ai`: BTBO 的四行; Ω-结点处 `with cmpC j i in e`, `lt` 保留结点 (证据就是 `e`), `gt` 走链 `iter (λ γ → ψ (acc h) (h p) (f γ)) zero`, `eq` 经 `cmp-eq` 取最小不动点. 终止检查通过: 递归都落在子树 `f γ`, `f n`, `x` 上, 与 BTBO 相同.

它证明的只是: **把派发从 "层号的有界三歧" 换成 "码的全序判定", 折叠与树族在类型上成立, 没有任何树上的比较.** 它没有证明的: 码的内容. 账如下 (判断):

1. 作层号用的码要 `Acc`. 终点要的层号是 Λ 之下的一切序数, 即一切 EBO 项; 链点 γ_k 是树, 它们作层号 (Ω_Ω = limΩ_0 (c ↦ Ω_c) 的分支 c 作 Ω_c 的层号) 时要码与 `Acc`. 码序在全体项上**不良基** (`ExBuchholz` 的 `not_wellFounded_lt`, 手册 §2: Ω > ψ₀(Ω) > ψ₀(ψ₀(Ω)) > …), 所以要标准形谓词, 并证 ψ 的输出 (就是基本列) 保标准形. 这正是 `EboLean3` 口径里的良基 487 行与基本列封闭 579 行. **(B) 省不掉记号侧第 3 层.**
2. 层号的 Ω 对极限层要基本列. 两种来源: 层号是 (码, 该码的树) 的对, Ω 对树递归 (`LevelFix` 的 `Ω̂` 三行 `refl` 是先例); 或按码的规则算. 前者不读规则, 但 `Acc` 搬运处要码与树的配对在不同 `Acc` 证明下一致, 这是 `LevelFix.Un` 出现的地方 (那里是依赖对加守卫的反演; 实验 2 的 `coe` 不反演, 判断可以避开, 未写).
3. 码与 `cmpC` 的形状. 要让 ψ₀(t_n) 的值对, 码必须能命名一切层号且 `cmpC` 必须与值一致: 这就是 EBO 的项与 `cmp` (同构意义下; 判断). 它们是自己写的, 不导入 `OCF.Align.EBO`, 纲领 4 的字面满足; 但它们是记号的序的拷贝, 翻译账要如实记.

合计 (判断): 码+比较 ≈ 130, 标准形+良基 ≈ 490, 封闭 ≈ 580, 树族+ψ+Ω+coe+FGH ≈ 300, 前三层 ≈ 1500, 与 `EboLean3` 的 1513 同量级. (B) 相对 `DirectClosed` ("记号+良基性→树") 的差别只有一处: 基本列不是按规则写出再翻译成树, 而是 ψ 在树上算出来, 记号的规则 1–6 变成关于这棵树的**定理**. 这是纲领目标 "树自足" 里能做到的那一半.

### 2.4 (A) 的代价为什么是结构性的 [判断, 带定理旁证]

(A) 之下 ψ_i 对 `T ℓ` 的结点 `limΩ_j` 要判定 j 对 i, 两者都只有到 ℓ 的结构路径. 两条路径在 Ω-分支处分叉, 就要比较两个分支坐标 c, c′ : `T k`, 它们没有公共上界. 对 k = 0 这是 `Ordᴰ` 上的无界三歧; 对 k ≥ 1, `T k` 含 Ω₁ 之上的元, 有界三歧就推出 LPO (壁垒). 仓库里的旁证 [定理]: `Stage2.dec→WLPO` (判定 `a ≺ᴵ suc ωᴵ` 推出 WLPO), `InaccScout.Trich₂→WLPO`, `InaccTree.noBT` (`L₁` 上的有界三歧为假), `Symbolic.Toy.loop` (把 Ω̂ 放进可数层作构造子, 折叠的递归不良基). 本审核对了这四条的陈述; 它们各否定一种具体形状, 合起来支持但不等于 "(A) 的 ψ 不能全定义" 这一判断.

所以 (A) 的 ψ 必须是部分函数: 输入的每个 Ω-结点要带 "它的层与目标的关系" 的证据, 证据随回灌更新 (世界), 并且 ψ 的输出要再带证据 (对 ψ 封闭). 这三件事就是仓库 11 月 4 日以来的全部内容: `⊲[w]`, `cmpB`, `LgB`, `raise`, 拷贝, `UpdS`/`RaiseAt` 一族否定. 进一步, 一个对 ψ 封闭、能回答一切派发的证据类型, 在 Λ 之下的层号上给出一个可判定的全序 (派发就是比较), 可判定全序加有限表示按定义就是记号系统. 这一步没有定理, 是判断; 它可以写成否定定理的形状 (§4 第一条义务).

- **(B) 的树优先写法**: 树族沿 `Acc` 递归、ψ 在树上派发只看码、基本列由 ψ 生成、记号规则作定理. 仓库里 `CodeGuide` §4 的 ✗ 项 "`Lvl = NF`, `i<j = cmpᵀ i j ≡ lt`" 就是它, 标为 "不试, 除非改约束, 设计分岔要作者判断". 没有编译过的文件. 实验 2 是它的类型骨架.

## 4 推荐的方法与第一步

**方法.** 接受 §2 的二分, 选 (B) 作主线, 把 (A) 降为一条只求否定定理的研究线.

**第一步 (一到两周, 判断):**

1. 把实验 2 的玩具码换成真码: `Code` 取 EBO 形 (0, +, ψ_u(a); 或直接用 `EboLean3` 的项类型拷贝到新文件), `cmpC` 取字典序比较, 证 `cmp-eq`、传递性、与 `s`/`Ω` 的几条小引理 (`↑` 要传递性).
2. 层号取 (码, 树) 的对, `Ω` 对树递归 (`LevelFix.Ω̂` 的三行), 不写基本列规则; `↑` 照 BTBO.
3. `T` 沿 `Acc` 递归, `Acc` 由 `EboLean3` 的良基给 (若它的序与第 1 步的 `cmpC` 不逐字相同, 先证序同构, 这是记号侧已有工作的搬运, 不是新数学).
4. 链点作层号时要标准形: 先把需要的闭包陈述写成接口 (`NF (code (ψ_j x))` 对 `NF (code x)`), 用 `EboLean3` 的封闭定理实填; 填不上的地方如实记 "条件".
5. 写出 `ψ₀Λ` 闭项与 FGH, 对 `WfFsn.EBO-tree` 做序数值验收. 由于树的基本列是 ψ 算出来的, 判断验收可以逐构造子对 `Lab` 归纳, 不必另写值理论.
6. 同时派一路否定: 把 §2.4 写成定理 "`T (Ω+1)` 上满足三路等式的全函数 ψ ⟹ WLPO" (或反例形状), 与 `dec→WLPO` 共用开关序列 `sw α`. 它决定 (A) 是否还值得投入.

**预计成本 (判断):** 第 1–3 步 300 到 500 行新代码; 第 4 步取决于 `EboLean3` 封闭定理的接口是否能直接消费, 0 到 600 行; 第 5 步 300 到 800 行. 前三层合计与 1513 同量级, 不会显著更短. 成功率: 写出合法闭项并通过序数值验收, 中高 (依据: 每一步都有先例, BTBO 的 ψ、`LevelFix` 的 Ω̂、`EboLean3` 的良基与封闭, 新东西只有搬运 `coe` 与码树配对); 行数低于 1513 且有余量, 低.

## 6 本设计最可能失败在哪里 (判断)

1. **接受度.** 若作者坚持层号的序必须由树给出, 本报告的推荐就不成立; 那时第一件事是把 §2.4 写成定理 (第 4 节第 6 步), 它要么关掉 (A), 要么给出 (A) 的证据类型必须满足的最弱条件.
2. **标准形封闭.** (B) 的链点作层号要 NF; 若 `EboLean3` 的封闭定理接口不能直接消费 ψ 的输出码 (那里的基本列是按规则写的, 这里是树算的), 要证两者逐项相同, 这是 `Lab` 一档的工作; 做不成就退回 `DirectClosed`, 一切都没有变差但也没有变好.
3. **码树配对与 `Acc` 搬运.** `Ω` 对层号的树递归时, 树与码的对应要在 `coe` 之下保持; 若某处需要 `Acc` 的证明无关或层号相等的 UIP, 就是 `LevelFix.Un` 再现. 实验 2 的 `coe` 不反演任何相等, 判断能避开, 未验证.
4. **值与大数.** `Review2Blind.blindᴬ` [定理]: 序数值相同的两棵树 FGH 可不同. (B) 的树基本列由 ψ 生成, 与 EBO 规则是否逐项相同要单独验收; 若只做序数值, 终点表述要分开 "序数 ≥ EBO" 与 "等于 EBO 的大数" (`RouteReview2` P4).
5. **穷尽.** §2.2 "只有 (A)(B) 两种递归" 是判断. 没试过的: 用 `--guardedness` 的余归纳表示分支函数 (判断: 分支仍要全定义, 不改派发); 把层号的 Ω-分支换成对 `Code` 的分支并把求值写成和 ψ 互递归的 IR (判断: 求值对码递归要良基, 回到 (B)). 下一路应先挑战这一条.
