# 第九次独立审查: 一致折叠的闭项拿到 ψ₀(Ω_Ω·2) 下界的最省办法

2026-11-12. 审查者是 Opus 5.5 的内部子智能体 (作者定). 次序: 先读规则与定义并写下看法 ([预览](Reports-2026-11-12/Review9-preview.txt)), 再读已编译的定理陈述, 最后读回报与台账. 简报与回报原文: [Reports-2026-11-12/Review9.md](Reports-2026-11-12/Review9.md). 唯一的实验 [Review9-R9Same.agda.txt](Reports-2026-11-12/attachments/Review9-R9Same.agda.txt).

## 1 结论

卡住 ψ₀(Ω_Ω·2) 的不是 "没有函数外延就算不出两个 ℕ 极限层号的字面相等". 被问到的那一对位置在同一支里; 用这一支自己的公共上界做结构比较, 这一对就保留, 层号相等由合法性数据 (位置搬运) 算出. 缺口有两处: Ω 结点层号上的派发只拿到 (目标层号, 裸源位置), 不知道这一对在同一支里 (来历丢了); 主线还没有参照框架的树与 `Raw (tw 2)` 的树之间的值关系.

## 2 实验 (主审复核)

`R9Same.agda` (99 行), 主审拷到自己的目录冷编: 退出码 0, 只有它自己的 Checking 行, 禁用构造 0. 都是闭实例上的归约 (有限测试):
- `same-branch-rN`, `same-branch-pN` (`refl`): 那一对的坐标字面相同.
- `kept-in-branch : cmpw (brV V2 η₀ l₀) (inj₁ tt) (inj₂ s) ≡ keep s refl` (`refl`): 在这一支的公共上界里比较, 保留.
- `kept-shifted : IsKeep (cmpw VLN q₁ s)` (`tt`): 目标与源在极限层号的不同分量时, 经位置搬运到同一分量后保留; `shift-eq` 是搬运给出的层号相等.
- `lost-outside = lostP`: 外层派发仍然折叠.

## 3 办法的评估 (审查者的判断)

- (a1) 不改块: 把派发结果里 "保留" 一项要的字面层号相等换成保合法的结构搬运; Ω 结点层号上按目标的支做结构比较. 只改第 2 层, 规模 300 到 450 行. 第一个障碍: 两个只含 zero/suc/lim 的层号之间的逆变搬运, 它的停机与单调性.
- (a2) 改块 (例如 Ω 结点层号上的加法保留嵌入): 一条新主线, 要作者定.
- (b) 不保留, 从更高处补回: 手算认为损失落后一步, 被链的下一项吸收; 依赖层号 0 的根见证, 越过 `tw 2` 以后可能消失 (违背 "闭包定理与阶段无关"). 规模 600 到 1200 行, 不确定.
- (c) RR7 那样的规范化中介不能直接搬: 新派发只看源层号是否字面有限, 对层号嵌入不单调.
- (d1) `T⁺ʷ ≼ TΛ` 没有证: 在 `T⁺ʷ` 上拿到的界还不是 `TΛ` 的界, 需要补这条嵌入或直接在塔的第 3 项的子项上证.
- 三条路都要同一个部件: 参照框架的树与 `Raw (tw 2)` 的树之间的跨层值关系. 建议先把它在小站上做成可复用的引理.
- 按形状能推到的稳妥上沿 (判断): ψ₀(Ω_Ω+Ω_{ω+1}); 第一处不一致大约在 ψ₀(Ω_Ω+Ω_{ω+2}) (链上) 或 ψ₀(Ω_Ω+Ω_{ω+1}²).

最便宜的决定性实验 (建议): E2, 在两个只含 zero/suc/lim 的层号之间写树的搬运与逆搬运, 证保第一位置, 保合法, 停机; 编得过则 (a1) 没有技术障碍. E2′, 证新派发下折叠输出里每个 Ω 结点的层号字面有限或是根见证.
