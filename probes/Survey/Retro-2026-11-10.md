## 0 对纲领与目标意味着什么

1. **强度没有动.** 记号无关的树侧, 序数值互相 ≼ 的最高点仍是 ψ₀(Ω_{Ω·ω²}) (`EmbVVInstO2.vv-ω²`). 乙线自己的折叠只到目标层 0 上的 Ω₁ 算术, 值下界 ψ₀(Ω₁·ω), 远低于 ψ₀(Ω₂). 三天里乙线相关的新文件约 180 个, Agda 代码约 12800 行 (§1), 而完整 EBO 参照树的前三层是 1513 行.
2. **有一条实在的进展, 它是证书, 不是闭项.** 派发证书 `Carry⁺` 对规范 Ω 塔的每一层与 Λ 成立, 由一条对树结构的归纳得到, 不按阶段加前提. 这是乙线第一条一直到 Λ 的阶段无关定理. 它不含 ψ, 也不说 Λ 的值.
3. **多数轮次处理的不是折叠的数学.** S3 第 9 轮以后约 20 轮里, 失败几乎都来自两处: 原块的合法性接受退化结点 (§3.2), 以及没有外延时的字面相等 (§3.3). 真正的数学障碍 W (没有公共上界就不能比较层号) 只在 S3 第 8 到 10 轮正面碰过; K 轮只做了目标层 0, 那里没有三路派发, 也没有回灌.
4. **对 "让树自足".** 合法性一侧有进展: 证书的每个字段都只读树的结构. 折叠一侧没有: 四行的形状仍照 EBO 的规则模板, 链的写法是作者按 D10 认可的改写. 所以现在能说的是 "树侧有了自己的合法性标准的雏形", 不能说 "不看记号就能写出下一步的定义".
5. **下一步的次序 (判断).** 先处理字面相等这一处 (§5.1), 再做第一次回灌 (§5.2). 回灌是乙线从未做过、而以前各条线都停在附近的一步; 它越早做, 这条线值不值得继续就越早有编译事实.

## 2 确立了什么

### 2.1 层号与证书 (定理)

- **层号到 Λ.** 合法树作层号, x ↦ Ω_x 沿结构递归, 闭包到 Λ (`LevelFixVal.Legal-Ω̂`, `Legal-Λ`; 这是原块已有的).
- **同界可比.** 同一合法界下, 两个字面第一位置三路可比 (`YiLevelCompare.bounded-compare`).
- **保留结点的派发证据.** 字段层满足 `Reg` 时, 已确定保留的结点的第一支与全部合法坐标都有派发证据, 目标只需合法 (`YiRegCover.all-retained-reg`).
- **证书对塔与 Λ.** `YiK1b.k1′ : K1′` (即 ∀ n → Carry (tw n) 与 Carry Λ); 增补后的 `YiCarryPlusInstances.tower-carry⁺`, `limit-carry⁺`. 任意层的带证书起点 `YiCarryPlus.seed⁺`.
- **读回保持 (条件定理, 前提有实例).** `YiCarry.guard-read-carry`: 给定 Reg y, Below y (Ω̂ y), Carry (Ω̂ y), 则 y 处一切带 `LglB` 的合法守卫坐标的读回满足 Carry. 实例在 `YiCarryExamples` (k = 0 与 k = tw 2). 层号取 tw 3 时读回再取 Ω̂ 仍带证书 (`YiCarryNeg2Read.tw3-read-target`).

### 2.2 折叠的片段 (定理)

- **可数部分.** `YiK2Base.ψᶜ : Raw 0 → Raw 0` 保持合法 (`ψᶜ-legal`) 与第一位置 (`ψᶜ-cp`).
- **gt 行的链.** ηₙ₊₁ = ηₙ + ψᶜ(body ηₙ), 增长由 "ψᶜ 的输出为正" 给出, 不比较 (`Chain.chain-grow`); 输出合法 (`collapse-legal`). 链点带 `LglB` (`YiCarryBounds.ChainB.next-B`, 规范链的实例 `YiCarryExamples.canonical-chain-B`).

## 3 诊断: 四件事被混在一起 (判断, 依据逐条给出)

### 3.1 W: 没有公共上界就不能比较层号

这是数学障碍 (`Barrier.barrier` 及其影子). 乙线对它的回答是: 判定型证据只在公共界下用, 其余用单向的结构证据 (子树路径 `Below`, 只给 "保留"), 证据随构造携带. 支持这一回答的定理是 `bounded-compare`, `all-retained-reg` 与证书对塔的闭包. 它还没有在带回灌的折叠里用过.

### 3.2 退化结点: 原块的合法性过宽

原块 `LevelFixCore` 的设计原则写在它的文首: "块里没有证明", 结点的下界 "是原始的值, 不带证据, 所以 Ω 总有定义". 后果是 `Legal` 接受下面这些对象, 而各轮的反例几乎都取自它们:

| 来源 | 反例对象 | 性质 |
|---|---|---|
| S3 第 9 轮 `no-next-ev` | 分支全为 0 的 Ω 结点 | 直接造的层号, 不是读回 |
| S3 第 10 轮 `no-omega-preservation` | 常零极限的后继 | 不是任何合法坐标的读回 (`x-not-coordinate`) |
| S3 第 11 轮 `no-reg₂-Ω₁` | 规范 Ω₁ 分支域里的常值极限 | 失败的是新加的严格性, 不是 `Reg` |
| D7 `no-rule-preservation` | 常值 Ω 分支的结点 | 值是对的 (`same-value`), 失败的是严格性 |
| D7 `no-omega-two` | Raw 里的常值 Ω 分支 | 平行块两处定义不一致 |
| D7 `no-faithful-preservation` | 分支在种子处取 0 | 链不增长; 链增长时同一输出合法 (`growing-output-legal`) |
| K2 `no-start-all` | 下界 lim (1, 0, 0, …) 不合法, 守卫域为空 | 退化结点 |
| `no-carry-Ω₂` | 规范 Ω̂ 2 分支域里下界同上的坐标 | 对退化坐标提了要求 |
| `no-K2′` | 下界里嵌着坏下界的高层结点 | 接口对一切带证书的源量化 |
| `funext-fold-tree→wlpo` | 下界编码一个布尔序列的结点 | 空守卫域的结点 |

每条否定都逼出一个字段或一次收窄: 位置字段, 下界合法, 嵌套下界, 只对带证据的坐标递归. 它们合起来就是 "一个结点是良构的" 的定义, 并不是折叠的数学内容. AGENTS 把 "用否定定理划出不能有的字段" 列为提供信息的标志; 这里要加一条限定: **反例对象若不在规范构造的读回域内, 这条否定说的是谓词太宽, 不是数学**. 一个太宽的合法性谓词可以无限地产出这样的否定.

反过来的事实是: 只对带证据的对象提要求时, 至今没有出现反例. `Ω₂-reg`, `tw3-reg`, 全塔与 Λ 的 `Carry` 和 `Carry⁺`, tw 3 上的读回保持, 规范链的增长与合法, 都成立.

### 3.3 字面相等: 没有外延时证明成了数据

原块的位置关系是字面的: `Cp` 的自反情形是 `≡`. 而 Carry 证书是树外另带的数据. 读证书的 ψ, 输出里会留下证书的痕迹; 位置保持在自反情形要求输出字面相等, 于是要求换证书后输出不变, 一直传到极限函数的相等 (§2.3 第五行). 不读证书的 ψ 又调用不了分支: 起点的守卫要用 Lgl k c, 这一项只在证书里; 在有 Funext 时, 这样的 ψ 推出 WLPO, 用的仍是空守卫域的退化结点 (§2.3 末行).

同一个根在这个仓库里出现过三次以上: `Legal` 里的 `irr` 字段 (分支不依赖守卫证明); D7 处理的相邻自反步; 更早 LevelFix 的 `Un` (2026-11-04 由 `LevelNoK` 在编码上消掉). 另一条线的处理办法也在仓库里: `Level` 族不用字面相等, 用逐点的结构互模拟 ≅, 并证明 ψ 保持它 (`Level.ψ-≅`, RR4 冷编过 `Level`, 主审本轮没有重跑).

### 3.4 V: 折叠不是值的函数

这是第 4 层的障碍. RR4 说明下界不需要值同余, 逐点前序在第 1 层够用 (`pointwise-mono₁`). 主审在 §5.9 把 §3.2 的现象错归到这里 (§4 第 1 条).

### 3.5 一个预测 (判断, 未验证)

目标层不为 0 时, 低于目标的结点要保留, 输出结点的分支函数要对分支域里的每个坐标定义, 也就是对每个合法守卫坐标 η 调用 ψ(g η e). 证书只在 η 带 `LglB` 时给出分支的证书, 而守卫 `Gd` 不推出 `LglB`. 所以保留行会要求守卫本身带上证据, 即改 `Gd`, 而 `Gd` 进了 `lc` 的类型, 这就是一个平行块. K 轮没有碰到它, 只因为目标层 0 没有保留行. RR4 §4.5 已经预见这一分支: "证据须进守卫, 转去查正性".

## 5 出路评估 (判断)

### 5.1 先决的一步: 怎样处理字面相等

| 办法 | 做法 | 依据 | 代价与风险 |
|---|---|---|---|
| (a) 证据进树 | 平行块: 结点内在地带下界合法与嵌套下界, 分支域只取带证据的坐标; ψ 只读树 | 证书的字段已由否定逐个定出, 规范塔满足它们; §3.5 的保留行也要求它; 主线差树 "合法性由形状给出" 是先例 | 反转原块 "块里没有证明" 的设计; 正性检查可能拒绝 (`LevelFixCore` 文首的 P1); 树里有了证明项, 树的字面相等会牵涉证明项的相等, `Un` 一类问题可能回来; 塔与 Λ 的定理要在新块上重证. YiIntr 正在侦察 |
| (b) 结构等价 | 位置关系的自反情形由 `≡` 换成逐点的 ≅; 证书一致性对 ≅ 归纳可证, 不要外延 | `Level.ψ-≅` 是仓库内的先例 | 同样是平行块, 另加层间搬运 (`Level` 文里的 `tr`); 不去掉退化结点, §3.5 仍在 |
| (c) Funext 作前提探路 | 在标明 "条件" 的探路文件里以 Funext 为模块参数, 把读证书的 ψ 写完, 直接去试第一次回灌 | 把 "Agda 的相等" 与 "折叠的数学" 分开; 成本低 | 结论只算条件, 不进成品; 交接文档的停止条件写着 "需要 Funext 就停下报告", 所以要作者明示许可 |

主审的看法: (a) 是主方向, 前提是 YiIntr 的骨架过得了正性检查; (c) 值得并行, 因为它最快告诉我们回灌这一步在数学上通不通; (b) 作 (a) 被正性拒绝时的后备. 若 (a) 过了正性但 `Un` 回来, 则 (a) 与 (b) 要合用.

### 5.2 决定性的一步: 第一次回灌

对层号为 1 的结点做 gt 行: 链点在 Raw 1 里, 下一点要用目标层为 1 的折叠的输出. 这需要 (i) 目标层非 0 的折叠, 因而有三路派发与保留行; (ii) 输出直接生成为坐标, 带守卫与证书. 历史上 C 线停在 "保留结点对任意坐标递归" 与 "回灌必须合法化" (`NegThirdPre.keep-req`, `NegLHRecIf.fb-must-legalize`), 乙线五轮停在事后检查输出的合法性. 携带证据的组织正是针对这两处的, 但这还只是判断.

建议: 这一步照配对的做法派, 一路构造, 一路对同一接口写否定; 并事先约定止损 (§5.4).
