## 0 结论先行

1. **终点的最省义务链只有四项** (§2): (O1) 一个 `Cd` 闭项 `T` 通过检查器; (O2) 定义里经过的每个非布劳威尔树的中间类型有纲领 1 的内部 View; (O3) `TerminalFoldAccept.reference ≤ᵛ T`; (O4) `T` 及其证书的导入闭包无记号模块. 不在义务链里的: 1513 行标杆, "让树自足", 互相 `≼`, 中间站的界, `Lab`, 基本列一致, FGH 的大小比较. 这些都是数据, 不是终点.
2. **最省的证明形状是 "一步支配的解释" [实验 `RR3BackwardCover.Cover.terminal`, 退出码 0].** 任给第 4 层的解释 ι : 记号项 → `Cd`, 只要 ι 在后继处与 ω-共尾处各满足一条一步不等式 (`hs (ι (pred t)) ≤ᵛ ι t`, `ι (fsn t n) ≤ᵛ ι t`), 并且 `T` 盖住 `ι (EBOψ k)` 对一切 k, 就有 `reference ≤ᵛ T`. **不需要** ι 保序, 不需要记号的良基证明, 不需要 `NF`/`Ctbl`/`G`-集, 不需要比较记号项, 不需要任何中间站. 良基性由 `Cd` 是归纳类型这件事免费提供. 这比 `EboLean3` 的参照树 (1513 行, 其中良基 487 行, 封闭性 579 行) 少掉整个良基与封闭性义务.
3. **证明形状反过来要求 `T` 有什么 [判断, 每环标档]:** ι 要忠实于值 (§3.3), 所以 ι(ψ_u(b)) 必须经由树侧一个按层号 u 索引的折叠 Ψ_u; 规则 6 的 γ-链要求 Ψ 在 ι 的像上有 "链支配", 这只有两种已知做法: 链逐项相等 (那就是翻译, `AccTreeLab.Lab≅tree` [定理]), 或 Ψ 在生成域上的受限值单调 (RouteReview2 的 R2; `Value.ψ⁰-not-cong`, `TpPort2Tab.no-valmonoT⁺` [定理] 说明不受限的版本是假的); `T` 要含树侧 Ω-塔的对角, 所以层号类型要对 x ↦ Ω_x 封闭到 Λ. 壁垒 (`Barrier.barrier` [定理]) 禁止的只是 "带 `Ordᴰ` 精确初始段、含 Ω-共尾元、有有界三歧" 的层号类型 (§3.4), 它不禁止层号到 Λ, 只禁止按值比较它们; 于是层号之间只能按字面位置比较 (`CRwBase.cmpB`, `StallDxBdec.bdec` [定理]), 折叠输出要作层号就要带位置证据, 这正是六路都撞到的 W 墙与拷贝墙 (`StallDiagnosis`). 这条链每一环都已有仓库里的编译事实对应, 本文的新内容是把它们倒着串起来: **卡点不是工程选择, 是终点证明形状逼出来的, 任何满足四条纲领的路线都要过同一关 (判断).**
4. **四条非常规路径的判断 (§5).** (i) 从记号机械抽树: 按纲领 4 的字面 (不 "引用") 可以做到, 代价约 1420–1513 行且今天就有 (`DirectClosed`, `EboLean3`); 但它的 ℕ-极限相邻项不是字面第一位置, 过不了纲领 1 解释里的 View, 而且 `Lab≅tree` 说它就是记号本身. 这是**作者裁决项**, 不是定理否定. (ii) 沿 `EmbVV`/`TotalValue` 往上: 每站都要新脚手架 (`CrossNext` α ≥ 1 估 1 万行), 到 EBO 有无穷多站, 所以只有阶段无关的一步定理才可能走到; `TotalValue` 的 "跨层回收" 正是在找这条一步定理, 风险集中在 R2. (iv) 其它: 把一切 Ω-共尾分派压进单一 ℕ-序列 (归档 `Higher`) 不越出壁垒前提, 但 `Barrier` 末节记录它不超出单序列编码所及, 社区估计只在 ψ₀(Ω_Ω) 与 ψ₀(Ω_{Ω+1}) 之间; "不经折叠" 的直接构造在证明时仍要折叠 (§5.4).

## 3 倒推: 最省的证明形状, 它逼出什么

### 3.1 实验: 一步支配的解释就够 [实验]

文件 `RR3BackwardCover.agda` (scratch 目录 `rr3backward/`, 选项 `--safe --without-K --cubical-compatible --guardedness --hidden-argument-puns`, 无公设、洞、停机或正性指示、`trustMe`; 编译 `agda --library-file=<scratch>/rr3backward/libraries -i src -i probes -i <scratch>/rr3backward <文件> +RTS -M6G -RTS`, 退出码 0, 只重新检查本文件, 依赖都取已有接口). 陈述:

```
module Cover
  (ι     : T → Cd)
  (ι-suc : ∀ t → cof t ≡ c1 → hs (ι (pred t)) ≤ᵛ ι t)
  (ι-lim : ∀ t → cof t ≡ cω → ∀ n → ι (fsn t n) ≤ᵛ ι t)
  where
  cover    : ∀ {t} (h : HC t) → read (E.tree h) ≤ᵛ ι t
  terminal : ∀ {X : Cd} → (∀ k → ι (EBOψ k) ≤ᵛ X) → reference ≤ᵛ X
```

证明是对 `HC` 推导的三行结构归纳 (`z≤`, `s≤s` + `≤ᵛ-trans`, `l≤`). 它说的是: **终点 (b) 的全部内容, 等于给出一个值忠实的解释 ι 和两条一步不等式**. 它不需要:

- 记号的良基证明 (`EboLean3Omega.wf`, 487 行) 与封闭性 (`EboLeanClosure`, 579 行): 参照树的良基由 `HC` 推导携带, `Cd` 自己是归纳类型;
- `NF`, `Ctbl`, `G`-集, `cmpᵀ`: 前提只量化 `cof t ≡ c1`/`cω` 的项, 哑值处的 ι 随意;
- ι 保序或是嵌入; 只要一步支配;
- 任何中间站: `terminal` 对 k 直接归纳, 没有 "ψ₀(Ω_{Ω·2}) 站" 这种东西.

它也**不**降低难度本身: 取 ι = `read ∘ tree ∘ hc` 则前提平凡, 结论回到原义务. 它的价值是把难度**定位**: 一切都在 ι 的定义与两条一步不等式上.

### 3.2 ι 必须忠实于值 [判断, 有一行定理依据]

ι 不能偷懒: 若 ι(t) 不随 t 增大, `ι-suc` 在后继处就要 `hs x ≤ᵛ x`, 与 `≤ᵛ` 的严格性矛盾 (TotalValue 的反向界否定已用到 "值严格序对全部 `Ordᶜ` 反自返" [定理]). 所以 ι(t) 至少要随 t 的后继严格增长, 实际上要 |ι t| ≥ |t|. 于是 ι 必须按项结构递归: ι(x + a), ι(Ω_u), ι(ψ_u(b)).

### 3.3 ι(ψ_u(b)) 逼出树侧按层号索引的折叠, 规则 6 逼出链支配 [判断]

- ι(ψ_u(b)) 要定义成某个树侧运算作用在 ι(b) 上; 记作 Ψ_{ι_L u}(ι b), 其中 ι_L : 项 → 层号类型 L, ι : 项 → 第 (ι_L u) 层的对象. 这就是 "折叠". 不经折叠的替代 (§5.4) 在证明时仍要它.
- `ι-lim` 在规则 6 (`EboLeanDef.fsnc … gt`: ψ_u(b)[n] = ψ_u(b[γ_n]), γ₀ = Ω_ν, γ_{k+1} = ψ_ν(b[γ_k])) 要求 Ψ_u(ι b) ≥ Ψ_u(ι(b[γ_n])) 对一切 n. 树侧 Ψ_u(Ω-极限 g) 的定义 (BTBO `ψ<` 的 `injᵇ` 分支与各路线的同形物) 是 lim_n Ψ_u(g(γ′_n)), γ′ 是树自己的链. 于是要 ι(b[γ_n]) 与 g(γ′_n) 可比, 归纳到 ι(γ_n) 与 γ′_n 可比, 再归纳到 **Ψ_ν 在这些输入上值单调**. 两种已知出路:
  - 链逐项相等 (ι(γ_n) 字面就是 γ′_n): 树的基本列与记号一致, 即 `Lab`; `AccTreeLab.Lab≅tree` [定理] 说这样的树 ≅ 记号良基证明翻译出的树. 这是路径 (i).
  - 受限值单调: Ψ 在 ι 的像 (生成域) 上单调. 不受限版本是假的: `Value.ψ⁰-not-cong` [定理] (两个同值的高层参数, 折叠后值不同), `TpPort2Tab.no-valmonoT⁺` [定理]. RouteReview2 的 R2 说 "一切值的结果汇聚于一条未证的单调引理"; `EmbVVInstO2.vv-ω²` [定理] 之所以能到 ψ₀(Ω_{Ω·ω²}), 是对具体行把链对齐 (文件头: "链行第 0 项换成 … 其余逐项对上"), 即在实例上做了第一种出路. `TotalValue` 的 "非零参数 1 的跨层回收" 是在原生成域上做第二种出路的第一步.
- `terminal` 的前提 ∀ k, ι(EBOψ k) ≤ᵛ T: T 要含 (或支配) 树侧 Ω-塔的对角. 所以 L 要对 x ↦ Ω_x 封闭到 Λ, 且 Ω_x 对 x 是**层号的函数**, 不是逐站手写. `LevelFixVal.Ω̂`, `Legal-Ω̂`, `Legal-Λ` [定理] 已有这一形状.

### 3.4 壁垒挡住什么, 不挡什么 (读定理陈述)

`Barrier.Ω-Extension` 的字段: 类型 I, 严格序 (传递、非自反), `ι : Ordᴰ → I` 严格保序, **精确** (`z <ᴵ ι (lim f) → Σ n. z <ᴵ ι (f n)`), 一个 `top` 在整个像之上, **有界三歧** `a <ᴵ c → b <ᴵ c → a <ᴵ b ⊎ b <ᴵ a ⊎ a ≡ b` (内涵等号). 结论 `LPO` [定理 `barrier`]. 末节自述未证: "任何折叠都必须按有界三歧派发" 是范式的定义, 不是定理.

对义务链的后果:

| 设计 | 是否落入前提 | 依据 |
|---|---|---|
| 层号类型含 Ω 作为元素, 且 Ψ 按层号的值序三歧派发 (BTBO 的 `<-dec` 推到 `Ord 1` 以上; 归档 `Ord1D/SpikeA2`, `Kovacs/Base2`) | 是 | `Naive.naive-barrier`, `¬naive-trich` [定理]; `Barrier` 末节的覆盖表 |
| 层号按**字面位置**比较, 只在同一合法界之下 (`CRwBase.cmpB : a ⊲[w] L → b ⊲[w] L → LgW w → LgB L → …`, `StallDxBdec.bdec`) | 否: `⊲` 是位置关系不是值序; `LgB` 把一个界之下的位置集做成链; 不存在一个合法界把整个 `Ordᴰ` 的像都放在下面 (ω 与 ω⁺_α 在 `Ordᴰ` 里没有公共上界, DecZero `TheoriesNoRawCommonBound` 与 `Barrier` 补记) | 陈述对照 [判断] |
| 把一切 Ω-共尾分派压进单一 ℕ-单调序列 (归档 `Higher.ψ<Ω` 用 `<ᴺ-dec`) | 否 | `Barrier` 末节: "没有违反定理 1, 而是绕开了前提"; 同节: 不超出单序列编码所及 |
| 不派发的算律折叠 (归档 `PastBTBO/SMB`) | 否 | 同上; 实际强度未算, 判断远低于 BTBO |

所以壁垒**不**挡 "层号到 Λ"; 它挡的是 "按值比较层号". 由 §3.3, ι 需要 Ψ_u 在 Ω-极限处按链点取值, 链点是折叠输出, 输出要作下一个链点的坐标, 坐标要能与节点自带的界比较; 不能按值比, 就只能按位置比, 输出就必须带 "它是当前界之下的位置" 的证据 (`HS`/`toLevel`, `Bd`). 这就是 AGENTS 交替路线的 "折叠输出回灌作下标, 被比较的两个下标必须有字面的公共上界" 的来源; 同一个 ordinal 在不同位置出现, 就是拷贝 (`StallDiagnosis` §2.4). **倒推的结论 (判断): W 墙与拷贝墙不是某个架构的失误, 是 "按位置比较 + 规则 6 的链" 的必然代价, 任何按纲领 1–4 走的候选都要正面回答 "折叠输出怎样成为合法位置" 这一问.** `StallDiagnosis` §3.2 已把它定位到 `sup`/`Lev` 两个自由选择上; 本文补的是: 自由的是实现, 问题本身不自由.

## 5 四种非常规路径

### 5.1 (i) 从记号侧的 EBO 参照树 "抽出" 不引用记号的树

**现状.** `DirectedViewDirectClosed` [定理 `full-EBO`, `fgh-reference`]: 沿良基证据直接生成树, 与参照双向同值, 执行切片 1420; `TreeEmit` 在树侧实例上做了同样的保值改写 (+132 行). 两者导入闭包都含 `EBO`.

**纲领 4 的边界.** 纲领 4 的字面是 "不引用记号的项、序或基本列". 把 EBO 的文法、`<ᵀ`、`fsn`、`NF` 原样**重新声明**为树侧模块 (不导入 `OCF.Align.EBO`), 树 = Σ (t) (NF t × Ctbl t) 带 `HC`, 导入闭包就干净. 这不是引用, 是抄写. `CodeGuide` §4 的 ✗ 项 ("`Lvl = NF` … 违反 … 这是设计分岔, 要作者判断") 已经把它标为作者裁决项. 本文同意它是裁决项, 不是定理否定.

**纲领 1 解释的障碍 (这是实质).** 作者解释要求中间层的 ℕ-极限 "相邻项按目标树自己的合法性步进, 即第一位置". 对记号层, t[n] 一般不是 t[n+1] 的子位置 (ψ₀(Ω)[n] = ψ₀(γ_n) 与 ψ₀(γ_{n+1}) 互不为子项); 要过 View 只能把 "合法性步进" 读成 "按可判定序 t[n] <ᵀ t[n+1]". 作者写 "即第一位置", 本文读作排除这种读法 [判断]. 另外 `Lab≅tree` [定理] 说过 `Lab` 的树 ≅ 记号的翻译; 差树主线的 ℕ-极限是部分和 (`f n ⊲ f (suc n)` 由形状给出), 正是为了满足第一位置, 代价是基本列与记号不同、只能做值验收. 这两件事合起来: 路径 (i) 满足纲领 4 的字面、终点 (a)(b), 不满足纲领 1 的解释; 若作者把解释放宽, 它今天就完成, 代价 ≈ 1420–1533 行, 并且 "让树自足" 目标被明确放弃 (树就是记号).

**成本与风险.** 成本最低 (已编译). 风险是纲领性的, 不是数学的. **可核对的第一步:** 向作者提一个是非题: "ℕ-极限相邻项之间的 '合法性步进' 是否允许是可判定序而非子位置". 否, 则此路关闭 (纲领否定, 非定理); 是, 则直接提取 `EboLean3` 的文法与 `wf` 到新模块, 里程碑是 `importclosure` 禁用 0 且 `reference ≤ᵛ T` 由 `read` 的 `≤ᵛ-refl` 给出.

### 5.2 (ii) 沿已有高值资产往上延伸

**现状.** `vv-ω²` 到 ψ₀(Ω_{Ω·ω²}) [定理]; `RouteSeal` §1 记下一站 ψ₀(Ω_{Ω²+1}) 要 `CrossNext` α ≥ 1 的闭包定理约 1 万行 (估计); `TotalValue` 在改值简化后的候选上证到 ψ₀(Ω_Ω)+ω ≤ |closed| [定理], 并在做任意参数的跨层回收.

**真实成本 (判断).** 从 ψ₀(Ω_{Ω·ω²}) 到 EBO 中间有 Ω², Ω^ω, Ω^Ω, Ω_Ω, Ω_{Ω_Ω}, … 无穷多类站. 按站做, 每站 1 万行量级, 不会终止. 唯一可能终止的形状是 M5 的一步定理. `TotalValue` 的 "任意 η 的遗传生成域与搬运/折叠保持" 正是它; 其早期信号: 若 "参数 1" 到 "任意 η" 的推广需要为每个 η 的形状另写一段 (例如按 Ω̇ 的行分类), 这条路就退回按站做. 现在的 `TotalValue` 定理表已按参数 1 与 "任意 η" 分开陈述, 本文建议: **先写任意 η 的陈述为接口记录, 再填**, 不先填参数 2.

**壁垒.** 此路的坐标是 `Ordᴵ`/世界, 比较都在字面公共上界之下, 不落入 `Ω-Extension`.

**里程碑.** (1) 接口: `GenRecover : ∀ η → <生成域> → <跨层回收>`; (2) 条件定理: `GenRecover → reference ≤ᵛ closed` 经 `Cover`; (3) 填 η 任意. 早期失败信号: (2) 写不出 (说明 M4 在该候选上无法定义, 即候选的对象类型装不下 ι 的像, 与 `SkeletonAudit` 的 `Ht` 封顶同类), 或 (3) 需要 `Funext`/UIP.

### 5.3 (iii) 归纳-递归直接定义层号与 Ω_x 的树族, 不经逐站折叠

**现状.** 这正是 `LevelFix` (判决 PARTIAL): `data LF` 含 `lc : (k : LF) (c : Raw k) (t : LF) (g : (η : Raw k) → Gd k c η → LF) → LF`, Ω̂ 的三行 `refl`, `Legal-Ω̂` 对一切层号一步, `Legal-Λ` [定理]; `LevelNoK` 去掉了 `Un`, `ψ₀Λ : T⁰ 0` 是无参数闭项 [定理], 但类型是 "带待计值符号的数据树, 还不是序数", 正确性只有有限测试. `RouteSeal` §5 的第一个障碍: ψ₀(Ω_Ω) 处证书要字面 `Lgl`, `NoKCertNeg.no-HS→Lgl` [定理, 前提可满足] 说由 `HS` 读成下标过不了 `Lgl` (反例: ω 与 ω′ = lim(n+1) 同构但不字面相等). 封存记录自己写: "差树的 '合法性由形状给出' 可能正好补上这一步, 重开时先试把 `LF` 的折叠换成和的作用".

**倒推下的评价 (判断).** M1 在这里是现成的, 且是四路里唯一把层号封闭到 Λ 的; M2 的障碍 (`no-HS→Lgl`) 与差树主线已经解决的问题同形 (`LgB` 的 `hl` 分支由部分和给出字面第一位置). 两者在仓库里从未接过. 这是**现有资产离义务链最近的组合**. 风险: `LF` 的 `lc` 节点以 `Raw k` 为坐标, `Gd k c η` 是字面第一位置守卫, 它是否会在 Ω-极限处重现拷贝墙 (`CohWNeg.no-cross` 一族), 没有定理; `LevelFixNeg` 的 `no-Lgl-Ωlim`, `no-cp-Ω3-Ω2` [定理] 划了两条边, 重开前先读.

**壁垒.** `LF` 的比较是守卫 `⊑̂` 上的, 不是值序; `Barrier` 不覆盖. 要核对的是 `LevelNoKLv` 的比较接口是否对裸 `Raw k` 量化 (`StallDiagnosis` 的 W 墙), 本文没有读到那一层.

**里程碑.** (1) `Lgl-from-shape : ∀ y → <差树形状> → Lgl k (rd y)` 替换 `no-HS→Lgl` 的前提 (这是封存记录自己的第一步, 估一两天); (2) `LevelNoKFold.ψ₀Λ` 计值到 `Cd` 并给 View (M3); (3) ι_L : T → LF 按记号项递归, 先只证 `ι_L (Ω-塔 k)` 与 `Ω̂^k` 的关系 (M4 的一半, 不碰对象层); (4) `Cover` 条件定理. 早期失败信号: (1) 需要 UIP/`Un` 回来; (3) 需要对 `Raw k` 的裸相等判定.

### 5.4 (iv) 其它路径

- **(iv-a) 单 ℕ-序列编码分派** (归档 `Higher`, `HigherGen`): 不落入壁垒前提, 社区估计 ψ₀(Ω_Ω) < 值 < ψ₀(Ω_{Ω+1}) (`Higher.agda` 注释, 非定理). `Barrier` 末节的结构观察: 不派发或单序列派发不超出单序列编码所及. 在义务链上它对应 "L 没有 Ω 以上的元素, 用对象层对角代替", 这与 AGENTS 交替路线的第一句相同, 差树主线已经是它的推广. 不作为独立路径.
- **(iv-b) 树侧 "突出集"** (`CodeGuide` §4 待试 #3, #5: 对 EBO 项写 W_u 式良基): 若对象是树侧文法, 它就是 (i) 的另一件外衣; 若对象是记号, 它是记号侧第 3 层 (已由 `EboLean3` 完成). 不是新路径.
- **(iv-c) 不经折叠的直接构造** (如 `RadicalValueOrbit` 的算子闭包 J^n, 已证 ≥ ψ₀(Ω_Ω) [定理 `named-lower`]): 定义可以不提折叠, 但 (b) 的证明按 §3.3 仍要 ι(ψ_u(b)) 的树侧对应物, 也就是折叠; 对纯可数算子闭包, ι 在 Ω_{Ω} 以上的项处没有东西可映 (判断: 可数算子的闭包不含层号, 规则 6 的链无处放). 它能给 BTBO 量级下界, 不能给 EBO 下界, 除非把它扩成 M2.
- **(iv-d) 换终点证明形状**: `sampled` 允许错位取站, 但 ι 仍要值忠实 (§3.2), 所以不省掉 M4/M5. 另一种是不用 ι, 直接对 `HC` 推导做 "参照树嵌入候选树的子位置" 的构造 (嵌入而非值比较): 这要候选的子位置集包含参照树的全部节点, 即基本列一致, 退回 `Lab`. 本文没有找到第三种形状 (**穷尽是判断**; 下一路先挑战它).
- **(iv-e) 本文推荐的 "先写条件定理"**: 不是路线, 是判定工具, 见 §6.

## 6 推荐与里程碑 (判断)

**第一步 (一周内, 不选路线): 把 R2 从判断变成带定义域的陈述, 并对三个候选各出一条条件定理.**

1. 在第 4 层新文件里, 以 `Cover` 为模板写记录 `ChainDom`: 对树侧折叠 Ψ 与解释 ι, 规则 6 所需的链支配, 律里每对坐标带字面公共上界证据 (AGENTS "律带公共上界"). 这一步只是写类型, 不证.
2. 对 `LevelNoKFold.ψ₀Λ` (iii), `RadicalValueNativeFinal.closed` (ii), `HtFeedClosed.TΛ` (差树主线) 各写 `ChainDom → reference ≤ᵛ T`. 能写出的候选说明其对象类型装得下 ι 的像; 写不出的, 失败点就是该候选的类型封顶 (`SkeletonAudit` 的方法), 这是编译事实而非读法.
3. 对能写出的候选, 派构造与否定配对去填 `ChainDom` (共用接口文件). 否定若成立, 要写成 "此候选的 Ψ 在 ι-像上不链支配" 的定理, 这才是第一条真正否定某个候选到不了 EBO 的定理 (目前没有任何候选被这样否定过).

**第二步按结果选路.** 预期 (判断): (iii) 最可能过第 2 条, 因为它的 L 已到 Λ; (ii) 的 `TotalValue` 候选对象类型是 `Σ Cd LgB`, ι 的像要经 `leg` 完成, 第 2 条可能卡在 "ι(Ω_u) 在 Cd 里没有对应物" (那就是 `Ht`/`Cd` 封顶的精确版本). 若 (iii) 过, 投入 §5.3 的里程碑 (1)(2); 若都不过, 回到 M2 重新设计, 并以 `ChainDom` 为设计约束 (从终点倒着选类型, 与 `SkeletonAudit` §4 的建议一致).

**并行的作者裁决项.** 路径 (i) 的是非题 (§5.1). 它不占编译资源, 但决定 "让树自足" 是否仍是目标.

**早期信号汇总.** 需要 `Funext`、UIP、`Un` 回来; 律对裸坐标量化 (`upd→wdec` 族会再现); 每个 η/行要单独一段证明 (退回按站); ι 的像类型要随 k 改变 (封顶). 任何一项出现, 停下写否定, 不硬攻.
