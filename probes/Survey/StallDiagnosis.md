> **结论先行.**
> 1. 六条否定各自都对, 前提都可满足, 范围都写明了; 但它们**全部是同一件事的六次重证**: 世界更新的接口对**不带字面公共上界**的下标陈述 (`at`/`off`/`r-sub`/`find`/"自选"), 于是每条都把 "对不可入的两个下标判等" 写了出来, 这正是手册 §3.1 的影子. 这不是壁垒定理的推论 (前提里没有序, 没有 `Ordᴰ` 初始段, 没有 Ω-共尾元), 是同族影子; 它与壁垒的关系最好的说法是: **壁垒逼出了 "比较要字面公共上界" 这条规则, 六路把它用在了坐标与层的比较上, 却没有用在世界的更新上.**
> 2. [实验] 在同一个合法高度 $L$ 的同一个合法世界里, 两个字面第一位置 $a,b$ 的相等**可判定** (`StallDxBdec.bdec`, 构造的, 只用 `cmpB` 与子项良基). 所以对**可入的**下标, 各否定的结论本来就是定理, 不是禁忌; 各否定杀掉的接口都要求对**一切**下标 (含不可入的) 有更新律. 限制在可入下标上的选择性更新没有被任何一条否定覆盖, 也没有一路试过.
> 3. 墙落在两个自由选择上: `HtTowerTy §4` 的 `sup` 把世界写成裸下标上的积 $\prod_{i:I}$ (下标不带可入证据), 以及回灌的形状 (读界, 升一个分量, 低层搬回) 从 `HtTowerFFold.RunM` 照搬 (那里世界是二元组, 选分量是投影). 这两个选择不是纲领或壁垒逼出的. 换掉它们的最小改动是 "世界的分量以 (坐标, 可入证据) 为下标, 更新由 `cmpB` 选择"; 代价是 `sup`/`Lev` 以上的全部脚手架重做, 并且会立刻碰到第二堵墙: 证据不唯一造成的拷贝 (`CohWNeg.no-cross` 那一族). 这第二堵墙是真的, 六路里只有 `CohW` 碰到过它.
> 4. 方法上的系统性问题: 每路换一个接口, 不换 "裸下标" 这个共同假设; 否定写得窄, "穷尽" 由判断补; 目标 "候选闭项 (读法可以是判断)" 本来今天就能交 (`DiagK3` 的 `Fold₊` 按 `growL′` 写得出, 无条件), 六路都因为**读法** (判断) 不到 ψ₀Λ 而没有交; 这说明真正缺的是树侧的值判据 (RouteReview2 R2, R5), 不只是世界的形状.
> 5. 下一步最快的判定: 在最小实例上写可入下标上的比较式更新 (`raiseB`), 四条律加一条 `cmpK`; 它要么一两天内编译过 (W′ 在可入下标上构造出来), 要么在 `cmpK` 处撞到拷贝墙, 那时把拷贝墙写成定理. `UniTr` 问对了问题, 但问在不带界的下标上; 它自己的 `emb⊲` + `sel→unitr` + `dec→sel` 加上 `bdec`, 在可入下标上大概立刻给出构造 (判断).
> 6. 把握 (判断): 合法有 FGH 的候选闭项: 高 (已经有); 读法到 ψ₀Λ 的候选闭项: 中低, 取决于 §5 的第一条引理; 项目达成 (闭项 + 序数值不低于 EBO 的编译证明): 低, 理由在 §6.

## 2 共同原因

### 2.1 六路的共同前提

把每条否定的接口写成同一个形状: 世界 $W$ 是下标类型 $I$ 上的族 (`sup` 的 $\prod_i$, `GW` 的 $\prod_{y:LH}$, 望远镜里 "同层位置的并"); 回灌要在 $i_0$ 处升高; 接口对**一切** $i$ 写一条律: 别处不变 (`off`), 子层不变 (`r-sub`), 按值能找到 (`find`), 或者落在任一同层位置下 (`AdmF`). 每条律都是关于 "$i$ 与 $i_0$ 的关系" 的陈述, 而 $I$ 有函数分支 (`HB S` 的 `hl`, `hΩ`; `LH` 的 `ll`, `lΩ`), 所以每条律都把 "分出 $I$ 的点" 的能力交了出来. 这是 `ClosedTermReview` 命题 W 的内容, 我同意它是定理级的 (`DiagKLev §2` 的一般形式).

### 2.2 它不是壁垒的推论, 是壁垒规则没用到的地方

壁垒 (`Barrier.Stages`) 的前提是: 严格序, 有界三歧 `dec : a < c → b < c → …`, `Ordᴰ` 的精确初始段 (`u-exact`, `v-exact`), 有 Ω-共尾元 `top`. 结论 LPO. 注意壁垒的三歧也是**有界**的 (两元在 `top` 之下), 它仍推出 LPO, 因为 `top` 是**值上**的上界 (位于整个 `Ordᴰ` 之上), 而 $u=\omega$ 与 $v_\alpha$ 的比较要看值 (精确性).

六路的 W 没有序, 没有初始段, 没有 `top`; 结论是相等的弱判定. 互不蕴含 (与 `ClosedTermReview §1.3` 同). 同族: 都是 "对一个有函数分支的类型判定一个点". 但关系可以说得更准:

- 壁垒的出路 (AGENTS 交替路线) 是把 "值上的比较" 换成 "字面公共上界之下的第一位置比较": `cmpF`, `cmpH`, `cmpB` 都是对上界结构递归, 停机且不需要 LPO. **这一招在六路里只用在了坐标与层的比较上, 没有用在世界的更新上**: `UpdS`, `RaiseAt`, `Find`, `AdmF` 的下标都是裸的, 没有 `⊲[w] b` 证据.
- [实验] `StallDxBdec.bdec : a ⊲[w] L → b ⊲[w] L → LgW S w → LgB L → (a ≡ b) ⊎ ¬(a ≡ b)`. 证明: `cmpB` 给出一方是另一方的第一位置; 非自反的第一位置是严格子项 (`toLt`); 子项关系良基 (`wf`), 所以严格子项不相等. 没有 `FE`, 没有 K. 这说明: **在字面公共上界之下, W 的结论是定理, 不是禁忌.** 各否定杀掉的接口之所以推出禁忌, 是因为它们对不在任何公共界之下的 $i, i'$ 也要求律. 而折叠从不在不可入的下标上回灌 (回灌发生在节点处, 节点的层带 `StH`/`hLim e` 见证, `e` 就是可入证据).

所以墙的准确命题 (我的改写, **[判断]**, 定理部分是 `bdec` 与各否定):

> **W⁺.** 世界更新的律若对裸下标陈述 (`i ≡ i′` 出现在律里, 或律对一切 $i$ 成立), 则推出 $I$ 上相等的 (弱) 判定 [各否定, 定理]. 若把更新限制在带可入证据 $(c, p : c \lhd_{[w]} b)$ 的下标上, 由 `bdec`/`cmpB` 选择 "在 $c_0$ 之上升高, 之下不动", 不推出任何判定 [`bdec`, 定理; 更新本身未写, 判断]. 代价是世界的分量以证据为下标: 同一个 $c$ 的两个证据给出两个分量, 这是 `Lev` 的 ℕ-和与 Ω-和造拷贝的同一现象 (`CohWNeg.no-cross`), 要么由折叠**携带路径**从不认同, 要么在界之下取规范代表 (可入时 `bdec` 使 "是否同一坐标" 可判定, 所以规范代表可算, 但算的代价未知).

### 2.3 为什么六路没看到可入下标这个选项

`ClosedTermReview §1.1` 把两组否定归为 "选择 $i_0$ (判等) / 不选择 (有损)" 两面, 并说 "忠实又单调的 $\delta_i$ 要知道 $i$ 与 $i_0$ 的关系, 又回到第一组". 这一步把 "知道关系" 等同于 "判等". 但在界之下, 知道关系 = `cmpB` 的输出, 免费. `TelW` 的 "(b)(c) 穷尽" 同样漏了它. `UniTr` 已经走到门口: 它证明 "有见证 $i_0\lhd i$ 时沿见证嵌入合法且在 `hself` 上恒等 (`emb⊲`), 有选择子就有 `UniTr` (`sel→unitr`), 相等可判定时选择子存在 (`dec→sel`)", 开放点 `Open-build` 是 "不假设判定写出 `UniTr`". 把 `UniTr` 的下标集从 `HB S` 换成 "`HB S` 中在公共界之下的坐标", `bdec` 就是 `dec`, `Open-build` 的可入版大概直接由 `dec→sel` 得到 (**判断**, 没有写).

### 2.4 第二堵墙: 拷贝

`no-wmatch` 逼出相干世界; `CohW` 做到链上相干 (`coh`, `yes-wmatch`), 卡在 `no-cross`: `Lev (hΩ κ g) = sup (E S κ) (Lev ∘ g)` 对每个坐标 $c$ 新造一份 `Lev (g c)`, 其中低级种类各有一份拷贝, 世界在独立位置. `CohWGl` 用层号 `lvl` 把拷贝的界对齐 (`glob`, `cross`), 于是更新要按层号选, 撞 `upd→wdec`. 这两堵墙是一对: **按相等认同拷贝 ⇒ W; 不认同拷贝 ⇒ 携带路径, 拷贝各有各的界, 比较时两边的界要能搬到一起.** 比较式更新 (2.2) 解决的是 W 这一半; 它把下标变成 (坐标, 证据), 拷贝问题以 "两个证据" 的形式回来. 这一半在六路里只有 `CohW` 碰到并写了定理, 其余五路停在 W 之前, 所以没看到它.

## 3 架构问题还是路线问题

### 3.1 墙落在哪两个定义选择上

1. `HtTowerTy §4` `sup I F` 的 `Wd = (i : I) → Wd (F i)`, 以及 `§5` `Lev` 在 ℕ-极限与 Ω-极限处取 `sup` (下标分别是 ℕ 与坐标类型). 裸下标上的积.
2. 回灌的形状: `HtTowerFFold.RunM`/`κc₁`: 读当前世界高度分量的界 (`rd lW (proj₂ W) (z₁ Y)`), 把这一分量换成读回值 (`mkCl₁ … (proj₁ lW , lv₁ c)`), 低层目标 `drp₁` 丢掉升高的分量搬回. 在 `step` 的二元组世界上, "换一个分量" 是投影与配对, 不选择任何东西; 搬到 `sup` 上就成了 `UpdS`. `CohW2Need` 把它读成 `RaiseAt`, `DiagKLev` 读成 `UpdS`, 都是这一形状在裸积上的直译.

对照第 0 层 (`HtFeedFold.κc zero = mkCl (sum W (z Y)) …`): 世界是一棵可数树, 回灌是 `sum W` 接上输出, **没有分量, 没有选择, 也没有读任何分量以外的东西**; 它天然就是 "在当前世界之上接长". `ClosedTermReview §1.4` 说这是 (c) 的来源, 我同意.

### 3.2 这两个选择是逼出来的还是自由的

- "比较要字面公共上界" (世界): 壁垒 + `no-glob`, `no-world-top` 逼出 [定理]. 不动.
- "种类以高度为下标" (`Lev`): 由 `no-retract` [定理] 与 "Ω_x 的 x 不可数" 逼出 [判断]. 不动.
- "世界 = 裸下标上的积": `sup` 的定义选择. 没有定理说它必须; `no-wmatch` [定理] 反而说裸积不行.
- "回灌 = 读界, 换一个分量, 搬回": 从 `step` 世界照搬. 没有定理说它必须 (`CohW2` 入口自己标为判断).

所以是**路线问题, 落在架构的一层 (类型层) 上**: 要改的是 `sup`/`Lev` 的世界与回灌的接口, 不是 `HB`, `⊲`, `LgB`, `cmpB`, `step`, 也不是第 0, 1 层的主线 (`HtFeed*`, `MainView*`).

### 3.3 最小改动与代价

**最小改动 (判断).** 新的并 `supB`: 世界分量以 (坐标, 可入证据) 为下标, `Wd = Σ (w : Wd S) ((c : E S κ) → Bd S κ c w → Wd (F c))`, `Lev (hΩ κ g)` 用它; `Lev (hl f)` 的 ℕ 下标可判定, 可留 `sup ℕ`. 更新 `raiseB (c₀, p₀) δ`: 对每个 $(c, p)$ 看 `cmpB p p₀`: $c_0 \lhd c$ (含 `hself`) 则沿返回的路径用 `emb⊲` (`UniTr` 已有) 把 δ 嵌进 `Lev (g c)` 再接长; $c \lhd c_0$ 严格则不动. 律: 在 $(c_0,p_0)$ 处恰好接长; 严格在 $c_0$ 之下的分量定义相等地不动; 世界只增 (`≤w`); 保合法. **没有** `off`, **没有** 层号相等.

**要重做的** (判断, 按文件): `HtTowerTy §4–5` (`sup`, `Lev`, `ι`), `HtTowerU` (`L`, `U`, `θ`, `Λᵁ`), `HtTowerNStage` (`L′`, `need′`, `wmatch′`), `CohWTy/CohWL/CohWGl` (链上相干的一套, 其中 `colim` 的思想可以保留), `DiagK*`, `ChainZ*`, `TelW*`, `UniTr*` 的全部脚手架; 大约几千行. **保留**: `HB`, `_⊲[_]_`, `LgB`, `cmpB`, `_⊞_`, `step`, `up`, `Ωtop`, `no-self`/`no-retract`, `HtFeed*`, `HtOut*`, `MainView*`, `GenAbs*`, 所有第 0, 1 层的值结果.

**新的义务 (判断, 这是风险所在).**

1. 拷贝 (§2.4): 同一 $c$ 的两个证据 $p, p'$ 给出两个分量; `raiseB` 在两处的结果**方向**一致 (良基), 但 `emb⊲` 沿不同路径的嵌入可以落在 `sup ℕ` 的不同分量 (ℕ-极限重复项时 `ι 0` 与 `ι 1`), 结果不相等. `cmpK` 在 `supB` 上要比较两个带不同外层证据的坐标, 这时需要把一边的界搬到另一边: 要么证明 "两个证据下的界互为第一位置" (不成立, 见上), 要么规定折叠只用规范证据 (ℕ-极限处取最小 $n$: 在界之下可算; Ω-极限处无最小, 要另想), 要么把种类改成路径, 从不认同. 这就是第二堵墙; `supB` 让它从 `no-cross` 的形状变成 "`cmpK` 要证据相等" 的形状. **这一步会不会撞墙, 是 §5 第一条引理要回答的.**
2. `--without-K` 的细节: 更新若用 `bdec` 返回的相等 `e : c₀ ≡ c₀` 做 `subst`, 在 $(c_0, p_0)$ 处 "恰好" 这条律要 `subst X e x ≡ x`, 没有 K 证不出 (`HB S` 有函数分支, 没有 Hedberg). 所以更新必须沿**路径** (`cmpB` 返回的 `⊲` 证明) 搬运, 不沿相等; "恰好" 这条律只在路径字面是 `hself` 时定义相等, 一般情形是命题. 折叠产生的证据是闭项, 会算到 `hself`; 一般定理要小心. `ClosedReview1` 的 D5 失败 (`Cannot eliminate reflexive equation`) 是同一个坑.
3. 读法不变: 这一改动不提供任何值定理 (同 D1, D2).

**另一个不改架构的选项 (判断).** 按作者原话, 候选闭项的读法可以是判断. `DiagK3` 的 `Fold₊` 用 `growL′` (统一 $H_0$ 增量) 今天就能写出无条件的 `Tᴰ₊` (合法, 有 FGH); 它的读法按 `noNew-emb` 的判断低于 ψ₀Λ (多低没有定理, 连粗界也没有). 它满足字面的目标, 不满足目标的意图. 交不交, 作者定.

## 4 研究方法的诊断

1. **同一假设上换写法.** 六路 (加此前三条) 的接口都以裸下标为前提: `UpdS` (DiagK) → `RaiseAt` (CohW2, 放宽到子层) → `growL′`/统一增量 (DiagK3, 不选择) → 结构翻译 (DiagK4) → 位置 + 自选 (TelW) → 链从 0 起 + `growL′` (ChainZ). 每一路换的是**律的形状**, 没有换**律的定义域**. 于是每条否定都重证一遍同一个影子. 手册 §3.1 "怎么防" 的三问 (是否要在两个世界里比值, 是否要对一切路径成立, 是否要判定一个极限点) 本来会在第二路就拦住: `off` 对一切 $i'$ 成立, 正是 "对一切路径成立".
2. **否定写得窄, 穷尽由判断补.** 每条否定只杀写明的接口 (这是对的, 规则要求如此), 但入口把 "剩下的办法只有这几种" 写成判断后, 下一路把这个判断当成前提 (`TelW` 的 (b)(c), `ChainZ` 的 "剩下的只有一致搬运", `LOG` 小结 "剩下的开放点只有一致搬运增量"). 否定越窄, 穷尽判断承担的重量越大; 没有人回头检查穷尽判断本身. 本次 `bdec` 就是对穷尽判断的一次反例 (它说还有一种办法), 用了 50 行.
3. **目标的字面与意图分离, 但没有交出字面的那个.** 作者要 "候选闭项, 读法可以是判断". 六路都在意图 (读 ψ₀Λ) 上自我否决, 没有一路交出字面的闭项并如实标读法. 结果是: 作者既没拿到闭项, 也没拿到 "这个闭项为什么不到 ψ₀Λ" 的定理 (只有判断). 这和 RouteReview2 R5 "中间站一个界也没有" 是同一件事: 没有树侧的值判据, "有损" 永远只能是判断, 路线也就只能靠判断关闭.
4. **翻译痕迹.** 三处: (i) 回灌的形状 (读界, 升一个槽, 搬回) 来自 `HtOut.Fb`/`RunM`, 根子是 Buchholz 式 "ψ 的链沿界升", 在 `step` 上无害, 在 `sup` 上成了 `UpdS`; (ii) `ChainZ` 把 BTBO 的 $\gamma_0=0$ 直译进差树, `stall` 说差树的输出是增量, 不是值 — 这是 "把记号的规则翻译成树" 的小样本; (iii) `Lev` 的形状来自下标塔的直觉 (入口自述), 它在 ℕ-极限与 Ω-极限处取**和**而不取**并** (colim), 拷贝由此而来. 这些都已在各入口如实记账, 不算隐瞒; 问题是记了账没有回头用.
5. **并行派发看不见汇聚.** 一天之内六路各 300 到 450 行, 每路的 "第一个障碍" 段都指向同一处 (`upd→wdec` 一族), 这在 `LOG` 里是可见的, 但派发按设计 (D1, D2, 一致搬运) 分, 不按 "共同前提" 分. RouteReview2 §4 第 1 条 "三路在等同一件事" 的教训在这里重演.
6. **做得对的.** 每条否定前提可满足 (都给了见证), 范围写明, 复核做了, "未走通" 的措辞合规, `FE` 标了条件. 这些纪律是好的; 它们让本次诊断能只看陈述就定位问题.

**应当怎样改 (判断).**

- 开一路前, 先把要用的**接口**写成记录, 并检查每条律的定义域: 律里出现的每对下标必须带字面公共上界的证据, 否则先写一条小否定 (半天) 再决定. 把这一条加进手册 §3.1 的 "怎么防".
- "穷尽" 一律标判断, 并要求下一路**先**挑战穷尽判断 (找第四种办法), 再在剩下的办法里选.
- 目标拆成两条交付: (a) 合法闭项 (今天就交, 读法如实标); (b) 一条关于 (a) 的**值定理或值否定** (它为什么不到 / 到了哪里). 没有 (b) 的路线不得以 "读法太低" 关闭.
- 新路与否定配对派发: 一路写构造, 一路写同一接口的否定, 两路共用一个接口文件; 谁先编译过谁定方向. 不再六路都写否定.

## 5 下一步建议

### 5.1 方向 A (推荐): 可入下标上的比较式更新, 在最小实例上判定

- **实例.** `S = S₀`, 并 `Lev (Ωtop S₀) = sup (HB S₀) (c ↦ Lev (up c))` 改成 `supB`: 世界 $(b : HB S₀, v : (c : HB S₀) → c ⊲[azero] b → Wd (Lev (up c)))$ (外层世界取 `A` 的 0 或任意 $w$).
- **第一条引理 (一两天).** `raiseB : (c₀ : HB S₀) (p₀ : c₀ ⊲[w] b) → δ → World → World`, 用 `cmpB p p₀` 与 `UniTr.emb⊲` 定义; 证四条: `at` (在 $(c_0,p_0)$ 处, 沿 `cmpB p₀ p₀` 的路径; 先只对 `hself` 字面情形证), `below` (严格在 $c_0$ 之下的分量 `refl` 不动), `≤w`, `LgW`. 预期能过; 过了就是 "W′ 在可入下标上构造出来" (与 `UniTr.Open-build` 的可入版同一陈述).
- **第二条引理 (判定性的).** 给 `supB` 定义 `cmpK`: 两个坐标带外层证据 $(p, e)$, $(p', e')$, $p, p'$ 都证 $c \lhd b$. 若能证, 方向 A 活; 若需要 $p ≡ p'$, 把它写成否定 `cmpK-needs-proof-eq` — 那就是第二堵墙的定理形式, 比 `no-cross` 一般. 两种结果都是信息.
- **先手.** 这一路是摆脱侧 (它去掉一条从 `RunM` 照搬的形状), 不读记号; 与 `UniTr` 的 `emb⊲`, `sel→unitr`, `dec→sel` 直接拼接.

### 5.2 方向 B (备选): 事件历史世界

世界不是族, 是有限的**升高事件表** (路径, 增量); 任一 (路径, 证据) 处的界由重放算出: 对每个事件用 `cmpB` 比当前坐标与事件坐标 (都在当时的界之下, 界只增所以证据可弱化), 在上者累加 `emb⊲` 的增量. 下标是事件表的位置 (离散), 选择由比较完成, W 与 W′ 都不触及; 拷贝问题以 "重放对证据的依赖" 回来. 第一条引理: 重放单调 (加事件只增界) 且在新事件处忠实. 它与 `CohWTy.colim` (世界由扩张生成) 同一思想, 把扩张从 "按级" 改成 "按事件". 比 A 多一层间接, 先做 A.

### 5.3 方向 C (零成本交付)

按 `DiagK3` 的选项 (ii) 用 `growL′` 写出 `Fold₊`, 得到无条件的 `Tᴰ₊` (合法, 有 FGH), 读法写 "低于 ψ₀Λ (判断, 依据 `noNew-emb`), 具体到哪一站无定理". 这满足作者原话的字面; 要不要交, 作者定.

### 5.4 对 `UniTr` 的评论

它问对了问题的一半: 把 "非选择性搬运" 写成一般陈述 (`UniTr` 记录), 证明它与积世界的非选择回灌互推, 并证明望远镜版 (D1) 在类型上不可能 (`no-outer-lift`, 结论 ⊥, 与判定无关) — 这条把 D1 "由外层界决定的界族" 关掉了, 比 `TelW` 的否定强. 积世界版它自己写 "障碍只是下标不可判定: 下标可判定时 `UniTr` 存在". 这正是 §2 的结论: 问题不在 "选择性/非选择性", 在**下标带不带界**. `UniTr` 的下标是裸的 `HB S`; 换成可入坐标, `bdec` 就是它要的 `dec`. 建议 `UniTr` 不再在裸 `HB S` 上攻 `Open-build` (那大概是禁忌, 与 `wdec` 一族同命), 而把 `LevSlot` 的下标限制到 $c \lhd_{[w]} b$, 用 `dec→sel` + `bdec` 给出可入版的 `UniTr`; 这与 5.1 的第一条引理是同一件事, 可以合并.
