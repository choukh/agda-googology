**构造性的树与折叠已经能给出 Λ 上的闭项，经典验收已经解决右侧正规时合法层号间的标准 Ω 树值比较；两者到 EBO 的值下界仍未接通。建议下一批先在塔第 2 项涉及的一个跨孩子格上，不用排中律证明折后分支的上确界下界，把同一命题留给经典证明作对照。**

### 1.2 值的一侧

- **Bach 与当前基本列一致。** `EboLeanDef` 直接重新导出 EBO 的 `fsT`、`γT`，`fsn` 的规则 6 用这条 γ 链。在 `EboBach` 的 `bach-ω`、`bach-Ω` 中右端就是这两套运算。另将 `EboLeanCmp` §1 的签名和证明体原样抽出重编，得到对所有 t、n 的 `fsn t n ≡ EBO.fsn t n`。输入非空的例子可取零和后继一，极限与规则 6 有 N1Ref、N1BachTest 的具体项。这里的共尾性是记号定理。[Bach](../OCF/Align/EboBach.lagda.md) · [基本列](../OCF/Align/EboLeanDef.lagda.md)
- **一般 Ω 单调的条件已经明确。** `IS` 从 `Ok a` 与 `a ≼ᴸ b` 给出嵌入，不要求 `Ok b`。`psAll`、`tpAll` 要求两侧合法；`tpAll` 给每棵源树一棵目标树及普通值上界。`ΩtMono` 还要右侧 `Nm b`，`ΩtSame` 要两侧正规及双向层值界。整组一般结论以类型论式排中律与普通依赖函数外延为参数，未另取选择公理。合法同值但形状不同的一对由 `ex₂` 实填。层值 `≼ᴸ`（孩子的严格上确界）和输出 `val` 的前序是两个关系。这里比较 Ω 树，没有比较折叠输出。[一般出口与实例](../OCF/Lean/YiQNEncGen.lagda.md) · [必要方向与充分方向](../OCF/Lean/YiRVOmega.lagda.md)
- **前提有不同的证据。** 经典分支使用 `LEM = (A : Set) → A ⊎ (A → ⊥)`，有数据的存在命题可取见证。把小类型解释为集合并在元理论中允许选择时，可为非空集合选元素，函数取通常的外延相等，这解释了经典参数的相对可满足性。代码没有构造一个封闭的 `LEM` 或 `Funext`。用排中律对等式作判定再由 Hedberg 推出特定类型的 UIP 是显式条件证明。冷编全程关闭 K。`inj→surj` 另需源类型的默认元素，实际取树零。ValV1 回报一度把满射条件写作等价；`tpPS` 给的是从满射到支配的方向，一般构造成功也不能反推原来必须用满射。[通用嵌入部件](../OCF/Lean/YiQNEncBase.lagda.md) · [槽位条件](../OCF/Lean/YiQNReg.lagda.md)
- **理想折叠到 EBO 仍是待证目标。** S1Sharp 的 `EBO♯` 与仓库版的 `ψ♯` 都在验收侧。建立项模型时，树和式以 `Dk` 选公共层；`τ` 一般接受源层不高于目标层，在保留行转换分支类型时用同值槽位的一个方向。`τm` 证明第一位置步进保持。还欠一般搬运的值与命名、重复加法闭包、A 的序归纳、B 的极限／结点两支／嵌入行、塔和 Λ 的命名与出口。尚无 `EBO参照 ≼ read EBO♯`。后继行的全局 `AddRep` 要单独验证可满足性，零次迭代的实例不能替代它。[理想折叠](../OCF/Lean/YiNMSharp.lagda.md) · [命名行](../OCF/Lean/YiNPName.lagda.md)

### 1.3 两条命名反例到底排除了什么

1. 条件（排中律）。`YiNMAbsorb.absorbed` 给 `T*` 与第 1 层 Ω 树相同的严格值，`absorb-fails` 给折向零层后的严格不等式。这已经反驳任意同值上下文的吸收。`B-false` 的底族条件 `ctx₀` 已填，但旧关系下 `T*` 具有指定名字这一前提没有证明。加强命名后，`YiNPAbsorb.¬named-T*` 对任意良基证据排除了这对树与名字，且 `lvn-tw1` 实填了规范塔层的遗传命名。[吸收](../OCF/Lean/YiNMAbsorb.lagda.md) · [加强后的排除](../OCF/Lean/YiNPAbsorb.lagda.md)
2. 条件（排中律）。`xw` 在有名字的下标选规范分支，在其余下标选择同输入值但折后行为不同的分支。`named-xw`、`named-β`、`lvn1`、`ctx₁` 和正规形证据均已填，`B-keep-false₁` 真正否定指定域上 `xw` 的 B 行。域 `D i = (i ≡ one)` 限制底族在哪些层要有名字，并没有限制输入树是怎样生成的。[命名反例](../OCF/Lean/YiNPWild.lagda.md)
3. **两棵树在拟议读回域之外，都没有这样的定理。** 目前没有那一域的归纳定义、其生成覆盖塔的证明或这两个非成员证明。对第一例还要区分树、名字及生成它的上下文，排除一对树与名字比排除整个树容易。对第二例，分支定义调用排中律本身不推出“按值无规范代表”。若改域，先给规范塔、底族和真正回灌的分支以成员推导，再给排除或正确的命名。把 B 本身藏进成员条件会使验证循环。

### 1.4 W1 的量化域与 W4 的壁垒审计

记 `h c = zero ⊕ ↑ zero c`。在任意零层极限树 `r = lim f a` 上，目标 `J = h (suc r)`。W1Neg 假设一个对**所有**零层树 c 有定义的布尔或 Maybe 判定，同时要求其保留结果与 `h c ≺ᴸ J` 的两个方向。把变号序列编码成树，`low` 与 `high` 把“全假”与严格小于 J 互推，得到 WLPO（判定布尔序列是否恒假）。`Negω` 给具体极限，`Sat` 在排中律下用理想判定填两条律。结论是一个构造性归约；要得到矛盾还得额外给出 WLPO 的否定。特别地，经典验收中从这条蕴涵得不到值不等式的否定。[W1Neg 原件](Reports-2026-11-16/attachments/B4W1-W1Neg.agda.txt)

**这一列和塔内格的联系可以比原报告写得更精确。** W1Trace 从理想塔第 2 项展开到零层折 `b+b`，其中 b 是塔第 1 项层号的 Ω 树。W1Trace3 从第二个链点沿 1、0、1 三个孩子到达以 `J = h (suc β₀)` 为槽位层的结点，`β₀` 字面为 ℕ 极限。底族出现折 b 向 J，保留后分支用 `body♯ (cv z)`。原 `bJ-keeps` 给出一个槽位和换型函数 cv；原 `col-J→wlpo` 的证明体直接调用一般格律，没有在两者之间证明 cv 满射，更没有证明运行 FGH 会枚举所有孩子。[塔内路径](Reports-2026-11-16/attachments/B4W1-W1Trace3.agda.txt)

本审计在**原件同一个槽位 q、底值 Ωt J** 上补编了 `ColumnImage.image-suc`。对所有 c，实际转换 `cv (fromBr J q (suc c)) ≡ suc (d c)`，证明是 `refl`，其中 d 是理想折叠在零层的自搬运。又对每个 c 证明 `h (d c)` 与 `h c` 互相支配。`Pull.image-law` 不用排中律，表明在任何这样保层值的像上，对所有自变量给出正确布尔答案仍推出 WLPO。具体 q、cv、β₀ 来自带排中律参数的理想塔。于是“只对这个转换的所有后继分支判定”仍能编码康托族；“只对有独立生成推导的调用判定”、重编号后不反映原比较、以及仅比较上确界，均未被这个结论排除。§6 附原样复编的补件。

**定义侧。** W4 的 `Ok-Λ` 和 `Ok-tw` 有闭项。其 `EBOᶜ : Tr zero` 已由新折叠在 Λ 上给出，`twᶜ` 对所有自然数定义。简报只点出塔第 2 项，低估了闭项的范围。`brwView` 实际覆盖**所有层**，包含零层；目标值取 W4Val，部分仍是同类树，ℕ 分支给第一位置的值步进。沿此 View 的任意部分递归所需的良基性还没有另证。层号证书、闭项、读回自身的值性质均未给 W4 输出以 BTBO 或更高的强度下界。[折叠与闭项](Reports-2026-11-16/attachments/B4W4-W4Fold.agda.txt) · [View](Reports-2026-11-16/attachments/B4W4-W4View.agda.txt)

- `kpT` 按框架路径递归，当前孩子内的目标走 `inj₁`，外来语境走 `inj₂`。Ω 形、孩子侧槽位、裸的指定孩子路径这三者相遇时，`kp` 返回 nothing。补编 `W4Local.bare` 覆盖任意 c、e、槽位、带路径的目标，即使 c=e 也回退。`off` 在孩子 2、目标层 1、槽位层 0 这一条字面对角上给出“保留 → 空”。而 W4Check 的 `fg-just` 给带树框架写法的保留实例。这里具体击中的是“能认出所有同一孩子”的正向前提。
- `branch→wdec` 要同一探针的对角开、异支关与逐孩子的路径；`hand→wdec` 要统一移交、探针及异支条件；`viaE→dec` 要对角一致及随下标给相等证据的派发；`full→dec` 要槽位存在性与可观察结果的完备性。`It n` 的升阶、加孩子框架、在手里的路径上复合都没有提供这些字段。`bare` 与 `off` 只核了上述指定接口的失败，其他接口的普遍不可构造性仍属未证。[观察条件](../OCF/Lean/YiAbsObs.lagda.md) · [框架条件](../OCF/Lean/YiAbsFrame.lagda.md)
- `Barrier.barrier` 需要嵌入 `Ordᴰ` 的保序、极限精确性、共同顶元及有界三歧等整套字段。W4 核心的编译依赖图只有自己的块、运算、路径与库，未导入或要求这种接口。裸格回退、W1 的按层值 WLPO 与该有界三歧的 LPO 归约是三条可核对的不同陈述。源码和依赖图能检验当前定义使用了什么，不能保证未来要求的值律也满足这些限制。[壁垒接口](../OCF/Barrier.lagda.md)

## 2. 第 4 层是否因排中律而更快

| 同一项研究义务 | 有排中律的证据 | 无排中律的证据 | 对排期的含义 |
|---|---|---|---|
| 两层均合法、右层正规且有层值界时的 Ω 树值单调 | 加普通函数外延已有一般结果和非平凡实例。对两非零层的比较、从单射取带默认值的逆、函数相等这几步均能在代码中定位。 | `TpPath` 沿字面路径给支配；有槽位满射时 `TpS` 直接给支配。这两条的域较窄。未复核出同一般性的无条件证明。 | 一般命题可直接复用经典结果。没有“去除排中律不可能”的逆向定理。 |
| 同一后继孩子顶槽位对正有限目标的整列判定 | `kp♯` 对全体目标作值比较；`YiLAFiniteAccept.agrees` 把它在本域的答案与构造算法双向联系。 | 新定理 `YiLAFiniteKeep.sound / complete` 对每个 n 和**每棵**零层树 c 成立。极限的第 n 个孩子已有 n 层高，故可排除其低于有限截点；落在截点内的孩子给出字面路径，能返回槽位、分支转换及保零证明。 | W1 曾指出有限层可能可判；这里新增的是全称证明与可用的保留数据。域可以是无限的，目标前驱是自然数。它不比较两个任意树层号。 |
| 标准族重编号后的实际折叠值 | 也可在同一无条件定理外加排中律，但得不到更强的这个实例。 | 新定理 `canonical-same` 给标准 Ω 树重编号前后同值。`W4Local.self-canonical` 还给**实际 W4 自身折叠**前后同值，对任意底族、非零底和零层偏移成立。证明用 W4 自身行的读回公式与 `Ev-monoˣ`。 | 已有无排中律的第 4 层值进展。这个正例的源、目标同层；跨孩子调用需要再证。 |

**重编号有一个首分支义务和一个值义务。** 现有 `Keep` 的肯定分支要求换号将目标首分支送到源首分支，`nodeLe` 用此证第一位置步进。`r + 0 = r`。更一般地，新定理 `no-based-path` 对两种字面路径都成立：任意 ρ 若保零，就不可能对每个 c 都从正后继目标 `h (suc r)` 给出到 `h (ρ c)` 的路径，单取零即得矛盾。可以把零支单列，在其余分支用 `shift r c = r + c`。这仍需为**折后分支族**证明值界。[首分支、正例与反例](../OCF/Lean/YiLAReindex.lagda.md)

对于同槽位的族 G，重编号结点总是被原结点支配。反向的一个充分条件是每个原分支都有某个换号分支支配它，两个下标可以不同（`At.cover`）。更宽的充分条件是每个原分支都被**整个新结点**支配，原分支为极限时可继续分解。没有必要从值界反取一个保留布尔量。新定理 `peak-lost` 排除了“保零平移对一切合法分支族保值”：取同一个零层槽位，分支 1 输出 2，其余输出 1，每支都正；偏移 2 后所有分支只输出 1。反例只否定全称律，标准族本身就有相反的正例。
