# 协调 03 · 第十批：内链归纳与外层出口实接成闭定理

**结论：两路结果已实际接起，得到闭定理，无前提。**

```agda
double : LV.ψ⁰ (Ω₂ᴸ LV.+ Ω₂ᴸ) ≼ read Ψ₃
double = B.assemble A.rows        -- A = B10LocalRows，B = B10ExitCore
```

这是编译定理，不用排中律或函数外延。左端是 Level 参照的 ψ⁰(Ω₂+Ω₂)，读作 ψ₀(Ω₂·2)，这个读法是判断。右端是 W4 的第三层标准闭项 Ψ₃（`WKShape.Ψ₃`）。它是 Level 端点上的结果，没有翻译到 src。ψ₀(Ω₃) 仍开放。纸面推导在两路都原样编出，第一种写法都通过。

## 2. 新取得的闭项下界（编译，无前提）

| 名字 | 签名 | 来源 |
|---|---|---|
| `double` | `LV.ψ⁰ (Ω₂ᴸ LV.+ Ω₂ᴸ) ≼ read Ψ₃` | 实接 |
| `rows` | `(n : ℕ) → Row n`，`Row n = Match (Y (suc n)) (B.z n 2)` | A：对不变量 `Inv` 递归，`inv (suc n) = In.next n (inv n)` |
| `rows-U` | `(n : ℕ) → Match (Y (suc n)) (B.U n 1)` | A |
| `pass` | `Real (B.c n) eΩ₂ → Real (B.c n) Ω̂ → Real (B.c n) (eY n) → Real (B.c (suc n)) (eY (suc n))` | A：规范指数传给下一状态 |
| `add-z2`、`exp-z2`、`add-U1`、`exp-U1` | 对一切 n，被加项与指数两个消费者，左端是 `Y (suc n)` 的参照，右端是 W4 的实际计算 | A |
| `term0`、`term1` | `LV.ψ⁰ (body (Y 0)) ≼ read Ψ₃`；`LV.ψ⁰ (body (Y 1)) ≼ read Ψ₃` | B（`term1` 与第九批 `outer` 同一陈述） |

## 3. 条件推理（只有这些）

| 名字 | 前提 | 状态 |
|---|---|---|
| `assemble` | `(n : ℕ) → Row n` | 已由 `rows` 实例化，得 `double` |
| `assemble-add` | `(n : ℕ) → AddAt (Y (suc n))`，只要被加项证据 | 比 `assemble` 弱的充分条件，本批未用 |
| `exit-below` | 证据落在 `B.z k j` 之下的任一树 | 已用于 `term0` |
| `no-frozen-state-if` | `H₂ ≼ H` 与 `LV.suc H ≼ LV.ψ⁰ (Y 1)` | 第二个前提与 `Gap′` 同类，开放；可满足性只是判断 |

## 4. 单个替换反例

| 名字 | 被替换的是什么 | 档位 |
|---|---|---|
| `frozen-row`、`frozen-add` | 首个非零项取的分量换成冻结状态的 `chainW 0`；`frozen-add` 对一切 d 否定被加项证据，所以在出口接口上确实失效 | 编译，无前提 |
| `frozen-below` | 对照：`chainW 0 ◃ B.z 0 2`，冻结项在实际链项之下 | 编译 |
| `zs-frozen` | 把状态换成初态 B₀ 后，第 2 个链点是 `zW 2`，不是 `chainW 0`，`frozen₀` 不覆盖 | refl |
| `lost-β`、`lost-c` | 零层底或零层链底错用成初态 `Ωt zero`：`L2-sem` 的 ψ⁰(Ω₂) 正性先丢失 | 编译，只否定 `L2-sem` 的前提，不否定错配后的结论本身 |
| （类型失配） | 零层底错配时 `Ψg` 不再是 `v (suc k)`，`approx` 接不上 | 只是类型失配，没有否定定理 |

## 5. 纸面与实码的首个分歧

- **A 路：** 没有分歧。简报第 1 至 3 步逐条原样编出，状态不变量、`RealX` 的三槽取法、`part n` 传递、`SumR-x` 组装都和纸面一致。唯一的编译失败是名字 `St` 与 `W4Fold.St` 重名，改名后通过，与数学无关。
- **B 路：** 轨道与分支编号都没写错，外层出口（第 3 步）原样编出。偏差有两处：
  1. **反查的读法：** 简报说 "把首个非零项的原始状态替换成冻结初态，用 `frozen₀` 验证"。实际上 `frozen₀` 否定的是 "所取项换成冻结状态的分量 `chainW 0`"，这与 `YiLAB10Rows` 的注释一致；真正把状态换成 B₀ 得到的是 `zW 2`，那里只有条件否定。
  2. **`Row` 比出口需要的强：** 出口不用指数一半，`AddAt` 已经足够（`assemble-add`）。B 路另有一次编译错误，是变量名 `up` 撞上 W4 的构造子，改名后通过。
- **最先需要改写的陈述：** 没有。两路都没有改写纸面里的中间陈述。
