## 3. `Second`：有见证（B9A）

**编译定理，无前提：**
- `at1 : AtPart 1`，即 `together dY1 eY1 SumR-U1 Real-U1 Ld-Y1 Lx-Y1`。
  - 分支是第二次更新所产极限的第 1 号**累加分支** `U 1`，路径是 `part 1`，即 `◃l 1`。
  - 描述对是第八批 `B8PairLevel` 的规范描述 `(dY1, eY1)`，没有换描述，也没有用到 `shift-d` 收窄。
- `second : Second`，证明体逐字是 `second = to-second at1`。`Second` 的定义已对照公共源码。
- `at-suc : (k : ℕ) → AtPart (suc k)`：沿 `U k ◃ U (k+1)` 与 `Match-up` 推出，覆盖一切 k ≥ 1。
- 两个消费者的闭不等式，左端是 Level 参照，右端是 W4 的实际计算：
  ```
  add-2 : LV.ψ⁰ (Y 1) ≼ read (proj₁ (ψ lvl1 (proj₂ ok₂ tt) (B₀ lvl1) zero (inc tt self) (Ωt zero) (chainW 2)))
  exp-2 : LV.ψ⁰ (WL.ψ₁ (Y 1)) ≼ read (proj₁ (E o₁ tdNil (chainW 2) Ω₁op (B₀ lvl1) zero (inc tt self) (Ωt zero)))
  ```
  另有 `U 1` 上的同形两条：`add-U1`、`exp-U1`。
- **消费位置（执行方说明，与源码一致）：**
  - 在 `U 1 = ex (z 1 + c) c nc (suc (z 1)) tt` 里：
    - 底 c 当 Ω₁ 用；
    - 前缀 `z 1 + c` 只用正性（`Real-pos`、`baseInfl`）；
    - 指数 `suc (z 1)` 里，`z 1 = ex c c nc (suc 0)` 实现 `eΩ₂ ⨾ Ω̂`，前一个 c 用 `Real-c1` 当 Ω₂，后一个 c 当 Ω₁。
  - `RealX` 给出的影子与 `eY1` 定义上相同。
- **新的一般行：**
  - `Real-pos : (a : Tr lvl1) → lvl1 ⊢ zero ◃ a → Real a zC`；
  - `RealX : … → Real a ea → Real b eb → Real x ex′ → Real (ex a b nb x tt) (exE ea eb ex′)`。

**外层下界（单列，编译定理，无前提）：**

-- body (Y 1) = Ω₂ᴸ LV.+ LV.up LV.zero (Y 1)；Ψ₃ = proj₁ (ψ₀ lvl3 ok₃ (proj₁ (Ωt lvl3)))（WKShape）

## 4. `First`：仍开放（B9N）

**编译定理，无前提：**
- `B9UpperRel`：对一切阶 n 的上界逻辑关系 `𝓤 n`，即 "这个运算的值不超过这个影子"。
  - 与 B6A 的下界关系 `WSW4` 同形，方向相反。
  - 逐行：`U-sh`、`U-limC`、`U-enter`、`U-node`、`U-up`；第 0 层指数 `L0E`、`L0I`。
  - 指数实现：`Real-zero`、`Rsuc`、`U1`、`U2`。
- `B9UpperTop`：
  - `Bok : (n : ℕ) → read (proj₁ (ψ lvl1 o (B₀ lvl1) zero (inc tt self) (Ωt zero) (cum Fz n))) ≼ Bnd n`，其中 `o = proj₂ ok₂ tt`，与 `out` 的 `o₁` 同一项。
  - `Bnd zero = sE (sC (eU zero)) fΩ (fΩ 𝟏 𝟏) (fΩ 𝟏 𝟏)`，`Bnd (suc n) = sE (sC (eU (suc n))) fΩ (fΩ (Bnd n) (Bnd n)) (fΩ (Bnd n) (Bnd n))`，只有影子算术。
  - `Ŝ = LV.lim Bnd`；`out1-up : out 1 ≼ Ŝ`。
- `B9UpperMain`：
  - `sandwich : (LV.ψ⁰ X₀ ≼ out 1) × (out 1 ≼ Ŝ)`。
  - `Gap = Ŝ ≼ LV.ψ⁰ X₀`；`Gap′ = LV.suc Ŝ ≼ LV.ψ⁰ (Y 1)`；`Gap→Gap′`。
  - `no-first-if : (H : T₀) → Ŝ ≼ H → LV.suc H ≼ LV.ψ⁰ (Y 1) → First → ⊥`，证明体是 `refute-at {X = Y 1} {n = 1} H (≼-trans out1-up up) low`，调用的就是主审补件里的 `refute-at`。
  - 同形的还有 `no-goal-add-if`（对闭目标 `Goal-add`）、`no-first-from-Gap`、`no-first-from-Gap′`。
  - `Gap-from-terms : (∀ n → Bnd n ≼ LV.ψ⁰ (ψ₁ (γ n))) → Gap`；`Gap→val : Gap → out 1 ≈ᵛ LV.ψ⁰ X₀`。
  - 正对照 `out0-cross : out 0 ≼ Pε`（经 `out0-up` 与 `fΩ-1`）：在初态复得 B8N 的 `fold-up` 目标，所以这套上界在第 0 阶不松。
- **前提与实例：** `no-first-if` 的第一个前提有实例 H = Ŝ；第二个前提就是 `Gap′`，没有实例。
- **执行方的纸面判断：** `Ŝ` 与 ψ⁰ X₀ 同为 ψ₀(Ω₂) 量级，所以 `Gap` 成立、`First` 为假。缺的是反向的 Level 理论（"ψ⁰ 不低于影子"），难点有三：
  - ψ⁰ 对 ≼ 不单调（`Value.ψ⁰-not-cong`），要一个结构序；
  - ψ₁ 产生右结合的和，要结合律；
  - 上界结点的累加与复合要被吸收。
  执行方估计 600 到 900 行，建议下一路首交 `∀ n → Bnd n ≼ LV.ψ⁰ (ψ₁ (γ n))`。
