## 主审补验与公共接口

取 W4 的第 2 层标准 Ω 树作运算 F，以标准底族为初态。记 `chainW n` 为对 F 做 n 次状态更新后，第 1 层槽位的实际树。另取 Level 中 `ψ⁰ (Ω₂ + Ω₂)` 的实际链，记其第 1 层链点为 `Y n`。记 `body x = Ω₂ + up x`，其中 up 是从第 1 层嵌入第 2 层的指定嵌入。

- **构造与值分别通过。** `YiLAB7Orbit.actual` 对每个自然数 n 给 `chainW n` 的生成推导。证明只用树构造、加法、累加和 W4 的更新行。Agda 导入图里项目模块只有本件与 W4Block、W4Ops、W4Path、W4Fold。`YiLAB7Replay.at-step` 从该推导同时给出原来的被加项证据 Sm 和指数证据 Re。`lower` 因而能在任意 n 处再次使用 `step-sum`。这是对指定运算和初态的全称定理。两类证据都在原来的“第 1 层折向零”语义内。
- **参照的来源已核。** `double-shape` 定义性地证明 `ψ⁰ (Ω₂ + Ω₂) ≡ lim (λ n → ψ⁰ (body (Y n)))`。`Y 0 = Ω₁`，下一点由 Level 自己的 ψ 在第 1 层对 `body (Y 0)` 求出。两侧编号由各自的递归给定，相同编号是否足以作值比较正是本次实验要检验的假设。
- **验收接口已实填。** `Match X y` 要求同一对描述 d、e 同时满足 W4 的 `SumR y d`、`Real y e` 和 Level 的 `Ld X d`、`Lx X e`。`seed` 在初态实填四个字段。`consume` 把任意见证送到零层折后的值不等式，`consume-exp` 则把 X 和 y 分别作指数消费，给出 `ψ⁰ (WSLevel.ψ₁ X)` 到真实 W4 迭代输出的值不等式。由此可以实测两个字段各交付什么。`First` 和 `Frozen` 的类型均已编译，它们的见证或否定留给第八批。

这修正了第七批“第一次更新之后没有下界”的读法。构造侧可以反复给出下界。还欠的是同一份下界能控制指定的 Level 参照，随后还要接回外层的 `body` 与 Ψ₃。即使 `First` 成立，也不自动得到 `ψ⁰ (body (Y 1)) ≼ read Ψ₃`。

{-# OPTIONS --safe --without-K --lossy-unification --cubical-compatible --guardedness --hidden-argument-puns #-}
module YiLAB7Orbit where

open import Data.Nat using (ℕ; zero; suc)
open import Data.Unit using (tt)
open import Data.Product using (proj₁; proj₂; _,_)
open import Data.Sum using (inj₁; inj₂)
open import W4Block
open import W4Ops
open import W4Path
open import W4Fold
lvl1 lvl2 : L
lvl1 = nd sS (λ _ → zero)
lvl2 = nd sS (λ _ → lvl1)

ok₂ : Ok lvl2
ok₂ = tt , λ _ → tt , λ _ → tt

p₁ : Pos lvl1
p₁ = inj₂ (tt , inj₁ tt)

-- 只生成本次迭代用到的树。Ω 行的零层分支仍遍历所有 z。
branch : Tr lvl1 → Tr zero → Tr lvl1
branch a z = up a tt (suc z) (z◃ z ◃s)

data Gen : Tr lvl1 → Set where
  gz : Gen zero
  gs : ∀ {x} → Gen x → Gen (suc x)
  gl : ∀ {f s} → (∀ n → Gen (f n)) → Gen (lim f s)
  go : ∀ {a} → Gen a → Gen (Ω p₁ (branch a))
  gx : ∀ {a b x} {nb : lvl1 ⊢ zero ◃ b} → Gen a → Gen b → Gen x → Gen (ex a b nb x tt)

addG : ∀ {a b} → Gen a → Gen b → Gen (a + b)
addG a gz         = a
addG a (gs b)     = gs (addG a b)
addG a (gl f)     = gl (λ n → addG a (f n))
addG a (go b)     = go (addG a b)
addG a (gx b c x) = gx (addG a b) c x

cumG : (f : ℕ → Tr lvl1) → (∀ n → Gen (f n)) → ∀ n → Gen (cum f n)
cumG f g zero    = g zero
cumG f g (suc n) = addG (cumG f g n) (g (suc n))

F : Op {lvl2} nil
F = opB lvl2 ok₂ (proj₁ (Ωt lvl2)) (proj₂ (Ωt lvl2))

c₁ : St {lvl2} nil → Tr lvl1
c₁ S = proj₁ (S lvl1 (inc tt self))

stepG : (S : St {lvl2} nil) → Gen (c₁ S) → Gen (c₁ (stepS F S))
stepG S g = gl (cumG (λ n → z (suc n)) (λ n → term (suc n)))
  where
  b = c₁ S
  z = iter (λ x → ex b b (proj₂ (S lvl1 (inc tt self))) (suc x) tt) zero
  term : ∀ n → Gen (z n)
  term zero    = gz
  term (suc n) = gx g g (gs (term n))

actual : ∀ n → Gen (c₁ (itS F n (B₀ lvl2)))
actual zero    = go gz
actual (suc n) = stepG (itS F n (B₀ lvl2)) (actual n)
