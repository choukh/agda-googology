# 协调 04 · 第十一批：前缀归纳与外层更新，Level 与 src 闭定理都已接通

**结论：两个闭定理都已实接，无前提。**

```agda
level : LV.ψ⁰ (LV.lim T.ll) ≼ read Ψ₃                              -- Level 端点
level = B.run-stages A.stages                                      -- A = B11PrefixMain，B = B11OuterCore

src : tr₀ (Ord-Ord.ψ₀ (Ord-Ord.lim T.ss)) ≼ read Ψ₃               -- src 端点
src = src-exit level
```

- **档位：** 都是编译定理，不用排中律或函数外延。
- **src 端点：** 读作 Ψ₃ 不低于 src 的 ψ₀(Ω₂·ω)。依据是 `YiLAB10Src` 里的定义：`T.ss 0 = S.Ω two`，`T.ss (suc n) = T.ss n S.+ S.Ω two`，即 n+1 份 src 的 Ω₂ 左结合相加，取极限后再折叠。
- **Level 端点：** 是 Level 参照的同一个值，即 `lim ll`。
- **Ψ₃：** W4 的第三层标准闭项 `WKShape.Ψ₃`。
- **仍开放：** ψ₀(Ω₃)，以及塔与 Λ 端点。
- **纸面：** 两路的数学都原样编出；只有 B 路有两处工程改写，见 §5。

## 5. 纸面与实码的首个分歧

- **A 路：** 没有分歧。简报第 1 至 3 步全部原样编出：`LdQ`、`LxQ` 与 `B8PairLevel` 逐条对应，只把 `inflΩ₂` 换成参数 `ie`，把零层尾部的零号行换成两个基例；不需要按投影用 `LeE` 搬运。
  - 原因（执行方说明）：`add` 对第三个参数递归，`ψ` 的穿透分支不看 P 的形状，所以证明除基例外不碰 P。
  - 唯一的编译失败是 `module S = Ord-Ord` 与 `WSShadow.S` 重名，删掉即过。
- **B 路：** 数学上没有分歧，各字段、分支、槽位都按纸面接通，接口未改。工程上有两处改写：
  1. **记录字段：** 记录 `Inv` 的字段类型里直接写 `state m`、`value m`，**记录声明本身**在 6G 堆耗尽（退出 251）。改成对变量 R、v 参数化的 `InvR`，再由函数实例化，整件约 8 秒通过。机制未测，执行方推测是声明时对具体闭项的检查。
  2. **首站的 Real 字段：** 两边写法不同（`c₁ (state 0)` 对 `I2.c`），直接给出时 6G 耗尽。改为先证树相等 `base-c`（refl），再 subst。
- **最先需要改写的陈述：** 第一处就是 B 路的记录 `Inv`。这属于工程改写，不改数学陈述。
- **手册：** 这两条与手册 §4 "陈述逐字写、经非单射的头求解的隐式参数显式写出" 一类堆墙经验同类，可作为新条目补进手册 §4，由主审定。
