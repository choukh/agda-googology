# B10B · 独立核查真实分支并把逐项界接回 Ψ₃

请在协调者给定的私有 B10B 目录工作，以 `B10Exit` 为模块前缀。模型 Opus 5.5。先读公共源码 `YiLAB10Rows`、`YiLAB10Branches`、`YiLAB9Paths`、`B9InnerOuter` 的定义与签名，自己展开两个编号，再对照[主审的纸面推导](../指令-03.md)。可以独立于 A 路完成。

**交付。** `assemble : ((n : ℕ) → YiLAB10Rows.Row n) → YiLAB10Rows.Result`。Result 是 Level 的 ψ⁰(Ω₂+Ω₂) 不高于 W4 的具体 `read Ψ₃`。同时交一个可实例化的单项出口及分别对零号项、首个非零项的无前提调用。整个族作前提时，注明其统一实例依赖 A 路的回报。

1. 以同一个 k 对照 `YiLAB9Paths.S k`、`v k`、`cz k` 与 `YiLAB10Branches.states k`。在 `WKGen.Main ok₂ (S k) w2 (v k) ...` 中取 `fold 2`，核实 `zs 2` 与 `B.z k 2` 的定义性等式。该模块的 `hc` 由 Ω₁ 到第一次更新的步进与 `B.rise` 传递，两个零层正性前提由现成的 `v-bound`、`cz-bound` 和 `1≼ψ⁰` 推出。实际 `Ψg` 是 `v (suc k)` 的树。
2. 将单项出口量化为任意已经配对的具体 `D`，或再弱到只用它在原始分支上的被加项证据。取 `Match.add-l`、`L2-sem`，用 `Match.add-w` 对齐两边的底和链底，再经 `Ψg-ge 2`、`approx k` 推至 `read Ψ₃`。零号项可在 k = 0 用 `seed`，沿 `chain-step 0` 到 `c 0`，沿 `◃e` 到 `z 0 2`。首个非零项用 `row0`。最后以 `finish` 合并零号与各个后继号。核对这条证明对更高前缀和 `Gap′` 的依赖。
3. **独立反查。** 在同一接口刻意把首个非零项的原始状态替换成冻结初态，用 `frozen₀` 验证这个改写确实失效。另查若把零层底或 `inc tt (inc tt self)` 链底错用成初态，哪一个前提首先丢失。若能给出该具体错配的编译否定就交付；只发生类型失配就按其范围说明。若主审写错轨道或分支，优先报告有类型的反例或给出正确编号。该反查允许发现比 `Row` 更弱的充分条件。

每路约 1200 行，可换一次写法。只在私有目录写纯 Agda，不改 W4。用仓库工程选项，每次 Agda 带 6G 堆。需要经典原理时只作验收参数并标明。交回入口、源码、日志、首个错误或退出码、前提的实例及纸面首个偏差。尚未与 A 路合成时把结论写成条件定理。请分开记录 Level、src、塔和 Λ 四种端点。
