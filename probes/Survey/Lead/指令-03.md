## 第十批的纸面推导

**目标。** `Result = LV.ψ⁰ (Ω₂ᴸ LV.+ Ω₂ᴸ) ≼ read Ψ₃`，即 Level 参照给出的 ψ₀(Ω₂·2) 下界。把左端按定义展开，逐项恰是 `ψ⁰ (body (Y n))`，其中 `body D = Ω₂ + up D`。每一项的前缀都是同一个 Ω₂，已有 `L2-sem` 对 D 全称量化。要完成这一站，纸面推导用不到更高前缀的语义、`First` 的真假或一般两分量理论。它们在后续站点的作用仍开放。

1. **两类递推分开编号。** 令 `S₀` 为标准底族已更新一次后的状态，`Sₙ₊₁ = stepS F Sₙ`，令 `cₙ` 为它的第 1 层分量。在第 n 个状态内部，链 `zₙ` 从零迭代 `x ↦ ex cₙ cₙ (suc x)`。用 `zₙ(2)` 给外层折叠作被加项。用累加分支 `Uₙ(1) = ex (zₙ(1) + cₙ) cₙ (suc (zₙ(1)))` 把指数证据递交给下一状态。已经编出对任意 n 的字面展开和分支步进 `Uₙ(1) ◃ cₙ₊₁`。树侧模块的 Agda 依赖图中，项目模块只有 W4 块、运算、路径、折叠及既有树侧轨道。[树侧接口](attachments/YiLAB10Branches.agda.txt)
2. **局部归纳（纸面）。** 取规范指数不变量 `Real cₙ (eY n)`。起点来自初始 Ω₁ 经过一次膨胀。另把已知的一次更新的 Ω₂ 指数、Ω₁ 指数及被加项 `Nx` 沿 `rise` 保持下去。构造 `zₙ(1)` 时，同一 `cₙ` 在左侧实现 Ω₂，在底位实现归纳假设的 `eY n`，指数 `suc zero` 只需实现零影子。由 `RealX` 得 `eΩ₂ ⨾ eY n`。再作一次 `ex`，前缀只取正性，底取 Ω₁，指数用上一步和 `Real-up ◃s`。所得影子恰是 `eY (suc n)`。这对原始项与累加项分别可用。原始项上再用 `SumR-x` 配 `Ld-Y n`；累加项上用 `part n` 保持指数不变量。由此预期对所有 n 有 `Row n = Match (Y (suc n)) (zₙ(2))`。归纳假设明写指数，单独一个存在性的 `Match` 不能指定所拾得的影子。[公共命题与已编首例](attachments/YiLAB10Rows.agda.txt)
3. **外层出口（部分已编）。** 令 `v n` 为同一轨道逐次更新的零层底。第 n 个指数近似项就是从 `Sₙ, v n` 再运行一次 F，输出 `v (suc n)`。两个零层参数对一切 n 均不低于 ψ⁰(Ω₂)，且 `approx n : read (proj₁ (v (suc n))) ≼ read Ψ₃` 已编。若拿到 `Row n`，将其被加项部分交给 `L2-sem` 和 `WKGen.Main.Ψg-ge 2`，可望得到 `body (Y (suc n))` 的逐项界。零号另用种子 `Y 0` 沿 `chain-step 0`、`◃e` 搬到原始链项，再用同一出口。`finish` 已编，收齐各项后用极限左规则交付闭定理。[已编出口与零层参数界](attachments/YiLAB9Paths.agda.txt)

分工采用同一个已编接口。A 验证局部归纳，B 独立检查编号、首例及替换反例，写参数化出口；协调者在两路复核后实接。若一个关键步骤不成立，交精确反例或缩小后的缺口。沿用预算，两份简报均允许提出替代写法。对重复的挂起乘幂行，本批统一复用 `RealX`；旧接口要求的仅指数的一半有时更弱，未核前提之前不宣称旧引理均为直接特例。完整的反向 Level 理论保留作候选，`First` 继续开放。[协调简报](第十批/00-协调简报.md) · [A 的归纳简报](第十批/B10A-内链归纳.md) · [B 的独立核查与出口简报](第十批/B10B-外层验收.md)

## 第四十三份评估 · 第七至九批

**结论。** 按当前投入再做数周至一两个月，沿 W4 直接证明值下界，取得记号无关终点及“值 ≥ EBO”的编译定理，我估约 **9%（3%–17%）**，上一份为 8%（3%–16%）。旧线单独约 1%。这些数字是主审判断。第九批的新证据在第 3 步，有编译见证的外层闭项仍处于有限层。

**说明。** 本次上调来自更新后的具体状态确实改善了一个闭项的值证明。单个有限层仍不能校准含不可数层号的步骤；树侧自足也没有新定理。旧定义有 BTBO 以上的保底成果，外推到 EBO 的希望维持原判断，两线共享障碍，概率不能相加。三批有可核的实质变化，未触发连续五批无进展的复议条件。

**会改变判断的事件。** 只做成固定前缀的 ψ₀(Ω₂·2)，终点仍约 9%–10%。若统一容纳非零目标层的保留行并在 W4 塔上编出 ψ₀(Ω_ω)，第 3 步约 0.30，终点约 12%。若对层号一致地取得 BTBO 下界，第 3 步约 0.40，终点约 16%。若在实际所需塔项上编出严格低于相应参照的值界且阻断这条比较，现行比较路线第 3 步降至约 0.05 或以下，终点约 2% 或以下。`First` 的真假单独不改变终点估计。

**局限。** 范围是主观范围，步骤彼此相关；跨层或跨孩子所需的新论证已经超出本轮证据。主审也参与设计下一站，故纸面归纳尚未计作已取得的下界。按交接分工，由协调者将本节写入 GoalOdds 第四十三份，保留旧条目。
