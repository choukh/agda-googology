# 指令 02 · 第八批主审判决与第九批派工

**W4 的第一次状态更新已经给出可观测的零层值增长。** 对同一参照树 `X₀`，更新一次有完整见证，冻结初态有编译否定。对包含它的整棵 `Y 1`，冻结初态已否定，一次更新仍开放。第九批固定整棵 `Y 1`，比较一次更新与两次更新。两路由协调者按简报派出，作者手工转达。

## 复核与补证

承接[协调回报](协调-01.md)。我从仓库附件和指令 01 附录恢复纯源码，在新的私有目录串行冷编。Agda 以 6G 堆检查 `B8FreezeMain`、`B8PairMain`，退出码均为 0；四个新模块各有自己的 Checking 行。核了四个模块的签名、关键证明以及两份主审补件。六份源码均使用 `--safe --without-K`，只含 OPTIONS 编译标注，没有公设、洞或经典参数。仓库和已安装库的接口可复用。[构造路留档](../Reports-2026-11-16/B8A.md) · [冻结路留档](../Reports-2026-11-16/B8N.md)

| 同一个参照 | 初态 `chainW 0` | 一次更新 `chainW 1` | 两次更新 `chainW 2` |
|---|---|---|---|
| `X₀`，即 `Y 1` 的零号分支 | 主审补证 `no-X₀-at-zero` | B8A 的 `first₀`，被加项与指数两个消费者均已实例化 | 由 B8A 的 `first₀-up` 取得 |
| 整棵 `Y 1` | B8N 的 `no-frozen` 对任何共同描述都成立，仅被加项字段已足以推出矛盾 | `First` 开放。`no-merge` 只排除指定描述的一个放宽不等式 | `Second` 开放，第二次更新的实际分支可直接用于试证 |

补证可以用同一个数值比较读懂。记 `out n` 为 W4 在同一条路径和同一底族上，把 `chainW n` 折到零层的读回。B8N 已给 `out 0 ≼ ψ⁰(Y 0)`；在 Level 的具体分支上展开，得到 `suc (ψ⁰(Y 0)) ≼ ψ⁰ X₀`。从 B8A 的 `first₀-up` 取被加项消费者，就有 `ψ⁰ X₀ ≼ out (suc n)`。合成即得 **`gain : ∀ n → suc (out 0) ≼ out (suc n)`**，所以在这个消费者上，任意正次数都严格高于初态。若初态已能承载 `X₀`，同一个消费者会给出 `suc (ψ⁰(Y 0)) ≼ ψ⁰(Y 0)`，与 B8N 的不自降定理矛盾。`X₀` 的配对带指数证据；严格增长这一步只用了被加项。该界以初态为基准，未比较相邻的任意两次更新。[主审值补件](attachments/YiLAB8Split.agda.txt)

B8A 另给出了对所有 n 的 Level 指数描述及对 `Y (suc n)` 的被加项描述。执行方关于 `First` 为假、或整条参照链可在第二次更新中找到的说法仍是判断。已证 `X₀` 的零层折后值严格低于 `Y 1` 的零层折后值，把整棵树作为下一题有实际区分度。本次未取得 `ψ⁰ (body (Y 1)) ≼ read Ψ₃` 或 ψ₀(Ω₃) 的下界。

## 第九批的共同题目

令 c 为一次更新后的状态。按 W4 的更新行，从零开始迭代 `z (suc k) = ex c c nc (suc (z k)) tt`，对正编号项取部分和，记 `U k = cum (λ j → z (suc j)) k`。主审补件证明每个 U k 都是第二次更新所产出极限的**实际分支**，`U 1` 定义性地等于 `ex (z 1 + c) c nc (suc (z 1)) tt`。这条树侧结果只导入 W4 的块、运算、路径、折叠与上批的树侧补件；已用 Agda 依赖图核对。值侧已有 `inner-seed : Match X₀ (U 0)` 和 `to-second : Match X (U k) → Match X (chainW 2)`。原始内链项和累加分支不同，使用哪个须在定理里写清。[树侧补件](attachments/YiLAB9Orbit.agda.txt)

- **B9A** 尝试 `Match (Y 1) (U 1)`，或给出有依据的另一实际分支。可直接在整树上证 `Second`，或以闭的外层值不等式交付。生成树出现了什么由树侧证明给出，Level 的描述只用于验收。[构造简报](第九批/B9A-第二次更新.md)
- **B9N** 对同一个 `Y 1` 检验一次更新的容量。首试给 `out 1` 可严格分离的上界，以被加项消费者裁定 `First`。若构造出 `First`，同样接受，须同时实例化两个消费者。两路只读同一接口，可并行。[对照简报](第九批/B9N-一次更新上界.md)

若 `Second` 有见证且 `First` 有否定，由 `no-frozen` 及 B8A 的向上封闭可判定：在这条轨道上，整棵 `Y 1` 首次能以该接口配对的更新次数是 2。若 `First` 成立，则首个次数是 1；若只有 `Second`，只能给出次数上界 2。单个分支或单个消费者的否定均按各自量化范围登记。当前仍缺从局部配对到第三层闭项实际输出的证明。

沿用每路约 1200 行、可换一次写法、每三批复评及连续五批同一必经缺口未动才交作者的约定。本批不更动 W4 定义。第九批齐后，协调者按[协调简报](第九批/00-协调简报.md)写 `协调-02.md`，主审再按 GoalOdds 六项格式评第七至九批。第四十二份的数字保留其原时间口径。
