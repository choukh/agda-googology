# 协调 01 · 第八批两路的复核

**结论：`Frozen` 有编译否定，`First` 仍开放。** `Frozen` 无见证、有否定：`no-frozen : Frozen → ⊥`，无前提。`First` 无见证，也无否定：B8A 未走通，执行方判断它在值上为假，这一条只是纸面。另有一个非初始配对的见证 `first₀ : Match X₀ (chainW 1)`，其中 X₀ 是 `Y 1` 的第 0 支 ψ(Ω₂)。按协调简报的判据，"`First` 与 `Frozen → ⊥` 同时成立" 没有达到，所以还不能说这一处的比较需要更新。路线判断交主审。

## 1. 执行与复核方式

- **公共目录：** 按 `第八批/00-协调简报.md` 的准备段原样执行。库文件取自协调者已有的文件，即环境变量 `B8_LIBRARIES`。`WKAll`、`YiLAB7Orbit`、`YiLAB7Replay` 各自退出 0，各有自己的 Checking 行。本批目录记作 `<B8_RUN>`。
- **派发：** 两路都用 Opus 5.5，并行，简报全文原样。派发消息只在简报前加了 `<B8_RUN>` 路径与 "最终消息就是回报原文" 一句。作者没有手工另派。
- **复核：** 在执行者交付目录之外另建私有目录 `<实验目录>/verify/b8rev/`，只复制源码，包括 `<B8_RUN>/B8Common/*.agda` 与两路的 `*.agda`，不复制任何 `.agdai`。从仓库根逐路串行运行：
  ```
  agda +RTS -M6G -RTS --library-file=<库文件> -i src -i probes -i <私有>/common -i <私有>/<路> <私有>/<路>/<入口>.agda
  ```
  退出码不经管道。

| 路 | 入口 | 退出码 | 自己的 Checking 行 | 首个错误 | 用时 |
|---|---|---:|---|---|---|
| B8N | `B8FreezeMain` | 0 | `B8FreezeMain`（同次运行公共源码共 17 个模块从头检查） | 无 | 39 秒 |
| B8A | `B8PairMain` | 0 | `B8PairMain`、`B8PairLevel`、`B8PairW4` | 无 | 7 秒（公共接口复用上一次的私有编译） |

- **扫描：**
  - 四份新源码第一行都是 `--safe --without-K --lossy-unification --cubical-compatible --guardedness --hidden-argument-puns`；
  - 没有 postulate、洞、停机或正性编译指示；
  - 没有用排中律或函数外延；
  - 没有本机路径。
- **依赖图：** `B8FreezeMain` 用 `--dependency-graph` 核过。项目模块是 W4Block、Ops、Path、Fold、WV*、WS*、WK*、YiLAB7Orbit、YiLAB7Replay，以及经 WVOne 继承的 `OCF.Align.*` 记号与参照模块，后者包括 BTBOValMain、Label、Prefix 等。两路都是纯第 4 层验收文件，这一点符合预期；没有新增树侧构造，翻译账为零。B8A 自己的依赖图在 `<B8_RUN>/B8A/main.dot`，执行方报告的项目模块相同，协调者没有另编。
- **警告：** 只有 `UnsupportedIndexedMatch`，B8A 一次运行里共 56 条，绝大多数来自公共依赖。

## 2. `Frozen`：有否定（B8N）

| 名字 | 签名 | 档位 |
|---|---|---|
| `no-frozen` | `Frozen → ⊥`，证明体逐字为 `no-frozen m = refute (consume m)` | 编译定理，无前提 |
| `refute` | `LV.ψ⁰ (Y 1) ≼ read (proj₁ (ψ lvl1 (proj₂ ok₂ tt) (B₀ lvl1) zero (inc tt self) (Ωt zero) (chainW 0))) → ⊥` | 同上。左右端与公共接口里 `consume` 在 x = `Y 1`、y = `chainW 0` 处的目标逐字一致（已对照 `YiLAB7Replay` 源码） |
| `no-add` | `(d : Sh 0) → SumR (chainW 0) d → L.Ld (Y 1) d → ⊥` | 同上，对一切 d |
| `fold-val` | 冻结折叠的读回 `≈ᵛ LV.ψ⁰ (Y 0)` | 同上（`fold-up` 与 `consume seed`） |
| `low` | `LV.suc (LV.ψ⁰ L.Ω₁ᴸ) ≼ LV.ψ⁰ (Y 1)` | 同上，定义性展开 |
| `irr` | `(x : T₀) → LV.suc x ≼ x → ⊥` | 同上 |

- **被否定的字段：** 只有被加项的两个字段 `add-w` 与 `add-l`；`e₀`、`exp-w`、`exp-l` 不参与。
- **机制是值界矛盾：** 冻结折叠的值等于 ψ⁰(Y 0)，而 ψ⁰(Y 0) 的后继不高于 ψ⁰(Y 1)，在第 0 层得 `suc x ≼ x`。不是比头构造或计算路径。
- **不是空真：** 同一棵冻结树在 `Y 0` 上有 `seed`，失败的是 Level 字段。
- **未判定：** 单看指数一半时，`consume-exp` 的冻结实例是否可满足。执行方说卡在缺 W4 侧的上界。

## 3. `First`：仍开放（B8A）

**编译定理，无前提：**

| 名字 | 签名 | 说明 |
|---|---|---|
| `first₀` | `Match X₀ (chainW 1)` | `X₀ = QB LV.zero`，即 ψ(Ω₂ + 0)，是 `Y 1` 的第 0 支。共用描述 d = `d₁`、e = `lC ε`，四个字段属同一对。Level 一侧只用了下标平移一格的放宽（`shift-d`、`shift-e`） |
| `c-add₀` | `LV.ψ⁰ X₀ ≼ read (proj₁ (ψ lvl1 (proj₂ ok₂ tt) (B₀ lvl1) zero (inc tt self) (Ωt zero) (chainW 1)))` | `consume first₀` |
| `c-exp₀` | `LV.ψ⁰ (WL.ψ₁ X₀) ≼ read (proj₁ (E o₁ tdNil (chainW 1) Ω₁op (B₀ lvl1) zero (inc tt self) (Ωt zero)))` | `consume-exp first₀`，用到指数字段 |
| `Lx-Y`、`Ld-Y` | `(n : ℕ) → Lx (Y n) (eY n)`；`(n : ℕ) → Ld (Y (suc n)) (sE (eΩ₂ ⨾ eY n) Nx)` | 主审说的 Level 一侧两项义务，对一切 n |
| `Real-c1`、`SumR-c1` | `Real (chainW 1) (lC ε)`；`SumR (chainW 1) d₁` | W4 一侧 `chainW 1` 的描述 |
| `Match-up` | `lvl1 ⊢ y ◃ y′ → Match x y → Match x y′` | 沿 W4 的结构步进向上封闭（`SumR-up`、`Real-up`） |
| `frozen→first` | `Frozen → First`，证明为 `Match-up (chain-step 0)` | 与 B8N 合看：`Frozen` 为假，这条只说明 `First` 至少与 `Frozen` 一样容易 |
| `seed-up`、`first₀-up` | `Match (Y 0) (chainW n)`；`Match X₀ (chainW (suc n))` | 对一切 n |
| `Goal-add`、`Goal-exp` | `First` 的两个消费者目标，左右端逐字写出；`first→add`、`first→exp` | 只是定义与投射 |
| `no-merge` | `Le 0 dY1 d₁ → ⊥` | 只否定 "用 `d₁` 这一个描述容纳 `Y 1`"。`first-if` 的第一个前提因此不可满足，不给正面结论 |
| `X₀≺Y1` | `LV.suc (LV.ψ⁰ X₀) ≼ LV.ψ⁰ (Y 1)` | `Goal-add` 的左端严格高于 `c-add₀` 的左端 |

- **没有检查的：** `at-step 1` 给出的结构描述能否容纳 `Y 1`。执行方说要否定它需要影子对参数的单调性，未做。
- **执行方的判断（纸面，未编译）：**
  - 编号配错了位：W4 的一次更新是 c ↦ c + "Ω₂ 折到第 1 层"，Level 的链步是 x ↦ ψ(Ω₂ + x)，所以 `chainW 1` 对应 X₀，而 `Y` 的整条链落在 `chainW 2` 之内；
  - 粗读 ψ⁰(Y 1) 约为 ψ₀(ε_{Ω+1}·Ω)，高于 W4 对 `chainW 1` 的折叠，所以 `Goal-add`、`Goal-exp` 都为假；
  - 有值依据的候选配对是 `Y n` 对 `chainW 2` 的内链项，纸面核到 n = 1、2，没有编译。
- **强度：** `first₀` 的两个不等式没有超出既有的 ψ₀(Ω₂) 量级；`ψ⁰ (body (Y 1)) ≼ read Ψ₃` 未动。
