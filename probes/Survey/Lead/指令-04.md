## 主审补证

令 `ss 0 = src.Ω₂`，`ss (suc n) = ss n + src.Ω₂`；在 Level 定义同样左结合的 `ll`。两种既有结构关系分别由 `M-Ω / M-add`、`Dn-Ω / Dn-add` 对 n 归纳，再经两方向的折叠保持定理。参照树自身的结构相容性沿加法保持。由此得到 `multiple n : tr₀ (src.ψ₀ (ss n)) ≈ᵛ ψ⁰ (ll n)`。极限两侧逐支对应，`omega` 给出两列取极限再折叠后的同值。取 n = 1 与第十批的 `double` 合成，得到 `src-double`。对任意 n 证明的是**两个参照**互相 ≼，其到 W4 的下界目前由这条实接直接给到两份 Ω₂。[已编译源码](attachments/YiLAB10Src.agda.txt)

## 第十一批推导

**目标**为同一个 Ψ₃ 的闭下界 `ψ⁰ (lim ll) ≼ read Ψ₃`，经已编 `src-exit` 可读成 src 的 ψ₀(Ω₂·ω) 下界。为避免逐个倍数另出一套证明，归纳量取“当前前缀中有几份 Ω₂”。`m = 0` 从一份起。保留原来的参照链编号 n，每个 n 只在当前前缀内使用。

| 已由 Agda 检查的接点 | 数学作用 |
|---|---|
| `next-shape m`、`q-shape m` | 加一份 Ω₂ 后，零层目标和第 1 层折叠的起点，均按同一条旧前缀的链展开。这对任意 m 成立。 |
| `Stage 0` 的实例 `stage0`、`base-d`、`base-x`、`first-new-x` | 起点复用第八、九批。下一前缀的基例从上一整条链取得，已有第一处换前缀的指数实例。`Stage m` 要求该前缀下的链点描述和被加项语义。 |
| `child-in-G`、`in-child`、`project-state`、`project-value` | 对任意真实底族，外层运算 G 的一个具体下方极限包含 F 的每次正迭代。进孩子语境后的底族投影由自然数归纳相等，不用函数外延。树侧依赖图中的项目模块为 W4 的块、运算、路径、折叠及既有树侧轨道。 |
| `outer m`、`collect`、`src-exit` | Ψ₃ 的外链第 2 项给出 G 的每个正次数迭代。只要能在这些实际输出中交付各前缀的值界，便可取极限并直接落到 src。 |

这些补件独立编译退出 0，构造性选项与项目一致。[树侧轨道](attachments/YiLAB11Orbit.agda.txt) · [验收接口](attachments/YiLAB11Target.agda.txt)

**A 路的纸面归纳。** 在已有前缀 P 右侧再加 Ω₂。新前缀指数取 `lC (λ n → prefix m ⨾ track (prefix m) n)`，即对“旧前缀指数与第 n 个链点指数的和”取极限。由上一轮全体链点的两个描述分别得到新基例 `base-d` 与 `base-x`。固定 P 后，按输入树的指数描述归纳，把 `B8PairLevel.LdQ / LxQ` 的固定 Ω₂ 前缀改为 P，零层尾部沿原来的结构序证明。被加项语义按 `Ld` 证明归纳，其零号行使用 `ψ⁰ P` 的界。递推内部保留全体指数描述，最后对外只交 `Stage m` 所需字段。

**B 路的纸面归纳。** F 为第 2 层 Ω 运算。G 把 Ψ₃ 外链第一个非零原始项当作指数运行 F。归纳状态包括：两个指定零层位置都支配 `ψ⁰ P`，第 1 层槽位实现 `prefix m`、Ω₁ 指数和被加项 Nx，并有 Ω₁ 到此槽位的结构步进。初态用第一次 F 更新后的现成结果。对一次 G 更新，先在其中的真实子极限内沿 F 重演第十批的 n 归纳。被加项在原始链第 2 项消费，累加分支 1 把当前链点的指数传给下一 n；此外，分支 0 携带的第一原始项实现 `prefix m ⨾ track (prefix m) n`。将后者沿所有 n 取极限并搬到 G 的实际输出，就得到下一 m 的前缀指数。分别在零层底和链底路径消费 A 路的语义，即可递交下一 m 的两个数值界。具体槽位和正反对照见 B 路简报。

核心待验证的是上述两套归纳能否在每次更换前缀时保持全部前提。只做部分结果时优先给出第一处换前缀后的闭结果，标明它作用在哪个状态和闭项。现阶段 ψ₀(Ω₂·ω)、ψ₀(Ω₃) 仍待证。第十一批不改前三层，不排除其它路线；第十二批后再作正式三批复评。[第十一批协调简报](第十一批/00-协调简报.md)
