## 公共源码

在仓库根执行下列整段，分发最后列出的 `B11_RUN`。库文件可由 `B11_LIBRARIES` 指定。两路目录分别为其下 B11A、B11B，公共模块在 common，日志在 logs。

```sh
export B11_RUN="$(mktemp -d "${TMPDIR:-/tmp}/agda-b11.XXXXXXXX")"
python3.11 - <<'PY'
import os
import re
import shutil
import subprocess
from pathlib import Path

root = Path(os.environ["B11_RUN"]).resolve()
for name in ("common", "B11A", "B11B", "logs"):
    (root / name).mkdir()
common = root / "common"
survey = Path("probes/Survey")
lead = survey / "Lead"
archive = survey / "Reports-2026-11-16/attachments"
for group in ("B4W4", "DefD1", "RedefS1", "B5D", "B6A", "B7A", "B8A", "B8N", "B9A", "B9N", "B10A", "B10B", "B10Join"):
    for source in sorted(archive.glob(group + "-*.agda.txt")):
        name = source.name.removeprefix(group + "-").removesuffix(".txt")
        (common / name).write_bytes(source.read_bytes())

parts = re.findall(r"(?ms)^```agda\n(.*?)^```$", (lead / "指令-01.md").read_text())
modules = [re.search(r"(?m)^module (\w+) where$", part)[1] for part in parts]
assert modules == ["YiLAB7Orbit", "YiLAB7Replay"], modules
for name, code in zip(modules, parts):
    (common / (name + ".agda")).write_text(code)
for name in ("YiLAB9Orbit", "YiLAB8Split", "YiLAB9Paths", "YiLAB10Branches", "YiLAB10Rows", "YiLAB10Src", "YiLAB11Orbit", "YiLAB11Target"):
    (common / (name + ".agda")).write_bytes((lead / "attachments" / (name + ".agda.txt")).read_bytes())

libs = root / "libraries"
if os.environ.get("B11_LIBRARIES"):
    libs.write_bytes(Path(os.environ["B11_LIBRARIES"]).read_bytes())
else:
    base = Path(shutil.which("agda")).resolve().parent.parent / "share/agda"
    paths = [base / "stdlib/standard-library.agda-lib", base / "cubical/cubical.agda-lib"]
    assert all(p.is_file() for p in paths), paths
    libs.write_text("".join(str(p) + "\n" for p in paths))

args = ["agda", "+RTS", "-M6G", "-RTS", "--library-file=" + str(libs),
        "-i", "src", "-i", "probes", "-i", str(common)]
checked = set()
for name in ("B10Join", "B10ExitMain", "YiLAB11Target"):
    log = root / "logs" / (name + ".log")
    with log.open("w") as out:
        run = subprocess.run(args + [str(common / (name + ".agda"))], stdout=out, stderr=subprocess.STDOUT)
    names = set(re.findall(r"(?m)^\s*Checking (\w+) \(", log.read_text()))
    print(name, "exit", run.returncode, "own Checking", name in names, log, flush=True)
    if run.returncode or name not in names:
        raise SystemExit(run.returncode or 1)
    checked.update(names)
expected = {p.stem for p in common.glob("B10*.agda")}
expected.update(("YiLAB10Src", "YiLAB11Orbit", "YiLAB11Target"))
assert expected <= checked, expected - checked
print("B11_RUN =", root)
PY
```

## 复核与合成

每路每次一个 Agda 进程。以 6G 堆运行，退出码不经管道，日志落文件。从执行目录只取源码，在另一私有目录冷编，检查各模块自己的 Checking、签名、禁用项和依赖。编译模板如下，替换占位符。

```sh
agda +RTS -M6G -RTS --library-file="$B11_RUN/libraries" -i src -i probes -i "$B11_RUN/common" -i "<本路目录>" "<本路入口>" > "<本路日志>" 2>&1
```

收到两路后建独立合成入口，先以 `B.run-stages A.stages` 检查 Level 闭定理，再由 `YiLAB11Target.src-exit` 检查 src 闭定理。若执行者提供了不同签名，用可实例化的实际结论接合。若仍有缺口，记录其量化范围、在哪一层、哪个槽位，用已编的最大子结论交付。

归档每路简报、原回报、源码和合成入口。在 `probes/Survey/Lead/协调-04.md` 写首个与纸面不同之处、实际端点、主审补件与本批执行结果，以及派发、完成、复核和合成时间。本批主审从私有复核目录建立到简报就绪的可测时段见指令 04。两路都复核后交回。
