1. 记 `R = state m`，`C = c₁ R`，`v = value m`，`zpath = inc tt (inc tt self)`。归纳携带 `ψ⁰(ll m) ≼ read (proj₁ v)` 和 `ψ⁰(ll m) ≼ read (proj₁ (R zero zpath))`，再携带 `Real C (prefix m)`、`Real C Ω̂`、`SumR C Nx`、Ω₁ 到 C 的结构步进。首站各项来自 `B9InnerOuter`、`B9InnerSecond` 与 `chain-step 0`。在任意 R 下做下面的单步，以 `Stage m` 作为参数。
2. 一轮 G 中有一个确切的子极限 `O.child`。它在各目标的第 n 支是 `O.kid n`；`O.project-value (suc n)` 把它对齐到以 R 为底族的 F 正迭代。对沿 F 的第 n 个状态，保持以上旧前缀的下界及描述，另传 `track (prefix m) n`。复用 `RealX`、`Real-up` 和 `SumR-x`，按 B10 的槽位取证。原始内链第 1 项实现 `prefix m ⨾ track (prefix m) n`；原始第 2 项供被加项消费。**分支 1** 将新链点指数传给下一次 F，**分支 0** 将第 1 项的指数传入这次 F 更新的结果。F 在自己槽上的 `itV` 与 `itS` 投影，必要时用自然数归纳取相等；不可默认为所有 n 的 refl。
3. 用 `Real-lim` 对 `O.child` 的实际分支取上一步给的第 1 项指数，再沿 `child-in-G` 与 `Real-up`，得到更新后的 `prefix (suc m)`。对零层两条指定路径分别用 `WKGen.Main` 的 `Ψg-ge 2` 与 `Stage.sem/lower` 构造下一前缀逐项值界；在零号参照项用 Ω₁ 种子，后继项用原始链第 2 项。逐项用 `in-child` 与 `child-in-G` 提升，`next-shape` 合并。两条路径的 `WKGen.wd` 随目标路径取，实际链底都要核到 zpath。Ω₁ 的结构步进、Ω₁ 指数与 Nx 沿 G 的 `inf` 保持。最后用 `outer`、`collect`。可改写接口，或直接交更强的闭定理。
