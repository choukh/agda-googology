#### 1 这个候选要试什么

主线 `YiLean` 的闭项与参照有三处形状不同: (i) 后继的 ω 倍从第 1 项起 (`succ m y = lim (acc (λ _ z → plus m y z) y)`: y, y+y, …), 参照从零起; (ii) 链从顶 (`top`, 读成 1) 起并且累加 (下一点是这一点加上折叠值), 参照的链不累加; (iii) 加法把被加数放在叶上.

#### YiZero 一路回报：候选甲 (基本列向参照对齐)

##### 1 判决

**C2 没有通过，有编译否定。C3 因此不适用。C2′ 只有条件定理。C4 通过。**

- **C2 否定。** `no-L : ∀ n m → ¬ (D.L (suc n) ⊑ᴵ κ m)`，`C2 = no-L 0`。
  - 原因在外层链的形状：下一点 = 这一点 + 折叠值，这一点放在叶上。只要起点非零，每个 ℕ 极限的第 0 项都不是零 (`NZ`)，所以 κ m 里没有 ≅ᴵ ω 的字面前驱。而参照的 `D.L 1` 含字面的 ω+1 (`sω-L1`)。
  - 这个否定与折叠怎么取基本列无关。`NZ-add` 对加数没有任何前提，`nz-any` 对任意步进函数 `s` 都成立。
- **正对照。** ω 倍改成从零起之后，折叠值里出现了字面的 ω+1 (`sω-F1`)，主线没有。也就是说，基本列的对齐在折叠这一层做成了，结构不可比只来自链。
- **C2′ 只有条件定理，前提是平移律。**
  - 条件定理 `c2′ : Tr → D.γ 1 ≼ᵖ read (co (pts 1))`。`Tr` 是只谈第 0 层参照树的平移律：`∀ X x y → x ≼ˣ y → x ≼ˣ (X L.+ y)`。
  - `tri→tr : Tri → Tr` 是编译定理，所以 `Tr` 在经典模型里成立。但 `Tri` 推出 LPO，所以这个前提的可满足性只在经典意义上。
  - 由此得到判断：C2′ 经典地成立，不会有编译的否定。
- **C4 通过 (下界，不是同值)。** ψ₀(Ω₁)、ψ₀(Ω₂) 分别 ≼ 读回的第 1、2 层闭项，ψ₀(Ω₂) ≼ 读回的 `T₃`。`T₃` 的 ψ₀(Ω_Ω) 仍只是读法。

**对纲领与目标的意思。**
- 闭项合法、证书无前提、塔与 Λ 合法，纲领 1、2、4 都守住了。
- 在 "仍允许链累加" 的范围里，结构可比做不到：机制是编译事实，而且对任何 "上一点放在叶上" 的累加链都成立。
- 把加数次序反过来 (折叠值放在叶上) 能保住参照的结构，但合法性要求折叠在链点上字面地抬高 (`Cp cₙ (G cₙ)`)。判断 (纸面)：它在 c₂ 处不成立，因为 c₂ 头上的极限结点 `G c₁ + G top` 不会在 `G c₂` 里字面出现。我没有在检查器里试反序，这一条只是判断，不能写成路线已否定。
- 另一条纸面判断 (没有编译)：内层链若不累加 (cₙ₊₁ = G cₙ)，合法性可以由 `top<` 加 `Ψ-cp` 加分支的单调直接得到。外层链 (`T₃` 的根) 却不行：`tw 3` 的各支在不同的层上，`F` 只沿加法前缀单调 (`F-up`)，又因为极限层号处的部分和，`F` 不保持第一位置。所以外层的累加是合法性逼出来的。

##### 2 设计：与主线 YiLean 相比改了什么

1. **ω 倍从零起** (`YiZeroFold.succ`)：`succ m y = G.lim (acc (λ _ z → plus m y z) G.zero)`，基本列是 0, y, y+y, …，与参照的 `ψ⁰ (suc a)` 一致。

##### 5 代价与翻译账

**对合法性证明的影响 (全部来自 ω 倍从零起)。**
- 新增 `add-top` (原来是 `add-weak` 的 `top` 子句)、`zero≤`、`top<`，加上 `Ψ-dn` 与 `add-dn` 各多一个 `top` 子句。
- 后继的第一位置从第 0 项改走第 1 项 (`Ψ-dn` 的后继情形是 `1 , …`)。ω 倍的第 0 步要前提 "`zero` 是 y 的第一位置"，由 `zero≤` 给出。
- 塔一侧多了 `CP-zero` 和一个子句；`Tw3` 的 `sh` 与 `dn-tr` 各多一到两个子句。
- 切片多 21 / 23 行。

**翻译账。**
- ω 倍从零起是 "向参照对齐"：参照是 Level 框架的树，它的 ω 倍照 BTBO/EBO 从 0 起。树自身没有要求它。
- `Dn y a G.top = a ≡ G.zero` 是这个对齐之后合法性逼出来的，属于树侧的要求。
- 这一步带来的信息：
  - 基本列对齐了，结构不可比仍在 (`no-L` 换了一棵树照样成立)。障碍完全在链的累加形状，不在基本列。
  - 第 0 层的折叠与参照 ψ⁰ 结构互模拟 (`readΨ`)。
- 对另一路 "每一项不低于它自己层号上的参照"：在第 0 层，值的证明现在可以经结构的 ≅ 走，不用逐步追 ≼。`read-copies` 从零起，`suc-lower` 缩成一行，容易了。代价是 `T₃-Ω₂` 的路径多一步 `plus≽`：第 1 个链点的头是 `top + W`，其中 `W` 从零起。

##### 6 第一个障碍、偏离与事故

**C2′ 卡在 `≼ˣ` 的 `sˣ` 上。**
- `lᵖ` 要求参照的每一项 ψ⁰(G n) ≼ˣ 链点的读回。`sˣ` 要旁证 `b ≼ a`，即两边顶的值相等。
- 链点是 X + y (X 是上一点，≥ 1，放在叶上)，它的后继结点是 suc (X + b′)。要对上参照的结点 suc a，需要 X + b′ ≈ a。这只在 b′ ≥ X·ω 时靠吸收成立。更小的结点必须改道，经 `wˣ`/`≼lˣ` 进 X 的结构里找，而选哪一边是一次值上的判定 (Tri 型)。
- 需要的两个实例：
  - X = read cₙ (内层链点，n ≥ 1 时是无穷的)；
  - X = 1 (外层第 1 点 = 1 + F top)。
- 判断 (没有试)：X = 1 的实例似乎可以构造地证，办法是给参照的项加一个结构上的有限/无穷谓词，吸收改用左边的 `1 + a ≼ a`。X 无穷的实例需要参照树上的左减法结构。
- 一般的 n 我没有做：它还要更高层上的同类引理，以及 n > 2 的值下界。

**偏离与事故。**
- Fold 里没有抄主线的 `top-as-node` 行，用不到。
- AccFin 是主线 AccFin 的副本，改动是：后继的索引从 0 改成 1、`read-copies`/`copies-⊴` 从零起、`T₃-Ω₂` 的路径；它自带一份 `read` 与 `fin`。
