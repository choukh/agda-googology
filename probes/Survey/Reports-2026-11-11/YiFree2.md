#### 一句话的任务

**从空白页写, 不导入仓库里的任何模块: 照已封存的 BTBO (`src/OCF/BTBO.lagda.md`) 的写法, 只把层号换成一棵含 Ω 结点的树 (层号本身是树, 所以 Ω, Ω_Ω 那样的不可数层号也是层号); 写出把 "塔的第 3 项" 折到第 0 层的闭项与它的合法性证书; 塔的每一项与塔的极限 Λ 要合法; 定义, 折叠, 合法性三层合计 500 行以内; 现在只要闭项与合法性, 强度以后用值定理验收.**

名词: 塔 `tw 0 = 0`, `tw (n+1) = Ω̂ (tw n)`, Ω̂ 是 "层号 x 的下一个 Ω" (Ω̂ 0 = 1, Ω̂ 1 = Ω₁, Ω̂ (k+1) 是以第 k 层的树为分支下标的 Ω 结点, 极限处逐项); `Λ = lim tw`. "塔的第 3 项" `tw 3` 是一个以第 0 层的树 η 为下标, 第 η 支是 "第 η 层的 Ω" 的结点; 把它折到第 0 层得到的可数的树读作 ψ₀(Ω_Ω), 与 BTBO 同一高度. "合法" 指树的每个 ℕ 极限相邻两项按 "第一位置" 步进 (第一位置: 沿基本列第 0 项或后继的前驱, 结点处沿某一支, 一路走下去能到达), Ω 结点的各支合法并且对下标单调.
