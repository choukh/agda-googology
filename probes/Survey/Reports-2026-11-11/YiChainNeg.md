#### 1 问题是什么

`≼ᵖ` 是值序 `≼` 的一个子关系: 推导的形状与 `≼` 相同, 但在左极限之下, 每一步 "后继对后继" (`sˣ`) 都要附带两边顶的值相等的证据. 在这个定义域上值单调是定理 (`VMᵖ`), 所以 `ChainP` 推出与 BTBO 持平. 构造路的障碍: 主线的链是累加的 (下一点 = 这一点 + 这一点的折叠值, 上一点放在叶上), 链点里的后继形如 `suc (X + b′)`, 参照里的后继形如 `suc a`; 要对上就要 `X + b′` 与 `a` 值相等, 而推导被迫在 "相等" 与 "严格小" 之间选. 问题是: **对具体的闭对象, 这样的 `≼ᵖ` 推导是否存在.** 值上 `D.γ n ≼ read (co (pts m))` 应当成立 (它已由别的定理间接给出, 或可以直接证); 不成立的只可能是 `≼ᵖ` 这个子关系太严.

## 回报原文

#### YiChainNeg 回报：`ChainP` 的否定路

##### 1 判决

**N1 的否定写不出来。** 编译定理 `lem→chainP : LEM → ChainP` 推出：`∀ m → ¬ (D.γ 1 ≼ᵖ read (co (pts m)))` 推出 `¬ LEM` (`no-N1`)；对每个 m ≥ 1，单独一条的否定也推出 `¬ LEM` (`no-N1⁺`)。更一般地，对一切 n ≤ m，否定都推出 `¬ LEM` (`no-neg`)。
- Agda 在这些选项下与 LEM 相容 (集合论模型)，所以 `¬ LEM` 不可证。这一句是元定理，算判断，没有编译。
- 因此 `ChainP` 与它在 n = 1 的情形，都不会有编译的否定。

**对纲领的意思。**
- 在经典逻辑下，`≼ᵖ` 作为一组对的集合与值序 `≼` 相同，并不 "太严"。它的代价在构造性上：推导要在每个左极限之下的后继处，判定 "顶的值相等" 还是 "严格小"。
- 对链点对，缺的只是这些局部判定 (`triOn→chainP`)：参照的前驱 a 与链点的前驱 b 之间的三歧。
- 能写出来的否定，只有 m = 0 这一种，原因在值上：`neg₀ⁿ`，n ≥ 1。`ChainP` 允许换下标 m，所以这条不挡路。

**机制 (N2)。** 编译定理只覆盖证法，不覆盖 `ChainP` 本身。障碍在于链是一边累加的：链点是 `X + y`，参照项不带前缀。
- 两边都加值相等的前缀时，`≼ˣ` 封闭，不需要判定 (`+ˣ`)。
- 只有一边左加时：
  - 左加 1：在严格的右树上封闭 (`add1-strict`)；在一般右树上推出 LPO (`add1→LPO`，探针退化)。
  - 左加 ω：即使只限严格的右树，也推出 LPO (`addω→LPO`，探针严格)。
- 所以 "按吸收与否改道" 这一判定，靠严格性给不出来。要靠链本身的结构。

**能容纳链点对的定义域 (N3)。**
- `≼ᵖ` 本身，在 LEM 下或有 `TriOn` 时，都能容纳。
- 去掉 `sˣ` 的第二前提，得到的就是 `≼` 本身 (`≼ʳ`)。n = 1 的对无条件在里面 (`in-ʳ₁`)，但那里的值单调等价于 `VMᴸ` (`vmʳ↔`)，又回到原来的开放问题。

三条 LPO 否定的读法：
- **`add1→LPO`**
  - 否定的是：对一切右树的 "左加 1 封闭" 引理。
  - 探针：`tα α`，0/1 的极限，是退化对象，读作 "谓词太宽"。
  - 配对的正面结果：`add1-strict`。
- **`cplˣS→LPO`** 与 **`addω→LPO`**
  - 否定的是：对一切严格树的 "完备" 与 "左加 ω 封闭"。
  - 探针 `Yw ω′ α`、`Yw ω² α` 是严格的 (`Yw-st`)，但不是链点的读回。
  - 所以它们否定的是 "只靠严格性" 这一种证法，不否定 `ChainP`。
- **机制，逐条核过：** 定理里没有折叠。失败的是 `sˣ` 的第二前提：吸收 `ω + b ≈ b` 成立与否，取决于 b ≥ ω²，在探针上就是 α 有没有真位。

##### 4 正面的结果 (对构造路有利)

- **`ChainP` 在 LEM 下成立** (`lem→chainP`)。构造路要证的命题经典为真，不会撞上反例。
- **`triOn→chainP` / `n1-from`。** 构造路的目标缩成局部判定：参照前驱与链点前驱之间的三歧。n = 1 的值序对已无条件给出 (`val₁`)，所以 n = 1 只缺 `TriOn (D.γ 1) (read (co (pts 1)))`。
- **`+ˣ` 与 `add1-strict`。** 两边前缀值相等时封闭；严格右树上左加 1 封闭。外层 n = 0 → 1 那一步的 "1 +"，只要 `read (F top)` 是严格树就能过。这一句的前提 (严格性) 是判断，没有证。

##### 5 没写成的条目与第一个障碍

- **N1 / N2 的否定：不存在** (相对 LEM 的相容性，见上)。N2 改为写机制。下面这段例子是纸面分析，没有编译：
  - n = 1 时，`F top` 的内层链是 c₀ = top，c₁ = top + Ψ⁰ top (值 ω)，c₂ = c₁ + Ψ⁰ c₁。
  - c₂ 的第 0 支 c₁ + ω² 的分支是 c₁ + ω·(i+1)，值 ω·(i+2)。这里吸收不成立，因为 ω·(i+1) < c₁·ω = ω²。
  - 所以 Ψ⁰(c₁ + ω²) 的分支是 ω^{ω·(i+2)}，而参照 ψ⁰(ω²) 的分支是 1, ω^ω, ω^{ω·2}, …。
  - `≼ˣ` 的推导在这一处要把分支下标平移一位，在吸收成立处 (j ≥ 1) 不平移。平移与否就是 `TriOn` 要的判定。
  - n ≥ 2 时，外层链点 X 是无穷的，同样的判定在外层也出现。
- **N3 的 "只在吸收已发生时要求相等"：** 没有写成可编译的定义域。判断：`VMᵖ` 的证法要求左极限之下每个前驱的像都保值 (`XEmb-limˡ`)，放松任何一处都丢掉这一致性。
- **`TriOn` 在 n = 1 的实例：** 没有证，也不是我这一路的目标。
  - 判断：这些子树都由有限的路径确定，值在 ε₀ 之下。给前驱配上 Cantor 范式编码并证明读回逐项一致，大概可以判定，这条路要借记号，只能放在验收文件里。
  - 链点读回的严格性 (`Strict`) 也没有证。
- **第一个障碍：** 没有检查器报错。缺的是对具体闭项的局部三歧，见上。
