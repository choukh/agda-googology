#### 1 这个候选要试什么

主线 `YiLean` 里, 结点折叠时的链是累加的: 下一点是 "这一点加上这一点的折叠值". 累加保证相邻两点有第一位置关系, 所以极限合法; 代价是树的链点层号与参照的错位. **候选乙把链改成不累加**: 下一点就是这一点上的折叠值 (根上的链: ηₙ₊₁ = F ηₙ). 这时极限合法要另一个理由: 折叠对层号 (沿第一位置) 单调, 即 η 是 η′ 的第一位置时 F η 是 F η′ 的第一位置, 并且 η 是 F η 的第一位置 (或别的足以让相邻两项步进的性质). 主线的 `F-up` 只对 "η′ = η 加上一段" 成立; 极限层号处顶的那一行取部分和, 使得一般的第一位置对上不成立. 所以你大概要同时改极限层号处的那一行 (逐项而不是部分和; 见 `YiPsum`), 或给层号加一个使单调成立的合法性条件. 具体怎么改由你定.

#### YiDiag 一路回报：候选乙 (链不累加)

##### 1 判决

**不累加的闭项写成了，范围是根上与内部结点都不累加。** 合法性证书无前提，也没有定义域。
- `T₃ : R` 的根链是 `pt 0 = top`，`pt (n+1) = F (pt n)`，下一点就是这一点上的折叠值。`T₃ = lim (λ n → F (pt n))`。
- 内部结点的链是 `chain j gk = iter gk top`，也不累加。
- 证书是 `T₃-legal : Lgl zero T₃`。

**判据 C2 通过，是编译定理。**
- `C2 : Σ ℕ λ m → D.L 1 L.⊑ᴵ κ m`，取 m = 1。实际证的比这更强：`L1≅κ1 : D.L 1 L.≅ᴵ κ 1`。
- 来源是 `read-pt1 : read (pt 1) ≅ D.γ 1`：读回的第 1 个链点与参照的 γ₁ 结构互模拟。

**C2′ 在 n = 0、1 通过**，也是编译定理。

**C3 只到 n ≤ 1**，n ≥ 2 未走通。

**C4 两条都通过。**
- n = 1 是同值 (`≅`)，ψ₀(Ω₁)。
- n = 2 是下界，ψ₀(Ω₂)。
- 由此得推论 `T₃-Ω₂`：ψ₀(Ω₂) ≼ 读回的 `T₃`。这是定理，不是同值。`T₃` 的 ψ₀(Ω_Ω) 仍只是读法。

**对纲领与目标意味着什么。**
- YiMono 的否定 `no-L` 指出，结构不可比的机制是链的形状。在这个候选里，去掉累加、并把 ω 倍改为从零起之后，第 1 步结构可比成为编译事实，不再是否定。
- 但 ω 倍从零起是照参照 (Level 框架) 的规则改的，不是树自身逼出的。见 §5 翻译账。
- n ≥ 2 的结构可比没有做成，判断卡在非零目标层的部分和。所以离无条件的 BTBO 下界还差一般 n 的结构可比 (或值比较)，不能说已经持平。

##### 2 设计 (与主线 YiLean 比，改了 5 处)

1. **链不累加。**
   - 写法：`chain j gk = iter gk G.top`。
   - 合法性靠两条引理：`Ψ-low` (`top` 是一切折叠输出的第一位置) 给第 0 步，`Ψ-cp` (折叠保持第一位置，不要输入合法) 给以后每步。两条都由 `chain-step` 组装。
   - 理由：本候选的题目。
2. **目标层 0 上，极限层号的 `top` 逐项 (`ltop zero h = G.lim h`)；别的目标层仍取部分和。**
   - 理由：根链不累加时，`F (f n)` 必须字面上是 `F (lim f)` 的第一位置。这是树自身的要求，由根链的合法性逼出。
   - 非零目标层逐项不行。原因：自身派发把各支的结点保留在不同支的槽位 `(n, q)` 与 `(n+1, q′)`，两者互不为第一位置。这一条是判断；本块里没有编译否定，旧块上同类的否定是 YiPsum 的 `side-lim-illegal`。
3. **`Way zero j = ⊤`。**
   - 作用：目标层 0 的折叠定义性地与派发无关 (`dispatch-free`，`refl`)。逐项那一行的合法性 (`top-mono` 的 `rf` 情形) 要用到它。
   - 理由：树自身的要求。字面第一位置不能跨两个只是外延相等的派发函数。
4. **`Lv` 不带位置搬运 (Shift)；`cmp` 在极限层号上，两个位置在同一支才往下比，不同支一律折叠。**
   - `lv : R → Lv ⌜η⌝` 对树本身递归，不读合法性证明。
   - 理由：若 `F` 读合法性证明，`root-mono` 在端点要两份证明相等。那是 `Set` 里函数类证明的相等，不可得。所以这一条是树自身的要求。
   - 代价：在部分和把不同支的结点混在一起处，跨支比较一律折叠，比主线弱。损失多少没有量过，是判断。
   - 新增的合法性条件：`LvL V`，即极限层号相邻两支之间有层号路径 `≤ᵛ`。它只供逐项那一行用，由 `lv-L : ∀ η → Lgl zero η → LvL (lv η)` 从坐标的合法性得到。
