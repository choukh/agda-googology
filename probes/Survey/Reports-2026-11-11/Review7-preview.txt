0. 目标的归约 (判断)
   - T⁺ 的第 0 项定义性地是 T₃ (T⁺-term₀), T₃⊑T⁺ 字面. 所以 "参照 ≼ read T⁺" 最省的读法仍要 "参照 ≼ read T₃",
     而两者的估计都是 ψ₀(Ω_Ω): 这是紧比较, 没有松量. T⁺ 的松量 (ψ₀(Ω_{Ω+1})) 只在 "迭代多少次" 上,
     它的每一项仍经过同形的主线链 (pts, 累加), 不改每一步要证的形状. 我不认为 T⁺ 的松量能省掉跨框架的那一步.
   - 要证的是: 对一切 n, γ_{n+1} = ψ⁰(Ω_{L n}) ≼ read T₃. 归纳形状: γ_n ≼ read η_n ⇒ ψ⁰(Ω_{L n}) ≼ read (F η_n),
     再由 x ≼ y ⇒ x ≼ θ + y (plus≽) 吸收累加.

1. 四处设计差别, 对下界方向的影响 (判断)
   (i)  链累加 η_{n+1} = η_n + F η_n, 上一点在叶上. 来源: 合法性 Lgl 的 lim 要字面第一位置 Cp, F η 字面上不含 η,
        F-up 只沿 "右加一段" 给 Cp. 所以累加是被 "字面第一位置" 的合法性逼出的, 不是验收方便.
        对结构可比 (⊑ᴵ / 模 ≅ 的前驱包含): 左加数破坏前驱包含 (δ ⊑ θ + δ 一般不成立; 反例 ω^ω 对 1 + ω^ω).
        对值下界 (≼): 无害, x ≼ y ⇒ x ≼ θ + y.
   (ii) ω 倍从 y 起 (y, y+y, ...) 对参照的 0, y, y+y, ...: 下界方向错一位即可, 无害.
   (iii) 极限层的 top 取部分和 psum 对参照 Ω(lim f) = lim Ω(f n): 下界方向用 "右加数支配" 即可, 无害.
   (iv) 折叠内部的规则 6 链也累加 (chain j gk): 同 (i), 下界方向要在第 j 层有 "x ⊴ η ⇒ x ⊴ θ + η".
   结论: 四处都不挡值下界, 都挡结构可比 (⊑ᴵ + Ψ⁰-mono 的直接套用). (i)(iv) 由字面 Cp 合法性逼出.

2. 不可省的核心 (判断)
   参照的 ψ⁰(Ω_ℓ) 在后继层号上展开为第 ℓ' 层的链, 递归到 ℓ 以下一切层号; L n 是 ε₀, ψ₀(Ω_{ε₀}), ... 的层号.
   所以任何证法都要一条对 "读回域里任意层号" 成立的跨框架折叠比较. 能选的只是它的最小形式.
   我看到的最小形式是 "同层号引理" SL:
       对合法 η (或链点及其子项的域): ψ⁰(Ω_{κ η}) ≼ read (F η),  κ η 是 η 的逐构造子拷贝 (Ordᴵ, lim 证据由 Cp 给)
   它只比较结构相同的两个层号上的两个折叠, 位置一一对应, 不需要层间嵌入 (EmbV 型), 也不需要主线内的值单调.
   累加 (i) 则在参照框架内处理: 要 "γ_n ≼ read η_n ⇒ ψ⁰(Ω_{L γ_n}) ≼ ψ⁰(Ω_{κ η_n})", 即参照框架内的值单调,
   限制在严格树 (St) 上 — BTBOFull 的 V1/V2/V3/Ψ-emb 似乎正是这种工具 (待查陈述).
   SL 的证明: YiLeanAccFin §3-§5 的 ⊴ (跨框架逐点前序) 推广到一切层号: 第 0 层用 ≼, 高层结构的;
   要 ⊴-+ˡ 于每一层, 折叠保持于每个目标与派发, 参照穿透分支的 tr⁻ 要 ≅ 不变性, 极限层的 <ᴵ-dec 与 cmp 结果一致.
   规模粗估 (判断): 800 到 2000 行. 第一个障碍预计在参照穿透分支的 tr⁻ (≅ 记账) 与极限层两侧派发一致.

3. 设计改动 (b) (判断)
   让链不累加需要放弃字面 Cp 合法性 (改模 ≅ 的前驱包含, 即参照的 HS 形状), 那是改第 1 层合法性, 是新主线候选,
   不是验收方便; 且即使两边定义同形, 跨两个数据类型的互模拟仍要对一切层号做一遍 (规模不降到零).
