### 1 问题

乙线: 层号是树. 塔的第 3 项的闭项已做成 (读法与 BTBO 持平). 第 4 步第一站 (公共上界 `tw 2`, 目标闭项是 `Ω̂ (suc (tw 2))` 的目标层 0 折叠, 读法 ψ₀(Ω_{Ω₁+1})) 没有过去. 已定的:

- 否定路: `top-branch→lpo`. 目标落在某一支里, 树是 `top`: 各支的像对**一切**带守卫的坐标定义并满足保留律 (只对路径相连的对要求), 则 LPO.
- 构造路: 分支取**相对目标所在一支**的坐标 (`rowᴿ`) 时, 行合法, 根保留, 所问的比较就是 `compare-link` 的值. 这是替代行: 分支族只取尾部.

- 两路各自走查的判断 (没有定理): 第 1 到 2 个链点之后, `own` 会遇到别的支上的结点, 两边的坐标互相独立.

**要判定的:** 把链点折到第 0 层时, 折叠问到的每一对 (目标位置 q, 根在位置 r 的子树) 上, 能否都有 `YiGenIf.Honest` 的 `OwnFold`. 你做 "能" 的一侧.

| `asked₁` | 第 1 个链点问到一对跨支、两边坐标都含极限的对 | 编译定理（闭实例） |
| `at→fe`, `fe→at`, `fe-pointwise` | 这一对上 "在位置上" 与 `FE` 等价；`FE` 两边逐点相等 | 编译定理 |
| `askdec→fe`, `weak-fe` | `AskDec` 推出 `FE ⊎ ¬FE`；这一对上接口的 `Honest` 推出 `¬FE ⊎ ¬¬FE` | 编译定理 |
| `complete-there→`, `complete-there←` | `Tᴾ` 的折叠在这一对上完全，当且仅当 `¬FE` | 编译定理 |
| `askedˢ`, `same-at`, `same-folds` | 同一支（坐标含极限）里的一对：在位置上，而 `Tᴾ` 的派发取折叠，即不完全 | 编译定理（闭实例） |
| `point₁ᴺ-out` | 第 1 个归一链点不在有限坐标的定义域里 | 编译定理 |

条件定理的前提：

```agda
AskN τ ξ = Σ ℕ λ n → Ask base (pointsᴺ n) τ ξ
AskDec = ∀ η (e : Gd zero raw1 η) (r : Pre (read0 η))
  η′ (e′ : Gd zero raw1 η′) (r′ : Pre (read0 η′)) (c : Low (read0 η′) r′) (t : RΩ)
  (g : (ζ : Low (read0 η′) r′) → .(GdL (read0 η′) r′ c ζ) → RΩ) →
  .(AskN (at η e r) (G.lc (br η′ e′ r′) c t g)) →
  At (lev (read0 η) r) (lev (read0 η′) r′) ⊎ (At (lev (read0 η) r) (lev (read0 η′) r′) → ⊥)
```

可满足性：`Locate`（排中律的实例）给出它；没有无前提的证明。

#### 4 强度的证据，与替代行

**强度的证据（都是派发层面，没有值）。**
- 量化域是调用闭包 `Ask base (pointsᶜ n)`：结点处折叠调用第一支、各支在同一目标下、各支在结点自己那一层下。分支函数是全函数，所以后两样对一切带守卫的坐标都算。这是行的合法性要的范围，比链实际走到的可数个坐标宽；诚实对整个范围成立。
- `chain-honest`：闭包里每个结点 `(τ, p)` 上 `Honest (posT τ) (ownAt …) (G.lc p c t g)`。
- `chain-dom`：闭包里的目标都在有限坐标的支上或是第 0 层，树都在定义域里。
- `top-branch-fin`：链问到的目标下，`top` 的分支族满足 `TopBranch` 的保留律，不要 `Link` 前提。
- `Φˢᶜ-keep`：自目标的折叠保留一切结点。

**替代行。**
1. `topᶜ`（自目标折叠在 `top` 上）：槽位的支截到有限部分并沿坐标累加。坐标含极限的支上保留结点的层号是有限的，不是 `read0 (nrm a)`。
2. `rowᶠ`（`top` 在分支目标下）：分支族沿 δ 累加；不满足 `Good` 的坐标取相对坐标 `η + nrm d`；根自己那一层的分支取常值（保留时用不到）。
3. 沿用上一轮的：加法里的 `topᴬ`；目标第 0 层的 `top` 取 `T₃ᵐ`（内含极限层号的部分和）。
4. `Tᴾ` 与 `Tᴺ` 的链用归一行 `topᴺ`，本身是替代行。

三个闭项 `Tᶜ`, `Tᴾ`, `Tᴺ` 都不带读法。它们之间、与上一轮 `T⁺` 之间的关系没有比。

#### 5 第一个障碍（在归一链上）

**位置。** `Ψᶠ` 在分支结点上的子句，`ndB` 的 `gk` 字段：目标 `at η e r` 的折叠在整个分支上的值。

- 目标位置：`br (suc (nrm wᴸ)) (γ wᴸ) (inj₁ tt)`，`wᴸ = lim (0, wᴾ+1, wᴾ+1, …)`，`wᴾ = lim (1, 1, …)`。目标层 `read0 (nrm wᴸ)`。
- 结点位置：`br (suc (nrm wᴾ)) (γ wᴾ) (inj₁ tt)`，层号 `Xᴾ = read0 (nrm wᴾ)`。
- 来源：`Gκ (suc wᴸ) = Gκ wᴸ + KT wᴸ`，结点 `KT wᴸ` 的每一支以 `Gκ wᴸ` 为前缀，前缀的第 1 项含 `KT wᴾ`。

没有检查器报错：折叠对任何派发都写得出，缺的是完全性的数据。

**缺的陈述** 是上面的 `AskDec`；在这一对上它的内容是：

```agda
FE = _≡_ {A = ℕ → LF} (λ i → read0 (G.zero +ʳ cᴾ i)) (λ i → read0 (cᴾ i))   -- cᴾ = psum (λ _ → one)
askdec→fe : AskDec → FE ⊎ (FE → ⊥)
weak-fe : (F : OwnFold (posT τᴸ)) → Honest (posT τᴸ) F ξᴾ → (FE → ⊥) ⊎ ((FE → ⊥) → ⊥)
```

机制：`nrm` 在极限处取部分和，目标层第 1 项里那个极限层号前面多一个 `0 +`，与结点层逐点相等而不是字面相等。

**与 `TopBranch` 的关系。** 不是同一个陈述，蕴涵没有证，两者都由 `Locate` 给出。
- `TopBranch` 说 `top` 的各支在一切目标下的像，推出 LPO。
- `AskDec` 说已经放在归一槽位上的结点对，我只得到一个函数外延实例的判定。它是否推出 LPO，没有判定。

**要分清的三点。**
- 这一对的坐标 `suc wᴸ` 在根的分支函数的定义域里，不是根上的链走到的可数个坐标之一。起点坐标 1 那一支只问层号 0 的目标，不问任何判定。链走到的坐标上是否出现同类的对，没有判定。
- `AskDec` 里还含同一支的对（§6 的闭实例）。那不是这类障碍：位置在同一支在生成 `KT` 时是已知的，搬进槽位后从树里读不出。把折叠写在生成数据上能否去掉它，没有做。
- 没有编译的否定定理。对归一链只能写 "派发全都完全未走通"。

**判断（没有编译）。**
- `FE` 在无公理的 Agda 里没有闭证明（两边不可转换），`¬FE` 也没有（与函数外延相容）。
- 归一把 `TopBranch` 的探针 `coordᴸ α` 换成部分和后，有限层号总在位置上，所以那条 LPO 机制不照搬到 `AskDec`。
- 任何只读树、不读证书的坐标归一都不能跨极限保持字面路径：合法树的路径是全序链。所以在分支函数只拿无关守卫的这个块里，极限层号的槽位之间拿不到路径数据。
- 根上的链从第 2 步起坐标含极限的后继（折叠输出里有 `suc (lim …)` 的形状），所以含极限坐标的目标会被实际走到。

#### 6 偏离与事故

- **没有按 "生成数据" 字面去写码上的折叠。** 定义域是树上的谓词，折叠只无关地带着它，派发从树里的位置读出。理由：把生成结构当相关数据时，同一棵树的两份推导要证折叠相等，极限处是函数相等。有限坐标上 "哪一支、路径" 本来就能由树判定。代价是归一链上同一支（坐标含极限）的对读不出来。
- **接口的 `OwnFold` 是 `RΩ` 上的全函数，我的折叠只在定义域上有定义。** `ownAt` 把折叠在被问到的那棵树上的值装成常值函数来满足 `Honest`。对定义域一致的陈述是 `honestᴰ`（同一个 `Ψᶠ τ` 对域里一切树）。接口没有动。
- **超出简报的部分：** `Tᴾ`、`Canon`、`TopBranchOn` 与 `top-branch-fin`。
- **对共用接口的增补（都在自己的文件里）：** `Tg`, `own`, `Ask`, `Disp`（`YiGenFold`）；`Dm.D`, `GoodP`, `Spine`, `TopRow`（`YiGenFoldDom`）；`cut`, `FinL`, `TopBranchOn`（`YiGenFoldFin`）；`AskN`, `AskDec`, `FE`（`YiGenFoldGap`）。
- **导入：** 只导入已定稿的模块，含上一轮否定路的 `YiOmNegBranch`, `YiRawNegOmega`, `YiLvNegKeep`。没有读、没有依赖同时在跑的 `YiGenNeg*`, `YiBtVal*`。
- **编译：** 一次类型错误（`suc` 在 ℕ 与 `LF` 间歧义），已修；没有堆耗尽。每次只跑一个 agda，没用 `--ignore-interfaces`，只按字面路径删过自己五个模块的接口。
- **没有做的：** 没有停下条件被触发（不需要 Funext、K 或改块）；没有临时目录里的 `.agda` 试验；没有改任何已有文件，没有提交。`git status` 里已有的修改是会话开始前就在的。
- **没有做的方向：** 把诚实的定义域从有限坐标推广到单一闭坐标的支里的全部位置（要槽位映射由坐标的语法形状给出）。
