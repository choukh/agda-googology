**公共上界含 Ω 结点。** `Lv` 加了一个构造子：

- `cmp V₂ q r = fold`：对一切位置对都折叠。
- `top`：按第 `top` 支里层号 0 的位置 `p₀` 的派发分两种。
  - **折叠时**照主线 `T₃` 的链：链点带坐标与合法性，下一点是 `η + F η`。观察里的派发一律折叠，不看外部派发 `x`。链点的合法性要用 `Ψ-lgl`，所以 `Ψ`、`Ψ-lgl`、`Ψ-cp`、`Ψ-dn`、`Up-mono` 写成一个互递归块。观察单调由字段 `up` 加 `Up-mono` 给出（沿 `Up` 走，观察都是链或部分和的第 0 项）。
  - **保留时**得到层号 0 的结点，分支取 `Kf T`：沿分支下标的结构累加，后继一步加 ω 份 `T (suc a)`。`T η` 是坐标 `nrm η` 那一支的 `top` 的像；`nrm` 在 ℕ 极限处取部分和，总是合法。
  - 保留时这样写的理由：结点的分支必须对一切下标有定义，并且对第一位置单调；而各支的 `top` 互不为第一位置，所以不能直接用各支的 `top`。

**如实写清的四条。**
1. **派发。**
   - 保留的：各支内部照主线（后继层号的根对其内部、ℕ 极限经位置搬运）；`top` 当目标层把 `p₀` 保留时（`Φ₂` 是这样，见 `Ω-keep`）。
   - 一律折叠的：`tw 2` 上的任意两个位置；`top` 的折叠行里的观察。
   - 依据的数据只有派发在 `p₀` 上的值，以及 `vΩ` 的 `V`、`up`。
2. **读法核对到哪里。**
   - 根链的形状：`T⁺-form`、`T⁺-feedback`、`T⁺-term₀`，都是 `refl`。
   - `Φ₂` 保留一切结点，包括 Ω_Ω 那个层号 0 的结点（`Ω-keep`，`refl`）。
   - 丢掉保留的一对（有限测试，`YiNextAccTest`）：坐标 `suc top` 那一支的层号 1 结点 `Ω₂`，它 `top` 支里同一支的层号 0 结点在位置 `s₂′`。`lost : cmp V₂ s₂ s₂′ ≡ fold`，而 `could : Way (lev (tw 2) s₂) (lev (tw 2) s₂′)` 说明有槽位可以保留。
   - 这一对会被 `T⁺` 第 1 项的链问到，是判断，没有编译成定理。
   - 我的判断：丢失只在可数坐标那个方向；Ω_Ω 塔逐层增高，上确界也许不受影响，所以值也许仍到 ψ₀(Ω_{Ω+1})。这一点没有核对，档位是判断。
3. **同一个下标的两份合法性证明。** 在这个构造里没有造成问题。
   - `Kf` 的坐标证明取 `nrm-lgl η`，由 η 算出。
   - 链点的证明由 `plus-lgl` 与 `Ψ-lgl` 算出；`up` 字段与 `nx` 用的是同一个项，定义性一致。
   - `tw 2` 上不比较位置，所以从来不需要把带不同证明的两个位置认作同一个。
4. **翻译账。**
   - 来自记号：ψ(0) = Ω_m、后继取 ω 倍、保留/折叠、链行，与主线相同；`top` 在目标 `tw 2` 上保留（Ω_ν 在 C_ν 里）。
   - 由树的要求逼出：`Kf` 与 `nrm`（保留结点的分支要全定义、单调、合法）；`Up` 与 `up-lv`（链行的合法性）；`Ψ` 与 `Ψ-lgl` 互递归（位置带合法性）；`cmp` 在 `vΩ` 上一律折叠（不做全分支比较）。
   - 负项：`vΩ` 只管 `tw 2`，是这一站特设的构造子。

#### 6 第一个障碍

**检查器方面没有障碍。** 障碍在读法上，是 `tw 2` 上的完全比较。要完全，就得写出这样一个函数：

`(η : R) (l : Lgl zero η) (q : Pre ⌜ η ⌝) (η′ : R) (l′ : Lgl zero η′) (r : Pre ⌜ η′ ⌝) → Way (lev ⌜ η ⌝ q) (lev ⌜ η′ ⌝ r)`

并且它在可以保留时都保留。

- 这要知道两棵可数树 η、η′ 之间的关系。即使只是 η ≡ η′ 这种同一支的情形（`lost` 那一对就是同一支），也不可判定。
- 我没有编译 "这个函数完全推出 WLPO/LPO" 的定理。说它是壁垒禁止的那类比较，是判断（形状上像 `dec→WLPO`）。所以这条路只能写 "保守，未走通"，不能写 "已否定"。

**可选的延伸没有做。** `tw 4` 的分支层号 `upT ⌜η⌝` 是结点层不为 0 的 Ω 结点。保留时的分支族要对 `Raw k₀` 里带结点的树有定义并且单调，而 `nrm` 只会归一 ℕ 极限，不能把结点的分支变成单调的（判断，没有编译）。
