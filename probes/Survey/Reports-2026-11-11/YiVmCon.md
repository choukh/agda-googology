#### 1 问题是什么, 为什么要做

`VMᴸ` 说: 两个带证书的可数序数 x, y, 值上 x ≼ y 时, 以它们为层号的 ψ₀(Ω_x) ≼ ψ₀(Ω_y). 它只谈参照框架, 与被验收的树无关. 证出来, 配上任何一棵树的 "它在自己层号上不低于参照" (只带值的下界), 就得到那棵树与 BTBO 持平的下界 (`btbo-vm` 是对旧树的版本), 以后每一站也用得上. 现成的单调性 (`Ψ⁰-mono`) 只对层号结构可比 (`⊑ᴵ`) 成立; 结构可比的证法在 BTBO 的对角链上已有编译否定 (`YiMonoBreak.no-L`).

上一路走到: `VMᴸ` 归约到后继情形 `Crux` (`crux→vm`). 想经 `EmbV` (由 `x ≼ y` 的推导造前驱嵌入) 来证时, 零, 后继 (`PEmb-suc`), 右极限 (`PEmb-limʳ`) 都有了; 左极限 (`l≼`) 要各项的嵌入在公共前驱上互相一致 (`PEmb-limˡ` 的前提), 而归纳假设给的各个嵌入互不相关. 上一路的判断 (未编译): 要求嵌入 "保初始段" 可以由唯一性得到一致, 但后继情形要定位前驱, 疑似推出 LPO 一类的原则; `VMᴸ` 在经典意义下成立.

## 回报原文

#### YiVmCon 一路回报：`VMᴸ` / `Crux` 的构造侧

##### 1 判决

**`VMᴸ` 和 `Crux` 都没有无条件证出，也没有被否定。** 这一路做成的是：在两个带证据的定义域上，它们是编译定理；一般情形是条件定理，前提推出 LPO。

- **新不变量 `XEmb`（保值嵌入）。** 它是前驱嵌入 `PEmb` 加一个条件：每个前驱的像与它值相等。
  - 保值之后，左极限的拼接不再需要一致性前提 (`XEmb-limˡ`)。同一层号下两个值相等的字面前驱必 `≅ᴵ`，这一步由有界三歧 `<ᴵ-dec` 加值序无自反得到。这正是上一路卡住的 `PEmb-limˡ` 前提。
  - 代价落在后继：`XEmb-suc` 要两边的顶值相等。
- **两个定义域上的定理（无条件）。**
  - `≼ˣ`：值序推导，但每一步后继对后继都带顶的反向不等式。
  - `≼ᵖ`：更宽，只有落在左极限之下的后继要带这条证据。
  - 在这两个定义域上，`embᵖ`、`VMᵖ`、`Cruxᵖ` 是编译定理。
  - 另有一个公共字面上界域 (`VMᵇ`, `Cruxᵇ`)，就是结构证法的定义域。
- **一般情形是条件定理。** `tri→vm : Tri → VMᴸ`，`cpl→vm`，`cpl→crux`。
  - 前提 `Tri` 推出 LPO (`tri→LPO`)。
  - 两个定义域对值序的完备性也各推出 LPO (`cplˣ→LPO`, `cplᵖ→LPO`)。
  - 所以这条证法不能做成无条件的。这些否定的只是证法，不是 `VMᴸ` 的反例。
- **对 BTBO 下界。** 归约成 `btbo-p : ChainP → D.BTBOᴵ ≼ read T₃ᵐ`，`ChainP` 说每个链点对 `(D.γ n, 读回)` 落在 `≼ᵖ` 里。
  - n = 0 是定理 (`chainP₀`)；n ≥ 1 未证。
  - 参照对角链自身相邻两项在 `≼ˣ` 里 (`diag-in`)。
  - 链点对不在公共上界域里（由 `YiMonoBreak.no-L`）。
- **强度。** 没有新的树强度定理。`T₃ᵐ` 的 ψ₀(Ω_Ω) 仍是读法，已证的下界仍是上一路的 ψ₀(Ω_{ω+1})。

##### 4 办法

- **不变量。** `XEmb a b` = `PEmb a b` 加上 `V (map P r) ≼ V c` 与 `V c ≼ V (map P r)`。引入 `≼ᵖ`，是让不保值的后继只出现在不经过左极限的位置。四种情形：
  - `z≼`：`XEmb-⊑ z⊑`。
  - `≼l`：`XEmb-limʳ`（像不变，保值不变）。
  - `l≼`：`XEmb-limˡ`。一致性来自保值加 `≈→≅`，不比较各项的推导。
  - `s≼s`：在 `≼ˣ` 里用 `XEmb-suc`，要顶值相等；值严格小时用 `wˣ`。在 `≼ᵖ` 的外层直接用 `PEmb-suc`，顶映到顶，不保值。
- **四个实例的嵌入怎么造，一致性从哪来。**
  - A：ω 的前驱 n 映到 ω⁺ 里的字面 n。各项保值，所以自动一致。
  - B：A 外套 `sᵖ`，顶 ω 映到 ω⁺，这一步不需要一致性。
  - C：各项 ω+n 映到 ω⁺+n。每个后继处顶值相等 (`⊕≼`)，`lᵖ` 才拼得起来。这一例真正用到了保值。
  - D：各项是 `D.cert 1` 的结构步进 (`⊑→≼ˣ`)，结构步进本身保值。层号不 `≅ᴵ`：第 0 项的第 0 项是 0 对 1，由检查器按规范化验证 (`γ≇`)。
- **试过而放下的办法。**
  - 关系版的 E（不要求函数式），在纸面上放下：`BTBOFullLe` 的 `Le-ψ` 派发时，`clashᴸ₄` 要用 `eq-pres`，非函数关系给不出它。
  - "各项像随下标单调"（弱一致），在纸面上放下：它能保 `≺`，保不了 `≅`。
  - "最小像 / 下一个前驱" 一类典范选择，在纸面上放下：例子 `suc x_α`，其中 x_α = lim(0,…,0,K,K,…)，求最小前驱要判定 α。
  - 不保值嵌入的重新拼接，在纸面上放下：前段的像可能已占满位置，后面的项放不下。
  - 以上都没有编译，只是纸面分析。

##### 5 第一个障碍

- **没有检查器报错，缺的是一个判定。** 这条证法在 `s≼s` 且位于 `l≼` 之下时，要知道顶的值相等还是严格小。精确类型就是 `Tri`：

  ```
  Tri = ∀ (a b : Ordᶜ L.zero) → a ≼ b → b ≼ a ⊎ L.suc a ≼ b
  ```

  用法见 `tri→cplˣ` 的 `(suc a, suc b)` 一支。`Tri → LPO` 已编译。
- **为什么不能不保值。** 原障碍是 `PEmb-limˡ` 的前提：

  ```
  ∀ n m {c} (r : c ≺ᴵ f n) (t : c ≺ᴵ f m) → map (P n) r ≅ᴵ map (P m) t
  ```

  各项的嵌入来自彼此独立的推导。除了保值之外，我没有找到别的典范选择，能让这个前提自动成立（判断）。
- **给否定路的信息（判断，未编译）。** `EmbV` / `VMᴸ` 本身推不推出 LPO 一类原则，仍是开放的。
  - 我试着构造反例族：要求 `≼` 推导对参数一致地给出，同时没有可计算的一致嵌入。几次尝试都失败了，原因是一致给出的推导本身带了足够的界的信息（例如 `suc u ≼ ω` 必须给出 u 的值的上界）。
  - 已编译的三条否定只说明 "先改写进 `≼ᵖ`" 这一步要 LPO，不说明 `VMᴸ` 要。
- **链上 n ≥ 1（判断）。** 链点是累加的，ηₙ₊₁ = ηₙ + 折叠值。`≼ˣ` 对左加平移不封闭：保值要求吸收律 `1 + a ≈ a`，而它在退化极限上不成立。所以 `ChainP` 要按树一侧的具体结构逐项做；新折叠的值下界 `lower-any` 只给 `≼`，不给 `≼ᵖ`。没有试。
