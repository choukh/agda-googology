#### 1 问题是什么, 为什么要做

层号 `tw 3` 的根是一个层号 0 的 Ω 结点: 下界 1, 分支对一切带守卫的第 0 层坐标 η 定义. 折叠在目标层高于结点层时把结点 **保留**: 输出是目标层的树里的一个保留结点, 它的各支是原来各支的折叠. "本该有的行" 取全域 (从下界 1 起的一切坐标). 层号不可数时 (公共上界含 Ω 结点), 全域的行拿不到数据, 一种规定写法甚至推出 LPO (`top-branch→lpo`); 写得出的是 **尾部行**: 分支域只取某个坐标 c′ 之上的坐标 (下界抬高到 c′; 相对坐标的行 `rowᴿ` 也是这一类). 在序数层面, 递增族与它的共尾子族上确界相同; 但折叠不是上确界的函数: 目标层 0 的折叠在一个层号 0 的结点上沿一条链取值, 链从结点的下界起步, 抬高下界改的是链的起点.

所以要问: **同一个结点, 完全行与尾部行, 各自再折到第 0 层, 读回的值有什么关系.** 作者 2026-11-11 定: 第 4 步的验收改成以值下界为主. 这个实验的结果决定第 4 步能不能用尾部行: 不掉值 (尾部 ≽ 完全) 就能用; 掉值就要重估.

#### 2 目标, 分步; 每步先交再往下

**第 0 步 (便宜的确认项, 目标层 0).** `T₃ᵐ` 是根上的链的极限: `pointsᵐ` 从下界起步, 每步加上这一点上的折叠值. 做一个起点换成 c′ 的版本 (c′ 取 3, 再取一般的带守卫的坐标), 证:
- 它合法;
- 现有的下界对它仍成立 (例如参照的 ψ₀(Ω₃) ≼ 它, 以及 `YiBtValTw3` 的 ψ₀(Ω_ω));
- 它与 `T₃ᵐ` 的值的两个方向: `read T₃ᵐ ≼ read (从 c′ 起的)` (不掉值) 与反向 (不涨值), 各自是定理, 反例, 还是归约到一条带确切类型的引理.

**第 1 步 (决定性的, 目标层 1).** 在目标层 1 上 (那里 "在不在位置上" 可判定, 完全行写得出), 给出同一个结点的两条行, 都是 `Raw (suc zero)` 的树:
- 完全行 `rowᶠ`: 保留结点, 下界是原来的下界, 每一支是原来那一支在目标层 1 下的折叠 (对一切带守卫的坐标);
- 尾部行 `rowᵗ`: 下界抬高到 c′ (先取 3), 分支域只取 c′ 之上的, 其余相同.
然后把两条行各折到第 0 层 (`Φᵐ (suc zero) …` 一类的观察 `obs`), 比较:
```agda
tail-no-loss : read (obs rowᶠ) ≼ read (obs rowᵗ)
tail-no-gain : read (obs rowᵗ) ≼ read (obs rowᶠ)   -- 或一条编译的严格反例
```
"同一个结点" 取哪一个由你定并说明: 可以是公共上界 `tw 2` 里最大那棵树 `top` 在一个层号 1 的目标位置下的行 (审查的原意; `YiGenFoldDom.TopRow`, `YiOmFoldRel` 是现成的近似物, 注意它们在某些坐标上用了相对坐标或常值, 不是完全行); 也可以先在公共上界没有 Ω 结点的设置里做 (例如层号 2 的闭项里那个被保留的层号 0 的结点, `YiRawFold.Ψ` 的保留行本来就是完全的), 那里工具齐全. 两个设置都做更好; 先做你有把握的.
陈述要写清: 两条行各自为什么合法; 完全行为什么是 "对一切带守卫的坐标逐支折叠" (不是模型, 不是常值); 尾部行与它只差下界与分支域.

**第 2 步 (若前两步做成).** 对一般的 c′ (带守卫与路径数据) 陈述并证明同样的两条.

**预计会碰到的.** 两个方向大概都要 "分支的折叠对坐标的值单调" 一类引理 (起点后移后链逐项不低). 这类单调性在乙线的块上还没有定理; 另一路 (前缀 `YiMono`) 同时在攻 BTBO 对角线上的那一条 `MonoT`. 不要等它, 不要依赖它的文件. 需要时把你要的单调性写成带确切类型的前提, 在规范实例上尽量证出来 (低层号, 有限坐标上结构可比, `mono-⊑` 那种), 并说明它与 `MonoT` 的关系. "不涨值" 一般不成立是可能的 (下界抬到链的极限之上值会变大); 那对下界验收无害, 但要写成定理并说明 c′ 在什么范围内两者同值.

**停下的条件.** 同一处两次重新设计仍过不了检查器; 需要函数外延或 K (可交显式前提的条件定理, 另给不带它的最强结果); 堆到 6G 仍耗尽. 约化: 把缺的引理写成带确切类型的模块参数, 其余条件地证出来并编译; 给前提一个实例或说明为何可满足.

发现尾部行掉值, 那是重要结果: 写成编译过的定理交回 (反例对象要在规范构造的读回域里, 不是退化结点), 不要绕开.
