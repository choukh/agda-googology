-- 接口: 可数层号定理的出口陈述 LOWERᵂ, 只用 W4 自己的词汇写覆盖条件 (不出现关系 Dom).

-- 状态的每个条目不低于该层的标准 Ω 树 (按 W4 的步进序).
Cov : ∀ {m} → Base m → Set
Cov {m} S = (j : L) (u : j ≤ m) → (proj₁ (Ωt j) ≡ proj₁ (S j u)) ⊎ (j ⊢ proj₁ (Ωt j) ◃ proj₁ (S j u))

-- 只含后继与严格 ℕ 极限形状的层号 m 上, 覆盖的状态与不低于 1 的底, 沿任何到零的路径:
-- 参照系统在镜像层号码上的折叠不高于 W4 的折叠.
LOWERᵂ : Set
LOWERᵂ = (m : L) (st : IsS m) (o : Ok m) (S : Base m) → Cov S → (β : Tr⁺ zero) → 𝟏 ≼ read (proj₁ β) → (w : zero ≤ m)
       → I.ψ⁰ (I.Ω (code m (IsS→IsN m st) o)) ≼ read (proj₁ (ψ m o S zero w β (proj₁ (Ωt m))))
