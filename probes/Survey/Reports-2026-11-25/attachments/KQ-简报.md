# KQ: 规范 Ω 树及其折叠沿层号路径的字面单调 (前缀 KQ, 工作目录 <实验目录>/kq)

先读公共约束: <实验目录>/briefs/COMMON.md . 注意: 这次的基目录是 <实验目录>/w5build (只读, 都已编译; 编译命令里的 `-i .../w4` 换成 `-i <实验目录>/w5build -i <实验目录>/kq`). 本任务只用原 W4 的定义: W4Block, W4Ops, W4Path, W4Fold, WVOne (另可参考 Nest1, W5Trace).

## 背景

第十五次独立审查 (<实验目录>/r15/R15Mono.agda, R15Steer.agda, 已复核) 证了: 塔的孩子族对右加法有字面路径 `tw-mono : hN n c ≤ hN n (c + d)` (由 `↑⊑+ : ↑ k x ⊑ ↑ k (x + y)`). 有了它, 朝 "某个孩子里的层" 折规范 Ω 树可以不比较孩子: 把分支下标 d 换成 c′ + d.
问题是这件事能否自持: 折叠的输出会被读回成层号 (折叠输出作下标, 下标读回成层号 `↑`), 读回出来的 Ω 形层号的孩子族还有没有同样的字面单调. 真实运行里的一个例子 (W5Trace): 层号 `Qr = nd (sΩ zero) (λ c → tw 1 ⊕ (Lβ₁ ⊕ (Lβ′ ⊕ lev c)))`, 其中 `lev c = zero ⊕ ↑ (h₁ c) (proj₁ (Ωt (h₁ c)))`. 已知的一条正面事实 (Nest1): 塔第 1 项从头折的链点字面嵌套, `nest : (n : ℕ) → zero ⊢ zt (suc n) ◃ zt (suc (suc n))`, 其中用到 `first-st : first (st (lim f a)) ≡ st (f 0)`.

## 要回答的 (每条: 定理, 或闭实例上的事实, 或带最小失败实例的障碍)

B1. 规范 Ω 树的读回. 证或否证:
  (a) `(c d : Tr zero) → lev c ≤ lev (c + d)` (lev 如上; 可先做 d = suc zero 与一般的后继、ℕ 极限两步);
  (b) 更一般: 层号路径 a ≤ b 给出 `↑ a (Ωt a) ⊑ ↑ b (Ωt b)` (先对 "b 是 a 的后继" 与 "a 是 ℕ 极限层号 b 的成员" 两种单步).
  审查的纸面判断: 两种单步在数学上成立, 但现行块里 `zero ⊕ a` 不定义地等于 `a`, 会卡住. 若确实卡在这里: 给出最小的失败处 (首个错误原文), 并在你自己目录的块的拷贝 (KQ 前缀的新模块名) 里把 `_⊕_` 改成 `zero ⊕ b = b` 定义地成立, 报告 (i) 引理是否随之可证, (ii) W4Ops, W4Path, W4Fold 的拷贝在改动后还能否编译, 不能的话首个错误在哪.
B2. 折叠的输出. 记 F c 为 "在孩子 c 里把规范 Ω 树朝第 0 层折" 的结果 (从头折的一步就是 WVOne 的 `st`; 也可取 KAsTw 里的 `stepRun` 形式, 状态与底固定).
  (a) 对一切 c: `zero ⊢ st c ◃ st (suc c)` 或它的读回形式 `↑ zero (st c) ⊑ ↑ zero (st (suc c))` 成立吗? 对 ℕ 极限的成员 (`st (f n)` 与 `st (lim f a)`, n 任意, 不只是 n = 0) 呢?
  (b) 朝私有层的类比: 固定 c′ 与目标层 j = h₁ c′, 记 G d 为 "在孩子 c′ + d 里沿 `steerPath 0 c′ self d` 把 `Ωt (h₁ (c′ + d))` 朝 j 折" 的结果 (R15Steer.steer-branch 右边的形状, 状态与底取固定的参数). `↑ (h₁ c′) (G d) ⊑ ↑ (h₁ c′) (G (d + e))` 成立吗? 先做闭实例 (c′ = 1, 2, ω; d = 0, 1, 2; e = 1), 把路径显式构造出来; 再试一般的 e = suc zero.
  对 (a)(b): 成立的写成定理; 闭实例成立而一般情形证不出的, 报出一般证明里缺的那条不变式的确切陈述; 闭实例就不成立的, 给出编译过的形状事实 (两棵树沿第一位置的前几层各是什么) 说明为什么没有字面关系.
B3. 若 B1, B2 都有正面结果: 写出一个可作为块的合法性条件的陈述 ("Ω 分支对右加法字面单调" 的确切形式), 并说明折叠保持它还缺哪条引理. 不要求证.

## 要点

- 这是探查, 结论可以是否定的. 否定要落在规范实例上 (塔, 规范 Ω 树, 真实链点), 不要用任意合法层号上的退化反例 (那只说明谓词太宽).
- 不改基目录与仓库. 改块的试验只在自己目录的拷贝里做.
- 闭实例上的 refl 明确标为有限测试, 不是证明.
