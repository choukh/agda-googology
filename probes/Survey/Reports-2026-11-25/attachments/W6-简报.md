# W6: 依赖分支与 "换参数" 的一行 (前缀 W6, 工作目录 <实验目录>/w6)

先读公共约束: <实验目录>/briefs/COMMON.md . 注意: 这次的基目录是 <实验目录>/w5build (只读, 都已编译; 编译命令里的 `-i .../w4` 换成 `-i <实验目录>/w5build -i <实验目录>/w6`). 里面并存两条链: 原 W4 (W4Block, W4Ops, W4Path, W4Fold, …) 与候选 W5 (共用 W4Block, W4Ops; 改的是 W5Path, W5Loc, W5Fold; 追踪在 W5Trace, W5Exp4Shape).
这是一次试验 (前三层的候选, 不替换任何现行定义). 你的模块用新名字 W6Block, W6Ops, W6Path, W6Loc, W6Fold, … (从 W4Block, W4Ops, W5Path, W5Loc, W5Fold 抄出并改模块名与导入), 这样能与基目录并存.

## 背景 (已编译的事实, 先读这两个文件)

<实验目录>/r15/R15Mono.agda 与 <实验目录>/r15/R15Steer.agda (第十五次独立审查交的, 主审已复核, 全是 refl 或结构递归):
- `tw-mono : (n : ℕ) (c d : Tr (tw n)) → hN n c ≤ hN n (c + d)`: 塔的孩子族对右加法有字面路径.
- `steer-node`: 把塔型层号 N 的孩子族换成 d ↦ h (c′ + d) 得到 N′; 现行折叠朝 "孩子 c′ 里的层 j" 沿一致路径折 N′ 的规范 Ω 树, 保留判定逐字是原层号上带证据的那一行, 每个分支逐字是孩子 c′ + d 里沿字面路径 `steerPath` 的折叠. 不定位, 不比较, 不回退.
现行折叠 (W4 与 W5) 在 Ω 形层号 N = nd (sΩ k) h 上, 目标路径是 `inc c′ v` (目标层在孩子 c′ 里) 时, 对规范 Ω 树的分支只能逐个回退 (W5 对有限的目标层就地折, 无穷的目标层仍回退; 见 R15Steer 的 `w5-miss`). 原因: 分支是 `Ω top g`, g d 是任意树, 折叠看不出它是 "孩子 d 里的树".

## 要做的

把 "换参数" 落成折叠的一行. 设计 (细节由你定, 约束在后):

1. 块 (W6Block): 在 Ω 形层号上加一个 "依赖分支" 构造子, 记作 `dg x D e`: 左项 x 是本层的树, D 在每个孩子 c 上给出该孩子层号上的树 (类型同 `up` 的 y), e 是每个 D c 非零的证据 (同 `up` 的 e). 含义是 "x 加上 对一切孩子 c 的 (D c 注入本层) 的上确界", 即现在的 `Ω top (λ d → up x d (D d) (e d))`. 读回 `↑`, 加法, `emb`, `fromBr`, 步进序等一切按结构递归的函数补上这个构造子的情形, 语义与那个去糖的形式一致.
2. `Ωt` 在 Ω 形层号上改用它: `dg zero (λ c → Ωt (h c)) …`.
3. 证书 (W6Path): Ω 形层号的证书加一个可选字段 `Maybe ((c d : Tr k) → h c ≤ h (c + d))`. 塔的证书给出 `just` (用 R15Mono 的证法), 别处先给 `nothing`.
4. 折叠 (W6Fold) 对 `dg x D e` 的行:
   - 目标不在指定孩子里 (经 `ink`, 一致路径 `inu`, `self` 等): 结果与现行 "Ω top 行复合 up 行" 作用在去糖形式上的结果形状相同.
   - 目标在指定孩子里 (`inc c′ v`), 证书有 `just m`: 换参数的一行. 先把左项 x 朝目标折作底, 然后是 `node⁺`: 保留判定用 `kp N o top (inc c′ v)`; 第 d 个分支是在孩子 c′ + d 里沿路径 `v ∙ m c′ d` 朝 j 折 D (c′ + d), 状态取原状态的 `inc (c′ + d)` 条目 (同 up 行进孩子时的平移); 回灌一支照 `steer-node` 的第三个参数.
   - 证书是 `nothing`: 照现行写法逐分支回退.
   - 与折叠互递归的单调性证明 `mono`, 迭代子 E / It 与保留判定里需要的情形一并补上.
5. 闭项: `Ok-Λ` 与 `EBOᶜ` 在 W6 上给出.

## 分阶段交付 (每阶段整体编译; 做不完就停在已编译的阶段并报清楚卡在哪)

- 阶段一: W6Block, W6Ops, W6Path, W6Loc 编译.
- 阶段二: W6Fold 编译 (无 TERMINATING 等指示, 停机与严格正性由检查器通过), 给出 W6 的 `EBOᶜ`.
- 阶段三: 形状事实 (refl), 文件 W6Shape:
  (i) 在 tw 1 上, 朝孩子 t (t 是 ω 的树) 的层号本身折 `Ωt (tw 1)`, 结果是 `node⁺`, 第 d 个分支逐字是孩子 t + d 里的折叠 (R15Steer.steer-node 的类比, 这次是在原层号 N 上, 不是 N′);
  (ii) 在 tw 2 上, c′ 取 `Ωt (tw 1)` 的树, 同样的事实;
  (iii) 左项非零的情形 ("x 右边接上规范 Ω 树", 见 W5Exp4Shape 的 branch-1 等): 朝一个无穷的私有层, 分支不再是尾巴.
