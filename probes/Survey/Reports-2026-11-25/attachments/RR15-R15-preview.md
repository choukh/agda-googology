## 2. EBOᶜ 的值

### 2.1 这几行在真实运行里确实被走到 (推出)

tw 2 的折叠: 对角链 z₀ = zero, z_{m+1} = 在层 tw 1 ⊕ ↑z_m 上朝 tw 1 折 Ωt. z₁ = ex β β β, β = Ωt (tw 1)
= Ω-分支 (c : Tr zero) ↦ up zero c (Ωt (↑c)). 所以 ↑z₁ 里对每个后继的可数 c 都有 sΩ (↑c⁻) 结点, 它的 Ok 证据
(OkO↑ 的 up 行与 Ω 行) 是 ↑c⁻ ≤ tw 1 经 `inc c (inc tt self)`, 即 "经指定孩子 c". 朝第 0 层折 Ωt (tw 1 ⊕ ↑z₁) 时,
这些分支被走链, 回灌目标是 ↑c⁻, 路径在 sΩ 结点上是 ink self, 下到 tw 1 结点时变成 inc c (inc tt self).
在 tw 1 结点上被折的树是 Ωt (tw 1) (以及平移基底 B′ 调出来的树), 于是 (a) 与 (c) 都触发.
所以从塔第 2 项起, 这几行不是死代码. 塔第 1 项 (twᶜ 1) 不触发: 朝 zero 的路径是 inu, 每个孩子里是可数层, 全是带证据的行.

### 2.2 机制: 私有目标上的输出是什么形状 (推出, 展开到第一层; 嵌套部分是估计)

设目标 j 是 tw 1 的私有层 (在孩子 c′ 里), 被折的东西来自 tw 1 或其上的层 (tw 1 ⊕ a).
  - tw 1 之上的部分 (a 的结构) 走 inu 行, 是正确的递归: 后继层的自身行, sL 的 way, ⊕ 平移出来的 sΩ zero 结点
    (目标一致地低于它的孩子) 都带证据.
  - 下到 tw 1 结点: Ωt (tw 1) 被折成 "v ↦ v + (Tr zero 分支, 各项是 v + 可数)" , 值上是 v + Ω₁.
    即从私有目标看, 整个 tw 1 这一块 (Ω_c, c 可数, 以及它们的上确界 Ω_Ω) 只剩一个 Ω₁ 型的量.
  - 输出树里保留下来的分支只有 k 侧槽位 (tw 1 上只有 Tr zero), 孩子侧槽位全部走链.

对最低的私有目标 j = ↑1: (a) 恰好正确, 损失只在 (c). 我展开了 ξ₁ = ψ_1(Ωt (tw 1 ⊕ 1)):
自身行给出 Ω_Ω 上的 ε 塔, 迭代子 E 把 "加 Ω₁" 迭代, Ω_Ω 作指数时经保留的 Tr zero 分支表现得像 Ω₁,
结果是 Ω₁ 的幂塔的极限, 即 ε_{Ω₁+1} (估计到这一步). 这等于理想的 ψ_1(Ω_2), 不是理想的 ψ_1(Ω_{Ω₁+1}):
tw 1 这一块被压成一个基数, "Ω_{Ω₁+a} 表现得像 Ω_{1+a}". 对 a ≥ Ω₁·ω 这个差被吸收. 这是 "滞后".

对更高的私有目标 j ≥ ↑2: (a) 也错 (严格低于 j 的私有槽位应保留而被走链), 输出只含 ω 与 Ω₁ 共尾的分支,
形如 Ω_j·ω^γ, γ 的分支只有 Tr zero. 于是回灌链 ξ_n 的极限不超过 Ω_j·ω^{Ω₂} 量级, 而理想链的第 1 项就已经是
ε_{Ω_j+1} 以上. 后果: 层号下标里一个 Ω_{j+1} 共尾的分支, 在 W4 的折叠下被取值在 "Ω_j 之上一个 Ω₂ 型不动点" 处,
而不是它的上确界处. 这个替换是递归的 (Ω_j 自己作为成分又被同样处理), 所以不是只差一步的滞后:
从 tw 1 之上看, tw 1 块里的 Ω_c (c ≥ 3) 表现得像 "Ω_2 的 c 倍" 量级, 整块表现得像只有两个基数 (公共的 Ω₁ 与一个
"通用私有" 基数). 这是 "封顶" 的机制.

同样的结构在每个 tw (n+1) 上重复: 从上面看, tw (n+1) 块里朝 tw n 的塌缩 (ink) 正确, 块内私有层只贡献一个通用基数.

## 3. 有没有每次比较都带字面证据的写法

分两类比较.

同孩子的比较 (目标与内容字面上来自同一个 `up _ c _`): 可以带证据. 办法是把 ψ 的目标也写成迭代子 E 已经用的
框架相对写法 (Tg: "本框架里的 i ≤ h c" 或 "外层框架的目标"), 回灌目标在它产生的那个孩子框架里记成 "本框架" (hereT).
这样同孩子的保留判定与 up 行在 h c 内部做 (可数层上完全可判), 不必回到 N 上比较 c 与 c′.
编译判据: 一条对一切 N, c 的引理 "目标与槽位写在同一孩子框架里时, kp 的结果等于在 h c 里算的结果", 加一个 refl 实例
(tw 1 上孩子 3 里朝 ↑2 折一个含 Tr (↑1) 分支的树, 输出保留该分支).

跨孩子的比较 (目标在固定孩子 c′, 内容的孩子 c 是 Ω 分支的约束变量, 例如 Ωt N 的每一项): 不能一致地带证据.
对一切 c : Tr k 给出 "j ≤ h c 或 h c 低于 j" 的函数就是在 Tr k 上判定, 对无穷的 j 应当推出 LPO (这是我对壁垒一族的预期, 没有核).
所以设计只能让这类比较不需要: (甲) 用一致的处理 (永不保留, 在内容自己的框架里按上下文折, 而不是折到第 0 层再加),
再证明真实运行里 "应保留" 的那些 c 被 "应折" 的 c 共尾地支配; 但 2.2 说明永不保留本身会让 Ω_j 作为成分被降级, 所以 (甲) 还不够.
(乙) 改块: 禁止私有层出现在它的结点之上的层号下标里 (读回 ↑ 遇到私有槽位的分支时不产生 sΩ 结点), 那些共尾度改用
对象层的对角 ℕ 极限加回灌的可数层号表示 (sL 上的比较由 way 给字面证据). 这就是参照系统的做法, 代价是读回要先于折叠定义.
编译判据 (对任何设计): 把回退行做成可识别的 (输出带标记, 或回退行要求一个不变式下的 ⊥), 用 PS 式的不变式证明
EBOᶜ 的运行不经过回退行; 否定侧, 用一个探针证明 "对无穷目标完全的跨孩子定位" 推出 LPO.

我的看法: 在这一族块里 (层号下标可以含私有槽位, 孩子按 Tr k 的任意元素索引), 做不到每次比较都带证据; 能带证据的只有同孩子的.
