#### 1. 结论

**对纲领与目标的含义。** W4 与候选 W5 的值是否达到 EBO，我没有判定，倾向与负责人接近：达不到的可能约六成（判断）。新的一点是：负责人列为 "壁垒的情形、不在可改之列" 的那一类（保留结点的分支下标是约束变量），在塔型层号的规范 Ω 树上不需要比较孩子，有一种每一步都带字面证据的写法。它的核心已编译，对一切塔高、一切目标层（含无穷的私有层）成立，但落成折叠的一行要改块。

##### 1.1 这几行做什么（由定义读出；与审计 §9.2 的表一致）

- `kp N _ (inj₂ (c , t)) (inc c′ v) = nothing`：孩子侧槽位、目标在指定孩子里，W4 一律走链。槽位层严格低于目标时应保留，这时偏低；对每个结点最低的私有目标（`tw 1` 上是第 1 层），孩子侧槽位都不低于目标，这一行正确。
- `ψ N o B j (inc c′ v) β (up x c y e)`：W4 给出 `ψ … x ⊞ (y 从头折到第 0 层)`。理想的做法要对 `h c` 与 `j` 三歧：`j ≤ h c` 时在 `h c` 里以 `ψ_j(x)` 为底朝 `j` 折 `y`，`h c` 低于 `j` 时保留 `y`。
- 候选：有限的私有目标用定位器就地折；孩子 zero 的内容经证书路径嵌入；保留判定在两边都是有限层时正确；其余仍回退。无穷的私有层与 W4 相同。

**我第一阶段有一处错，已被负责人的 §14 纠正。** 我写 "回退行没有偏高的情形"，依据是它在 `Tr j` 里的序数值不超过理想值。这个依据不够：结果以后还要再折到第 0 层，W4 的尾巴是可数树，原样带下去，最终值可以高于理想塌缩的对应值（§14 的例子：第 1 层目标、孩子 3 里的 Ω₃）。我同意 §14 "候选与 W4 逐行不可比"。

##### 1.2 机制（判断；展开到第一层是手工推导，嵌套部分是估计）

设 `j` 是 N 的私有层，被折的内容来自 N 或它上面的层。

- N 之上的部分（后继层的自身行，`sL` 的 `way`，一致路径）走带证据的行。
- 下到 N：N 的规范 Ω 树被折成 "底加一个只含 k 侧分支的量"，输出里保留下来的分支只有 k 侧槽位。
- 对最低的私有目标（`tw 1` 上的第 1 层），我手工展开 `ψ_1(Ωt (tw 1 ⊕ 1))`，得到 Ω₁ 的幂塔的极限，即 ε_{Ω₁+1}。这等于理想的 ψ₁(Ω₂)，不是理想的 ψ₁(Ω_{Ω₁+1})：整块被压成一个基数，层号下标足够大时这个差被吸收。这是 "滞后"。
- 对第 2 层以上的私有目标，保留判定也错，回灌链的值形如 "Ω_j 加一个第 1 层型的量"，而理想链的第 1 项已在 ε_{Ω_j+1} 以上。这个替换是递归的。按这条推导，W4 的结构部分第一次与理想分开是在层号下标含 Ω₃ 共尾的分支处；塔第 2 项的结构部分约在 ψ₀(Ω_{Ω₃})，塔的上确界约在 ψ₀(Ω_{Ω_ω})（粗估，低阶项不可靠）。候选把 `tw 1` 块里第一个失败的私有目标从第 2 层推到第 ω 层，`tw 2` 以上的块没有变。
- 这只是 "结构部分"。回退行的尾巴把低块的第 0 层塌缩值送进可数层的回灌（已编译的 `above-btbo`、`next-closure` 是它的一个实例），树上的折叠对非标准形的层号仍有值。这一部分能补多少，我没有估法。所以总的倾向只是约六成达不到，不是定论。

##### 1.3 哪一处不是工程问题

- **是工程问题的**：孩子 zero 的内容（候选已做）；有限的私有目标（候选已做）；**约束变量的那一类，在塔型层号的规范 Ω 树上**（本次编译，见第 3 节）。
- **不是工程问题的**（判断）：
  1. 两个具体的、没有字面关系的孩子之间的比较，孩子下标类型含 Ω 共尾元时（`tw 2` 起）是壁垒定理的情形。
  2. 读回层号里的 Ω 形结点（如追踪里的 `Qr`）：它的孩子族由折叠输出或 `Ωt` 的读回给出，对右加法没有字面的单调路径。其中一个原因是 `zero ⊕ a` 不定义地等于 `a`，这是块的写法问题；另一个原因是折叠输出之间本来没有字面关系，这不是写法问题。

##### 1.4 下一条该证的

按成本排，接口都已有编译的部分：

**定理（Agda，无前提；折叠是 `W4Fold.ψ`，没有改）。**

`R15Mono`：

```agda
↑⊑+ : (k : L) (x y : Tr k) → ↑ k x ⊑ ↑ k (x + y)
hN : (n : ℕ) → Tr (tw n) → L          -- hN n c = tw n ⊕ ↑ (tw n) c
tw-mono : (n : ℕ) (c d : Tr (tw n)) → hN n c ≤ hN n (c + d)
steerPath : (n : ℕ) {j : L} (c′ : Tr (tw n)) → j ≤ hN n c′ → (d : Tr (tw n)) → j ≤ hN n (c′ + d)
```

`R15Steer`，模块 `Steer (n : ℕ) (c′ : Tr (tw n))`，其中 `N = tw (suc n)`，`oN = Ok-tw (suc n)`，`h′ d = hN n (c′ + d)`，`N′ = nd (sΩ (tw n)) h′`，`oN′` 的各分量取自塔的证书，`top = inj₁ (inj₁ tt)`，`ws v d = steerPath n c′ v d`。以下都是 `refl`：

```agda
ws-zero : ∀ {j} (v : j ≤ hN n c′) → ws v zero ≡ v
steer-kp : ∀ {j} (v : j ≤ hN n c′)
         → kp N′ oN′ top (inu (ws v)) ≡ kp N oN (inj₁ (inj₁ tt)) (inc c′ v)
steer-branch : (S : Base N′) {j : L} (v : j ≤ hN n c′) (β : Tr⁺ j) (d : Tr (tw n))
  → ψ N′ oN′ S j (inu (ws v)) β (proj₁ (upz {s = sΩ (tw n)} {h = h′} d (Ωt (h′ d))))
  ≡ ψ (h′ d) (proj₂ oN (c′ + d)) (λ i u → S i (inc d u)) j (steerPath n c′ v d) β (proj₁ (Ωt (h′ d)))
steer-node : (S : Base N′) {j : L} (v : j ≤ hN n c′) (β : Tr⁺ j)
  → ψ N′ oN′ S j (inu (ws v)) β (proj₁ (Ωt N′))
  ≡ node⁺ (kp N oN (inj₁ (inj₁ tt)) (inc c′ v))
      (λ d → ψ (h′ d) (proj₂ oN (c′ + d)) (λ i u → S i (inc d u)) j (steerPath n c′ v d) β (proj₁ (Ωt (h′ d))))
      (λ d → proj₁ (ψ (h′ d) (proj₂ oN (c′ + d)) (λ i u → S i (inc d u)) (tw n)
                      (self ∙ lift (tw n) (↑ (tw n) (c′ + d))) (S (tw n) (ink self)) (proj₁ (Ωt (h′ d)))))
```

读法：朝孩子 c′ 里任意层 j 折 "尾段层号 N′" 的规范 Ω 树时，保留判定与原层号上带证据的那一行逐字相同，每个分支与回灌逐字是孩子 `c′ + d` 里沿字面路径的折叠。对一切 n、c′、j、v、d。

**实例（`refl`，属有限检查性质的形状事实）。** `t` 是 ω 的树，`h₁ = hN 0`：

```agda
w5-miss : loc (h₁ t) (h₁ (suc t)) ≡ nothing
steer-hit : steerPath 0 t self (suc zero) ≡ inc tt self
inst₁ : (S : Base T1.N′) (β : Tr⁺ (h₁ t))
  → ψ T1.N′ T1.oN′ S (h₁ t) (inu (T1.ws self)) β (proj₁ (upz {s = sΩ zero} {h = T1.h′} (suc zero) (Ωt (h₁ (suc t)))))
  ≡ ψ (h₁ (suc t)) (proj₂ T1.oN (suc t)) (λ i u → S i (inc (suc zero) u)) (h₁ t) (inc tt self) β (proj₁ (Ωt (h₁ (suc t))))
inst₂ : (S : Base T2.N′) (β : Tr⁺ (hN 1 cΩ))        -- cΩ = proj₁ (Ωt (tw 1)), T2 = Steer 1 cΩ
  → ψ T2.N′ T2.oN′ S (hN 1 cΩ) (inu (T2.ws self)) β (proj₁ (upz {s = sΩ (tw 1)} {h = T2.h′} cΩ (Ωt (T2.h′ cΩ))))
  ≡ ψ (T2.h′ cΩ) (proj₂ T2.oN (cΩ + cΩ)) (λ i u → S i (inc cΩ u)) (hN 1 cΩ) (steerPath 1 cΩ self cΩ) β (proj₁ (Ωt (T2.h′ cΩ)))
```

`w5-miss` 与 `steer-hit` 是同一处：目标是第 ω 层，孩子是 t + 1；候选的定位器放弃，换参数给出路径 `inc tt self`。`inst₂` 说明孩子下标含 Ω 共尾元（塔第 2 项）时同样成立。
