# 目标与验收契约

2026-09-09。唯一目标是从类型宇宙定义规则自动提取基本列，应用于 Mahlo 并认证 F_{α_M} 及具体大数。

## 1. 输入和“自动”的含义

输入 R 是明确呈现的对象类型理论：基础规则、宇宙形成与闭包、计算与消去规则，以及绑定、代换和允许的算子。具体目标见 [INPUT.md](INPUT.md)。一个宿主 `Set` 值或任意函数黑箱不构成完整输入。

可以预先固定通用编码、调度和适用于所支持规则类别的提取方法。该方法必须说明覆盖哪些规则，不能要求对任意类型理论都成功。研究者可以证明通用提取原理；Mahlo 实例不能额外输入手写的目标 ψ 记号、基本列或等价的预制下降操作。

独立文献中的目标序数用于校准输出，不能用于生成输出。若算法实际读取了它，就必须报告为参考系统实现，不能登记为本目标完成。

## 2. 输出必须包括基本列本身

目标是从 R 统一生成一个有效表示 O_R、其比较／下降操作、端点表示 Top_R，以及基本列操作。允许研究不同表示方案，但必须明确其计算与语义契约。

对表示为非零极限的 λ，输出总可计算的 λ[n]，并证明：

\[
 |\lambda[n]|<|\lambda|,\qquad
 \sup_n|\lambda[n]|=|\lambda|.
\]

指定严格递增或非递减约定，并证明足以支撑后续增长比较的正则性。零与后继也必须有正确的计算处理。若采用另一种下降接口，应证明其产生所需基本列和 FGH 行为，不能仅把树分支改名为基本列。

上述要求同时适用于端点和递归计算可能访问的内部极限。只有端点共尾族、只有树良基性、只有程序增长上界，都不满足输出契约。

表示的语义不要求是源宇宙每个类型的集合论秩；目标是宇宙规则系统所支持的证明论强度。局部近似可以有冗余，但最终必须证明既不漏掉目标强度，也不超报。

## 3. Mahlo 实例的终点

α_M 指所选 Setzer MLM 的证明论序数，采用独立分析中的记号约定；见 [INPUT.md](INPUT.md)。必须证明生成端点确实对应它，而非仅具有 Mahlo 名称或某个 Mahlo 集合论模型。

在生成的基本列和明确迭代约定下定义：

\[
F_0(n)=n+1,\quad F_{\beta+1}(n)=F_\beta^{\,n+1}(n),\quad
F_\lambda(n)=F_{\lambda[n]}(n).
\]

这些方程是输出端要求，不是生成 λ[n] 的方法。最终大数为 N_M=F_{α_M}(k)，k 尚未选定。旧归档 v0/v1 的手选基本列与点值约定不约束新提取器。

## 4. 必须同时满足的验收项目

| 编号 | 必证内容 |
|---|---|
| E | 提取确实来自输入宇宙规则；绑定、代换与计算规则相容；没有把目标答案藏进参数 |
| C1 | 生成表示合法，序关系正确；Mahlo 端点与独立参考 α_M 精确对应 |
| C2 | 全部所需基本列可计算、下降、共尾，并具备有效增长比较所需的正则性 |
| C3 | FGH 是闭合全函数，满足方程；结果不依赖良基证书的选择 |
| C4 | 输入单调与层级支配；若有阈值，明确范围和可计算界 |
| C5 | 与独立参考 FGH 的受控双向比较；不得用任意快速输入换算掩盖差异 |
| C6 | 最终支配所选 MLM 的可证全函数；明确函数表示、证明编码与定量分析 |
| C7 | 冻结 k 后给出可检查的实际大数下界，验证每条比较的输入条件 |

证明论端点相同不自动蕴含 C5–C7。渐近支配也不保证某个固定输入已经足够大。

## 5. 研究纪律

每次探索写明：所分析的宇宙规则、产生的具体逼近操作、下降／共尾证据，以及尚缺的部分。只有能推进这些内容的辅助引理才能进入当前路线。

禁止用自然数层级增长、一般高阶程序分析、证明枚举、手写序数库或单独的良基性移植替代核心任务。这些方法可以作为有明确接口义务的工具；不能因它们自身有进展就宣布宇宙提取有进展。

元理论中的推理与对象理论规则分开记录。不得默认增加完整 Agda 宇宙能力、一般 Acc 或 Mahlo 消去器。进入实现后坚持 `--safe --without-K`，不靠 postulate、终止绕过或未证明的目标实例交付结果。
