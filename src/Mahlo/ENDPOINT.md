# U0/U4：端点与量词审计

状态：识别到真实的元归纳依赖；端点统一化尚未解决。

## 1. 原文证据

[Mahlo 原文](https://csetzer.github.io/articles/mahlo.pdf) 的 Definition 5.12、Lemma 5.13 和 Theorem 5.14 通过引用单宇宙加 W 型论文的相应构造得到阶段性结果。

追查 [Setzer，Well-ordering proofs，§4.7](https://csetzer.github.io/articles/2papdiss.pdf)，发现 Lemma 4.40 的证明明确写为 **“Meta Induction on i : N”**。Theorem 4.41 的陈述把自然数 n 放在对象理论可证明性符号之外；其后才给出证明论序数上确界。

因此，现有来源支持的是逐阶段的证明模式。它尚未直接交付一个 Agda 中统一的证书生成函数。此处的“未交付”不等于无法在更强宿主中实现。

## 2. 目标接口

待核验候选阶段为 `b_n = ψ_{Ω₁}(Ω_{M+n})`。需要分别完成：

1. n 到合法记号 b_n 的统一计算。
2. b_n 的次序与共尾性质，确证上确界为目标 α_M。
3. 对每个 b_n 以下初始段的证书。
4. 将阶段性证书合成为一个封闭函数。
5. 引入端点对象 Top，规定 Top[n]，并证明它的下降递归原理。

“所有 x < b_n 可达”还不直接提供 b_n 自己的证书。若已证 b_n < b_(n+1)，可以使用下一阶段的初始段结果取得它；这个移位也必须出现在形式化中。

## 3. 宿主统一化的具体检查

从源证明的 `W_0`、`W_(i+1)` 构造出发，记录：

- 每个阶段是小谓词 `Nat → V`，还是更大的类？
- 形成下一阶段时用了哪一种 W／宇宙构造？
- 阶段构造是否可置于固定的 Agda 类型？
- 证明的递归是否只依赖 n 的前驱？是否同时提升了谓词大小？

仅在这些问题得到解答后，才能判断普通 Nat 递归配合当前宿主是否足够，或需要进一步的宇宙闭包。不能根据“元归纳”三个字直接宣布一定需要新公理，也不能根据 Agda 有 `Set₁` 就宣布问题消失。

## 4. 本轮决定

端点关卡继续保持开放。当前 External 模块不定义目标序数、阶段记号、Top 或 FαM；没有用常量列或仅有前几个阶段冒充目标基本列。

下一步先把原文的阶段构造翻译为有明确宇宙级别的类型草案，再开展完整良序证明工程。

## 第二轮补充

[正归纳生成模块](WellOrder/Accessible.agda) 已检查：生成类型的层级是资格／前驱关系层级的并，且可消去到更高层级。对已编码的小参数，[W 编码](Universe/GeneratedCode.agda) 给出同一子宇宙内的生成谓词代码。

这排除了“每使用一次归纳生成就必然提高宇宙”的简单障碍，但尚未证明原文所有阶段参数公式保持同一层级，也未构造统一的阶段证书。端点关卡继续开放。
