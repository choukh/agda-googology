# U3：首个 Mahlo 引理的依赖拆解

状态：原文依赖审计；第二轮已实现通用归纳生成与小覆盖，但下表中的具体 Mahlo 引理仍未完成。见 [第二轮记录](SECOND-ITERATION.md)。

依据 [Setzer §5，第 18–19 页](https://csetzer.github.io/articles/mahlo.pdf)。沿用原文的 `W`、`A`、闭包算子和 distinguished set 记号；这些符号目前不是本项目已经定义的 Agda 类型。

| 节点 | 原证明中的用途 | 本地下一项义务 |
|---|---|---|
| 5.8(a,b) | 把有限项的闭包依赖缩到可表示的支持，并保持包含关系 | 有限记号、支持及闭包的定义与归纳 |
| 5.8(c,d) | 从全局闭包事实取得小的 distinguished set 见证 | 小谓词与收集已实现；初始段并已证；仍需实际记号下的 Lemma 4.26 |
| 5.9 | 用常值族算子把指定族编码到所生成的子宇宙 | Recode 已给出两分量解码等式；对象规则解释仍需接入 |
| 5.10 | 根据输入小族及 distinguished set 见证构造 f,g，反射到对应子宇宙 | 明确该算子的类型、构造性选择步骤与大小；实例化通用闭包构造 |
| 5.7 | 在反射得到的子宇宙内识别相关初始段 | 完成其前置闭包及记号引理，不能将它列为公理 |
| 5.11(a) | 合用 5.10 与 5.7，建立 M 以下的关键闭包包含 | 展示反射在证明中的实质用途 |
| 5.11(b) | 从 (a) 与归纳得到 W 与其扩张在 M 以下的一致性 | 检查所用归纳原理及其宿主解释 |
| 5.12–5.14 | 阶段构造及各阶段归纳下界 | 另见 ENDPOINT.md 的统一化审计 |

本轮已编码 5.9 的常值族重编码核心；首个足以判断主线飞跃是否落实的数学任务是 5.10–5.11。当前 External.Example 只是对非恒等算子的计算检查，不是 5.10 所需算子，也不满足路线图对该实际算子实例的最终验收条件。

5.10 的存在性步骤需要逐一翻译为带见证的构造，而不是把论文中“存在”统一替换成宿主 postulate。尤其从输入族得到 distinguished set 扩张的步骤，要同时记录见证所在宇宙及其证明数据。
