# 第四轮：有限支撑计算及其正确性

日期：2026-09-08。

本轮将闭包从一个完全外给的谓词推进到可执行的有限支撑算法，并证明算法与闭包推导规则等价。**尚未完成原记号 OT 的实例化，也没有取得新的 Mahlo 强度下界。**

## 1. 已实现及已证明

[FiniteSupport.agda](Notation/FiniteSupport.agda) 用列表表示有限支撑、用列表的列表表示备选支撑族。允许重复，不需要有限集合商类型或成员相等的判定。

- `tensor` 枚举两族支撑的所有拼接；`tensor-in/out` 证明满足乘积族等价于分别满足两族。
- `finite-witness` 从一个满足证书提取具体有限列表、列表包含于原种子谓词的证书，以及仅用这个列表仍能满足同一支撑族的证书。
- `decide` 在种子成员可判定时给出带正确性证书的判定；任意小谓词不自动可判定。

[Closure.agda](Notation/Closure.agda) 在有限分解表达式上实现 `K a d`，计算 d 在截断点 a 下所需的备选支撑族。种子谓词 A 不参与 K 的计算；`C A a d` 表示其中至少一个支撑完全由 A 提供。

独立定义的 `Derivable` 有种子、零、Mahlo 常量、加法分解、φ、Ω、受限 ψ 等推导规则。已经证明：

| 定理 | 精确内容 |
|---|---|
| `sound` / `complete` | 有限支撑证书与规则推导证书可以双向转换 |
| `seed` | A 中低于 a 的表达式属于计算闭包 |
| `monotone-C` | 扩大种子谓词保留闭包成员资格 |
| `finite-character` | 每个闭包成员都有可提取的有限种子见证，且只用这些种子仍属于闭包 |
| `local-C` | 在**同一个截断点 a** 以下转换种子成员资格，即可转换该截断点的闭包证书 |
| `decide-C` | 给定种子谓词的判定，计算闭包成员的肯定证书或反证 |

这里的有限性指每个成员的支撑有限，**不表示闭包本身是有限集**。显式枚举支撑可能迅速膨胀；本轮没有复杂度或高效性结论。

代码还给出了表达式上的候选 M(A)、τ_A 及种子到 τ_A 的映射。它们使用计算出的闭包，合法性仍是显式输入。

## 2. 原文公式核对

对照 [Setzer 前置论文](https://csetzer.github.io/articles/2papdiss.pdf) Definition 5.1–5.4、Lemma 5.5，以及 Mahlo 论文沿用的闭包构造。下载后的 PDF 页码为 47–48；网页抽取的页索引有偏差。已直接查看原始页面，未只依赖文本抽取。

Definition 5.3 的受阻 ψ 分支印为单元素支撑族 `{{d}}`，没有显式的截断过滤。它与前文规则的协调需要合法 ψ 项满足 `d = ψκc < κ`：若 `κ ≤ a`，就有 `d < a`。

本实现每次引入种子都显式检查 `d < a`，受阻分支亦如此。这使算法与所声明的推导规则无条件等价。**与原文简写等价的证明仍需真实 OT 的比较、三歧性及 ψ 界定理**；本轮没有判定原文有误，也没有将任意布尔比较视为满足这些定理。

## 3. 与真正 Mahlo 记号的距离

`Expr` 是闭包计算的分解表达式，不是完整 OT。特别是：

1. `add b c` 表示二元分解位置；没有实现原文主项序列的正规性，也不是一般序数加法算法。
2. `lt` 是传入的可执行布尔函数，没有默认顺序规律。真正的比较、支撑函数、正规性、ψ 指标的正则性仍待实现。
3. 需要证明合法正规项及其分解与此表达式对应，并证明计算闭包与原文闭包相符。候选 M、τ 中加入根的合法性，不能替代这项对应证明。
4. 尚未提供表达式与自然数代码之间的编码／解码证明，因而本轮候选 M、τ **尚未接入既有 Nat 索引的 `Distinguished.FromClosure` 或宇宙中的 `GeneratedCode`**。
5. 同一截断点的 `local-C` 不是 Se98 Lemma 4.7 所需的全部截断变换，也不是 distinguished-set 唯一性或 4.26。

因此，第三轮所列“具体记号闭包实例及小性编码”任务本轮只完成计算部分；不将剩余接口义务改记为完成。C1–C7 均未整体验收通过。

## 4. 下一步顺序

先实现原文主项序列与各类项的语法约束、正规分解，再逐项实现原始比较及其依赖的支撑计算。以参考定义的实例核查这些操作，禁止借用表达式大小等替代序数顺序。

随后给出正规项到分解表达式的对应、自然数编码／解码和闭包相符定理，将 M、τ 接入现有生成归纳与宇宙编码。再推进特定截断的局部性、唯一性及 4.26。

量级契约中的定量证明分析来源与缺口表仍待完成；本轮有限支撑定理不能替代可证全函数上界、端点统一化或基本列校准。
