# 理论探索三：从原始递归推导提取增长上界，以及一次返回类型提升

2026-09-09。纸面研究，无新增代码。承接[理论探索二](EXTRACTION-BRIDGE-2.md)。

本轮完成一个受限但无条件的小定理：从一阶原始递归的有限构造推导，直接计算支配其函数的有限增长层级；证明这些层级在增长意义上无法被有限截断。随后给出返回函数的递归如何突破该界。

**范围**：输入是函数构造／全性推导，不是任意良序证书，也不是完整算术或类型理论的任意证明。下面的 ω 是这一增长标尺的指标上确界，不能称为 PRA、MLM 或某个未分析理论的证明论序数。上轮计划要求的完整良序证书上界提取仍未完成。

## 1. 固定输入规则，而非先指定端点

令 PR 的推导表达式包括有限元数的零函数、后继、投影，以及以下两条构造规则：

- 复合：由 g 与同元数的 h₁,…,hᵣ 构成 g(h₁,…,hᵣ)。
- 原始递归：由 g(x̄)、h(i,y,x̄) 构成 f，满足 f(0,x̄)=g(x̄)，f(i+1,x̄)=h(i,f(i,x̄),x̄)。

零元数情形允许，空输入的大小约定为 2。推导只含返回自然数的上述规则，不默认加入一般 λ 应用、高阶参数、W 或宇宙。

算法为每份推导 p 分配自然数 b(p)：

\[
\begin{aligned}
b(\mathrm{zero})=b(\mathrm{succ})=b(\mathrm{proj})&=0,\\
b(\mathrm{comp}(g,\bar h))&=1+\max(b(g),b(h_1),\ldots,b(h_r)),\\
b(\mathrm{rec}(g,h))&=1+\max(b(g),b(h)).
\end{aligned}
\]

这只读取有限推导结构。它不是最小增长级别算法；恒零函数也可能因冗余推导而得到很大的 b。

## 2. 上界操作来自递归规则的计算需要

基本规则只需后继上界 H₀(n)=n+1。若同一单调上界 h 已支配递归初值和步函数，输入不超过 n，则需要对 h 至多迭代 n+1 次。因此采用统一闭包操作

\[
J(h)(n)=h^{\,n+1}(n),\qquad H_{k+1}=J(H_k).
\]

这里是分析者根据规则证明选出的上界操作，不宣称已有“从任意规则自动发现最优 J”的元算法；自动化的是固定规则解释后的逐推导翻译。这一限制在推广到宇宙时必须保留。

对 k 归纳可证 H_k 在自然数上严格递增，H_k(n)≥n+1，且 H_k(n)≤H_{k+1}(n)。当 n≥1 时后一不等式严格，因为至少多进行一次严格增大的迭代。后文只在 n≥2 使用这些性质。

## 3. 完整的局部上界证明

**定理。** 对每份 PR 推导 p，设其函数为 f_p，令 N=max(2,x̄)，则

\[
 f_p(\bar x)\le H_{b(p)}(N).
\]

证明按推导结构归纳。基本函数显然满足。以下子推导归纳假设对所有输入成立，不要求 f_p 本身单调。

**复合。** 令 m 为所有子推导层级的最大值。每个 h_j(x̄)≤H_m(N)，而 H_m(N)≥N≥2。因此将归纳假设用于 g，得到

\[
 g(h_1(\bar x),\ldots,h_r(\bar x))
 \le H_m(H_m(N))
 \le H_m^{\,N+1}(N)=H_{m+1}(N).
\]

若没有 h_j，g 是零元函数，直接由 H_m(2)≤H_m(N) 得到同一结论。

**原始递归。** 对输入 (i,x̄)，令 N=max(2,i,x̄)，m=max(b(g),b(h))。对 j≤i 证明

\[
 f(j,\bar x)\le H_m^{\,j+1}(N).
\]

j=0 来自 g 的归纳假设。若 j<i，步函数的所有实参不超过 H_m^{j+1}(N)：j 与 x̄ 均不超过 N，累计结果由内层归纳控制。故

\[
 f(j+1,\bar x)\le H_m(H_m^{\,j+1}(N))=H_m^{\,j+2}(N).
\]

最后 i≤N，得到 f(i,x̄)≤H_m^{N+1}(N)=H_{m+1}(N)。证毕。

这里同时得到一个有效增长证书：从 p 计算 b(p)，无需先运行 f_p，也无需判定其真实增长级别。

## 4. 覆盖、端点调度与可计算阈值

每个固定 k 的 H_k 都有 PR 推导：H₀ 是后继；若 H_k 已有推导，迭代函数 I_k(0,x)=x、I_k(t+1,x)=H_k(I_k(t,x)) 由原始递归构成，再取 H_{k+1}(n)=I_k(n+1,n)。这是元层对固定 k 生成有限推导；还不是在 PR 内定义统一的 (k,n)↦H_k(n)。

H_{k+1} 在所有 n≥1 严格超过 H_k，因此任何有限截断都不能支配 PR 全部函数。再结合第 3 节，没有 PR 函数逃出全部有限层级。这里的“精确覆盖”是**函数增长类的双向覆盖**，不是认证良序阶型的覆盖。

提取标尺由基本级、有限最大值和升一级生成；其规范级别是自然数，指标上确界因而为 ω。按固定的无移位调度令 Top[n]=n，得到严格递增且共尾的端点列。定义

\[
 A(n)=H_n(n).
\]

对任何一元 PR 推导 p，取可直接计算的阈值 N_p=max(2,b(p)+1)。当 n≥N_p 时，

\[
 f_p(n)\le H_{b(p)}(n)<H_n(n)=A(n).
\]

所以 A 支配所有 PR 一元函数，且 A 不属于 PR；否则把其 PR 推导代入上述结论会得到 A(n)<A(n)。A 的元层全性由先对 k、再对迭代次数的嵌套自然数递归证明。该论证没有给出任意源程序归约步与序数下降逐步对应的模拟；不能将增长上界证明登记为全部 E2 已完成。

## 5. 独立校准，明确基本列的位移

[Schmitz, Complexity Hierarchies Beyond Elementary，§2.1–2.2、§5.3.1](https://arxiv.org/pdf/1312.5686)采用 F₀(n)=n+1、后继迭代 n+1 次，有限层级与这里的 H_k 相同，并讨论有限层级与原始递归类的关系。但其 ω 的基本列取 n+1，因此该文 F_ω(n)=H_{n+1}(n)，与本节 A 的约定不同。

无需混同两种函数，可直接证明

\[
 A(n)\le F_\omega^{\mathrm{Schmitz}}(n)\le A(n+1).
\]

左边用层级单调，右边用输入单调。这提供一个受控的双向比较实例，而非仅凭同属 Ackermann 量级就声称逐点相等。它不决定未来 FαM 的基本列约定或固定大数输入。

## 6. 一次返回类型提升，怎样突破所有有限级

加入函数类型与返回类型可为 ρ 的自然数递归子：

\[
R_\rho(a,s,0)=a,\qquad
R_\rho(a,s,k+1)=s(k,R_\rho(a,s,k)).
\]

高阶递归是 System T 的标准能力；参见 [Schwichtenberg–Bellantoni, Feasible Computation with Higher Types，导论](https://www.mathematik.uni-muenchen.de/~schwicht/papers/mod01/mod01.pdf)。这里仅用其一般类型递归背景，不采用该文针对可行计算另加的限制。

J 本身可用返回自然数的递归定义，在上下文中接受函数参数 h。令 ρ=ℕ→ℕ，则

\[
 K(k)=R_{\mathbb N\to\mathbb N}(\mathrm{succ},\lambda i\,h.J(h),k),
 \qquad D(n)=K(n)(n).
\]

按 k 归纳，K(k)=H_k 逐点成立，故 D=A。这次递归的累计值是整个函数，而不是某次调用的自然数结果，因此能在一个有限表达式中统一遍历全部有限级。第 4 节已证明，任何只为每份程序分配有限增长级别的可靠分析都无法覆盖 D。

这是一个实际的**类型返回值提升带来的函数增长下界**。它不是完整高阶片段的上界分析，更没有证明该片段恰以 ω 为终点；加入更多这样的构造还可能更强。Π 函数类型也不是 Mahlo 类型宇宙，此处没有得到宇宙闭包或反射的坍缩规律。

## 7. 对 Mahlo 主线的判断与下一关

本轮支持：有限规则推导确实可以携带可自动提取的增长证书，且逐项宽松上界能与整体精确的增长类覆盖共存。它还给出必须跨越有限标尺的具体高阶项，而非凭宇宙名字猜测强度。

本轮尚不支持：由任意宇宙规则自动发现上界操作；由可证函数的增长标尺直接恢复证明论序数；由 System T 的高阶迭代直接推出 Mahlo 反射的基本列。

**下一关不继续堆叠有限层级实例。** 转向高阶代换与应用的上界解释：函数参数应携带“把输入界转换成输出界”的信息，不能只带一个固定自然数级别。须给出相应的应用、抽象、递归规则，并调查其消去如何形成有效下降表示。若需要预先输入整个目标序数系统，必须明确报告这只是已有序数分析的形式化，未达到用户要求的统一生成。

文献候选 [Schwichtenberg–Wainer, Infinite Terms and Recursion in Higher Types，§1](https://epub.ub.uni-muenchen.de/4490/1/26.pdf)研究带自主序列的无限项代码及归约。其序列形成规则包含对全部分支合法性的条件，不能因代码是自然数就认定合法性可判定。它是下一步调查的表示方法候选，不是已经得到可判定基本列系统的现成结论。
