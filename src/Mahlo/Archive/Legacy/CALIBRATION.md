# 终点与量级验收契约

**主线补充（2026-09-09）**：计算表示与基本列须由[统一提取技术](EXTRACTION-PLAN.md)产生；Setzer 记号是独立校准基准。下文 v0/v1 的手选列已降为探针，不再固定最终输出的点值。另须证明提取对输入宇宙规则的正确性与覆盖性。C1–C7 全部保留。


更新：2026-09-08。吸收关于 FαM、增长率与具体大数的对齐讨论。以下是必须完成的证明义务，不是现有代码已证性质。

## 1. 三个对象分别固定

- 指标：Setzer MLM 的证明论序数 α_M，采用 ROADMAP.md 指定的原记号系统。
- 函数：指定基本列和迭代约定下的 FαM : Nat → Nat。
- 数值：冻结输入 k 后的 N_M = FαM(k)。k 目前未选定。

2026-09-09 已采用[定义 v0](DEFINITION-FIRST.md)：输入从 0 开始，后继层迭代 n+1 次，端点取无移位的 b_n；随后[定义 v1](UNIVERSE-AND-SEQUENCES.md)选定内部极限的有限高度搜索列。真实记号实例及其校准未完成，k 尚未确定。改变任何影响数值的约定，都需重新校准，不能仅保留旧函数名。

## 2. 必须证明的性质

| 编号 | 证明义务 | 主要证明方法／依赖 |
|---|---|---|
| C1 | 记号合法性、比较正确性、参考系统对应及端点准确性 | 有限语法归纳、保序解释、端点共尾性；只有保序嵌入不足以排除目标被高估或低估 |
| C2 | 基本列合法、下降、共尾、适当单调，及有效增长比较所需的规律 | 范数与受输入控制的下降关系；Bachmann 性质或经证明足够的替代条件 |
| C3 | 闭合全函数、统一端点证书、求值方程、结果与证书选择无关 | 良基递归及其唯一性；树转换须保持下降接口与求值。只证明自然数输出相等，不要求所有证书彼此相等 |
| C4 | 输入单调性及有效层级支配 | 在选定约定下证明；若仅从阈值起成立，必须给出范围与可计算阈值，不能偷换为全输入结论 |
| C5 | 与独立参考层级精确对应或有受控的双向比较 | 同基本列优先证明逐点相等；不同基本列需给出两向模拟与明确比较界 |
| C6 | 最终支配 MLM 的可证全函数 | 定量证明分析：由具体可证全性证明提取低于 α_M 的下降／计算界，转换为 FGH 界，再由端点吸收 |
| C7 | 固定输入的大数具有明确数值下界 | 冻结 k 和基准定义，构造可检查的符号展开与不等式链，验证 k 满足每条比较规则的条件 |

C5 的参考层级必须有独立的记号／基本列来源或充分的增长校准，不允许把实现复制一份后称为参考。允许的输入调整必须预先限定并证明不会掩盖层级差异；禁止用任意可计算的快速增长换算函数制造“等价”。

## 3. 函数增长的核心定理目标

对所选参考系统的每个 β < α_M，目标是有效取得阈值 N_β，使 n ≥ N_β 时 F_β(n) < FαM(n)。不能只从 β < α_M 推出所有 n 的点值比较。

但支配所有较低层级只有下界意义，更强函数也满足它。精确标定还要求 C1、C2、C5 的端点及计算对应。若只得到上下界夹逼，就报告实际的夹逼范围，不宣称已经确定精确量级。

C6 升格为完整目标的必做项。先固定“MLM 可证全函数”的表示：对象理论版本、自然数函数的程序／公式表示、证明编码与语义解释。目标陈述为每个这类 g 都有 N，使所有 n ≥ N 时 g(n) < FαM(n)。随后研究能否从证明中有效提取 N；不得预先把这一提取能力视为已证。

证明路线分开记录：

1. 宇宙反射提供计算所需的良基性下界。
2. 对象证明的定量分析提供可证全函数的计算上界。
3. Hardy、下降函数与所选 FGH 约定之间的比较连接两端。

仅知道证明论序数，或仅移植阶段良序证明，均不自动交付第 2、3 项。现有针对 KPM 的结论不能直接代替 MLM 的定理。

## 4. 数值验收独立于渐近验收

不同函数可以有相同的最终增长关系，却在任意有限前缀差异很大。基本列的前缀会影响 FαM(k)，所以“最终支配”不能单独证明选定 k 的数值很大。

建立数值证书清单，至少包含：选定 k、实际使用的端点基本列项、若干精确定义的基准 F_β(m) 或其他大数、逐条比较条件及下界证明。基准需有实质强度，并与目标选择同时审阅，不能用微弱下界充当大数验收。

无需算出十进制展开。验收对象是封闭定义及可检查的下界证书。若 k 不满足比较阈值，应报告现有下界不足；调整 k 必须记录为新的数值定义。
