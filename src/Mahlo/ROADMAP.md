# 通往 F_{α_M}：类型宇宙飞跃研究路线图

日期：2026-09-08。性质：研究计划；其中待证命题不是已完成成果。

首轮进度见 [FINDINGS.md](FINDINGS.md)：U0/U1 部分完成，任意族算子的子宇宙与相容等式已通过 `--safe --without-K`。完整规则解释、5.10 的实际算子、关键良序引理和端点统一化仍开放；G1 尚未整体验收通过。

## 1. 目标与主线选择

目标是在 Agda 中，不添加公理、不关闭正性或终止检查，得到明确指向单个 Mahlo 宇宙证明论序数的可计算基本列，并据此定义快速增长函数。

固定参照理论为 Setzer 的 `MLM`，固定序数记号为该论文的系统：

\[
\alpha_M := |MLM| = \psi_{\Omega_1}(\Omega_{M+\omega}).
\]

这里 `M` 是参考序数分析中的 Mahlo 标记；目标是折叠后的可数序数。不得混用不同文献、旧代码中同名的 `ψ`、`Ω`、`M`。`KPM`、`KPM⁺`、内部 Mahlo 与外部 Mahlo 分别登记；不能只凭名称互换强度。

选择的主线是：

> **安全的宇宙闭包构造 → 实现对象理论的规则 → 重建 Mahlo 良序证明 → 统一端点 → 基本列与 FGH。**

Lens 是可选的证明组织与程序提取工具，暂不承担主线的强度承诺。W 型、归纳递归与有证明支撑的良基递归均可使用；“由类型检查器接受终止”不要求所有源代码调用都直接发生在记号的语法子项上。

研究成功的完整交付物包括：

1. 固定的序数记号、顺序及目标端点定义。
2. 目标以下极限的可计算基本列，以及目标端点自己的基本列。
3. 下降性、共尾性、所需的单调性与增长规律。
4. 在明确的 Agda 宇宙层级中得到的良基性／可达性证明。
5. 一个封闭的全函数 `FαM : Nat → Nat`，证明它满足约定的 FGH 方程。
6. 独立于函数命名的强度校准，说明该指标确实是参考系统的 `α_M`。

精确比较数值还需要固定基本列和迭代次数约定。只具有相同序数阶型，并不能让不同实现的 FGH 定义相等。

## 2. 与现有 OCF 路线的关系

[OCF/ROADMAP.md](../../probes/OCF/ROADMAP.md) 保留为原有探索记录。本文件是一条独立研究主线，不续接其 Phase 7–13 编号。

| 项目 | 原有迭代路线的主导方式 | 本路线 |
|---|---|---|
| 强度来源 | 延长已有 Higher／OCF 模板，增加指标、迭代层与对角化 | 构造对族算子封闭的子宇宙，用宇宙反射证明新的闭包性质 |
| 起点 | 已有 Brouwer 树及其 bounded trichotomy | 原论文的宇宙规则、有限记号与良序证明 |
| 决策对象 | 任意函数分支所代表的树及其界 | 有限记号；依赖函数留在证明层 |
| 主要进度 | 新增若干迭代层并解释其强度 | 一个新的宇宙规则得到实现，一个反射／折叠引理得到证明 |
| 端点 | 多轮扩张逐步逼近 | 从开始就设计 `α_M` 的统一共尾序列与证明 |
| Lens | 另一种候选表示 | 仅在能承载关键反射引理时加入 |

“飞跃”不意味着代码完全不用自然数递归。基本列必然由自然数索引，FGH 也需要有限迭代。区别在于：**自然数负责展开已由宇宙机制获得的强度，不负责通过反复复制旧模板来产生该强度。**

不把旧报告中的“Agda 下 Mahlo 不可能”“某段代码的输出类型决定精确强度上限”等判断作为前提。已有失败说明特定表示或证明方案遇阻；本路线仍需独立的可行性证明，也不预先宣称一定成功。

## 4. 总体结构：证明层与计算层

采用有限序数记号作为计算接口，宇宙闭包作为良基性证明的来源。

```text
参考文献的 MLM 规则与序数分析
             │
             ▼
更高 Agda 宇宙中的规则实现 ──► Mahlo 反射／distinguished sets 引理
                                      │
有限记号 OT、规范性、比较 ───────────────┤
                                      ▼
                          各初始段的可达性 + 统一端点证明
                                      │
有限复杂度范数、基本列 ────────────────┤
                                      ▼
                             可计算下降接口 → FαM
```

避免再次要求比较任意函数 `b s`、`b s′` 所编码的大树。比较算法作用于有限记号；其语义正确性和良基性由证明层提供。有限记号可比较并不使良基性自动成立。

可以使用显式记号、可达性证书或证书生成的树。暂不要求把全部结果转换回旧 `Ord₀`。如后来确有复用需求，再证明独立的转换正确性。

## 5. U0：锁定对象理论、端点与宿主预算

**优先级最高；在大规模实现前完成。**

工作内容：

1. 从 [S1] 的理论规则、§3 记号、§5 良序证明建立依赖表；记录每个外部引理来自何处，尤其是其引用的单宇宙加 W 型良序证明。
2. 把参考理论 `MLM` 与 Agda 宿主分开。写出哪些集合、谓词、族、算子位于 `Set ℓ`，哪些位于 `Set (lsuc ℓ)` 或更高层。
3. 提取原文中的阶段界。候选阶段为 `b_n = ψ_{Ω₁}(Ω_{M+n})`；逐一核查起始下标、合法性、严格增长及 `sup_n b_n = α_M`，不只从显示公式假定连续性。
4. 立即审计 §5.14 中“对每个 n”的量词位置：是对象理论内的统一定理、元理论中的定理模式，还是依赖不同环境的证明族？
5. 为端点证明选择一个固定的宿主层级／闭包条件。若目前只能说明每个 n 分别可实现，必须把统一化缺口显式列为阻断项。

候选解释方案：将对象 Mahlo 宇宙的代码类型解释为宿主的 `Set ℓ`，把它放入更高的宿主 sort，并以解码及必要的 `Lift` 处理大小。

该方案利用的是：对给定外部族算子，可用参数化 IR 构造一个小子宇宙。它避免把所有任意算子装入同一个递归数据类型的负位置。**这是待验证的解释候选，不是已经完成的内部 Mahlo 实现。**

需要核对：任意允许的对象算子是否均可解释；子宇宙代码和解码是否大小正确；代换、限制映射、等式规则是否保持；`Lift` 是否破坏证明依赖的计算规则。不得给 `Set` 添加按其全部类型构造分析的消去器。

交付：`THEORY.md`、`RULE-MATRIX.md`、`ENDPOINT.md`。其中每条规则标“已构造／仅文献成立／缺口”。

通过条件：得到可审计的理论对应与端点证明方案，所有宿主假设写明。没有端点方案时，只批准短小的 U1、U2 可行性探针，不批准完整库开发。

## 6. U1：真实宇宙反射的最小安全实现

以 [S1, S2] 的规则和 [S3] 的作者代码为依据，保留来源与复现信息；不从本地简化 `mahlo` 树反向猜测宇宙规则。本轮独立实现仅用内建依赖，避免整体导入定义了 K 的旧辅助文件；详见 [THEORY.md](THEORY.md)。

核心数学接口：

\[
\mathrm{Fam}(\mathrm{Set}_\ell)
 = \Sigma(A:\mathrm{Set}_\ell).(A\to\mathrm{Set}_\ell).
\]

对任意允许的族算子 `f`，构造其小子宇宙 `(U_f,T_f)`，并证明限制映射与解码相容：

\[
\iota_f\circ\mathrm{Res}_f=f\circ\iota_f.
\]

“任意”指量化的参数，不是只测试若干预先列好的算子。构造必须包括后续原证明真正需要的 Π、Σ、自然数、W 等闭包。

验证重点：

- 开放参数 `f` 下的封闭性证明，而非只验证恒等算子实例。
- 至少一个原良序证明所需的非平凡族算子实例。
- 在没有额外分层限制的情况下保留该算子的作用。
- `--safe --without-K` 检查完整依赖闭包。

通过条件：U0 中关键 Mahlo 规则获得对应实现；单有 `data U` 编译成功不算通过。

停止条件：若必须限制成固定算子列表、加入旧 `strat` 条件，或关闭检查，则先记录丢失的规则并重新评估强度，不继续称它为目标 `MLM` 的实现。

## 7. U2：有限记号与基本列的计算可行性

U0 给出参考系统后，本阶段可与 U1 的数学工作交错进行。

按 [S1] §3 建立有限原始项、合法记号判定、顺序、所需的有限支撑／闭包测试。先实现原文真正用到的最小片段，再扩至 Mahlo 标记与相应 ψ 项。

比较算法递归于有限项及辅助复杂度。为互递归给出明确的下降度量；不能仅凭论文称其“原始递归”就假定 Agda 接受现有写法。这里允许有证明的良基递归。

基本列首选方向：审计 [S4] 的范数方法。其一般形态是从满足复杂度界的较小记号中取最大值：

\[
a[n]=\max\{b<a\mid N(b)\le B_a(n)\}.
\]

这只是研究接口，**不是已选定的基本列公式**。必须落实 `N` 与控制界 `B`，证明候选集可有效处理、最大值计算终止，并核查 [S4] 的假设在 `MLM` 扩展记号上成立。范数可能不直接界定所有语法编码，不能省略有限枚举／规范化论证。

对非零极限需要下降、单调和共尾；若使用非严格递增列，须证明它不在真初始段停滞。对后继统一返回前驱，零单独处理。进一步按增长校准需求验证 Bachmann 性质或相应替代条件。

通过条件：得到可执行的基本列候选与明确的正确性义务；不能以有限输入测试替代共尾性证明。

若范数方案在目标扩展上不适用，则研究显式 ψ 基本列规则。两者都是同一宇宙主线的计算接口，不是退回 Higher 的自然数指标扩张。

## 8. U3：重建宇宙驱动的良序证明

这是主线的核心研究投入。按原文依赖顺序移植证明，而不是先实现整套高阶 Lens。

### U3a：最小的前置宇宙闭包证明

从 Setzer 的单宇宙加 W 型分析中提取后续必需的 accessibility／distinguished sets 工具。仅移植 Mahlo 步骤实际依赖的部分。

这不是要求逐一完成 ε₀、Γ₀、大小 Veblen、BH、BTBO 的全部工程阶梯。低阶例子只作为比较、基本列和 FGH 约定的校准，不作为主线里程碑。

### U3b：Mahlo 的决定性反射步骤

优先解剖 [S1] 的 Lemma 5.10 与 5.11：构造作用于族的算子，取得对该算子封闭的子宇宙，再由 distinguished sets 论证取得新的闭包与可达性。

需要展示：具体是哪一个宇宙闭包规则使原来无法得到的结论成立；该规则在 U1 中如何实现；所得结论对应哪些合法 ψ 项。

每个关键引理同时记录：

- 原论文陈述和位置；
- 宿主中的精确类型与宇宙级别；
- 所需代码、解码与限制映射；
- 递归来源；
- 是否仍有未实现前提。

### U3c：到达各阶段界

把反射结果与 W 型所提供的后续闭包结合，重建原文 §5.14 的阶段性良序证明。

通过条件：取得与参考记号系统对齐的实质下界证明。`Mahlo` 构造子存在、程序在输入 1 时算出 2、输出类型叫作 `Ord`，均不计为强度证据。

停止条件：若所有已完成结果都能删去 U1 的关键反射操作而原样成立，需要检查是否只实现了较弱前置片段；尚未展示飞跃的引理不得报作 Mahlo 完成。

## 9. U4：把阶段性证明统一到 α_M

U0 先设计，本阶段落实。不能留到最后才发现统一化不可表达。

一个候选端点列是 U0 核验后的 `b_n`。但知道每个 `b_n` 的初始段良基，并不自动给出 `Acc(b_n)`；要覆盖该界本身，还需在更大的已证阶段中取得它，或单独证明该界的可达性。

本阶段必须交付：

1. 封闭项 `bound : Nat → Notation`，不是为每个 n 生成一份不同源代码。
2. 统一的可达性证书族，覆盖所选 `bound n` 及其递归所需前驱。
3. `bound` 严格上升或适当单调且共尾于 `α_M` 的校准。
4. 一个端点记号／带证书的极限对象 `Top`，其基本列由 `bound` 给出。
5. 在一个固定、明确的宿主框架中，得到 `Top` 的下降递归原理。

禁止把“每个阶段在某个宇宙中分别可表达”直接改写成“存在统一的阶段函数”。特别检查递归中是否悄悄需要 `Set ℓ`、`Set (lsuc ℓ)`、……不断变化，而当前签名不能容纳它们。

若端点统一化需要更强宿主，就回到 U0 指定并构造该宿主机制。较高宇宙或对 next-universe／子宇宙构造的进一步闭包是候选，不能未经证明宣布“再加一层就够”。

通过条件：目标端点的统一、可执行下降对象存在并被安全检查接受。只有各有限阶段时，报告“初始段成果，端点未完成”。

## 10. U5：接入 FGH 与最终强度校准

为延续现有数值约定，可采用：

\[
F_0(n)=n+1,\qquad
F_{a+1}(n)=F_a^{\,n}(n),\qquad
F_\lambda(n)=F_{\lambda[n]}(n).
\]

该约定的输入 0 行为可能退化；不能用少量小输入评估强度。若改用 `n+1` 次迭代，应作为显式版本变更，重新校准。

主实现采用 U3–U4 提供的可达性证书做良基递归。也可以先将证书编译为携带所选基本列的树，再结构递归，但必须证明转换保留下降接口与 FGH 方程。

最终验收：

- `FαM : Nat → Nat` 为封闭定义，无待填参数或公理。
- 完整依赖通过固定版本的 `--safe --without-K`；记录可复现命令。
- 零、后继、极限以及 `Top` 的求值方程得到证明。
- 基本列及 endpoint 的语义校准闭合。
- 若要主张“支配 MLM 的可证全函数”，单独证明相应增长比较，不能仅引用针对 `KPM` 的 Hardy 结论。Hardy 与本 FGH 约定之间的换算也须交代。

无需实际展开天文规模的十进制输出。最终大数是 `FαM k` 的可计算定义及其证明；求值测试用于检查实现约定与错误分支。

## 11. Lens 的重新准入条件

在 U1–U3 出现明确数学接口后，Lens 只做有边界的探针：

> 能否将一个实际的 Mahlo 反射／折叠引理组织为带依赖的实现变换，同时保留参考序数下界和所选基本列？

探针必须给出准确输入、输出、语义关系、宇宙预算，以及它消除了哪一项主线证明负担。若只产出新的高阶类型或 Church 项而无校准，不进入主线。

本地 [Lens/NoCubical.agda](../../probes/Lens/NoCubical.agda) 的 `deriv`、`veblenLens`、`Gamma0` 标签目前不能作为已证引理。有限迭代闭包不是不动点枚举；`φ_ω(0)` 也不是标准 `Γ₀`。修复这些低阶问题可以服务于获准的探针，但不单独启动完整 Lens 工程。

Lens 失败不阻断主线。若它成功，仍必须完成 U4 的端点统一化和 U5 的增长校准。

## 12. 推进顺序与研究决策

| 关卡 | 最小可审阅产物 | 决策 |
|---|---|---|
| G0 | 对象规则表、宿主候选、端点量词与层级审计 | 允许针对性可行性探针 |
| G1 | 任意允许族算子的安全子宇宙构造与规则对应 | 决定是否投入完整良序证明 |
| G2 | Mahlo 关键引理的完整证明草案；计算接口的可行性证据 | 通过后扩大实现；否则定位确切缺口 |
| G3 | 已校准的阶段良基性和统一端点 | 开始最终 FGH 封装 |
| G4 | `FαM`、基本列与强度证明、可复现检查 | 目标完成 |

U2 可与 U1／U3 交错，但在 G1、G2 未通过之前，限制在检验主线假设所需的最小实现。此处“交错”是任务依赖安排，不要求使用多代理。

不沿用旧路线图中的 LOC 与成功概率估计；目前不足以支持数值精度。主要风险依次是：对象理论规则实现、Mahlo 引理的构造性移植、端点统一化、基本列规律与增长校准。

第一次研究迭代只安排四个交付：

1. 写全 U0 规则表，尤其标明内部／外部 Mahlo 的桥接义务。
2. 固定版本复现作者外部子宇宙代码，并审计更高宇宙解释候选。
3. 拆解 Lemma 5.10、5.11 和 Theorem 5.14，列出最小依赖及统一化需求。
4. 提出适配目标记号的范数／基本列方案，列出必须证明的具体命题。

第一轮不承诺完成一个全功能序数库。它的成功标准是排除或落实关键桥梁，从而能有依据地决定下一阶段投入。

## 13. 失败结果的处理

| 遇阻位置 | 正确结论与后续 |
|---|---|
| 直接内部 Mahlo 数据声明被正性检查拒绝 | 该编码失败；继续审计更高宇宙解释候选，不关闭正性检查 |
| 外部构造不能实现某条 MLM 规则 | 准确标明较弱对象理论；研究补足规则的安全宿主机制，不将目标偷偷改成外部变体 |
| 原证明某处使用宿主中尚无的原则 | 记录该原则与必要性，寻求构造性替代或另一项已实现的宇宙闭包 |
| 只有逐阶段证明，没有统一族 | U4 未通过；研究所需的闭包／宇宙预算，不以更多固定 n 的例子替代 |
| 范数方法的目标扩展假设不成立 | 换显式基本列或适配记号，保留已完成的宇宙证明 |
| 旧树桥接仍需不可得的全局三歧 | 保留有限记号加证书主线，暂缓桥接 |
| 所有安全宿主候选均存在实质缺口 | 输出精确缺口和已证初始段；暂停主线，不改报成功或全局不可能 |

## 14. 与仓库的实施边界

本路线的文档与后续实现统一放入 `src/Mahlo/`，避免混淆旧 Phase 编号。历史探针已归档到 `probes/OCF/` 与 `probes/Lens/`；成品 `src/OCF/BTBO.lagda.md` 保留原位。默认文档构建只发布成品文章，不发布本研究目录或探针。

模块职责（目前仅 `Universe/External.agda` 已实现；其余为后续计划）：

- `Universe/`：族算子、子宇宙、规则实现与宇宙预算。
- `Notation/`：有限项、规范性、比较、支撑与目标界。
- `WellOrder/`：distinguished sets、反射、初始段与端点证书。
- `Fundamental/`：范数、基本列与规律。
- `Growth/`：FGH、求值方程与增长校准。
- `Evidence/`：来源、证明状态、阻断项及复现说明。

可复用 OCF 的算术与证明技巧；复用前核查其前提和语义。`PastBTBO/Mahlo` 用作失败案例，不默认其 `Op/Sub` 骨架等同原论文宇宙。Lens 的 FGH 代数可供约定对照，不默认其高阶项名称已获证明。
