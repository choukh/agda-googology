## 2. 5.10 的实际算子

原文依据：[Setzer Mahlo 论文](https://csetzer.github.io/articles/mahlo.pdf)，直接查看第 19 页的 5.10–5.14；宇宙翻译依据第 12–14 页 4.6–4.9。以下采用宿主类型重新表达，不声称逐字复现对象推导。

为避免混淆，记 `W(A)` 为正归纳生成谓词，`𝒲` 为所有小 distinguished 谓词的并；它们不是同一个对象。固定 `a ∈ 𝒜^𝒲(𝒲)`，首先需要一个小 distinguished 谓词 C，满足 `a ∈ C^a(C)`。

对输入族 `q = (X,Y)`，先构造常值族算子的子宇宙 `U_q = Close (λ _ → q)`，再取该子宇宙内部的 distinguished 并 `𝒲_q`。置

```
D_q = 𝒲_q ∪ C
B_q = C^a(D_q) ∩ a
```

目标是构造小 distinguished 谓词 E_q，满足 `B_q ⊆ E_q ⊆ 𝒲`。所需算子恰为

```
F(q) = (Nat, E_q)
```

**F 的构造使用常值算子的 U_q，而不是 Close F。** 因而没有在定义 F 时直接调用它自己所生成的宇宙；只有 F 定义完毕后才使用 `Close F`。这消除了表面自指，尚未构造出 E_q。

### 类型与层级表

以下大小结论以各项尚待证明的编码／转移成立为前提；不是将它们假设为项目公理。

| 项 | 宿主类型／层级 | 已有机制或缺口 |
|---|---|---|
| q | `Fam : Set₁` | 已实现 |
| U_q、El_q | `Set`、`U_q → Set` | 常值重编码已实现 |
| U_q 中谓词的代码 | `Nat → U_q : Set` | 已有代码接口 |
| 𝒲_q(x) | `Set` | 可对小代码及小的 distinguished 证书作 Σ；实际证书编码与正确性仍待接入 |
| C、D_q、B_q、E_q | 各为 `Nat → Set`，类型本身在 `Set₁` | 需要实际闭包的小性与 distinguished 并／扩张定理 |
| 𝒲(x) | `Set₁` | `SmallCover.Global` 已体现此大小差异 |
| E | `Fam → (Nat → Set)` | 需要从每个 q 的数据统一构造见证，不能只给逐个存在性 |
| F | `Fam → Fam` | 若 E 已构造，`q ↦ (Nat,E q)` 正好匹配现有 `External` |

小覆盖的可能构造已经具体到：给定 `B_q(x) → 𝒲(x)` 的带见证映射，以 `Σ x : Nat. B_q(x)` 为索引收集 distinguished 谓词，再取其并。这个索引在 Set。当前代码能收集见证，但其并 distinguished 的具体定理仍欠缺。

这不是无条件的选择公理：前提必须真的提供每个成员的见证。若只有截断存在性，此构造不能直接使用。也不需要把整个 𝒲 缩小到 Set。

## 3. 反射证明的最小骨架

以下每步列出的性质都必须证实；这份骨架不是已完成证明。

**第一步：小见证。** 从 a 的资格提取 C。需要参考闭包的有限支撑定理及小 distinguished 覆盖。第四轮算法的有限支撑性质尚不能替代参考闭包对应。

**第二步：构造 E_q。** 证明 D_q distinguished 且包含于 𝒲；闭包单调性和 a 的前驱闭合给出 `B_q ⊆ 𝒲`。再对小的 B_q 使用上述收集与并定理。

**第三步：反射资格。** 在 `U_F` 中通过 `res₀/res₁` 取得 E_q 的谓词代码，证明其解码是外部 E_q，并把 distinguished 性质转回内部。

这里有一项可简化的候选移植方案：用 `U_F` 已有的自然数代码及恒空族作为第一次 restrict 的输入，而不预先要求任意 C 都已有 U_F 代码。因为每个 D_q 都包含 C，E_q 都覆盖 `C ∩ a`；结合 `a ∈ C^a(C)`、同一截断点的种子限制及单调性，仍有希望得到内部资格。此方案是本项目提出的条件改写，尚未形式化；不据此判定原文有误。

**第四步：反射前驱闭合。** 对内部闭包成员，先缩到内部小 distinguished 谓词 A；把其解码族 q 重编码入 U_q，推出 `A ⊆ 𝒲_q`。算子输出 E_q 再覆盖所需前驱，且 E_q 在 U_F 中有代码。由此尝试取得 `C^a(𝒲_F) ∩ a ⊆ 𝒲_F`。

**第五步：从 5.10 到 5.11。** 对 a < M，使用 5.7 识别反射后的初始段，再证明把 a 加入该初始段得到 distinguished 谓词。因为 𝒲_F(x) 在 Set，该扩张可作为外部小见证，得到 a ∈ 𝒲。

### 不能藏在接口中的债务

| 编号 | 必须补的数学内容 |

| R1 | 参考闭包的有限支撑、单调性与截断限制 |

优先追查 R3 与 R5 的完整证明草案；R2 保留为必做的前置证明。只给 F 一个 Agda 类型而把这些都当参数，不算通过反射关卡。

## 4. 阶段到端点的宇宙预算

本轮最小实验：[StageBudget.agda](StageBudget.agda)。它确实使用了有限支撑成员和已有正归纳生成模块，不仅是给一个任意端函数取名字。

| 对象 | 固定大小 |
|---|---|
| 有限支撑族 | `List (List Nat) : Set` |
| A(x)、C^a(A)(x)、M(A)(x)、τ_A(a)(x) | `Set₁` |
| W(A)(x) | `Set₁` |
| `Class = Nat → Set₁` | `Set₂` |
| `stage : Nat → Class` | 在固定状态类型上作 Nat 递归 |

实验实现了以下形状：

```
stage 0     = 𝒲 ∩ M
stage (n+1) = W(stage n) ∩ Ω_(M+n+1)
```

合法性、次序、有限支撑、𝒲、M 与阶段界的自然数代码均为明确参数。代码在 `--safe --without-K` 下通过，说明**在这些参数提供的固定层级下，阶段构造本身不要求逐阶段提升宇宙或把 𝒲 缩小**。

这仍不证明：阶段 distinguished、相邻阶段初始段一致、阶段界属于下一阶段、任何 TI 或 α_M 的可达性。尤其统一的阶段数据不等于统一的阶段证明。

下一项统一证明的候选不变量包含：阶段的 distinguished 性质、相邻阶段的一致性及相应 Ω 界的成员证书。需要将这些性质推广到上述大谓词，并实际给出零阶段证明与保持步骤。其类型可以在固定较高层表达；保持步骤是否成立还需数学证明。

端点还需要合法且共尾的 `b_n = ψ_{Ω₁}(Ω_{M+n})`，以及统一的 `TIbelow(n)`。若只获得 b_n 以下可达，可用已证的 `b_n < b_(n+1)` 从下一阶段取得 b_n 的证书。再结合选定的 Top 基本列构造端点下降证书。共尾性、阶段移位、统一证书和基本列不能互相省略。

这里使用较强宿主组织证明，不是在宣称 MLM 自身证明了其全部统一端点结论。对象理论与宿主继续分开。

## 5. 量级认证：来源追踪结果

找到两项更明确的上界入口：

- [Setzer，A Model for a type theory with Mahlo Universe](https://csetzer.github.io/articles/uppermahlo.pdf)，1996 草稿 §6：模型及向 KPM⁺ 的解释，上界结果；其中定理证明仍有引用和改造前文的步骤。
- [Setzer，Universes in Type Theory I — Inaccessibles and Mahlo](https://csetzer.github.io/articles/modeltypetheoryinaccessiblemahlo.pdf)，§5，Theorem 5.3–5.4：模型和与 KPM⁺ 的证明论强度对应。

这些已核查结果支持继续追踪上界证明，**本轮没有从它们取得“给定 MLM 可证全性证明，输出所选 FGH 的计算界”的定理**。这不等于文献中不存在该结果。

待核验的桥接链为：选定 MLM 程序／全性证明表示 → 保持自然数计算意义的 KPM⁺ 证明翻译 → 定量消去／见证界 → Hardy 或下降界 → 本项目 FGH 界及端点吸收。每个箭头都要有具体定理；不能用 KPM 的层级结果直接替代 KPM⁺，也不能从两个理论证明论序数相同推出该计算结论。

基本列候选仍见 [FUNDAMENTAL-PLAN](../FUNDAMENTAL-PLAN.md)：范数方案在目标扩展上的适用性尚未落实。本轮未改变 C、D 两关未通过的状态。
