# 从类型宇宙提取基本列：文献与纸面可行性评估

2026-09-09。本轮仅作文献调查和纸面推理，不新增代码。本文修正 EXTRACTION-PLAN 中“下一轮直接实现规则语法”的安排：先论证关键桥梁，再决定是否实现。

## 结论

**受限、显式呈现、由元理论认证的统一提取路线值得研究；从任意语义宇宙直接读出其精确证明论序数及基本列，目前没有依据。** 本轮核对的资料提供三类局部正面结果：良基性证明的程序内容、系统化的宇宙强度下界构造、从抽象序变换生成坍缩记号。没有一篇被核对的资料已经把三者合成为适用于本项目 Mahlo 宇宙的自动提取定理。检索未发现不等于证明不存在。

需区分四个目标：

| 目标 | 判断 |
|---|---|
| 对任意类型 A，直接给出“它的序数和基本列” | 输入信息不足：类型没有指定前驱关系，宇宙闭包也没有指定精确序数秩 |
| 对显式良基构造／证明，提取下降程序 | 有扎实先例；须说明证明提供的关系和分支接口，不能称为从裸宇宙提取 |
| 从一类宇宙规则统一生成可计算序数表示和列 | 有邻近的通用构造支持；宇宙到这种构造输入的桥梁尚需研究 |
| 对本项目 MLM 精确达到 α_M，并认证 FGH | 未落实；即使前三步成功仍有覆盖性、上界、端点及定量校准问题 |

## 1. 文献实际支持什么

### 1.1 Hancock：可达性、交互程序和 lens

[Ordinals and Interactive Programs，2000](https://www.lfcs.inf.ed.ac.uk/reports/00/ECS-LFCS-00-421/) 的摘要把 lens 定位为系统化建立更强类型论下界的候选工具；研究对象含自然数及对依赖积封闭的外部宇宙序列。[正文 §5.1.3，印刷页 130](https://www.lfcs.inf.ed.ac.uk/reports/00/ECS-LFCS-00-421/ECS-LFCS-00-421.pdf#page=137) 明确登记 lens 的推广不足，以及希望研究新宇宙规则的工作。

[作者的序数与交互程序说明](https://www.dcs.ed.ac.uk/home/pgh/pt-ordinals.html) 给出 Stop／Wait／Read 的程序解释，并区分构造下界与确定精确界的困难。

**能采用的结论**：宇宙原则支持的证明可有实质下降计算内容，lens 是组织该内容的候选。**不能采用的结论**：lens 已是通用于 Mahlo 的提取器，或者作者的历史研究愿望已经成为定理。旧报告中“至今未解”一类断言不能仅凭旧论文推出。

### 1.2 Dybjer–Setzer：Mahlo 的关键边界

[Predicativity of the Mahlo Universe in Type Theory，§1–2、§6](https://csetzer.github.io/articles/dybjerSetzerWeylVolume2025/dybjerSetzerWeylVolume2025Final.pdf) 区分外部开放的 Set 与内部 Mahlo 宇宙；指出给后者添加自然的消去规则会产生 Palmgren 悖论。其意义解释通过对子宇宙内参数的局部检查处理循环性，而非提供任意 Mahlo 宇宙对象上的通用递归器。

**推论**：不能把“像遍历普通归纳类型一样遍历整个 Mahlo 宇宙”当作当然合法的提取方案。对外部语法或合法子宇宙递归仍可能成立；悖论不是这种元层提取的不可能性定理。该论文没有给出我们所需的自然数索引共尾列提取算法。

### 1.3 Freund：确有统一生成坍缩记号的先例

[Computable Aspects of the Bachmann–Howard Principle，arXiv v3，Definition 1.1–1.2、§4](https://arxiv.org/pdf/1809.06774) 从编码的 prae-dilator D 统一构造相对于 D 可计算的记号系统 ϑ(D)，并把该构造与良基性断言分开。输入包括线性序上的函子作用和自然的有限支撑；dilator 还须保持良序。

这是最直接的正面证据：**抽象结构到坍缩记号可以是一项统一的计算，而不必逐个手写目标序数。** 但任意族算子 F:Fam→Fam 不自动满足这些条件；文中的结论也不是一项 Mahlo 基本列定理。“Bachmann–Howard”是这里的构造名称，不能据此断定所有输入的统一强度上限，也不能据此认定已达 Mahlo。

### 1.4 基本列与增长性质仍须单独处理

[Kraus–Nordvall Forsberg–Xu，Type-Theoretic Approaches to Ordinals，§1、§4、§6](https://fredriknf.com/papers/ordinals_tcs2023.pdf) 解释了无限上确界与外延可判定性之间的构造性限制；普通 Brouwer 树的 sup 构造子也不自动等同于外延序数上确界。这直接警示我们此前从自然数分支树走向基本列的缺口。其 HoTT／商归纳归纳框架不能未经论证直接视为本项目安全 Agda 核心内的可用定理。

[Fernández-Duque–Weiermann，Fundamental sequences and fast-growing hierarchies for the Bachmann–Howard ordinal，§3、§8–10](https://arxiv.org/pdf/2203.07758) 对特定坍缩系统建立 Bachmann 性质、正则性及层级比较。它支持“量级需要额外正则性”的判断，不提供从任意宇宙生成这些性质的通用算法，也不能直接套用到 MLM。

## 2. 纸面排除：哪些直接方案不成立

以下是本项目的逻辑分析；不冒充上述文献中的现成 Mahlo 定理。

### 2.1 语义大小不是证明论强度

给定类型 A，尚无次序可谈。同一个自然数载体可搭配不同良序；单看元素构造不能唯一决定所需关系。给定宇宙闭包规则，又可能有不同大小的模型。因此，某个模型中宇宙或 W 树的集合论秩，不能直接认作理论可证明良序的上确界。

若要讨论 α_M，输入应是固定对象理论及其宇宙规则，而非任意宿主 Set 的全部能力。额外 Agda 宇宙可以服务元证明，但必须与被测理论分开。

### 2.2 不可枚举并不意味着没有有限观察

对任意 e:ℕ→(ℕ→2)，对角函数 d(n)=1−e(n)(n) 不在枚举中。因此不能要求全部 El(a) 都有满射枚举。另一方面，某个特定程序可能只查询有限多个函数值，这与不可枚举性完全相容。

但“每次计算只看有限信息”没有自动给出一个统一有效的观察模量，也没有保证观察覆盖所需序数秩。必须为选定的语言／操作另证连续性、支撑或模拟性质。上一轮把“接下来实现有限语法”当作已确定路线，证据还不够。

### 2.3 有限语法不能消除语义判定障碍

令 s_e(n) 判断机器 e 是否在 n 步内停机；这是具有有限代码的全函数。若一个通用过程既能精确构造任意这种 0／1 序列的序数上确界，又能判定该上确界是否为 0，就能判定机器是否永不停机，从而判定停机问题。

这排除的是“任意可计算序列的精确上确界＋可判定零”这一组合，不排除受约束的基本列、不可判定的外延表示或保留内涵语法的提取。自然数索引、有限源代码本身都不够。

### 2.4 树下降与序数基本列之间有真实缺口

若树节点所有孩子都表示 0，采用通常的序数 supremum 语义，其上确界还是 0，孩子并不严格下降。若改用树秩

ρ(node(f)) = sup_n (ρ(f(n)) + 1)，

则该节点秩为 1，虽然有无限多个分支，却表示后继而非极限。因此不能按构造子 `sup` 直接分类为 FGH 的极限分支。

要输出基本列，需约束分支严格递增，或另给能正确处理后继／极限的表示及正规化；不能既允许任意宿主函数，又默认外延分类可判定。

## 3. 纸面正面结果：什么时候可以提取

### 3.1 连续闭包的基本列确实由构造给出

设 f 是严格递增且在极限处连续的序数函数，a<f(a)。令 a₀=a，aₙ₊₁=f(aₙ)，λ=sup_n aₙ。由严格递增，aₙ<aₙ₊₁；由连续性，f(λ)=sup_n f(aₙ)=λ。任意不小于 a 的 f 不动点都支配所有 aₙ，所以 λ 是不小于 a 的最小不动点，其基本列可直接取 aₙ。

例如 f(ξ)=ω^ξ、a=1 得到 1,ω,ω^ω,… 及 ε₀。这是统一闭包构造的例子，而不是 Mahlo 的证明。用于类型宇宙时，还必须证明相应宇宙操作的序数解释具有这些性质。任意 Fam 算子没有自动给出保序性或 ω 连续性。

### 3.2 已生成有效良序后，共尾列有通用构造

假设已经得到一个可计算表示的线性良序 O，其域和比较可判定，并且输入 λ 附带“非零极限”的正确信息。依自然数编码扫描 O 中低于 λ 的元素，初始先搜索一个低于 λ 的元素；随后取每个有限前缀中的最大值 bₙ。

所有 bₙ<λ，且 bₙ≤bₙ₊₁。对任意 γ<λ，由 λ 是极限，可取 γ<δ<λ；枚举最终遇到 δ，所以 bₙ 最终超过 γ。若需要严格递增，可在每次得到 bₙ 后继续搜索一个更大的低于 λ 的元素，极限性保证搜索终止。

这是条件性纸面算法；不提供一般良序的可判定极限分类，也未证明在当前宿主内的统一终止证书。它说明一旦有效表示与分类具备，“给出某套共尾列”可以很通用。所得列依赖编码，Bachmann 性质和有效 FGH 比较仍不由此推出。

此前的高度搜索思想可在将来作为这一层的候选复用，但前提是记号由宇宙提取产生，且完成增长校准；不能把已有手写 OT 换个接口就算完成主线。

### 3.3 值得审计的中间表示

候选研究图式是：

```
对象宇宙规则 R
  → 有有限支撑／相容性的序变换描述 D_R
  → 统一的反射或坍缩记号生成
  → 有效逼近及基本列
  → 独立强度与增长校准
```

Freund 的结果支持其中某类输入的中间一箭头。第一箭头和 Mahlo 所需的推广仍是待研究命题，最后两箭头也不能省略。不是要求所有 Fam 算子本身都是 dilator；可能需要把整个规则的证明作用解释为这种对象或更高阶的类似结构。

最关键的纸面义务：对宇宙规则的组成给出组合式解释，证明代换与嵌入相容、支撑条件，以及强度覆盖。源代码有限不等于序变换具有有限支撑；含函数参数的有限表达式仍可能对语义对象有无限依赖。

Lens 是另一种组织这种解释的候选，不能仅因名称或低阶实例就先选定它。当前应比较它与 dilator／算子控制方法需要的实际假设。

## 4. 端点统一化不能隐藏在“自动”里

在足够强的外部元理论中，可以考虑枚举某个有效理论 T 的良序证明并对已认证的序作有限和，生成逼近其可证序数上确界的候选族。这至少说明“语法到共尾逼近”不在概念上依赖唯一的传统 ψ 记号。

但此想法需要固定良序表示和证明语法、证明枚举的正确性与覆盖性、具备有限和封闭性，并由元理论统一承认所有枚举证明的健全性。它没有免费提供对象理论自己的统一反射。还需解释其上确界为何是本项目的 α_M、内部基本列如何获得、编码引起的增长畸变如何控制。所以它可作可行性参照，不能作为规避 Mahlo 分析的捷径。

尤其，T 对每个具体阶段分别可证明良基，不等于 T 能证明所有阶段的统一可达性。若后者足以推出 Con(T)，在第二不完全性定理的通常假设下就不能要求一致的 T 自证。更强宿主可能承载元证明，但必须公开其所用原则。

## 5. 投入判断与下一步

建议继续做**有边界的纸面调查**，暂不投入新的语法、比较器或解释器工程。已有证据支持研究方向，不支持宣布 Mahlo 自动提取已有成熟方案。

下一份应交付一个“宇宙规则到支撑／反射结构”的候选引理，而不是代码：

1. 固定一个普通宇宙片段及精确消去规则，说明输入是什么；避免沿用宿主全部 Set。
2. 比较 lens 与有限支撑序变换，选出能解释 Π 和宇宙提升的候选；逐项列出需要的假设。
3. 纸面推导一次真正的宇宙提升，证明输出逼近的下降与共尾；不能只用预先给出的自然数分支树。
4. 单独把 Mahlo 的族算子闭包代入候选引理，定位它需要新增的局部性、反射或高阶支撑原则。若只有占位假设，就报告未通过。

通过上述关卡之后，再决定形式化什么。即使局部提取成功，对完整 MLM 的覆盖性和精确上界仍需独立分析，不能从若干下界实例外推。
