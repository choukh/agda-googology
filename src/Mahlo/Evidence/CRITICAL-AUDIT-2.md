# 第二次关键路径审计：性质转移与 5.6 的小性

日期：2026-09-09。继续[第一次审计](CRITICAL-AUDIT-1.md)的 R3、R5。来源为 [Setzer Mahlo 预印本](https://csetzer.github.io/articles/mahlo.pdf)，直接核对第 17–19 页图像，并追查第 12–14 页的翻译规则。

## 1. 决策摘要

有一项机制得到确认：对一个固定谓词，转移 distinguished 性质只需成员资格的双向映射，不必假定类型相等、代码相等、函数外延性或证明无关性。

有一项实际移植缺口浮现：5.6 所印阶段公式的一条生成规则引用了目标类 Z。现有代码和已审计的规则尚不能直接把该阶段编码为小谓词。需要证明一种只引用当前阶段的替代构造。局部 distinguished 覆盖的范围则可由 ψ 的严格指标界对齐，不构成另一项范围缺口。

因此继续针对该缺口做数学验证，仍不恢复完整记号比较工程。没有判定原理论不一致，也没有证明本项目已能完成 Mahlo 反射。

## 2. R3：固定谓词的性质转移

设同一自然数记号、合法性和次序下，谓词 A、B 有逐点双向映射。再给定对应的资格 M₀/M₁ 和前驱 Pred₀/Pred₁ 的逐点双向映射。

从来源生成证书构造目标生成证书时：资格沿正向转换；目标前驱沿反向转换，送入来源的归纳假设。这一步已有 `Locality` 的结构归纳支撑。

若 A 是 W₀ 的初始段，要证明 B 是 W₁ 的初始段：

1. B 成员先转到 A，取得合法性。
2. B 成员转到 A，再进入 W₀，最后转到 W₁。
3. 对 B 中的 x 和 W₁ 中低于 x 的 y，先把 y 转到 W₀，使用 A 的初始段性质，再把结果转回 B。

反方向同理。这个证明不使用任何映射复合等于恒等的定理。

[MemberTransfer.agda](MemberTransfer.agda) 已在任意相关宇宙层级下形式化该条件定理，启用 `--safe --without-K`。它检验了“是否必须增加外延性／K 才能转移初始段性质”这一具体疑点，没有替代实际 M、τ 的转换。

### 剩余准确边界

- 必须从参考闭包及其编码构造 M、Pred 的双向映射；不是把它们留作最终公理。
- 还要把代码中的生成谓词与解码后的生成谓词接起来，已有 `GeneratedCode.sound/complete` 可提供部分机制。
- 这是**一个已有代码的谓词**的转移，不是所有谓词的并在两个宇宙中相等。一般只能从内部小 distinguished 见证得到外部见证，不能反向把任意外部谓词编码进任意 U_F。
- 因而 R3 的“转移机制”已验证，R3 的 Mahlo 实例仍未完成，R4 的内部并性质也未完成。

## 3. R5：5.7 真正使用 5.6 的位置

5.7 按项结构分支；困难分支是嵌套 ψ 指标。其用途是：先由 5.6 找到所需前驱集合的小表示，再由 5.3 的局部覆盖论证推出成员资格。其他 ψ 分支仍依赖 5.1、5.4 及前置初始段定理。

所以 5.6 不是可省略的记号计算辅助：它提供把类上的事实送回小宇宙的关键表示。该步骤若未落实，5.10–5.11 的类型表不能算可行性证明。

## 4. 5.6 的印刷公式与宿主缺口

写 `r = ψ_M(a)`、`t = ψ_r(b)`、`Z = C^t(𝒲) ∩ C_r(b)`。前提为 `t ∈ 𝒜^𝒲(𝒲)`。这里两种 C 分别是种子闭包和原文辅助闭包，不可混用。

第 17 页的 Y 下一阶段中，普通构造取当前 Yⁿ 的成员，但高指标 ψ 那一项量化的是 **κ、c ∈ Z**。页面不是 OCR 转写才出现 Z。

在我们的宿主解释中，𝒲(x) 及一般 Z(x) 可在 Set₁；引理目标却是给出 Z 的 `Nat → Set` 小表示。如果直接把这条引用 Z 的规则放入阶段生成器，现有小编码不能自动容纳它。必须给出独立的小表示、消去 Z 的等价条件，或改写生成规则。

这只是已核查预印本在本项目移植中的缺口。本轮未取得独立的出版版公式或作者勘误，不能据此断言文献定理错误。

## 5. 候选替代构造：只从当前阶段生成

提出以下本项目的改写，尚未形式化为参考系统定理：

```
Y₀ = SC_M(a) ∪ {0,M}
Yₙ₊₁ = Yₙ ∪ Y₀
       ∪ 从 Yₙ 的成员作合法普通构造所得项
       ∪ { ψκc | κ,c ∈ Yₙ，合法，r ≤ κ，c < b }
       ∪ 从 Yₙ 中低于 t 的成员及其证书选取的局部 distinguished 覆盖
Y∞ = ⋃ₙ Yₙ
```

显式保留 Yₙ，保证阶段递增。局部覆盖允许依赖成员证明；这里不要求按自然数 y 作与证明无关的唯一选择。

### 小性与包含方向

若每个局部覆盖有小代码，那么每一阶段只使用小的自然数索引、当前成员证书和 Π／Σ 等构造；自然数并也保持小性。阶段证明 `Yₙ ⊆ Z` 可随阶段一起递归维护。普通及 ψ 构造的保持性对应 5.5 的闭包条件；当前阶段项则由归纳假设保留。

这项修改去除了生成器对 Z 成员资格的直接调用，但没有去掉证明中对 `Yₙ ⊆ Z` 的使用。证明可在较大层，编码对象仍需保持小。

### 局部覆盖范围：可以对齐

5.5(d) 印出的范围是 `c ∈ Z ∩ r`，而 5.6 的覆盖规则使用低于 t 的阶段成员。由于合法 ψ 项满足 `t = ψ_r(b) < r`，低于 t 的范围包含在低于 r 的范围内。因此在已有阶段包含证明 `Yₙ ⊆ Z` 下，可以使用 5.5(d)。这里需要指标界及传递性，但不需要扩大该引理的适用范围。

5.5(d) 本身仍须取得构造性证明及代码，其所承诺的小覆盖不能留作最终公理。这个依赖不以整个 Z 已有小表示为前提。

## 6. 反向包含的证明路线与债务

目标是 `Z ⊆ Y∞`。替换高指标 ψ 规则后，有限多个子项若分别进入不同阶段，可用阶段递增性把它们提升到共同阶段，再使用下一步生成规则。

首先尝试重建原文辅助命题：

```
x ∈ OT，SC_M(x) ⊆ Y∞，G_M(x) < b  ⇒  x ∈ Y∞。
```

候选证明按 x 的语法结构归纳。基本／普通构造处理子项；ψ 项若低于 M，其 SC_M 包含该项本身，可直接使用前提；若不低于 M，则通过 SC、G 分解把前提传给两个子项，并从 G 条件取得参数界，使用高指标 ψ 规则。该说明仍依赖真实比较与支撑分解定理，尚不是完整形式化证明。

再按 Z 中项的结构分支：普通构造用子项，高于截断 r 的 ψ 分支用两个较短参数及共同阶段；低于 r 的分支沿原文的 Ω 后继指标、M 指标及 ψ_M 指标分类，使用辅助命题和局部覆盖。第 18 页各个嵌套 ψ 比较分支的前提传递仍需逐项核验。

需要完成的可审阅结论是：

1. 5.5(d) 的小覆盖有实际构造，并用 `t < r` 正确接入阶段规则；
2. 改写后的 Y∞ 满足辅助命题；
3. 每个剩余 ψ 分支确实进入 Y∞，没有在证明中提前使用目标全局良序性或 Z 的小性。

在这三项完成前，候选改写不能记为修复成功。
