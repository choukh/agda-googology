# 当前主线：从类型宇宙规则统一提取基本列

2026-09-09。用户澄清后的研究目标。本文件取代旧 ROADMAP、CRITICAL-PATH 和 DEFINITION-FIRST 的执行主线；目标强度与 CALIBRATION 的 C1–C7 保留。

**当前执行约束：先文献调查和纸面可行性论证，不直接实现 E1。** 最新[可行性评估](Evidence/EXTRACTION-FEASIBILITY.md)给出条件性正面结果、失败方案及尚未接通的 Mahlo 桥梁；下文 E1 的代码交付仅在纸面方案通过后启动。

后续[理论探索一](Evidence/EXTRACTION-BRIDGE-1.md)排除了直接将 Π 的全函数语义当作有限支撑操作的方案，并核对了“有效理论到递归证明论 dilator”的通用定理。[理论探索二](Evidence/EXTRACTION-BRIDGE-2.md)进一步简化端点共尾族所需假设，并排除“任意认证递归良序的精确规范化与可判定分类”。当前优先研究由规则产生有结构的证明上界；不直接实现汇总后的通用精确规范化器。

## 目标和禁止的捷径

输入一个明确呈现的类型宇宙规则系统，由通用技术产生可计算下降表示，进而得到基本列与 FGH。Mahlo 的 ψ 语法、端点列和下降公式不能由调用者手工提供。Setzer 的目标序数只作为独立的强度校准基准，不作为提取器的计算输入。

这不是“先给参考记号和基本列，再用宇宙证明良基”。旧路线的代码保留作校准探针；不能将它们接到输入端而宣称完成自动提取。

“自动”允许预先固定编码、归约策略和自然数调度。所有选择必须对支持的规则统一定义，不在 Mahlo 实例处植入目标答案。不能预设任意宇宙都存在一个通用、完备的提取器。

**逐证明上界与整体精确性**：允许提取结果高估某份证明所认证的序，但全部输出必须低于目标端点并在其中共尾，且具有有效下降与增长比较。不得以“逐项精确恢复任意递归良序”为要求，也不能用更强宿主的序数充当统一上界。纸面对象固定为内涵 MLM；额外上层宇宙、一般 Acc 与完整 Agda 规则须各自交代，不默认纳入。

## 输入输出契约（研究规格，尚无通用实现）

输入候选是带绑定的有限规则语法：类型形成、引入、消去、计算规则，以及 Π、W、宇宙及归纳递归闭包的明确描述。`V = Set` 和任意宿主函数 `F : Fam → Fam` 本身不是可供模式匹配的规则语法。

输出分两层：首先从合法构造／推导提取下降对象和归约保持证明；然后给出这些对象的统一有效逼近、序数解释及目标端点。只映射单个 W 树不等于捕获一个宇宙的强度。

验收要求：

1. **计算来源**：每个分支由输入规则及通用调度产生，无手填序数列。
2. **正确性**：语法归约与提取下降有明确的模拟关系，下降有良基证明。
3. **基本列语义**：区分零、后继与真正的极限，证明下降、共尾及所需单调性。任意 `Nat → Tree` 不是自动合格的基本列。
4. **覆盖性**：不遗漏目标理论的相关推导／归纳能力；说明宿主额外能力只服务于元证明，未被偷偷计入目标强度。
5. **校准**：独立对应 α_M，并完成 C1–C7；两个方向及有效界都须交代。

## E0 已执行：可数分支提取与一个障碍

[Extraction/Countable.agda](Extraction/Countable.agda) 使用仅含 `empty / unit / natural` 的小分支代码宇宙及其 W 树。统一提取规则为：

```
extract (node empty f)   = leaf
extract (node unit f)    = next (extract (f tt))
extract (node natural f) = sup (λ n → extract (f n))
```

它不导入 Mahlo 记号、比较或手写基本列。`preserves-child` 证明每个输入直接子树都对应输出下降；`all-accessible` 证明输出分支关系的可达性。自然数分支的有限链实例逐点归约为对应有限输出链，`finite-correct` 对所有 n 成立，不只是几个测试值。

**边界**：输入仍含用户给出的树和宿主分支函数；这是提取管线的一小段，不是从整个宇宙自动生成端点。`sup` 只是分支构造子，尚未证明它是严格序数上确界或具有共尾基本列。允许常值／重复分支，所以不能直接沿用 `Growth.Target` 的 limit 分类。

同文件的 `no-enumeration` 证明：不存在满射 `Nat → (Nat → Bool)`。给定候选 e，取 d(n)=not(e(n)(n))；若 d=e(k)，在 k 处矛盾。证明不使用公理、排中律或函数外延性。

这排除了“为每个 El(a) 统一枚举全部元素，再列出所有分支”的朴素扩展，因为当前 External 宇宙可表示 Π Nat (λ _ → Fin 2)。`InExternal.no-decoded-enumeration` 已直接对任意 F 的 `Close F` 中这个 Π 代码证明不存在满射；此障碍已连接实际宇宙代码。

它**没有**排除枚举封闭语法、按观察构造有限逼近、对证明做归约分析或更精细的坍缩方法，也没有证明自动提取不可行。

## 后续关键路径

| 阶段 | 决定性问题 | 下一件具体产物 |
|---|---|---|
| E1 语法呈现 | 从语义函数切换到规则语法后，能否统一获得可枚举观察？ | 先给含函数绑定与应用的最小类型化语法、解释和有限观察操作；证明观察与解释相容，不假定归约器终止 |
| E2 消去到下降 | 观察或归约树怎样产生严格下降且共尾的序数逼近？ | 对一个完整低阶片段证明提取正确性及覆盖性；不能只将自然数分支重命名为 limit |
| E3 宇宙提升 | 加入一个宇宙规则后，提取器的提升由规则统一导出吗？ | 同一算法处理加入宇宙前后两种输入；以独立已知分析校准差别，具体基准理论需先固定 |
| E4 Mahlo 闭包 | res₀/res₁ 与算子绑定如何呈现，如何产生坍缩？ | 为允许的算子建立语法及代换／归约规则，检验覆盖全部目标对象算子；不可只覆盖任意选出的可数子集 |
| E5 端点与量级 | 统一输出能否达到 α_M 而不超报？ | 提取端点族、两向强度与有效 FGH 比较，之后冻结大数输入 |

下一轮先为固定低阶片段给出“证明到有结构的下降上界”的纸面小定理，验证局部支配、整体覆盖及下降算法来源；同时明确 MLM 的良基证书语言。若采用归约证明提取，必须明确有限语法、可数语义和对象理论全部规则之间的区别，避免把“封闭项可枚举”误当成“语义类型可枚举”。

## 文献定位

[Hancock 的研究说明](https://www.dcs.ed.ac.uk/home/pgh/chat.html) 指出，可达性证明包含所表示序数的前驱结构。这支持调查“构造／证明到下降结构”的方向；不是已有 Mahlo 自动提取定理。现有 Setzer 宇宙与序数分析材料继续用作规则来源和独立校准；目前未确认一条可直接实现本契约的通用文献定理。
