# Mahlo：从类型宇宙规则自动提取基本列

**核心目标：建立一套从类型宇宙的定义规则中自动提取基本列的技术，将其用于 Mahlo 宇宙，得到具有严格量级证明的 F_{α_M}，最终构造相应的大数。**
