# U2：基本列方案与本轮证明义务

2026-09-09：用户要求先给定义，现已选定[高度搜索列 v1](UNIVERSE-AND-SEQUENCES.md)，控制界直接取 n，并给出具体有限枚举算法。以下未选定的范数／控制界方案作为先前计划保留；v1 的参考对应和增长规律仍待验收。

本轮只锁定计算接口与前提，不提前编写语义未经校准的 ψ 基本列。

参考 [Buchholz–Cichon–Weiermann，第 283–285 页](https://epub.ub.uni-muenchen.de/3849/1/16.pdf) 的范数方法；其中 KPM 实例不是 MLM 扩展端点的现成定理。

## 1. 候选接口

先按 Setzer 原系统建立有限原始项、合法性判定和次序。选择复杂度范数 N 与控制函数 B，研究

`a[n] = max { b < a | N(b) ≤ B(a,n) }`。

范数、控制界和最大值算法尚未选定。它们不是可以留给调用方的公理参数。

## 2. 必需的证明

| 层面 | 义务 |
|---|---|
| 语法 | 合法性、规范形式及参考系统的对应 |
| 次序 | 可判定性、严格序性质、参考语义正确性 |
| 有限搜索 | 复杂度有界候选可有效处理，最大值算法终止 |
| 基本列 | 对非零极限下降、单调且共尾，后继返回前驱 |
| 保持性 | 输出仍是合法记号，支撑约束保留 |
| 增长规律 | 所需 Bachmann 性质或有证明的替代条件 |
| 端点 | Top 的列与内部极限基本列分别校准 |

在上述规律建立前，仅凭“每项更小”不能推导目标增长强度。

## 3. 新合入的 Notation/Fusion 探针如何利用

历史 `probes/OCF/Notation/` 可提供有限项表示、带下降证明的返回值、证书驱动 FGH 的工程经验。其自身报告承认规范性、良基性和部分共尾性缺口；因此不直接复用其 ψ／I／M 语义标签。

若复用某段计算代码，须先给出到参考 Setzer 记号的对应。Fusion 的 `V t` 证明沿指定基本列展开可以终止，但不能独自替代指定列的共尾性，也不能自动证明完整记号顺序的良基性。

下一项交付是范数假设的逐条核查表；若方法不适用于目标扩展，再转向显式 ψ 基本列规则。

## 增长与数值验收补充

基本列方案还须支持 [CALIBRATION.md](CALIBRATION.md) 中的有效比较阈值、独立参考层级对应及具体输入的下界证书。仅有下降与共尾不算增长校准完成；允许任意长有限前缀的渐近结论也不能代替固定 k 的数值证明。
